## 1. 實作摘要

本次實作根據計劃「甲基化顯著性深入診斷與多層驗證策略」完成了以下功能：

### 1.1 新增資料結構 (Stats.hpp)

新增 `QualityFlags` 結構，包含：

- **CoverageCategory** 列舉：CNV_Loss, Low, Normal, Elevated, CNV_Gain, High_Copy
- **LOHSubtype** 列舉：None, LOH_Noise, LOH_Weak, LOH_Strong, LOH_Subclone
- **QualityTier** 列舉：High (>=70), Medium (40-69), Low (<40)
- **QualityFlags** 結構：整合所有品質評估指標

### 1.2 新增輸出欄位 (RegionProcessor.hpp)

在 `RegionResult` 結構中新增 7 個欄位：

| 欄位名稱 | 類型 | 說明 |
|:---|:---|:---|
| `hp_ratio` | double | HP1/(HP1+HP2)，範圍 [0,1] |
| `potential_loh` | bool | HP ratio < 0.1 或 > 0.9 時為 true |
| `coverage_multiple` | double | NumReads/75.0 (預期 Coverage 倍數) |
| `coverage_category` | string | Normal/Low/High/CNV_Loss/CNV_Gain/High_Copy |
| `loh_subtype` | string | None/LOH_Noise/LOH_Weak/LOH_Strong/LOH_Subclone |
| `quality_score` | float | 綜合品質分數 [0-100] |
| `quality_tier` | string | High/Medium/Low |

### 1.3 核心演算法 (RegionProcessor.cpp)

新增以下輔助函數：

1. **compute_hp_ratio()**: 計算 HP 比率，使用 Laplace 平滑避免除零
2. **is_potential_loh()**: 判定是否為潛在 LOH
3. **compute_coverage_multiple()**: 計算 Coverage 倍數
4. **determine_coverage_category()**: 根據 Coverage 倍數分類
5. **determine_loh_subtype()**: 根據 LOH 狀態和驗證類別決定 LOH 子類型
6. **compute_quality_score()**: 綜合計算品質分數
7. **determine_quality_tier()**: 根據品質分數決定品質層級

### 1.4 Quality Score 計算公式

```
Base score: 100

Penalties:
- NumReads < 30: -20
- NumReads < 50: -10
- NumCpGs < 20: -15
- NumCpGs < 30: -10
- Coverage < 0.5x: -30 (CNV loss candidate)
- Coverage < 0.8x: -15 (Low coverage)
- Coverage > 2.0x: -20 (High copy)
- Potential LOH: -25

Bonuses:
- HP and Allele tests both significant: +10
- Cramér's V >= 0.3: +15
- Cramér's V >= 0.2: +5

Final: clamp(score, 0, 100)
```

### 1.5 SignificanceAnalyzer 調整

在分類邏輯中加入 HP 平衡檢查，為後續 LOH_Subtype 追蹤提供基礎。

2. **Quality Score 區分能力提升**: AUC 從 0.519 提升至 0.6235 (+10.4%)

## 9. 建議

> [!IMPORTANT]
> Quality Score **不應**作為單獨的過濾器使用。

### 9.1 正確用法

1. **輔助診斷**: 用於識別低品質區域（LOH、Coverage 異常）
2. **風險分層**: 將結果分為 High/Medium/Low 風險層
3. **結合其他特徵**: 與 VCF QUAL、VAF 等結合使用

### 9.2 後續改進方向

1. **探索 QUAL + Quality Score 組合**: 先用 QUAL 過濾，再用 Quality Score 分層
2. **機器學習整合**: 使用 Random Forest 或 XGBoost 整合多特徵
3. **權重調整**: 根據更多樣本優化 Quality Score 的權重公式
