一、總結：系統做到哪裡、卡在哪裡

本專案利用 ONT 長讀長「同一條 DNA 分子同時跨越多個 somatic SNV」的能力，建立局部 mutation-state constraints，再把每個區塊轉成有向布林超立方體上的群組 Steiner arborescence 問題求解。 它的定位是可稽核的區域 mutation-state candidate reconstruction， 不是已恢復每個樣本真實的 cellular clone genealogy。

二、三層系統總覽：治理支撐程式、程式實作科學

整個系統可 MECE 拆成三個互斥層面。下層為上層提供保證：治理層約束 AI 與人的行為， 程式層把方法固化成可重現的二進位與腳本，科學層才產出可宣稱的結論。

三、科學管線：12 步端到端流程，每步都有對應驗證

流程的核心設計原則是「不混合」：不混合不同 phase set、不混合兩個 homolog、 不用距離取代 read 證據。每一步都綁一個可機械檢查的驗證條件（Step → Verify）， 任何一步 abstain 都是正式輸出，不是資料遺漏。

九個「尚未成立」的前提（不可當作已知）

UNPROVEN 展開九項尚未成立的前提 不可假設為真
  1. read-AF 可準確代表 cell prevalence。
  2. allele-specific CN／LOH、purity、multiplicity 已校正。
  3. arithmetic unique winner 具有統計穩定性。
  4. minimum states 等於真實 clone 數。
  5. hidden state 是已存在的細胞 clone。
  6. Sister／Direct geometry 可直接翻成多 clone／subclone。
  7. local PS×HP blocks 可拼成 whole-sample lineage。
  8. methyl association 可決定 edge、方向或 clone。
  9. 10,717 resource abstains 與 ranked subset 可互換外推。

八個已成立的前提

ESTABLISHED 展開已驗證成立的前提 可作為推論基礎
  1. exact PS×primary HP 分區與 strict linkage 已完成 chr1–22 全範圍執行。
  2. C++ 對 frozen read-AF 公式、minimum family 與 tie count 通過小型 exhaustive oracle 與 HCC1395 parity。
  3. family complete 時，minimum vertex-set family 是在現行 recurrence-allowed model 下的 exact 結果。
  4. 固定 vertex set 後，每個非根節點選一個 Hamming-1 predecessor 可形成 rooted arborescence。
  5. exact topology signature census 只對 71,955 ranked units 成立。

五、甲基輔助層：association-only，不進 topology 打分

甲基層在早期曾被期待作為 subclone 的獨立確認證據，最終定案為 bounded auxiliary —— 它是 pattern-conditioned regional association， 不改 edge、不重新打分 topology、不決定方向。

為什麼甲基不能當 subclone 確認器

用甲基確認 subclone 會形成循環論證：甲基本身受 germline haplotype（cis-ASM）與 CN-gain 影響。HP tag 可以消掉 germline ASM，但消不掉 CN-gain 造成的假象。 因此甲基的正式定位只有兩個：負向篩選與 L3 旗標。

十一、不應重踩的八個舊方向

這八條是已付出代價換來的邊界，重踩即浪費
  1. 以舊 50 kb adjacency 取代 strict read linkage。
  2. 混合不同 PS 或跨 HP 建樹。
  3. 把 recurrence-allowed model 寫成已強制 strict perfect phylogeny。
  4. 用 deterministic representative 當成 tied family 的真實唯一樹。
  5. 把 HCC1395 與 HCC1395_DORADO 當兩個 biological replicates（它們是同一 cell line 的 technical pair）。
  6. 用 methyl difference 直接重排 topology。
  7. 把 read cluster 或 molecule pattern 當成 cell clone。
  8. 用 2026-07-25 的 h* recovery 更新完整 topology（該結果尚未列完 candidate family）。

新接手者回答問題前的八個檢查

  1. 問題談的是 read、molecule、mutation state、copy 還是 cell？
  2. 分母是全部 groups、mutation-bearing、family complete、ranked 還是 topology-resolved？
  3. family 是否完整？
  4. model 是 recurrence-allowed 還是 strict infinite-sites？
  5. CN／LOH 是否 assessed？
  6. tree 是 exact candidate、AF representative、topology-only 還是 consensus？
  7. 使用的結果是否有 path、SHA-256、schema 與 receipt？
  8. 來源是否列於過期登錄？

任一項不清楚 → 先 abstain，查 authority_manifest.json，不要自行補完。
