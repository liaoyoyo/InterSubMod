## Master Dataset 關鍵欄位速查

### LOH 相關
| 欄位 | 說明 | 來源 |
|------|------|------|
| `Potential_LOH` | HP Imbalance 判定 (bool) | ISM RegionProcessor |
| `to_loh_bed_hit` | 是否落在 LOH.bed 區間內 (bool) | Master dataset 建置時 intersect |
| `HP_Ratio` | HP1-family / (HP1+HP2-family) (float) | ISM RegionProcessor |
| `LOH_Subtype` | None/LOH_Noise/LOH_Weak/LOH_Strong/LOH_Subclone | ISM RegionProcessor |
| `core_loh_like` | 另一種 LOH 計算（hp_ratio_core） | Master dataset 建置 |
| `tool_potential_loh` | ISM 工具端 LOH 判定 | Master dataset 建置 |
| `tool_core_loh_match` | ISM LOH 與 core LOH 是否一致 | Master dataset 建置 |

### HP 標籤相關
| 欄位 | 說明 |
|------|------|
| `HP1FamilyN` | HP1-family (HP1+HP1-1) read count |
| `HP2FamilyN` | HP2-family (HP2+HP2-1) read count |
| `NHP0` | Unphased read count |
| `NHP3` | HP3 (conflict) read count |
| `hp_ratio_core` | 核心 HP ratio (不含 HP0/HP3) |
| `hp_assign_rate` | HP assignment rate |
| `hp0_ratio` | HP0 / total |
| `hp3_ratio` | HP3 / total |
