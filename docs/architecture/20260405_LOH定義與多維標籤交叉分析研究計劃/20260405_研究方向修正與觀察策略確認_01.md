# 研究方向修正與觀察策略確認（2026-04-05）

## 一、修正背景

經系統性觀察（O1-O15、G1-G7、Read-level、ASM 定量）與 Self-phasing 因果鏈驗證，已建立完整的研究證據基礎。本文件記錄使用者對後續研究方向的三項核心修正，作為所有後續研究的基礎共識。

---

## 二、修正一：ReadParser 多維標籤分析（非捨棄，而是全面區分）

### 先前方案（已否決）

> ISM 端 ReadParser 只使用 germline HP tags（HP:i:1 / HP:i:2），忽略 somatic HP tags

### 修正後方向

ReadParser 應**同時區分與驗證**所有標籤維度，而非捨棄任何一種：

| 標籤維度 | 來源 | 用途 |
|----------|------|------|
| **HP tags**（HP:i:1, HP:i:2） | LongPhase germline phasing | Haplotype 基本分群 |
| **HP family tags**（HP1-family, HP2-family） | ISM 內部聚合 | 包含子型的家族分群 |
| **Somatic HP tags**（HP:i:11, HP:i:21, HP:i:33） | LongPhase haplotag（含 somatic） | 觀察 self-phasing 效應的直接窗口 |
| **ALT/REF** | BAM base at SNV position | 體細胞變異的等位基因支持 |

### 核心邏輯

這四個維度各自提供不同的觀察角度：

1. **HP 與 ALT/REF 的交叉**：驗證「ALT reads 是否系統性偏向某一 HP」→ 直接量化 self-phasing bias 程度
2. **HP family 與甲基的關聯**：分析「HP1-family vs HP2-family 的甲基化距離」是否反映真實的 ASM
3. **Somatic HP tags 的觀察價值**：不是要「用」somatic HP tags，而是要「觀察」它們的行為來驗證 self-phasing 假說
4. **LOH 內外的分層觀察**：在 LOH 區域內，各標籤維度的分佈是否符合預期的生物學模型

### 目標

透過多維交叉分析，回答：
- 附近的甲基化模式符合哪些標籤維度的關聯？
- 這些關聯在統計上是否顯著？
- LOH 內外的 TP/FP 資料分佈是否有可解釋的差異？
- 是否能依據 LOH 特性驗證特定的癌症生物學假說（如 second-hit、LOH-driven methylation silencing）？

## 三、修正二：ISM 定位的完整表述

### 先前表述（不完整）

> ISM 是「read-level epigenetic context for variant interpretation」，核心是偵測 entropy imbalance ASM

### 修正後定位

ISM 是 **read-level epigenetic context for variant interpretation**，具備兩層功能：

#### 功能層 1：特徵區分與 F1 提升

- 區分 TP/FP 的甲基化特徵差異
- 篩選 FP、提升 F1 是其中**一種可能的功能**
- 必須在安全約束下（TP loss ≤ 2%）才有實用價值
- **現狀**：TO 模式下此功能尚未可行（60+ 特徵全 AUC < 0.64）

#### 功能層 2：甲基化特徵分析與生物學解釋

- 用甲基化與多維特徵分析數據，並**解釋**觀察到的模式
- 需要**強的方法學基礎**和**癌症生物學邏輯**支撐
- 不只是統計結論，還要能回答「為什麼」
- 例如：
  - 為什麼 LOH 區域的甲基化距離模式不同？
  - ASM 在不同 haplotype 上的分佈是否反映 cis-regulatory 機制？
  - PERMANOVA 偵測到的 entropy imbalance 是否對應已知的表觀遺傳調控？

### 兩層的關係

功能層 2 是功能層 1 的**基礎**：只有先建立可信的生物學解釋框架，才能判斷哪些特徵真正有區分力、哪些是 confound。先前 O1-O13 的教訓正是如此 — 許多看似有效的特徵（epipolymorphism AUC=0.845、L2 AUC=0.80）都被證實為 confound。

## 四、修正三：LongPhase-TO 版本基準

### 先前假設（已修正）

> PON-only phasing 是改進方向，應以此為基礎重跑

### 修正後原則

| 項目 | 基準版本 | 說明 |
|------|----------|------|
| **所有驗證與證明** | LongPhase-TO baseline（原版） | 所有結論的參照基準 |
| **PON-only phasing** | 保留為「可觀察版本」 | 可比較觀察，但未驗證為「更好」 |
| **結論引用** | 必須標明使用的 LongPhase 版本 | 避免混淆 baseline 與 experimental |

### 理由

PON-only phasing 修改了 phasing scaffold 的 somatic variant 權重，產生了以下觀察：
- LOH.bed 完全一致（Jaccard=1.0）
- Somatic bias 17.3:1 消除
- N50 +99.7%

但**尚未驗證**：
- 這些改變是否真的在 ISM 分析層面帶來更好的結果
- Haplotag 步驟的 HP 分配缺陷（100% reads → HP:i:21）是否會引入新問題
- 跨 7 個樣本的一致性未確認

在未完成系統性驗證前，所有研究以 baseline 為基準，PON-only 作為對照觀察。

## 五、正確的研究推進順序

### 原則：一步步確認與觀察

不是先確定方案再驗證，而是**先觀察、再確認方法、最後解釋**：

```
Step 1: LOH 區分
  → 在 baseline LongPhase-TO 數據上，精確界定 LOH 內/外的資料分佈
  → 確認 LOH 判定標準是否需要修正（ISM LOH vs LOH.bed vs SEQC2）
  → 量化：LOH 內 TP/FP 各佔多少、分佈差異有多大

Step 2: TO 數據全貌觀察
  → 以 baseline 為基準，觀察 TO 數據在多維標籤下的行為
  → HP × ALT/REF × Methylation 的交叉分佈
  → 與 Paired 模式的對照（已有 O1-O10 基礎）

Step 3: ISM 觀察方法是否需要修正
  → 現有的統計檢驗（PERMANOVA / Fisher / χ²）是否適合 TO 數據
  → 距離度量（NHD / Bernoulli）在 LOH 區域是否需要調整
  → 分群策略（HP-family vs HP-fine）在 TO 下的表現

Step 4: 結果解釋
  → 觀察結果是否能用癌症生物學邏輯解釋
  → 哪些模式是 artifact（self-phasing）、哪些是真實信號
  → 是否能建立 LOH 特性與生物學特性的可驗證假說
```

### 與 Phase 優先序的關係

上述 Step 1-4 是 **Phase 2 A+D 的前置觀察**，不是 Phase 2 本身。先透過觀察確認方法的可靠性和數據的可信度，再決定：

- Phase 2A 的 normal methylation baseline 該怎麼建
- 需不需要先修正 ISM 的 LOH 判定方法
- TO 模式是否需要完全不同的分析 pipeline

## 六、現有 ISM 程式碼的標籤支持狀態

### 目前 ReadInfo 結構體（DataStructs.hpp）

```cpp
struct ReadInfo {
    int read_id;
    std::string read_name;
    int chr_id;
    int32_t align_start, align_end;
    int mapq;
    std::string hp_tag;      // "1", "2", "1-1", "2-1", "unphase"
    bool is_tumor;
    AltSupport alt_support;  // ALT, REF, UNKNOWN
    Strand strand;
};
```

### 目前 FullLabel 結構體（Stats.hpp）

```cpp
struct FullLabel {
    AltSupport allele;       // ALT/REF/UNKNOWN
    std::string hp_tag;      // 保留原始 HP tag 字串
    Strand strand;           // FWD/REV
    bool is_tumor;           // Tumor/Normal
    // combo_code(): HP × Allele × Strand × Sample 編碼
    // get_hp_family_label(): HP1-family vs HP2-family
};
```

### 目前已支持的檢定維度

| 維度 | 檢定方法 | 說明 |
|------|----------|------|
| HP（HP1 vs HP2） | PERMANOVA + Fisher | 基本 haplotype 分群 |
| HP-family（HP1-fam vs HP2-fam） | PERMANOVA + Fisher | 包含子型的家族分群 |
| Allele（ALT vs REF） | PERMANOVA + Fisher | 體細胞變異等位基因 |
| Sample（Tumor vs Normal） | PERMANOVA | Paired 模式專用 |

### 尚未支持但需觀察的維度

| 需求 | 現狀 | 優先度 |
|------|------|--------|
| HP × ALT/REF 交叉表 | FullLabel 有 combo_code 但未輸出交叉統計 | 高 — Step 2 核心 |
| Somatic HP tag 區分 | hp_tag 字串包含但未明確分類 | 中 — Step 1 觀察用 |
| LOH 內/外分層統計 | RegionProcessor 有 loh_status 但未交叉輸出 | 高 — Step 1 核心 |
| HP × Methylation × LOH 三維交叉 | 不支持 | 中 — Step 3 判斷用 |

## 七、關鍵待釐清問題清單

| # | 問題 | 觀察階段 | 說明 |
|---|------|----------|------|
| Q1 | ISM 判定的 LOH 與 LOH.bed 的差異有多大？ | Step 1 | 已知 ISM LOH 過判（85.5% concordance），需精確量化差異分佈 |
| Q2 | LOH 內的 TP/FP 甲基化距離分佈是否有結構性差異？ | Step 1 | O15 已顯示 LOH 內甲基化全面失效（7/7 AUC~0.50），但未分 TP/FP 細看 |
| Q3 | HP × ALT/REF 的交叉分佈在 TO baseline 下是什麼樣子？ | Step 2 | Self-phasing 理論預測 ALT 偏向一個 HP，需量化程度 |
| Q4 | 現有 PERMANOVA 在 LOH 區域是否仍有意義？ | Step 3 | LOH 內 HP-balance 消失，距離矩陣的排列檢驗前提可能不成立 |
| Q5 | ASM 在 LOH 區域的行為是否符合 second-hit 生物學模型？ | Step 4 | 可驗證假說：LOH 區域 ASM 應該消失（因為只剩一個 allele） |
| Q6 | 跨 HP × LOH 的甲基化模式是否能區分 germline FP 與 somatic TP？ | Step 4 | 最終目標：建立有生物學根據的區分框架 |
