0大框架：兩條路、四個檢定

read×CpG 甲基矩陣建好後分兩條路：一條把 reads 聚合成計數（問「甲基率有沒有差」率/點層），一條算 read-read 距離（問「reads 有沒有分成幾何上分離的群」結構層）。

1Fisher exact 率/點層

做什麼：每個 CpG 建一張 2×2 表，算「兩群甲基比例差到不像隨機」的精確機率（超幾何，小樣本也準），再對 region 內所有 CpG 做 BH-FDR。

BH-FDR 校正 Fisher_Frac_Sig = 顯著 CpG 的比例
🟢 實例（本 session 外部稽核）：read-level 置換下，null（無真差）的 Fisher 顯著率只有 0.68%（BRCA2）/ 1.87%（TBC1D16），低於名目 5% → per-CpG Fisher 沒有偏樂觀。真訊號則 19.9%/31.1% ≫ null（perm p=0.002）。 來源：runs/audit_B2.json（本 session modkit/permutation 稽核）
⚠ caveat：每個 read 在該 CpG 算一個獨立 0/1。跨 region/genome 沒有再做多重檢定校正（只在單 region 內 BH）→ 這才是「ASM 存在率」可能偏高的真來源（待修）。

2Cramér's V 全域效果量

做什麼：Fisher 給「有沒有差（p）」；Cramér's V 給「差多強（效果量，0–1）」。但稀疏表 χ² 不可信，所以有 Cochran 可靠性閘。

Cramér's V = √( χ² / (N × (min(列,行) − 1)) ) ← 2×2 時 = √(χ²/N)，範圍 [0,1]
🟢 實例（源碼確認）：reliable 條件 = 期望<5 的格子 ≤20%（MathUtils::cramers_v）；summary 存 reliable ? V : 0（不可靠當 0，不讓假高 V 過關）。gate = (Fisher p ≤ 閾值) AND (V ≥ 閾值)（GlobalTest::apply_gating）。 來源：src/core/MathUtils.cpp:154 + GlobalTest.cpp:128-141（本 session 讀回）
⚠ 源碼問題（稽核確認）：chi_square_p 是 placeholder = Fisher p（欄名誤導，下游無人用）；建議刪或實作真卡方 CDF。

3PERMANOVA 結構層 · 核心

做什麼：把每條 read 當高維空間一個點（用 read-read 距離），問「HP1 群和 HP1-1 群這兩坨點，是不是真的分開」。不需分布假設。

pseudo-F = [ SS_between / (k−1) ] / [ SS_within / (N−k) ] SS_within = 群內所有對的平方距離和（小=群內緊密） SS_between = SS_total − SS_within 打亂群標籤 999 次重算 F → p = (#{perm_F ≥ 觀測F}+1)/(999+1)
🟢 實例（BRCA2，validated）：HP1-1 群 silhouette=0.31、ari_blind_allele=0.79（盲分群高度還原等位結構），對應 PERMANOVA 顯著的結構。這是 modkit/DSS（率差工具）完全沒有的「分群顯著性檢定」。 來源：cis_scan_full.json + control_cohesion_cistest.json（BRCA2 chr13:32315128）
⚠ 源碼問題（稽核）：生產配置只跑 99 次 permutation → p 最低只能到 0.01，與 genome-wide 不相容，建議升 999+。

4Dispersion（PERMDISP）結構層

做什麼：PERMANOVA 顯著有陷阱——「群分開」可能是中心不同（真分群），也可能只是兩群散度不同。Dispersion 檢定分辨這兩種。

⚠ 源碼問題（稽核）：dispersion 的 anova_p 是硬寫死 3 段查表（F>4→0.01 / F>2.5→0.05 / 否則 0.1），不是真 F 分布，會 0.5× 懲罰 heuristic_score（待修）。

5LabelTest Δ = d_between − d_within 結構層

做什麼：PERMANOVA 的「單一數字直覺版」。直接在距離矩陣上比「異群平均距離」減「同群平均距離」。

6Silhouette 分群品質 · 選 k

做什麼：每條 read 算 (b−a)/max(a,b)，a=到自群平均距離、b=到最近鄰群平均距離。範圍 [−1,1]，越高分群越乾淨。ISM 用它自動選最佳 k（2..10）。

7⭐ 精華：兩法會 disagree（487 latent 真實例）

最重要的意義：Cramér's V（率/點層）和 PERMANOVA（結構層）在不同層、會給不同答案。同一個位點，稀疏表讓 Cramér's V 被 Cochran 閘到 0，但 reads 在距離空間其實分得很開 → PERMANOVA 仍顯著。這證明 PERMANOVA 能抓到 Fisher/CramersV 漏掉的真結構。

🟢 實際例子（validated）：762 個被率層判 MISSED 的位點中，487 個是 latent —— gated CramersV=0（率層測不出），但 PERMANOVA 顯著（結構層測得出真 HP 分群）。納回後提升 characterization。⚠ 但這是 characterization，不可寫成 TP/FP filter。 來源：memory project_asm_locus_display_and_cramersv_reliability_gate（validated, scripts 83-88）
