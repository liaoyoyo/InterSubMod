L0 — 三句話結論
  1. 方法定位：外部甲基化方法分 6 條軸；ISM 主要站「軸C read-read 距離+clustering」，而 modkit/DSS/methylKit 等主流站「軸A per-position 率差」——兩者問的問題本質不同（率差 vs 結構）。
  2. 新穎性：無單一工具佔 ISM 完整組合（read-read 距離矩陣 + PERMANOVA 結構顯著性 + normal-anchored somatic cis-test + 5mC/5hmC 分軌 + LOH/CN 耦合），但每個單獨元件都有更成熟對手。
  3. 可改進：最高 ROI = ① per-CpG Fisher → beta-binomial + dispersion shrinkage（DSS）；② 距離建在 soft 機率（cvlr/pycoMeth）；③ 停 5mC/5hmC max-collapse。另發現源碼引用錯誤（DAMEfinder 誤標「De Waele 2020」應為 Orjuela 2020）。
⚠ 誠實邊界：「組合無人佔 ≠ 該組合更好/有用」—— 是否帶真訊號需 Phase B 實機 benchmark 驗證（已規劃未執行）。所有 ASM 結果 = 單樣本 HCC1395 ⭐3 單 pipeline。調查覆蓋 82 工具（10 類），由 24-agent workflow 全程 WebFetch 一手實證。

6 軸分類地景

所有外部甲基化方法可乾淨地分成 6 條「分析軸」。這是理解全局的關鍵框架。

🔑 核心洞見：modkit dmr 在 per-position 聚合計數上比率差（軸A）；ISM 保留 read×CpG 矩陣量結構（軸C）。modkit dmr 甚至沒有內部 --haplotype——單倍型 DMR 須先 pileup --phased 把 HP 當靜態樣本，這正是 ISM 的 somatic-controlled HP1 vs HP1-1 軸的差別。

ISM 方法（6 核心，源碼確認）

① read-read 距離矩陣

NHD(預設)/L1/Bernoulli/Pearson/Jaccard；共同覆蓋 ≥5 CpG；NaN→MAX_DIST。顯式 N×N，between-molecule。

② 階層 clustering

UPGMA(預設)+Ward/Single/Complete；silhouette 自動選 k=2..10 → subclonal read 群。

③ PERMANOVA 結構檢定 ★

pseudo-F + 999 perm + dispersion；檢定 HP/somatic 群是否結構分離。「結構非失序」引擎。

④ per-CpG ASM + disorder

Fisher+BH-FDR / NME / epipolymorphism（4-CpG）。程式碼明文 cite DAMEfinder/pycoMeth/methclone/Metheor。

⑤ Cramér's V + Cochran 閘

全域 HP×甲基關聯；最小期望格≥5 才標 reliable。

⑥ normal-anchored cis-test ★

d_somatic=C−B / d_cis=C−A / d_drift=B−A（A=normal HP1, B=tumor HP1, C=tumor HP1-1）；held CN/ploidy。

Δβ = per-CpG 均甲基差，按 CpG 配對 → Wilcoxon signed-rank + Cohen's d；HP-axis(HP1 vs HP1-1 somatic) / ALLELE-axis(ALT vs REF)；copy-partition 把 d_HP 拆 d_copy + d_within(真 cis) + drift。詳見 01_ism_method_spec_from_source.md（含 file:line）。

3 個最像 ISM 的工具（投稿必正面對照）

C cvlr (Raineri 2023)

ONT read-level、不需 phasing、Bernoulli-mixture EM 分群。差別：模型式（非距離矩陣）、無顯著性檢定、germline、固定 k 無 BIC。⚠ GitHub 404

C ASMS (Raineri 2024)

ONT modBAM、no-phasing、EM 2-component 依甲基分 reads 找 ASM。單一最像；ISM 多 PERMANOVA + normal-anchor + 多群 silhouette。⚠ UNVERIFIED 須親讀

E qFDRP (Scherer 2020)

用和 ISM NHD 完全相同的 normalized-Hamming read-pair kernel，但平均成 per-CpG scalar、丟幾何、無 label/PERMANOVA。✓ verified

F NanoMethPhase (Akbari 2021)

HP 軸最直接長讀對照：haplotag + HP1 vs HP2，外包 DSS beta-binomial，5mC only、germline imprinting。ISM 加 somatic HP1 vs HP1-1 + cis + LOH + 5hmC。

KEEP — 守住的可防守新穎性

① PERMANOVA「結構非失序」

supervised、label-tested 的 between-molecule 結構顯著性檢定 —— cvlr（最近鄰）有分群但無顯著性檢定。最該 foreground 的單一新穎點。

② normal-anchored somatic cis-control

唯一：所有對手都是對稱 A-vs-B/trio，無法分 somatic-specific allelic 甲基 vs germline baseline。

Phase B — 實機 benchmark 方案（⚠ 尚未執行）

核心問題：紙上已知 ISM 組合無人佔，但「無人佔 ≠ 更好/有用」。Phase B 要回答：當 modkit dmr 說「無率差」但 ISM PERMANOVA 說「有結構」時，ISM 的 call 是真訊號還是噪音？

在 HCC1395（SEQC2 truth + 既有 haplotagged BAM）上，對 BRCA2 / TBC1D16 / imprinting ICR 正控 + panel，並排跑 ISM vs modkit dmr（率差基準）/ cvlr / ASMS（read-clustering 近鄰）/ DSS（嚴謹統計）/ qFDRP（disorder 對照） → concordance 表 + discordant-case 深析 + runtime。
