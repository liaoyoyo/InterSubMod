A. 可行性裁決（一頁 Verdict-Pyramid）

論文目標「Subclonal reconstruction using somatic haplotagging and methylation profiles (ONT)」可完成 —— 但僅在嚴格 frame 下，且 HD-1 未解前 reconstruction-spine 宣稱受限。

一句話：論文做得成 = 「在 genetic 骨幹上、用 read 層次多證據、對特定區域的 subclone 做有 documented confounds 的個案刻畫與驗證（proof-of-concept, ⭐3 單樣本 → G-A 後 ⭐4）」；不是「用甲基重建全基因組 subclone 樹、勝過既有方法」。

✅ 可完成（as framed）

  • 區域內 / read 層次 / 多證據（haplotag + multi-sSNV + methylation）subclone characterization / verification（chr2:18M 旗艦 PRIMARY-verified）
  • ASM 存在 + somatic-enrichment 刻畫，並誠實標 non-filter（honest-negative 本身可發表）
  • 跨 6 樣本 / 3 癌種 reproducibility ⭐3（6/6 excess-over-null；G-A 後 ⭐4）
  • Sanctioned 整合 innovation（三件式 on bulk ONT）
  • methyl-phasing-assist T1 unphase rescue（0.885）supporting
  • a-priori 軸 C′ = 唯一合法 non-circular 管道（~7.6%；優勢 = 可解釋非偵測力）

❌ 不可宣稱（overclaim 紅線）

  • methylation 驅動的 genome-wide subclonal reconstruction surpassing existing
  • 完整 clonal phylogeny / CCF tree / lineage tree（學派 1-2 定義）
  • tumor-only 無監督 subclone 偵測（已 NEGATIVE，noise≈structure 83-100%）
  • methylation 當獨立 discriminator / variant filter（DEAD 4 路）
  • 「對手用 short-read」或「對手缺顯著性檢定」（reviewer reject）
  • 「distance-based 甲基重建新穎」（Sgootr 2023 單細胞已建）／ 18086020 timing 當定論

決定強度的 gate（解前不可 overclaim）

「ISM 能做別人不能」的誠實答案

不是無人有的能力，是先驗元件於尚空交集的新穎組合 + 資料-regime niche。別人更強處：single-cell 甲基做 genome-wide lineage（觀測 CELL = 真重建）；SNV-CCF + phylogeny + allele-CNA 做正式 reconstruction；DeCiFer 解 multiplicity；ROCIT 已做 read-level 甲基 tumour-origin genome-wide（supervised/無 normal）。ISM 在這些軸不領先、不宜宣稱領先。

B. Clone/Subclone 重建學派全景（6 學派）

遺傳骨幹（學派 1-4）— 零甲基 · 非 read-level · 與 ISM 互補（0 真 CONFLICT）

① SNV / VAF-CCF clustering

PyClone-VI · DPClust · SciClone · MOBSTER
CAN：bulk 反卷積 CCF clonal/subclonal 群、cohort-scale
CANNOT：multiplicity 不可識別；只產 cluster 非 tree

② Phylogeny / clonal-tree

PhyloWGS · Canopy · CITUP · LICHeE
CAN：建完整 lineage tree + per-subclone genotype
CANNOT：tree 非唯一；單 bulk 嚴重欠約束

③ Allele-specific CNA

ASCAT · Battenberg · TITAN · MEDICC2
CAN：purity/ploidy/allele-CN、call LOH、CN phylogeny
CANNOT：purity-ploidy 不可識別；WGD 等價；LOH-unmask 82-91%

④ Multiplicity / timing

DeCiFer · MutationTimeR · PCAWG-11
CAN：解 multiplicity(DCF)、mutation 定年排序
CANNOT：CN-known 仍不足定 m；單 slice 僅部分重建
⑤ single-cell（DNA + 甲基）— 甲基 lineage 唯一真實 regime · 不同 regime 非競爭

⑤ single-cell methylation lineage

Gaiti · Epiclomal · MethylTree · EPI-Clone · Sgootr
CAN：甲基近-100% 重建 lineage/epiclone（真重建）
CANNOT：需 single-cell + label；Liu-Goretsky/Lee 靠物理預分選
⑥ long-read phasing + read-level 甲基分群 — ISM 最近鄰與真實邊界

⑥a long-read phasing

longphase-S（ISM 骨幹）· MethPhaser(+Cancer) · NanoMethPhase · Wakhan
多數不做 subclone；bulk 無跨 phase-set linkage

⑥b read-level 甲基分群

cvlr · ASMS · qFDRP · CpelNano · MethylBERT
不分離 ASM 與 somatic subclone；無 matched-normal 錨點

⑥c 2025-26 新競品 L3 未全文核

ROCIT · TumorLens · MethPhaser-Cancer · DPClust-on-LR
各佔不同子集（見 §E）；正快速填補白地

🎯 Where ISM Sits

ISM 不佔據任何「沒人做過」的能力空白；它佔據先驗元件的新穎組合於一個尚空的交集：

① unsupervised read×read 距離矩陣 PERMANOVA 結構檢定 ② normal-baseline somatic cis-test ③ somatic-subclone target on bulk ONT · read level

每單元件皆 prior art（Sgootr 距離式 / qFDRP NHD / cvlr·ASMS read 分群 + 檢定 / longphase-S 骨幹）；整合才是 claim。reconstruction 由 somatic haplotagging（genetic）驅動，甲基 = corroborate（germline-haplotype 層；非 driver）。
觀測單元根本差異（理解樞紐）：single-cell 觀測 CELL（跨 locus 物理連鎖）→ 能拼全基因組家譜；bulk long-read 觀測 READ（局部單分子、無跨 locus 細胞 linkage、無跨 phase-set linkage）→ ISM 物理上限於 regional。
