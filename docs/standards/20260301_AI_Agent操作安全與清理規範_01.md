# AI Agent 操作安全與清理規範

- 生效日期：2026-03-01
- 適用範圍：InterSubMod 專案內所有 AI Agent 任務

## 1. Readiness 檢查觸發規則

`scripts/analysis/check_ai_agent_readiness.sh` 改採「異常觸發」，不要求每次任務都先跑。

建議觸發情境：
1. 重開機或環境重建後首次任務。
2. `.mcp.json`、`output` 軟連結、docs 結構有變更。
3. 任務結果與歷史基線不一致。
4. Agent 出現路徑解析或文件落點錯誤。

## 2. output 儲存預設策略

1. repo 內保留固定入口：`output/`。
2. 實體輸出放在 repo 外硬碟：`/big8_disk/liaoyoyo2001/InterSubMod_runs/output`。
3. 以軟連結對接：`output -> /big8_disk/liaoyoyo2001/InterSubMod_runs/output`。

## 3. 清理與刪除安全政策

1. Agent 禁止直接刪除檔案（含 `rm`, `find -delete`, 覆寫式清空）。
2. 需要移除的檔案，一律先搬移至 Archive 暫存區：  
   `/big8_disk/liaoyoyo2001/InterSubMod_runs/Archive_pending_delete/`
3. Agent 必須回報：
   - 搬移原因
   - 原始路徑
   - 暫存路徑
   - 搬移時間
4. 最終刪除由使用者手動執行，Agent 不得代為最終刪除。
5. 除非使用者明確指示，否則不執行任何實際清除動作；若清理必須存在，需放在可審核的執行腳本中。

## 4. 建議搬移流程範本（僅搬移，不刪除）

```bash
ARCHIVE_ROOT="/big8_disk/liaoyoyo2001/InterSubMod_runs/Archive_pending_delete"
STAMP="$(date +%Y%m%d_%H%M%S)"
TARGET="${ARCHIVE_ROOT}/${STAMP}"
mkdir -p "${TARGET}"

# 範例：將待移除檔案搬移到暫存區
mv /path/to/file_or_dir "${TARGET}/"
```

> 備註：上述流程只做「搬移暫存」，不包含任何最終刪除步驟。
