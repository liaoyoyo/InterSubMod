# output 軟連結與版本控管規範

- 生效日期：2026-02-28
- 決策來源：2026-02-28 使用者拍板（D3-A）

## 1. 原則

1. 專案保留 `output/` 路徑作為固定入口，方便腳本與分析流程。
2. 實際輸出可存放於其他硬碟目錄，並由 repo 內 `output` 以軟連結對接。
3. `output/` 一律不納入 Git 版本控管。

## 2. 建議做法

```bash
# 範例：將實際輸出放在另一顆硬碟
mkdir -p /big8_disk/liaoyoyo2001/InterSubMod_runs/output

# 若既有 output 為實體資料夾，先搬移後再建立軟連結
mv /big8_disk/liaoyoyo2001/InterSubMod/output/* /big8_disk/liaoyoyo2001/InterSubMod_runs/output/
rmdir /big8_disk/liaoyoyo2001/InterSubMod/output
ln -s /big8_disk/liaoyoyo2001/InterSubMod_runs/output /big8_disk/liaoyoyo2001/InterSubMod/output
```

## 3. 驗證命令

```bash
# 應顯示 output -> /實際硬碟路徑
ls -la /big8_disk/liaoyoyo2001/InterSubMod/output
```

## 4. 注意事項

1. 搬移前先確認下游流程無執行中程序。
2. 若跨檔案系統搬移，請先估算 I/O 時間與空間。
3. 若需要保留歷史 run，建議在實體輸出目錄再按日期分層。
