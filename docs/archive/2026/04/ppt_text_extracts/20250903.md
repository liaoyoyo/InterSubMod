## Slide 30: 三、整體結論
高顯著 FP 位點的核心特徵 = 高覆蓋度（BAM、VCF DP、周邊 ±1kb 可用讀段）。→ 提示：FP 更容易出現在 高深度、可能有 CNV 或重複序列的區域。
等位基因頻率 (

一、顯著差異的特徵
1. BAM 單點覆蓋度
HighSig > Other，p=1.23e-05
解讀：高顯著位點的原始測序深度（BAM coverage）顯著高於其他位點。
可能意義：
高覆蓋區容易檢出「假陽性」（False Positive, FP），因為過多 reads 增加了測序錯誤或比對錯配被誤判的機率。
這也符合某些研究觀察：極端高 depth 區域常常富含 CNV 放大或重複序列。
2. VCF DP
HighSig > Other，p=0.000272
解讀：在 variant caller 的有效讀段數 (VCF DP) 也同樣顯著偏高。
可能意義：
呼叫過程中，即使過濾後的 reads，HighSig 區域仍然累積較高 DP，增加 FP 風險。
換句話說，這並非僅僅是 BAM raw depth 偏高，而是 caller 保留下來的 reads 也更多。
3. 可用讀段總數（±1kb）
HighSig > Other，p=5.08e-05
解讀：周邊 ±1kb 內能提供判讀的讀段數量也顯著偏高。
可能意義：
高 coverage 區域往往不只一個點，而是整段都有較高的 read 支撐。
這些區域可能和基因體結構特徵有關（例如 segmental duplication）。

二、無顯著差異的特徵
1. VCF AF
p=0.1 → 無顯著差異
解讀：等位基因頻率（Allele Frequency, AF）分布在兩組差不多，代表 FP 並非單純因為 VAF 偏高或偏低。
可能意義：
假陽性未必來自「比例」異常，而是 coverage 與區域性因素。
2. 正反股相關指標
顯著數差值 p=0.508
可用讀段差值 p=0.0668（趨勢，但未達顯著）
解讀：strand bias 並非 FP 的主要決定因子。
3. SNP 聚集（±100bp）
p=0.745
解讀：FP 位點並沒有特別集中在 SNP 熱點區域。
4. 與 TP 近鄰比例
HighSig 8% vs Other 0%
解讀：少部分 FP 靠近真實變異 (TP)，但數量太少，目前不足以成為主要區分特徵。

三、整體結論
高顯著 FP 位點的核心特徵 = 高覆蓋度（BAM、VCF DP、周邊 ±1kb 可用讀段）。→ 提示：FP 更容易出現在 高深度、可能有 CNV 或重複序列的區域。
等位基因頻率 (AF) 與 strand bias 並非顯著因子。→ 代表這些 FP 並不是因為「比例偏差」造成，而是環境性/結構性問題。
聚集效應與 TP 鄰近比例不具顯著性，對 FP 訊號解釋力有限。

四、後續建議
QC 層面：對於高 depth 區域，考慮在 variant calling 後增加一個 上限過濾 (max depth filter)，例如：>500× 的位點自動標註或濾除。
生物學層面：比對這些 HighSig 區域是否對應到 CNV 擴增區 或 低複雜度序列 (low-complexity / tandem repeats)。
分析層面：將「覆蓋度相關特徵」加入 FP 訊號模型，可能能顯著降低假陽性率。

## Slide 129: (no title)

你有一批已標記 haplotype（單倍體）與 somatic-alt/ref（體細胞變異等位基因）的長 read；
這些 read 在同一組 CpG 位點都有覆蓋，且在甲基化水準（高／低）上呈現趨勢性差異──不是每個 CpG 都明顯，但整體有趨勢；
希望利用「附近 CpG 的甲基化模式」，結合 SNP 位點訊息，來估算每條 read 與其標籤之間的「甲基–SNP 差距」，進而驗證該 somatic 位點的真實性（TP vs. FP），或剔除 mapping error。

以下為「甲基–SNP 距離」方法的重點處理流程：
資料前處理
過濾 MAPQ<20 之 reads、去除低覆蓋（CpG<5×）位點
校正 bisulfite 轉換效率（以 λ DNA 等 control 估算並調整）
模板建構
將 ref/alt 兩組 reads 在上下游 N 個 CpG 的平均甲基率 mˉi\bar m_i 計算出來
依照門檻（例如 mˉ>0.7\bar m>0.7→1、<0.3<0.3→0）二值化，得到 hi(ref)h_i^{(\text{ref})} 與 hi(alt)h_i^{(\text{alt})}
二值化個別 reads
將每條 read 在相同 N 個 CpG 位點上，根據其甲基比率二值化為 mim_i
中間值 (0.3≤mˉ≤0.70.3\le \bar m \le0.7) 可標記為「不定」並排除
距離計算
定義權重 ，其中 d_i 為 CpG 與 SNP 的基因組距離
計算 Hamming／加權曼哈頓距離：分類與篩選
計算 ΔD：若 ΔD>0，read 更接近 alt；反之接近 ref
根據交叉驗證結果設定最優距離閾值 ，剔除 D>Dmax⁡ 之 potential FP 或 mapping error
參數敏感度分析
調整二值化門檻（如 0.6/0.4、0.8/0.2）與權重衰減參數 λ，透過 ROC／PR 曲線選最優組合
結果驗證
用已知 truth set 做 ROC、Precision–Recall 評估
進行 permutation test、in silico spike-in 與 orthogonal 實驗（Sanger bisulfite）驗證方法穩健性
