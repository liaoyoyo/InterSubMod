## Slide 72: (no title)

你有一批已標記 haplotype（單倍體）與 somatic-alt/ref（體細胞變異等位基因）的長 read；
這些 read 在同一組 CpG 位點都有覆蓋，且在甲基化水準（高／低）上呈現趨勢性差異──不是每個 CpG 都明顯，但整體有趨勢；
希望利用「附近 CpG 的甲基化模式」，結合 SNP 位點訊息，來估算每條 read 與其標籤之間的「甲基–SNP 差距」，進而驗證該 somatic 位點的真實性（TP vs. FP），或剔除 mapping error。

以下為「甲基–SNP 距離」方法的重點處理流程：
資料前處理
過濾 MAPQ<20 之 reads、去除低覆蓋（CpG<5×）位點
校正 bisulfite 轉換效率（以 λ DNA 等 control 估算並調整）
模板建構
將 ref/alt 兩組 reads 在上下游 N 個 CpG 的平均甲基率 mˉi\bar m_i 計算出來
依照門檻（例如 mˉ>0.7\bar m>0.7→1、<0.3<0.3→0）二值化，得到 hi(ref)h_i^{(\text{ref})} 與 hi(alt)h_i^{(\text{alt})}
二值化個別 reads
將每條 read 在相同 N 個 CpG 位點上，根據其甲基比率二值化為 mim_i
中間值 (0.3≤mˉ≤0.70.3\le \bar m \le0.7) 可標記為「不定」並排除
距離計算
定義權重 ，其中 d_i 為 CpG 與 SNP 的基因組距離
計算 Hamming／加權曼哈頓距離：分類與篩選
計算 ΔD：若 ΔD>0，read 更接近 alt；反之接近 ref
根據交叉驗證結果設定最優距離閾值 ，剔除 D>Dmax⁡ 之 potential FP 或 mapping error
參數敏感度分析
調整二值化門檻（如 0.6/0.4、0.8/0.2）與權重衰減參數 λ，透過 ROC／PR 曲線選最優組合
結果驗證
用已知 truth set 做 ROC、Precision–Recall 評估
進行 permutation test、in silico spike-in 與 orthogonal 實驗（Sanger bisulfite）驗證方法穩健性
