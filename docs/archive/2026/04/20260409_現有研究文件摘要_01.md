# 現有研究文件摘要：概念文件撰寫參考

## 1. TO FP 問題（數字、根因、過濾結果）

### 核心數字

| 指標 | 數值 | 來源/驗證 |
|------|------|----------|
| TO FP rate (HCC1395) | **30.6%** | SEQC2 truth set |
| Paired FP rate | **~1.04%** | ClairS paired |
| TO raw FP 總量 | ~2,734,187 | ClairS-TO 原始輸出 |
| PON 移除率 | **99.48%** (2,717,339) | 僅 HCC1395 驗證 |
| 殘餘 FP | **14,202** | PON + caller filter 後 |
| 殘餘 FP 中 raw_absent 比例 | **98.6%** | paired 從未 call 出 |
| ISM 特徵對殘餘 FP 的移除力 | **0%** (TP loss <=2% 約束下) | 60+ 特徵 AUC < 0.64 |
| 跨樣本 FP rate 異質性 | **8.7%-74.6%** (8.6 倍) | 7 個樣本 |

### 三層過濾結構

1. **Layer 1: PON** -- 移除 99.48% raw FP（已知 germline variants）
2. **Layer 2: Caller filter** -- 額外移除 ~15.7%
3. **Layer 3: ISM** -- 移除 0%（60+ 特徵全部 AUC < 0.64）

### 殘餘 FP 本質

- 98.6% 為 "raw_absent" 型：ClairS-TO call 出但 ClairS-Paired 原始輸出中從未出現
- 本質是 PON database 覆蓋不到的**罕見 germline heterozygous variants**
- 擁有真正的 allelic structure 和 mQTL-driven ASM
- 在 ISM 分析解析度下與 somatic TP **不可區分**
- 唯一區別：normal 樣本中是否也有此 variant -- 這恰恰是 TO 模式下不可得的資訊

### 根因結論

**這不是技術缺陷，是生物學本質限制。** Germline FP 擁有與 somatic TP 相同的 allelic structure、ASM、coverage 和 CpG density。

## 2. Self-Phasing（因果鏈、量化影響）

### 機制

LongPhase-TO 讓 somatic mutation 自己決定自己被分到哪個 haplotype（「球員兼裁判」循環依賴）。在 TO 模式下，somatic variants 混入 phasing scaffold，ALT reads 互相連結形成巨大 cluster，全部指向同一 HP。

### 因果鏈五步驗證（穩定度 4/5）

| 步驟 | 證據 | 數值 |
|------|------|------|
| S0 | Somatic HP1:HP2 bias | **17.3:1** (614K vs 35K)，94.6% 偏向 HP1 |
| S2 | 移除 self-phasing 後 TO TP LOH 消失比例 | **62%** (AF 0.1-0.8 近 100%) |
| S3 | 同位點 HP_Ratio 跨模式相關 | **r = 0.001** (288K pairs) |
| S4 | TO-only LOH 在 paired 下完全平衡 | **86.5%** (HP_Ratio 0.4-0.6) |
| S5 | Cohen's d (HP_Ratio 差異) | **-1.20** (巨大效應量) |

跨樣本方向一致性：**7/7 samples** 全部觀察到相同方向。

### 對 ISM 特徵的影響

| 分類 | 特徵數 | 佔比 | 狀態 |
|------|--------|------|------|
| A. 完全不依賴 HP | ~42 | 55% | 結論穩固 |
| B. 直接依賴 HP | ~29 | 38% | TO 結果不可信 |
| C. 間接依賴 HP | ~14 | 7% | 大部分影響微弱 |

### 重要精確化

「62% TO LOH 是 artifact」中的 LOH 指的是 **ISM 計算的 HP_Ratio LOH**（HP_Ratio < 0.1 or > 0.9），而非 **LOH.bed region-level LOH**。PON-only phasing 實驗證實 LOH.bed 完全不受 self-phasing 影響（Jaccard=1.0）。

### PON-Only Phasing 修正結果

- **VCF 層面**：bias 消除、N50 +99.7%、phased rate +23.6pp、LOH.bed Jaccard=1.0
- **Haplotag 層面**：發現新問題 -- somatic 位點 GT=0|0 導致 refHaplotype=UNDEFINED，所有 reads 統一標記為 HP:i:21
- **修復方案**：ISM ReadParser 忽略 somatic HP tags (HP:i:11/21/33)

### 關鍵限制

修正 self-phasing 後 TO 仍無法接近 Paired：
- Self-phasing artifact: ~35% 差距（可修正）
- Scaffold 品質差距: ~65% 差距（結構性限制）
- FP 組成差異: 1% vs 31%（無法改變）
- 永久差距預估: ~0.15-0.20 AUC

## 3. ISM 價值（什麼有效、什麼無效、定位）

### ISM 不能做的事

| 不能做的事 | AUC/效果 | 驗證充分度 |
|------------|---------|-----------|
| TO FP 過濾 | 60+ 特徵全 AUC < 0.64，FP removal = 0% | 4/5 |
| TO LOH 判定 | 62% artifact，HP_Ratio r=0.001 | 4/5 |
| TO HP-based 分群 | HP tag 與真實 haplotype 幾乎無關 | 5/5 |
| 跨區域甲基化 correlation | shared read count confound | 5/5 |
| FN rescue（HP-free） | 122,790 FN AUC<0.53（random） | 4/5 |
| TO 分類增量 | ISM 僅增 +0.003-0.030 over Caller-only | 4/5 |
| 純甲基化 clustering 區分 | HP-free combo AUC=0.564, ClusterPermanovaF=0.512 | 4/5 |

### ISM 能做的事

| 能做的事 | 證據 | 驗證充分度 |
|----------|------|-----------|
| ASM 定量 (32-66%) | 5 方法交叉驗證，7/7 樣本一致 | 4/5 |
| Somatic heterogeneity 描述 | HPFineNGroups N>=4 TP rate=86.8%, residualized AUC=0.617 | 4/5 |
| Paired F1 微弱改善 | +0.0112 [+0.0044, +0.0188]，McNemar p=1.44e-51 | 3/5 |
| 甲基化矩陣產出 | 直接讀 BAM MM/ML | 5/5 |
| VerificationClass 分類 | 跨模式 concordance V=0.914 | 4/5 |

### 定位轉向

**原始期望**：ISM = variant filter，用甲基化特徵過濾 FP 提升 F1
**現在定位**：ISM = epigenetic characterizer，ASM 定量 + subclone 結構解析 + 二次打擊推論

> 論文定位從 "variant filter" 轉向 "read-level epigenetic context characterization"。ISM 的獨特價值是它能在 read-level 做 PERMANOVA -- 這是其他工具無法複製的能力。

### ASM 定量結果

| 方法 | 樣本量 | ASM 比例 |
|------|--------|---------|
| M1 ISM PERMANOVA | 748K regions | 32.2% |
| M2 ALT/REF Wilcoxon | 4,017 regions | 45.3% |
| M3 Per-CpG Fisher | 4,017 regions | 55.2% |
| M4 Point-biserial | 4,017 regions | 36.1% |
| M5 Bootstrap delta CI | 4,017 regions | 41.8% |

FP ASM > TP ASM（7/7 方向一致），原因：germline variant 有 mQTL-driven stable ASM，somatic variant 較弱或不穩定。但 TP/FP 重疊太大，無法用於區分。

### HPFineNGroups（正面發現）

- N>=4 + NR>=80：TP rate **89.1%**
- 低 AF (0.1-0.2) 時信號最強 (+50pp)
- 7/7 樣本一致
- Residualized AUC = 0.617
- 不能用於 FP filtering（AUC<0.85），但作為 somatic clone diversity 的定量標記有明確生物學意義
- CramersV 93% 為零是 2x2 設計缺陷，HPFineNGroups 已克服（AUC +0.125）

## 6. 五個研究願景（目標、成功標準）

### 研究定位

InterSubMod 是一個「**可解釋 epigenetic evidence 整合框架**」，不是另一個 somatic caller。

### 五個目標

| 目標 | 核心問題 | 輸出 |
|------|---------|------|
| G1 | Per-CpG 甲基位點多標籤關聯性評分 | 每 CpG 的關聯標籤集合 + 關聯強度分數 |
| G2 | 單 region 與跨 region 的 clone 結構分析 | Subclone 結構圖 + 突變 co-occurrence |
| G3 | 二次打擊與事件發生順序推論 | 事件順序推論 + 二次打擊候選清單 |
| G4 | Tumor-Only 的 normal 資訊補強 | Purity-corrected methylation + germline/somatic ASM 區分 |
| G5 | 整合 evidence panel 提升 F1 | Rescue 規則 + filter 規則 + F1 benchmark |

### 成功標準（雙軌制）

| 成功類型 | 定義 | 驗證方式 |
|---------|------|---------|
| **可解釋性成功** | 清楚說明 CpG/region 甲基模式與 HP/SNV 關聯理由 | case study + evidence panel 可追溯 |
| **F1 提升成功** | Paired 或 TO 的 precision/recall 有量化改善 | Benchmark + baseline 對比，需統計顯著 |

**陷阱警告**：「evidence panel 解釋了很多位點」不等於「F1 提升」。

### 執行優先順序

```
Phase 1（當前）：方向 E -- ML read classification（目標 1+5 落地）
Phase 2：方向 A+D -- normal methylation ref + CN/Purity-aware（目標 4）
Phase 3：方向 B -- gene-level evidence integration（目標 3）
Phase 4：方向 C -- CpG 功能分層（目標 1 精細化）
```

### Paired/TO 互補策略

- TO 是**獨立主線**（非 paired 簡化版）
- Paired 是**對照與驗證來源**
- Paired 先定義可信 evidence --> 移植到 TO
- TO 大量 FP 提供壓力測試

### LOH 定位

LOH/HP imbalance 屬於 **evidence panel 第一層（基礎觀察），非主判斷器**。
- Paired: LOH-like 輕度 FP enrichment（1.194x），但有 sample heterogeneity
- TO: LOH-like 呈 TP 富集（0.805x），方向與 paired 相反
- 關鍵限制：LOH 只在同一 PS block 內有效，不能跨 block 串聯

## 7. 競爭態勢（ISM vs 其他工具）

### 最接近的競爭/先行研究

| 工具/研究 | 相似度 | 與 ISM 的關鍵差異 |
|-----------|-------|-------------------|
| **NanoMethPhase** (Genome Biology 2021) | 高 | NanoMethPhase: 全基因組 ASM；ISM: per-SNV clustering |
| **PRISM** (Bioinformatics 2019) | 高 | PRISM: reference-free bulk deconvolution；ISM: read-level with variant anchor |
| **MethylBERT** (Nat Commun 2025) | 中高 | MethylBERT: supervised ML deconvolution；ISM: unsupervised clustering + significance |
| **t-nanoEM** (Cell Reports Methods 2025) | 中 | t-nanoEM: converted reads + targeted capture；ISM: native MM/ML + WGS |
| **CAMDAC** (TRACERx, Nat Genet 2025) | 中 | CAMDAC: bulk CN-aware deconvolution；ISM: read-level per-SNV |
| **DeepSomatic** (bioRxiv 2024) | 低-中 | 上游 caller 競爭者，不使用甲基化 |
| **LongPhase-S** (bioRxiv 2025) | 互補 | ISM pipeline 上游組件；purity estimation 可直接輸入 |

### ISM 的獨特定位（尚未被覆蓋）

1. **以 somatic SNV 為錨點 + read-level methylation clustering + 雙向顯著性驗證**的完整框架 -- ISM 獨有
2. **在 variant verification 場景中使用甲基化 pattern** -- 大多數研究用甲基化做 deconvolution/ASM detection
3. **同時輸出 cluster-first 與 label-first 的 VerificationClass** -- 無直接對標

### 學界共識事項

1. Purity/CNV 校正必要性（TRACERx、POG、多項研究一致）
2. 長讀序多模態價值（POG、NanoMethPhase、t-nanoEM、LongPhase-S）
3. LOH-SNV 作為天然 tumor/normal 分離標籤（TRACERx、POG）
4. Promoter methylation + LOH = classical second hit（POG、t-nanoEM、CRC TSG）
5. ONT 甲基化/錯誤型態耦合（LongPhase 文獻）

### 存在分歧或未驗證之處

1. 局部甲基化 cluster 的生物意義（ISM read-level per-SNV clustering 缺獨立驗證）
2. Read-level clustering vs ML-based classification（無 head-to-head 比較）
3. Cross-platform/cross-sample 甲基化特徵可攜性（ISM 實驗顯示 PairwiseMedianDist 方向有樣本依賴）
4. Germline ASM vs Somatic ASM 區分（TO 場景缺乏解法）

### 論文定位建議

> 以長讀序 somatic variant 為錨點，整合甲基化 pattern、haplotype、copy-number 資訊，提供 read-level epigenetic context for variant interpretation

此定位與 Long-Read POG、TRACERx、t-nanoEM 互補，且目前無人完整實作。

## 8. 未來方向（Phase 2 A/B/C/D 詳情）

### Phase 1（當前）：方向 E -- ML Read Classification

- 靈感：MethylBERT (2025)
- 目標：用 ML 模型學習 read-level methylation pattern，取代/補充 unsupervised clustering
- Phase 1A 進度：已建立 per-read training/export layer，141,014 regions 在 manifest
- Phase 1A 結果：Paired F1 +0.0112（顯著但弱）；TO F1 -0.0206（負增益，待 self-phasing 修正）
- Phase 1B：is_tumor 分類，受限於 normal_reader 未接入

### Phase 2：方向 A + D -- Normal Methylation Ref + CN/Purity-Aware

**方向 A: Copy-Number / Purity-Aware Read-Label Modeling**
- 靈感：TRACERx CAMDAC + Long-Read POG
- 核心：在 LOH 區域，ALT reads ~ tumor-derived，REF reads ~ normal contamination
- 用 ALT/REF 標籤估計局部 tumor purity + 腫瘤 vs 正常甲基化背景
- 外部支撐：TRACERx LOH-SNV -> PDR 驗證（R>0.8）

**方向 D: Normal Sample 甲基化參考**
- 核心：在 paired 場景，利用 normal BAM MM/ML 建立 per-region normal methylation baseline
- ISM 聚類結果若與 normal 一致 -> downgrade 為 germline ASM
- 解決 FP 主因（germline ASM 混淆）的根本方案

### Phase 3：方向 B -- Gene-Level Evidence Integration

- 靈感：Long-Read POG IMPALA + TRACERx TSG analysis
- 核心：加 gene-level integrator，把同一基因多個 SNV window 彙總
- 結合 CNV/LOH，回答「此基因是否有 biallelic inactivation 證據」
- 定義 second-hit archetypes：mutation->LOH, LOH->mutation, promoter_methylation->LOH 等
- 直接對應 BRCA1/RAD51C/CDKN2A 等臨床問題

### Phase 4：方向 C -- CpG 功能分層與智慧選擇

- 靈感：EVOFLUx fCpGs + TRACERx M_R/M_N + MHB 研究
- 核心：將 CpG 依功能分為 Regulatory / fCpG-like / MHB-core
- 不同目標選不同 CpG 子集
- EVOFLUx 已識別 978 fCpGs 可直接借用

### 立即可做的觀察（研究建議）

1. LOH-SNV PDR 驗證（用 ALT/REF reads 分別計算 methylation pattern）
2. fCpG overlap 分析（EVOFLUx 978 fCpGs 與 ISM 視窗交叉）
3. Gene-level aggregation pilot（選 10 個已知 TSGs 彙總）
4. Normal methylation baseline（對 normal BAM 跑 ISM 同一視窗比較）

## 11. 隱含假設與風險

### 最大風險：Self-phasing 系統性汙染

在 P0 修正完成前，所有依賴 HP 的結論嚴格來說都是「在汙染條件下的觀測」。影響結論 3、5、8、12、15。

### 單樣本外推風險

PON 移除率（結論 2）、LOH.bed Jaccard（結論 13）、PON-only phasing（結論 10）均只在 HCC1395 驗證。HCC1395 的基因組特性（chr8 大塊 LOH、高純度 ~95%）可能不代表臨床樣本。

### Phase 1A 適用範圍可能被高估

- Discovery holdout 不顯著（CI 含零）
- Mixed mode 有害（-0.0206）
- H2009 負向
- 效應量極小（+0.011 F1）
- 建議定位為 proof-of-concept，非「已確認有效」

### Purity 影響

- 低 purity (<40%)：固定甲基化門檻嚴重傷害 Recall
- 高純度細胞株（80-95%）中 TP within_dom 本來就偏高
- 低純度臨床樣本可能表現不同

### LOH.bed 生成機制待確認

LOH.bed 是基於 VCF AD 還是 BAM HP tag？這是 P0 級待驗證事項，影響對兩套 LOH 系統關係的理解。
