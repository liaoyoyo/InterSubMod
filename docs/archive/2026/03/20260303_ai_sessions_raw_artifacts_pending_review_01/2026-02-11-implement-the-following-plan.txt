│                                                                              │

│ Step 3: 建立 scripts/pipeline/steps/01_longphase_s.sh                        │
│                                                                              │
│ LongPhase-S somatic_haplotag：                                               │
│                                                                              │
│ # 核心指令                                                                   │
│ ${LONGPHASE_S_BIN} somatic_haplotag \                                        │
│   -s ${GERMLINE_PHASED_VCF} \                                                │
│   -b ${NORMAL_BAM} \                                                         │
│   --tumor-snv-file ${SOMATIC_VCF} \                                          │
│   --tumor-bam-file ${TUMOR_BAM} \                                            │
│   -r ${REFERENCE} \                                                          │
│   -t ${THREADS} \                                                            │
│   --tagSupplementary -q 20 \                                                 │
│   --output-somatic-vcf \                                                     │
│   --truth-vcf ${TRUTH_VCF} \                                                 │
│   --truth-bed ${TRUTH_BED} \                                                 │
│   -o ${OUTPUT_PREFIX}                                                        │
│                                                                              │
│ 功能設計：                                                                   │
│ - 接受參數：--sample, --output-dir                                           │
│ - 輸入路徑驗證（所有 BAM/VCF/REF 存在性檢查）                                │
│ - 執行時間與記憶體記錄（/usr/bin/time -v）                                   │
│ - 自動建立 BAM index（samtools index）                                       │
│ - 記錄 LongPhase-S 的 stdout/stderr 到 log 檔                                │
│                                                                              │
│ Step 4: 建立 scripts/pipeline/steps/02_intersubmod.sh                        │
│                                                                              │
│ InterSubMod 甲基化分析（對 TP 和 FP VCF 各執行一次）：                       │
│                                                                              │
│ # 對 TP VCF                                                                  │
│ ${INTERSUBMOD_BIN} \                                                         │
│   --tumor-bam ${TAGGED_BAM} \                                                │
│   --normal-bam ${NORMAL_BAM} \                                               │
│   --reference ${REFERENCE} \                                                 │
│   --vcf ${TP_VCF} \                                                          │
│   --output-dir ${OUTPUT_DIR}/intersubmod_tp \                                │
│   --threads ${THREADS} \                                                     │
│   --window-size ${WINDOW_SIZE} \                                             │
│   --distance-metric ${DISTANCE_METRIC} \                                     │
│   --log-level ${LOG_LEVEL} \                                                 │
│   --output-filtered-reads                                                    │
│                                                                              │
│ # 對 FP VCF（同上，替換路徑）                                                │
│                                                                              │
│ 功能設計：                                                                   │
│ - 接受 tagged BAM 和 TP/FP VCF 路徑                                          │
│ - 序列執行（TP 先、FP 後），避免記憶體爆炸                                   │
│ - 可選 --plot-type no 跳過視覺化（節省時間）                                 │
│ - 記錄 significance_summary.csv 路徑                                         │

│ Step 5: 建立 scripts/pipeline/steps/03_filter_analysis.py                    │
│                                                                              │
│ 過濾條件分析 + F1 計算：                                                     │
│                                                                              │
│ 輸入：                                                                       │
│ - intersubmod_tp/significance_summary.csv (TP 位點甲基化特徵)                │
│ - intersubmod_fp/significance_summary.csv (FP 位點甲基化特徵)                │
│ - 原始 somatic VCF（提取 QUAL, VAF）                                         │
│ - SEQC2 truth set 總 sSNV 數量（計算 Recall/FN）                             │
│                                                                              │
│ 處理邏輯：                                                                   │
│ 1. 讀取 TP 和 FP 的 significance_summary.csv                                 │
│ 2. 從 VCF 提取對應位點的 QUAL 和 VAF                                         │
│ 3. 合併甲基化特徵（AlleleDelta, CramersV）與 VCF 特徵                        │
│ 4. 應用過濾條件：(QUAL < 0.75) OR (AD > 0.25 AND V < 0.05 AND VAF < 0.24)    │
│ 5. 計算 baseline 和 filtered 的 Precision/Recall/F1                          │
│ 6. 輸出 metrics.json                                                         │
│                                                                              │
│ 輸出格式（metrics.json）：                                                   │
│ {                                                                            │
│   "sample": "HCC1395",                                                       │
│   "mode": "s-pure",                                                          │
│   "purity": "pure",                                                          │
│   "truth_total": 39447,                                                      │
│   "baseline": {"tp": 30476, "fp": 4822, "precision": 0.8634, "recall":       │
│ 0.7726, "f1": 0.8155},                                                       │
│   "filtered": {"tp": 29836, "fp": 1426, "precision": 0.9544, "recall":       │
│ 0.7564, "f1": 0.8439},                                                       │
│   "improvement": {"f1_delta": 0.0284, "fp_removed": 3396, "tp_removed": 640} │
│ }                                                                            │
│                                                                              │
