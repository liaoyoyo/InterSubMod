## 對話背景

InterSubMod 專案累積了大量研究文件，但缺乏讓 AI 能快速「由淺入深」查閱的導航架構。本次對話依據預先設計的計劃，建立「Layer 0 → Layer 1 → Layer 2 → Layer 3」的 4 層披露架構，並將前次 docs 重整的 ~131 個變更整理成 10 個邏輯性 git commit，完整歸檔到 develop。

## 關鍵決策

| 決策 | 原因 | 影響 |
|------|------|------|
| 採用 `docs/experiments/INDEX.md` 而非 `RESEARCH_HISTORY.md` | 與現有目錄分層一致，AI 探索 experiments/ 時自然發現 | INDEX.md 成為 Layer 2 核心入口 |
| Layer 2 深入摘要選定 5 個方向 | 優先記錄最有繼續研究價值的方向（TP/FP、Purity-Aware、Subsample、雙向驗證、PERMANOVA） | 關鍵數字（OR 值、F1 表格）集中於此，減少重複查閱細節文件 |
| 必讀清單寫入 AGENTS.md 與 CLAUDE.md | 確保新 AI Session 啟動時強制執行「先讀歷史再行動」 | 防止重複已驗證失敗的研究方向 |
| git 整理採「10 個邏輯 commit」而非單一大 commit | 歷史清晰可追溯，每個 commit 對應一個語意範疇 | develop 分支歷史易讀，blame 有意義 |

## 研究歷史 INDEX.md 內容摘要

### Layer 1 — 12 個研究方向（全部）

| 狀態 | 方向 | 關鍵結論 |
|------|------|---------|
| ✅ | 甲基化解析 MM/ML | 需 CIGAR 展開解碼 |
| ✅ | CIGAR 座標映射 | Soft-clip 偏移、Del 跳過、Ins 不消耗 |
| ✅ | 距離計算聚類 | NHD 最穩定，BERNOULLI 速度最快 |
| ✅ | OpenMP 平行化 | 8 thread 加速 5x+ |
| ✅ | Fisher/χ² 統計 | Cramér's V 有效量化效應強度 |
| ✅ | PERMANOVA | 計算昂貴，預設關閉；Cramér's V 足夠 |
| ✅ | Bernoulli 距離 | F1 高於 NHD 0.5-1%，推薦預設 |
| ✅ | TP/FP 特徵富集 | LOH_like OR=7.33、LowAF OR=0.046（FP） |
| ✅ | 雙向驗證 | 4 象限矩陣：Label-First vs Cluster-First |
| ✅ | F1 最佳化 | F1=0.8481（AF≥0.3 OR SubclonalSomatic） |
| ⏳ | Subsample 混樣偏差 | HCC1395 ONT 無 MM/ML；DORADO 低純度閾值傷 Recall |
| 🔄 | Purity-Aware 策略 | 三段式閾值設計，待完整驗證 |

### Layer 2 — 5 個深入摘要（含數字）

1. **TP/FP 特徵富集**：OR 值表格、F1 對比 baseline 0.8155 vs 最佳 0.8481
2. **Purity-Aware 過濾策略**：<40%/40-60%/≥60% 三段閾值設計
3. **Subsample 混樣甲基化偏差**：4 假說排序 + MM/ML Guard 機制
4. **雙向驗證（Label-First vs Cluster-First）**：4 類決策矩陣
5. **PERMANOVA + Cramér's V**：AUC 值、三層過濾建議
