### 3. Shell 腳本改進

**scripts/run_batch_vcf_analysis.sh**

修復前（行 149-153）：
```bash
wait
echo "[Batch] All VCF analysis jobs completed."
```

修復後：
```bash
FAILED=0
for i in "${!PIDS[@]}"; do
    PID="${PIDS[$i]}"
    LABEL="${LABELS[$i]}"
    if ! wait "$PID"; then
        FAILED=$((FAILED + 1))
        echo "[Batch] WARNING: Job '${LABEL}' (PID ${PID}) failed"
    fi
done

if [ $FAILED -gt 0 ]; then
    echo "[Batch] WARNING: ${FAILED}/${#PIDS[@]} job(s) failed."
else
    echo "[Batch] All ${#PIDS[@]} VCF analysis jobs completed successfully."
fi
```
