# 文檔庫架構重整（第二階段）

## 對話資訊

| 項目 | 內容 |
|------|------|
| 日期 | 2026-01-12 |
| 時長 | 約 30 分鐘 |
| AI 模型 | Claude Opus 4.5 |
| 主要目的 | 完善文檔庫架構：二級歸檔、Hooks 自動化、文檔規範整合 |

## 對話背景

延續 2026-01-11 的文檔庫第一階段重整，用戶提出以下改進需求：
1. trash 目錄內含有價值的舊結構檔案，不應直接刪除
2. solutions/ 和 experiments/outputs/ 需要二級歸檔（按任務目標分層）
3. 需要 Claude Code Hooks 自動化提醒
4. CLAUDE.md 需要加入文檔管理規範

## 關鍵決策

| 決策項目 | 決定內容 | 理由 |
|----------|----------|------|
| 舊結構處理 | 移至 archive/deep/2025-12_old_structure/ | 保留完整歷史紀錄，便於日後查詢 |
| 二級歸檔結構 | 任務目標為第二級，年/月為第三級 | 先按任務分類再按時間，查找更直觀 |
| Hooks 類型 | PostToolUse + Stop | 覆蓋程式碼修改、git 提交、會話結束三個關鍵時機 |
| 深度歸檔索引 | 每個備份目錄需包含 INDEX.md | 提供快速查詢入口 |
