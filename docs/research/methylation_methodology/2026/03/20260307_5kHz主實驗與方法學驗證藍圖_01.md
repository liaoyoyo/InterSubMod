# 5kHz 主實驗與方法學驗證藍圖（2026-03-24 後主線版）

## 1. 主線背景與定位

InterSubMod 已完成三件關鍵工作：

1. `paired pure / TO` 基線建立
2. 方法學審查 closeout
3. 研究方法與相關文獻突破方向全域分析

目前已確認的高層結論是：

- InterSubMod 現階段最穩定的流程分工是 `caller-first → methylation-support → annotation / QC / artifact triage`
- `label-first / cluster-first` 可保留為解釋框架與 annotation 基座，但不是下一階段唯一主研究目標
- 若要真正突破目前天花板，主軸必須從規則微調轉向方法升級

因此，本文件不再把 `paired pure` 本身當研究終點，而是把它重新定位為後續突破方向的固定 baseline 與驗證資料。

## 2. 已確認的基線前提

### 2.1 可直接沿用的研究前提

1. `HCC1395 5kHz paired/TO` 與 `HCC1395_DORADO paired/TO` 已可作固定 head-to-head baseline。
2. `GQ` 仍是最穩定的 caller-side 訊號；甲基特徵尚未穩定超過 caller-first。
3. `VerificationClass`、`QualityScore`、`PairwiseMedianDist`、`LOH_Subtype` 較適合當 support / annotation / diagnostics。
4. germline ASM 是目前 paired hard FP 的核心根因，單靠 gate 微調或單一甲基特徵無法解決。

### 2.2 不再當主線重複驗證的方向

1. 單純重做 `label-first / cluster-first` 合理性驗證
2. `H006 window_bp=1000`
3. `AlleleDelta standalone filter`
4. 將 `PERMANOVA` 升級為 filter
5. 期待以更嚴 gate 直接解決 germline ASM FP

## 3. 下一階段突破方向

### 3.1 Phase 1：方向 E，ML Read Classification

- 目標：突破 unsupervised clustering 的辨識天花板，直接在 read-level pattern 上學習 tumor / normal / artifact 結構
- 主要比較對象：現有 `VerificationClass`、`QualityScore`、`PairwiseMedianDist`
- 預期成果：原型 read classifier、head-to-head 比較報告、代表性 read-level diagnostics

### 3.2 Phase 2：方向 A+D，Normal Baseline + CN/Purity-aware

- 目標：在聚類前先校正 normal contamination、LOH、copy-number 與 purity 對甲基訊號的混合作用
- 關鍵切入：利用 paired normal BAM 建立 per-region normal methylation baseline
- 預期成果：purity-corrected methylation matrix、germline vs somatic ASM 區分原型

### 3.3 Phase 3：方向 B，Gene-level / Mechanism-level Integration

- 目標：把 per-SNV 視窗證據提高到 gene-level 的 second-hit / biallelic event narrative
- 整合對象：multiple SNV windows、LOH/CNV、promoter methylation、caller / phasing 資訊
- 預期成果：gene-level evidence panel、second-hit archetype 定義

### 3.4 Phase 4：方向 C，CpG 功能分層與智慧選點

- 目標：依 driver / ASM / lineage / structural 不同任務，選擇不同的 CpG 子集
- 外部連結：fCpG-like、regulatory CpG、MHB-core
- 預期成果：annotated CpG catalogue、分任務 distance / evidence 配置

## 4. 樣本與資料角色

### 4.1 主 benchmark 樣本

1. `HCC1395 5kHz paired`
   - discovery 與 stress-test 主樣本
   - FP 與 noisy 結構較多，最適合觀察新方法是否真的改善
2. `HCC1395_DORADO paired`
   - 同 biological sample 的 cross-platform validation
   - 對「只在 5kHz 成立」的現象有最佳辨識力

### 4.2 TO 驗證樣本

1. `HCC1395 5kHz TO`
   - mode-specific rescue / support 驗證
2. `HCC1395_DORADO TO`
   - TO support 規則的跨平台 validation

### 4.3 其他 pure paired 樣本

- 角色是穩定性與可攜性檢查，不是主發現來源
- 用途是確認新方法是否只在單一 sample / chemistry 成立

## 5. 每次啟動時要回答的問題

1. 這一輪是在推進哪個 phase：E、A+D、B 還是 C？
2. 這一輪要和哪個既有 baseline 比較？
3. 這一輪的輸出是新方法原型、annotation layer，還是 gene/CpG evidence panel？
4. 這一輪是否重新打開了已 closeout 的舊問題？若有，需先說明原因。

## 6. 證據與報告原則

### 6.1 固定比較原則

每次 benchmark 都必須同時列出：

- `truth_total`
- `calls_total`
- `TP`
- `FP`
- `FN`
- `precision`
- `recall`
- `F1`

比較口徑至少要能回答：

1. `ClairS` 相對 `SEQC2`
2. `LongPhase-S` 相對 `SEQC2`
3. `InterSubMod` 相對 `SEQC2`

若是新方法 phase，還必須補：

4. 新方法相對現有 `caller-first + methylation-support` baseline 的差異
5. 是否跨 `5kHz / DORADO` 方向一致

### 6.2 異常與不合假設時的輸出

若研究結論不合預期，必須至少輸出：

1. 相關聯數據表
2. region diagnostics 圖
3. 本輪改動與假說對照
4. 對可能原因的推理

## 8. 現階段不作主證據的方向

1. 只做舊規則的微調 sweep
2. 只做 `paired pure` 合理性複驗
3. 把 TO support 規則直接升級成全域部署規則
4. 在沒有 normal baseline 的情況下宣稱解決 germline ASM
5. `mixed purity / subsample` 作為當前第一主證據

這些方向不取消，但要等突破方向 phase 有明確輸出後再考慮延伸。
