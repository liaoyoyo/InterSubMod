# Exact-PS×HP 區域 mutation-state tree：研究狀態與 AI 交接手冊

## 1. 背景摘要

本研究利用 Oxford Nanopore Technologies（ONT）長讀長在同一 DNA molecule 上
同時跨越多個 somatic single-nucleotide variants（sSNVs）的能力，建立局部
mutation-state constraints。每條 read 不等於一個 cell，也不等於一個 clone；
它只表示某個 molecule 對一組 sSNV 呈現的 R/A/X pattern。

為降低不同 homolog 與 phase block 混合，資料先依 exact nonmissing phase set
（PS）與 primary haplotype tag（HP1/HP2）分開，再以至少三條 distinct molecules
支持的 endpoint linkage 建立 strict read-linked components。大 component 以
read-supported ordered partition 分成原始 \(k\le12\) 的 local blocks。

每個 block 轉成有向布林超立方體上的群組 Steiner arborescence 問題：
完整 R/A pattern 是 mandatory mutation state；含 X 的 partial pattern 是 subcube
terminal group。現行 primary solver 在 recurrence-allowed、unit-cost、只允許
0→1 Hamming-1 transition 的模型下，列舉所有 minimum vertex sets；固定 vertex set
後，每個非根節點選一個合法 predecessor，即形成 rooted arborescence。

read-AF 再用同一 PS×HP block 內 supported R/A molecule counts，對完整 minimum
candidate trees 作 deterministic ordering。此層未整合 CNV、LOH、purity、mutation
multiplicity、BaseQ likelihood 或 AF uncertainty，因此只可稱條件式排序。甲基層則
是 pattern-conditioned regional association；它不改 edge、不重新打分 topology。

專案最適合定位為：

> 可稽核的區域 mutation-state candidate reconstruction，以及其可識別性、
> 拒絕條件與有界輔助證據。

不是：

> 已恢復每個樣本真實的 cellular clone genealogy。

## 2. 研究問題與輸出層級

| 層級 | 問題 | 現行輸出 | 最高可說到哪裡 |
|---|---|---|---|
| L1 read linkage | 哪些 sSNVs 被相同 molecules 局部連結？ | W components／blocks | local read-linked region |
| L2 state selection | 哪些完整 R/A mutation states 可共同滿足 reads？ | minimum vertex-set family | read-compatible candidate states |
| L3 parent mapping | 這些 states 有哪些 Hamming-1 parent assignments？ | candidate arborescences | model-compatible parent trees |
| L4 read-AF | 哪些候選較符合高 fraction mutation 較早的先驗？ | AF-preferred candidates | CN/LOH-unadjusted ordering |
| L5 topology | AF-best trees 有幾種 rooted graph shapes？ | exact signature census | mathematical graph geometry |
| L6 methyl | R/A pattern 是否與區域甲基結構相關？ | association sidecar | pattern-conditioned association |
| L7 biology | 是否為真實 cell clone／subclone lineage？ | 尚無 | 必須 abstain |

一個 stage 通過不能替下一個 stage 背書。

## 3. 現行資料範圍

- 7 technical datasets：
  - HCC1395
  - HCC1395_DORADO
  - COLO829
  - H1437
  - H2009
  - HCC1937
  - HCC1954
- 6 biological IDs：HCC1395 與 HCC1395_DORADO 是同一 cell line 的 technical pair。
- Chromosomes：chr1–22。
- sSNV universe：同次 LongPhase-S recalibrated PASS、biallelic autosomal sSNVs。
- Primary grain：

```text
dataset × chromosome × exact PS × primary HP × strict component × local block
```

## 4. 端到端流程

```text
LongPhase-S PASS sSNVs
→ exact PS × primary HP read projection
→ support≥3 strict endpoint read linkage
→ k≥2 W components
→ k>12 read-supported ordered partition
→ R/A/X supported patterns
→ active-bit compression
→ exact minimum vertex-set family
→ Hamming-1 parent mapping factorization
→ supported-pattern read-AF ranking
→ exact global-best topology signatures
→ methyl association-only sidecar
→ reports / receipts / workstation
```

### Step → Verify

1. **sSNV 與 read identity join**  
   → 驗證：projection multimatch=0；每個 record 綁定 same-run PS/HP authority。
2. **Strict linkage**  
   → 驗證：154/154 dataset×chromosome receipts；W、edge、component 守恆。
3. **Partition**  
   → 驗證：跨 cut constraints 明確記錄；每個 block original \(k\le12\)。
4. **Solver**  
   → 驗證：只有 objective/family exhausted 才發布 complete family；guard hit abstain。
5. **Parent mapping**  
   → 驗證：每個非根節點 parent 少一個 bit；tree count 使用 exact integer。
6. **read-AF**  
   → 驗證：Python/C++ exact score、tie count parity；zero denominator fail-closed。
7. **Topology census**  
   → 驗證：71,955 rows 全重現 canonical score/tie；680,527 global-best trees。
8. **Methyl sidecar**  
   → 驗證：authority 與 topology 分開；association halo 不改 edge incidence。

## 5. Canonical 分母

```text
469,849 autosomal sSNV dataset-records
→ 255,752 strict components
→ 170,131 k=1 abstain
→ 85,621 k≥2 W
→ 98,955 final topology groups
→ 85,941 mutation-bearing
→ 75,224 complete minimum families
→ 71,955 read-AF ranked
```

### 5.1 Solver／AF

| 指標 | 數量 | 分母／解釋 |
|---|---:|---|
| Final groups | 98,955 | 全部 local groups |
| No active ALT | 13,014 | 不作 mutation tree inference |
| Mutation-bearing | 85,941 | active \(k\ge1\) |
| Family complete | 75,224 | 87.53% of mutation-bearing |
| Resource abstain | 10,717 | search-node guard；非隨機缺失 |
| read-AF ranked | 71,955 | complete、通過 AF recurrence screen、非 zero denominator |
| Zero denominator | 3,224 | structure 可有，AF 不可算 |
| AF recurrence-screen abstain | 45 | structure 保留；全部 minimum sets recurrence-required，故不進 AF ordering |

### 5.2 AF-best tree resolution

| 類型 | 數量 | ranked 分母比例 | 可解釋 |
|---|---:|---:|---|
| Unique best tree | 39,648 | 55.1011% | raw-score arithmetic unique |
| Tied, same rooted-unlabeled topology signature | 23,858 | 33.1568% | shape 相同、labeled tree 未解 |
| Tied, cross topology | 8,449 | 11.7421% | topology 未解 |
| One rooted-unlabeled topology signature | 63,506 | 88.2579% | model-conditional graph shape |

AF 前已只有一棵 structural candidate 的 ranked units 為 28,693；AF 真正將
原始 multi-tree units 縮成唯一者為 10,955／43,262＝25.32%。因此 AF 有幫助，
但不能說它解決了所有多樹問題。

## 6. 重要術語

| 術語 | 中文詞義 | 本研究角色 |
|---|---|---|
| sSNV | 體細胞單核苷酸變異 | Boolean mutation dimension |
| PS | 相位集合 | 禁止跨 phase set 混合 |
| HP | haplotype tag | 分開兩個 homolog 的 read evidence |
| W | strict read-linked component | k≥2 的局部 read-linkage region |
| block | 有界分析單位 | \(k>12\) component 的 local partition |
| R/A/X | REF／ALT／未知 | read pattern；X 形成 subcube |
| active k | 至少一個 supported A 的位點數 | 真正 solver dimension |
| mandatory vertex | 完整觀察 mutation state | 必須進入 candidate vertex set |
| terminal subcube | partial pattern 的 compatible states | 至少選到一個 representative |
| hidden／extra state | 未列於 mandatory set 的 state | 可為 connector 或 group representative，不等於 clone |
| candidate family | 全部同分 minimum vertex sets | 完整後才能排名 |
| read-AF | supported molecules 的 ALT/(REF+ALT) | ordering heuristic |
| topology signature | 忽略 mutation label 的 rooted tree shape | graph geometry census |
| ABSTAIN | 不滿足完整性／適用性 | 正式輸出，不是遺漏 |
| \(h^*\) | minimum additional non-mandatory vertex count | objective 值；不等於完整 candidate family |
| rooted three-gamete screen | 檢查一對 characters 是否同時出現 10/01/11 | post-hoc recurrence-free compatibility screen |
| `input_vaf_eligible` | legacy/caller-VAF eligibility 欄位 | 目前不控制 internal read-AF，必須拆名 |
| Technical PASS | 命令、schema、receipt、hash 與守恆通過 | 不代表 biological validation eligible |
| Primary HP | upstream 投影保留的 HP1/HP2 read stratum | 不能解讀為父系/母系或 cell clone |

## 7. 已知成立的前提

1. exact PS×primary HP 分區與 strict linkage 已完成 chr1–22 全範圍執行。
2. C++ 對 frozen read-AF 公式、minimum family 與 tie count 通過小型 exhaustive
   oracle 與 HCC1395 parity。
3. family complete 時，minimum vertex-set family 是在現行 recurrence-allowed
   model 下的 exact 結果。
4. 固定 vertex set 後，每個非根節點選一個 Hamming-1 predecessor 可形成
   rooted arborescence。
5. exact topology signature census 只對 71,955 ranked units 成立。

## 8. 尚未成立的前提

1. read-AF 可準確代表 cell prevalence。
2. allele-specific CN／LOH、purity、multiplicity 已校正。
3. arithmetic unique winner 具有統計穩定性。
4. minimum states 等於真實 clone 數。
5. hidden state 是已存在的細胞 clone。
6. Sister／Direct geometry 可直接翻成多 clone／subclone。
7. local PS×HP blocks 可拼成 whole-sample lineage。
8. methyl association 可決定 edge、方向或 clone。
9. 10,717 resource abstains 與 ranked subset 可互換外推。

## 9. 不應重踩的舊方向

- 以舊 50 kb adjacency 取代 strict read linkage。
- 混合不同 PS 或跨 HP 建樹。
- 把 recurrence-allowed model 寫成已強制 strict perfect phylogeny。
- 用 deterministic representative 當成 tied family 的真實唯一樹。
- 把 HCC1395 與 HCC1395_DORADO 當兩個 biological replicates。
- 用 methyl difference 直接重排 topology。
- 把 read cluster 或 molecule pattern 當成 cell clone。
- 用 7/25 的 \(h^*\) recovery 更新完整 topology；該結果尚未列完 candidate family。

## 11. 新 AI 回答問題前的檢查

1. 問題談的是 read、molecule、mutation state、copy 還是 cell？
2. 分母是全部 groups、mutation-bearing、family complete、ranked 還是
   topology-resolved？
3. family 是否完整？
4. model 是 recurrence-allowed 還是 strict infinite-sites？
5. CN/LOH 是否 assessed？
6. tree 是 exact candidate、AF representative、topology-only 還是 consensus？
7. 使用的結果是否有 path、SHA-256、schema 與 receipt？
8. 來源是否列於過期登錄？

若任一項不清楚，先 abstain 或查 `authority_manifest.json`，不要自行補完。
