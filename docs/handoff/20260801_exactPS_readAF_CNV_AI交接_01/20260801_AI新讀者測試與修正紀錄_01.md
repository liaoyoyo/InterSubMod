# AI 新讀者測試與修正紀錄

> **交接包可供沒有舊對話的 AI 安全接續研究；它能正確把現況解讀為 local
> mutation-state candidate reconstruction，而不是已證實的 cellular clone tree。**

## 3. 無前情 AI reader test

測試限制：

- 不提供舊對話。
- 第一輪只給交接包，不指向其他背景文件。
- 要求讀者自行說明 read-AF、CNV、recurrence、resource abstain、topology 與
  單一樹輸出的界線。

### 第一輪發現與修正

| 發現 | 風險 | 修正 |
|---|---|---|
| recurrence structural model 與 AF screen 的關係不夠明示 | 可能把 45 units 當成 structure failure | 新增 `AF_ABSTAIN_RECURRENCE_SCREEN`；structure 保留、AF abstain |
| P0 項目只有清單，依賴不夠機器可讀 | AI 可能跳過 clean release 先跑全量 | 加入 `action_id`、sequence、depends_on、owner、status、DoD |
| manifest 與 TSV authority 分工可能被誤讀 | 形成兩份競爭 SoT | manifest 定義為 machine-readable authority index；TSV 專管分母 |
| resource-limit 沒有直接映射 tree decision | guard hit 可能仍被選 winner | 明定 `ABSTAIN_RESOURCE_LIMIT → ABSTAIN_INCOMPLETE → SEARCH_NODE_GUARD` |
| topology 用語含混 | 可能把 labeled tree 與 graph shape 混用 | 統一為 `rooted-unlabeled topology signature` |
| read-AF wording過強 | 可能被解讀為 compatibility／likelihood | 統一為 `monotonicity preference ordering` |
| 分母表缺 excluded/unknown/fan-out | 98,955/85,621 可能被誤報成 prevalence | 新增 parent、excluded、unknown、reason；標明 one-to-many partition |
| CN／合併欄位不足 | AI 不知道何時應 fail-closed | 新增 purity、ploidy、CN、multiplicity、HP mapping 與 bridge receipt 欄位規格 |

### 第二輪結果
