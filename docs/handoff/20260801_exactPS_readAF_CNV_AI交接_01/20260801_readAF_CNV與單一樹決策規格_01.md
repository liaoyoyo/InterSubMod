# read-AF、CNV 與「單一樹」輸出決策規格

## 1. 方法學裁決

> **read-AF 可以作 monotonicity preference ordering，但目前不能作 biological single-tree
> confirmation。**

主要原因不是「族群大小讓 AF 完全無效」，而是：

1. 族群大小決定終點 snapshot 的 mutation carrier fraction，因而影響可辨識性。
2. read-AF 沒有 clone-size sampling、coverage uncertainty 或 overdispersion model。
3. CNV、LOH、mutation multiplicity 與 copy loss 尚未整合。
4. 同一批 marginal AF 對同一 vertex set 的不同 parent assignments 通常不是獨立
   edge likelihood。

因此目前的 `best_tree_unique=true` 只表示 frozen arithmetic score 沒有 exact tie，
不等於統計穩定或生物唯一。

## 2. 族群大小到底影響什麼

令：

- \(\pi_c\)：終點樣本中 clone／cell population \(c\) 的比例；
- \(m_{cj}\)：clone \(c\) 在位點 \(j\) 的 mutation-bearing copy 數；
- \(C_{cj}\)：clone \(c\) 在位點 \(j\) 的 total copy number；
- \(\rho\)：tumor purity；
- \(C_{Nj}\)：normal cell 的 total copy number。

忽略 mapping/callability 後，bulk VAF 的概念式為：

\[
E[VAF_j]
\approx
\frac{\rho\sum_c\pi_c m_{cj}}
{(1-\rho)C_{Nj}+\rho\sum_c\pi_c C_{cj}}.
\]

這說明 VAF 同時受到：

- 最終 clone proportions；
- mutation multiplicity；
- total／minor copy number；
- purity；
- allele-specific copy；
- sampling 與 mapping；

共同影響。

### 2.1 為何族群大小本身不否定單調必要條件

在 copy-neutral、無 loss、無 recurrence、單 copy mutation 的理想 nested lineage：

```text
祖先 mutation 的 carrier cells
⊇ 後代 mutation 的 carrier cells
```

因此不論後代族群最後長到多大，理論上仍有：

\[
f_{\mathrm{ancestor}}\ge f_{\mathrm{descendant}}.
\]

族群大小主要控制兩者差距：

- 後代幾乎取代祖先其他分支時，兩者可能非常接近；
- coverage 低時，微小差距可能因抽樣而反轉；
- branching 時，parent mutation 應覆蓋互斥 children 的聯集。

白話例子：

```text
20% 細胞只有 mutation A
80% 細胞有 A+B
```

在理想 copy-neutral、單 copy 情境，A 的 carrier fraction 是 100%，B 是 80%
（未分 HP 的純腫瘤 diploid VAF 約為 50% 與 40%）；族群大小改變差距，但仍符合
A≥B。若 100% 細胞都已是 A+B，兩者 carrier fraction 皆為 100%，終點樣本就
無法只靠 AF 判斷 A 與 B 的先後。

所以「祖先 fraction 不低於後代」是理想模型下的必要條件；現行 score 只把它
轉成沒有 hard threshold 的 preference ordering，不是 formal compatibility test，
更不是充分的 ancestry 證明。

### 2.2 branching 需要比 pairwise 大小更強的條件

若 parent 有互斥 children，理想 cellular prevalence 還應滿足：

\[
f_{\mathrm{parent}}\ge \sum_{c\in children}f_c.
\]

現行 edge score沒有估計互斥 clone fractions，也沒有實作 branching sum rule。
它只能對 marginal mutation fractions 進行 deterministic preference。

## 3. 現行 read-AF 定義

同一 exact PS×HP block 中，先保留 support \(\ge3\) 的 R/A/X patterns。
對 mutation \(j\)：

\[
\widehat{AF}_j=\frac{A_j}{A_j+R_j},
\]

`X` 不進該位點分母。

候選邊 \(p\rightarrow c\) 新取得 mutation \(j(c)\) 時：

\[
s(p,c)=\sum_{i\in p}
\left(\widehat{AF}_i-\widehat{AF}_{j(c)}\right).
\]

整棵候選樹：

\[
S(T)=\sum_{c\neq root}s(parent(c),c).
\]

此分數偏好「parent 已有 mutations 的 AF 不低於新取得 mutation」。
C++ 以 exact rational 計算，因此 tie／unique 是算術精確，但不包含統計不確定性。

## 4. CNV／LOH 為何能破壞解釋

### 4.1 Allele-specific amplification 反例

同一個 cell 可能有：

```text
HP1-derived copy A = 10
HP1-derived copy B = 11
```

同一 HP 上讀到 `10` 與 `11`，可能來自一群細胞內不同 duplicated copies，
不必然是祖先 clone 與後代 clone。

### 4.2 LOH 與 copy loss

- copy-neutral LOH 可為 `2+0`，total CN 仍為 2，但 minor CN 已不是 1。
- deletion／LOH 可移除已存在 mutation，違反 mutation 只增加的模型。
- subclonal LOH 使 molecule fraction 不等於 cell fraction。
- 兩個 HP 都存在只能排除完整 clonal LOH，不能排除 subclonal LOH。

因此 CN gate 至少需要 total CN、minor CN／allele-specific CN、segment callability
與 subclonal CN status。只看 total CN=2 不足以稱 copy-neutral compatible。

## 5. 單一樹輸出決策

### 5.1 必須依序執行的 gate

| 順序 | 條件 | `tree_decision` | 可輸出 |
|---:|---|---|---|
| 1 | `active_k=0` | `NO_MUTATION_TREE_INFERENCE` | root-only 狀態，不稱突變樹 |
| 2 | objective/family 未完整 | `ABSTAIN_INCOMPLETE` | reason、guard、已知下界；不可選 winner |
| 3 | structure 可完整，但全部 minimum sets 需要 recurrence | `AF_ABSTAIN_RECURRENCE_SCREEN` | recurrence-allowed structural candidate set；AF 不排序 |
| 4 | 要求 strict perfect，但 recurrence required | `ABSTAIN_MODEL_MISMATCH` | recurrence flag；不可稱 perfect tree |
| 5 | 完整候選集合本來只有一棵 | `EXACT_SINGLE_CANDIDATE_TREE` | model-conditional mutation-state tree |
| 6 | AF 不可算且候選 topology 相同 | `TOPOLOGY_ONLY` | canonical shape，不宣稱 labeled tree |
| 7 | AF 不可算且 topology 多種 | `CANDIDATE_SET_ONLY` | 全候選或 consensus backbone |
| 8 | AF best 多棵、topology 相同 | `TOPOLOGY_REPRESENTATIVE_ONLY` | shape＋不變/變動 edges |
| 9 | AF best 跨 topology | `CONSENSUS_BACKBONE_ONLY` | 共識邊與完整 co-top set |
| 10 | AF 算術唯一，但 CN/uncertainty 未通過 | `RAW_AF_UNIQUE_REPRESENTATIVE` | 一棵 display representative＋警告 |
| 11 | AF 唯一、CN gate 與 stability gate 均通過 | `AF_CONDITIONAL_SINGLE_CANDIDATE_TREE` | 條件式單一候選；仍非 confirmed cellular tree |

現行結構模型本身允許 recurrence；第 3 列不是否定 structural family，而是因
read-AF 的 ancestry-monotonicity 解釋預設無 recurrence，所以在 AF layer
fail-closed。Canonical 45 units 即屬此類。

若同一 minimum family 同時含 recurrence-compatible 與 incompatible vertex sets，
目前 frozen cohort 實際觀察為 0 units；未來程式仍須明定只排名 compatible subset
或整個 unit abstain，不能默默把兩者混在同一 biological interpretation。

### 5.2 現行 cohort 的結論

目前 allele-specific CN/LOH 尚未整合，AF uncertainty 也未校準。因此：

- 現行 AF-unique rows 最多只能映射為
  `RAW_AF_UNIQUE_REPRESENTATIVE`。
- 不應有任何 row 自動升格為
  `AF_CONDITIONAL_SINGLE_CANDIDATE_TREE`。
- 結構上原本只有一棵的 row 仍可稱
  `EXACT_SINGLE_CANDIDATE_TREE`，但解釋限於 local molecule/mutation-state model。

## 6. 不可用 majority edges 拼出新樹

若多棵候選樹並列，不可把每條出現率最高的 edge 各自抽出後拼接，因為拼出的圖
可能：

- 從未出現在任何合法候選中；
- 讓一個 child 有兩個 parents；
- 違反 Hamming-1 或 model constraints；
- 在一般圖上形成 cycle；
- 混合互相排斥的 vertex sets。

合適做法是：

1. 保留完整 candidate/co-top set。
2. 計算每條 edge 在合法候選集合中的 support。
3. 只把所有候選共有的 edges 畫成 consensus backbone。
4. 選一棵既存候選作 deterministic display representative。
5. 明確標示 representative selection rule，不把它當推論結果。

## 7. 不可把所有 local blocks 拼成一棵全樣本樹

PS×HP blocks 是 local、haplotype-specific evidence units。沒有跨 block read/linkage 時：

- 不可因共享 `ROOT` 就聲稱它們屬於同一 cellular lineage。
- 不可跨 HP 串接；同一細胞的兩個 homolog 不是兩群細胞。
- 不可以不同 blocks 的 AF representative 事後排序後串成全域樹。

若為 dashboard 顯示，可將各 local trees 接到人工 super-root，但必須標：

```text
DISPLAY_SUPERROOT_NOT_PHYLOGENY
```

真正合併只能在同一樣本、同一 HP、存在 bridging reads／共同 anchors、
CN applicability 足夠時，對 union evidence 重新執行完整 solver。

## 9. 下一輪必要驗證

1. **Copy-neutral truth simulation**  
   → 驗證：祖先順序恢復率、tie rate 與 coverage curve。
2. **Equal-generating-distribution simulation**  
   → 驗證：不得將有限樣本微差稱 confirmed direction。
3. **Allele-specific amplification／LOH simulation**  
   → 驗證：CN gate 擋下 biological AF claim，但保留 structural family。
4. **Read bootstrap 或 beta-binomial stability**  
   → 驗證：報告 winner/topology frequency；門檻須預先校準。
5. **Branching sum-rule assessment**  
   → 驗證：互斥 children 的 prevalence constraints 沒有被 pairwise score 掩蓋。
6. **Independent CN annotation**  
   → 驗證：genome build、segment coverage、total/minor CN 與 exclusion regions一致。

## 10. 論文安全措辭

可以寫：

> Among the completely enumerated minimum read-compatible candidates, one
> representative uniquely maximized the unadjusted read-AF monotonicity score.
> Because allele-specific CN/LOH and AF uncertainty were not integrated, this
> result is reported as a model-conditional representative rather than a
> confirmed cellular lineage.

不可以寫：

- VAF 證明某 mutation 較早發生。
- AF 最高者就是 ancestral clone。
- 88.26% 區域已確認真實 topology。
- 不同 HP 代表不同 cell clones。
- 多棵 local trees 已合併成全樣本癌症演化樹。
