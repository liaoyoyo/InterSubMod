# 軟體輸入、輸出與研究流程

用 Input–Transform–Output + Claim Boundary：**LongPhase負責phasing/tagging/recalibration，exact-PS與LongLineage負責局部candidate reconstruction，InterSubMod負責read-level methylation/距離/分群統計，Python/HTML負責呈現；四層互不取代。**

## 1. 全流程

```text
Tumor/Normal BAM + FASTA + caller VCF
              │
              ├─ paired ── LongPhase-S ── phased/recalibrated VCF + HP/PS + tagged BAM/sidecar
              │
              └─ tumor-only ─ LongPhase-TO ─ phased VCF + LOH/HI context + HP/PS + tagged BAM
                                         │
                                         ├──────── exact PS × primary HP read assignments
                                         │               │
                                         │  exact-PS / LongLineage candidate reconstruction
                                         │  ── candidate families / local graph shapes / abstains
                                         │
                                         └──────── InterSubMod
                                                  (tagged BAM + FASTA + candidate/somatic VCF)
                    ── per-region read×CpG matrices
                    ── read–read distances and read dendrograms
                    ── clustering/association/statistics + summary schema
                                         │
                    Python builders → validated JSON/TSV/HTML presentation
```

HTML不得重新計算science；如果HTML中的數字無法回到validated JSON/TSV與artifact ID，就不是可引用結果。

**重要：兩個下游是parallel provenance branches。** 現行supported contract沒有「把LongLineage `topology_units`或`topology.jsonl`直接轉成InterSubMod `--vcf`」的bridge。InterSubMod的VCF必須是caller／LongPhase producer明示且經genome-build/contig/schema驗證的VCF；LongLineage JSON/TSV輸出不得僅因含position欄就冒充VCF。

## 2. LongPhase-S（paired tumor-normal）

外部行為依本機KB `knowledge/05_tools/longphase-s.md`（last verified 2026-07-11）與釘選source/CLI為準。

| 類別 | 內容 |
|---|---|
| 主要輸入 | phased germline SNP VCF、normal BAM、tumor BAM、somatic SNV/indel VCF、reference FASTA |
| 主要transform | somatic haplotagging、tumor DNA fraction estimation、variant recalibration |
| 主要輸出 | read-level `HP:Z:` tags、tagged BAM/CRAM、可選recalibrated somatic VCF（PASS/LowQual）與log |
| 常見HP詞彙 | `. / 1 / 2 / 3 / 4 / 1-1 / 2-1 / 1-2 / 2-2`；實際run可能只出現子集 |
| 安全用途 | paired read phasing/tagging、候選variant recalibration、下游read-level feature input |
| 不可推論 | HP後綴不是cell barcode；單一HP tag不證明clone或演化方向；論文F1結果不可外推成本專案所有sample |

**ISM downstream compatibility（frozen release baseline `ddd8909a`）**：有效 HP 分組只辨識
`1 / 2 / 1-1 / 2-1 / 3` 與 `0 / unphased`；LongPhase-S 可能輸出的 `4 / 1-2 / 2-2`
會落入 `HP_OTHER` 或被 HP 檢定排除，不能暗示九種上游詞彙都能進入 ISM HP tests。
任何 real-data preflight 必須先做 HP value census，並記錄被接受／排除的數量。

概念上應稱`tumor DNA fraction`；CLI的`estimate_purity`／`--tumor-purity`是歷史識別字，不等於已估出cellular purity。

## 3. LongPhase-TO（tumor-only）

外部行為依本機KB `knowledge/05_tools/longphase-to.md`（last verified 2026-07-11）與釘選source/CLI為準。

| 類別 | 內容 |
|---|---|
| 主要輸入 | tumor BAM、input SNP/variant VCF、reference FASTA、caller selection、PON；platform `--ont/--pb` |
| 主要transform | PON/allele-concordance candidate selection、read-linkage phasing、可選LOH detection、HI context |
| 主要輸出 | phased VCF、haplotagged BAM、明示`--loh`時的`LOH.bed`、VCF header內歷史`tumor_purity`識別字 |
| 安全用途 | 無matched normal時的candidate phasing與context產生 |
| 不可推論 | tumor-only結果不等於paired evidence；LOH/HI是model/context，不是cell lineage；本研究舊TO觀察不能外推為工具的一般行為 |

## 4. Exact-PS／LongLineage candidate reconstruction

這一層不是InterSubMod的`tree.nwk`，也不是LongPhase的haplotagging。

### Input contract

- exact non-missing phase set（PS）與primary HP範圍。
- read/molecule對各sSNV ALT/REF的觀察與exact assignment。
- bounded local block與active mutation集合。
- frozen scoring時可使用read-AF；但AF order是assumption-conditional。

### Output contract

- strict read-linked components與bounded local groups。
- minimum candidate families、global-best candidate trees或abstain原因。
- rooted-unlabeled graph-shape signatures與tie/unique分類。
- read assignment/candidate-family receipts；不是cell ID或whole-sample phylogeny。

### 4.1 Branch-specific檔名與schema

| 邏輯artifact／feature輸出 | 格式／schema | 用途 | 能否直接當InterSubMod `--vcf` |
|---|---|---|---|
| `m1_sites` | BGZF TSV；`longlineage.m1_sites` | site-level M1 read linkage record | 否 |
| `topology_units` | BGZF JSONL；`longlineage.topology_unit` 2.0.0 | candidate family/topology unit與abstain/tie狀態 | 否 |
| `<sample>.unit_lineage_paths.tsv.gz`＋receipt | feature-candidate path table | 由candidate edges呈現hierarchical mutation path | 否；feature preview only |
| `<sample>.<chrom>.read_assign.receipt.json`／assignment TSV | feature-candidate read assignment | read對candidate state的assignment | 否；不是variant callset |
| `<sample>.<chrom>.tag_bam.receipt.json`／tagged BAM | feature-candidate BAM writer | 將candidate label寫回BAM auxiliary tags | 否；不會生成InterSubMod region VCF |

能力與branch差異的包內證據：[LongLineage capability matrix](evidence/longlineage_capability_matrix.md)；安全邊界見[public-preview boundary](evidence/longlineage_public_preview_boundary.md)。因production `run`目前應exit 6，這些輸出名稱是contract/capability說明，不是本snapshot授權的production執行配方。

## 5. InterSubMod core

### 必要輸入

| CLI | 語意 | 前置條件 |
|---|---|---|
| `--tumor-bam/-t` | 含MM/ML methylation與可用HP/PS context的long-read BAM | BAM index；tag語意需與producer commit相符 |
| `--reference/-r` | CpG context與region boundary使用的FASTA | `.fai`缺失為hard error |
| `--vcf/-v` | 每筆candidate/somatic record定義分析region | genome build、contig與BAM/FASTA一致 |
| `--output-dir/-o` | 結果根目錄 | full VCF可產生大量region，先plan/容量檢查 |
| `--normal-bam/-n` | optional normal baseline | 只在明示workflow與schema下使用 |

未明示`--distance-metric`的effective CLI default是`NHD`；`Config.hpp`中的BERNOULLI initializer不是有效CLI default。

### 核心transform

1. 依VCF record取得region與跨位點reads。
2. 從MM/ML解析read-level CpG methylation。
3. 建read×CpG矩陣與read–read distance。
4. 以hierarchical clustering/UPGMA產生read dendrogram與cluster labels。
5. 計算PERMANOVA、label/HP association、per-CpG/region statistics與明示schema欄位。

### 主要輸出

| 輸出 | 意義 | 禁止誤讀 |
|---|---|---|
| `metadata.txt`, `reads.tsv`, `cpg_sites.tsv` | region與read/CpG provenance | 不是cohort summary |
| `methylation.csv` | read×CpG methylation matrix | missing值與coverage需按schema處理 |
| `distance/<metric>/...` | read–read methylation distance | distance不是lineage distance |
| `clustering/tree.nwk` | 以read為leaf的hierarchical dendrogram | **不是clone tree、cell phylogeny或ancestry** |
| clustering/significance artifacts | read clustering與label association統計 | association不是independent clone confirmation |
| `significance_summary.csv` | 跨region summary | 本baseline現行contract為199欄；一律按header/schema讀，不用固定欄號 |
| `run_summary.json` | run-level execution summary | 不是science authority，除非另被authority registry採納 |

199欄contract的兩個重要anchor：第187欄（1-based）`VerificationSchemaVersion`、第196欄`RegionStratificationSchemaVersion`。最終驗收以synthetic runtime output讀header，不只做source parsing。

## 6.1 可複製的current-supported bridge範例

下列範例只串接已support的LongPhase/caller→InterSubMod branch；LongLineage reconstruction另有自己的artifact/receipt，不插入`--vcf`位置。

```bash
# 這三個路徑必須來自同一site profile與producer receipt；不可從目錄名稱猜。
UPSTREAM_TAGGED_BAM=/absolute/producer/output/sample.tagged.bam
UPSTREAM_SOMATIC_VCF=/absolute/producer/output/sample.recalibrated-or-phased.vcf.gz
REFERENCE_FASTA=/absolute/reference/GRCh38.fa
ISM_OUTPUT=/absolute/new/output/intersubmod

samtools quickcheck -v "$UPSTREAM_TAGGED_BAM"
test -f "$UPSTREAM_TAGGED_BAM.bai"
test -f "$UPSTREAM_SOMATIC_VCF.tbi"
test -f "$REFERENCE_FASTA.fai"

build/bin/inter_sub_mod \
  --tumor-bam "$UPSTREAM_TAGGED_BAM" \
  --reference "$REFERENCE_FASTA" \
  --vcf "$UPSTREAM_SOMATIC_VCF" \
  --output-dir "$ISM_OUTPUT" \
  --distance-metric NHD
```

→ 驗證：command receipt記錄LongPhase/caller commit與CLI、BAM/VCF/FASTA/index SHA、genome build與contigs；InterSubMod exit 0；`significance_summary.csv`按header/schema解析為199欄；`tree.nwk`只標為read dendrogram。

LongLineage preview的 immutable candidate `b9aaa12` frozen baseline是47/47 tests；後續private safety stack `f60b5f3`才是49/49 foundation PASS。下列命令用來驗目前checkout的工程 foundation與strict gate，不能把49歸給`b9aaa12`：

```bash
cmake -S . -B build-verify-debug -DCMAKE_BUILD_TYPE=Debug
cmake --build build-verify-debug -j2
scripts/ci/check_all.sh build-verify-debug
scripts/ci/check_public_preview_gate.sh HEAD  # 現況預期安全exit 1
build-verify-debug/bin/longlineage run --manifest <MANIFEST> --repo "$PWD"
# 現況production run預期 KernelBlocked / exit 6；不可改寫為可用production pipeline。
```

上述foundation結果的包內receipt是[longlineage clean foundation receipt](evidence/longlineage_clean_foundation_receipt.json)。

## 8. 驗證每一層

1. Upstream：record exact binary/source commit、CLI、input hashes、HP/PS/tag schema。
2. Reconstruction：驗component/group/family denominators、abstain與tie，不只看winner。
3. InterSubMod：clean build/test、tiny synthetic I/O/schema、real-data read-only preflight。
4. Presentation：HTML數字回指artifact/claim ID，0 external request，desktop/mobile/no-JS/print/XML/SVG QA。
5. Publication：main/Wiki/Pages/About/Release manifest綁同一commit與hash。
