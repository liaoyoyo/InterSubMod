# 交接分冊 03：輸出層

## 0. 一句話

這個專案的輸出**不是「跑完就有一堆檔案」**，而是**每個正式產出都被三層 receipt 綁定**
（build → QA → release），且每個數字都能回指到一個有 SHA-256 的 artifact。
接手者要學會的核心技能是：**看到一個數字，能在 30 秒內說出它的 authority 是誰**。

## 3. Receipt 體系（本專案的品質核心）

每個正式產出都會生出一組互綁的 receipt：

```text
authority readiness  →  report_data.json  →  standalone HTML  →  QA  →  release_receipt.json
     (輸入驗證)            (資料層)            (呈現層)        (視覺)      (最終有效標記)
```

以最新的 2026-08-01 release 為例，實際輸出的狀態欄位：

```json
{
  "all_pass": true,
  "statuses": {
    "data_technical_status":        "FROZEN_TECHNICAL_RESULTS_WITH_EXPLICIT_ABSTAIN",
    "scientific_completeness_status":"INCOMPLETE_WITH_ABSTAIN",
    "report_build_status":          "PASS",
    "browser_qa_status":            "PASS",
    "release_status":               "VALIDATED_DERIVED_OBSERVATION"
  }
}
```

> **這裡有個關鍵觀念**：`report_build_status=PASS` 與 `scientific_completeness_status=INCOMPLETE_WITH_ABSTAIN`
> **同時成立且不矛盾** —— 前者說「這份報告技術上正確地呈現了資料」，後者說「資料本身有 10,717 個 abstain 未解」。
> 交接時務必讓接手者理解這個區分，否則會把 technical PASS 誤讀成科學完成。

### 三個不可混淆的狀態

| 狀態 | 意思 | 不代表 |
|---|---|---|
| `technical_all_pass=true` | 命令、schema、hash、守恆檢查通過 | **不代表** 可作為 biological validation evidence |
| `VALIDATED_DERIVED_OBSERVATION` | 這是從 authority 正確衍生的觀察視圖 | **不代表** 建立了新的科學結論 |
| `INCOMPLETE_WITH_ABSTAIN` | 有明確標記的未解部分 | **不是** 資料遺漏或 bug |

## 5. ISM 單一區域的輸出長相

C++ 主程式對每個 region 產出：

```text
<output-dir>/<vcf_class>/<chrom>/<region>/
├── metadata.txt                    區域基本資訊與統計
├── reads.tsv                       read 明細（含 alt_support、HP tag）
├── methylation.csv                 甲基化矩陣（Read × CpG）
├── distance_matrix_<METRIC>.csv    Read-Read 距離矩陣
├── significance_summary.csv        顯著性彙總
└── *.png                           視覺化圖表
```

根層另有：

```text
<output-dir>/
├── full_execution_analysis.log
├── significance_summary.csv        各區域彙總
└── significance_statistics.txt     全域統計
```

> ⚠ region 子目錄數量**超過一萬**，這是為什麼 repo 有 hook 阻擋對 output 的遞迴掃描。
> 要統計時用 `ls -d .../*/ | wc -l`，不要 `du -sh` 或 `find .`。

## 6. 分母登錄（避免百分比誤讀）

同一個「比例」在不同層意義完全不同，因此有專門的分母登錄表：

```text
InterSubMod/docs/handoff/20260801_exactPS_readAF_CNV_AI交接_01/denominator_registry.tsv
（19 個 metric × numerator / denominator / excluded / authority）
```

**規則**：回答任何百分比之前，先從這張表指出 numerator、denominator、excluded/unknown 與 authority。
說不出來就不要報那個百分比。
