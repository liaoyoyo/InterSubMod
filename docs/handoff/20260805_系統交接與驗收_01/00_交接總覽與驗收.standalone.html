六、輸出層：technical PASS 不等於科學完成

這是驗收時最容易誤讀的一組狀態。最新 release 同時具有這兩個欄位，而且不矛盾：

"report_build_status":           "PASS"                              ← 報告技術上正確呈現了資料
"scientific_completeness_status":"INCOMPLETE_WITH_ABSTAIN"           ← 資料本身有 10,717 個 abstain 未解
"release_status":                "VALIDATED_DERIVED_OBSERVATION"
狀態意思不代表
technical_all_pass=true命令、schema、hash、守恆檢查通過✗ 不代表可作為 biological validation evidence
VALIDATED_DERIVED_OBSERVATION從 authority 正確衍生的觀察視圖✗ 不代表建立了新的科學結論
INCOMPLETE_WITH_ABSTAIN有明確標記的未解部分✗ 不是資料遺漏，也不是 bug

每個正式產出都被三層 receipt 綁定：build receipt → QA receipt → release receipt， 三者以 SHA-256 互綁。詳見 InterSubMod/docs/handoff/20260805_系統交接與驗收_01/03_輸出層.md。

八、交接時不可省略的五件事

1 frozen binary 要一起交 最易遺失

產生論文核心數字（71,955 ranked units、拓撲 census）的 binary 不在 repo 內，也不在 /big7_disk：

路徑   : /bip7_disk/liaoyoyo2001/build-exact-af-20260724/bin/exact_ps_topology_af
SHA-256: ba13ccf23d091854c191f81dd97fa891368d11179df9a69e915f0340b7233b2e
狀態   : 與當前 dirty 源碼 = not_proven_byte_reproducible

本輪已驗證它與 5 個源碼快照的雜湊全部一致。搬遷、清理或換機時極易遺失，務必連同 SHA-256 一起交付。

2 claim ceiling 要一起交

接手者必須知道：confirmed cellular subclone = 0、linear ancestry = 0、 CN/LOH 為 NOT_INTEGRATED、甲基為 association-only。 L7 生物層必須 abstain。詳見 parent handoff。

3 分母登錄要一起交

沒有 denominator_registry.tsv（19 個 metric × numerator/denominator/excluded/authority）， 任何百分比都會被誤讀。回答任何百分比前，必須能指出它在這張表的哪一列。

4 不可重踩的八個舊方向要一起交

例如：不可用舊 50 kb adjacency 取代 strict read linkage、不可混合不同 PS 或跨 HP 建樹、 不可把 HCC1395 與 HCC1395_DORADO 當兩個生物重複、不可用甲基差異重排 topology。 完整八條見 parent handoff §9。

5 論文狀態要說清楚

7/12 骨架、內容過期，不可直接送審。章節骨架可保留， 但 Methods / Results / NO-GO 狀態必須依 P0-4 的 frozen evidence 重寫。

九、給驗收者的三個提問

如果只有 10 分鐘驗收，問這三題最有鑑別力 —— 它們直接測試對方有沒有理解 claim boundary。

提問正確回答答錯代表
「這個百分比的分母是哪一層？」 能立刻指出 denominator_registry.tsv 的那一列，說出 numerator / denominator / excluded 會在論文中混用不同層的比例
「10,717 個 abstain 是資料遺漏還是正式輸出？」 ✓ 正式輸出（search-node guard 觸發），且為非隨機缺失，不可與 ranked subset 互相外推 沒理解 abstain 的設計意圖
「這棵樹是生物學上的 clone 譜系嗎？」 ✓ 不是。只能說 model-conditional 的 read-compatible candidate states 與其 graph geometry；L7 abstain overclaim — 這是本專案最嚴重的錯誤類型
