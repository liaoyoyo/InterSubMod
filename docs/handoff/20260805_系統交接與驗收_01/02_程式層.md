## 4. 怎麼跑

### 標準全流程

```bash
./scripts/run_vcf_all_snv.sh --mode all-with-w5000
```

### 快速驗證（chr19，< 30 秒）

```bash
./scripts/run_vcf_all_snv.sh --mode chr19-verification
```

### 直接呼叫 C++ 核心

```bash
./build/bin/inter_sub_mod \
    --tumor-bam <tumor.bam> \
    --reference <ref.fa> \
    --vcf <somatic.vcf> \
    --output-dir <results> \
    --threads 32 \
    --window-size 1000 \
    --log-level debug
```

> 手動執行只產數據檔（TSV/CSV），**不會**自動生成熱圖；圖表需接續跑 `tools/` 下的 Python 腳本。

### ⚠ 長 compute 的紀律

- **不要**把產數字的長計算包進 workflow / subagent 的黑箱步驟 —— 中斷會半完成且無法驗證。
- 標準做法：主流程背景跑 → 落 `.json/.tsv` → **讀回確認非 error** → 才寫報告。
- ≥3 樣本的實跑要先做資源 preflight（N 個 30-45 min 的 BAM 平行會撞 CPU/mem，預設改循序）。
