## 線 1 — ISM 方法本體與作用位置（核心）`ism-core`

### narrative_logic（邏輯）
- **為何做**：ONT 長讀讓人第一次能在單 read 上同時看甲基修飾（MM/ML）和 haplotype（HP tag）。傳統 per-position 聚合工具（modkit/pycoMeth）或 germline-only ASM 工具（NanoMethPhase）都不處理癌症 somatic sub-haplotype 維度，也沒有去 copy confound 機制。
- **發現什麼**（三點）：
  - ⭐ 全基因組 strong-ASM 極稀少（0.34%，hypo 44%/hyper 56% 無方向偏好）→ 稀有率直接限制任何應用方向的統計功效。
  - ⭐ 甲基分群是 **germline-haplotype 層級**：可靠分 HP1 vs HP2，但同 haplotype 內 somatic 亞群信號弱（T3 AUC 0.65 < null 0.71）——是方法層級限制，非 bug。
  - 🔴 **最重要 NEGATIVE**：甲基當 TP/FP filter 被四道判死（LOSO 100% 循環 / AUC=0.505 / strong-ASM 在 FP 富集 5× OR=0.194 p=1.8e-28 / LOSO held-out mean −0.00004 p=0.125 反向）。
- **結論**：ISM 正當定位＝去 confound 的 **characterization 工具**，非 discovery/filter。可回答 3 問：①allelic 甲基差是真 cis 還是 copy/drift（normal-anchored cis-test）②某位點 reads 是否可靠分亞群且與 HP/somatic 對齊（PERMANOVA + Cramér's V gate）③哪些位點統計可靠 vs 稀疏表 artifact（Cochran gate 識別 487 latent）。誠實限制：normal-anchored cis-test 只在有 matched normal 的樣本完整（目前僅 HCC1395）；依賴單一 pipeline 上限 ⭐3；原創在 sub-haplotype 解析度 + normal-anchoring 組合。

### method_role（作用位置）⭐
- **坐落**：上游 ONT 工具（Dorado base/methyl calling → MM/ML；longphase-TO phasing → HP tag）與 下游 Python 後處理（Δβ、normal-anchored cis-test、copy-partition 分解）之間，是核心 C++ binary。
- **輸入**：① Tumor BAM（含 MM/ML + HP tag 如 1/2/11/21/33）② Normal BAM（可選）③ Reference FASTA（hg38）④ Somatic SNV VCF（ClairS-TO）。
- **輸出**：每 SNV ±1000bp 視窗一資料夾含 summary.csv（117 欄/位點）；`significance_summary.csv`（全位點滙總）；距離矩陣 CSV / 樹 / 甲基矩陣（可選）。
- **5 階段流程**（對應 SVG fig1 + 源碼模組）：
  1. ① 輸入 + Read 擷取：BamReader（MAPQ≥20、read len≥1000）；ReadParser 過濾；HP tag 分群（HP1/HP2/HP1-1/HP2-1/HP3/HP0）。
  2. ② 甲基矩陣：MethylationParser 解 MM（C+m? delta-encoded）+ ML（/255=機率），CIGAR→ref 定位 CpG；MatrixBuilder 建 reads×CpG；二值化（>0.8 甲基 / <0.2 未甲基 / 中間 ambiguous）。
  3. ③ read-to-read 距離：每對 read 算甲基 pattern NHD（預設）；需共同覆蓋 ≥5 CpG（C_min=5，`DistanceMatrix.hpp:27-28`）；不足記 MAX_DIST=1.0；產生 N×N。
  4. ④ UPGMA 階層聚類：TreeCutter 用 silhouette 在 k=2..10 自動選群數。
  5. ⑤ 顯著性套件→輸出：GlobalTest（Fisher + Cramér's V + reliability gate）、StructureTest（PERMANOVA pseudo-F）、LabelTest（HP-merged / HP-fine 4-group / ALLELE 三層 label-first）、PerCpgAsm（逐 CpG Fisher+BH-FDR / NME / epipolymorphism）→ summary.csv。
- **上游關係**：需 Dorado 的 MM/ML + longphase-S 的 HP tag（含 somatic HP1-1）；無 HP1-1 就無法做 somatic-controlled HP-axis。
- **下游關係**：Δβ、normal-anchored cis-test（三路 normal-HP1/tumor-HP1/tumor-HP1-1）、copy-partition 分解均在 Python 層（tsg scripts/03、34、37），不在 C++ binary 內。
- **並行化**：每 SNV 位點 OpenMP 獨立並行（RegionProcessor.process_all_regions，每 thread 各有 BamReader/FastaReader）。

### high_cog_load（高認知負荷 — 做 HTML 必配例子/SVG）
- 【需例子/SVG】**Δ（距離差）vs Δβ（甲基率差）是完全不同的量** ⭐：Δ 是 read-read 距離空間 d_between−d_within（無方向、單位 NHD）；Δβ 是每 CpG 甲基比例差（有方向、單位 0-1 rate）。混淆會把「結構有無」和「方向」混為一談。例：HP-axis Δ=0.15 vs 同位點 Δβ=−0.122。SVG：左格 N×N 距離熱圖、右格 per-CpG β 條形圖，箭頭標各算哪個空間。
- 【需例子/SVG】**為何做 read-read 距離而非比 per-CpG 平均**：per-CpG 平均丟失共甲基化結構。SVG：4 reads × 5 CpG 矩陣，同 HP 共甲基化、異 HP 相反；per-CpG 平均看起來差不多，距離矩陣才看出亞群。
- 🔴【需例子/SVG】**HP1-1 是 somatic sub-haplotype 不是第三條染色體**：HP tag=11 易誤解為第三單倍型，實為「同 HP1 germline 染色體上帶 somatic ALT 的 reads」。類比：父親那條染色體後天突變，longphase-S 標 HP1-1。HP-axis 比 HP1（無突變）vs HP1-1（有突變），hold constant 染色體身份故 copy 數非混淆。
- 【需例子/SVG】**normal-anchored cis-test 三路比較邏輯**：d_somatic/d_cis/d_drift 互相依存，判準 \|d_cis\|>1.8×\|d_drift\|+0.02 需同看兩量。SVG：三盒（normal-HP1/tumor-HP1/tumor-HP1-1）+ 三箭頭。BRCA2：d_cis 小 d_copy 大→copy 主導；chr17/TBC1D16：d_within=0.142 perm p=0.001→真 cis。
- 【需例子/SVG】**Cramér's V reliability gate 與「487 latent 位點」**：核心是 Cochran 最小期望格≥5 的 reliable 旗標。CramérV=0 但 PERMANOVA 顯著＝稀疏表 reliable=false→真分群被 gating 閘住，不是矛盾。SVG：稀疏表（CramérV 不可靠）vs 密集表（可信）；`GlobalTest.cpp:128-141`。

## 線 2 — ISM 方法演進：當時做法 vs 新做法 `ism-evolution`

### narrative_logic
- **為何做**：ISM 從 haplotagged BAM → read-read 距離 → UPGMA → PERMANOVA 偵測 somatic 附近的等位甲基化結構差異（ASM）。競品問「率差多少」，ISM 問「read 是否分成有標籤差異的兩群」——文獻未佔的位置。但 2026-06-10 全碼稽核（12-reviewer，105 findings）發現系統性問題。
- **發現什麼**（系統性問題 + 兩個認知修正）：
  - 🔴 per-CpG Fisher（`PerCpgAsm.cpp:274-313`）把同 haplotype/clone 長讀當獨立 Bernoulli，忽略 over-dispersion。
  - 🔴 C++ 甲基解析（MethylationParser.cpp）只走 C+m?＝5mC-only，5hmC 完全不計。
  - 🔴 Δβ 預設軸把 1-1 折入 HP1-family 的 germline/ALLELE 軸，非 somatic-controlled，本就被 baseline allelic methylation confound。
  - 🔴 跨 region / genome-wide 完全沒有多重檢定校正，global_p 取 3 個 p 最小值未做 Sidak/Bonferroni。
  - ◽ 修正：引用「De Waele 2020」已改 Orjuela 2020（891e04b）；expected_coverage hardcoded 75 其實 Pass 2 已由 KDE 覆寫（已 wired）；CramersV gate 用 Cochran expected≥5 是標準實務。
- **結論**：**沒有翻轉已 concluded 方向結論的錯誤**（filter-DEAD / phasing B+ 站得住），但三個必修：T1 補 MM/ML golden test、T2 補 fill_report.py null refuse、T3 釐清/改 Fisher anti-conservative。外部建議：學 DSS beta-binomial+shrinkage / cvlr-pycoMeth soft 機率距離 / modkit 分軌 5mC/5hmC / DAMEfinder CpG-pair tuple log-odds。最具差異化新穎＝PERMANOVA-on-read-read-distance 的有監督結構檢定 + normal-anchored somatic cis-control。

### method_role（pipeline 位置）⭐
- 輸入 = haplotagged BAM（longphase-TO/MSA 加 HP:Z: tag）+ VCF（somatic SNV 候選）+ FASTA。

### narrative_logic
- **為何做**：論文定位/投稿防守需說清 ISM 與 modkit dmr / DSS / methylKit 的本質不同，以及有沒有人在做同樣的事。Phase A 用 24-agent workflow（wf_9e64e51d-03d）對 82 工具全程 WebFetch 一手查證（2.3M token），再 7-agent workflow（wf_22ba1b9b-db4）補 4 軸地景 + 共同難點。
- **發現什麼**：業界甲基方法 MECE 分 6 軸——A=per-position 率差（主流，modkit dmr/DSS/methylKit）、B=within-read CpG-CpG LD（MHB/MHL/Metheor）、C=between-read 距離+clustering（**ISM 主場**）、D=cohort 跨樣本網路、E=disorder/WSH scalar、F=長讀 phasing/ASM。軸 C 內最像 ISM 的＝cvlr（Bernoulli-mixture EM，無距離矩陣/無顯著性）、ASMS（Raineri 2024，最像但 ⚠UNVERIFIED preprint）、qFDRP（同 normalized-Hamming kernel 但塌成 per-CpG scalar 丟幾何）。⭐ 沒有任何工具同時具備 ISM 五項組合：顯式 N×N 距離矩陣 + UPGMA+silhouette + PERMANOVA pseudo-F 結構顯著性 + normal-anchored somatic cis-test + LOH/CN 耦合。且核心問題（甲基能否判別 TP vs FP）誠實 NEGATIVE。
- **結論**：可防守新穎＝這個特定組合 +「結構非失序」supervised PERMANOVA + somatic cis 控制，非任何單一步驟；但 ISM 在 per-site 統計（無 beta-binomial）、spatial region-FDR、phasing-free 模式、CN/purity deconvolution 上弱於業界，且「組合無人佔 ≠ 更好/有用」，需 Phase B head-to-head 驗證。源碼引用 bug：PerCpgAsm.cpp:6「De Waele 2020」錯→Orjuela et al. 2020。

- 【需例子/SVG】**normal-anchored cis-test（d_cis vs d_drift）**：d_cis = tumor HP1 vs HP1-1（同 germline haplotype 上 somatic 差距）；d_drift = matched normal HP1 vs tumor HP1（germline baseline）。三角圖：normal-HP1/tumor-HP1/tumor-HP1-1 連線。d_cis>>d_drift＝somatic cis；相近＝drift。例 BRCA2 Δβ=−0.122。
- 【需例子/SVG】**modkit dmr 沒有 --haplotype 模式**：做法是先 pileup --phased 拆 hp1/hp2 bedMethyl 再餵 dmr pair 當「兩個樣本」＝把 haplotype 當靜態樣本，失去分子連結。左右流程圖：左 modkit（modBAM→pileup --phased→兩 bedMethyl→dmr pair）vs 右 ISM（modBAM+HP tag→read×CpG→距離矩陣→PERMANOVA）。

### narrative_logic

## 線 10 — 背景知識 + 名詞表 + 樣本/pipeline `background-glossary`

### narrative_logic
- **為何做**：整個研究核心詞彙（haplotype、HP-tag、ASM、cis、Δβ、LOH、cnLOH）對有實驗室背景但非長讀計算基因體背景的讀者，字面意思與技術定義差距大，且在本專案有專屬操作定義——必須先建名詞表才能讓任何研究線結論被正確理解。
- **發現什麼**：ISM 是分析 ONT 長讀腫瘤的 C++17 工具，整合甲基（BAM MM/ML→5mCG/5hmCG）+ somatic 突變（ClairS/ClairS-TO）+ 單倍體型（LongPhase-S/-TO）；核心輸出＝每 somatic SNV 區域（±5kb）read-level 甲基距離矩陣 + significance_summary.csv（59 欄）。7 樣本（含 1 basecall 變體），3 癌種（乳腺 HCC1395/1937/1954、黑色素瘤 COLO829、肺 H1437/H2009）。主 benchmark＝HCC1395（SEQC2 truth 39,447 somatic SNV）。三 pipeline：paired_full（canonical，ΔF1=+0.0112）、paired_pileup、tumor_only（TO，ΔF1=−0.0206 NEGATIVE）。三條不可直接比較 F1。

### high_cog_load
- 🔴【需例子/SVG】**Haplotype / HP-tag 與 somatic subclone tag 混淆**：HP:i:1/2 是 germline 兩染色體版本；TO 還輸出 HP:i:11（HP1+somatic）/21/33。BRCA2 HP1-1 在 LongPhase-S＝「germline HP1 haplotype 上帶 somatic ALT 的讀」（`HaplotagStrategy.cpp:505-516`）。SVG：兩染色體（HP1 藍/HP2 橘），HP1 上標 somatic ALT 分裂 HP1-1；HP:i 對應表（1/2/11/21/33）。
- 🔴【需例子/SVG】**cis vs trans 與 normal-anchored cis-test 為何必要**：copy number 變化讓某 haplotype copy 增多→表觀「等位差異」實為 dosage confound。normal-anchored cis-test 用 normal HP1 vs tumor HP1-1（copy number 相同）排除 dosage。三欄圖：normal HP1（基準）/tumor HP1-1（帶突變）/tumor HP2；箭頭標 d_within（cis 候選）和 d_copy。caveat：BRCA2 d_within=−0.023 vs d_copy=−0.11（copy 主導）。Martin-Trujillo CN 解釋 82-92%。
- 【需例子/SVG】**LOH 與 cnLOH 區別及對 phasing 影響**：LOH＝只剩一等位（可 CN loss CN=1 或 cnLOH CN=2 兩份同等位）。LOH 區 germline het SNP 消失→LongPhase-S 無 anchor＝methyl-assisted phasing 白地。染色體圖：正常 diploid（HP1/HP2 + SNP）vs LOH（只剩藍一條，SNP 消失）vs cnLOH（兩條都藍）。LOH 區 NG=2 inner 93-99% 依賴 ISM 輔助。
- 🔴【需例子/對照表】**Δβ 分母口徑差——Do2020「+5×」vs 本專案「稀有 0.34%」為何不矛盾**：Do2020 是跨個體 SNP-anchored bisulfite 族群 ASM DMR 比率；本專案是 within-sample somatic-controlled ONT read-level。分母完全不同非真矛盾。兩列對照表：左 Do2020（族群 SNP-anchored bisulfite，測跨人多態性），右 ISM（within-sample somatic-controlled read-level HP-axis 顯著率）；底部「就像比全班身高標準差 vs 某人兩手長度差，都是差異但參照系不同」。
- 【需例子/直方圖】**TO self-phasing bias：為何 94.6% reads 偏 HP1**：LongPhase-TO 無 Normal BAM 只用 tumor 自身 somatic SNV 推 haplotype；帶 Alt 的 reads 被 tag 成「有突變的 haplotype」（工具內設為 HP1 衍生）→大量偏 HP1/HP1-1。直方圖：x=HP tag 類型，y=reads 比例；左 paired_full 近均勻 HP1/HP2，右 TO 94.6% HP1-family 極端偏態。
