為什麼能用「點突變 + 甲基」
推出 clone / subclone，並給每條 read 正確的標記？

以 HCC1395 在 chr2:18,066,481–18,110,828（6 個 sSNV 跨 18,068,480–18,108,828）的一段 LOH 區為例，逐步拆開這條推理鏈。本頁不講背景、直接走邏輯：為什麼 LOH 讓訊號變乾淨 → 為什麼點突變能切出互斥譜系 → 為什麼甲基能獨立印證同一個切分 → 為什麼要用正常組織對照濾掉假訊號 → 最後怎麼給每條 read 正確的 tag。每一步都標清楚哪些是觀測、哪些是推論。

L0 一條邏輯鏈看懂

LOH＝無塵室→ 點突變(sSNV)＝譜系條碼→ 甲基＝獨立印證的指紋→ 扣 normal 濾假→ 每條 read 標 tag（α / α-1 / β）

關鍵前提是 LOH（雜合性缺失）：這段 DNA 只剩單一條親本染色體。於是同一條染色體上 read 之間的差異，不可能是「兩條親本本來就不同」造成的 → 一定是腫瘤後天累積的 somatic 變化。點突變把 read 切成互斥的譜系（α / β），而甲基化模式沿著同樣的譜系一起變 — 這是一條與點突變不同來源的正交軸，互相印證了同一個 subclone 切分（其「獨立性」僅限正常組織無等位差異的乾淨 CpG，見 §⑤）。

▸ 給教授一句話：在這個 LOH 區裡，「LOH → somatic 點突變定義的 α/β 兩譜系 → 甲基沿譜系變化」這條骨幹在實際資料中獲證、且跨 basecaller 複製（basecaller = 把測序電訊號翻成 ATCG 的軟體；HKU 與 DORADO 是兩套不同軟體跑同一批 read → 屬技術重現、非獨立病人）。但這是一個有界的結論（tier L2，單位點 × 單樣本 × 單 pipeline）：真實譜系是 ~3 條不是「5 群」、突變先後順序是推論不是觀測、乾淨的甲基訊號只限於正常組織沒有等位差異的 CpG 子集。

⓪ 先回答最關鍵的問題：為什麼非得「偵測甲基」不可？

如果只看點突變就能重建 subclone，何必費力去讀甲基？因為點突變這條軸太稀疏、太脆弱，單靠它常常標不準。甲基提供了三件點突變做不到的事 —— 但也有一條必須誠實守住的邊界。

甲基的三個不可替代價值
  1. 正交印證：點突變在這 40 kb 只有 6 個、覆蓋又低，很多 read 跨不過任何一個資訊位點。甲基是密集的第二條軸（這裡 10 個 CpG），在基因條碼模糊處仍能印證同一個譜系切分 —— 兩條獨立證據指向同一個分群，可信度遠高於單軸。
  2. 救援標記（方法定位，本案例尚未逐 read 量化）：純靠點突變無法定相（phase）的 read，原理上可用甲基指紋補回它屬於哪條譜系 → 給出更完整的 tag。本案例已實證的是「正交印證」（FDR 通過）；逐 read 救援是設計理據、待量化。
  3. 刻畫功能：甲基告訴你這個 subclone「關掉了哪些基因」= 生物學行為，而不只是身分標籤。點突變只說「它不一樣」，甲基說「它哪裡不一樣、可能造成什麼」。
● 但守住這條邊界（本頁全程不越線）
  1. 這裡甲基是印證 / 刻畫（characterization）軸，不是驅動者、更不是變異 filter。「用甲基當 filter 去濾真假突變」那條路在本專案已驗證為 DEAD。
  2. 乾淨案例依賴三個前提：① LOH（單一親本）② somatic 定義的譜系 ③ 用正常組織對照扣掉既存的等位甲基差異。缺一就不能外推到一般非-LOH 位點。

① 為什麼「長 read」是關鍵：同一條分子上同時讀到兩種記號

整條推理之所以成立，物理基礎是：一條 ONT long read = 一個 DNA 分子 = 一顆腫瘤細胞的單條染色體。在這同一條分子上，我們同時讀到兩種記號 —— 改變字母的點突變（基因條碼）與不改字母、只改化學標記的甲基化（表觀指紋）。短 read 跨不過這 40 kb，無法把多個記號綁在同一條分子上，這條推理就斷了。

點突變 vs 甲基化一個改字母、一個改化學標記，兩者都會遺傳給後代
直覺：點突變（sSNV）是 DNA 字母被改寫（如 C→G），一旦發生，這個細胞的所有後代都帶著 → 是穩定的「譜系條碼」。甲基化（5mC）是在 C 上掛一個化學標記，不改字母但會改變基因開關；它也會在細胞分裂時被複製繼承，但比點突變更可塑 → 是「譜系指紋」。兩者都沿著細胞家族遺傳，所以都能用來追譜系，但性質互補。

② 為什麼這個位點特別乾淨：LOH 是一間「無塵室」

一般位點每個人有兩條親本染色體（HP1 + HP2），它們本來就可能不同（germline 差異）。所以兩條 read 不一樣，未必是腫瘤造成的 —— 這是個 confound。LOH 把其中一條整段刪掉，只剩單一親本。於是任何 read 間差異都必然是後天的，subclone 訊號就浮出來了。

這一步成立 · L2LOH 獲證（HP1 1.7% 殘餘 + 單一 PS），且落在 SEQC2 獨立標註的 LOH 區內 → 這是後面所有推理的乾淨前提。

③ 為什麼點突變能切出 subclone：互斥 → 姊妹分支

承 §②：因為是 LOH 單一親本，read 上的字母差異不可能是「兩親本本來不同」，只能是後天 somatic → 於是一條 read 帶哪組突變，就等於它的譜系標籤（而非定序錯誤）。把每條 read 在 6 個點突變的字母排出來，會看到兩種互斥的模式：α（只有 pos3 突變成 A）與 β（pos1/2/6 突變、pos3 還是參考）。關鍵在於 沒有任何一條 read 同時帶兩組突變（0 違反）→ 用最簡原則（parsimony）只能解釋成它們是從共同祖先分出去的姊妹分支。⚠ 下面會看到：β 本身又分相距 ~40 kb 的左塊 (1)(2) 與右塊 (4)(6)，兩塊之間沒有跨距 read，屬「甲基橋接的推論」而非直接的點突變 linkage —— 本頁嚴格區分這兩者。

這一步成立（分清觀測 vs 推論）· L2觀測：點突變條碼把 read 切成與 α 互斥的 β 程式（pos3：0 違反，跨 basecaller 複製），pos5 再切出 α-1（provisional，直接支持 HKU 4 / DORADO 2 條）。推論（L3）：β 的左塊 (1)(2) 與右塊 (4)(6) 之間沒有跨距 read，它們同屬 β 是靠「互斥 + 甲基一致性」的推論，不是直接的點突變 linkage。這就是「從點突變找到 subclone」的機制 —— 但它只給「身分」，還沒給功能、也標不到所有 read（下一步交給甲基）。

④ 為什麼甲基能「印證」這個切分：第二條獨立的軸

現在把甲基疊上去。對每個 CpG，比較 α 的 read 與 β 的 read 的平均甲基率。如果甲基只是隨機噪音，兩群不該有系統差異。但實際上多個 CpG 在 α / β 之間乾淨地分開、且方向一致 —— 帶 α 條碼的同一批分子也帶 α 的甲基長相。這是一條與點突變不同來源的正交證據軸，印證了同一個 subclone 切分；最強的 3.1 / 3.2 連換一個 basecaller（DORADO）都複製。（注意：此「不同來源」僅對正常組織無等位差異的乾淨 CpG 成立；§⑤ 會看到 4 個 CpG 的甲基其實與 haplotype 綁定、並非獨立。）

這一步成立但有界 · L2甲基沿 α / β 方向一致地分開 = lineage coherence（譜系一致性），印證了 §③ 的切分；但這不證明甲基能獨立定義 clone。而且這些 α/β 差異裡，有一部分其實是「正常組織本來就有的等位差異」假冒的 —— 必須先用正常組織對照濾掉（見 §⑤），乾淨子集才算數。

⑤ 為什麼要再用正常組織對照：濾掉「假的」甲基訊號

這一步是誠實的關鍵。不是所有 α / β 甲基差異都是 subclone 後天造成的。有些 CpG 在正常組織本來就有「等位特異甲基（germline ASM）」—— 兩條親本的甲基本來就不同。這種差異即使沒有腫瘤也會出現，會冒充成 subclone 訊號。所以拿配對的正常組織（matched-normal）的 HP1 vs HP2 當對照：normal 本來就有差異的 CpG → 標記為 confounded（不能採信）；normal 平的、只有腫瘤裡才分開的 → 才是乾淨的後天訊號。

誠實校正 · L2乾淨的 subclone-甲基訊號真實存在，但只限正常組織沒有等位差異的 CpG 子集（最強 3.1/3.2）。這也說明為什麼非有正常組織對照不可 —— 少了它，會把 4 個 germline-ASM 的 CpG 誤當成 subclone 訊號。

⑥ 怎麼給每條 read「正確的 tag」：三層證據疊加

把前面所有訊號合起來，就能給每條 read 一個正確的標記。標記是三層疊加：① 它在哪條染色體（haplotag HP）→ ② 它帶哪組點突變（α / β）→ ③ 有沒有子分支突變（pos5 → α-1）。甲基指紋在每一步提升信心、並補上點突變標不到的 read。

● 標 tag 時必守的三條誠實底線（對抗式複核抓出的過度宣稱已撤回）
  1. 是「~3 條譜系」不是「5 群」。pos4(chr2:18,096,269) 後面緊接一段 20bp poly-T 同聚物（ONT 最易出錯的情境），它的 G/T/DEL 三態是定序抖動（HKU bq20 計數 C:21 / T:13 / DEL:10 / G:4，且 4 條 G 全是 reverse strand），不是三個真 subclone。pos4 變異本身真，但三態不可拆成三群 → 併成一個 pos4-altered 的 β 子狀態。
  2. 突變的「先後順序」是 parsimony 推論，不是觀測。α / β 是姊妹分支，不能用局部 VAF 排誰先誰後（局部 VAF 被 LOH 扭曲）；(4)(6) 共現也無法排序。任何「先突變/後突變」的句子都屬推論層（L3）。
  3. pos3 是「真值空隙」不是 FP。pos3(chr2:18,086,020) 落在 SEQC2 高信賴區間的空隙裡 → 外部真值無法評估（不是被判為假陽性）；它當 α 的 pivot 只有內部 read linkage 支持，外部無真值可確認。
  4. β 的左塊 (1)(2) 與右塊 (4)(6) 是「甲基橋接的推論」，不是點突變的直接 linkage。兩塊相距 ~36–40 kb、沒有跨距 read 把它們連在同一條分子上（HKU 跨塊 n=1–2、11=0；DORADO n=0）→ 它們同屬一個 β 程式，是靠「與 α 互斥 + 甲基一致性」推論出來的（L3，圖 3 以虛線標示）。勿寫成「點突變直接證明 β 是單一分支」。

⑦ 收尾對照：只有點突變 vs 加上甲基

把「為什麼要偵測甲基」用一張對照圖收尾。左邊是只靠點突變能做到的（稀疏、有 read 標不到、低訊號變異難確認）；右邊是加上甲基後多出來的能力。

本頁總結在 LOH 無塵室裡，點突變把 read 切成互斥的 α / β 譜系，甲基沿同一個切分獨立印證並補足標記 —— 這就是「從 sSNV + 甲基推出 clone/subclone 並標 tag」可行的原因。偵測甲基的價值在於它是第二條獨立、密集、可刻畫功能的軸；但結論有界（L2、~3 譜系、僅乾淨 CpG 子集、甲基為印證非驅動非 filter）。

⑧ 限制與證據邊界（教學頁不藏 caveat）

這些是把本頁結論寫進論文/報告時必須一起帶上的邊界。完整權威裁決見 頁 05 與 verdict_02。

整體 tier = L2：單位點 × 單樣本 × 單 pipeline
cross-basecaller（HKU vs DORADO）是同一細胞株的技術/資料重現，不是獨立的生物學重複。要升 ★4 需要第二個樣本（如 COLO829）或第二個 LOH 位點。
pos3 落 SEQC2 高信賴區間「空隙」→ 外部真值不可評估（非 FP）
α 譜系的 pivot 突變只有內部 read linkage 支持，外部真值集無法確認此點。
甲基 confound 未完全形式排除
3.3/3.4/3.5/4.1 在配對正常組織已有顯著 germline ASM；乾淨子集限於正常組織無 HP 差異的 CpG。且「LOH 前既存的等位甲基差異被保留、再被 somatic 切分」這條機制，無丟失 allele 可對照，無法被本資料形式排除 → 保守視為「這些 CpG epigenetically labile」並排除。
「0 違反」僅限 strict 定義；DORADO normal 未 tag
放寬的 pos4-β 定義在 DORADO 有 1 條 discordant read；多組遠距 pair 無跨距 read，故「0 observed」非強跨資料複製。germline-ASM confound 檢定僅靠 HKU normal，confound 側未跨 basecaller 複製。
外部驗證三層裁決（防 over-claim）
① 區域有 somatic 事件 = YES；② 被外部 characterize 為 subclone = PARTIAL（sample-level YES〔Fang 2021〕、locus-level NO）；③ 我方假想樹被外部逐節點 reproduce = NO。禁寫「確認 5 subclone / 完整演化樹」「SEQC2 驗證此區是一個 subclone」「甲基 driver / 獨立重建」「DORADO 是獨立病人」。
可防守的一句話（投稿口徑）A regional, LOH-constrained, somatic-haplotag-conditioned subclonal structure with cross-basecaller methylation coherence. —— 不是 "Confirmed five-subclone evolutionary reconstruction."
