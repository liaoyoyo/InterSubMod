InterSubMod 解釋中心

把各研究任務的敘述與邏輯，轉成分層、配圖、嚴謹定義的解釋頁，讓有實驗室背景的讀者全面理解。每個概念一頁，重點先行、細節折疊。這頁是入口與導覽。

L0 一眼看懂這個研究在做什麼

用 ONT 長讀在單一 read 上同時讀到 somatic 突變 + 單倍型 + 甲基化，研究 LOH 如何重塑 haplotype 結構，並誠實界定甲基化能做（characterization）與不能做（當 variant filter）的事。

▸ 給 PI 一句話：論文主體 = 三~四道防彈 NEGATIVE（甲基不能當 filter）+ phasing 脊柱（Grade B+）+ ASM copy-confounded 支撐。主軸 = Subclonal Reconstruction（somatic haplotag + methylation）。

🔴 讀本站的 4 條鐵則
  1. 「存在 ASM」≠「能判別 TP/FP」——兩個 claim 永遠分開講。
  2. HP-axis（HP1 vs HP1-1）somatic-controlled；ALLELE-axis（ALT vs REF）被 germline het baseline 污染。
  3. 絕對 AUC 系統性膨脹（germline het null median 0.974）；引相對 null（excess/delta）不引絕對 AUC。
  4. 甲基→TP/FP filter = DEAD，勿再開；同 haplotype 內拆亞群（T3）= NEGATIVE。

▦ 10 條研究線（一句話 + 給 PI 重點 + tier）

每條線一張卡。狀態色：方法 POSITIVE NEGATIVE/DEAD 混合。

ISM 方法本體 ⭐3

讀 ONT 癌症 BAM，對每 somatic 位點做甲基矩陣→read-read 距離→聚類→PERMANOVA 結構檢定。量「結構連結」非 filter。
▸ PI：量 between-molecule 結構；核心 = somatic sub-haplotype 解析度 + normal-anchored cis-test 去 3 假象。
方法本體 →  甲基讀取/篩選細節 →

整個專案的「語言」：read / haplotype / HP-tag / 5mC / ASM / cis / Δβ / LOH / CN 等 28 核心詞 + 統計 worked example。
▸ PI：HP-axis vs ALLELE-axis、「存在≠判別」、excess-over-null 三個定義決定所有結論能否成立。

methyl-phasing-assist 混合

用每條 read 甲基模式幫判斷它屬哪個 haplotype，救援 unphase read 或糾正 longphase-S 打錯的 tag（V1-V12）。
▸ PI：88.5% 模擬 unphase 能回推 haplotype 且 normal 排除 copy 假象，但 94% 真實 unphase read 住在 LOH/imprinting → 機制在最需要處失效。
關聯入度最高（7）· 建議樞紐起點

ism-vs-external（軸 C vs 軸 A）⭐3

ISM 把「read 是否結構分亞群」當主問題（軸 C），而非算「兩組率差」（軸 A）；且誠實 NEGATIVE：甲基不判別 TP/FP。
▸ PI：可防守新穎 = read-read 距離 + PERMANOVA + normal-anchored cis 三位一體，但每個單元件都有更成熟競品。
待建

四道 NEGATIVE（filter DEAD）⭐2 L4

用甲基特徵辨別 TP/FP 多道驗證全失敗——這些 NEGATIVE 本身即論文貢獻（防彈負結果）。
▸ PI：pilot ΔF1=+0.00242 低於門檻 / LOSO 100% 循環 / 消融確認甲基是第 5 順位 vestigial。
待建

LOH-phasing 脊柱 B+ ⭐3

LOH 區突變留下「同單倍型分裂」phasing 特徵可與 germline FP 區分，但由 LOH 物理結構決定故帶 by-construction 循環。
▸ PI：LOH 內 NG=2 reads 93-99% same-hap（7/7, p=0.0078），但 self-ref 全基因組負控（~25-50hr）未跑 → Grade A 待決策。
待建

ASM ZAR1L/BRCA2 + 跨樣本 ⭐3

BRCA2/ZAR1L 確有 ASM、真實可重現，但「存在」與「能判別 TP/FP」是兩件事——它判別不了。
▸ PI：Δβ=−0.122、6/6 樣本 excess>0 跨 3 癌種；但 strong-ASM 在 FP 富集 5×（OR=0.194）→ 生物現象非可用 filter。
待建

ASM cis + CN confound ⭐3

ASM 廣存但既不判別 TP/FP，其 cis 殘差也不改善判別，甚至 FP 比 TP 更常出 cis 訊號。
▸ PI：6 樣本 28 萬位點 powered：TP 顯著率 3.95% > FP 1.07% 但絕對靈敏度~4% / COLO829 TP≈FP。
待建

主軸：Subclonal Reconstruction 混合

ONT 單 read 同時讀 somatic + HP tag + 甲基，揭示 LOH 重塑 haplotype，誠實界定 characterization vs filter。
▸ PI：deliverable = 四道防彈「甲基不能當 filter」+ 方向一致跨樣本 phasing 訊號；脊柱 = genetic haplotagging。
待建（論文框架）

真實案例：chr2:18M subclone 重建 案例 L2

HCC1395 一段 LOH 區的 6 sSNV + 甲基逐步重建走查。並陳「手動 IGV 直覺 → 實測校正」，給教授與同學看一個真實 subclone 怎麼被拼回來。
▸ PI：骨幹（LOH→α/β somatic 譜系→甲基追蹤）獲證且跨 basecaller 複製；3 處校正（5群→~3、順序=推論、operational≠germline ASM）。

案例 audit：chr2:18M 權威裁決 L2

第二輪獨立複核（matched-normal ASM 控制 + 跨 basecaller FDR）對推論 1-6 逐一裁決，並把甲基訊號拆成「乾淨 tumor-associated」vs「既存 germline ASM confound」。

ISM subclone pipeline 構想 構想 · B2

從 chr2 案例萃取的 9 步 ISM subclone 分析方法（輸入→譜系→甲基+ASM控制→可防守樹）+ 3 防呆 + 系統化路徑。構想基礎，非已實作模組。

ism-evolution（統計口徑稽核）⭐3

ISM 現行版有多個統計口徑問題（Fisher 假獨立 / 5mC-only / germline 軸 Δβ 污染 / 跨 region 無多重檢定），稽核後無翻轉結論但需補修。
▸ PI：「結構存在嗎」沒根本錯誤，但 Fisher 假 read 獨立 + 跨 region 無 MT 校正 → ASM 存在率偏樂觀。
