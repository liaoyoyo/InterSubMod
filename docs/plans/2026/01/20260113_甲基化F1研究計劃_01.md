# 甲基化顯著性與 F1 最佳化研究計劃

## 1. 研究背景

### 1.1 問題陳述

InterSubMod 分析腫瘤樣本中的甲基化異質性，目前：
- 甲基化顯著性指標 (Cramér's V) AUC 僅 0.5194，**無鑑別力**
- TP 顯著率僅 6.11%，93.9% 的真陽性沒有顯著甲基化訊號
- 直接用顯著性過濾會使 F1 從 0.8155 惡化至 0.0899

### 1.2 基準數據

**明恩 SNV 結果**：

| 指標 | Pileup SNV | 明恩 SNV | 差異 |
|:---|---:|---:|---:|
| TP | 30,596 | 30,490 | -106 |
| FP | 13,357 | 4,842 | -8,515 |
| FN | 8,851 | 8,960 | +109 |
| Precision | 0.6961 | 0.8630 | +0.1669 |
| Recall | 0.7756 | 0.7729 | -0.0027 |
| **F1-score** | **0.7337** | **0.8155** | **+0.0817** |

**理論上限**：F1_max = 0.8736（完美移除所有 FP）

### 1.3 F1 優化取捨關係

| 方向 | 比例要求 | 圖示說明 |
|:---|:---|:---|
| **嚴格**（降 FP） | FP:TP = 1:0.69 | 每刪 1 FP，誤刪 TP < 0.69 → 有利 |
| **寬鬆**（降 FN） | FN:FP = 1:1.449 | 每救 1 FN，誤抓 FP < 1.449 → 有利 |

**有效策略判斷**：`移除的 FP / 移除的 TP > 1.45`

---

## 2. 研究目標

### 2.1 主要目標

1. 探索是否存在 **組合特徵** 可提升 TP/FP 區分能力
2. 評估各種 **條件過濾策略** 對 F1 的影響
3. 記錄研究過程供後續參考

### 2.2 次要目標

1. 了解甲基化異質性與 SNV 真假的關係
2. 發現可能的觀察現象（即使無法提升 F1）
3. 為未來研究建立基礎架構

### 2.3 非目標

- 本研究 **不** 追求顯著的 F1 提升
- 本研究 **不** 修改現有主流程
- 陰性結論同樣有價值

---

## 3. 研究方法

### 3.1 數據觀察層級

```
層級 1: 原始數據觀察
├── samtools view → 查看特定區域的 reads
├── bcftools query → 提取 VCF 欄位特徵
└── IGV 視覺化 → 直觀觀察甲基化模式

層級 2: 統計分析
├── Python 腳本 → 計算分布、AUC、相關性
├── sklearn → 機器學習特徵選擇
└── scipy → 統計檢定

層級 3: 程式碼實驗
├── 開 git 分支 → 實驗性修改
├── 單元測試 → 驗證改動正確性
└── 批次分析 → 評估整體效果
```

### 3.2 實驗管理原則

1. **獨立分支**：每個程式碼實驗開獨立 git 分支
2. **完整記錄**：記錄假說、方法、結果、結論
3. **可重現性**：保存命令、腳本、數據
4. **不影響主流程**：實驗程式碼不合併入主分支

## 4. 可觀察特徵列表

### 4.1 VCF 原始特徵 (F01-F05)

| 編號 | 特徵 | 說明 | 提取方式 | 預期 |
|:---:|:---|:---|:---|:---|
| F01 | QUAL | ClairS 品質分數 | `bcftools query -f '%QUAL'` | TP > FP |
| F02 | AF | Variant Allele Frequency | `bcftools query -f '[%AF]'` | 可能有特定範圍 |
| F03 | DP | Read Depth | `bcftools query -f '[%DP]'` | 高深度更可靠 |
| F04 | H flag | Haplotype-specific | `bcftools query -f '%INFO/H'` | 與 phasing 相關 |
| F05 | Strand Bias | FAU/RAU 比值 | 計算 (FAU+FCU+FGU+FTU)/(RAU+...) | FP 可能有更強 bias |

### 4.2 甲基化分析特徵 (F06-F10)

| 編號 | 特徵 | 說明 | 來源 | 預期 |
|:---:|:---|:---|:---|:---|
| F06 | CramersV | 效應量 | significance_summary.csv | 現有 AUC=0.52 |
| F07 | LabelDelta | 標籤距離差異 | significance_summary.csv | 已知有微弱效果 |
| F08 | GlobalP | Fisher p-value | significance_summary.csv | 低 P 可能更可信 |
| F09 | VerificationClass | 雙向驗證分類 | significance_summary.csv | Strong 應有更高 TP 率 |
| F10 | DominantLabel | 主導標籤維度 | significance_summary.csv | hp/allele/none |

### 4.3 衍生特徵 (F11-F15)

| 編號 | 特徵 | 說明 | 計算方式 | 預期 |
|:---:|:---|:---|:---|:---|
| F11 | NumReads | 甲基化分析深度 | significance_summary.csv | 低深度不可靠 |
| F12 | NumCpGs | CpG 位點數量 | significance_summary.csv | 少 CpG 增加噪音 |
| F13 | Regional Clustering | 50kb 窗口聚集度 | 計算每位點周圍位點數 | 高聚集可能是 FP |
| F14 | QUAL × CramersV | 品質與效應量交互 | 建立 2D 過濾曲面 | 找最佳組合閾值 |
| F15 | AF × LabelDelta | VAF 與標籤差異交互 | 分析交互效應 | 可能發現隱藏規律 |

## 5. 實驗設計

### 5.1 Phase 1: 快速驗證 (1-2 天)

#### 實驗 1.1: VCF QUAL 分布分析

**假說**：TP 的 QUAL 分數高於 FP

**方法**：
```bash
# 提取 QUAL
bcftools query -f '%QUAL\n' data/vcf/HCC1395/pileup/filtered_snv_tp.vcf.gz > tp_qual.txt
bcftools query -f '%QUAL\n' data/vcf/HCC1395/pileup/filtered_snv_fp.vcf.gz > fp_qual.txt

# Python 分析
python3 04_scripts/exploration/analyze_qual.py
```

**成功標準**：AUC > 0.55

#### 實驗 1.2: VCF AF 分布分析

**假說**：TP 的 AF 分布與 FP 不同

**方法**：
```bash
bcftools query -f '%POS\t[%AF]\n' filtered_snv_tp.vcf.gz > tp_af.txt
bcftools query -f '%POS\t[%AF]\n' filtered_snv_fp.vcf.gz > fp_af.txt
python3 04_scripts/exploration/analyze_af.py
```

**成功標準**：特定 AF 範圍的 TP/FP 比例顯著不同

#### 實驗 1.3: Strand Bias 分析

**假說**：FP 有更強的 strand bias

**方法**：計算 forward/reverse strand ratio，比較分布

**成功標準**：bias ratio 在 TP/FP 間有顯著差異

#### 實驗 1.4: Regional Clustering 分析

**假說**：FP 傾向於在特定區域聚集

**方法**：計算 50kb 窗口內的位點數，分析 TP/FP 分布

**成功標準**：高聚集區域的 FP 比例顯著高於 TP

#### 實驗 1.5: 現有特徵組合 AUC

**假說**：組合多個甲基化特徵可提升區分能力

**方法**：使用 Random Forest 計算特徵重要性和 5-fold CV AUC

**成功標準**：組合 AUC > 0.6

## 6. 判斷標準

### 6.1 特徵有效性

| AUC 範圍 | 判定 | 後續行動 |
|:---|:---|:---|
| > 0.6 | **有效** | 優先納入組合模型 |
| 0.55 - 0.6 | **弱有效** | 與其他特徵組合測試 |
| < 0.55 | **無效** | 記錄並跳過 |

### 6.2 過濾策略有效性

必須 **同時滿足**：

1. **FP/TP 移除比 > 1.45**
2. **新 F1 > 0.8155** (baseline)
3. **策略可解釋**（非過擬合）

### 6.3 實驗結論類型

| 類型 | 說明 | 價值 |
|:---|:---|:---|
| **陽性** | 發現有效策略 | 直接可用 |
| **條件陽性** | 特定條件下有效 | 需進一步驗證 |
| **陰性** | 證明無效 | 避免未來重複探索 |
