# 純樣本甲基研究執行計畫

## 摘要

本階段執行順序固定為：

1. `HCC1395 5kHz` pure `tumor/normal`
2. `HCC1395 ONT_Dorado + HCC1395BL` pure `tumor/normal`
3. 其他 pure paired samples
4. pure tumor-only
5. mixed purity / subsample

這份計畫只處理「現在該先做什麼、每一步要產生什麼、怎麼判定有效」，避免研究又被 purity/subsample 問題帶偏。

## 1. 階段目標

### 1.1 階段 A：建立 pure tumor/normal 基線

先完成：

1. `HCC1395 5kHz`
2. `HCC1395 ONT_Dorado`
3. 其他 pure paired samples

固定輸出：

- `benchmark_comparison.tsv`
- `method_design_validation.tsv`
- `label_cluster_agreement.tsv`
- `round_summary.md`

驗收條件：

1. 每個樣本都有可追溯 benchmark 指標
2. 每個樣本都有非空的方法學驗證表
3. 每個樣本都記錄時間、測試重點、改動、主要結果與結論

### 1.2 階段 B：驗證 `label-first` / `cluster-first` 是否可用

重點不是先比較輸贏，而是先回答：

1. 哪些資料條件下 `label-first` 可用
2. 哪些資料條件下 `cluster-first` 可用
3. 哪些 region 因 HP/Allele 由 `Weak` 升級到 `Strong` / `Subclone`
4. 哪些 region 出現衝突，需要回頭檢查設計與假設

固定輸出：

- `method_design_validation.tsv`
- `label_cluster_agreement.tsv`
- `diagnostics/<region_id>/...`

驗收條件：

1. 至少能明確列出升級、衝突、不可解讀的 region
2. 每種狀態都有可回頭追的 diagnostics

### 1.3 階段 C：重大節點敏感度分析

第一批必做設定：

1. `distance_method`
   - `BERNOULLI`
   - `NHD`
   - `L1`
2. `read_filter_profile`
   - `stable_default`
   - `igv_closer`
   - `relaxed`
3. `window_bp`
   - `1000`
   - `5000`
4. `methylation_mode`
   - `analog_full`
   - `binary_default`

固定輸出：

- `methodology_sensitivity.tsv`
- `failure_diagnosis.md`

驗收條件：

1. 能指出影響結果最大的 3 個節點
2. 能區分哪些是工程預設、哪些是研究關鍵因子

### 1.4 階段 D：pure tumor-only

只在 paired pure 有穩定結論後才做。

驗收條件：

1. 至少有一批 paired pure 中有效的特徵可搬到 tumor-only
2. 比較 paired pure 與 tumor-only 的差異不只看 F1，也看哪些 region / 特徵失效

### 1.5 階段 E：mixed purity / subsample

最後進行。

驗收條件：

1. 先能明確說出 paired pure 的穩定結論
2. 再測試 purity/mixed 是否破壞或保留這些規律

## 2. 交付物

### 2.1 研究 round 層級

每次 round 都要產生：

- `round_context.json`
- `round_summary.md`
- `benchmark_comparison.tsv`
- `benchmark_comparison.md`

### 2.2 方法學層級

- `method_design_validation.tsv`
- `label_cluster_agreement.tsv`
- `methodology_sensitivity.tsv`
- `failure_diagnosis.md`

### 2.3 診斷層級

每個被挑選深入分析的 region 都要有：

- `region_summary.tsv`
- `region_notes.md`
- `heatmap_methylation.png`
- `heatmap_distance.png`
- `label_vs_cluster.png`

## 3. 驗證與評估標準

### 3.1 Benchmark

必列：

- `truth_total`
- `calls_total`
- `TP`
- `FP`
- `FN`
- `precision`
- `recall`
- `F1`

### 3.2 方法學

至少回答：

1. `label-first` 是否可用
2. `cluster-first` 是否可用
3. 哪些 region 從 `Weak` 升級
4. 哪些 region 衝突
5. 衝突可能來自資料、方法或假設哪一層

### 3.3 可觀察性

若結論不合假設，至少要有：

1. 相關聯數據表
2. 圖片輸出
3. 改動與假說對照
4. 初步原因推理

## 4. 任務順序與依賴

1. 完成研究文件與入口腳本
2. 用 `HCC1395 5kHz` 跑第一輪 round
3. 對異常 region 匯出 diagnostics
4. 用 `HCC1395 ONT_Dorado` 做交叉驗證
5. 擴到其他 pure paired samples
6. 整理敏感度矩陣
7. 再決定是否進入 tumor-only
8. 最後才做 mixed purity / subsample
