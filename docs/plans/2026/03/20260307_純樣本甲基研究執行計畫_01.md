# 純樣本甲基研究執行計畫（突破方向版）

## 摘要

這份計畫接在 `2026-03-24` 的方法學審查 closeout 與突破方向全域分析之後，目的不是再把 `paired pure` 當唯一主題重跑，而是用既有 baseline 推進四個方法升級 phase：

1. `Phase 1`：方向 E，`ML read classification`
2. `Phase 2`：方向 A+D，`normal methylation reference + CN/Purity-aware`
3. `Phase 3`：方向 B，`gene-level evidence integration`
4. `Phase 4`：方向 C，`CpG 功能分層與智慧選點`

所有 phase 都必須回接到固定 baseline：`HCC1395 5kHz paired/TO`、`HCC1395_DORADO paired/TO`，並保留其他 pure paired 樣本作穩定性檢查。

## 1. 本階段總目標

1. 把現有 `caller-first → methylation-support → annotation / QC / artifact triage` 架構當作固定比較基準
2. 將研究資源從規則微調轉向方法升級
3. 確保所有新方法都有跨 `5kHz / DORADO` 的 head-to-head 比較
4. 不再把已 closeout 的舊問題重新包裝成主任務

## 2. 四個 phase 的任務拆分

### 2.1 Phase 1：ML Read Classification（方向 E）

**目標**

- 建立 read-level classifier 原型，直接和現有 clustering/annotation 路徑比較
- 確認 read-level modeling 是否能在 `5kHz` 與 `DORADO` 上帶來一致增益

**主要任務**

1. 定義 read-level feature set 與 label schema
2. 建立 baseline 對照：`VerificationClass`、`QualityScore`、`PairwiseMedianDist`
3. 在 `HCC1395 5kHz paired/TO` 建 discovery prototype
4. 在 `HCC1395_DORADO paired/TO` 做 cross-platform validation

**固定輸出**

- `phase1_model_spec.md`
- `phase1_head_to_head.tsv`
- `phase1_error_taxonomy.md`
- `phase1_readlevel_diagnostics/`

**驗收條件**

1. 新方法必須和固定 baseline 同表比較
2. 必須同時回報 `5kHz` 與 `DORADO` 方向是否一致
3. 若只在單一 sample 成立，需明確標記為 sample-specific

### 2.2 Phase 2：Normal Baseline + CN/Purity-aware（方向 A+D）

**目標**

- 直接處理 germline ASM、normal contamination、LOH/CN 對甲基訊號的混合效應
- 讓 normal methylation baseline 進入建模主體，而不是只作事後解釋

**主要任務**

1. 建立 per-region normal methylation baseline
2. 定義 tumor/normal corrected matrix 或 read-label model
3. 使用 `paired_persistent_final_fp` 與 shared hotspot 當 diagnostics input
4. 與現有 `caller-first + support annotation` baseline 比較

**固定輸出**

- `phase2_baseline_model.md`
- `phase2_corrected_matrix.tsv`
- `phase2_hard_case_review.md`
- `phase2_before_after_benchmark.tsv`

**驗收條件**

1. 必須能說明哪些 FP 被 normal baseline 重新解釋
2. 必須能分出「校正後改善」與「仍不可解 case」
3. 不得只用單一 sample 宣稱已解決 germline ASM

### 2.3 Phase 3：Gene-level Evidence Integration（方向 B）

**目標**

- 將 per-SNV 視窗證據整合成 gene-level 的 second-hit / biallelic event narrative
- 讓 InterSubMod 從局部視窗分析走向機制層級解釋

**主要任務**

1. 定義 gene-level evidence schema
2. 彙總同一基因多個 SNV windows、LOH/CNV、promoter methylation
3. 選 10 個已知 TSG / driver gene 做 pilot
4. 定義 second-hit archetype 與 evidence panel 格式

**固定輸出**

- `phase3_gene_panel.tsv`
- `phase3_archetype_definition.md`
- `phase3_case_studies.md`

**驗收條件**

1. 至少有一批 gene-level case 能比 per-SNV 視角更可解釋
2. evidence panel 必須可追回原始 SNV window 與 diagnostics

### 2.4 Phase 4：CpG 功能分層與智慧選點（方向 C）

**目標**

- 依任務不同，替 CpG 指派不同功能層級與權重
- 避免把所有 CpG 視為同等訊號來源

**主要任務**

1. 建立 CpG annotation schema：regulatory / fCpG-like / MHB-core / other
2. 交叉檢查 ISM 視窗內 CpG 與外部功能集
3. 評估不同 CpG 子集對距離、分類、gene-level evidence 的影響

**固定輸出**

- `phase4_cpg_catalogue.tsv`
- `phase4_subset_benchmark.tsv`
- `phase4_annotation_notes.md`

**驗收條件**

1. 必須能說明不同 CpG 子集對不同任務的角色差異
2. 不得只做功能標籤盤點而沒有回接 benchmark 或 evidence panel

## 3. 驗證資料與固定比較矩陣

### 3.1 固定 baseline

- `HCC1395 5kHz paired`
- `HCC1395_DORADO paired`
- `HCC1395 5kHz TO`
- `HCC1395_DORADO TO`

### 3.2 支援樣本

- 其他 pure paired 樣本：可攜性與穩定性檢查
- mixed purity / subsample：暫不作主線，只在 phase 有明確結果後再評估

### 3.3 每次比較必列

- `truth_total`
- `calls_total`
- `TP`
- `FP`
- `FN`
- `precision`
- `recall`
- `F1`
- 與固定 baseline 的差值
- 是否跨 `5kHz / DORADO` 同方向

## 6. 明確不做

1. 不把 `H006 window_bp=1000` 重新打開成近期主任務
2. 不再把 `AlleleDelta standalone filter` 當全域 hard filter 候選
3. 不把 `TO rescue` 的 sample-specific support rule 直接升級成跨樣本部署規則
4. 不在沒有 normal baseline 的情況下宣稱解決 germline ASM
5. 不以舊的 `paired pure → TO → mixed` 順序當研究主線本身；它現在只是驗證資料梯度
