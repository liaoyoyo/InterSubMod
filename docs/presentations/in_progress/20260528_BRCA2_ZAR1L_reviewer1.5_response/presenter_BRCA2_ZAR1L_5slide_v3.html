🧬 ASM / haplotype 概念

  • ASM (allele-specific methylation)：同一基因座兩條 allele 的甲基化程度不同
  • HP:Z tag (longphase-s)：1/2 = germline-tagged · 1-1/2-1 = reconstructed-somatic-tagged · 3 = ambiguous
  • reconstructed somatic haplotype：longphase-s 用 somatic SNV 重建出的 haplotype-tagged reads
  • 5mC / β (beta value)：單 CpG site 甲基化率（0=未甲基 / 1=全甲基）；IGV 中紅=高、藍=低
  • Δβ：(somatic β) − (germline β)；負值 = somatic 比 germline 少甲基（hypomethylation）
  • MM/ML tag：BAM 內甲基化 modification 機率編碼（ONT 5mCG calling）

📊 統計概念

  • Wilcoxon signed-rank：paired non-parametric test，對同一 CpG 的 germline vs somatic 配對
  • Cohen's d：標準化 effect size；|d|<0.2 trivial / 0.2-0.5 small / 0.5-0.8 moderate / >0.8 large
  • Lister 2009 ribbon：DNA 甲基化生物學中 |Δβ|≥0.2 視為 biologically meaningful 的閾值
  • negative control：隨機抽非-TSG 非-LOH 位點跑同 pipeline，建立 null 分布排除系統噪音
  • 全基因組 survey（S5）：把 ISM 差異引擎掃過全基因組 18,149 somatic 位點，582 達顯著；BRCA2 rank 25

🔬 位點生物背景（三重重疊）

  • BRCA2：DNA 雙股斷裂修復、乳癌/卵巢癌 TSG（Vogelstein 138 driver）；變異在 most-upstream TSS +42 bp
  • ZAR1L (alias ZAR2, LOC646799)：C4-type zinc finger TF；Liu 2010 證其直接 silence BRCA2 forward 轉錄；變異在 ZAR1L canonical TSS −235 bp = ZAR2 exon 1 內
  • bidirectional overlapping promoter：兩基因頭對頭共享的啟動子；BRCA2/ZAR2 有 111-nt antiparallel overlap；Liu 2010 實驗定位 −187…+310
  • 三重重疊（v3 軌道圖）：變異同時在 (i) BRCA2 5'UTR/promoter、(ii) ZAR2 exon1、(iii) Liu 2010 雙向啟動子內 — strengthen mechanism plausibility
  • CpG destruction artifact：變異剛好破壞 CpG dinucleotide → 看似 hypomethylation 但其實是 sequence-driven 假象（本例 AGA→AAA 非 CpG，已排除）
  • cis-ASM cascade：cis-acting 變異破壞 TF binding → 觸發 allele-specific 甲基化變化

🗂 資料 / 框架邊界

  • LOH (Loss of Heterozygosity)：一條 allele 完全失去，HP1+HP2 不會同時存在 → ASM 框架 by definition 不適用
  • 為何排除 LOH：HCC1395 hyper-diploid（ploidy 2.85），51/95 (53.7%) TSG 落 LOH（含 BRCA1/TP53/CDH1/RASSF1A/CDKN2A）→ 經典 TSG 須改用 bulk methylation 分析
  • TVAF / NVAF：Tumor / Normal Variant Allele Frequency（本例 0.189 / 0.002）
  • SEQC2：FDA-led Sequencing Quality Control Phase 2；提供 HCC1395 truth set
  • curated 95 TSG：COSMIC CGC ∪ Vogelstein 138 ∪ breast DDR（因 COSMIC API / OncoKB 404 改 hardcode）
