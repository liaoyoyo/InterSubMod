🔴 HCC1395 self-train 結論 generalizability 不足

HCC1395 同時是 LR train + test set，cycle 1 +0.02236 屬 in-sample fit。跨 4 個未見樣本：HCC1937 marginal +0.008 · 其他 3 樣本 transfer ΔF1 ≤ 0 · HCC1954 −0.377 災難 — HCC1395 alone 結論不足以宣告 filter generally valid。

⚠ Mechanism: caller-F1-headroom-bounded

3/4 新樣本 caller F1 > 0.83 + FP density < 4% → 不留 filtering room（filter 找不到有意義 threshold）。HCC1954 transfer 災難 = caller_af coef overfit HCC1395 AF 分佈。
