Slide 5 · Mechanism · 為何 5-rank coef +0.75 但 incremental ≈ 0C style · SVG DAG

Causality DAG：caller_af → HPFineF (proxy) → false ISM attribution — L2 ridge 把相關特徵 split 造成假 contribution

L2 ridge-split 機制（為何 5-rank coef +0.75 但 incremental ≈ 0）：L2 regularization 把高相關特徵 coef 分散 — HPFineF +0.75 是 caller_af 的 partial 共變異 split，並非獨立貢獻。drop 5 methyl 後 caller_af + LOH + Cov + NG 4 features 重新分配權重就 capture 同訊息，使 ΔF1 幾乎不變。
跨方法收斂（最強佐證）：
  • • 5/19 V6 §13 Day 3 measured methylation contribution → +0.0005~+0.0007
  • • 5/20 Cycle 3 H_M1a (refit-mode) → +0.00065
  • • 5/20 Cycle 3 transfer shrinkage 修補 → < 7%
  • → 三條獨立路徑同方向同 magnitude，DAG 機制收斂
給 PI 看的重點

單一統計顯著的 coef 不等於 incremental contribution。L2 LR 框架下，高相關特徵之間的 coef split 是常見 artifact —— 必須用 ablation (drop-and-refit) 才能量化 incremental。本案例 methylation rank 5 coef +0.75 看似明顯，但 ablation 後 vestigial。
