M2 · 正確的判別軸（核心方法論貢獻）無監督 NEGATIVE → a-priori 條件化軸

判別力來自「對齊獨立 a-priori 軸」，不是「無監督切得出來」。
  • tumor-only 無監督 clustering + PERMANOVA = NEGATIVE（double-dip：Noise a-priori 0% → TI 100%）F src:project_tumor_only_axis_negative
  • 正解：a-priori 條件化軸（haplotag 1-1/ALT-REF、扣 normal）→ Noise 0% 真判別 F
  • 含義：HP tag 1-1/2-1 = somatic haplotype；1-2/2-2 = 多 subclone（longphase-S，HCC1395 缺）
圖位 ★關鍵教學圖 新SVG：左「無監督 double-dip」(同資料訓練+驗證的循環箭頭) vs 右「a-priori 軸」(獨立標籤→判別，非循環) 對比。← 用例子講解最有力的一張

M3 · 切群 ≠ subclone（最重要的辨別）多數切群是 cis-ASM 假象

無監督切群與標籤幾乎不相交；「subclone 候選」多為 cis-ASM。
  • 全 7 樣本 Jaccard(無監督, 標籤) = 0.091–0.161 一律低（跨 3 癌種）F src:allsample_subcluster_split/SUMMARY
  • 5-態分類（全基因組 N=30,490）：state③ label-first 真關聯但 cis-ASM 非 subclone F src:20260620_decisionflow_5state
  • phylo v1「subclone 候選」全假象 → cis-ASM 零 subclone（double-dip 修正）O
  • 切群多閘重設計（balance + null-excess + alignment）+ coarse/fine 雙輸出 ⚠ deck 前確認「三閘」vs「四閘+Rnull=15」口徑

M5 · 論文基石就位為什麼需要甲基補強：sSNV 太稀疏

sSNV 在基因組上太稀疏，單 read 幾乎跨不到 2 個 → motivation：需甲基提供 read 內共現訊號。
  • Q1 coverage（HCC1395）：sSNV 密度 10.6/Mb、中位相鄰間距 51.4 kb、read ref-span 中位 4.9 kb F src:ssnv_spacing_coverage.json @114200e
  • P(≥2 sSNV / read) = 0.74%；94.2% read 跨 0 sSNV；±5kb window 33.2% read 跨完整 F
  • S3 limitations 草稿就位：LOH-unmask confound / phase-set 天花板 / T2 口徑修正 O
