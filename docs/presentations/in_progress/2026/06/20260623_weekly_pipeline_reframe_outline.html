判別機制怎麼判「對齊」+ 配合特徵定義

對齊 = 切群 read-set 與獨立標籤（HP/allele）顯著重合；再配合其他特徵給定義。
  • 對齊判定：CramérV ≥ 0.7 + Fisher（與 HP/allele 標籤交叉，a-priori 非循環）F
  • 配合特徵：AF / CN / coverage / LOH → 區分 cis-ASM vs subclone 候選 I
  • 歸因：對齊 germline → cis-ASM（多數）；不對齊 + 特徵支持 → subclone 候選
圖位 新SVG：判別決策（切群 → 交叉標籤 → 對齊? → 配特徵 → 定義）
