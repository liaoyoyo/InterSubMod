邏輯鏈 (cont.) · 統計驗證

PERMANOVA 配 PERMDISP （核心）

PERMANOVA
群在距離空間是否真分離？打亂標籤建 null，看觀測 pseudo-F 是否落右尾。
F = (SS組間/(k−1)) / (SS組內/(N−k))
99 次排列 · min_reads=5 · 存在性檢定
PERMDISP
排除「只是較離散、非型態不同」的假象（Anderson&Walsh 2013：兩者一組）。
!! PERMDISP 此 run 未開（enable_dispersion=false）→ 啟用為收尾動作
為何 SOUND：成熟框架（Legendre & Legendre《Numerical Ecology》/ Anderson 2001 / McArdle & Anderson 2001 + 微生物組 β-diversity 先例）；非循環——HP 標籤來自 somatic_haplotag（零甲基，源碼證實），是「甲基結構 vs 獨立基因標籤」對齊，非自證。
演算法：StructureTest.cpp run_permanova + check_dispersion · GlobalTest.cpp（Cramér's V / Fisher 輔）

結論

方法 SOUND_WITH_CAVEATS

1有效

PERMANOVA = 甲基領域 best-in-class 存在性檢定；分類窮舉覆蓋每個位點，並分 tumor-only / tumor+normal 兩層。

2合理

建在成熟框架（Legendre · Anderson 2001 · McArdle + 微生物組 β-diversity 先例）；非循環（HP 零甲基）；read-level 有 qFDRP / cvlr 先例。

3可行

PERMANOVA + PERMDISP 已實作 C++；單細胞先例 PDclust / scMelody / SINCEF 同骨架；外部 61 源（59 親讀）· 無同-regime 衝突。

誠實邊界（Remarks）
分類 ≠ subclone（有結構普遍 ~91.7%） PERMDISP 此 run 未開 · k/穩定性缺口 勿稱「獨有顯著性檢定」（cvlr/ASMS 皆有 randomization）→ 增量在檢定對象 characterization-only · 甲基屬 germline-haplotype 層 · filter 方向 DEAD
