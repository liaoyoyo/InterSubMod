圖1Δβ = 把 read 收斂成「平均甲基值」——擅長方向型、漏掉「交叉型」

情境 A cohesion 佐證：HP1-1 silhouette 0.267（群內最聚）；盲分群 ARI=0.79。【⚠ 上輪 copy-partition：此 −0.122 多由 copy 解釋，純 allele cis d_within=−0.023 small-but-real p=0.022】
對照結論：Δβ 是「兩層平均」→ 量的是「整段一致的方向性位移」。情境 A（方向型）平均後仍明顯 → 抓到；情境 B（交叉型）平均後抵消 → 漏，但 read pattern 明顯不同 → 分群(ARI)抓到。「篩選平均」是優點也是盲點，交叉/位置型需補分群(ARI)/max|Δ|/PERMANOVA 雙鍵。
工程科學敘述：Δβ 本質＝兩層平均——(1) 每個 CpG 把該群 reads 的甲基狀態平均成群率 β（消掉 read 數不均）→ (2) 取 shared CpG 算 per-CpG Δ → (3) Δβ = 平均(Δ)，對 ~193 個 CpG 做 paired Wilcoxon（跨位點是否一致差異）→ (4) normal 當基線拆 cis vs drift。正因為是「篩選平均」，它量的是「整段一致的方向性位移」：方向型（如 BRCA2 Δβ=−0.122）抓得到；但前後反向的交叉型會被平均抵消（Δβ≈0、Wilcoxon p=0.438 NS）→ 這是 Δβ-mean 主排序的系統性盲點，需補分群(ARI)/max|Δ|/PERMANOVA 雙鍵（工程任務 #19）。

圖2舊 ISM（Cramér's V）vs 新 Δβ：為何同樣有 tag，舊方法抓不到

同樣的 tag（含 somatic 子標）、同一個 locus——差別在 分析指標的設計：舊＝無監督分群的類別關聯（Cramér's V，混淆且 tumor-only）；新＝方向性、somatic-controlled、normal-anchored、copy-partitioned 的 Δβ。
一句話結論：這不是缺資料（tag/normal 模組都在 binary 內），是方法學（指標設計）問題。舊 ISM 用 Cramér's V(cluster↔hp) 量「甲基分群是否關聯單倍型」——高值但被 germline-allelic 與 copy 混淆、無 normal、無方向，所以 BRCA2 不突出；新方法把對比重新定義成 HP1 vs HP1-1 方向性 Δβ ＋ normal-anchored cis ＋ copy-partition，才把 somatic-cis 訊號隔離出來（並誠實標出它其實小）。下一步工程＝把這指標接回 binary 的 SignificanceAnalyzer 重跑（任務 #19）。
