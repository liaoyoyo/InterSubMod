1A · HP 6 值分佈 (HP=0/1/2/11/21/33)

分析 6 個 BAM (HCC1395 baseline / HCC1395 V6 / HCC1937 V6 / HCC1954 V6 / H1437 V6 / H2009 V6) 在 chr8+chr19 (H2009 = chr19 only) 上每條 tagged read 的 HP:i tag 值分佈。 HP 6 值意義：HP=1/2 = germline-only 單純 HP1/HP2；HP=11/21 = somatic 對應 HP1/HP2 family；HP=33 = V3F-style conservative ambiguous (V6 啟用 "no-promote" 邏輯)；HP=0 (此資料無)；untagged = 未分配。

1D · germline-absent 區 baseline / V5 / V6 三方比較

結論: V6 在 germline-absent 區行為 = V3F-style 保守 (hp=33 firing ×60 = +14.1 pp vs baseline)， 避免 V5 Layer 1.5 在 germline-absent 區的設計缺陷。V6 在 ratio 上是 trade-off：以 ratio 從 1.14 (V3F) 退步到 1.84 換取 marker coverage +9.0% / hp=33 +4.7% / Layer 1.5 缺陷修補。

Attribution caveat: 不能單獨說「V6 修對 17.3:1」— 應標明「V3F (commit 41ff147) 主力修對；V6 在多維度價值 (marker eng + germline-absent 保守化) 改善 vs V5」。
