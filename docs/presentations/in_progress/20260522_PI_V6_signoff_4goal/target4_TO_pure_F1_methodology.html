PI Q&A (4 題預備) ⭐⭐⭐ L3

從 A4 報告 §A.2 (PI 必問問題標準答案) 抽取 4 題；點擊展開查看完整答案。

Q1 — 為什麼不用 Random Forest / XGBoost？

A4 已測。100 fold (4 algo × 5 sample × 5 seed) overall mean ΔF1：

  • LR: −0.00004 ± 0.00005
  • DT: +0.00255 ± 0.00573
  • RF: +0.00267 ± 0.00512
  • XGB: +0.00102 ± 0.00235

全部低於 Cohen +0.005 small ribbon。沒有 algorithm 達到「5/5 sample positive」的 production filter 條件。換 model class 不是這個問題的解。 [source: A4_summary.json:220-256]

Q2 — 跨 algorithm 比較公平嗎？hyperparameter 有 tune 嗎？

用文獻常用 default：

  • DT: max_depth=5, min_samples_leaf=100
  • RF: n_estimators=200, max_depth=8, min_samples_leaf=50
  • XGB: n_estimators=200, max_depth=6, lr=0.1

未 per-sample tune（會引入 hyperparam leakage，因 held-out τ 已是 oracle）。5 random seed (42, 7, 100, 999, 2026) 排除 single-seed artifact。Cohen ±0.005 ribbon 保守設定下 4 algo 全 ribbon-null。 [source: A4 markdown §2.2-§2.3]

Q3 — HCC1395 上 DT/RF +0.013 為何不算成功？

該 +0.013 是 LR 無法 capture 但 tree-based model 能 capture 的 non-linear interaction，僅出現於 1/5 sample。

HCC1395 是 cycle 1 development sample — train pool 中 4 sample 可能 share 部分 batch effect（同一 lab pipeline，同 caller_af 分佈區段）。其餘 4 sample 全 algorithm 共通失敗 → 此 +0.013 也屬 partial circularity（in-distribution capacity, not generalize ability），不構成 production filter 依據。 [source: A4 markdown §5.2 Layer B]

Q4 — train-test gap +0.48 看起來很大，是不是 overfit？

表面看 LR HCC1937 gap = +0.4841 似 overfit；但 DT/RF/XGB HCC1937 gap 也都 ≈ +0.48：

  • LR: +0.4841
  • DT: +0.4854
  • RF: +0.4845
  • XGB: +0.4852

差距 < 0.002。如果是 model overfit，high-capacity model gap 應更大；實測四者等價 → gap 來源是 caller_F1 baseline asymmetry（HCC1937 = 0.37 vs 其餘平均 ≈ 0.83）的計算 artifact，非 model 變異。LR 並未 underfit。 [source: A4 markdown §4.1-§4.2; A4_summary.json gap_mean fields]
