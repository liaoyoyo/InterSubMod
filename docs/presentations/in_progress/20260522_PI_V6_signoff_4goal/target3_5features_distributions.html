3A.5 features individual boxplot

4 core features (caller_af / loh_inner_flag / Coverage_Multiple / NG) TP vs FP 分布， 每 sample 一個 panel；每 panel 標 AUC + Cohen's d。本節為 static 主圖， 互動版見 §3D Plotly cross-sample bar。

⚠ Caveat · loh_inner_flag 是 binary feature {0, 1}，boxplot 不適用
下方 Figure 3A boxplot grid 中 loh_inner_flag 的 TP/FP median 都 = 0 (一條線)， 這是 binary feature 的 boxplot artefact 不是 feature 失效。 訊號在 prevalence (inner% 比例差)，請看 §3A.1 grouped bar 或 §3C 9-cell heatmap 判讀。 AUC + Cohen's d 是正確 metric (5/5 sign-consistent ⭐3 anchor)。
Figure 3A · 4 core features × 5 樣本 TP/FP boxplot。每 panel 標 AUC + Cohen's d。 Blue = TP，Red = FP。 [source: figures/A3_5features_boxplot_per_sample.png]
L2-3A.1 為什麼 caller_af HCC1395 出現 AUC=0.924？

HCC1395 為 5% 低 tumour purity (tumour-in-normal dilution)；TP 真實 AF≈0.05 但 ClairS-TO 模型 會 boost 至 median 0.43；FP germline tail median 0.11 → TP 大幅高於 FP。 此 AUC 不能跨樣本推廣 — HCC1937 (high purity) 反向。

[source: A3_per_feature_AUC_cohend_5sample.tsv:2 (TP_median=0.4262, FP_median=0.1147), line 11 (HCC1937 TP_median=0.3262, FP_median=0.9931)]

L2-3A.2 loh_inner_flag 為 binary 0/1，boxplot median 全為 0 — 怎麼解讀？

median=0 是 boxplot 的 binary 特性 (大多數變異點 outer-LOH)；訊號在 mean-shift 與 prevalence。 Cohen's d 為 mean diff / pooled sd，能量化 binary feature 的分布偏移：

  • HCC1395 d=0.88 → TP inner 比 FP inner 比例顯著高
  • HCC1937 d=0.93 → 同向
  • HCC1954 d=0.29 (最弱但同向 — high-purity small-FP-pool)

正確視覺化見 §3A.1 grouped bar (TP-inner% vs FP-inner% per sample)。

[source: A3_per_feature_AUC_cohend_5sample.tsv:3,12,21,30,39]

結論 · caller_af 不可直接 pool 5 樣本作 filter feature
Direction 由 tumour purity × ClairS-TO model behaviour 結構性決定 (HCC1395 5% purity → model boost AF；high-purity samples → FP germline tail occupies high-AF)。 cycle3 filter 必 per-purity stratify 或 per-sample LR fit (cycle 4 LOSO 已 confirm pool-LR 抹平訊號)。

4.Caveats / 已知 limitation

  1. Mann-Whitney p-value 全趨 0 · 因 5 樣本 n>1k 級別，p-value 普遍 <0.001； 本報告以 Cohen's d magnitude (≥0.5 strong / ≥0.2 small) 為主要判讀依據， 不用 p-value 作 filter 設計依據。
  2. Methylation 5 sub-features individual AUC ≤ 0.63 marginal · confirm cycle1 step0 「pure ISM feature 上限 ~0.58 ceiling」；HPFineF 為 methylation 最強但仍邊際。 cycle3 ablation 需量化整合到 filter 後的 ΔF1 contribution。
  3. HCC1954 / H1437 / H2009 FP 量極小 (687 / 773 / 1,342)，部分 9-cell n_FP=0 → TP-rate=1 為 trivial；解讀必看 n_total 欄。
  4. 本分析無 within-LOH OLS residualization · AUC 為 unadjusted。 若要宣稱「feature X 獨立於 LOH/AF 之外仍有訊號」必續跑 /auc-confound-guard (within-group OLS + AF-bin 交叉 + permutation)。本報告純 descriptive，不做 independence claim。
  5. NG bin NG≤2 合併 NG=2 · NG=0/1 為 missing 表示，與 cycle1 step1 命名一致。
  6. caller_af direction 不可推廣 · §3E 已 formal documented； cycle3+ filter 設計需 per-purity stratify。
  7. Tier upgrade ≥ ⭐3 需求 · 若要 claim「9-cell FP enrichment 為跨樣本 reproducible」 → 必跑 /auc-confound-guard 三關 + 引入 5 樣本以外 4 個 held-out (V3F/V5 paired) + per-sample stratified LR fit 對 caller_af。
