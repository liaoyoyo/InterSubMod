📝 講稿 · S5 4-algorithm LOSO · 120 秒（最關鍵）

問題 framing（20 秒）

本週最重要的問題：能不能用算法（不限 LR）+ 特徵組合，在 tumor-only 設定下做出超過 caller F1 且能 generalize 到 5 樣本的 filter？

實驗設計（30 秒）— 為什麼用 4 個 algorithm

  • 原本 LR fail 大家會問「是不是 LR 線性假設不夠？」
  • 所以我們跑了 LR / Decision Tree / Random Forest / XGBoost 4 種，覆蓋 linear → tree-based → ensemble
  • 5 random seed（42, 7, 100, 999, 2026）排除 single-seed artifact
  • 5-sample LOSO × 5 seed = 100 fold per algo, 400 fold total

結果（30 秒）— 真實數字（TSV 重算）

「4 algo overall mean ΔF1：LR −0.00004 / DT +0.00255 / RF +0.00267 / XGB +0.00102。全 < Cohen +0.005 small ribbon。500 fold 中只有 3 個 algo×sample cell 突破 +0.005：HCC1395 上 DT (+0.01378) 與 RF (+0.01269)，加上 HCC1937 上 XGB (+0.00562)；其他 17/20 cell 全 ribbon-null。」

Mechanism: 100% sample-level circularity（30 秒）

cycle 1 在 HCC1395 self-train 看到 +0.02236，LOSO 後 −0.00012 → drop +0.02248。100% of cycle 1 effect 來自 sample-level circularity，沒有任何成分來自 generalizable signal。

caveat: HCC1395 是 development sample。HCC1395 + DT/RF +0.013 是 in-distribution capacity，partial circularity（train pool 4 sample share batch effect）→ 不構成 production filter 依據。HCC1937 XGB +0.006 為 ribbon edge，5 seed CI 跨 ribbon (95% CI [−0.001, +0.012])。

結論

不是 model class 的問題，是 5 樣本 distribution shift。換 LR→DT→RF→XGB 救不回。S6 NO-GO 基於 mechanism level 證據（500 fold 全 ribbon-null + 100% circularity decomposition），不是表面 fit。

A4-Ext · 其他 6 algorithm 為何不試（PI Q1）

  • Ensemble (LR+RF voting): 0 + 0 voting lower bound ≈ 0 — 兩個 base 都 ribbon-null 投票不會翻
  • Calibration (Platt / isotonic): F1 monotone re-mapping invariant — 不動 ranking 不改 F1
  • Per-AF-bin LR: caller_af 是 collider bias — 切 bin 反而 condition on collider
  • Boolean rule: cycle 3 已試 +0.01499 marginal — 同 in-distribution capacity 範圍
  • Per-zone LR / Threshold-only: vote 3/5 — Cycle 5 optional probe（pivot Path D）

非知識庫背景概念（PI 不一定知道）

🔬 longphase-TO 機制相關

  • priority bug: longphase-TO 在 read 上找不到 germline het 位點可投票時，hardcode 預設 HP=1（而非 HP=0 unphased）→ 在 germline-absent 區域形成 17.3:1 systematic bias
  • HP tag 6 值: HP=0 (unphased) · HP=1/2 (paired-germline) · HP=11/21 (self-phasing somatic) · HP=33 (V6 Layer 1.5 ambig conservative bucket)
  • V6 Layer 1.5: V3F-style hybrid + HP=33 conservative bucket，讓「不確定」位點不被偏 HP=1，而是落 ambig bin
  • paired truth: paired-mode caller（normal + tumor 同時）提供的真實 haplotype label，作為 tumor-only 模式的 ground truth
  • SP1/2/3: chr19 priority bug spotlight 三個 cherry-picked 個案 (IGV verified 113:0 / 109:1 / 108:0)，作為 17.3:1 bias 的視覺鐵證
  • ALT-only ratio: 只計 ALT allele reads 的 HP1:HP2，比 all-reads ratio 對 priority bug 更敏感（ALT 只占 ~5% 但完全暴露 bug 訊號）

📊 ISM region-level 指標

  • ISM = InterSubMod，本專案區段層 (region-level) 分析框架，把 BAM read 聚合成 marker / NGroups / methyl 等統計
  • NGroups (NG): read 在區段內被分成的 haplotype-like 群數（2 / 3 / ≥4），是 phasing 深度指標
  • 4-way comparison: baseline / V3F / V5 / V6 四個 BAM 版本同表並列，避免單一指標 cherry-pick
  • marker count / rate: 區段是否有 phase-informative marker；rate 是 marker / region 比例
  • HP1:HP2 ratio offset: region 端統計 HP1 vs HP2 reads 比，理想 LOH 為 1.5:1 左右
  • LOH-positive marker rate: region 落在 LOH 區的 marker 比例
  • net TP:FP: 區段所有 marker 中 TP 對 FP 的淨比（V6 14:1）
  • hp=3 ambig reads: V6 Layer 1.5 在 region 端正確標 ambig 的 read 數（V6 firing 證據）

📈 Feature / statistics 概念

  • Cohen's d: 標準化 effect size = (mean_TP − mean_FP) / pooled_SD；常用閾 0.2 (small) / 0.5 (medium) / 0.8 (large)
  • sign-consistent N/5: feature 在 N 個樣本上 Cohen's d 同號（同向），5/5 為跨樣本通用
  • direction-flipping: feature 在不同 sample 上 d 反向（e.g. caller_af HCC1395 +1.33 vs HCC1937 −1.46）→ 無法 cross-sample train
  • loh_inner_flag: region 是否在 LOH 區域「內側」（不貼邊界）的 binary feature（0/1）
  • caller_af: caller 自己估計的 allele frequency；本研究中 direction-flipping 主因
  • HPFineF / NME_imbalance / ClusterPermanovaF: 9 個 ISM-derived features 中的細粒度 HP / methylation entropy / cluster PERMANOVA F 統計
  • collider bias: 在因果鏈下游 condition 反而引入 spurious correlation（如 per-AF-bin LR）

🤖 ML / methodology 概念

  • LOSO = Leave-One-Sample-Out cross-validation：4 樣本訓練 + 1 樣本 hold-out，重複 5 次每樣本當 test 一次
  • ΔF1 = filter F1 − caller F1，> 0 表示 filter 有 net 改善
  • Cohen ribbon: ±0.005 (small) / ±0.01 (medium) / ±0.02 (large) ΔF1 effect size 閾值，作為 production filter 標準
  • sample-level circularity: 訓練與測試 row 來自同一 sample → 模型可學該 sample 特異 pattern → in-distribution 高 ΔF1 全部 collapse on LOSO
  • distribution shift: 樣本間特徵分布不同（如 caller_af direction 反向），訓練樣本學的 weight 無法 generalize
  • in-distribution capacity: 模型在訓練 distribution 內 fit 的能力，與 generalize ability 是兩件事
  • LR / DT / RF / XGB: Logistic Regression / Decision Tree / Random Forest / XGBoost — 4 個常見 ML algorithm，本研究全 ribbon-null
  • 5 seed × 100 fold: 5 random seed × 5 sample LOSO × 4 algo = 500 fold total per experiment
