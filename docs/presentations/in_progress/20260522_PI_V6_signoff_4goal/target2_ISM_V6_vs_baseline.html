Q5 · 350 個 Lost TP regions 深度分析

關鍵發現：350 個 lost TP 全部 (100%) 在 LOH=NA，97% 的 V6 NG_off = 2（剛好差 1 個 bucket 沒過 threshold）。V3F 在同 region 仍保留 327/350 = 93% 作為 marker — V6 因 hp=3 保守化把 V3F NG 推到 boundary 以下。

機制詮釋：V6 hp=3 保守化把這些 LOH=NA、高 AF clonal region 的 HP-tagged reads 拉回 ambig bucket，NG count 從 3 降到 2。這是 V6 的設計取捨 — 在 LOH=NA 區為了保守化 ambiguous tag，犧牲 boundary marker。不是 bug。

對 V6 production tag scope 的影響：Lost 350 TPs 全在 LOH=NA boundary，V6 production tag 適用 scope（LOH-positive regions）不受影響。Net gain +7,693 TPs vs net add +549 FPs (TP:FP = 14:1) 為極度有利交易。

反例搜尋 Verdict：無 critical 反例。V6 的失分都是「邊界 / 非主要適用範圍 / 設計取捨」，主結論 V6 > baseline 不被推翻。建議將反例分析寫入 PI sign-off email 作為「我們也誠實地檢查 V6 失分的地方」transparency 證據，強化結論可信度。

V6 反向 stratum 共同特徵

  • AF：sub-clonal (AF < 0.1) — NG≥3 filter 設計上不適用
