[開場] 這張投影片要解釋 17.3:1 偏移不是噪音、不是 cnLOH artifact，是系統性 bias。 [主軸] 三條獨立論證互相補強： 1. 生物學：23 條染色體不應同向； 2. cnLOH 只影響單 chr，無法解釋 23/23； 3. Paired mode 對同一份 BAM 重 phasing → 1:1，證明問題在 TO mode 的 phasing 路徑。 [結論] 這是 LongPhase-TO 工程 bias，下一張投影片進入 chr19 SP1/2/3 個案 IGV 鐵證。
