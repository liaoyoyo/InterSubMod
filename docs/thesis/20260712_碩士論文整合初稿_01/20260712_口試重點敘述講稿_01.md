## 投影片 1｜研究問題：bulk 比例不足以直接決定演化樹

**畫面 assertion**：`同一組 bulk VAF 可以對應多種演化結構；長讀的價值是增加物理 linkage，而不是自動產生真實 clone tree。`

**建議圖**：`figures/01_research_narrative_map.svg` 左半部。

**講稿（約 1 分 40 秒）**：

> 腫瘤不是單一細胞群，而是多個遺傳上不同的族群混合。傳統 bulk 方法通常由每個突變的 read counts、VAF、purity 與 copy number 推估 cellular prevalence，再做 mutation clustering 或 tree inference。這些方法很重要，但它們主要從群體比例反推結構。
>
> 問題是，一組相近的 VAF 並不保證突變出現在同一群細胞，也不保證一個突變一定早於另一個突變。copy number、normal contamination 與 mutation multiplicity 也會讓 VAF 與 cell fraction 之間不是一對一。
>
> ONT 長讀提供一個新的觀察角度：我可以直接看同一條 DNA 分子上哪些 sSNV 共現，而且同一條 read 還可能帶有 haplotype 與 modified-base tags。但我要先強調，增加 evidence 不代表自動得到生物真相；它只是在明確條件下縮小可行解空間。

**轉場**：

> 因此我的研究問題不是「如何畫出最漂亮的一棵樹」，而是「如何讓每一棵輸出的樹都能回答它從哪個 evidence 來、還有沒有其他同樣可行的解」。

**不要說**：長讀能直接讀出 clone；VAF 方法都不可靠。

## 投影片 3｜相關方法不是同一個排行榜，而是不同 evidence regimes

**畫面 assertion**：`Caller、CCF clustering、global phylogeny 與本研究的 regional linkage 解不同問題。`

**講稿（約 1 分 50 秒）**：

> 我把相關方法分成四層。第一層是 ClairS 或 DeepSomatic 這類 somatic caller，回答某個位點是否有 somatic evidence。第二層是 LongPhase 與 LongPhase-S，回答 read 的相位與 somatic haplotype evidence。第三層是 PyClone-VI，利用 read counts、purity 與 allele-specific copy number 推估 mutation clusters 和 cellular prevalence。第四層像 PhyloWGS 或 Pairtree，進一步做全域 phylogeny inference。
>
> 本研究不是取代這些工具。我使用 caller 與 haplotagging 產生輸入，再用同一 DNA 分子的 sSNV 共現建立局部相容候選集。PyClone-VI 則作為 conditional sensitivity analysis，而不是 gold truth，因為它不輸出演化樹，而且仍依賴 CN、purity 與模型假設。
>
> 換句話說，我比較的是 evidence regime 與 estimand，不是把不同任務硬排成單一性能排行榜。

**可能追問**：「為什麼不直接用 PyClone/PhyloWGS？」  
**短答**：

> 它們從群體頻率與 CN/purity 做統計推論；我的方法利用 same-molecule physical linkage。兩者互補，且我的輸出是 regional candidate set，不是 global CCF tree。

## 投影片 4｜Input contract：先保證資料角色，再談演算法

**畫面 assertion**：`Canonical tree input 是 normalized raw-all 經 LongPhase-S 重校準後的同 run _sc.vcf PASS。`

**建議圖**：`figures/02_layered_evidence_pipeline.svg` 上半部。

**講稿（約 2 分）**：

> 方法的第一個工程重點不是 tree solver，而是 input contract。2026 年 7 月的 audit 發現，如果只把原始 ClairS PASS 當 LongPhase-S universe，就會漏掉 LongPhase-S 能夠從 non-PASS rescue 回 PASS 的位點；如果使用歷史含 truth-BED 的 tagged BAM，也可能把 benchmark scope 帶進 production analysis。
>
> 因此我把 canonical chain 固定為：paired ClairS raw-all biallelic sSNV，先正規化，再讓 LongPhase-S 做雙向 recalibration，最後由同一次 run 的 `_sc.vcf PASS` 作 primary tree input。ClairS PASS 只保留為 sensitivity analysis。
>
> 每個 caller record 都必須在 all-site ledger 中有唯一 disposition。missing、extra、duplicate conflict、truth flag leakage 或 sidecar identity mismatch 任何一項出現，流程就 fail-closed，不會默默 fallback 到舊 BAM tags。

**轉場**：

> Contract 決定哪些位點能進來；下一步要決定分析的單位是什麼。

## 投影片 5｜分析單位：region × mutation-bearing HP family

**畫面 assertion**：`HP1/HP2 只切 allelic family；它們不是父母來源，也不是 clone label。`

**講稿（約 1 分 50 秒）**：

> 我先把相鄰 sSNV 距離不超過 50 kb 的位點連成 connected component。要注意的是，50 kb 是相鄰 gap 門檻，整個 region 的總 span 可以大於 50 kb。
>
> 在每個 region 內，read 依 LongPhase-S 的 HP tag 分到 mutation-bearing HP1 或 HP2 family。無 trio orientation 時，HP1/HP2 只是兩條 homologous haplotype 的任意標籤，不能叫父系或母系。HP3、HP4 與 extended states 保留作 auxiliary evidence，不進 primary lineage denominator。
>
> 所以 primary unit 是 region × HP family。root-only family 是 reference control，不是 lineage。這個定義把「allelic partition」與「cell clone」分開，避免最常見的語意跳躍。

**可能追問**：「同一 HP family 難道不就是同一 clone？」  
**短答**：

> 不是。同一 homolog 上可以累積多次、跨多個 subclone 的 somatic events；HP 只提供 allelic background，不提供完整 cell identity。

## 投影片 6｜形式化：read–mutation matrix 與 rooted compatibility

**畫面 assertion**：`Reads 提供 terminal mutation states；hidden state 是數學補點，不是未觀察到的 clone。`

**講稿（約 2 分 10 秒）**：

> 對每個 unit，我建立 read × mutation matrix。每一格至少區分 read 支持 ALT、支持 REF，或因 coverage／quality 無法判定。每條 read 的 mutation pattern 形成 observed terminal state，全零向量作 root reference。
>
> 在 rooted all-zero、0 到 1 單調累積的模型下，若一對 characters 同時出現 `10`、`01`、`11`，就違反 rooted three-gamete condition。這個用語很重要；只有把 `00` root 也另外算進四種組合時，才可稱 root-augmented four-gamete framing。
>
> Solver 可以加入 hidden mutation states 連接 observed terminals，但這些 hidden nodes 只是 Boolean state space 的 Steiner-like graph states。它們不是我們實際觀察到的細胞，也不能直接命名為 hidden clone。

**轉場**：

> 有了可行狀態後，真正的關鍵是如何處理多解。

## 投影片 7｜域內完整列舉與誠實拒絕

**畫面 assertion**：`Determined 只表示宣告域內恰一個 recurrence-free 最小解；多解、recurrence-required 與 capped 都是正式輸出。`

**建議圖**：`figures/06_worked_candidate_tree_example.svg`（只裁右半部候選樹也可）。

**講稿（約 2 分 20 秒）**：

> Solver 的目標不是找一棵分數最高的樹，而是先最小化連接完整與 partial observations 所需的額外 mutation-state nodes，再對所有最小節點集列舉每個合法 unit-predecessor parent choice。接著我分開記錄 exact ordered tree `T` 與不含 state label 的 topology `Topo`，因為兩者回答不同問題。
>
> 「完整」有明確適用域：每個 solver unit 最多 8 個 sSNV，也就是最多 256 個 Boolean states；額外 states 最多 4 個，每一層最多檢查 150,000 組合。Analytical tree cap 設為 0，代表不截斷分析候選；32 棵只限制畫面顯示。任何一個 cap 被觸發，就只能標 `capped`，不能宣稱 complete 或 determined。
>
> 我只在 recurrence-free minimum solution 恰好一棵、candidate set 完整且 V1–V7 通過時使用 `determined`。如果有多棵，就完整保存 candidate set；如果所有最小解都需要 recurrence，就標 `recurrence_required`；如果 analytical set／required artifact 不完整或超出計算域，就分別標 underdetermined／incomplete 或 capped。這些不是錯誤碼，而是 identifiability 與 pipeline refusal 的正式結果。
>
> 這個設計的資訊工程價值，在於演算法不能把 preference 偽裝成 certainty。VAF 可以在既有候選內作探索排序，但 selection 不等於 confirmation，也不能把排序後的形狀稱為 posterior probability 或 accuracy。

**可能追問**：「為什麼不直接挑最合理的一棵？」  
**短答**：

> 因為若多棵樹在 read constraints 下同樣可行，任選一棵只反映 heuristic，而不是資料識別出的生物結論。域內完整候選集讓後續獨立證據可以真正消歧；域外則保留 capped reason，不假裝完整。

## 投影片 9｜Raw VAF 的主要結構跨技術來源高度再現

**畫面 assertion**：`HCC1395 兩技術來源的主要 raw-VAF 結構高度一致，但每位點並非完全相同。`

**講稿（約 2 分）**：

> 我用 HCC1395 與 HCC1395_DORADO 這兩個同 cell line、不同技術來源的資料檢查 technical reproducibility。Latest LongPhase-S PASS universe 的 union 是 82,705 個 alleles，exact shared 是 76,721，Jaccard 為 0.9276。對 shared alleles，CCC 是 0.9339、Spearman 是 0.9093、MAE 是 0.0624；93.07% 的差值落在簡單 independent-binomial 95% band 內。

**短答**：

> 不是。這是兩份技術資料的 VAF 差是否落在簡化 binomial sampling band，既不是 variant accuracy，也不是 tree accuracy。

## 1 分鐘極短版結論

> 本研究利用 ONT 長讀在同一 DNA 分子上的 sSNV 共現與 haplotype family，建立區域 mutation-state candidate trees。主要工程創新是完整的 input contract、all-site ledger、域內最小候選解列舉與 fail-closed refusal。Producer 已 7/7 完成；solver 只有 legacy HCC1395 audit，4,000-stress headline 已因 counter flaw 撤回，fresh verifier 也仍 FAILED。HCC1395 跨技術 raw VAF 高度再現，但 PyClone minor membership 只中度一致。因此我把結論限制在待完成驗證的 regional hypotheses，而不是 confirmed biological clone genealogy。

## 口試常見問題與回答

### Q1. 你的方法到底是在重建 clone 還是 haplotype？

> 都不是直接等同。HP 用來切 allelic family；solver 在 family 內重建 regional mutation-state candidate trees。它們可產生 clone hypotheses，但沒有 cell-level truth 時不能稱 confirmed clones。

### Q2. 為什麼 region 用 50 kb？

> 50 kb 是相鄰 sSNV 的連接門檻，目的是在 read linkage 與計算狀態空間之間取得 operational balance；不是宣稱生物事件只有 50 kb。終稿應以 sensitivity analysis 檢查不同 gap threshold。總 region span 可能大於 50 kb。

### Q3. 你的 hidden state 有什麼生物意義？

> 它是連接 observed terminal states 所需的最小相容 mutation state，是 graph/Boolean-space object。它可能形成 biological hypothesis，但本身不是已觀察細胞或 clone。

### Q4. Solver 0 fail，為什麼不說 100% accuracy？

> 因為 verifier 與 solver 共享同一形式規格，0 fail 證明 implementation consistency。Biological accuracy 需要獨立 truth，兩個 estimands 不同。

### Q5. VAF 能不能幫你挑出正確的樹？

> VAF 可以在 read-compatible candidate set 內作 exploratory ordering；但未完整校正 purity、CN 與 multiplicity，而且來源仍是相同 reads，因此 selection 不是 independent confirmation。

### Q6. 為什麼不把 PyClone-VI 當外部驗證？

> 它可作 conditional external model sensitivity，但不是 gold truth。它依賴相同 variant counts、purity/CN 假設，且只輸出 mutation clusters/CCF，不輸出 phylogenetic tree。

### Q7. 98% overall PyClone agreement 不是很好嗎？

> 這個值被約 98% clonal-majority 位點支配。對真正關心的 subclonal set，Jaccard 只有 .381；因此我報 subgroup denominator，而不只報 overall。

### Q8. 甲基化為什麼最後沒有成為主角？

> 因為 filter/rescue/ranking 的 cross-validation effect 沒有穩定成立。保留它作 bounded characterization 比為了故事完整而過度宣稱更符合科學工程原則。

### Q9. HP1/HP2 是父系和母系嗎？

> 沒有 trio 或外部 orientation 時不是；它們只是兩條 homologous haplotypes 的任意標籤。

### Q10. HCC1395 與 DORADO 可以叫 replicate 嗎？

> 只能叫同一 cell line 的不同技術資料來源，用來評估 technical reproducibility；不能當獨立 biological replicates。

### Q11. 為什麼 clean-v3 沒完成還能寫論文？

> 研究問題、資料契約、形式模型、演算法與工程驗證已可審閱；全樣本 workers 雖完成，但 final verifier 已 terminal FAILED，因此我把 topology 部分明示為 blocked，而不是用未 release 或歷史資料替代。這份是整合初稿，終版 Result freeze 需修復後的 `_SUCCESS` 與 U0–U7 receipts。

### Q12. 這篇論文最像哪個資訊領域問題？

> 它同時包含 typed data contracts、constraint satisfaction、complete solution enumeration、uncertainty representation、fail-closed validation 與 reproducible scientific software。

### Q13. 你的方法有 NP-hardness 證明嗎？

> 本論文不做這個過度延伸。Foulds–Graham 的 theorem 是一般 unrooted/undirected minimum-Hamming Steiner decision problem；本研究解的是 rooted、monotone、bounded/capped compatible enumeration，不能直接套用同一 complexity claim。

### Q14. 如何真正證明一棵 candidate tree？

> 最直接的是 single-cell genotype 共現、multi-region 或 longitudinal samples，並配合獨立 allele-specific CN/purity。這些證據可以在不重用相同 read-derived ranking 的情況下消歧。

### Q15. 你的主要 negative result 是什麼？

> 兩個：methylation filter/ranking 沒有穩定泛化；其次，HCC 主要 VAF structure 高度再現，但 independent PyClone minor membership 只有中度一致。兩者共同支持保守的 candidate-tree claim ceiling。
