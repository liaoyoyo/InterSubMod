① 新方向 / 新題目（這是「要聚焦與說明」的最新主軸）

ISM = 首個於 ONT 長讀 tumor/normal paired 資料、整合三件事於 read 層級的軟體：① read 層次甲基結構檢定（距離→分群→PERMANOVA）+ ② matched-normal-anchored somatic cis-test（殘差+d_cis/d_drift/d_within 分解）+ ③ somatic-subclone 目標。

新穎性 = 三者於 tumor/normal read-level 的「整合」（個別元件皆有前例：qFDRP 距離核、Do2020 de-novo ASM 亦用 matched-normal、Sgootr 距離式甲基重建）→ 距離/read-level 甲基本身不是新穎。

貢獻 = 量化 somatic 變異與甲基位點的「關聯強度」；甲基↔突變因果機制歸既有文獻背景（SBS1/5mC deamination，citation 待補），ISM 不宣稱因果/順序。

措辭收斂（framing 凍結裁決）：用 「characterize methylation-associated subclonal structure conditioned on somatic haplotags」，非「reconstruct subclones using methylation」。標題仍保留。
