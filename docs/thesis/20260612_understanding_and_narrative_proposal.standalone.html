① 研究故事（白話版 — 這是我對你研究的理解，請看對不對）

  1. 獨特條件：ONT long-read 能在同一條 read 同時讀到三種訊號——somatic 突變、germline 單倍型、甲基化（5mC）。這讓我們能在 read 層級問一個別人問不了的問題：腫瘤看到的甲基化差異，到底是 somatic（腫瘤新生），還是只是 germline（天生）/ 拷貝數 的假象？
  2. 缺口：過去文獻看到腫瘤「等位基因特異性甲基化（ASM）」很多，但 (i) 沒人在 read 層級把它跟 germline-allelic / copy 背景分開（de-confound）；(ii) 沒人公開證偽「甲基能不能拿來篩 somatic 變異真偽」；(iii) somatic-controlled 的 ASM 樣貌沒被界定。
  3. 主發現＝規則（de-confound floor）：用 ISM 掃 6 樣本 332,705 位點，可靠的甲基 read 分群只有 12,868（3.87%），而且壓倒性是 germline-allelic（跟天生單倍型走，不是 somatic）；816 個可測位點裡只有 1 個（chr17）是乾淨 somatic cis 候選；而且甲基完全不能篩 somatic 變異真偽（四道獨立證據）。→ 把看似豐富的腫瘤 ASM 誠實拆成「大多是 germline 背景」。🟢
  4. 例外：chr17/TBC1D16 這一個位點，somatic / 單倍型 / 甲基三訊號（同 pipeline）對齊同一 LOH 重塑事件；TBC1D16 剛好是已知癌症甲基化基因（hypo→EGFR 黑色素瘤轉移），生物學「一致」（非「證實」）。🟡
  5. 重建脊柱（標題的 reconstruction）：LOH 約束下，somatic haplotagging（genetic 引擎）把 read 分到子單倍型、重建 LOH-constrained 子克隆結構（方向 7/7、same-hap occupancy 6/6 ≥93%）。這是「reconstruction」的來源——由 genetic 骨幹完成、甲基是 characterize。
  6. 跨樣本：現象層 6/6 跨三癌種復現（excess-over-null +0.10–0.24），但同一位點是樣本私有（0/38）。
  7. 誠實天花板：甲基是 germline-haplotype 層級；subclone 層級能否用甲基判別還 undetermined（正確對照 G-B 沒跑）；單樣本/單 pipeline ⭐3。
  8. 交付：read-level de-confounded 癌症 ASM 目錄 + 誠實負結果（甲基不能 filter）+ 甲基輔助 phasing 的 tooling 展望。

② 論文要 carry 的一句話（候選 — 你最想讓讀者記住哪個？）

候選 A（建議 / 最防彈）— de-confound floor

「在 read 層級，腫瘤的甲基化分群主要跟隨 germline 而非 somatic、且不能用來篩變異真偽；我們把看似豐富的癌症 ASM de-confound 成一個誠實目錄，並標出唯一的 somatic 例外（chr17）。」

→ 全 🟢、今天可寫、最防 overclaim、Genome Biology tier。標題的 reconstruction 由 genetic 骨幹（R6）承載。

候選 B — 三訊號 co-validation 重塑

「long-read 讓 somatic／單倍型／甲基三訊號在 read 層級 cross-check 同一 LOH 子克隆重塑事件。」

→ 較吸睛，但 🟡 contingent（chr17 單 locus + by-construction + HD-1）；紅隊對「正交共驗證」措辭有意見（同 pipeline 非真正獨立）。

候選 C — 甲基輔助 phasing 的 tooling 潛力

「甲基化追蹤 haplotype 結構，開啟甲基輔助相位救援（held-out 0.885、非-copy 0.979≥0.866）。」

→ 這是 future tooling（第五章），單樣本，不適合當 carrying claim；當亮點補強可以。

③ 誠實天花板（不可違反 — 全文一致）

  • 甲基 = germline-haplotype 層級；分不同 haplotype 強、within-haplotype 弱。
  • 甲基絕非 variant TP/FP filter（死四道）。
  • subclone-甲基 somatic-specificity = undetermined（G-B null 未跑）；勿寫成已 NEGATIVE 也勿寫成已 POSITIVE。
  • chr17 = 最強 cis 候選非「乾淨」；乾淨 cis = 816 可測中僅 1（非 1/332,705）。
  • same-hap = occupancy 6/6 ≥93%；三訊號用「same-pipeline cross-check」非「orthogonal co-validation」。
  • single-pipeline / 單樣本 ⭐3 上限；reconstruction 只描述 genetic 骨幹，甲基一律 characterize。

⑤ narrative-frame N2 — 框架推薦（適合的敘述方式）

主框架（macro 弧，給摘要 + 緒論）= ABT + SCQA

「Long-read 能在一條 read 同讀三訊號（And），看似有豐富的腫瘤 ASM（And），但 read 層級它跟 germline 非 somatic、且不能篩變異（But），因此我們交付一個 de-confounded 目錄 + 唯一的 somatic 例外（Therefore）。」

理由：de-confound 故事天生是「看似…但其實…因此…」的 ABT 結構；SCQA 漏斗（Situation→Complication→Question→Answer）對齊論文 Intro 的 CARS，把「apparent ASM」當 Complication、「是 somatic 嗎」當 Question。MethPhaser/NanoMethPhase 也都用「However」當鉸鏈。

Results 骨架 = Rule + Exception 雙主軸 + Assertion-Evidence 標題

規則（de-confound floor：R1-R4,R7）→ 例外（chr17 + phasing 脊柱：R5-R6）；每節小標寫成「會說話的結論句」（如「甲基分群跟隨 germline 而非 somatic」）非 topic 標籤。

結論 = Verdict-Pyramid

先講判決（甲基能 co-validate、不能 filter），再層層證據。

備框架 / 不選

備：Duarte Sparkline（what-is vs what-could-be）——若想更凸顯 future tooling 可局部切換。
不選：Hero's Journey / 三幕劇——對 de-confound characterization 太戲劇、易 overclaim，與誠實天花板衝突。
