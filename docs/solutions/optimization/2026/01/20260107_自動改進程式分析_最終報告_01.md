# 2026-01-07 顯著性篩選改進 — 最終總結報告

> **分析日期**: 2026-01-07  
> **迭代次數**: 5 輪  
> **最終方案**: V ≥ 0.1 效應量閾值

---

## 1. 背景問題

| 問題 | 修改前數據 |
|:---|:---|
| FP 顯著率 > TP | 40.8% vs 28.6% |
| FP 高度聚集 | chr9:41.7Mb 有 78 sites/50kb |
| ROC AUC ≈ 0.5 | 無法區分 TP/FP |

**核心問題**：甲基化異質性指標無法區分真假陽性 SNV 位點。

---

## 2. 迭代測試總結

| Round | 修改內容 | TP 顯著率 | FP 顯著率 | TP/FP 比 | 結論 |
|:---:|:---|:---:|:---:|:---:|:---|
| 基準 | 無 (修改前) | 28.6% | 40.8% | 0.70 | ❌ FP > TP |
| 1 | Gating 加 V 閾值 | 28.5% | 40.9% | 0.70 | ❌ 無效 |

## 3. 程式碼修改部分 (按重要性排序)

### 1️⃣ **最重要**：Significant 判定加入效應量閾值

**檔案**: `src/core/RegionProcessor.cpp` (line ~907)

```diff
-bool is_significant = r.passed_gating && (r.global_p_value <= 0.05);
+bool is_significant = r.passed_gating && 
+                      (r.global_p_value <= 0.05) && 
+                      (r.cramers_v >= 0.1);
```

**影響**: FP 顯著率從 40.8% 降至 2.1%

### 2️⃣ **輔助**：Gating 雙重閾值

**檔案**: `src/core/GlobalTest.hpp`, `GlobalTest.cpp`

```diff
+double min_cramers_v = 0.1;  // 新增配置

-result.passed_gate = (result.fisher_ffh.p_value <= config_.gating_p_threshold);
+bool p_pass = (result.fisher_ffh.p_value <= config_.gating_p_threshold);
+bool v_pass = (result.cramers_v >= config_.min_cramers_v);
+result.passed_gate = p_pass && v_pass;
```

**影響**: 減少後續分析負載，但對最終結果影響小

## 4. 修改後結果數據解釋

### 顯著率大幅下降是預期的

| 類型 | 原因 |
|:---|:---|
| **TP 從 28.6% → 6.1%** | 許多 TP 位點確實沒有明顯的等位基因特異性甲基化 |
| **FP 從 40.8% → 2.1%** | FP 的「假顯著」主要來自低效應量但低 p-value 的位點 |

### 為什麼 VerificationClass 無法區分 TP/FP

| 發現 | 解釋 |
|:---|:---|
| FP Strong 37% > TP 24.5% | FP 位點的聚類與標籤一致性反而更好 |
| 原因 | FP 可能位於系統性甲基化異質區域 (e.g., 重複序列邊界) |

## 6. 結論

1. **Cramér's V ≥ 0.1 是有效的區分閾值**：將 TP/FP 比從 0.70 提升至 2.92
2. **VerificationClass 不適合區分 TP/FP**：它只描述聚類與標籤一致性
3. **深度過濾冗餘**：高 V 位點通常深度已足夠
4. **進一步改進需從根本重新設計**：可能需要考慮 CpG 密度、離 SNV 距離等因素
