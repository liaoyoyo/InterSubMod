你想確認：在你已列出的過濾、矩陣、距離、分群與檢定流程之外，**還有哪些「常見但容易漏掉」的特殊情況**，會讓輸出的顯著結果出現「TP 不夠多 / FP 偏多」或「和直覺、生物不一致」的現象。下面我用**實務上最常踩雷**的角度補齊。

---

## 一、統計檢定本身的「假顯著」來源（很常被誤判成生物訊號）

### 1) PERMANOVA 顯著其實是「群內離散度不同」造成（不是群間真的分開）

* **現象**：Label-first 顯著，但 heatmap 看起來像是某一組比較散、另一組比較集中，而不是兩群分離。
* **原因**：PERMANOVA 對「位置差異」與「離散度差異」都會反應；只要某一組變異比較大，就可能顯著。
* **建議補檢**：加做 **PERMDISP / betadisper 類型的 dispersion test**；或至少輸出各組的平均群內距離與其分佈，判斷是否是 dispersion 驅動。

### 2) 你在「挑 K、挑 metric、挑 window」後才做 p-value → 會有 selection bias（等於隱性多重比較）

* **現象**：Cluster-first 很容易顯著，或不同參數跑出來的「顯著位點」不穩定。
* **原因**：先用資料挑到最能分的切法，再用同一份資料做顯著檢定，p-value 會偏樂觀。
* **修正方向**：

  * 把「選 K / 選 metric」視為模型選擇，後面顯著性要更保守（例如用 bootstrap 外層重抽，或把 K 固定策略化，而不是以最佳化為主）。
  * 至少輸出 **effect size（R²、Delta、|Between-Within|）+ 穩定性**，不要只看 p。

### 3) 多重檢定與依賴性：跨 SNV/region 大量測試，且位點彼此相關

* **現象**：整體顯著比例偏高（FP 多），或顯著集中在某些區段。
* **原因**：同一區域多個 SNV、重疊 window、CpG 空間相關，會讓「有效測試數」遠小於名目數，常見 FDR 假設被破壞。
* **補強**：

  * 明確做 **FDR（q-value）**，並考慮 region-level 匯總（避免同一 locus 重複報）。
  * 用「permutation 生成的 null 分佈」檢查整體 p-value 是否過度偏小（QQ plot）。

### 4) 小樣本/高度不平衡分組時，p-value 會變得離散或不穩定

* **現象**：HP1 很少、HP2 很多時，PERMANOVA / Fisher 結果跳動大；或出現「少數那組剛好幾條離群 read」就顯著。
* **建議**：加上最小每組 read 數門檻、限制 group imbalance（例如最大/最小組比例），並把 **permutation 次數與可用排列數**輸出（小 N 時很重要）。

## 二、距離矩陣/缺失值處理帶來的「結構假象」（非常容易造成不直覺）

### 5) Group-specific missingness：兩組 reads 的「可用 CpG 數」系統性不同

* **現象**：看起來分群很漂亮，但其實只是某一組 reads 覆蓋的 CpG 多、另一組少；距離被 overlap 數量主導。
* **來源**：read 長度差異、clipping、mapping 差異、或 CpG 呼叫品質在某一組較差。
* **補強檢查**：

  * 每個 read 輸出：有效 CpG 數、uncertain(-1)比例、缺失比例。
  * 做一個簡單檢定：**label 是否可預測「有效 CpG 數」**（若能，顯著結果高度可疑）。
  * 距離建議做 **以共同有效位點數量正規化**，並設「overlap 太低直接排除」。

### 6) NaN/不可計算距離的填補策略會偷偷影響分群

* **現象**：同一批資料，某些 region 的 dendrogram/切群結果很怪，或不同版本跑出結果差很多。
* **原因**：NaN 被當 0、當最大值、或被忽略，都會改變樹。
* **建議**：把「距離矩陣缺失比例」「每個 read 的可比對對數」輸出成 QC；缺失過高直接標為不可判定（不要硬做顯著）。

### 7) outlier reads（嵌合、結構變異、錯配）主導分群 → Cluster-first 會變成「離群偵測器」

* **現象**：Cluster-first 顯著、穩定性也可能過關，但實際只是固定那幾條怪 read 一直被分出來。
* **補強**：

  * 加 robust/outlier 診斷：每條 read 的平均距離、最近鄰距離、是否長期落單。
  * 若「顯著來自很小一群」且 effect size 不大，優先標記為 artifact 候選。

## 三、標籤與分組邏輯的生物/技術特例（會直接造成 FP 或 FN）

### 8) HP/PS 相位資訊混用：同名 HP 但不同 phase set（PS）其實不可比

* **現象**：HP1 vs HP2 做 Label-first 時顯著或不顯著都很怪、不同區域結果不一致。
* **原因**：PS 不同代表相位區塊不同，HP1 在不同 PS 之間不一定是同一條染色體來源。
* **建議**：Label-first 分組要用 **(PS, HP)** 作為分組單位，或至少要求同一個 region 內 PS 一致，不然等於把不同相位塊混在一起。

### 9) ALT/REF 支援判定與 mapping bias：不同等位 reads 的比對品質/剪切比例系統性不同

* **現象**：Allele label 顯著，但同時看到 ALT 組 mapQ 較低、softclip 較多、read 長度較短。
* **原因**：reference bias、附近重複序列、或 indel 造成 ALT reads 更難對位，導致甲基化呼叫/覆蓋結構不同。
* **補強**：把 mapQ、clipping%、identity、aligned length 這些當作 QC covariate；若與 label 強相關，顯著結果要降權或剔除。

### 10) 「SNV 改變 k-mer → 甲基化呼叫模型偏差」：看起來像 ASM，其實是 caller 的序列脈絡偏差

* **特別重要（長讀常見）**：很多甲基化模型（尤其訊號模型）受附近序列影響；SNV 會改變 CpG 附近的 k-mer，可能讓同一 CpG 的 ML 分佈在兩等位系統性不同。
* **典型現象**：顯著主要集中在「靠 SNV 很近」的 CpG，離遠一點就消失。
* **建議**：

  * 把 CpG 依距離 SNV 分層（例如 0–10bp、10–50bp、>50bp）看訊號是否只在近端。
  * 設定「排除距離 SNV 太近的 CpG」作為敏感度分析（如果一排除就不顯著，極可能是模型偏差）。

### 11) 混合了不同 modification type 或標記（例如 5mC/5hmC 或 CpG/CpH）

* **現象**：某些 region 變得非常吵，或顯著但型態不像 CpG 甲基化。
* **建議**：確認 MM tag 中 modification code 有被嚴格篩選，只保留你要的類型（例如只看 CpG 上的 5mC）。

## 四、癌症資料的「生物混雜」特例（會讓結果不符合直覺，但其實合理）

### 12) CNV / LOH / allele imbalance 讓「等位分組」變成「拷貝數/亞克隆分組」

* **現象**：Allele-first 很顯著，但其實那個 allele 只存在某個亞克隆；你看到的是「亞克隆差異」不是純 ASM。
* **建議**：把每個 region 的 VAF、等位 read 數不平衡程度、是否落在已知 LOH/CNV 區段當作解釋變數。

### 13) tumor purity / normal contamination 造成群內混雜

* **現象**：同一個 label 裡面其實混了 tumor 與 normal reads，導致群內距離變大（PERMANOVA 可能因此顯著或反而不顯著）。
* **建議**：若你有 is_tumor 標籤，做分層：先在 tumor-only 跑一次、normal-only 跑一次，比對一致性。

### 14) imprinting / X-inactivation 等「本來就會 allele-specific」的現象（不是 somatic）

* **現象**：即使是 “somatic anchor”，仍可能因誤納入 germline 或靠近 imprinting 區域而出現看似 ASM。
* **建議**：對照 matched normal 或加上「是否位於已知 imprinting/X 相關區」註記（至少在論文討論要能解釋）。

---

## 五、我建議你在現有計劃上「必補」的 8 個 QC / 防呆輸出（直接降低 FP）

1. **PERMANOVA 的 dispersion 檢查**（或至少輸出各組群內距離分佈）
2. **每組 read 的有效 CpG 數 / uncertain 比例** + 檢定是否與 label 相關（偵測 missingness confounding）
3. **NaN 比例與可比對對數**（distance matrix completeness）
4. **mapQ / aligned length / softclip% 在各 label 的分佈差**（偵測 mapping bias）
5. **(PS, HP) 一致性**：同一 region 內 PS 是否混雜
6. **近 SNV CpG 敏感度分析**（排除近端 CpG 看顯著是否消失）
7. **effect size 門檻**（例如 PERMANOVA R²、Delta、Fisher 的 OR/φ）避免「p 很小但效應很小」
8. **負對照**：random shuffle label / 或使用預期不該有 ASM 的區域，確認 FP 率在可接受範圍

---

### 最容易造成「顯著但不直覺」的前三名（依經驗排序）

1. **PERMANOVA 被 dispersion 驅動**
2. **group-specific missingness（有效 CpG 數差異）**
3. **SNV 導致 methylation caller 的 k-mer 偏差（近 SNV 特別明顯）**
