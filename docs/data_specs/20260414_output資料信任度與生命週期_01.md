# Output 資料信任度與生命週期規範

## 1. 信任度等級定義

| 等級 | 定義 | 使用規則 | 標註方式 |
|------|------|---------|---------|
| **CURRENT** | 使用最新方法產出，結論可信，可直接引用 | 可用於新分析、報告、論文 | INDEX 表格 Status 欄 |
| **PRE-FIX** | Self-phasing 修正前產出，HP tags 可能受循環依賴影響 | **非 HP 欄位可用**（AF, GQ, DP, methylation statistics）；**HP 相關欄位不可信**（HPRatio, HPSig, effective_hp_reads, HP-based 分群） | INDEX 表格 + 備註 |
| **SUPERSEDED** | 被後續版本完全取代，僅供歷史回溯 | 不可引用於新分析；僅供了解歷史脈絡 | 搬至 archive/ 或 concluded/ |
| **DEPRECATED** | 已知錯誤或方法缺陷，結果不可信 | **禁止使用** | INDEX 表格 + 警告標記 |

### PRE-FIX 詳細範圍

**受影響的欄位**（依賴 haplotag BAM）：
- `HP_Ratio`, `HPSig`, `HP_Entropy`
- `effective_hp_reads`, `hp1_count`, `hp2_count`
- `HPFineNGroups`, `HPFine_*` 系列
- 所有 HP-based 分群結果
- `LOH` 判定（依賴 HP 比例）

**不受影響的欄位**：
- `AF`, `GQ`, `DP`, `QUAL`（來自 caller VCF）
- `mean_methylation`, `methylation_variance`, `epipolymorphism`（直接來自 BAM MM/ML tags）
- `n_reads`, `n_cpgs`（直接計數）
- `ClusterPermanovaP`, `ClusterPermanovaF`（基於甲基化距離矩陣）

## 2. 生命週期規則

### 信任度升級

| 觸發條件 | 動作 |
|----------|------|
| Haplotag 重跑完成 + ISM 重新分析 | PRE-FIX → CURRENT |
| 新 canonical run 完成 | 對應舊 run 不變（同 sample 不同日期共存） |

### 信任度降級

| 觸發條件 | 動作 |
|----------|------|
| 發現方法論缺陷 | CURRENT → DEPRECATED + 寫入 experiments INDEX |
| 新版本取代舊版本 | 舊版 → SUPERSEDED + 搬至 archive/ |
| 程式碼重構改變輸出格式 | 舊格式 → PRE-FIX 或 SUPERSEDED |

### 刪除安全度（Archive 專用）

| 等級 | 定義 | 建議 |
|------|------|------|
| **SAFE_DELETE** | 完全重複的執行（重試、命名變體） | 優先清理 |
| **LOW_RISK** | 結論已寫入 docs/，原始數據僅供極端回溯 | 確認 docs/ 報告完整後可刪除 |
| **KEEP** | 仍有潛在回溯價值（被 observation_workspaces 引用） | 暫不刪除 |
