> **版本**: v1.0 | **日期**: 2026-04-11

## 1. Canonical Run 結構

### 1.1 目錄階層

```
big7_disk_output/canonical/
├── {sample}/                     # 7 個樣本
│   ├── paired_full/              # Paired mode, full-call VCF
│   │   └── {run_id}/            # 時間戳 + 描述
│   ├── paired_pileup/            # Paired mode, pileup VCF
│   │   └── {run_id}/
│   └── to_pileup/                # Tumor-only mode, pileup VCF
│       └── {run_id}/            # 僅 HCC1395 有 TO 資料
```

### 1.2 樣本與模式矩陣

| 樣本 | paired_full | paired_pileup | to_pileup |
|------|-------------|---------------|-----------|
| HCC1395 | 6 runs | 有 | 有 |
| HCC1395_DORADO | 有 | 有 | — |
| COLO829 | 有 | 有 | — |
| H1437 | 有 | 有 | — |
| H2009 | 有 | 有 | — |
| HCC1937 | 有 | 有 | — |
| HCC1954 | 有 | 有 | — |

### 1.3 Run ID 命名格式

```
{YYYYMMDD}_{sample}_{mode}_{caller}[_{suffix}]
```

範例:
- `20260314_HCC1395_paired_full_full` — 標準 run
- `20260314_HCC1395_paired_full_full_complete_matrix` — 完整距離矩陣版
- `20260314_HCC1395_paired_full_full_1` — 同日流水號

### 1.4 Run 內部結構

```
{run_id}/
├── intersubmod_tp/               # TP 分析結果
│   ├── significance_summary.csv  # 核心彙總
│   ├── {vcf_name}/chr{N}/...     # Per-region 輸出
│   └── debug/                    # 除錯資訊
├── intersubmod_fp/               # FP 分析結果（同上結構）
├── benchmark/                    # TP/FP benchmark 結果
└── logs/                         # 執行日誌
```

## 2. Observation Workspace 結構

### 2.1 標準結構

```
{workspace_name}/
├── README.md                     # 概述、狀態、生成腳本（11/56 個有）
├── round_context.json            # 執行元數據
├── observation_report.md         # 分析報告
├── conclusions_for_git.md        # Git-friendly 結論
├── decision_notes.md             # 判讀註記
├── figures/                      # PNG 視覺化
└── data/                         # TSV/CSV 分析表
```

### 2.2 命名規則

#### 系統性觀察 (O-series)

```
{YYYYMMDD}_O{NN}[v{N}]_{topic}
```

範例:
- `20260401_O01_master_distribution` — 第一版
- `20260401_O13v2_cross_region_confound_control` — 第二版（confound 控制後重做）

#### LOH 研究系列

```
{YYYYMMDD}_loh_round{N}_{topic}[_{suffix}]
```

範例:
- `20260327_loh_round1_cross_sample_audit` — HP fix 後版本
- `20260327_loh_round1_cross_sample_audit_before_hp_fix` — HP fix 前版本

#### 一般工作區

```
{YYYYMMDD}_{topic}
```

範例:
- `20260402_phasing_causal_chain`
- `20260406_allele_deep_dive`

### 2.3 狀態後綴規則

| 後綴 | 意義 | 處理方式 |
|------|------|---------|
| `_before_hp_fix` | HP integer tag fix 前的版本，已被取代 | **不應引用**。對照用。 |
| `_post_to_hp_fix` | HP fix 後重跑版本 | 對照 before 版本使用 |
| `_post_hp_fix` | 同上（較早命名） | 同上 |
| `_smoke` / `_smoketest_*` | 小規模測試用 | 不可引用 |
| (無後綴) | 當前有效版本 | 正式引用 |
