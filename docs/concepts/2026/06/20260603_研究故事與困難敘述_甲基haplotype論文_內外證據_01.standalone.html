同一工具、兩個答案：「甲基-單倍型一致事件存在嗎」=YES（BRCA2）；「能演算法式判別 TP/FP 嗎」=NO（AUC 0.505）。稀有但真實 → characterization + 工具，不是篩子。

0一句話故事

我們想做一個能把 haplotype / LOH / 甲基 集中在「位點」上、可重現分析的甲基癌症工具（ISM）。最硬的困難是：tumor 5mC 太混亂，沒有演算法能篩出「大量、清楚、一致於 haplotype/somatic」的甲基差異位點——肉眼看得到個案，統計抓不到群體。我們試過把甲基當篩子，被自己的數據證偽（LOSO 100% 循環）。於是做了關鍵決定：從「篩子」轉向「characterization + 工具」。而 BRCA2 promoter 一個真實、有癌症機制的個案，證明這方向稀有但高價值。

1願景：為什麼做 InterSubMod

最初願景：把所有 tag（HP / HP-1 / HP3 / unphase / LOH）集中，用「位點」分析甲基化 read 的狀況與差異，比對與 tag 的相關性，做統計與判斷輸出；成為甲基癌症研究的套件，特別是 haplotype 與 LOH 都是關鍵資訊。對應原始 5 目標（甲基評分 / clone 結構 / 二次打擊 / TO normal / evidence 整合）。

外部佐證：此方向有活躍工具地景——MethPhaser（Nat Commun 2024）、NanoMethPhase（Genome Biol 2021）證明 read-level 甲基 × haplotype 可耦合；O'Neill（Cell Genomics 2024，189 腫瘤）證明癌症 read-level 甲基 × LOH biallelic inactivation 真實有功能。⚠ 多數工具是「從甲基推 haplotype」（因果與 ISM 相反），ISM 的 read-read 距離矩陣 + subclonal + LOH 耦合 是尚未被填的 niche。

2核心困難（你的原話 → 科學工程問題鏈）★

tumor 5mC 更混亂，光靠 5mC 可能不夠；沒辦法用演算法篩出很多清楚、一致於 haplotype/somatic 的甲基差異位點，所以無法統計與判斷數量。IGV 肉眼看得到不少一致位點，但怕偏誤（先看 tag 就認為一致）；統計 TP/FP 特徵都無法明確驗證。位點無法定位，下游（如判 unphase read）就難做。
外部研究強力佐證（最硬的一段）：「tumor 5mC 比 normal 混亂」是領域公認現象——Derrien（Genome Med 2021 supports）用 read-level PDR/epipolymorphism 證實腫瘤甲基化顯著比正常混亂、混亂來自 read 內部不一致；Landan（Nat Genet 2012 supports）證甲基化以隨機過程形成 → 單位點難有 read 間一致性；Russo「Epigenome Chaos」（Cancers 2021）定性為跨癌種 hallmark。你的困難有文獻名字（epigenetic heterogeneity / epipolymorphism），站得住。 ⚠ 口徑差異：外部多為 bisulfite 短讀，我們 ONT 長讀——現象/機制一致，量測不同。

用甲基篩 caller FP 提升 F1 → LOSO 證偽（held-out −0.00012、5-sample mean −0.00004 p=0.125、HCC1954 transfer −0.377）；甲基特徵其實裝飾性；persistent FP 不可削減。

為什麼是 Productive Failure 而非失敗：它乾淨地否證了一個誘人假說，並給了三個可寫進論文的硬負結果（filter 循環、甲基非判別、ASM 反指）。外部 Martin-Trujillo（Nat Commun 2017 supports）標題即「Copy number rather than epigenetic alterations are the major drivers of allelic methylation in tumors」——背書「看似 ASM 的差異主因常是 CN/LOH dosage」。

4轉折決定：從「篩子」到「characterization + 工具」★

程式類型能不能做為什麼
描述 / 定位✅ 做得出給一個位點，ISM 客觀建矩陣→分群→比對 tag→與 normal 對照（BRCA2 就這樣被證實）
判別 / 決策❌ 做不出需穩定、跨樣本、可泛化決策邊界——被四層否證：①可定位但反向（FP 富集 5×）②效應被雜訊吞沒（AUC 0.505）③量測層模糊（5mC/5hmC + read 稀疏）④單樣本天花板（只有 HCC1395 有 ground-truth）
故事轉折金句：「做不出判別 program」不是工程失敗，是被自己的數據證明的科學邊界——把這條邊界誠實畫出來，本身就是論文的方法學貢獻。

5錨點：BRCA2 promoter — 稀有但真實

內部（L1-L2）：BRCA2 promoter（chr13:32,315,128）HP-axis Δβ=−0.122，抗 Bonferroni；6/01 normal-anchored cis-test 初判 d_cis=−0.142，但 06-07 copy-partition 分解後 = subclone/copy 主導（HP1-1=somatic subclone tag 非 copy、非 CN-dosage）——真 within-somatic cis 僅 d_within=−0.023（perm p=0.022，邊際但真）；乾淨 cis 改 chr17/TBC1D16（見下 C1/C8）。

外部（L3）：Fishchuk（Cancer Biomarkers 2024 supports）BRCA2 promoter 高甲基化→低表現；Evans（AJHG 2018 partial）BRCA1 cis-ASM-silencing 先例；Esteller 2000 / Catteau 2002 領域共識。

⚠ 三個必須誠實標的不對齊（reviewer 一查就破）
1. 方向相反：canonical 文獻是 hyper→沉默；我們內部是 hypo（Δβ=−0.122）→ 外部佐證的是「此 locus 甲基化在癌症有意義」，不是我們的方向。
2. 基因特異性：最強 cis-ASM 先例是 BRCA1 不是 BRCA2；BRCA2 promoter 甲基化文獻較薄（跨研究偵測率 0–69%）。
3. 未測表現：我們只量甲基化、沒測 BRCA2 mRNA/蛋白 → 「→沉默→癌症」下游因果內部未驗證，外部提供 plausibility 非證實。
這個錨點的正確講法（06-07 de-confound 後）

「我們在一個有明確癌症機制的 TSG promoter 上，先看到表面強 allelic 甲基差（−0.122），再用 normal 對照 + within-tag 分解揭露：這個表面差大部分是 subclone/copy 混淆，真正的 focal 等位 cis 只有邊際的 −0.023（p=0.022，小但真）。能拆出這個真相、不被表面騙，正是 ISM 的獨有價值；乾淨的 cis exemplar 是 chr17/TBC1D16。下游表現後果是 future work。」

6現在的判斷

三軸：主軸 LOH-constrained phasing（n=7 W=28 p=0.0078，Grade A 要求#1）｜支撐 ZAR1L/BRCA2 ASM characterization（real / 稀有 / 非方向 / 非判別 / CN-confound 排除）｜methods LOSO sample-level NEGATIVE（誠實方法學）。

三層光譜（取代二分）：存在性 YES → 可定位性 部分（regime-A 15/23）→ 可判別/可泛化 NO（AUC 0.505）。BRCA2 通過前兩層、卡第三層 = 「可定位但無判別力」中間態。ISM 多功能：同輸出餵 5 問題（①一致事件定位 ②判別 TP/FP[NEG] ③tag read 輔助 ④subclone/phasing[LIVE 主軸] ⑤LOH/CN de-confound）。

7B工具地景：epipolymorphism（methclone/Epihet）vs ASM（ISM）★

核心釐清：epipolymorphism 量「失序 disorder」（一個位點內部多亂）≠ ISM 量「結構/一致性 structure」（read 是否一致於 haplotype/somatic）。這定義了 ISM 的差異化 niche。

維度methclone / EpihetISM（InterSubMod）
量什麼epipolymorphism / 組合熵（位點內失序度）read×CpG 矩陣 + read-read 距離 + 分群（結構一致性）
核心問題位點多亂 / 兩樣本 clonality 變化（disorder）read 是否一致於 haplotype/somatic（cis-driven ASM）
平台bisulfite 短讀ONT 長讀（modBAM MM/ML）
位點固定 4 相鄰 CpG（~72bp）範圍內全 CpG（長 read 跨 kb）
haplotype/SNV 連結無有（HP/HP-1/LOH tag + somatic SNV + cis-test）
read-read 距離矩陣無（算位點熵）有（L1/NHD/Bernoulli + 階層分群）
5mC/5hmCbisulfite 混淆可分軌（C+m vs C+h）
語言C++（methclone）/ R（Epihet）C++17 + Python
對故事的深層意義：epipolymorphism 文獻群（methclone/Epihet/Rossi25/Lin21/Derrien21）量化了我們的困難（tumor 甲基 read 層高失序）並提供成熟工具地景——但它們回答「disorder」、不是我們的「haplotype-consistent ASM structure」。它們量到的高失序背景正是 ISM 要在其中撈「稀有一致結構」的噪音地板，再次解釋我們訊號為何稀有（0.34%）。沒有人用長讀做 haplotype-linked read-read 距離的 ASM 結構分析 = ISM 的差異化定位。

工具/文獻：methclone（Li 2014, Genome Biol, PMID 25260792）· Epihet（Chen 2021, Sci Rep 11:376, DOI 10.1038/s41598-020-79627-x）· Martin-Trujillo 2017（Nat Commun, PMID 28883545）「CN 主導 allelic methylation」（C6 深確認；Nature 全文本輪被 auth 擋，中心 claim 與 DOI/PMID 已確認）。
