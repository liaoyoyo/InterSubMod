L0 一句話目標 + 論文主軸 research 總覽

研究總覽分層的最頂層：終極目標 + 一段話主軸 + 承載引擎。所有下層（漏斗/卡/矩陣/鏈）都收斂到這裡。

終極目標

在癌症長讀（ONT 5mC/5hmC）資料中，以單 read 解析度 characterize somatic 突變 + LOH 如何重塑 haplotype／甲基地景，並交付利用它的 tooling（LOH-constrained phasing signature）。 定位 read-level epigenetic & haplotype CHARACTERIZATION + TOOLING 論文，明確不是 variant-calling filter。

一段話主軸（所有存活證據都支持的）

在 LOH 區腫瘤物理上只保留單一 haplotype，故 somatic SNV 形成同-haplotype 子家族、跨樣本方向一致可偵測（phasing 訊號，Grade B+）；ASM 真實存在且現象層跨 6 樣本／3 癌種復現，但它小、非方向、與 copy-dosage 無關、且關鍵地不能判別真／假變異——故甲基不能當 variant filter（三~四道獨立證死）。論文貢獻 = LOH-driven haplotype 結構的 read-level characterization + 一份誠實、機制解明的「甲基能／不能做什麼」目錄。

承載引擎 = ISM (InterSubMod)

ONT 長讀 read×CpG 甲基矩陣 + read-read 距離 + 階層分群（CramersV gate）+ HP/LOH tag 比對 + normal-anchored cis-test。C++17 + Python。pipelines: paired_full / paired_pileup / tumor-only。主樣本 HCC1395（有 SEQC2 ground-truth）。

6 聚焦問題（逐一誠實作答）

① 這個研究重要嗎？
重要但須誠實定位。價值 = read-level 連結 somatic/LOH 與 haplotype-linked 甲基地景 + 交付 LOH-phasing tooling。但「重要」≠「能做 filter」——最大價值反而在一份機制解明的「甲基能/不能做什麼」目錄（負結果有教育+防雷價值；背書：Kapoor&Narayanan 2023 leakage taxonomy、Martin-Trujillo 2017 CN-confound）。
② 別人沒做清楚、我做清楚的是什麼？
三件：(1) LOH single-haplotype 約束下 somatic SNV 同-HP1 子家族、Inner>Outer 跨樣本一致（7/7, p=0.0078）+ 乾淨 paired 負控；(2) 把「甲基能否判別 somatic TP/FP」徹底證死並機制解明（LOSO 循環 / AUC=0.505 / regression-to-extreme）— 現有 production caller 沒人把 CpG 甲基當 standalone FP 判別器公開證偽；(3) 乾淨 falsify copy-dosage 作 driver（MW p=0.6183, ρ=−0.083）。
③ 我的資料能否回答？
部分能、有明確邊界。能：HCC1395 有 SEQC2 ground-truth → filter-neg/dosage-falsify/regression-to-extreme/ARI ruler 都 powered L1；phasing 7/7 跨 6 樣本/3 癌種。受限：(a) ASM positive 全 single-pipeline + 單樣本 → 封頂 ⭐3（⭐4 需 COLO829）；(b) phasing by-construction 部分循環，對照未跑（HD-1）；(c) 6 最強 cis untestable；(d) 0/38 underpowered 非 private。
④ 方法比現有多提供什麼資訊？
ISM read-level 同時給 read×CpG 矩陣 + read-read 距離 + 階層分群（CramersV gate）+ HP/LOH tag 比對 + normal-anchored cis-test。相對 Δβ-only 能抓 discrete clustering（與 Δβ 互補：BRCA2 是 clustering-only Δβ~0.007 被 Δβ 漏但被 CramersV 抓；反之高-Δβ FP 被 CramersV 正確排除）。normal-anchored cis-test 區分真 cis vs drift。但這多出的資訊不轉化為 variant-filter 判別力（已證死）。
⑤ 結果怎麼驗證？
已用：LOSO 留一、2000× shuffle permutation null、subhap-matched 對照、blind-ARI ruler 附 imprinting 正控（GNAS/RB1=1.000）、signed-rank 跨樣本一致、bootstrap CI、germline-het null、copy-test/Bonferroni、乾淨 paired 負控。待補：R-SELFREF 對照（HD-1）、regression-to-extreme bootstrap stability、COLO829 ⭐4、各 headline grep 原檔（含本輪 4 個 provenance gap）、/citation-verification 核外部 PMID/DOI。
⑥ 能否變一張清楚的圖／明確結論？
能。明確結論（一句）：在 LOH 約束下 somatic 變異重塑 haplotype 子結構（phasing 可偵測、Grade B+）、ASM 真實存在但小/非方向/copy-independent/不可判別變異（甲基非 filter，死四道）。清楚的圖候選：(1) 三軸結構圖（主 phasing / 支撐 ASM / 底座 4 道 NEGATIVE）；(2) NG=2 Inner>Outer 7/7 forest plot；(3) filter 死四道對照圖；(4) V10 甲基「非 copy」depth-matched control 圖。
