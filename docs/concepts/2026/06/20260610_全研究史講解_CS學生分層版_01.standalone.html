一個癌症長讀甲基化研究的完整故事：
它證明了什麼、未來能做什麼、什麼此路不通（以及為什麼）

一句話：用「長讀定序」同時讀腫瘤的 突變(somatic)、單倍型(haplotype)、甲基化(methylation) 三種訊號，問「甲基化能不能幫忙判斷哪些突變是真的」。答案是不能（甲基不是分類器），但它能 characterize（描述）腫瘤如何重塑表觀地景 —— 這個「誠實的負結果 + 一份描述目錄」就是研究的核心產出。
🎓 怎麼讀（給 CS 學生）：每個概念都配一個你熟的 CS 類比（LOH=RAID-1 鏡像、phasing=git-blame、循環依賴=train/test leakage、germline/somatic=base vs diff、FDR=多重比較…）。細節都收在可展開的卡片裡（▸ 點開），讀到夠就停。證據色：🟢 已驗 / 🟡 未跑或 contingent / 🔵 立場。每個數字都附 ledger 來源。

0 這研究到底在做什麼？（30 秒版）

先給 CS 學生一個能掛東西的骨架，再展開。

問題設定：癌症定序要找出腫瘤「後天獲得的突變」（somatic variants）。但工具（caller）會誤報一堆假突變（false positives, FP）。研究問：能不能用「甲基化」這個額外訊號當特徵，把真突變(TP)和假突變(FP)分開、提升準確率(F1)？

三個訊號（都在同一條長讀 read 上同時讀到）：

  • somatic 突變 = 腫瘤後天獲得的變異（要找的目標）。CS 類比 相對 germline baseline 的 diff。
  • haplotype / phasing = 這條 read 來自父方還母方染色體。CS 類比 git-blame：把交錯的行歸回各自分支。
  • methylation 甲基化 = CpG 位點上的化學標記（開/關）。CS 類比 一個 label-conditioned 特徵。
六個月後的結論（一句）：甲基化不能當分類器篩突變（試了至少 4 種方式全失敗，而且失敗都有乾淨的 confound 原因）；但甲基化訊號真實存在、跨癌種可復現，且在「LOH 區域 somatic 突變如何形成同一單倍型的子家族」這件事上提供了一個跨樣本一致的 phasing 訊號。→ 論文從「filter（分類器）」轉向「characterization（描述）+ tooling（工具）」。

1 時間軸 — 研究怎麼演化的（6 個階段 + 每階段的轉折）

這研究不是一條直線，是「探索 filter → 撞牆 → 發現根因 → 轉向 characterization」的過程。每個 ▸ 可展開看那階段發生什麼。

2026-03 · TO FP 規則掃描 + 揭露 self-phasing 根因
展開細節

起點：ClairS-TO caller 輸出 FP 率高。PoN（panel of normals）已移除 99.48% raw FP（2,717,339/2,731,541），剩下 ~80 個/樣本是 germline leak，且在甲基化上「長得像」真突變。掃 QS/GQ 單規則（H011 QS≥50 ΔF1=+0.0086），甲基新特徵 H003 AUROC=0.473（隨機）→ reject。同時揭露 self-phasing 循環依賴：somatic HP bias 17.3:1。

轉折：能 filter 的已被 PoN 拿掉，剩的 FP 在甲基化上像 TP → 認知到 HP 特徵全失效不是設計問題，是 self-phasing 循環污染。
2026-04 上 · KDE infra fix 推翻 baseline + LOH-phasing 主軸誕生
展開細節

修了一個 infra bug：CN 估計的 expected_coverage 被 hardcode 成 75×，實際 HCC1395 是 53.0×（SEQC2 真值 54×）→ 舊值是 +39% artifact。這個修復推翻了多個 COLO829 結論（2 個 CRITICAL claim RETRACT）。同期發現 LOH-constrained phasing：NG=2 Inner same-HP1 vs Outer gap 6/6 樣本皆正（Wilcoxon W=21 p=0.0156），Inner×NG=2 ≥93% same-haplotype。

轉折：infra bug 證明多個結論是計算 artifact（2 RETRACT）；同時 NG=2 same-hap phasing signature 成為論文主軸候選（從 filter pivot 到 phasing）。
2026-05 上 · self-phasing priority-bug audit（baseline→V3F→V5→V6 修補鏈）
展開細節

量化 priority bug：全基因組 34,855 個 read-level victims（chr19 僅占 2.16%，推翻 chr19 是 hotspot）。三層獨立證據鏈（17.3:1 bias + IGV + 34,855 victims）。V6 patch 移除 Layer 1.5 後 strictly dominates baseline（marker +52.4%），但 caller F1 三版完全相同 0.7166（修 phasing 不改 caller 結果）。PI 簽核 V6 4-goal PASS（254/273 verified，0 fabrication）。

轉折：self-phasing 是「壓低真信號」非「製造假信號」→ V6 確立為 production baseline。
2026-05 中 · 甲基 filter Phase 2 — LOSO 揭露 100% 循環（filter 方向死）
展開細節

甲基 filter pilot：加 5 個甲基特徵的 LR，in-sample ΔF1=+0.02236 看似不錯。但決定性的 LOSO（leave-one-sample-out）：held-out −0.00012 = 100% sample-level circularity；5 樣本 mean −0.00004 Wilcoxon p=0.125（方向為負）；HCC1954 transfer −0.377 災難性。drop 全 5 甲基特徵只掉 +0.00065（甲基是 vestigial，caller_af coef +3.44 主導）。

轉折：LOSO 證明 in-sample gain 全是循環（held-out 歸零）→ filter 方向 WITHDRAWN，論文改寫為 characterization study。
2026-05 下 · ISM ASM characterization 誕生 — 但 somatic-specificity NEGATIVE
展開細節

ASM 主軸啟動：BRCA2 somatic hypo p=6.09e-11。修了 MSA dup-emission bug（5mC+5hmC 雙列把 beta 砍半），全 39,447 TP 重跑 Δβ=−0.122。但 B-discrimination NEGATIVE 且 anti-discriminative（strong-ASM 在 FP enriched 5×, Fisher OR=0.194 p=1.8e-28）；apparent somatic-specificity 是 threshold artifact（Bonferroni 後 OR 1.79→0.81）。imprinting 正控（blind-ARI 0.758）反證方法有效 → 所以 NEGATIVE 是真 biology。

轉折：ASM 真實存在但反覆證明非 somatic-特異、非判別器 → pivot 到 cis-test 深掘。
2026-06 · de-confound 收斂 + 跨樣本復現 + 332,705 位點 catalog
展開細節

用 copy-partition 把「看起來像 cis 的 ASM」拆解：BRCA2 的 −0.122 為 subclone/copy-confounded（HP1-1=somatic subclone tag 非 copy、非 CN-dosage；焦點 cis d_within 只 −0.023，邊際；% split 不 robust）。copy dosage decisively NOT driver（MW p=0.62, signed ρ=−0.083 反向）。全基因組 816 個 HP-axis loci 中只有 1 個乾淨 cis = chr17/TBC1D16。跨樣本：同位點 0/38 復發（private），但 genome-wide 6/6 excess-over-null（mean 0.168, 3 癌種）= 現象復現。收斂成 332,705 位點 7-TAG catalog。

轉折（現況）：收斂到 read-level characterization + tooling catalog（非 filter）；全基因組僅 chr17 唯一乾淨 cis exemplar。唯一卡關 = HD-1（phasing 循環對照，待用戶決定）。

2 三分類總覽 — 哪些有成果 / 哪些是機會 / 哪些不可行

研究的所有 thread（35 條）分三類。這是回答你「哪些可當目標、哪些未來有機會、哪些不可行」的核心。

✅ 成果（可當目標/貢獻）10已驗證、可寫進論文的紮實結果：LOH-phasing 脊柱、ASM 存在、chr17 cis、catalog、self-phasing 根因、KDE fix…
🟡 機會（未來有潛力）7有潛力但未驗/受限：甲基輔助 phasing(umtag)、cis 大規模協議、FDR 校準、5mC 純化、Δβ 通道、latent 納回…
🔴 不可行（已死+原因）18已 NEGATIVE/NO-GO，且死因明確（多為 confound）：甲基 filter、ASM 判別、subclone clustering、germline FP、O9/O11/O12/O13…
💡 一個關鍵體會：18 個「不可行」不是浪費 —— 它們大多是「一個看似很強的訊號，其實是 confound 假象」的故事。把它們嚴謹證死、講清楚死因，本身就是論文最可防守的貢獻（一份『甲基能/不能做什麼』的誠實目錄）。

7 給 CS 學生的 10 個關鍵概念（每個配 CS 類比 + 示意圖）

這些是認知負荷最高的點。每個先給「為什麼難」，再給你熟的 CS 類比，必要時配示意圖。讀完這 10 個，整篇就懂了。

① LOH（Loss of Heterozygosity）= 失去兩份拷貝之一RAID-1 鏡像

為什麼難：CS 學生沒有「每樣東西有兩份（二倍體）」的模型。更糟：本研究裡 LOH 同時是生物事件、是 artifact（62% 的 LOH 是 self-phasing 假象）、也是分層變數。cnLOH（copy-neutral：丟一份又複製另一份，總數還是 2 但多樣性歸零）特別反直覺。

CS 類比 每個人對每個基因有兩份拷貝（父母各一），像 RAID-1 鏡像磁碟對。LOH = 一面鏡子掉了，剩單份無冗餘（surviving copy 上的缺陷全暴露 → 這就是為何 LOH 對抑癌基因致命）。cnLOH = 陣列把存活的那片重新複製以維持「2 片」假象，所以 df（拷貝數）報「健康，2 片」但其實多樣性歸零 —— 就像一個 cache 回報滿載但每條 line 都是重複的。而且這裡 62% 的 LOH 是測量 artifact（phaser 吃自己的 output）。
② Haplotype phasing = 把 read 歸回父/母染色體分支git-blame + 循環依賴

為什麼難：學生直覺把基因組想成一條字串。Phasing 強迫雙股模型 + 機率指派問題。最深的陷阱是 self-phasing 循環依賴：TO 模式下用 somatic 變異 phase reads，再用 phasing 判斷 somatic 變異 —— 工具吃自己的 output（17.3:1 bias，94.6% somatic→HP1）。還有術語爆炸：HP1/HP2、HP1-1（germline-H1 + somatic 子標記，不是拷貝）。

CS 類比 你有兩個 source branch（母/父）被逐行交錯成一個檔、branch 標籤被剝掉。Phasing = git-blame 式重建：用 SNP marker 當 commit 指紋把每行（read）歸回 branch。HP1/HP2=兩個重建的 branch；unphased=歸不了的行。self-phasing bug = 從你要驗證的 commit 推 branch 成員，再用該 branch 成員驗證那些 commit —— input 依賴自己 output 的 build system。17.3:1 collapse 是這個 feedback loop 的簽名，不是生物。HP1-1 = 子標籤（從 main fork 的 feature-branch），是 tag 不是實體拷貝。
③ ASM（Allele-Specific Methylation）= 真實但不判別的 label-conditioned 特徵真實 ≠ 有用

為什麼難：(1) 生物：甲基化是 CpG 上的化學標記。(2) 認識論（更難）：整個 6 個月在證 ASM 真實但不可用作判別器。ASM 廣泛存在（~0.34% strong loci, 跨癌 6/6 復現）卻 (a) anti-discriminative（FP enriched 5×, OR=0.194 p=1.8e-28），(b) apparent somatic-specificity 是 threshold artifact（1.79→0.81），(c) ALLELE-axis 被 baseline allelic 甲基 confound（必跑 germline-het null）。

CS 類比 ASM = label-conditioned 特徵：「依 allele/haplotype 標籤分組算甲基分布，看兩組差異」。經典 ML 教訓：一個特徵可以統計上真實（一致非零、跨資料復現）卻對你的目標類幾乎零判別力（兩類分布大量重疊），還可能被 confound（allele-axis 差異在 normal germline-het 位點也有，要當 null 減掉）。對映：高 prevalence + AUC 僅略高於 chance + Simpson 式 confound = 真實但無用的分類器 input。
④ read × CpG 甲基矩陣 = 每區域的稀疏特徵矩陣term-document matrix

為什麼難：這是核心原始資料結構，CS 學生其實最好懂 —— 但它是稀疏、ragged、領域特定地 noisy：不是每條 read 蓋每個 CpG（到處缺格），read 是不同欄範圍的片段，甲基 call 是機率的（BAM MM/ML），5hmC 太稀疏（5.9%）不能 cluster。下游的距離矩陣 + 階層分群全從這矩陣算。

CS 類比 一個 binary（其實 ternary：甲基/未甲基/未覆蓋）特徵矩陣 —— rows=reads（樣本）、columns=CpG（特徵）、cells=甲基狀態。像 NLP 的稀疏 term-document matrix：documents=reads, terms=CpG，但多一個「未觀測」狀態（每條 read 只蓋連續一段欄，像只含詞彙連續切片的 document）。下游全是標準非監督 ML：pairwise row distance → 階層分群 → 「reads 有沒有分 2+ 甲基子群」。陷阱：缺格是結構性（覆蓋）非隨機 → naive 距離會把覆蓋當 confound 洩漏（這就是 O11/O13 崩的原因）。
⑤ De-confounding = 控制造成假象的第三變數Simpson + collider

為什麼難：這是全研究最 load-bearing 的方法概念。幾乎每個 NEGATIVE 都是 de-confound 故事：epipolymorphism AUC 0.845→0.530（殘差化 n_reads）；cross-region 分層 shared read count 後消失；AlleleDelta 其實是 AF。還有兩個連老手都會錯的失敗模式：(1) collider bias（殘差化 ON collider 反而製造信號）、(2) 必須 within-group OLS 不是 pooled OLS。

CS 類比 Confounding = Simpson 悖論 / lurking variable 造成的假相關，就像 benchmark 上「演算法 A 比較快」其實是「A 的 input 比較小」—— 比較前必須控制 input size。De-confound = 對 lurking variable（n_reads/AF/CN）partial-out/殘差化再測，相當於 A/B test 裡 hold 住一個變數。兩個陷阱對映 CS bug：collider bias = 條件在一個被 cause 和 effect 都指向的變數，開了非因果路徑（像用 outcome 選資料集 = selection bias 製造相關）；pooled vs within-group OLS = 忘了先 GROUP BY 再 regress，跨組變異洩進「within」估計（join/聚合粒度 bug）。規則：任何 AUC>0.58 都要過 within-group OLS + AF-bin 交叉 + permutation 三關才信。
⑥ By-construction circularity = 自我驗證的 train/test leakagetrain/test leakage

為什麼難：全研究最精緻、最常見的失敗模式，且以兩種偽裝出現：(1) self-phasing（somatic phase reads，phasing 判 somatic）；(2) LOSO/filter（in-sample +0.0224 但 held-out −0.0001 = 100% 循環）；(3) copy-partition（BRCA2 用一個已編碼那個切分的 tag 去「發現」切分）。每次 in-sample 數字都很漂亮，循環在你 hold out 之前隱形。

CS 類比 這就是 train/test leakage / data snooping —— ML 評估的頭號大罪。self-phasing loop = 從模型算 label，再用同一 label「驗證」模型（test set 洩進 training）。LOSO（Leave-One-Sample-Out）= 樣本層的 k-fold CV：+0.0224 in-sample 蒸發到 ~0 held-out（transfer −0.377）是 overfit 到樣本特異 quirk 的教科書簽名（模型背了 HCC1395，沒學到可泛化的東西）。統一教訓：漂亮的 in-distribution 數字在誠實 held-out 確認前一文不值；held-out 崩 = in-sample 是洩漏不是學習。
⑦ FDR / null model = 全基因組規模的多重比較校正多重比較 / look-elsewhere

為什麼難：學生知道 p<0.05 = null 下 5% 機率，但全基因組跳躍不直覺：測 ~33 萬個位點，raw 5% 假陽性 = ~16,000 個「顯著」純靠運氣。本研究生死繫於此：「strong-ASM」數隨校正大幅擺動（172→3018，但 null strong-rate ≥ TP strong-rate → 整個 effect correction-fragile）。chr17 p=0.001×816≈0.82（Bonferroni NS）。12,868 reliable（3.87%）就在 5% 噪音地板下緣 —— 可能全是噪音。

CS 類比 多重比較 = 每個 data engineer 跑幾千個 A/B test 都會撞的「p-hacking / look-elsewhere」：固定 5% per-test 錯誤率、跑 30 萬個 test，~15,000 個「贏」是純噪音。Bonferroni = alpha 除以 test 數（殘暴、近零容忍，像要求 6-sigma）。BH-FDR = 較實用的「我接受我 flag 的發現裡 ~5% 是假的」（控 false-discovery 比例）。permutation null = Monte-Carlo/bootstrap baseline：shuffle 標籤（破壞真結構）重算統計幾千次得「隨機長怎樣」分布，看觀察值是否在尾端離群 —— 像建隨機對照判斷 latency 改善是真的還是 jitter。頭號陷阱：需要寬鬆閾值才存活的 effect（172→3018, null≥signal）= 只在你調過的 benchmark 上贏的最佳化。
⑧ Co-validation（正交佐證）vs filter（分類器）= 同資料兩種角色checksum vs classifier

為什麼難：全研究的中心 framing 區別，也最易混。同一份甲基/ASM 資料兩種用法：(A) 當 FILTER（分類器 input 決定 TP/FP 提升 F1）—— 這方向徹底 DEAD；(B) 當 CO-VALIDATION（獨立正交證據，在某一位點剛好與變異 call + haplotype 都同意時佐證一個故事）—— 唯一乾淨範例 chr17/TBC1D16，332,705 中的 1 個。要懂「真實但無用作 filter」和「有價值作佐證」不矛盾：太重疊無法 threshold 的 noisy 訊號（爛分類器）仍可在少數手選位點與兩個獨立 channel 同意（好佐證）。

CS 類比 filter vs co-validation = 分類器 vs checksum/共識。FILTER 是你信任去 auto-decide 每個 case 的學習判別器 —— 甲基在此失敗就像 AUC≈0.5 的特徵，撐不起決策邊界，用了還傷（FP-enriched）。CO-VALIDATION 是正交佐證，像把一個值跟獨立 checksum 對、或要求三個獨立 sensor/replica 同意才信一筆關鍵紀錄：你不在 30 萬筆全跑，只在「三個獨立 channel（somatic call / haplotype / methylation）剛好同意」的那一筆提升信心。關鍵直覺：太弱不能當獨立分類器的證據源，仍可在單一手驗實例當有效獨立佐證 —— orthogonality（channel 獨立）比 per-instance accuracy 重要。研究禁止的反 pattern：把「甲基在 TP enrich 3.95% vs FP 1.07%」包裝成 retrieval —— 那是 enrichment（characterization）不是 usable filter（4% sens, FP 非零, COLO829 TP≈FP）。
⑨ Germline vs somatic = 遺傳的(每個細胞) vs 後天的(腫瘤獨有)base 檔 vs diff

為什麼難：最基礎的二分，幾乎所有下游概念都依賴它，卻是純領域知識無日常類比。germline=你遺傳的，在每個細胞（含 matched normal）；somatic=腫瘤後天獲得，只在腫瘤細胞 —— caller 要找的就是它。後果串起整份研究：(1) TO 模式無 matched normal 可減，germline 漏進來當 FP（殘餘 FP 98.6% raw_absent germline leak）；(2) germline ASM(46.4%) > somatic ASM(35.9%)，甲基更像 germline；(3) 必跑 germline-het null；(4) imprinted 區當正控（blind-ARI 0.758=5× somatic）。

CS 類比 germline vs somatic = base 檔 vs diff。germline = 每個 checkout 都有的 committed baseline（每個細胞，含 matched-normal reference branch）；somatic = 只在腫瘤 working copy 的 uncommitted local diff。somatic caller 的工作本質是 diff tumor normal —— 只輸出不在 baseline 的行。TO 模式 = 弄丟了 normal reference，等於沒有 base 檔要重建 diff，遺傳的 baseline 行（germline）漏成假「change」（98.6% raw_absent FP = 沒 base 可減的 baseline 行）。germline-het null 控制 = 宣稱「這是腫瘤後天」前，先確認它不是已存在於普通遺傳雜合位點（別把 baseline 行當 diff）。imprinted 當正控 = test suite 裡的 known-good fixture。
⑩ Single-pipeline ceiling = 為何結論封頂 ⭐3（單一 oracle / 相關失效）單一 primary DB 的 replica 共識

為什麼難：學生看到很多強跨樣本復現（6/6, mean +0.168, CV 0.26）會以為結論鐵證。微妙的關鍵：所有 tier 封頂 ⭐3，因為每個樣本的 somatic 真值都來自同一個 caller（ClairS-TO）。若這單一 oracle 有系統偏差，偏差在 6 樣本被同樣複製，「6/6 一致」不能排除「caller 一致地錯一樣」。共享 pipeline 的跨樣本復現量的是 pipeline 一致性，不是生物真值。

CS 類比 這是分散式系統/ML labeling 的相關失效 / 單一真值源問題。用一個 labeler（或一個上游服務）的 label 驗模型、跨 6 資料集都同意，就像 6 個 replica 都讀同一個 primary DB：primary 壞了，6 個 replica 完美同意且全錯 —— 共享來源的 replica 共識對真值毫無證明力（沒有獨立來源就沒有 Byzantine 容錯）。ClairS-TO 就是那個單一 oracle；「6/6 復現」= 高 test-retest reliability，不是 validity。打破天花板要獨立 oracle（COLO829 / 第二 caller / matched-normal truth set）—— 就像你不用同一個 parser 的 output 驗那個 parser，不用第二個一樣壞的時鐘量時鐘準度。tier 系統正編碼這個：⭐3=真實可復現但單 pipeline，⭐4+=被獨立來源佐證。
