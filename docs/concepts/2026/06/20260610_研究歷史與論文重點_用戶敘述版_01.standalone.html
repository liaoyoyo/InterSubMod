2 ISM 的獨特價值 — 一個 modkit 看不出、ISM 才揭露的真相

這是整個工具為何值得做的最佳說明（你給的例子）。

「如果只用 modkit，你會把 BRCA2 的表面 ASM（≈ −0.16 / 驗證值 −0.122）當成『強 ASM』；ISM 的 normal-anchored cis-test + within-tag 分解才揭露：這個表面差大部分是 subclone/copy 混淆的 artifact，真正的 focal 等位 cis 效應只有 d_within=−0.023（邊際）。這就是 ISM 獨有的價值。」

⚠ 口徑更正（依 2026-06 標準文件）：你原句「~80% 只是 copy number」要校正 —— ① 別寫精確 %（不 robust）、別寫「copy number」：confound 是 subclone-structure（HP1-1 是 somatic subclone tag）非 CN-dosage；② Martin-Trujillo 2017 是 CN-dosage 文獻，而我們 dosage 已 REFUTED（MW p=0.62）→ 它是「被我們控掉的 confound 警告」，不能反過來佐證「BRCA2=copy」（category error）；③ BRCA2 是 hypo ≠ canonical hyper-silencing。→ 正確講法用定性：「表面 ASM 主要是 subclone/copy 混淆、真 focal cis 邊際」。

ISM 在工具地景的定位（2026 六軸比較 vs modkit/NanoMethPhase/DSS 等）：ISM 站「軸 C：read-read 距離 + clustering」（modkit/DSS 是「軸 A：率差」）；最相似的外部工具是 cvlr/ASMS/qFDRP。可防守的新穎點 = PERMANOVA 結構 + normal-anchored cis 分解。memory: ism_vs_external_tools

2.5 ISM 方法與判別細節 — 它怎麼做、怎麼下判斷

這是「製作 ISM 分析甲基分群差異」（目標 1.3）的內部細節。先看 8 步 pipeline 流程圖，每步可展開看「做法 + 判別方式」；最後是「ISM 怎麼下判斷」的判別標準。

每一步的做法 + 判別方式（點 ▸ 展開）：

① + ② 建 read×CpG 甲基矩陣資料層
做法
從 tumor + matched normal BAM 的 MM/ML tag 讀每條 read 在每個 CpG 的甲基狀態（5mC），建一個 read（列）× CpG（欄）矩陣，cell = 甲基 / 未甲基 / 未覆蓋（三態）。
判別
這步不判別，是建資料結構。

⚠ 重點：覆蓋是 ragged（每條 read 只蓋連續一段 CpG），缺格是結構性（覆蓋）非隨機 → 下游距離度量必須小心別把覆蓋當 confound（這是 O11/O13 失敗的根）。

③ + ④ read-read 距離 + 階層分群分群
做法
對矩陣每對 read 算甲基 profile 距離（6 度量：NHD / L1 / L2 / Pearson / Bernoulli / Jaccard）→ 得 read×read 距離矩陣 → UPGMA 階層分群把 reads 分子群。
判別
「這個位點的 reads 有沒有分成 2+ 個甲基子群？」= 非監督分群。子群數 = 後續 NGroups（但注意 NGroups 其實主要受 HP-tag 數驅動，非純甲基）。
⑤ CramersV + PERMANOVA reliability gate ★核心判別「分群明不明顯」★ 判別核心
做法
用 CramersV 量分群與 HP 標籤的關聯強度，但加 Cochran 最小期望格 ≥5 的 gate（稀疏表 = 小 HP group 如 3 vs 51 → CramersV 歸零）；同時用 PERMANOVA（distance-based, robust）測分群顯著性。
判別（三態）
reliable = CramersV≥0.1 且過 Cochran gate 且 GlobalP≤0.05 且 NumReads≥20｜latent = gate 歸零但 PERMANOVA 顯著（= 被 gate 擋掉的真分群，全基因組 487/762 MISSED）｜none = 皆非。

💡 這是「哪些位點甲基分群明顯」的判別核心。CramersV gate 偏嚴（487 個真分群被擋）→ 用 PERMANOVA 救回成 latent，但 latent 集 只能提升 characterization 分辨、不能當 filter（minN<15 FP-leaning, enrich≈base）。🟢 待 FDR/null 校準確認 reliable 12,868 非噪音。

⑥ HP/LOH tag 比對 ★判別「分群來源 somatic vs germline」尺規判別
做法
把 haplotype tag（HP1 / HP2 / HP1-1 / HP2-1）+ LOH tag 疊到甲基分群上，用 blind-ARI（Adjusted Rand Index）量「甲基分群 vs HP 標籤」的一致度。
判別（用尺規）
對照 imprinting 正控（GNAS/RB1 ARI=1.000，normal DMR 0.758 → 證尺規可靠）+ germline-het null（0.177）。somatic TP ARI 0.135 < null 0.177（p=0.922）→ 判定甲基分群是 germline-allelic 背景，不是 somatic subclone。

💡 這就是為何「甲基分 read」分出來的是 germline haplotype 結構（分不同 haplotype 強、同 haplotype 內 somatic 亞群弱）。imprinting 正控反證「方法有效，NEGATIVE 是真 biology」。🟢

⑦ normal-anchored cis-test ★判別「cis vs copy vs drift」（ISM 獨有）★ 獨有判別
做法
三路比較甲基：normal HP1（配對正常的單倍型）/ tumor HP1 / tumor HP1-1（腫瘤 somatic 子標記）；再用 copy-partition 把表面 allele 甲基差拆成 d_copy（拷貝數造成）vs d_within（真等位 cis 驅動）。
判別
cis = d_within > 1.5×d_copy 且 perm p≤0.05｜copy/subclone-confounded = 混淆主導（BRCA2 即此：表面 −0.122 ≈ tag-partition 混淆 −0.11 + focal cis 邊際 −0.023；⚠ HP1-1 是 somatic subclone tag 非 copy-number）｜drift = germline 漂移｜untestable = pure-ALT / CGI-desert（無 within 真值）。

💡 這是 ISM 相對 modkit 的關鍵獨有能力（見上方 §2）：把「表面看似強 ASM」拆出真相。全基因組 816 loci 經此判別後僅 chr17/TBC1D16 唯一過 cis；6 個最強位點 untestable（需 COLO829/新法）。🟢

Δβ 互補發現通道（必 clustering-gated）+ ⑧ 7-TAG 輸出分類
Δβ 做法
per-position allele 甲基平均差 dbeta_max（抓「分群不明顯但平均差大」的位點）。
Δβ 判別
🔴 不可 naive 加（dbeta_only 分支最 FP-enriched, TP:FP 11.9; naive 加會把 TP:FP 3.7→1.0 collapse）→ union = clustered OR（大 Δβ 且 有 clustering 佐證）。
⑧ 7-TAG
綜合上述每位點貼 1 個語意 TAG：A 乾淨 cis somatic-ASM / B copy-confounded / C germline-allelic / D high-Δβ FP-prone artifact / E latent / F untestable / G 無訊號。

ISM 怎麼下判斷 — 用到的所有「對照尺規」

ISM 不靠單一數字下判斷，而是每個 claim 都要 beat 一把對照尺規。這是它能誠實證死假象的關鍵。

  • 正控imprinting 正控（ARI ruler）：GNAS/RB1 ARI=1.000 → 證「方法能偵測真的 allele-specific 行為」，所以 somatic NEGATIVE 是真 biology 非方法壞。
  • 負控germline-het null：任何「somatic ASM」claim 必須 beat 普通遺傳雜合位點的 baseline（0.177）—— 否則只是 baseline allelic 甲基。
  • 負控subhap-matched 對照：排除「有無子單倍型」confound（TP 3.77% vs FP 1.09% 仍維持 ~3.5×）。
  • 負控paired 負控：證 phasing 現象是 TO-specific（paired gap median≈0, NS）。
  • nulllabel-shuffle / HP-shuffle null：excess-over-null（打亂標籤重算，看觀察值是否在尾端）—— 6/6 樣本 excess>0。
  • 三關de-confound 三關：任何 AUC>0.58 的判別宣稱，必過 within-group OLS（先 GROUP BY）+ AF-bin 交叉 + permutation test 才採信（O11/O12/O13 全在此被證死）。
一句話：ISM 的方法核心不是「找訊號」，而是「用一整套對照尺規 + normal-anchored cis 分解，把假象（copy / germline / confound / 循環）一層層剝掉」—— 剝完後剩下的（如 chr17）才是真的。這就是為什麼它能誠實地說「甲基不能 filter，但這些位點的甲基分群是真的」。
