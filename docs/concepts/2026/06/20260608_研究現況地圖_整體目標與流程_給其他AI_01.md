## L0 — 一句話目標 + 論文主軸

**終極目標**：在癌症長讀（ONT 5mC/5hmC）資料中，以**單 read 解析度** characterize **somatic 突變 + LOH 如何重塑 haplotype/甲基地景**，並交付利用它的 tooling。**這是 read-level epigenetic & haplotype CHARACTERIZATION + TOOLING 論文，不是 variant-calling filter。**

**論文主軸（一段話）**：LOH 區腫瘤只保留單一 haplotype → somatic SNV 形成同-haplotype 子家族、跨樣本可偵測（phasing 訊號）；ASM 真實存在、現象層跨 6 樣本/3 癌種復現，但小、非方向、與 copy-dosage 無關、**不能判別真/假變異**（甲基不能當 filter，三~四種方式證死）。貢獻 = LOH-driven haplotype 結構的 read-level characterization + 一份誠實機制解明的「甲基能/不能做什麼」目錄。

**承載引擎 = ISM (InterSubMod)**：ONT 長讀 read×CpG 甲基矩陣 + read-read 距離 + 階層分群 + 比對 HP/LOH tag + normal-anchored cis-test。C++17 + Python。pipelines: paired_full / paired_pileup / tumor-only。主樣本 HCC1395（有 SEQC2 ground-truth）。

## 🔴 別踩的雷（其他 AI 必讀）

1. **甲基→TP/FP filter 已 concluded NEGATIVE/死四道 — 勿重開**（除非有 C1 新數據/C2 新方法/C3 新前置）。
2. **characterization-set（628/15391/strong-ASM）絕不寫成 filter**（最高頻 overclaim；15391 TP/FP=1.0、strong-ASM anti-discriminative OR=0.194）。
3. **BRCA2 ≠ 乾淨 cis 錨點**（= **subclone/copy-confounded**：HP1-1 是 longphase-S somatic subclone tag 非 copy、非 CN-dosage；focal cis d_within=−0.023 邊際；**% 不 robust**）；勿寫「BRCA2 真 cis-driven / 強 somatic ASM / copy number / 純 artifact / 精確 %」；乾淨 cis 改 **chr17/TBC1D16**；BRCA2 hypo≠canonical hyper，勿當 TSG-silencing 證據。
4. **「Grade A」是 Grade B+**；p=0.0078 是方向一致性非 effect 大小；n=7 = bio-n=6。
5. **所有 ASM 單樣本 HCC1395 ⭐3 / 單 pipeline ClairS-TO**；⭐4 需 COLO829；「跨樣本 6/6」是 phenomenon-level（非 cis-ASM 復現）；「private 0/38」是 underpowered（非 biological privacy）。
6. **改 validated 文件需用戶核准**（加 amendment 不覆寫）；**只 git add 自己的檔**（多 session 並行）；**長 compute 不放 workflow agent step**（背景 Bash 落檔 → Read 驗 → 才寫報告，§13.0）。
