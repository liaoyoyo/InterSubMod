0定調：ISM 是多功能平台，「同一工具、兩個答案」

整個專案最容易被混淆的一點：ISM（InterSubMod）不是「甲基篩變異的篩子」，而是一個 read-level epigenetic context 引擎。同一套輸出（read×CpG 甲基矩陣 → read-read 距離 → 分群 → 比對 HP/LOH/somatic tag → 可用 normal BAM 對照），餵給不同的問題，得到不同的答案：

關鍵洞見：能力 ① 和 ② 用同一套輸出、問不同問題。①「存在嗎」=YES、②「能判別嗎」=NO，兩者並存不矛盾。這就是為什麼「ISM 有用（①③④⑤）」和「甲基當 filter 無效（②）」可以同時成立——把這兩件事分開，整個故事就通了。

1三層光譜：存在 → 可定位 → 可判別（取代原本的二分法）★

盲點掃描抓到我原本「存在 vs 可定位」二分法的真漏洞：缺一個中間態 ——「可定位、但反向 / 無判別」。BRCA2 與 strong-ASM 正是這態：找得到位點，卻無法用來判別真假突變、甚至反指。所以正確的描述是三層光譜，訊號逐層收窄：

中間態還要再分兩種失效機制（硬化 workflow 補的）：(a) 訊號反向 —— strong-ASM 不是沒訊號，而是反向富集在 FP（LOH→單倍型化→低覆蓋→極端 baseline 的回歸極值 artifact，61% 來自 chr8 hotspot，drop-chr8 後 OR 仍 5.16→2.84 表示體系性而非一地）；(b) 雜訊吞沒 —— 效應量在全域被 read-level 稀疏 + 量測噪音稀釋到 AUC≈隨機。

2為何「想法可行 + 有觀察佐證」，卻「無法清楚分析 + 建系統流程程式」★

關鍵在分清兩種 program：

程式類型能不能做為什麼
描述 / 定位 program✅ 做得出給一個位點，ISM 客觀建甲基矩陣→分群→比對 tag→與 normal 對照，告訴你「這位點有沒有 ASM、是不是 cis-driven」。BRCA2 就是這樣被證實的。
判別 / 決策 program❌ 做不出給全基因組自動「判別 TP/FP」或「自動篩出一大批一致位點」，需要一個穩定、跨樣本、可泛化的決策邊界——而證據說它不存在 / 不穩定。

決策邊界為什麼不存在？四層疊加（這也補上了原困難敘述漏掉的維度）：

一句話：「可行」在個案 + 機制 + 描述層（ISM 做得好、有 BRCA2 鐵證）；「無法系統化」在全域 + 跨樣本 + 一致判別層（需要一個被你自己數據否證的決策邊界）。
所以「做不出判別 program」不是工程失敗，是一個被數據證明的科學邊界——這本身就是論文的誠實貢獻。論文是 characterization + tooling，不是 filter / classifier。

3ISM 能力 ①-⑤ × 原始 5 目標 × 構想 映射

你說得對 —— ISM 範圍不只「甲基-單倍型-突變一致事件」。它的輸出餵 5 種問題，分屬不同原始目標（每條附 Cynefin 因果域）：

待你確認：能力②（判別 TP/FP）是目標1+5 的細項，但答案 NEGATIVE。依你指示，已標「已驗證負結果 → 先放緩、不重啟；可能是資料/觀察或工程限制，非必然根本不可能」，寫進論文當誠實負結果，不再投入。

4難度 × 價值矩陣（7 構想，含 n=1/⭐3 caveat）

難度看「現有證據實況」、價值看「對 G6 論文貢獻」。⚠ 盲點掃描提醒：I4a「高可能」必須標明僅 HCC1395 單樣本 ⭐3，別誤讀成跨樣本已驗。

5任務切分：4 桶 + 2 個新獨立子任務

桶內容狀態
A 論文定稿phasing 主軸 + I4a 個案 + I4.3 normal-anchored cis-test 元件（獨立） + I6.1 de-confound + LOSO + 純 phasing 延長 read（獨立，屬主軸不靠甲基）寫

C 協作I2 tag→caller + tag 規格凍結（HKU，不阻塞論文）平行
D 關閉 / 暫緩I1 全部（DEAD）、I3 甲基版（hold）、I5（依賴 I4，deferred）、能力②（負結果放緩）不動手
2 個被掃描抓出、應獨立的子任務：①純 phasing 延長 read（不靠甲基） —— 原本埋在 I3 甲基失敗敘述裡，其實是主軸 phasing 工作，難度/價值完全不同；②normal-anchored cis-test 抽成可重用方法元件 —— 它是論文最硬的方法學亮點之一，應有獨立 deliverable（供 BRCA2/ZAR1L/其他位點重用）。

依賴鏈：I5 卡 I4（個案稀有 → 二階 ceiling）；I3 甲基版卡甲基判別力（AUC 0.505）；能力② 已 NEGATIVE 封頂。

6待你確認 · open gaps（可勾選你想討論的）★

三支 workflow 的 22 條 open gap，收斂成 6 個討論主題。每條附我的初步處置建議；你勾選想深入討論的，或直接告訴我哪些 OK。

  • 質疑：「high cohesion = cis-driven」假設可被挑戰嗎？是否只驗了 BRCA2 一個位點（self-selection bias）？高 cohesion read 會不會只是 mapping/phasing artifact？
    處置：可補強且應補 —— 對 ZAR1L + 幾個 regime-A 位點也跑 normal-anchored cis-test（單樣本內可做、不需新樣本），把「1 個位點」變「>1 個位點」。這會直接把論文最硬的方法學再加固。建議納入 B 桶。
  • 質疑：「M9 跨樣本不可達」聽起來像物理限制，實際是「目前只有 HCC1395 tagged BAM + SEQC2 CN ground-truth」的工程限制。若有 COLO829 tagged BAM + ground-truth，能升 Tier-B 嗎？這對論文位階影響大。
    處置：需你拍板 —— 這是「ASM 維持 ⭐3 單樣本 off-goal」vs「投入做 COLO829 升 ⭐4」的策略決定（上週決議是 off-goal）。我建議論文初版維持 ⭐3 誠實邊界，但把「⭐4 路徑＝COLO829 ground-truth」明列為 future work（而非含糊說「不可達」）。
  • 質疑：「support 有多硬」取決於 reviewer 怎麼讀稀有性。若審閱者認為 0.34%≡無意義，need 預備「為何稀有仍有價值」+「可用於 X / 不適用 Y」的具體功能表。
    處置：寫作前備好 —— (a) BRCA2 真實案例 + 明確癌症機制；(b) 「可用於：位點層級 ASM 驗證、TSG 沉默機制、與 tag 比對；不適用：全基因組 TP/FP 篩選、跨樣本自動判別」功能表；(c) 對標 Nature 級「發現稀有但真實現象 + 方法學亮點」敘事。建議納入 A 桶論文 §價值段。
  • 質疑：read-level 稀疏→β 估計噪音的量化曲線缺失；5mC/5hmC 砍半 artifact 是個案（BRCA2）還是系統性，未跨強位點驗；跨 6 樣本個體特異性只知方向一致、未知大小可比性。
    處置：部分可補（單樣本內） —— coverage vs β CI 曲線 + 對 26 strong 位點驗 5mC/5hmC artifact 規模（= I7a/I7b）可在 HCC1395 內做；跨樣本 β 平行度結構性不可達（誠實標 caveat）。建議 I7a 納入 B 桶必做。
  • 質疑：H-B 顯示甲基對 CN 有弱信號（perm p=0.001 非 null，但 AUC<0.58）。reviewer 可能問：100 萬位點各 AUC 0.54，疊加 ensemble 是否能升到可用判別力？
    處置：記為 open，但不重啟 filter —— 這屬 I3/能力② 留白。依你指示「能力② 放緩、可能是資料/工程限制」，我建議論文標「ensemble 未探索，屬 future work；但單特徵層級已證非判別」，不在本論文投入（避免重開 concluded 方向）。
  • 評選結果建議 adopt_alternative：純 Verdict-Pyramid 給了結論卻沒給「為什麼會這樣」；改用 Cynefin 域分類 + WRAP 自我證偽 + Feynman「為何難」 hybrid 更貼合「解釋為何可行但有界限」。
    處置：本看板已採其精神（§2 Feynman why-hard + §3 Cynefin 域 tag + §6 WRAP-style falsifier 區）。待你確認要不要在正式論文/PI 簡報也走這套，還是維持矩陣為主。

7敘述腳本

60 秒版（給 PI）

「ISM 不是甲基篩子，是一個 read-level epigenetic context 引擎。同一工具、兩個答案：問『甲基-單倍型一致事件存在嗎』——存在，BRCA2 用 normal 對照證明是真 cis-driven；問『能不能演算法式判別真假突變』——不能，全基因組稀有 0.34%、判別力 AUC 0.505 中性。『做不出判別程式』不是工程失敗，是被數據證明的科學邊界，這正是論文 characterization + tooling 的誠實定位。主軸 phasing 本週已到 Grade A 強度。」

30 秒版（給協作者）

「我們能在位點層級可重現地定位並驗證稀有但真實的甲基-單倍型事件（如 BRCA2 promoter），但無法把它做成跨樣本自動篩 TP/FP 的程式——訊號太稀疏、太反向、太樣本特異。所以 ISM 的價值是 characterization 工具 + 可調靈敏度，不是 classifier。」
