## 2. 思想鑰匙：把「存在性」與「可定位性」分開 ★★★

你 7 條構想裡反覆出現的張力，本質是**兩個不同的問題被當成同一個**：

| | 問題 | 現況答案 | 難度 | 價值 |
|---|---|---|---|---|
| **Q-存在** | 甲基差異與 haplotype/somatic 一致的事件，**存在嗎？是真的嗎？** | **是，且至少一個位點是真 cis-driven**（BRCA2 promoter）| **高可能**（已證）| **目標高價值** |
| **Q-定位** | 能不能**用一套演算法、跨樣本、找出很多清楚一致的位點**，並用它**判別 TP/FP**？ | **不能/極稀有/非判別**（全基因組 strong-ASM 僅 0.34%；連續 |Δβ| AUC=0.5049 中性）| **偏難～非常困難** | **目標有益（非高價值）** |

> **這就是你說「肉眼看得到、統計抓不到」的本質**：你的眼睛在做的是 **Q-存在**（這個位點看起來真的有分群一致）——它常常是對的。但你想要的「**可以統計、可以定量數量、可以拿來篩**」是 **Q-定位**——它在 tumor 全基因組層級**訊號根本不足**。
>
> **一旦把這兩件事分開，7 條構想的難度標籤幾乎自動排好**：凡是停在「找/證實個案存在」的 → 偏難但可達且高價值；凡是要求「一致演算法 / 跨樣本 / 判別力 / 篩選」的 → 非常困難甚至不可行，且只剩 characterization 價值。

## 3. 核心困難敘述（科學工程版）

把你親口講的困難，整理成一條可引用的**問題鏈**（每一環都是後一環的前置）：

```
(1) tumor 的 5mC 訊號本身比 normal 混亂          ← 訊號源頭噪音高
        ↓
(2) 缺一套演算法能篩出「大量、清楚、且一致於             ← 定位演算法缺口
    haplotype 或 somatic sSNV」的 5mC 差異位點
        ↓
(3) 因此無法「統計」與「定量數量」這類位點             ← 從個案無法升到群體統計
        ↓
(4) IGV 肉眼看得到不少位點與 tag 一致，但這是                ← confirmation-bias 風險：
    Q-存在；一旦「先看 tag 再判讀」就有確認偏誤            先看 tag→易自我說服
        ↓
(5) TP/FP 特徵統計都無法明確驗證一致關係             ← Q-定位 在全域被否證
    （連續 |Δβ| AUC=0.5049 中性、strong-ASM 反在 FP 富集 5×）
        ↓
(6) 甲基差異位點「無法被客觀定位」                    ← 下游全部卡在這
        ↓
(7) → 無法做下游（判 unphase read、延長 somatic read、
       二次打擊順序…全部缺定位基礎）
```

**為什麼需要 InterSubMod**（這條困難鏈直接推導出工具的存在理由）：
- 第 (4) 環的偏誤風險，正是你建 InterSubMod 的動機——**把「肉眼判讀」換成「位點層級、可重現、可統計、可比對 tag 相關性」的客觀分析**，並能用 normal BAM 的 tag 當對照（normal-anchored cis-test）來驗證「真 cis-driven vs 只是 drift」。
- 第 (5) 環的否證，是 InterSubMod 跑出來的**誠實負結果**——它把「甲基能不能判別」這題在全域釘死為「不能」，反而讓論文站得住。
- 第 (6)→(7) 的依賴鏈，解釋了為什麼 I3/I5 這類「下游構想」難度被 I4 的稀有性**二階放大**。

## 4. 價值錨點：稀有 ≠ 低價值

**BRCA2 promoter 個案**：chr13:32,315,128，HP-axis Δβ=−0.122，抗 Bonferroni，6/01 normal-anchored cis-test 證實**真 cis-driven**（d_cis=−0.142 vs d_drift≈−0.022）。這是一個有明確癌症生物機制（BRCA2 = TSG，promoter hypermethylation 沉默）的真實事件。[src: master_draft.md line 108, 119]

→ **論點**：即使這類事件在全基因組稀有（~26 個獨立位點，0.34%），只要工具能**指出它們、並能以可調靈敏度輸出**，對下游（功能基因組學、TSG 沉默機制、ASM 圖譜）就有很高價值。論文的賣點因此是：

> **InterSubMod = 把 haplotype / LOH / 甲基集中在「位點」上做完整快速分析、並比對 tag 相關性的甲基癌症研究套件**——它不保證「篩掉 FP」，但它能在一個 read-level epigenetic context 框架下，**可重現地刻畫並定位稀有但真實的甲基-單倍型事件**，並把哪些 tag 與哪些位點相關講清楚。

這把「數量稀少」從**弱點**重新定位為**「高特異性、低召回、可調靈敏度」的工具特性**——這是 characterization + tooling 論文的正當賣點，而不是 filter 論文的失敗。
