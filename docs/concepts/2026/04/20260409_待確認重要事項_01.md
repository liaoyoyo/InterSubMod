## 2. 隱含假設清單

以下假設在現有研究推論鏈中被隱含採用，但從未直接驗證或僅有部分驗證。若任一假設錯誤，可能影響相關結論的有效性。

| # | 假設 | 來源 | 若假設錯誤的影響 | 驗證方式 | 狀態 |
|---|------|------|-----------------|---------|------|
| A1 | **Germline ASM >> somatic passenger SNV ASM (3-6x)** | 45+ 篇文獻支持（Jenkinson 2020, Kerkel 2008 等）；Beyond-AUC 綜合驗證引用 | 若 somatic ASM 接近 germline ASM，則「甲基化無法區分 TP/FP」的根因可能不是生物學限制，而是技術限制——修正技術（如更高覆蓋、更精確甲基化呼叫）有可能突破。但 7 methods x 25 features x 748K regions 的實證否決非常強 | 在我們的 7 個樣本上直接定量 germline ASM 與 somatic ASM 的 effect size 比較（需 paired VCF 的 germline calls） | **未直接驗證** (P2) |
| A2 | **SEQC2 truth set 對 HCC1395 是完整的** | Jaccard=0.928 with FDA gold standard；SEQC2 是目前最大規模的 somatic benchmark | 若 truth set 有系統性遺漏（如低 AF 區域），TP/FP label 可能不準確，影響所有 AUC 計算。但 Jaccard=0.928 暗示遺漏率 < 7.2% | 與 GIAB/NIST 其他 truth set 交叉比較；檢查 truth set 在 AF<0.1 區域的覆蓋率 | **部分驗證** (P2) |
| A3 | **PON-only phasing 不降低 phase 品質** | HCC1395 單樣本測試：N50 +99.7%, phased rate +23.6pp | 若其他樣本的基因組特性（如更少 germline SNPs、不同染色體結構）導致 PON-only 降質，修正方案可能不通用 | 在 COLO829、HCC1954 等 2-3 個額外樣本執行 PON-only phasing 並比較 N50/phased rate | **單樣本驗證** (P1) |
| A4 | **Self-phasing 是 TO HP tag 汙染的主要原因** | 完整五步因果鏈（S0-S5），7/7 samples 一致，Cohen's d=-1.20 | 結論本身穩固（穩定度 4），但目前僅在 HCC1395 上做了 PON-only 修正測試。若其他樣本的 self-phasing pattern 不同，修正效果可能不如預期 | 多樣本 PON-only phasing + haplotag 驗證 | **因果確認；修正效果單樣本** (P1) |
| A5 | **甲基化特徵根本無法區分 TP/FP** | 7 methods x 25 features x 748K regions；Beyond-AUC 全面驗證；pure methylation 全 AUC <= 0.58 | 這是 **修正前** 的結論——self-phasing 修正後，29 個 B 類 HP-dependent 特徵的表現可能改變。特別是 within_dom_alt_frac（目前 AUC=0.679，LOSO=0.721）在修正後可能進一步改善 | P0-2 完成後重測 HP-dependent 特徵 AUC | **HP-free 部分確認；HP-dependent 暫停判定** |
| A6 | **HP-free 特徵真的不使用 HP 資訊** | A/B/C/D 四類分類已完成（03_ISM分析價值界定.md） | C 類特徵（~14 個）有間接 HP 依賴（如 GlobalP 取 min(p_alt, p_hp, p_hpfam)、CramersV 取 max），可能傳遞微弱 HP 汙染。但 TO mode 已程式碼移除大部分間接影響（如 QS 的 LOH penalty=0.0） | 逐一檢查 C 類特徵的計算路徑，確認 TO mode 下 HP 成分是否完全歸零 | **大部分確認，C 類需逐一檢查** (P2) |
| A7 | **F1 metric 適合評估 ISM** | PR-AUC 與 ROC-AUC 排序一致（Richardson 2024 確認 AUC 穩健）；BSS 全為負值 | 統計相關性與臨床相關性不同。ISM 即使 F1 微弱（+0.011），在特定高風險基因位點的精確度可能更有價值。但目前無 gene-level 分層驗證 | Phase 2B gene-level evidence 中加入 per-gene F1 分析 | **統計面確認；臨床面未驗證** (P2) |
| A8 | **細胞株樣本代表臨床腫瘤行為** | 7 個細胞株 purity 80-95%，缺乏正常組織混入 | 高純度導致 within_dom_alt_frac 在 TP 中也偏高（~40% TP 有 within_dom=1.0），安全約束下 FP removal=0%。**低純度臨床樣本（30-70%）可能更容易區分**，因 TP 的 ALT reads 稀釋在更多 normal reads 中 | 取得 1-2 個低純度臨床樣本或使用 subsample 模擬（但 subsample 已知有 tumor-normal 組織甲基差異混淆） | **已知局限** (P2) |
| A9 | **1000bp window 是最適 ISM 分析視窗** | 目前固定使用 SNV +/- 500bp，未系統測試其他 window size | CpG island 中位大小 ~800bp，但 CpG shore 延伸到 2kb。不同 window 可能捕捉不同尺度的甲基化 pattern | 系統性測試 500bp / 1000bp / 2000bp / 5000bp window，比較 AUC 和 CpG 覆蓋率 | **未驗證** (P2) |
| A10 | **6 種距離度量已足夠** | NHD / L1 / L2 / Bernoulli / Jaccard / Correlation 已實作並測試 | 未測試 Earth Mover's Distance（EMD）、information-theoretic metrics（如 mutual information、Jensen-Shannon divergence）。但 Beyond-AUC 驗證中 7 方法全面否決暗示距離度量非瓶頸 | 若 Phase 2 需要，可加入 EMD 等度量 | **合理假設但未窮舉** (P2) |

## 3. 穩定度 3 的結論（需特別注意）

穩定度 3（需注意）表示驗證充分但存在可能翻轉的前提或單一樣本限制。以下 5 個結論是最容易因新數據而改變的。

### 3.1 結論 2：PON 移除 99.48% raw FP

| 維度 | 內容 |
|------|------|
| **當前證據** | HCC1395 5kHz：2,717,339 / 2,731,541 = 99.48% |
| **穩定度 3 原因** | 僅 1 個樣本驗證；不同族群的 rare germline 組成不同，PON 覆蓋率可能因樣本而異 |
| **什麼會改變結論** | 若其他樣本 PON 移除率 < 95%，結論需下修。但即使降至 95%，「PON 是最強 filter」的定性結論不變 |
| **需要的驗證** | 在其他 6 個樣本分別計算 PON 移除率（特別是 HCC1954 的 74.6% FP rate 樣本） |
| **優先級** | P1——影響論文定量陳述，但定性結論穩固 |

### 3.2 結論 11：Phase 1A paired F1+0.011

| 維度 | 內容 |
|------|------|
| **當前證據** | External validation delta F1=+0.0112, CI=[+0.0044, +0.0188]；McNemar p=1.44e-51 |
| **穩定度 3 原因** | Discovery holdout CI 含零（+0.0073）；Mixed mode 有害（-0.0206）；H2009 負向（-0.0039）；效應量極小 |
| **什麼會改變結論** | (1) 更多外部樣本中 CI 一致不含零 → 穩定度升至 4；(2) H2009 負向被證明是系統性問題 → 結論需限定為「非 H2009 樣本適用」 |
| **需要的驗證** | (1) 3+ 個獨立外部樣本 OOD validation；(2) H2009 負向根因分析（是否與其特殊基因組結構有關） |
| **優先級** | P1——論文核心主張之一，需更多生物學驗證支撐 |

### 3.3 結論 8：Read-level CONDITIONAL NO-GO (AUC=0.721)

| 維度 | 內容 |
|------|------|
| **當前證據** | within_dom_alt_frac AUC=0.679；LOSO AUC=0.721（首次 >0.70）；但 TP loss <= 2% 下 FP removal=0% |
| **穩定度 3 原因** | within_dom_alt_frac 是 B 類特徵（直接依賴 HP），受 self-phasing 汙染；高純度細胞株是根因——低純度樣本可能更好 |
| **什麼會改變結論** | (1) Self-phasing 修正後 AUC 改善 + 分布分離 → FP removal > 0% → 從 NO-GO 轉為 GO；(2) 低純度臨床樣本 AUC > 0.75 → CONDITIONAL GO；(3) 放寬安全約束至 TP loss 5% 後 FP removal > 0% |
| **需要的驗證** | P0-2 完成後重測 within_dom_alt_frac；低純度樣本驗證（若可取得） |
| **優先級** | P0/P1——**所有暫停判定中最有潛力反轉的方向** |

### 3.4 結論 13：LOH.bed Jaccard=0.847 vs SEQC2

| 維度 | 內容 |
|------|------|
| **當前證據** | LOH.bed 與 SEQC2 FDA gold standard 的 Jaccard=0.847（後修正為 0.928） |
| **穩定度 3 原因** | 僅 HCC1395 1 個樣本驗證；SEQC2 主要是 SNV benchmark，LOH zones 準確性與 SNV truth set 不同；15.3% 不重疊可能含重要生物學差異 |
| **什麼會改變結論** | LOH.bed 生成機制確認（P0-3）可能揭示 kappa=0.670 不一致性的根因，進而重新解釋 Jaccard 值的意義 |
| **需要的驗證** | (1) P0-3 LOH.bed 生成機制；(2) 多樣本 LOH 驗證；(3) 與 CNV 工具（如 ASCAT）獨立比較 |
| **優先級** | P1——觀察值，影響 LOH 相關分析的解釋框架 |

### 3.5 結論 14：QS TO AUC=0.497 (含穩定度 3 的補充結論 15)

| 維度 | 內容 |
|------|------|
| **當前證據** | QS 在 TO 等同隨機（AUC=0.497）；非 LOH 位點 QS AUC=0.549；LOH penalty 解釋 35% 降幅，剩餘 65% 是 scaffold 品質差距 |
| **穩定度 3 原因（補充結論 15）** | LOH 區域內甲基化「全面失效」的表述需精確化——依賴 HP 分群的甲基化特徵在 LOH 區域天然無效（缺乏雙側 HP 對比），但未測試 HP-independent 甲基化特徵（region-level entropy、mean methylation）在 LOH 區域的表現 |
| **什麼會改變結論** | Self-phasing 修正後 TO QS 預期改善至 0.55-0.60（仍遠低於 Paired 0.754）。若修正後 AUC > 0.60，QS 仍有微弱參考價值 |
| **需要的驗證** | P0-4 完成後重新計算 TO QS AUC |
| **優先級** | P1——QS 是 ISM 面向用戶的核心輸出指標 |

| G6 | **PON-only phasing 僅在 HCC1395 驗證** | VCF 層面結果（bias 消除、N50 翻倍）是否在其他 6 個樣本穩定復現？ | 修正方案的通用性 | P1 | 在 COLO829、HCC1954 執行 PON-only phasing |

## 6. Phase 2 前置條件清單

| Phase 2 方向 | 前置條件 | 當前狀態 | 關鍵風險 | 優先級 |
