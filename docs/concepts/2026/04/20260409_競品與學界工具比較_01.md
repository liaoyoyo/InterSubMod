# 競品與學界工具比較：InterSubMod 在癌症甲基化分析領域的定位

> **建立日期**：2026-04-09
> **分析範圍**：ISM 與 14 個學界相關工具的功能、定位、技術路線比較
> **目的**：釐清 ISM 的獨特定位、與現有工具的互補/競爭關係、已知限制

---

## 1. ISM 定位聲明

InterSubMod (ISM) 是一個以 **somatic SNV 為錨點** 的 read-level 甲基化結構分析工具。它從 haplotagged BAM（帶 HP tags）加上 somatic VCF 出發，在每個 SNV 的 1000bp 視窗內建構 Read x CpG 甲基化矩陣，計算六種距離度量（NHD、L1、L2、CORR、Bernoulli、Jaccard），執行 PERMANOVA 與 Chi-squared 統計檢驗，並整合 HP tag、ALT/REF allele、LOH 狀態等生物學共變項。ISM 不做全基因組 DMR 偵測、不做 bulk methylation deconvolution、不做 methylation-based phasing。它的核心價值在於提供 **read-level 表觀遺傳 context for variant interpretation** -- 以單分子解析度觀察 somatic variant 周圍的甲基化結構，而非作為 variant filter。這個「SNV-anchored read-level methylation clustering with HP integration」的完整組合目前在學界是獨有的。

## 4. ISM 的不可替代性論證

以下列出 ISM 具備而其他工具不具備（或僅部分具備）的能力：

### 4.1 Read-level 甲基化分析（非 region-level 或 bulk-level）

大多數甲基化分析工具在 region-level（methclone 的 4-CpG loci）或 bulk-level（CAMDAC、EpiSCORE）運作。ISM 保留每條 read 的完整甲基化向量，建構 Read x CpG 機率矩陣，使得 read-read 距離計算成為可能。MethylBERT 也在 read-level 運作，但其目標是 tumor/normal classification，而非 SNV-centered clustering。

### 4.2 SNV-centered 視窗設計（非 gene-centered 或 DMR-centered）

現有工具的分析單位通常是：
- **基因/啟動子**：CHALM, MethSig
- **DMR**：NanoMethPhase, CpG_Me/DMRichR
- **全基因組 CpG**：CAMDAC, EpiSCORE
- **固定 CpG block**：methclone (4-CpG), PRISM (short regions)
- **特殊 CpG 集合**：EVOFLUx (978 fCpGs)

ISM 的分析單位是「somatic SNV 的 1kb 視窗」，直接將甲基化觀察錨定到 variant 位點。這使 ISM 可以回答「這個 variant 周圍的甲基化結構是否異常？」而非「這個區域是否有 DMR？」

### 4.3 HP tag 與甲基化的整合分析

ISM 的四群組設計（HP1-ALT, HP1-REF, HP2-ALT, HP2-REF）直接連結 haplotype 與 allele 資訊。這使得以下分析成為可能：
- **Allele-specific methylation (ASM) 偵測**：PERMANOVA 在 allele 分群上檢驗甲基化差異
- **Haplotype-specific methylation**：HP1 vs HP2 的甲基化模式比較
- **LOH 偵測**：HP ratio 極端偏斜自動標記 LOH 區域
- **Self-phasing 偵測**：HP tag 與 allele 完全吻合的循環依賴模式

其他工具中，NanoMethPhase 輸出 haplotype-resolved methylation，但不在 per-SNV 層級做整合分析。MethPhaser 使用甲基化做 phasing，但不做 variant characterization。

### 4.4 PERMANOVA on read-read 距離矩陣

ISM 是唯一在 read-read 甲基化距離矩陣上執行 PERMANOVA 的工具。PERMANOVA 檢驗的是「不同群組的 read 之間的甲基化距離是否顯著大於群組內」，這比 t-test/Wilcoxon 在均值上的比較更能捕捉多維分布差異。研究已確認 PERMANOVA 能唯一捕捉某些 entropy imbalance 訊號（ASM 定量分析 POSITIVE 結論）。

### 4.5 Somatic heterogeneity characterization (HPFineNGroups)

ISM 發展出的 HPFineNGroups 指標（fine-grained HP-aware methylation clustering 產生的群組數）已被確認為 somatic heterogeneity marker：
- N >= 4 + NumReads >= 80 時，TP rate = 89.1%
- 低 AF (0.1-0.2) 訊號最強（+50 percentage points）
- 7/7 樣本一致
- Residualized AUC = 0.617（排除 confounders 後仍有訊號）

這是一個 ISM 獨有的、具有生物學意義的輸出，目前沒有其他工具能產生等價指標。

## 5. ISM 的已知限制

### 5.1 甲基化特徵無法區分 TP/FP（全 AUC <= 0.58）

這是 ISM 最根本的限制。經過 Beyond-AUC 七種互補統計方法 x 多層分層 x 25 特徵 x 748K regions 的全面驗證，**純甲基化特徵（排除 HP tag 依賴特徵後）在區分 TP/FP somatic variants 的能力接近隨機**。這不是 ISM 特有的問題，而是反映了一個更深層的生物學現實：germline ASM 的效應量遠大於 somatic passenger SNV 的效應量（文獻支持 3-6 倍差距）。

### 5.2 Self-phasing pollution in TO mode

在 Tumor-Only (TO) 模式下，LongPhase 的 haplotype phasing 使用了 somatic variant 作為 phasing 信號。這導致 HP tag 與 ALT/REF allele 之間產生循環依賴（self-phasing），在 LOH 區域尤為嚴重：62% LOH 在移除 somatic variants 後消失，somatic bias 17.3:1。已確認 PON-only phasing 可消除此問題，但需全量重跑。

### 5.3 HP-dependent 特徵對 TO 不可靠

ISM 在 paired mode 下的有效訊號幾乎全部來自 HP tags。在 TO 模式下：
- HP-free ISM 特徵全 AUC ~ 0.53（隨機）
- All-ISM AUC 0.60-0.64，但 caller_af 單獨就達 0.654
- ISM 在 caller 基礎上僅增加 +0.003 ~ +0.030 AUC
- **TO 模式下 ISM 近乎無效**

### 5.4 Germline ASM >> Somatic passenger SNV effect

ISM 原始假設是 somatic variant 周圍的甲基化模式能反映其真偽或生物學特性。但研究顯示：
- 32-66% SNV 位點有 ASM，且 FP > TP（germline variant 更容易位於 ASM 區域）
- Paired mode 下 fine-pairwise distance 全 AUC < 0.50（反轉），說明 germline ASM > somatic ASM
- 45+ 篇論文支持：cis-regulatory ASM 在人類基因組中普遍存在，效應量遠超 somatic passenger

### 5.5 Identifiability problem

ISM 觀察到「未甲基化的等位基因」不等於「腫瘤特異的等位基因」。在不引入 normal sample methylation reference 的情況下，無法區分：
- 腫瘤特異性低甲基化（真正的 somatic epigenetic change）
- 正常細胞的等位基因特異性甲基化（germline ASM）
- 序列偏好造成的系統性甲基化差異

## 6. 學界方法論趨勢

### 6.1 Single-cell 甲基化（scBS-seq, scNMT-seq）

單細胞甲基化定序正在從技術開發走向大規模癌症應用。關鍵進展包括：
- **scNMT-seq**：同時偵測 chromatin accessibility、DNA methylation、transcription（Clark et al., Nat Commun 2018）
- **MethSCAn**：改良的 scBS-seq 分析框架，更精確量化低覆蓋度下的甲基化水平（Nature Methods 2024）
- **Multi-omic co-assays**：scM&T-seq, scCOOL-seq, snNMT-seq 等同時觀測多層 omic

**與 ISM 的關係**：ISM 使用的 read-level 分析某種程度上模擬了 single-cell methylation（每條 read 近似一個細胞的片段）。但 ISM 的解析度受限於 read length（ONT ~10-50kb），而非真正的 single-cell 全基因組。未來 single-cell ONT 的成熟可能使 ISM 的 read-level 框架直接遷移。

### 6.2 Long-read native methylation（ONT, PacBio）

長讀定序的原生甲基化偵測正在快速演進：
- **ONT 5kHz basecalling**：CpG 偵測準確度持續提升，支持 5mC + 5hmC 雙通道
- **PacBio SPRQ-Nx**：預計 2026 年支持 5hmC 偵測
- **pb-CpG-tools**：PacBio 官方提供 CpG methylation 二次分析工具
- **覆蓋度需求降低**：NanoMethPhase 已證明 ~10x 即可有效偵測 ASM

**與 ISM 的關係**：ISM 目前僅支持 ONT MM/ML 標籤。PacBio 的 HiFi reads 準確度更高但讀長較短，可能需要不同的距離計算策略。5hmC 雙通道是 ISM 尚未開發的維度。

### 6.3 Multi-omic 整合（methylation + mutations + expression）

學界正朝「多模態資料整合」方向聚集：
- **Long-Read POG**（Cell Genomics 2024）：CNV + aDMR + ASE + somatic 在同一患者整合
- **TRACERx**（Nat Genet 2025）：CAMDAC + ITMD + M_R/M_N 整合分析
- **t-nanoEM**（Cell Reports Methods 2025）：hybridization capture + ONT + methylation
- **IMPALA**：Long-Read POG 使用的多訊號整合框架

**與 ISM 的關係**：ISM 目前停留在 methylation + HP tag 的二維整合。Phase 2B 計劃的 gene-level evidence integration 正是對齊此趨勢。

### 6.4 Spatial Transcriptomics meets Methylation

空間表觀遺傳學是 2025-2026 年的新興領域：
- **Spatial epigenome-transcriptome co-profiling**：同一組織切片上同時觀測甲基化與轉錄組（Nature 2023, Nature 2025）
- **SPACE-seq**：利用 polyadenine-tailed epigenomic libraries 實現 spatial multiomics
- **腫瘤微環境空間分析**：結合空間轉錄組與免疫浸潤分析

**與 ISM 的關係**：ISM 的 read-level 分析概念上與 spatial 甲基化分析互補（ISM 看 intra-tumor heterogeneity at variant level，spatial 看 inter-cellular heterogeneity at tissue level）。兩者結合可能揭示 variant-associated epigenetic changes 的空間分布。

### 6.5 AI/ML 用於甲基化 Pattern Recognition

深度學習在甲基化分析中的應用正在加速：
- **MethylBERT**（Nat Commun 2025）：Transformer-based read-level methylation pattern classification
- **EMethylNET**：XGBoost + DNN 多癌種分類，98.2% 準確度
- **GRAIL Galleri / CancerSEEK**：cfDNA 甲基化 + AI 做 multi-cancer early detection (MCED)
- **Graph-based models**：用圖神經網路建模 CpG 間的空間關係

**與 ISM 的關係**：ISM 目前使用 unsupervised clustering + 統計檢驗。MethylBERT 式的 supervised learning 可能比硬規則更 robust，是 ISM Phase 1 方向 E 的直接參考。但 ISM 的 PERMANOVA 框架在不需要訓練資料的場景中仍有其價值。

                    │                         │                         │
            ┌───────┴───────┐         ┌───────┴───────┐         ┌──────┴───────┐
            │   Phasing     │         │ Deconvolution │         │  Clonality   │
            │   Tools       │         │    Tools      │         │    Tools     │

         └──────────┬──────────┘    └─────────┬─────────┘    └────────┬────────┘

                              └───────────────────────────────┘

ISM 位於三大工具類別的交匯處，但不完全屬於任何一類。它的獨特性在於將 phasing（HP tags）、deconvolution 概念（ALT/REF 分群）、clonality 分析（read-level clustering）整合到一個 variant-centered 的框架中。這也意味著 ISM 的競爭對手不是單一工具，而是多個工具的組合使用。ISM 的價值定位因此是：**在單一框架中提供 variant 位點的 read-level 表觀遺傳 context，補充但不替代上述任何一類工具**。
