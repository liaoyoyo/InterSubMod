## §2 HP tag 階層完整定義

LongPhase-S `--somaticMode`（mainline v1.7.3 內建）輸出的 BAM HP tag **不只 HP1/HP2/HP3 三值**，而是 5 階層 string 編碼（`HP:Z:1-1`、`HP:Z:2-1` 等）。完整 enum 定義在 mainline source code：

**Enum source**: `src/haplotag/HaplotagType.h:97-108` (HP1_1=5 / H2_1=7 等，mainline v1.7.3 內建)

| HP 值 | 語意 | 用途 |
|-------|------|------|
| `1` | 純 germline het HP1 anchor 支持 | 主 haplotype 1 |
| `2` | 純 germline het HP2 anchor 支持 | 主 haplotype 2 |
| `1-1` | HP1 + 一個 somatic SNV 累積 | 含 tumor allele 的 HP1 sub-clone |
| `2-1` | HP2 + 一個 somatic SNV 累積 | 含 tumor allele 的 HP2 sub-clone |
| `3` | 無法 phase（fall-through） | unphased / 邊界 |

**HCC1395 baseline tag 統計**（per A3 README + A8 全 chr 統計）：

| HP | 占比 (autosome 平均) | 解讀 |
|----|---------------------|------|
| HP1   | ~25-32% | 主流 phasable |
| HP2   | ~26-31% | 主流 phasable（與 HP1 平衡）|
| HP1-1 | ~2.5-5% | somatic 累積 sub-clone |
| HP2-1 | ~2.4-3% | somatic 累積 sub-clone |
| HP3   | < 1% per autosome | fall-through 極少 |
| no_HP | ~36-43% | 未 tag（mappability / anchor 不足）|

> 三個重點：(a) `-1` 尾綴 = 有 somatic anchor 進來；(b) HP1 vs HP2 在 autosome 整體平衡（per A8），但 chr 內部局部仍可有偏差（如 §10 chr8 LOH dominance）；(c) HP3 fall-through 在 chr6 / chr16 / chrX 顯著升高（per A8 §10），其他 chr < 0.5%。

## §4 ISM pipeline 細節

InterSubMod (ISM) 在 LongPhase-S 輸出的 tagged BAM 之後接手，主要 C++ 模組：

| 模組 | 路徑 | 職責 |
|------|------|------|
| `main.cpp` | `InterSubMod/src/main.cpp` | CLI / region iteration |
| `MatrixBuilder.cpp` | `InterSubMod/src/core/MatrixBuilder.cpp` | 從 BAM read MM/ML 解析 CpG 甲基化機率，組成 read × CpG matrix |
| `DistanceMatrix.cpp` | `InterSubMod/src/core/DistanceMatrix.cpp` | 6 種距離度量（Manhattan / Cosine / Euclidean / Jaccard / Hamming / Pearson）read-read 距離 |
| `SignificanceAnalyzer.cpp` | `InterSubMod/src/core/SignificanceAnalyzer.cpp` | Fisher / 顯著性檢定 |
| `render.py` | `InterSubMod/scripts/render.py` | 輸出 read × CpG heatmap + hierarchical clustering dendrogram |

**Region 輸出結構**（per `output-structure.md` rule）：

```
{region_name}/
├── metadata.txt
├── reads.tsv
├── methylation.csv             ← read × CpG 機率矩陣
├── distance_matrix_{METRIC}.csv ← 6 metric 各一檔
├── significance_summary.csv
└── *.png                        ← heatmap + cluster
```

## §5 改進 tag 構想（6 狀態 + 缺失值補完 + HP 細分樹 linear depth naming）

用戶 5/22 提出的核心構想：**現行 LongPhase-S HP tag 只看 germline het anchor + 1 階 somatic 累積，遺漏多階 sub-clone 演化結構**。改進方向有三層；v4 採 **linear depth notation** (per user 5/23 選)。

### §5.1 兩位點 6 狀態 R/A/X matrix

對相鄰兩個 SNV 位點，每個 read 在每位點的可能狀態為：

- **R** (Reference) = 該 read 在該位點顯示 ref allele
- **A** (Alt) = 該 read 在該位點顯示 alt allele（含 somatic SNV）
- **X** (eXtinct/missing) = 該 read 未覆蓋該位點 / base quality 不足 / 對齊邊界

兩位點組合 = 3 × 3 = 9 種，其中 4 種含 X 缺失需補完（F2v2 演化樹 inset 替換舊 F2）：

![F2v2 兩位點 R/A/X 9 狀態組合 + 演化樹 inset](../../../research/hku_collaboration/figures/F2v2_6state_with_tree_inset.png)

### §5.2 X 缺失值補完規則（用 ISM 甲基聚類 + 鄰近 SNV vote 3-step flow）

對 4 種 X 缺失模式（RX / AX / XA / XR），ISM 用 read 的甲基化模式聚類 + 鄰近 SNV vote，**把 X 的 read 歸到最相似的 R 或 A 群**（F3v2 取代舊 F3，4-panel + 3-step icon）：

| 缺失模式 | 已知 | 3-step 補完規則 |
|---------|-----|----------------|
| **RX** | locus 1 = R | (1) 同 PS read 集合 → (2) ISM methyl cluster → (3) 鄰近 SNV vote → {RR, RA} |
| **AX** | locus 1 = A | 同上 → {AA, AR} |
| **XR** | locus 2 = R | 同上推 locus 1 → {RR, AR} |
| **XA** | locus 2 = A | 同上推 locus 1 → {AA, RA} |

![F3v2 4 種 X 補完規則示意（3-step flow）](../../../research/hku_collaboration/figures/F3v2_x_imputation_flow.png)

### §5.3 HP 細分樹 — linear depth naming 4 場景

per v4 plan §A4 + user 5/23 選定的 linear depth notation：

- `HP1` = germline root（RR）
- `HP1-1` = HP1 的第一代 child（+1 somatic event α）
- `HP1-1-1` = HP1-1 的第二代 child（+2 somatic events，linear extension）
- `HP1-2` = HP1 的第一代 child 但 mutation event 不同（兩個 1st-gen events）
- `HP2`/`HP2-1`/`HP2-1-1` 同理（germline het 另一條 haplotype）

**4 場景結構**：

| 場景 | 觀察 | 結構 | 編碼 |
|------|-----|------|------|
| **A linear** | `{RR, AR, AA}` | HP1 → HP1-1 → HP1-1-1 | 純 linear，每步 +1 somatic |
| **B branching 1st-gen** | `{RR, AR, RA}` | HP1 → {HP1-1 (AR), HP1-2 (RA)} | 第一代兩 mutation event 分支 |
| **C branching + linear** | `{RR, AR, RA, AA}` | HP1 → {HP1-1, HP1-2} → {HP1-1-1, HP1-2-1} | AA 歸屬 ambiguous（紫色），用甲基聚類 / 鄰近 SNV 區分 |
| **D HP1 + HP2 並行** | 兩 lineage 各自 | germline het root → HP1 + HP2 各自帶 A/C 結構 | 全圖 |

![F4v2 演化樹 4 場景（A/B/C/D linear depth）](../../../research/hku_collaboration/figures/F4v2_evolution_tree_4scenarios.png)

### §5.4 用戶 PowerPoint slide 範例

- **Slide #1「往前推三點」** — chr2:18,086,020 FP 候選位點 — 詳細實證見 §9
- **Slide #2「合理推論 LOH + sub-clone」** — HP 細分樹從 HP2 → HP2-1 → HP2-1-1 推進，每層用甲基同/異群分支 — 這對應**腫瘤內 sub-clone 演化軌跡**（與 §10 A6 stratification finding 對照：subclone proxy 在 LOH inside 反而最低，與預期相反）

> **待 HKU 對齊**：(a) HP1-1-1 / HP1-2-1 / HP1-1-2 linear depth naming 是否採納；(b) ISM cluster cutoff 用 cosine 還 Manhattan，τ 門檻值；(c) 兩位點外推到 N 位點時的 X 比例上限。

## §6 HCC1395 paired 流程下的實證數據（A2 finding）

A2 pysam analysis 對 tagged BAM 直接掃 chr1+chr8+chr19，產出三組實證：

### §6.1 PS set TP 位點分佈 ✅ POSITIVE

從 SEQC2 v1.2.1 PASS-only TP positions（chr1 3,440 + chr8 2,605 + chr19 874 = 6,919 total），按 read PS tag 聚合：

| 指標 | 值 |
|-----|----|
| PS sets 總數 | **759** |
| **median TP / PS** | **5** |
| IQR [p25, p75] | [2, 12.5] |
| max TP / PS | **90** |
| **PS sets ≥2 TP** | **85.9% (652/759)** |

→ 絕大多數 PS set 含足夠 TP 位點做 read-level 分群（85.9% ≥2 TP），ISM 改進 tag 構想在絕大多數 PS 上有發揮空間。

![A2_1 PS set TP 位點分佈](../../../research/hku_collaboration/figures/A2_1_ps_set_tp_count_dist.png)

### §6.2 相鄰 TP somatic pair common reads ✅ POSITIVE for 緊鄰

按 chrom+pos 排序，每個 PS set 內相鄰 TP pair (i,j) 算 distance + common reads，共 3,963 pairs：

| 區段 | pairs | median common reads |
|------|-------|---------------------|
| ≤ ±16 bp（caller window 內）| 96 (2.4%) | **70.5** |
| (16, 500] bp | 86 | 64 |
| > 500 bp | 3,781 | 16 |

→ caller 視窗內 pair 共享 reads 4.4× 於遠距 pair；但只占 2.4%。median pair distance 17.4 kb 遠超 ONT 平均 read 長度 → **95% pair 需 LongPhase-S PS chaining 跨越單 read**。

![A2_2 相鄰 TP common reads 分布](../../../research/hku_collaboration/figures/A2_2_common_reads_xy.png)

### §6.3 LOH HP-missing ROC vs SEQC2 truth ❌ NEGATIVE

1 kb bin × min 5 reads，full chr1+chr8 scan, 324,595 bins：

| 指標 | Overall | chr1 | chr8 |
|------|---------|------|------|
| n_bins | 324,595 | 199,075 | 125,520 |
| LOH fraction | 67.7% | 48.0% | **99.1%** ⚠ |
| **AUC** | **0.504** | 0.509 | **0.446** ⚠ |

→ ❌ Hypothesis（AUC > 0.7）清楚被拒絕。

**機制解釋**：LongPhase-S `--somaticMode` 用 **heterozygous germline SNV** 為 phasing anchor，LOH 不改變 germline het 位點（germline-from-normal 仍是 het），只改 tumor allelic frequency → LOH 區段 reads 仍拿到 HP tag → HP-missing rate 不變。

→ **要間接驗 LOH 需改觀察 tumor HP1 vs HP2 read count imbalance，而非 HP-missing rate**。

![A2_3 LOH HP-missing ROC（AUC 0.504）](../../../research/hku_collaboration/figures/A2_3_loh_hp_missing_vs_seqc2.png)

### §9.2 4 層證據（4-Layer Evidence）

**Layer 1 — SEQC2 truth**：14 位點中 4 個 TP（in_tp_vcf=1），其中 3 個亦由 ClairS-TO ssrs 報出（in_clairs_ssrs=1）+ chr2:18,086,020 (FP candidate)。區段密度（4 TP / 32 kb = 125 TP/Mb）顯著高於 chr2 全 chr 平均（~10 TP/Mb）→ **真實 somatic-rich hot region**。

**Layer 2 — LOH context**：14 位點全在 SEQC2 LOH 區（`in_loh=1`）→ tumor-only haplotype（HP1 對偶被刪除或 copy-neutral LOH）→ 殘留 haplotype 上的 somatic 累積會集中於 HP2-1 子分支。

**Layer 3 — HP2-1 dominance**：14 位點 HP2-1 比例 58%–76% 一致偏高（平均 ~67%）→ 整段是 **HP2-1 sub-clone 的 signature region**。chr2:18,086,020 的 HP2-1=71% 在區段內最高之一，與該位點 AF=0.494（接近 het level）一致 — 候選位點與整段 HP2-1 框架對齊。

**Layer 4 — caller blind spot**：ClairS-TO 在 chr2:18,086,020 ±16 bp 內僅看到自己中心位點的 33 bp 區段，**完全看不到周圍 13 個鄰近位點的 HP2-1 累積證據**（最近的 in_loh 位點距離 = 4,332 bp >> 16 bp）。ISM 補完此 phasing 訊號後，候選 FP 在 HP2-1 sub-clone 框架下可重判定。

### §9.3 FP 機制 — LOH 崩潰下的 caller 誤判

**機制假設**：
1. LOH 區的 het balance 崩潰 → tumor reads 出現 AF=0.494（看似 het 但其實是 HP2-1 single-haplotype 飽和）
2. ClairS-TO pileup 看到該 AF 結構時 model 無法區分「真 het somatic」與「LOH × sub-clone saturated alt」
3. 周圍 9 個 anchor 位點（HP2-1 累積但 ClairS-TO 未 call）的證據被 ±16 bp window 過濾掉
4. 結果：model 把 LOH × HP2-1 集中區的 sub-clone signature **誤判為 FP**（或者反之，部分真 sub-clone 位點被 SEQC2 truth set 漏標 → ssrs called 但 not in truth → 自動分到 FP）

**ISM 補完路徑**：
- 串接 14 位點 HP 簽名 → 區分「true FP」（隨機散落 HP）與「LOH-driven sub-clone TP candidate」（一致 HP2-1）
- 用 §5.2 4 規則（RX/AX/XR/XA）對 chr2:18,086,020 周邊的 X 缺失補完 → 在 HP2-1 sub-clone 框架下可獲得 sharper 判定
- 寫回 BAM aux field `HP:Z:2-1-1` + `MC:Z:cluster_A` → future ClairS-TO retraining 可吸收

### §9.4 Caveat

1. F7 為單一 region 案例 — 結論 FP 機制需 cross-validate 其他 LOH × HP-dominant region
2. SEQC2 truth set 本身可能漏標 LOH-driven sub-clone TP（陽性偽陰性）— 此候選 FP 是否本就應為 TP 需 orthogonal validation（如 Wakhan / SAVANA）
3. ISM cluster cutoff τ 未驗證；F5 ISM heatmap 為示意非真實該 region 輸出
4. 14 位點 anchor 累積 HP2-1 但僅 4 個被 ClairS-TO ssrs 報出 — anchor 不召回率高（10/14 = 71%）反映 caller blind spot 嚴重性

1. **chrX 全落 Z6**（SEQC2 BED 不標 chrX）→ X-inactivation 假性訊號（subclone h1-side = 0.80）
