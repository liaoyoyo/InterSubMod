## §2 LongPhase-S 5 階層 HP tag

LongPhase-S `--somaticMode` 在 mainline v1.7.3 已內建 5 階層 string 編碼（`HP:Z:1-1` 等），enum 定義在 `src/haplotag/HaplotagType.h:97-108`（HP1_1=5 / H2_1=7）：

| Tag | 語意 | 來源 |
|------|------|------|
| HP1 / HP2 | 純 germline het anchor 直接 phase | LongPhase phase pass 1 |
| HP1-1 / HP2-1 | germline anchor 不足、由 somatic SNV 補 phase | mainline `--somaticMode` pass 2 |
| HP3 | ambiguous（衝突或 conf 過低） | fallback |

HCC1395 baseline 統計（per A3 + A8）：5 tag 全現；HP1 ~25-32%、HP2 ~26-31%（autosome 平衡）、HP1-1+HP2-1 ~5%、HP3 < 1% per autosome。BAM @PG 真實揭示：**非 CCU fork、非 v1.0.0**，而是 mainline `twolinin/longphase` v1.7.3 + `--somaticMode` + ClairS-TO ssrs `pileup/HCC1395_methyl_PASS.vcf` + SEQC2 `--highCon-snp` 引導（per A1 §Q4 v4 終版）。

## §3 改進構想 6 個核心 claim

1. **6 狀態 R/A/X 細分**：兩 SNV pair 觀測 (RR/RA/AR/AA + RX/AX/XR/XA + XX = 9)，X = read 不 cover 該位點
2. **4 缺失補完規則**：RX→{RR, RA} / AX→{AA, AR} / XR→{RR, AR} / XA→{AA, RA}，用 ISM read×CpG 甲基相似度聚類 + 鄰近 SNV vote 決定
3. **HP 細分樹串聯多 SNV pair（linear depth naming）**：`HP1` = germline root → `HP1-1` = HP1 第一代 child（+1 somatic）→ `HP1-1-1` = HP1-1 第二代 child（+2 somatic，linear extension）；`HP1-2` = HP1 同層 sibling（不同 1st-gen mutation event），`HP1-1-2` = HP1-1 第二代不同 mutation event sibling
4. **ISM read × CpG matrix 接口**：每條 read 內 CpG 位點 5mC 機率向量，作為 read clustering 距離度量（6 metric：Manhattan / Cosine / Euclidean / Jaccard / Hamming / Pearson）
5. **預期 caller 受益**：median TP pair distance 17.4 kb >> ClairS-TO ±16 bp window，僅 2.4% pair 落在 window 內；剩 97.6% pair 的 phasing 訊號透過 BAM HP tag → ClairS pileup tensor channel 6 (phasing_info) 進入 model
6. **演化樹編碼系統（linear depth notation，per user 5/23 選）**：取代舊版 `HP1-1-1 = sibling 1, HP1-1-2 = sibling 2` 混淆命名，新規則固定 depth index 從 root 起算（見 §4 表）

## §4 演化樹編碼系統（linear depth notation 4 場景）

per user 5/23 選定的編碼規則 + plan v4 §A4 + v4_evolution_figures README：

| 場景 | 觀察組合 | 結構 | 樹形編碼 |
|------|---------|------|---------|
| **A 純 linear** | `{RR, AR, AA}` | HP1 → HP1-1 → HP1-1-1 | 兩個位點都+1 somatic，linear 累積 |
| **B branching 1st-gen** | `{RR, AR, RA}` | HP1 → {HP1-1 (AR), HP1-2 (RA)} | 同一 1st-gen 起源 + 兩個 mutation event 分支 |
| **C branching + linear** | `{RR, AR, RA, AA}` | HP1 → {HP1-1, HP1-2} → {HP1-1-1, HP1-2-1} | AA 歸屬不確定 → 用甲基聚類 / 鄰近 SNV 區分（紫色 ambiguous）|
| **D HP1+HP2 並行** | 兩 lineage 各自 | germline het root → 兩條 haplotype 各自帶 A/C 結構 | 全圖：HP1 lineage + HP2 lineage 共 root |

樹形範例（場景 C）：

```
germline het Ref（root）
├── HP1
│   ├── HP1-1 (＋somatic event α)
│   │   └── HP1-1-1 (＋somatic event β; linear)
│   └── HP1-2 (＋somatic event γ；sibling of HP1-1，非 child)
│       └── HP1-2-1 (＋somatic event δ; linear)
└── HP2
    └── ...（mirror structure）
```

> **命名差別**（v4 vs 舊 plan）：v4 採 **linear depth index** — `HP1-1-1` 表「HP1-1 的直系 linear extension」，不是「HP1-1 的第一個 sibling」。同層分支用 `HP1-2 / HP1-3` （第一代 siblings 多事件）或 `HP1-1-2`（HP1-1 第二代多事件）。

## §5 chr2:18,086,020 完整實證例子摘要（per F7 figure + 14 位點 4-layer evidence）

從 `data/F7_14sites_status.tsv`（14 sites 涵蓋 chr2:18,068,480 – 18,100,683 = 32 kb span）：

**已知事實**（直接從 TSV 抓）：
- chr2:18,086,020 屬 ClairS-TO ssrs 報出位點（`in_clairs_ssrs=1`），但 **不在 SEQC2 TP truth set 中**（`in_tp_vcf=0`）→ candidate FP
- 14 位點全在 SEQC2 LOH 區（`in_loh=1`）
- 14 位點 HP_dominant 一致為 HP2-1，比例範圍 58%-76%（區段內 HP2-1 累積支持）
- chr2:18,086,020：DP=77，AF=0.4935，HP2-1=55/78 (71%) — 接近 het level，HP2-1 dominant

**4 層證據（4-layer evidence callout，per HKU 報告 chr2 region IGV-style 圖 F7）**：
1. **Layer 1 — SEQC2 truth**：14 位點中 4 個 TP（in_tp_vcf=1），其中 3 個亦由 ClairS-TO ssrs 報出（in_clairs_ssrs=1）+ chr2:18,086,020 (FP candidate) — 顯示區段是真實 somatic-rich 區
2. **Layer 2 — LOH context**：整 32 kb 全 LOH → tumor-only haplotype 表現會集中於 HP2-1 子分支
3. **Layer 3 — HP2-1 dominance**：14 位點 HP2-1 比例 58%-76% 一致偏高 → 整段是 HP2-1 sub-clone 的 signature region
4. **Layer 4 — caller blind spot**：chr2:18,086,020 ±16 bp 內 ClairS-TO 看不到周圍 13 個鄰近位點的 HP2-1 證據；ISM 補完此 phasing 訊號 → 候選 FP 在 HP2-1 sub-clone 框架下可重判定

**FP 機制 — LOH 崩潰**：caller 在 LOH × HP2-1 集中區因失去 het balance 把 sub-clone signal 誤判為 noise；ISM 串接 14 位點 HP 簽名後可區分「true FP」（隨機散落 HP）與「LOH-driven sub-clone TP candidate」（一致 HP2-1）。
