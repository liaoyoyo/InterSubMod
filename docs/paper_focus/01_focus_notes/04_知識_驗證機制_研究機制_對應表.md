# 知識 ↔ 驗證機制 ↔ 研究機制 對應表

> **L0 一眼結論**：每個結論都能回答三件事 ——「**用什麼方法驗的（驗證機制）**」「**為什麼會這樣（研究機制）**」「**證據多硬（tier）**」。filter 類結論用的是**對抗性驗證**（LOSO/null），所以最硬；cis/跨樣本類用的是**copy/null 控制**，所以多在 🟡 待原檔對賬。
>
> **L1 重點邏輯**：
> ① **驗證機制決定可信度**：LOSO 留一 + permutation null = 最對抗、最可防守（filter-DEAD 因此最硬）。
> ② **研究機制決定能不能推廣**：phasing/ASM 的研究機制是「LOH 單一 haplotype」——這是 single-pipeline + 單樣本天花板的根。
> ③ **外部佐證只在 characterization/negative 借得到力**（Kapoor leakage、Martin-Trujillo CN-confound）；filter-positive 方向沒有外部可借（因為它本來就不成立）。

## L2 — 驗證機制速查（每個機制測什麼／何時用）

> 這是「研究機制庫」：要驗一個新 claim 時，先問「它屬哪類」，再挑對應機制。

| 驗證機制 | 測什麼 | pass / fail 判準 | 用於 |
|---------|--------|-----------------|------|
| **LOSO 留一交叉** | 結論是否 sample-level 循環 | held-out 與 in-dist 落差大 → 循環 fail | 任何「跨樣本 filter/predictor」claim |
| **permutation / label-shuffle null** | 訊號是否超過隨機 | 觀察值落在 null 內 → 無訊號 | AUC / excess / 任何 effect 是否真 |
| **subhap-matched 對照** | 是否「有無子單倍型」confound | matched 後差異消失 → confound | ASM somatic-enrichment |
| **MW + signed ρ falsification** | 變因是否 driver（可證偽）| 不可區分 / 反向 → driver 被 REFUTED | copy-dosage、任何 dosage-artifact 假設 |
| **condition Fisher 分層** | FP 富集是訊號還是 regime | OR 集中在 mechanistic 同一 regime → artifact | high-Δβ→FP |
| **blind-ARI ruler + imprinting 正控** | 分群是否 somatic-specific | TP ARI < germline-het null → germline-allelic | subclone/clustering specificity |
| **n signed-rank + bootstrap + paired 負控** | 方向是否跨樣本一致 + TO-specific | paired 負控顯著 → 非 TO-specific | phasing gap |
| **control-for-methylation partial-r** | 關聯是甲基 mediator 還是別的 | 控甲基 r 幾乎不動 → 非甲基（collider）| AF↔NGroups 歸因 |
| **normal-anchored cis-test** | 真 cis vs copy vs drift | within>HP perm 顯著 → cis；否則 copy/drift | 每個 cis-candidate |
| **excess-over-null（genome-wide）** | 現象是否跨樣本復現 | 6/6 excess>0 → phenomenon 復現 | 跨樣本 generality |

## L1 — 三條提醒（用這表時）

- 🔴 **最硬的是 NEGATIVE**：①②③④⑥⑦⑧ 都 🟢；filter-DEAD 用的是最對抗的 LOSO+null，所以是論文最可防守的質量。
- 🟡 **cis / 跨樣本還在 tsg 另一檔**：⑤⑨⑪⑫ 待原檔對賬（投稿前定位 → `02 文件庫` + `05 任務樹 P-provenance`）。
- 🔵 **沒有 filter-positive 列**：因為任何「用甲基判別」的 claim 都進不了這張表（驗證機制一上就 fail）——這本身就是論文的結論。
