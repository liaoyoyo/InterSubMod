## 3. 🔴「共驗證」的兩種意思 —— 必須選對（全資料夾最重要的一個 framing）

「共驗證」可以指兩件**完全不同**的事，一個成立、一個已死四道：

| | 意思 | 例 | 裁決 |
|---|------|----|------|
| ✅ **(A) 正交佐證** orthogonal corroboration | 三訊號互為**獨立證據**，在 LOH 約束下交織、佐證**同一個** haplotype 重塑事件 | LOH 區 somatic SNV 形成同-HP1 子家族（somatic↔haplotype 正交佐證，🟢 7/7）；其中少數位點伴隨真 ASM（甲基 characterize 該事件） | **成立、可防守** |
| ❌ **(B) 互相篩選** mutual filtering | 用一個訊號**判別/篩選**另一個 | 用甲基 filter somatic TP/FP | **已死四道**（LOSO 循環 / AUC=0.505 / ~4% sens / clustering=germline-allelic）|

> **結論**：你的標題用 **(A)** 解讀 → 強且誠實，等同我們收斂的 characterization+tooling 主軸。**任何 sub-item 一旦滑向 (B)（「用甲基刪 FP」「用甲基當 marker 判別 subclone」）就撞 concluded NEGATIVE。** 這條線是全資料夾的判準。

**「共驗證」三條軸現況**（哪幾對真的能互相佐證）：
- **somatic ↔ haplotype**：🟢 **成立**（phasing 脊柱，7/7 p=0.0078125，但 by-construction 部分循環 → Grade B+）
- **haplotype ↔ 甲基**：🟡 **部分/未來式**（V10 顯示 LOH 內甲基能 phase 且「非 copy」；但 aDMR×LOH 非富集 → umtag future-work）
- **somatic ↔ 甲基**：🟢 **只在 characterization 層成立**（ASM somatic-enriched 3.95%>1.07%）；🔴 **判別層死**（不能 filter）

## 5. Glossary（核心術語 — 給新讀者/其他 AI）

| 術語 | 一句話 |
|------|--------|
| **ASM** | allele-specific methylation；同一位點兩 allele/haplotype 甲基不同 |
| **HP-axis vs ALLELE-axis** | HP-axis（HP1 vs HP1-1）somatic-controlled；ALLELE-axis（ALT vs REF）被 germline 基線 confound → 必跑 germline-het null |
| **Δβ** | per-position allele 甲基**平均差**（連續量）；ISM 不直接用（見方向卡 M3）|
| **NGroups / HPFineNGroups** | read 依 HP tag {HP1,HP1-1,HP2,HP2-1} 分的 sub-family **數**（capped 4）；🔴 **是 HP-tag count 不是甲基量**（HD-4）|
| **CramersV gate** | ISM 判 read×CpG 分群是否 reliable（Cochran 最小期望格≥5）；CV=reliable?v:0 |
| **normal-anchored cis-test** | normal HP1 / tumor HP1 / tumor HP1-1 三路比，分真 cis-driven vs drift vs copy |
| **cis vs copy vs drift** | cis=真 allele 內甲基驅動｜copy=拷貝數造成的表觀差｜drift=隨機/germline 漂移 |
| **regression-to-extreme** | 高-Δβ 聚 FP 不是判別力，是 LOH→低覆蓋→極端 baseline 的同一 regime artifact |
| **LOSO** | leave-one-sample-out；測 sample-level 循環性（filter 死第一道）|
| **excess-over-null** | 各樣本 private somatic 的 ASM 率減 HP-shuffle null；6/6>0 = phenomenon 復現 |
