# 研究方向卡 — 可行性裁決（你的 6 方向 + 3 ISM 方法確認 + 1 困難）

> **L0 一眼結論**：你的 6 個方向裡 **2 個要否決（D4/D6，已被本週分析推翻）**、1 個 filter 用法否決但可當觀察（D5）、3 個值得做但要先確認（D1/D2/D3）；ISM 4 個確認裡 **2 個是高價值該做（catalog/合併Δβ）**、1 個要修方法（過嚴）、1 個 framing 成立。

> **L1 重點邏輯**：
> ① **判準只有一條**：方向是「正交佐證（characterization）」→ 可做；是「互相篩選/判別（filter）」→ 已死。

## D1 — 用甲基區分/救援 unphase read（umtag · methyl-assist phasing）

- **裁決**：🟡 **PROBE（值得做，但只能當 tooling / future-work，不能當現在的 result）**
- **重點假設**：haplotype-linked 甲基訊號可救援 unphased reads（縮小 unphased fraction），且非靠 copy。
- **現況證據**：機會空間真（45.84% unphased 🟡）；held-out extrap 0.8852 vs null 0.5236 🟡；V10 depth-matched normal 0.979 > tumor 0.866 = **「非 copy」**控存活 🟡。
- 🔥 **燒烤**：你說「用甲基區分 unphase」——可以，但**held-out extrapolation ≠ 真正去救一條 unphased read**（FT-5）；而且 aDMR×LOH **非富集**（Fisher p=0.382 🟡）、germline-het null 非判別（0.974）。所以現在它是「**有潛力的 tooling 原型**」不是「已驗證的方法」。
- **外部佐證**：✅ **強** —— MethPhaser / NanoMethPhase / HapBridge 等都做過 methyl-assist phasing（外部 L3 已驗此方向可行）→ 你不是孤例，可借力對標。
- **可驗證數據/方法**：switch-error / N50 vs MethPhaser/HapBridge（業界 yardstick）+ orthogonal phase-truth（COLO829 LOH 內）。
- **方法是否修正**：要補 yardstick + 真-unphase 救援實測（非 held-out 模擬）。
- **假設與細節驗證**：① 救援是否真縮小 unphased fraction（非模擬）；② 「非 copy」要在 ≥2 樣本重現；③ ledger+INDEX 未註冊 → HD-5 先正式化。
- **下一步**：→ 任務樹 V-umtag（需 COLO829 N8）。

## D2 — 用甲基對 read 做分群

- **裁決**：🟡 **PROBE（機制上 ISM 已做；但要分清它揭示什麼）**
- **重點假設**：甲基 read-clustering 能揭示 subclone 結構。
- **現況證據**：ISM 本來就是 read×CpG → read-read 距離 → 階層分群（這部分 ◽ 已穩定）；但 somatic-subclone 訊號 = NEGATIVE（見 D6）。
- 🔥 **燒烤**：「用甲基對 read 分群」**機制可行（ISM 在做）**，但你要的若是「分出 somatic subclone」——那 B2 已證分出來的是 **germline allelic 背景**（ARI 0.135 < het null 0.177，p=0.922 🟢），不是 somatic subclone。所以 D2 ≈ D6 的方法面。
- **外部佐證**：epipolymorphism / read-level methylation heterogeneity（Landan2012 / Derrien2021 等 L3）支持「read-level 甲基分群存在」，但也說 tumor 更混亂、難找一致 → 與我們一致。
- **可驗證數據/方法**：ARI vs imprinting 正控（GNAS/RB1=1.000 🟢）+ germline-het null。
- **方法是否修正**：要**normal-anchored**（減去 germline allelic 基線）才可能逼出 somatic subclone（見 D6）。
- **假設與細節驗證**：分群「是否 somatic-specific」必跑 germline-het null（已做＝否）。
- **下一步**：併入 ISM-4 catalog（標每位點分群是否 reliable）。

## D3 — cis-candidate 如何確認 + 大規模驗證所有位點

- **裁決**：🟡 **PROBE（真正的開放方法問題，值得設計協議）**
- **重點假設**：能在全基因組尺度判定每個 HP-axis 位點是真 cis-driven ASM 還是 copy/drift。
- **現況證據**：816 HP-axis loci 經 Bonferroni+copy-test 後**唯一乾淨 cis = chr17/TBC1D16**（within 0.142 > HP 0.122, perm p=0.001 🟡）；**BRCA2 = subclone/copy-confounded 🟡**（HP1-1 是 longphase-S somatic subclone tag 非 copy、非 CN-dosage；focal cis d_within=−0.023 邊際；% 不 robust）；6 個最強訊號 **untestable**（pure-ALT tag CGI-desert，copy-test 只能算 leaky-tag 7/60）。
- 🔥 **燒烤**：「大規模驗證所有位點」——問題是**現有 cis-test 對最強的位點測不了**（pure-ALT/CGI-desert）。所以「大規模」目前卡在「**怎麼測那些測不了的**」，不是算力問題。而且 partition **未 anchor SEQC2 CN ground-truth** → 連 copy 判定都還沒接真值。
- **外部佐證**：✅ Martin-Trujillo2017（**CN-dosage** 解釋 imprinted allelic 甲基 82–92%，L3）→ 背書「必須先排 copy 類混淆」的一般方法學原則；⚠ 注意 BRCA2 的實際混淆是 copy-**partition**/subclone（**非 CN-dosage** — dosage 已於 ledger #86/#87 以 MW p=0.62 / ρ=−0.083 反向單獨 REFUTED）；O'Neill/POG2024 偵 cis-ASM 復發 → 對標。
- **可驗證數據/方法**：normal-anchored cis-test（normal HP1/tumor HP1/tumor HP1-1 三路）+ copy-partition + **anchor SEQC2 CN** + COLO829 解 untestable。
- **方法是否修正**：① cis-test 要接 SEQC2 CN 真值；② 對 pure-ALT/CGI-desert 設計新判別（或承認 untestable 並標註）。
- **假設與細節驗證**：① chr17 要第二樣本重現（單 locus 單樣本 nominal p）；② 「60 cis → 1」的塌縮要寫清楚 copy-test 邏輯。
- **下一步**：→ 任務樹 V-cis-protocol（設計可規模化協議）。

## D4 — AF↔NGroups 正相關 = subclone 甲基 marker

- **裁決**：🔴 **NO-GO（你的這個假設本週已被你自己的分析推翻）**
- **重點假設（你提的）**：intermediate-AF subclone 帶不同甲基 → AF↔NGroups 正相關是 subclone **甲基** marker。
- **現況證據**：HD-4（06-08）🟢 —— baseline Spearman r=0.656(n=36854)；**控甲基 r 幾乎不動**（0.655 wrong-direction collider）；NGroups **99.5%≤2** 是 HP-tag {HP1,HP1-1,HP2,HP2-1} sub-family **capped count**（甲基矩陣不進 count，LabelTest.cpp:265-305）；ledger verdict = **PHASING_DRIVEN**。
- 🔥 **燒烤（最該被燒的一點）**：NGroups **不是甲基量，是 HP-tag 數**。AF 高 → LOH 區 somatic ALT sub-family 出現 → NGroups 1→2，這是 **AF 的算術函數**，與甲基無關。你控了甲基特徵 r 還在 0.655（甲基是 mediator/collider，控它是 wrong control）。所以「AF↔NGroups 是甲基 marker」**為假**——它是 **phasing/haplotype-occupancy signature**。
- **可救援的價值**：✅ 它**支撐 phasing 主軸**（AF→haplotype occupancy 的 read-level 證據），改述後仍有用。
- **方法是否修正**：要**一次 ISM re-run** 匯出 `fine_group_counts{HP1,HP1-1,HP2,HP2-1}` + `n_clusters`（甲基-only count）做乾淨 partial-corr knockout（definitional+mechanism+分布三證已一致，這是補刀）。
- **假設與細節驗證**：把「subclone 甲基 marker」改述成「AF→haplotype occupancy（phasing）」。
- **下一步**：→ 任務樹 V-hd4-closeout（N9，off 關鍵路徑）。

## D5 — strong-ASM（high-Δβ）loci 在 FP 富集，是否可特殊刪除

- **裁決**：🔴 **NO-GO 當 filter ｜ 🟡 可當 Discussion 觀察**
- **重點假設（你提的）**：strong-ASM 在 FP 富集 → 把這些位點「特殊刪除」可降 FP。
- **現況證據**：combo high-Δβ+no-clust+LOH → TP 0.86% vs FP 7.97%（~9× 🟡，源檔待對賬）；但 strong-ASM 5× = **反判別 OR=0.194**（🟡，61% 來自單一 chr8 hotspot）；機制 = regression-to-extreme（LOH→低覆蓋→極端 baseline 的同一 regime）。
- 🔥 **燒烤**：三個問題讓「特殊刪除」站不住：① **循環**——整個 filter 方向 LOSO 證 100% sample-level circularity（🟢），這個刪除規則在 held-out 會塌；② **單樣本**——只有 HCC1395 FP 夠多能算，且 61% 來自一個 chr8 hotspot；③ **冗餘**——「LOH + 低覆蓋」本來就是 caller 已用的 alignment/coverage filter，你是在**重新發現已知的低覆蓋 LOH 區 FP-prone**，不是新的正交 filter。
- **外部佐證**：無（這是內部 artifact 解釋，不是外部可借力的方向）。
- **可驗證數據/方法**：要跨樣本 + bootstrap stability + drop-chr8 才能當「flag」；但即使成立也只是 caller 既有覆蓋/LOH filter 的子集。
- **方法是否修正**：不建議當 filter；可在 §Methods-Neg 寫成「已機制解釋的 artifact」加分。
- **假設與細節驗證**：「FP |Δβ| 較大」**已 RETRACTED**（abs_dbeta MW p=0.137 NS 🟡）。
- **下一步**：保留為 NEGATIVE 底座 §N3 的機制解釋（不另開 filter）。

## ISM-3 — 是否加入/合併 Δβ 找位點 + 為何 ISM 不包含

- **裁決**：⭐ **PROBE/code（值得做，當「互補發現通道」不是取代）**
- **為何 ISM 不含 Δβ**：ISM 架構是 **read-level**（read×CpG → read-read 距離 → 階層分群 → CramersV/PERMANOVA on HP labels）；Δβ 是 **position-level allele 平均差**（不同分析單位）。ISM 沒內建 per-position allele 對比，所以漏掉「分群不明顯但平均差大」的位點。
- 🔥 **燒烤/設計**：合併**可以更全**——但**不能 naive 加 Δβ**（高-Δβ regime 是 FP-enriched，會引入 D5 的 FP）。正確設計：**union 發現通道** = 「discrete-clustered（CramersV reliable）**OR** large-Δβ **且** 有 clustering 佐證」，再用 normal-anchored cis-test 過濾 copy/drift。
- **外部佐證**：modkit / NanoMethPhase 的 per-position DMR 方法（L3）可借。
- **可驗證數據/方法**：兩通道 Venn（ISM-only / Δβ-only / 交集）+ 各自 TP/FP 組成。
- **方法是否修正**：✅ **候選 C++/Python** —— 在 ISM 輸出加 per-position Δβ 欄 + union 標記。
- **下一步**：→ 任務樹 C-merge-dbeta。

## 困難-1 — 篩選 paired 的 TP/FP（FP 太少 + 加 normal 甲基差異更難）

- **裁決**：🔴 **NO-GO 當 filter（誠實困難，建議不投）**
- **重點**：paired FP 數量太少 → power 不足；filter 方向本身已死四道；加 normal 甲基差異 → 再加一層 germline allelic confound。
- **現況證據**：filter 死四道 🟢（LOSO 循環 / AUC=0.505 / ~4% sens / clustering=germline-allelic）。
- 🔥 **燒烤**：你已經點出核心——FP 太少。**正確替代**＝不用 paired-FP，改用 **genome-wide private somatic + HP-shuffle null**（已做，6/6 excess 🟡），用「現象復現」取代「FP 篩選」。加 normal 甲基只會把問題變更難，不會解。
- **可驗證數據/方法**：genome-wide-null（已有）。
- **方法是否修正**：不投 paired-FP-filter；保留為「為何不可行」的誠實段落。
- **下一步**：寫進 NEGATIVE 底座（為何 paired-FP 不可行）。
