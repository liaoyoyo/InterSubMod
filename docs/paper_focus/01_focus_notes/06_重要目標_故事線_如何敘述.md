# 重要目標 · 故事線 · 如何清楚敘述

> **L0 一眼結論**：真正重要有價值的是**三個 characterization/tooling 交付物**（read-level haplotype 結構 + 位點甲基 catalog + 「甲基能佐證不能篩選」目錄），不是任何 filter；故事一句＝**三訊號在 LOH 下正交共驗證同一 haplotype 重塑事件**。
>
> **L1 重點邏輯**：
> ① **價值在 characterization 不在 filter** —— filter 已死，但「把現象 characterize 清楚 + 交一個工具」是真貢獻且今天就能交。

## L2 — 故事線（共驗證版 — 可直接當 abstract 骨架）

> **背景**：癌症長讀能同時讀到 somatic 突變、haplotype 與甲基，但三者多在 region/aggregate 層各看各的。
> **缺口**：沒人在 **read-level** 把三訊號縫成「同一事件的正交佐證」，也沒人誠實界定甲基**能**做什麼、**不能**做什麼。
> **作法**：ISM 在單 read 解析度建 read×CpG 矩陣 + 距離 + 分群 + HP/LOH tag + normal-anchored cis-test。
> **發現**：在 LOH 約束下腫瘤只留單一 haplotype → somatic SNV 形成同-HP1 子家族（**phasing：somatic↔haplotype 正交佐證，7/7**）；其中少數位點伴隨**真實 allele-specific 甲基差異**（~4% sens；chr17/TBC1D16 為乾淨 cis exemplar），甲基**現象層跨 6 樣本/3 癌種復現**——但它小、非方向、與 copy 無關、**且不能判別真/假變異**。
> **貢獻**：(1) read-level LOH-haplotype 結構 characterization + phasing tooling；(2) 位點甲基分群標籤 catalog；(3) 一份機制解明的「甲基能正交佐證、不能篩選」目錄（filter 死四道）。
> **誠實邊界（一句）**：**共驗證＝正交佐證（co-validation），不是互相篩選（filtering）。**

**敘述三鐵則（減認知負擔）**：
1. **一句結論先行**（L0），再給邏輯（L1），最後才細節（L2/L3）——讀者讀到夠就停。
2. **每個數字帶 🟢🟡🔵**——讀者一眼知道能不能信。
3. **「共驗證≠篩選」每節都守**——這是最容易被誤讀、也最致命的一條線。
