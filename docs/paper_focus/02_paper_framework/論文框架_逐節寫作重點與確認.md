## 1. Introduction（緒論）

> **L0 寫什麼**：癌症長讀能同時讀 somatic/haplotype/甲基，但沒人在 read-level 把三者縫成「正交共驗證同一事件」，也沒人誠實界定甲基能/不能做什麼 —— 本研究補這個。

**1a 主題為何重要**
- 聚焦重點：long-read 癌症基因體的獨特性 = 單分子同時帶 somatic + phase + 5mC/5hmC；read-level 連結三訊號有真實研究/臨床需求（理解 somatic+LOH 如何重塑表觀地景）。
- 料：🔵 framing（定位）+ 🟢 三訊號各有 read-level 證據（phasing 7/7、ASM exists、filter dead）。

**1b 目前還沒解決什麼**
- 聚焦重點：(1) read-level 三訊號**正交佐證**未被系統 characterize（多在 region/aggregate 層）；(2) 很多人想用甲基 filter somatic 但**沒人公開證偽**；(3) ASM 在 somatic-controlled（HP-axis）下的真實樣貌未被界定。
- 料：🔵 + 外部 L3（無 production caller 用 CpG 甲基當 standalone FP 判別器）。

**1c 本研究如何補缺口**
- 聚焦重點：ISM read-level 共驗證 characterization + tooling + **誠實負結果目錄**（甲基能佐證、不能篩選）。
- 怎麼確認/聚焦：🔴 **Intro 的 hook 必用「共驗證=正交佐證」**（不是 mutual filter）→ 等你拍板（CONFIRM-1）。
- caveat：不在 Intro 承諾任何 filter/predictor 能力。

## 5. Discussion（討論）

> **L0 寫什麼**：把結果擴回意義 —— 共驗證 framework 的生物意義 + 「為何甲基不能 filter」對領域的防雷貢獻 + 與文獻對齊/不對齊 + tooling 展望 + 誠實 limitation。

- 聚焦重點：
  - **生物意義**：LOH 重塑 haplotype-linked 甲基；ASM 真但小/非方向 → 對「ASM 普遍且 hypo 主導」的文獻提供 somatic-controlled 視角。
  - **方法貢獻（防雷）**：甲基不能 filter 的機制（regression-to-extreme / germline-allelic / sample-circularity）—— 對想用甲基 filter 的人有教育價值（背書 Kapoor2023 / Martin-Trujillo2017）。
  - **對齊/不對齊**：Martin-Trujillo（CN-**dosage** confound）被我們控掉/REFUTED ⚠**不 corroborate「BRCA2=copy」**（category error，confound 是 subclone 非 CN-dosage）；Do2020 口徑差異；BRCA2 hypo≠canonical hyper（BRCA2=subclone/copy-confounded，HP1-1=subclone tag 非 copy）。
  - **tooling 展望**：umtag（future-work，外部 MethPhaser 已驗方向）；catalog 交付。
- 料：🔵 framing + L3 文獻 + 🟢/🟡 結果。
- 怎麼確認/聚焦：🔴 **誠實 limitation 段**（single-pipeline ⭐3 / single-sample / by-construction circular HD-1 / 6 untestable cis）；守 FT-1~5 + OR-1~6。
- caveat：Discussion 不可把 limitation 輕描淡寫成 caveat。
