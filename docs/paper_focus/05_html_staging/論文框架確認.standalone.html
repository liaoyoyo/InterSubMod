5 Discussion（討論）

L0 寫什麼：結果擴回意義 —— 共驗證的生物意義 + 「為何甲基不能 filter」的防雷貢獻 + 文獻對齊/不對齊 + tooling 展望 + 誠實 limitation。
  • 生物意義：LOH 重塑 haplotype-linked 甲基；ASM 真但小/非方向 → 給文獻「ASM 普遍 hypo 主導」一個 somatic-controlled 視角。
  • 方法貢獻（防雷）：甲基不能 filter 的機制（regression-to-extreme / germline-allelic / sample-circularity）對想用甲基 filter 的人有教育價值。
  • 對齊/不對齊：Martin-Trujillo (CN-DOSAGE 82-92%) 不 corroborate BRCA2 reclassification（copy-DOSAGE 已 REFUTED MW p=0.6183；confound 是 subclone 非 CN-dosage = category error；其正確角色是我們控掉的 confound 警告）；Do2020 口徑差異；BRCA2 hypo≠hyper。
