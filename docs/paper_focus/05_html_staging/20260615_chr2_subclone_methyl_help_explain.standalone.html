chr2:18M Subclone 案例 — 位點狀況 × 甲基驗證 × 甲基是否幫助 subclone 分析

HCC1395 · chr2:18,068,480–18,108,828 · HKU_MOD + DORADO cross-check · L2（單位點×單樣本）· 圖由 CSV 繪製（§13-A 注入，非手填）
一句話結論：在 SEQC2-confirmed LOH 區，subclone 結構由 somatic 變異 linkage（基因）定義；甲基「有幫助」但是有界輔助 —— 橋接基因連不起來的 block、補 phasing tag 分不開處、指派缺突變的 read，且必須先用 matched-normal ASM-control 扣掉既存 germline ASM，剩下的乾淨子集才是真 subclone 訊號。甲基 非獨立判別/重建工具。

① 位點狀況 — 6 個 somatic 變異

區域 ~40 kb 內 6 個 sSNV：4 個乾淨 TP、1 個 truth-gap 真 somatic、1 個落 homopolymer。

#座標變異狀態角色
(1)18,068,480C>GTP HighConfbeta-left block
(2)18,072,546G>CTP HighConfbeta-left block
(3)18,086,020G>Atruth-gapα defining（真 somatic，落 SEQC2 HC 空隙不可 truth 驗）
(4)18,096,269C>Ghomopolymerbeta-right（後接 20bp poly-T → G/T/DEL 是 ONT jitter，非 3 subclone）
(5)18,099,697G>CTPα-1 nested（巢狀於 α）
(6)18,108,828C>GTP HighConfbeta-right block

LOH 背景：HP2 母本保留 ~98.3%(HKU)/99.6%(DORADO)，normal 6 點全 REF。→ 單親 haplotype 保留，lineage 由 somatic 定義。

② 甲基驗證結果 — ALT vs REF 每 CpG 的 5mC（CSV 繪製）

每個變異錨點的 CpG：ALT-genotype read 與 REF-genotype read 的 5mC 平均。分得越開 = 甲基越能跟著該 allele/lineage。綠底=乾淨 tumor-acquired；紅底=被既存 germline ASM confound（見 §3）。三角=DORADO 複製值。

ALT-genotype 5mC（HKU） REF-genotype 5mC（HKU） ▲ DORADO 值 乾淨子集 confound 子集

所有乾淨子集（2.1/2.2/3.1/3.2/5.1/5.2）HKU+DORADO 同方向且過 BH-FDR → 真訊號非單 basecaller 雜訊。3.4/3.5 在 DORADO 未過 FDR（▲ 偏淡）。

③ 為何要扣 confound — matched-normal ASM-control（CSV 繪製）

關鍵：有些 CpG 在 normal 裡 HP1 vs HP2 本來就有顯著甲基差（既存 germline ASM）。這些位點的 tumor 甲基差不能算 subclone 形成後的新訊號 → 保守排除。這就是 ISM 用 normal-anchor 把 subclone 訊號與 ASM confound 拆開的地方。

normal HP1 5mC normal HP2 5mC

3.3/3.4/3.5/4.1 normal HP1-vs-HP2 已顯著（FDR≤0.05）→ confound，排除。2.1/2.2/3.1/3.2/5.1/5.2 normal 無 HP 差異 → 乾淨保留。

④ 中間 / 關鍵位點狀況（決定結構是否成立的三個）

(3) 18,086,020 — α 的 defining + 橋接角色

真 tumor-specific somatic（tumor 29A/30G、normal 0A/18G、mapQ60、雙股、非 homopolymer），但落 SEQC2 HC 空隙不可 truth 驗。它與 (1)(2)(4)(6) 互斥 → 撐起 α / beta-like 分叉。

(4) 18,096,269 — homopolymer 陷阱

後接 20 bp poly-T（GRCh38 親驗）→ ONT 產生 G/T/DEL 混合 call（HKU G4/T13/DEL10/REF21）。不是 3 個 subclone，合併為單一 pos4-altered beta-right state。

(5) 18,099,697 — α-1 nested（provisional）

(5)C 只在帶 (3)A 的 read 出現 → (3)→(5) perfect nesting（唯一有 direct nesting 支持的順序）。但 direct support 僅 HKU 4/DORADO 2 reads → provisional。

beta-left ↔ beta-right — 甲基橋接的中間缺口

(1)(2) 與 (4)(6) 相距 >36 kb，read 跨不到 → 無直接 genetic linkage。靠互斥 + 甲基 coherence 暫接為同一 beta-like program（樹上畫虛線）。這是甲基實際補上的缺口。

⑤ 🔑 甲基分析有幫助到 subclone 分析嗎？

有幫助，但是「有界輔助（corroborate / bridge / characterize）」，不是獨立判別器，且幫助綁在 normal-anchor ASM-control 之上。

✅ 甲基實際幫到

① 橋接基因連不起來的 block（beta-left↔beta-right >36kb）
② 補 LongPhase-S fine-tag 分不開處（HP2/HP2-1 跨 basecaller 不穩）
③ 指派缺 defining 突變的 read（ref-genotype read 帶乾淨 β 甲基 → epigenotype 追 lineage）
④ 跨 basecaller 複製 = 真訊號非雜訊

⚠ 但嚴格有界

① subclone 結構是 somatic linkage（基因）定義的，不是甲基 → 甲基 corroborate 非 primary discriminator
② 幫助綁在 ASM-control：不扣 germline ASM，naive 甲基會誤導
③ 甲基沒獨立重建 tree / 定 clone 數 / 排演化順序 / 證甲基造成突變
論文用語：甲基 = lineage coherence + 區域 characterization + read-assignment，conditioned on normal-anchored ASM-control —— 是論文主軸「甲基 corroborate 非 validated discriminator」的乾淨實例。
可防守敘述 = 「a regional, LOH-constrained, somatic-haplotag-conditioned subclonal structure with cross-basecaller methylation coherence」（非 confirmed 5-subclone）。
