位點甲基分群標籤 catalog — 逐欄勾選確認

L0：catalog = 一位點一列 → 9 分類欄 + 7 數值欄 → 收斂成 1 個 TAG（共 7 類）+ 6 張觀察分佈圖。核心欄 clustering_reliability 直接答「哪些位點甲基分群明顯」。骨架先跑（現有欄），Δβ/cis 之後補。
📝 每列選 ✅保留 / ✏️微調 / ❌移除 + 寫意見（自動存瀏覽器）。圖那節是 要/改/不要。答完按右上「匯出我的回答」貼回給我。三色：🟢有證據 / 🟡待對賬 / 🔵設計提案。

A 核心分類欄（4 — 決定 TAG 的主力）

① clustering_reliability ⭐核心
reliable（CramersV Cochran 最小期望格≥5 且顯著）/ latent（CV gated=0 但 PERMANOVA 顯著＝487 類）/ none
配數值：cramersV_value · permanova_p · min_expected_cell ｜⚠ PERMANOVA p 閾值/minN 待校準
② dbeta_magnitude
large / medium / small（per-position allele 甲基平均差）依賴 ISM-3
配數值：dbeta_max ｜⚠ cutoff large≥0.2/med0.1-0.2/small 待校準；高-Δβ FP-prone 須配 clustering
③ clustering_origin
somatic-linked / germline-allelic / drift（blind-ARI vs germline-het null，imprinting 正控）
配數值：ari_value · ari_null · ari_p ｜B2 證多為 germline-allelic
④ cis_status
cis / copy / drift / untestable（normal-anchored cis-test + copy-partition）依賴 D3
配數值：within_d · hp_axis_d · cis_perm_p ｜⚠ 未 anchor SEQC2 CN；6 個 untestable

B 結構/補充欄（含你加的 n_CpG/coverage/LOH/gene）

⑤ somatic_status
somatic / germline-het / FP（ClairS-TO VCF + SEQC2 truth）
⑥ axis（HP-axis / ALLELE-axis）
somatic-controlled vs germline-confounded；LOH 位點只有 ALLELE-axis
⑦ mod_type（5mC / 5hmC / mixed）
BAM MM/ML 依賴 MSA Level1 dup-bug 修復（否則 collapse artifact，BRCA2 教訓）
⑧ recurrence（single / cross-N）
跨樣本復現（0/38 underpowered → 復發稀有非 private）
⑨ LOH_status（in/out LOH）你加的
影響 axis + artifact 判讀
⑩ n_CpG / coverage / region_size 你加的
影響 reliability 的基本量（檢查 reliability 是否被覆蓋驅動）
⑪ gene / is_TSG_promoter 你加的
生物意義（是否落 TSG promoter）
⑫ provenance_tier（🟢/🟡）
數字是否原檔對賬

C 7 個 TAG（每位點收斂成 1 個 = 標籤分類）

TAG-A 乾淨 cis somatic-ASM
reliable + cis + somatic-linked + somatic（寶物，例 chr17/TBC1D16 🟡）
TAG-B copy-artifact
cis_status=copy（排除於 cis，例 BRCA2 🟡）
TAG-C germline-allelic 背景
clustering_origin=germline-allelic（多數 read-clustering）
TAG-D high-Δβ FP-prone artifact
large-Δβ + (none/latent) + LOH + 低覆蓋（regression-to-extreme，只標註不 filter）
TAG-E latent 真分群
CV gated 但 PERMANOVA 顯著（487 類，納回提升 characterization）
TAG-F untestable
pure-ALT/CGI-desert（6 最強訊號，需新法/COLO829）
TAG-G 無訊號
none + small-Δβ（背景）

D 6 張觀察分佈圖（你要的「明確數值 + 分佈圖」forest view）

這節選 ✅要 / ✏️改 / ❌不要。

P1 Δβ 分佈
all loci + large/med/small cutoff 線
P2 CramersV 分佈
reliable 閾值 + latent 區標色
P3 ARI 分佈
somatic TP vs germline-het null vs imprinting 正控（0.758/1.000）
P4 within_d vs HP_axis_d scatter
cis vs copy 對角線分界
P5 per-TAG 計數長條 = Results R6 主圖
7 TAG 各幾個
P6 coverage/n_CpG vs reliability
檢查 reliability 是否被覆蓋驅動

E 待校準/缺漏（要你定的閾值）

閾值校準法
用 imprinting 正控(GNAS/RB1=1.000) + 已知例(chr17) 校 PERMANOVA p / Δβ cutoff / cis perm p
骨架先跑（順序）
先用現有欄(reliability/origin/somatic/axis/LOH/cov/gene)跑骨架表 → Δβ(ISM-3)/cis(D3) 之後補
