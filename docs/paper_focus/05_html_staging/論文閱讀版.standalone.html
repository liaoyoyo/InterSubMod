Abstract

Long-read sequencing resolves somatic mutations, haplotypes and 5mC/5hmC on single molecules, yet whether allele-specific methylation (ASM) in cancer reflects somatic events has not been characterized at read level nor de-confounded from germline-allelic and copy-number background.

Methods. ISM, a read-level pipeline (read×CpG matrix, read–read distance, reliability-gated clustering, haplotype/LOH tagging, normal-anchored cis-test), catalogues 332,705 loci across six cancers.

Results (rule). Reliable methylation read-clustering exists at 🟢 12,868 loci but is overwhelmingly germline-allelic; genome-wide only 🟢 1/332,705 is a clean somatic cis-ASM (chr17/TBC1D16), and methylation does not discriminate true from false somatic variants (four independent lines). Copy-number dosage is not the driver 🟢 MW p=0.6183. (exception) At that single locus and along the LOH-phasing axis, somatic, haplotype and methylation signals co-validate the same reshaping event 🟡.

Conclusions. A read-level de-confounding of cancer ASM + a mechanism-resolved catalogue of what methylation co-validates versus cannot filter.

1　Introduction

Long-read resolves somatic variation, haplotypes and 5mC/5hmC on one molecule, enabling a read-level test of whether cancer ASM is somatic or germline-allelic.

1.1　Why this matters

read-level 連結三訊號 + de-confound apparent ASM。🔵

1.2　The gap

(i) read-level somatic-controlled de-confound 未做；(ii) 甲基-as-filter 未公開證偽；(iii) somatic-controlled ASM 樣貌未界定。🔵 [@MartinTrujillo2017]

2.2　Boundary — methylation cannot discriminate true/false somatic variants（四道）

  • (a) LOSO 100% circularity 🟢 +0.02236→−0.00012; mean −0.00004, p=0.125 [@Kapoor2023]

2.3　★ RULE — read-level catalogue：甲基分群是 germline-allelic，不是 somatic（de-confound floor）

6 樣本 332,705 位點 → 7 TAG 🟢 catalog wf_5644ed77-082 6/6 驗：reliable 甲基分群 12,868（3.87%） 但 cis-test 證全是 germline-allelic 背景；latent 28,254（PERMANOVA 救回但 enrich≈base 無判別力）；無訊號 291,518（87.6%）；乾淨 somatic cis-ASM 全基因組僅 1（chr17）。→ 甲基 allelic 分群 germline-driven，不是 somatic 判別器。

MW neutral-vs-gain p=0.6183；signed ρ(|Δβ|,CN)=−0.0829 → REFUTED 🟢。唯一乾淨 cis = chr17（within 0.142 ≫ d_copy 0.029, perm p=0.001）🟢；BRCA2 = copy-confounded（d_within −0.023 ≪ −0.11）🟢。

3　Discussion

3.1　規則的意義（de-confound 貢獻）

甲基 allelic 分群 read-level 主要是 germline；apparent ASM 多被 germline/copy 混淆 → 給「ASM 普遍 hypo 主導」文獻一個 somatic-controlled de-confound 視角（守 3 不對齊）[@Do2020]。

3.2　例外的意義 + 邊界

chr17 是罕見 somatic co-opt 甲基的 exemplar（讓規則完整）；甲基不能 filter 的機制（circularity / regression-to-extreme / germline-allelic）= 防雷貢獻 [@Kapoor2023][@MartinTrujillo2017]。

3.3　Tooling 展望（future）

甲基追蹤 haplotype 結構 → 開啟甲基輔助 phasing（umtag）🟢 held-out 0.8852 / V10 非-copy（T-PROV）；需 yardstick / COLO829 [@MethPhaser]。

3.4　Limitations

single-pipeline ⭐3；機制單樣本 HCC1395；chr17 例外單 locus 不可複製；phasing by-construction（#21 待）；6 cis untestable；matched normal 僅 HCC1395。

4　Methods

4.1 Samples. HCC1395（SEQC2 truth）+ HCC1937/1954/H1437/H2009/COLO829；ONT 5mC/5hmC；ClairS-TO（single-pipeline）。

4.2 ISM pipeline. read×CpG 矩陣 → read–read 距離（6 度量）→ 階層分群 + CramersV reliability gate（Cochran≥5；三態 reliable/latent/none）→ HP/LOH tag → normal-anchored cis-test。vs 現有工具見 benchmark（#23）。

4.3 Catalogue. 16-欄 schema → 7-TAG（scripts 98-100；catalog_skeleton.tsv 332,705 列；wf_5644ed77-082 獨立重驗）。

4.4 Validation. LOSO / 2000× shuffle null / subhap-matched / blind-ARI + imprinting 正控 / signed-rank + bootstrap + paired 負控 / copy-test / germline-het null。

4.5 Statistics & pre-registration. effect size + CI；genome-wide FDR（改正 BH-on-min-p）；NEGATIVE 走 falsification；#21/#22 跑前判準寫死（pre_registration_與fallback doc），fallback：de-confound floor 永遠成立。
