## 2. ASM 文獻預期比例

### 2.1 全基因組 ASM 比例（正常組織）

| 指標 | 數值 | 來源 |
|------|------|------|
| Heterozygous SNP 顯示 ASM 的比例 | **23%-37%** (per cell line) | Shoemaker et al. 2010, Genome Research |
| 跨所有 cell line 一致的 ASM | **~6%** of ASM events | Shoemaker et al. 2010 |
| 全基因組 bimodal methylation 區域 | **325K 區域** (6% genome, 11% CpGs) | Loyfer et al. 2025, Nature Communications (Atlas) |
| 其中遺傳變異驅動的 ASM | **34K 區域** (~10% of bimodal regions) | Loyfer et al. 2025 |
| 親源印記 (imprinting) ASM | **460 區域** (含 78 已知印記基因) | Loyfer et al. 2025 |
| CpG-SNP 驅動的 ASM 比例 | **38%-88%** of ASM regions | Shoemaker et al. 2010 |
| 450K array CpG 有 mQTL 的比例 | **~15.4%** | Multiple EWAS studies |
| EPIC array CpG 有 mQTL 的比例 | **~23.0%** | Multiple EWAS studies |
| 大規模 GWAS (n=32,851) mQTL | **~45.2%** (190,102 / 420K CpGs) | Hannon et al. / GoDMC consortium |
| 跨組織 mQTL (9 tissue types) | **37.9%** CpGs; 37% pan-tissue, 5% tissue-specific | Multi-tissue EWAS |

**關鍵解讀**:
- 「多少 SNP 有 ASM」高度依賴定義嚴格度和檢測方法
- 寬鬆定義 (any mQTL association): 15-45% 的 CpG 被影響
- 嚴格定義 (per-read allelic difference > 0.2): 通常 5-15%
- 最嚴格定義 (跨組織一致): ~6% 或更低

### 2.2 Cancer 中的 ASM

| 指標 | 數值 | 來源 |
|------|------|------|
| Cancer vs Normal ASM 增幅 | **5-9 倍** | Do et al. 2020, Genome Biology |
| Multiple myeloma ASM 增幅 | **5 倍** | Do et al. 2020 |
| B cell lymphoma ASM 增幅 | **8.5 倍** | Do et al. 2020 |
| Glioblastoma ASM 增幅 | **9 倍** | Do et al. 2020 |
| Cancer-only ASM 中 LOM 驅動 | **49-76%** (allele-specific loss of methylation) | Do et al. 2020 |
| Cancer-only ASM 中 GOM 驅動 | **16-25%** (allele-specific gain in poised chromatin) | Do et al. 2020 |
| Cancer allele switching 比率 | **43%** vs 14% in normal | Do et al. 2020 |
| Somatic mutation 伴隨 ASM gain | **6-17%** of somatic mutations (paired myeloma) | Do et al. 2020 |

**關鍵解讀**:
- Cancer 中 ASM **大幅增加**，主因是全域低甲基化 (global hypomethylation)
- 主要機制是 allele-specific loss of methylation (LOM)，而非 gain
- Somatic mutation 可直接導致 de novo ASM（6-17% 的 somatic mutations）
- 71% 的 de novo ASM TF binding site motif classes 與 germline-driven ASM 相同

### 2.3 Germline vs Somatic 位點的預期 ASM 比例

| 位點類型 | 預期 ASM 比例 | 機制 | 信心度 |
|----------|--------------|------|--------|
| **Germline heterozygous SNP** | **15-37%** (依定義) | cis-mQTL、CpG-SNP disruption、印記 | 高 (多篇大型研究) |
| **Somatic SNV (paired)** | **5-15%** (estimated) | de novo ASM、TF binding disruption | 中 (有限直接數據) |
| **Somatic SNV (cancer-specific)** | **可能更高** in cancer context | global hypomethylation + focal GOM | 中-低 (推測) |
| **FP (germline leak)** | **接近 germline 水平** | 本質上是 germline，應有 mQTL-driven ASM | 高 (推理) |
| **FP (sequencing artifact)** | **~0%** (隨機) | 無真實 allele 差異 | 高 (推理) |

**核心假說**: 如果 FP 中很大部分是 germline leak（特別在 TO 模式），那麼 FP 的 ASM prevalence 應該**高於** TP（somatic），因為 germline 位點有更強的 mQTL-driven ASM。這是一個完全不同於之前 O1-O13 的研究角度。

## 3. ASM 偵測方法比較

### 3.1 方法總覽

| 方法 | 統計檢驗 | 分析單元 | ISM 已有？ | 適用性 | 複雜度 |
|------|---------|----------|-----------|--------|--------|
| **A: Per-read allele-stratified methylation** | t-test / Wilcoxon | 整體 region mean | 部分 | 高 | 低 |
| **B: PERMANOVA on distance matrix** | Permutation F-test | 全矩陣 | 已實作 | 中 | 中 |
| **C: Per-CpG Fisher's exact test** | Fisher's exact | 每個 CpG 獨立 | 否 | 高 | 低 |
| **D: Methylation-genotype correlation** | Pearson/Spearman | CpG ~ allele | 否 | 中 | 低 |
| **E: CPEL (Ising model)** | Bootstrap + Ising | Haplotype block | 否 | 高 | 高 |
| **F: Bayesian (DSS)** | Beta-binomial Wald test | CpG site | 否 | 中 | 中 |
| **G: modkit dmr** | Likelihood ratio + HMM | Region/base | 否 | 高 | 低 |

### 3.2 方法 A: Per-Read Allele-Stratified Methylation Comparison

**原理**: 將 reads 按 ALT/REF allele 分層，計算兩組的 region-level mean methylation，比較差異。

**步驟**:
1. 從 ISM output 的 `reads.tsv` 取得每條 read 的 allele (ALT/REF) 和甲基化向量
2. 按 allele 分組，計算 mean methylation per group
3. Wilcoxon rank-sum test 或 t-test 比較兩組

**Pros**:
- 最直觀，統計簡單
- 可直接使用 ISM 現有 output
- 快速計算

**Cons**:
- 忽略 per-CpG 空間結構
- Region mean 可能掩蓋局部 ASM
- 當 CpG 數量少時 power 低

**Statistical power**: 中等。需要每組 >=5 reads，methylation difference >=0.15 才有合理 power。

**False positive rate**: 低（Wilcoxon 較保守），但可能有 false negatives。

### 3.3 方法 B: PERMANOVA on Methylation Distance Matrix

**原理**: ISM 已計算 read-read 距離矩陣，以 allele 為分組因子執行 PERMANOVA。

**步驟**:
1. 取 ISM output 的 `distance_matrix_[METRIC].csv`
2. 以 ALT/REF allele 為 grouping variable
3. PERMANOVA: pseudo-F = SS_between / SS_within
4. Permutation test (999-9999 次) 得 p-value

**Pros**:
- ISM 已有完整實作（`enable_permanova=true`）
- 利用多種距離度量（NHD, L1, Bernoulli 等）
- 考慮整體甲基化模式差異，不只 mean
- 對多變量 pattern 差異敏感

**Cons**:
- 計算量較大（需完整距離矩陣 + 置換）
- 不指示「哪些 CpG」驅動差異
- 對 sample size (read count) 敏感
- NaN 處理需注意

**Statistical power**: 中-高。對整體 pattern 差異有好的 power，但對單一 CpG 的局部效果可能不敏感。

**False positive rate**: 低（permutation-based），但需注意 read count imbalance（ALT vs REF reads 不平衡時需校正）。

### 3.4 方法 C: Per-CpG Fisher's Exact Test

**原理**: 對每個 CpG 位點，建立 2x2 列聯表 (allele x methylation status)，執行 Fisher's exact test。

**步驟**:
1. 對 window 內每個 CpG，統計 ALT reads methylated/unmethylated 和 REF reads methylated/unmethylated
2. Fisher's exact test (one-sided or two-sided)
3. 多重檢驗校正（BH-FDR across CpGs within region）
4. 定義 ASM region: >=1 significant CpG with |delta_methylation| >= threshold

**Pros**:
- 精確到每個 CpG 位點
- 不需假設分布
- 可識別具體哪些 CpG 有 ASM
- 文獻最廣泛使用

**Cons**:
- 忽略 CpG 間相關性
- 多重檢驗負擔（一個 region 可能有 5-50 CpGs）
- 低 read count 時 power 極低
- 需二值化甲基化 (threshold at 0.5 或使用 ML probability)

**Statistical power**: 單一 CpG 低（需 >=5 reads per allele），但跨 CpG 整合後可接受。

**False positive rate**: 受多重檢驗影響，需 FDR 校正。建議 BH-FDR < 0.05。

### 3.5 方法 D: Methylation-Genotype Correlation

**原理**: 將 allele 編碼為 0 (REF) / 1 (ALT)，計算與每個 CpG 甲基化狀態的 point-biserial correlation。

**步驟**:
1. 編碼: allele = 0/1, methylation = 連續值 (ML probability)
2. Point-biserial correlation (等價於 t-test)
3. 或 logistic regression: methylation ~ allele + covariates

**Pros**:
- 可利用連續 methylation probability（不需二值化）
- 可加入 covariates (read length, mapping quality, etc.)
- 與 mQTL mapping 框架一致

**Cons**:
- 每個 CpG 獨立測試，忽略空間相關
- 只看線性關聯
- 在 per-SNV 層級，本質等價於方法 A 但 per-CpG

**Statistical power**: 與方法 C 類似，但利用連續值可能略高。

### 3.6 方法 E: CPEL (Ising Model)

**原理**: 用統計物理學的 Ising model 聯合建模多個 CpG 位點的甲基化狀態，考慮 CpG 間相關性。

**步驟**:
1. 建立 haplotype block 內 CpG 的聯合甲基化模型
2. 三個檢驗統計量:
   - T_MML: mean methylation level 差異
   - T_NME: normalized methylation entropy 差異
   - T_PDM: 遺傳-表觀基因關聯
3. Bootstrap hypothesis testing + BH correction

**Pros**:
- 最完整的統計框架
- 考慮 CpG 間相關性
- 可偵測 mean difference 和 entropy difference
- 96% 的 ASM 是 entropy imbalance（mean 無差但 pattern 不同），此方法可偵測
- 5-20 reads per allele 即可

**Cons**:
- 計算量極大（~48h per sample, 20 CPUs）
- 需要完整的 per-read CpG 甲基化矩陣
- 實作複雜度高
- 原始程式碼為 WGBS 設計，需適配 ONT 數據

**Statistical power**: 最高。尤其對 entropy imbalance 有獨特偵測能力。

**False positive rate**: 低（bootstrap + BH correction）。

### 3.7 方法 F/G: 已發表工具

#### pycoMeth (Genome Biology, 2023)

- **方法**: Fisher's exact test + IHW (Independent Hypothesis Weighting) 多重校正
- **特點**: 原生支援 ONT nanopore 數據；MetH5 快速存取格式；支援 haplotype-aware ASM testing
- **ASM 模式**: 接受 phased BAM，用 read groups 標記 haplotypes
- **Workflow**: `Meth_Seg` (Bayesian segmentation) -> `Meth_Comp` (differential testing)
- **優勢**: 為 ONT 原生設計，效能優於短讀段工具

#### NanoMethPhase (Genome Biology, 2021)

- **方法**: SNV calling + WhatsHap phasing + DSS DMA
- **特點**: 將 reads phase 到 haplotype，轉為 mock-WGBS format
- **ASM 偵測**: 用 DSS R package 對 phased haplotype 做 DMA
- **最低覆蓋度**: ~10x genome-wide
- **優勢**: 端到端 pipeline，整合 phasing + methylation + DMA

#### NANOME (Genome Biology, 2025)

- **方法**: XGBoost consensus methylation + Clair3 variant calling + haplotype-aware analysis
- **特點**: 整合 Megalodon, Nanopolish, DeepSignal 的共識模型
- **改進**: 單鹼基解析度 +12% (MSE)，單分子 +3% (F1)
- **ASM 偵測**: 結合 variant calling 和 long-read phasing
- **優勢**: Nextflow pipeline，雲端/HPC 可部署

#### modkit (ONT official, 2024+)

- **方法**: `modkit pileup --phased` + `modkit dmr pair`
- **統計**: Likelihood ratio scoring + Cohen's h effect size + HMM segmentation
- **特點**: ONT 官方工具，原生支援 HP tag 分群
- **輸出**: hp1.bedmethyl + hp2.bedmethyl，可直接比較
- **優勢**: 最輕量，直接處理 modBAM

#### DSS (Bioconductor)

- **方法**: Beta-binomial model + Wald test
- **特點**: 考慮生物學變異性，shrinkage estimation
- **ASM 適用**: 需先將 reads 按 allele 分開，再作為兩個 "sample" 比較
- **優勢**: 統計學最嚴謹，有理論 power guarantee

#### methylKit (Bioconductor)

- **方法**: Fisher's exact test 或 logistic regression
- **特點**: 可整合 DSS 後端
- **ASM 適用**: 類似 DSS，需先 allele-stratify

## 4. ONT 特有考量

### 4.1 Methylation Calling Accuracy

| 指標 | 數值 | 來源 |
|------|------|------|
| Dorado CpG per-read accuracy (R10) | **~95-97%** (F1 score) | ONT benchmarks 2024 |
| Dorado super v5 mode modal accuracy | **Q28 (~99.8%)** base calling | ONT 2024 |
| DeepBAM vs Dorado AUC improvement | **up to +7.36%** | DeepBAM 2024 |
| R10 vs BS-seq correlation | **0.868** (aggregate) | ONT 2025 |
| Per-CpG site accuracy (>10x) | **>0.95 correlation** with BS-seq | Multiple benchmarks |

**影響評估**:
- **Per-read methylation call 有 ~3-5% 錯誤率**，這意味著在 per-CpG Fisher test 中，即使完全沒有 ASM，也可能因為 calling error 產生微小的 allele-methylation association
- **解決方案**: 使用 ML probability (0-255 continuous) 而非硬性二值化；或設定 methylation difference threshold >= 0.15-0.20
- **Aggregate level** (site-level, >=10 reads): correlation with BS-seq >0.95，足夠可靠

### 4.2 Long Read 的優勢

1. **同一 read 同時攜帶 allele info + methylation info**: 這是 ONT 最大的優勢。短讀段需要先 phase，再 impute 甲基化；ONT 直接在同一分子上讀到兩者。
2. **Haplotype block 跨越**: ONT reads 平均 10-30 kb，可跨越多個 SNP，建立長程 haplotype。
3. **不需 bisulfite 轉化**: 避免 bisulfite conversion 的偏差 (incomplete conversion, degradation)。
4. **5mC + 5hmC 同時偵測**: 可區分真正的甲基化和 hydroxymethylation。
5. **Read-level phasing**: 同一 read 覆蓋 SNV + 附近 CpG，不需 imputation。

### 4.3 Phasing Quality 對 ASM 偵測的影響

| Phasing 問題 | 對 ASM 的影響 | 嚴重度 |
|-------------|-------------|--------|
| **Switch error** | HP1/HP2 reads 互換，稀釋 ASM signal | 高 |
| **Unphased reads (HP=0)** | 被排除分析，降低 power | 中 |
| **Short phase blocks** | SNV 與附近 CpG 可能在不同 block | 中-高 |
| **TO 模式 phase 品質較低** | 整體 ASM 偵測 power 降低 | 高 |
| **LOH regions** | 只有一個 allele，無法偵測 ASM | 致命 |

**關鍵數字 (from ISM data)**:
- 根據 O7 觀察，TO 模式的 phase 品質指標與 paired 模式有顯著差異
- Switch error rate 影響：每 1% switch error 約稀釋 2% ASM effect size
- **建議**: ASM 分析應排除 LOH 區域，且 phase block N50 >= 100 kb

### 4.4 最低 Read Depth 要求

| 目標 | 最低 depth (per allele) | 推薦 depth | 來源 |
|------|----------------------|-----------|------|
| 基本 ASM 偵測 | **5 reads** | **10 reads** | CPEL simulations |
| 可靠 per-CpG testing | **5 reads** | **10-15 reads** | NanoMethPhase |
| Genome-wide ASM mapping | **10x total** (~5x/allele) | **20x total** | NanoMethPhase, NANOME |
| High-confidence ASM | **10 reads/allele** | **20 reads/allele** | Literature consensus |
| Per-CpG methylation rate | **10x site coverage** | **20x** | ONT benchmark studies |

**ISM 數據的覆蓋度**: 我們的腫瘤樣本 coverage ~50-75x，在 heterozygous SNP 位點，每個 allele 預期 ~25-37x，遠超最低需求。

## 5. 預期結果與分析策略

### 5.1 預期 ASM 比例估計

| 位點類型 | 預期 ASM prevalence | 依據 |
|----------|-------------------|------|
| **Germline heterozygous SNP** | 15-37% | Shoemaker 2010; Atlas 2025; mQTL studies |
| **FP (germline leak in TO)** | 15-37% (同 germline) | TO FP 大部分是 germline; 根據 O1-O10 |
| **FP (sequencing artifact)** | ~0-2% (隨機) | 無真實 allele，不應有系統性 ASM |
| **TP (somatic, paired mode)** | 5-15% | Do et al. 2020: 6-17% somatic mutation with ASM gain |
| **TP (somatic, cancer context)** | 可能 10-20% | Cancer global hypomethylation 增加 ASM |
| **LOH-region TP/FP** | 不適用 | 單 allele，無法偵測 ASM |

### 5.2 推薦分析策略

#### Phase 1: Quick Validation（用 ISM 現有 output）

**目的**: 快速確認 ASM prevalence 差異是否存在

1. **方法 A (Stratified Comparison)**:
   - 從 `reads.tsv` 取 allele assignment (ALT/REF) + methylation 向量
   - 計算每個 SNV region 的 allele-stratified mean methylation
   - Wilcoxon rank-sum test
   - 統計 ASM-positive 比例 (p < 0.05, |delta| >= 0.15)
   - 比較 TP vs FP 的 ASM prevalence

2. **方法 B (PERMANOVA)**:
   - 啟用 ISM 已有的 PERMANOVA（`enable_permanova=true`）
   - 以 allele 為 grouping factor
   - 比較 TP vs FP 的 PERMANOVA p-value 分布

**預期結果**: FP (germline leak) 的 ASM prevalence > TP (somatic)，差異 10-25 個百分點。

#### Phase 2: Per-CpG Resolution（新增分析）

**目的**: 獲得 CpG 層級的 ASM 定位

1. **方法 C (Per-CpG Fisher's Exact Test)**:
   - 從 `methylation.csv` 取每個 CpG 的 per-read 甲基化狀態
   - 按 allele 分群建立 2x2 表
   - Fisher's exact test + BH-FDR
   - 定義 ASM-CpG: FDR < 0.05, |delta_methylation| >= 0.20
   - 定義 ASM-region: >= 2 adjacent ASM-CpGs

2. **方法 G (modkit dmr)**:
   - 對已有的 haplotagged BAM 執行 `modkit pileup --phased`
   - `modkit dmr pair` 比較 hp1 vs hp2
   - 與 ISM-based 結果交叉驗證

#### Phase 3: Advanced Analysis

**目的**: 深度特徵化 ASM 與 variant type 的關聯

1. **Confound control**: 必須控制的混淆因素:
   - **Read count**: ALT/REF read balance (AF)
   - **CpG density**: region 內 CpG 數量
   - **Genomic context**: CpG island / shore / shelf / open sea
   - **LOH status**: 排除 LOH 區域
   - **Phase quality**: 只保留高品質 phased reads

2. **多層分析**:
   - L1: Raw ASM prevalence by variant class (TP/FP/Germline)
   - L2: After controlling for AF, CpG density
   - L3: After controlling for genomic context
   - L4: Cross-sample validation (7 samples)

### 5.3 ISM Output 到 ASM 分析的數據流

```
ISM 現有 output (per SNV region):
  reads.tsv          -> allele (ALT/REF) + HP tag
  methylation.csv    -> CpG x Read matrix (binary/probability)
  distance_matrix.csv -> read-read distance
  metadata.txt       -> region info, CpG count, read count

Phase 1 (新增 Python script):
  reads.tsv + methylation.csv
  -> allele-stratified methylation mean
  -> Wilcoxon test per region
  -> ASM prevalence by TP/FP class

Phase 2 (新增 Python script):
  methylation.csv + reads.tsv
  -> per-CpG 2x2 table (allele x methylation)
  -> Fisher's exact test + BH-FDR
  -> ASM-CpG map per region

Phase 2b (modkit, 獨立 pipeline):
  haplotagged BAM + SNV bed
  -> modkit pileup --phased
  -> modkit dmr pair
  -> ASM regions (independent validation)
```

## 7. 核心發現與衝突觀點

### 7.1 共識觀點

1. **ASM 在正常基因組中普遍存在** (15-45% CpGs affected, depending on definition)
2. **ASM 在 cancer 中顯著增加** (5-9 倍)，主因是 global hypomethylation
3. **cis-mQTL 是最主要的 ASM 機制** (>80% of ASM is genetically driven)
4. **ONT 長讀取是 ASM 偵測的理想平台** (同一分子同時讀取 allele + methylation)
5. **Per-CpG Fisher test 是最廣泛使用的方法**，但忽略 CpG 間相關性

### 7.2 衝突觀點

| 觀點 A | 觀點 B | 可能原因 |
|--------|--------|----------|
| ASM prevalence 23-37% (Shoemaker) | ASM prevalence ~10% bimodal (Atlas) | 不同定義：任何統計顯著 vs 嚴格 bimodal |
| Per-CpG testing 足夠 (多數文獻) | CPEL shows 96% ASM is entropy-only (Jenkinson) | Mean difference 可能不足以偵測 ASM；entropy imbalance 是主要模式 |
| 10x coverage 足夠 (NanoMethPhase) | 20x per allele 推薦 (benchmark studies) | 取決於所需 effect size 和 FDR control |
| Somatic mutations 6-17% 有 ASM (Do 2020) | Somatic mutations 非 mQTL-driven，ASM 應低 | Cancer context 增加 ASM，但機制不同 |

### 7.3 關鍵不確定性

1. **Somatic SNV 的 ASM prevalence 在 ONT 數據中尚無直接測量** -- 文獻中 ASM 研究主要用 Illumina 或 WGBS
2. **TO 模式的 phase error 對 ASM 偵測的確切影響** 需要經驗測量
3. **96% entropy-only ASM** 的發現 (CPEL) 如果成立，意味著大多數方法會漏掉大部分 ASM
