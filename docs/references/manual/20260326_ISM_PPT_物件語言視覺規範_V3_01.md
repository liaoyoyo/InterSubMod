### 1.2 HP 色彩邏輯說明

HP1 和 HP2 在 V3 均為藍色系，以**深淺**區分：

```
HP1 (REF)    ████████  #5B9BD5 淺藍  → 無特殊標記
HP1-1 (ALT)  ████████  #5B9BD5 淺藍  → 中間疊加橘色突變點 ●
HP2 (REF)    ████████  #4472C4 深藍  → 無特殊標記
HP2-1 (ALT)  ████████  #4472C4 深藍  → 中間疊加橘色突變點 ●
Somatic SNV  ●          #ED7D31 橘點  → 覆蓋在 read bar 上
```

## 二、術語與標籤語言規範

### 2.1 讀序分類術語（CRITICAL）

| 術語 | 定義 | 視覺呈現 |
|------|------|---------|
| `HP1` | HP1 單倍型背景的 REF reads（不帶 ALT）| 淺藍色 read bar，無突變標記 |
| `HP1-1` | HP1 單倍型背景帶 ALT reads（somatic mutation on HP1 allele）| 淺藍色 read bar + 橘點 |
| `HP2` | HP2 單倍型背景的 REF reads | 深藍色 read bar，無突變標記 |
| `HP2-1` | HP2 單倍型背景帶 ALT reads（若 somatic SNV 在 HP2 上）| 深藍色 read bar + 橘點 |
| `HP1-2` | HP1 背景帶有第二個 somatic subclone 標記 | 僅在 subclone 分析場景使用，一般場景不出現 |

**重要**：標準 somatic SNV 場景只有 HP1、HP1-1（或 HP2、HP2-1），不出現 HP1-2。

### 2.2 讀序行標籤格式

矩陣左側行標籤（左到右）：
```
[HP彩色方塊] [HP類型] [ALT/REF標記] [R1/R2序號]
例：  ■       HP1-1     ALT★           R1
      ■       HP1-1     ALT★           R2
      ■       HP1       REF            R3
      ■       HP2       REF            R4
```

### 2.3 CpG 列標籤格式

矩陣上方列標籤：
```
[CpG序號]      C1    C2    C3    C4    C5   [SNV位置標記]
[SNV標記]                                       △
```
SNV 所在欄位上方加橘色小三角 `△` 或垂直橘線。

## 四、物件規格

### 物件 A：讀序條（Read Bar）

```
形狀：圓角矩形（長 3.5–6.5"，高 0.28"）
填色：HP1=#5B9BD5 / HP2=#4472C4 / Normal=#D6DCE4
突變標記（疊加）：
  - Somatic ALT 橘點：直徑 0.18"，填色 #ED7D31，圓形
  - Germline 綠點：直徑 0.16"，填色 #70AD47，圓形
  - 錯誤灰方塊：0.12" × 0.12"，填色 #A5A5A5
左側標籤格式：HP彩色方塊(0.12") + HP類型文字 + ALT/REF + R序號
```

### 物件 B：CpG 矩陣格子

```
形狀：正方形（0.25" × 0.25"）
顏色（甲基化程度）：
  - p > 0.8：深橘 #C55A11（高甲基化，高信心）
  - 0.5 < p ≤ 0.8：淺橘 #F4B183（中高甲基化）
  - 0.2 < p ≤ 0.5：淺藍 #9DC3E6（中低甲基化）
  - p ≤ 0.2：深藍 #1F3864（低甲基化，高信心）
  - 缺失：淺灰 #D6DCE4
SNV 欄位上方：橘色三角 △（0.12"）
行標籤（左側）：HP 彩色方塊 + R序號
列標籤（上方）：C序號
```

### 物件 C：ISM 五目標卡片（S04 專用）

```
格局：2+3（上排2塊，下排3塊），共5塊
每塊尺寸：寬 5.8"（上排）/ 3.9"（下排），高 2.0"
框線：1.5pt，對應目標序號色彩（目標1=藍/2=深藍/3=橘/4=綠/5=紅）
填色：BG-alt #EEF2F7
內容：
  左上：數字序號（大字 28pt，對應色彩）
  右上：目標標題（中文 16pt Bold）
  中間：1-2行說明（13pt）
  右下角：小標「輸入：...」「輸出：...」（11pt，深灰）
```

### 物件 D：研究路線圖軌跡（S29 專用）

```
三條平行水平時間線，垂直間距 1.5"
Line 1（橘色）：「個人實驗進度」— 標記已完成實驗節點
Line 2（藍色）：「外部文獻對照」— 標記關聯論文節點
Line 3（深藍/綠色）：「程式開發進度」— 標記功能完成節點
特殊標記：
  「你現在在哪裡」：垂直橘色虛線貫穿三軌
  「下一步」：右側紅色虛線框
時間軸範圍：2025-11 → 2026-12（至少）
```

### 物件 E：術語提醒框（Term Callout）

```
位置：右下角，固定 x=Inches(10.5), y=Inches(6.8)
尺寸：寬 2.6"，高 0.6"（單條）；堆疊 0.05" 間距
框線：0.75pt，顏色對應術語類別

格式：「術語：定義」11pt，顏色同框線

僅用於技術方法頁（S05-S14）
```

### 物件 F：結果徽章（Result Badge）

```
形狀：圓角矩形
尺寸：自動（文字+padding 各 0.08"）
顏色：
  成功/綠：背景 #00B0A0，文字白色
  警告/橘：背景 #FFC000，文字深灰
  失敗/紅：背景 #C00000，文字白色
  資訊/藍：背景 #5B9BD5，文字白色
文字：11pt Bold
```

## 五、頁碼與標題規範

### 頁碼格式

每頁左上角（x=0.3", y=0.15"）：
```
S01 ｜ 封面與簡介
```
- `S01`：16pt Bold，Navy `#1A3A5C`
- `｜ 封面與簡介`：13pt，Sub-text `#7F7F7F`

### 頁面標題格式

標題行（y=0.45"）：
```
【 頁面標題 中文 28pt Bold 】
英文副標題 Calibri Light Italic 13pt Sub-text
```

分隔線（y=0.9"）：0.75pt，BG-alt `#EEF2F7`，全寬
