## 三、版面規範速查

### 3.1 基本設定

| 項目 | 值 | 來源 |
|------|-----|------|
| 比例 | 16:9 | S2 §5.1 |
| 尺寸 | 13.333" × 7.5" | python-pptx 標準 |
| 安全邊距 | 左右 0.75" / 上 1.0" / 下 0.5" | S3 §2.3 |
| 安全內容區 | 11.833" × 6.0" | S3 §2.3 |

### 3.2 一頁一重點規則

| 規則 | 內容 | 來源 |
|------|------|------|
| 6x6 Rule | ≤6 行 × ≤6 詞/行（中文 ≤12-15 字/行） | S3 §1.1 |
| Bullets | ≤4 條 | S1+S2 |
| 視覺元素 | ≤6 個 | S3 §1.1 |
| 字級種類 | ≤3 種/頁 | S3 §1.3 |
| 10 秒法則 | 觀眾應在 10 秒內抓到重點 | S3 §3.1 |

### 3.3 必須拆頁的信號

1. 同一頁超過一張圖表
2. 文字縮到 16pt 以下才放得下
3. 一頁同時講背景+方法+結果+結論
4. 觀眾需要很長時間才找到重點
5. 多面板圖在簡報中應拆成每面板一頁

### 3.4 Assertion-Evidence 標題法（科學簡報推薦）

**傳統**：「Results」「Data Analysis」（描述性標題）
**A-E 法**：「LOH 區域 ISM 甲基化完全失效（7/7 AUC≈0.50）」（結論式標題）

- 標題寫**結論句**（≤2 行），讓觀眾立即知道重點
- 頁面其餘用**圖表/視覺證據**支持標題結論
- 來源：Penn State Assertion-Evidence 研究 (Garner & Alley, 2013; ScienceDirect 2025 replication)
- **適用場景**：結果頁、驗證頁、結論頁
- **不適用**：封面、目錄、Section Divider

## 四、圖表規範速查

### 4.1 科學圖表必備元素

- [ ] 結論式標題（「證明 X」而非「顯示 X」）
- [ ] 軸標籤 + 單位（字體 ≥16pt）
- [ ] 圖例（字體 ≥16pt，不遮擋數據）
- [ ] 資料來源 + 時間範圍
- [ ] 直接標注數值（減少查閱圖例）
- [ ] 色盲友善色板

### 4.2 圖表版面比例

| 類型 | 視覺:文字 | 適用 |
|------|----------|------|
| Chart-Dominant | **75:25** | 數據展示頁（最常用） |
| Two-Column | **60:40** | 左文右圖 |
| Side-by-Side | **50:50** | Before/After 比較 |
| Grid/Bento | **50:50** | 多指標儀表板 |
| Full-Bleed | **95:5** | 純視覺衝擊 |

### 4.3 ISM 固定樣本順序

```
HCC1395 → HCC1395_DORADO → HCC1937 → HCC1954 → H2009 → H1437 → COLO829
```

### 4.4 ISM 圖表分組規則

- **初步觀察**：Paired / TO 兩組分開
- **細緻觀察**：2×2 layout × 7 samples（Paired TP / TO TP / Paired FP / TO FP）
- **圖片 aspect ratio**：強制保持原始比例（fit-within + centered）
- **寬圖/直式圖**：自適應佈局

## 五、Speaker Notes 規範

### 5.1 個人規範結構（S2 §8）

每頁 notes 至少包含：
1. **這頁目的**
2. **口頭講解重點**
3. **完整中文推論**
4. **數據或圖表證據**
5. **原始檔案或路徑**
6. **補充背景**

### 5.2 ISM V3 結構（S4 §八）

```
【本頁主旨】（一句話核心訊息）
【關鍵詞彙】（術語：定義）
【口頭說明建議】（銜接語）
【報告人】：廖子游
```

### 5.3 建議整合格式

```
【本頁目的】：（一句話）
【關鍵詞彙】：
  - 術語1：定義
  - 術語2：定義
【口頭講解重點】：
  （如何向觀眾口頭說明，2-3 句）
【數據證據】：
  - 引用的數字/圖表
  - 來源路徑
【補充背景】：
  （可選，提供深度脈絡）
【報告人】：廖子游
```
