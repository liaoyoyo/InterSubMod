# 指令修正與偏好收斂 Skill 規格

## 1. 目的

把「這次哪裡不夠準、下次怎麼改」制度化，讓後續研究文件越寫越符合需求，而不是每次重新摸索。

## 2. 技能實體

- [intersubmod-report-prompt-refiner/SKILL.md](/home/liaoyoyo2001/.codex/skills/intersubmod-report-prompt-refiner/SKILL.md)

## 3. 觸發條件

1. 使用者指出這次報告不夠完整或不夠像想要的樣子。
2. 使用者要求把偏好整理成固定 prompt。
3. 使用者要求建立 skill / agent 可重複規格。

## 4. 固定輸出

1. 缺口清單
2. 偏好摘要
3. 下次 prompt 模板
4. 問答式 refinement 清單
5. 建議升級成固定規則的項目

## 5. 缺口分類

| 類別 | 例子 |
|---|---|
| 內容缺口 | 背景太少、結論不夠整合 |
| 證據鏈缺口 | 沒附來源、表格不足 |
| 圖表缺口 | 沒解釋圖意義、沒寫軸標 |
| 指令缺口 | 時間範圍不清、讀者不清、輸出形式不清 |
| 簡報缺口 | 字體不一致、頁面太擠、notes 缺失、沒有版本確認檔 |

## 6. 問答式 refinement 範本

1. 這次開頭結論是否夠清楚？
2. 背景知識段落是否過長或過短？
3. 你要的是更多數據表，還是更多文字推論？
4. 這次表格欄位哪些還要補？
5. 哪些偏好要升級成固定規則？
6. 這次 PPT 要偏中文主體還是更強雙語？
7. speaker notes 是否夠完整？
8. deck 的輸出目錄與版本確認方式是否符合預期？

## 7. 偏好收斂原則

1. 只固定高影響、跨任務通用偏好。
2. 允許篇幅與細節深度依任務調整。
3. 若偏好重複出現三次以上，優先納入固定規格。

## 8. 驗收標準

1. 下次相同類型任務可直接套用模板。
2. 偏好摘要夠短，但能真正影響輸出品質。
3. 缺口清單能直接轉成下一輪修正項目。
