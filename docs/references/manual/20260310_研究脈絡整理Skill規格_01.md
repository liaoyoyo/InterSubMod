# 研究脈絡整理 Skill 規格

## 1. 目的

把知識庫層級與近期研究進度，濃縮成「這輪任務真正需要的背景」，避免報告一開始就直接跳到數據而失去脈絡。

## 2. 技能實體

- [intersubmod-context-synthesizer/SKILL.md](/home/liaoyoyo2001/.codex/skills/intersubmod-context-synthesizer/SKILL.md)

## 3. 觸發條件

1. 使用者要求研究背景、前情提要、導讀。
2. 使用者要求寫週報，但讀者不一定熟悉近期研究。
3. 使用者要求解釋 paired、tumor-only、candidate-specific rescue、label-first、cluster-first 等概念。

## 4. 輸入欄位

| 欄位 | 說明 |
|---|---|
| `task_scope` | 本輪任務範圍 |
| `reader_level` | 讀者熟悉程度 |
| `must_explain_terms` | 必須補充解釋的術語 |
| `must_read_docs` | 本輪一定要先讀的文件 |

## 5. 固定輸出

1. 背景摘要
2. 重要術語表
3. 已知前提與未驗證邊界
4. 本輪建議補讀文件

## 6. 撰寫標準

1. 專有名詞第一次出現時加中文詞義。
2. 只保留本輪需要的背景，不重抄知識庫。
3. 若不同樣本方向不同，要明確標示。
4. 若結論只在單一模式成立，不可寫成通則。

## 7. 常用術語模板

| 術語 | 中文詞義 | 在本專案的角色 |
|---|---|---|
| paired tumor-normal | 配對腫瘤/正常樣本分析 | 用於較穩定的主線驗證 |
| tumor-only | 純腫瘤分析 | 問題較難，適合驗證 rescue 與 triage |
| label-first | 依標籤驗證結構 | 驗證 HP/Allele 是否真能解釋甲基結構 |
| cluster-first | 依分群驗證標籤 | 驗證聚類結果是否真的對應標籤 |
| candidate-specific rescue | 候選集救援分析 | 直接針對 lost TP / removed FP 驗證規則 |

## 8. 驗收標準

1. 讀者看完背景段落後，能理解這輪任務的上下文。
2. 讀者能分辨哪些結論已成立、哪些尚未驗證。
3. 背景長度沒有淹沒主報告主體。
