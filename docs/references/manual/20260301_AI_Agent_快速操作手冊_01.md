# AI Agent 快速操作手冊

## 1. 健康檢查（異常時執行）

```bash
cd /big8_disk/liaoyoyo2001/InterSubMod
scripts/analysis/check_ai_agent_readiness.sh
```

建議觸發時機：
1. 重開機/重開工作階段後的第一個任務。
2. `.mcp.json`、`output` 軟連結、或 docs 架構剛調整過。
3. 任務輸出與預期不一致，或 Agent 出現路徑/文件落點異常。

若出現 `FAIL > 0`，先修復再執行研究任務。

## 2. 固定入口（避免路徑分岔）

1. repo 根目錄：`/big8_disk/liaoyoyo2001/InterSubMod`
2. output 入口：`output/`（實體為軟連結到 `/big8_disk/liaoyoyo2001/InterSubMod_runs/output`）
3. docs 入口：`docs/README.md`
4. 當前焦點：`docs/CURRENT_FOCUS.md`
5. 規範入口：`docs/standards/README.md`

## 3. Knowledge MCP 檢查

`.mcp.json` 需包含：

```json
{
  "mcpServers": {
    "knowledge": {
      "type": "stdio",
      "command": "python3",
      "args": ["/big8_disk/liaoyoyo2001/knowledge/scripts/mcp/knowledge_server.py"]
    }
  }
}
```

## 4. 文件落點規則（新版）

1. 計畫：`docs/plans/YYYY/MM/`
2. 報告（可重跑）：`docs/reports/validated/YYYY/MM/`
3. 報告（最終口徑）：`docs/reports/finalized/YYYY/MM/`
4. 實驗：`docs/experiments/in_progress|validated|finalized/YYYY/MM/`
5. 歷史快照：`docs/archive/deep/`（immutable，不回寫）

## 5. 禁用舊語彙（新文件不可再用）

1. `docs/analysis/`
2. `docs/reports/2026/`（請改 `reports/validated` 或 `reports/finalized`）
3. `experiments/outputs/`
4. 以 `output/bip8_disk_output` 當唯一輸出根（應改寫為 `output/` 入口或可配置 `OUTPUT_ROOT`）

## 6. 最小任務流程範本

```bash
# 1) 異常時健康檢查
scripts/analysis/check_ai_agent_readiness.sh

# 2) 執行流程（範例）
./scripts/pipeline/run_benchmark.sh --sample HCC1395

# 3) 驗證輸出
./scripts/verify_output.sh

# 4) 寫報告到 validated
# docs/reports/validated/YYYY/MM/YYYYMMDD_主題_01.md
```

## 7. 檔案清理安全規則（預設）

1. Agent 不可直接刪除檔案。
2. 若需移除，先搬到 Archive 暫存區：  
   `/big8_disk/liaoyoyo2001/InterSubMod_runs/Archive_pending_delete/`
3. 搬移後回報你，由你手動最終刪除。
4. 細則依 `docs/standards/20260301_AI_Agent操作安全與清理規範_01.md`。
