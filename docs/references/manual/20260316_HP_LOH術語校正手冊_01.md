# HP / LOH 術語校正手冊

## 一句結論

InterSubMod 文件中，必須把 **read-level HP tag**、**variant-level haplotype / H-flag 線索**、**region-level LOH inference** 明確分開寫。`HP=3` 不是 LOH，`hp_assign_rate` 不是主要生物訊號，`HP skew` / `haplotype skew` 只是 annotation / diagnostics，不能單獨升級成 LOH call。

## 1. 三層概念

| 層級 | 典型欄位/輸出 | 正確意義 | 不可直接做的事 |
|---|---|---|---|
| read-level | `HP=1`、`HP=2`、`HP=1-1`、`HP=2-1`、`HP=3` | 單條 read 的 germline haplotype 背景與是否支持 somatic ALT | 不能單靠某一個 HP tag 宣稱 LOH |
| variant-level | `H` flag、`AF~1.0`、`Potential_LOH`、`has_h_flag` | haplotype imbalance / LOH-like / allelic imbalance 線索 | 不能把單一 flag 當正式 LOH 結論 |
| region-level | phased genotype、`LOH.bed`、CNV / copy-number context | 長區段上的 LOH / structural event inference | 不能和 read-level HP tag 混寫成同一層證據 |

## 2. LongPhase-S

`LongPhase-S` 是 **paired tumor-normal** 的 somatic haplotagging + purity estimation。

### 2.1 HP tag 讀法

| HP 值 | 正確定義 |
|---|---|
| `1` / `2` | read 可分配到 germline haplotype 1 / 2 |
| `1-1` | read 支持 somatic ALT，且 ALT 可追溯到 germline haplotype 1 |
| `2-1` | read 支持 somatic ALT，且 ALT 可追溯到 germline haplotype 2 |
| `3` | read 支持 somatic ALT，但無法由既有 germline haplotype 唯一導出 |

### 2.2 文件寫法規則

1. `1-1 / 2-1 / 3` 一律寫成 **ALT-supporting reads**。
2. 不再把 `1-1 / 2-1` 寫成 `subclone 1`、`chimeric read`、或「跨越兩個 phased block」。
3. `HP=3` 可寫成 `ALT + unresolved germline HP` 或 `ambiguous somatic haplotype`，但**不可直接寫成 LOH**。

## 3. LongPhase-TO

`LongPhase-TO` 是 **tumor-only** 的 phase + haplotag + LOH region inference。

### 3.1 核心分工

1. `phase`：輸出 phased VCF，並可產生 `LOH.bed`
2. `haplotag`：把 phase 結果標到 BAM
3. `LOH`：來自 phased genotype / region inference，不是來自 BAM 中某個 HP tag

### 3.2 文件寫法規則

1. `LongPhase-TO` 的 LOH 一律優先連到 `LOH.bed`、phased genotype、copy-number context。
2. 若只看到 `H` flag、高 `AF`、`Potential_LOH` 或 `has_h_flag`，請寫成 `LOH-like` 或 `haplotype-imbalance proxy`。
3. 除非有 region-level 證據，不要把 `LOH-like` 升級成「已確認 LOH」。

## 4. InterSubMod 常用術語

| 術語 | 在 InterSubMod 的統一口徑 |
|---|---|
| `HP skew` / `haplotype skew` | 通常指 collapsed haplotype imbalance，例如 `(1 + 1-1)` 對 `(2 + 2-1)` 的偏斜；是 read-level / region summary annotation，不是正式 LOH call |
| `hp_assign_rate` | region 內 read 的 HP 可分派比例；代表 phase completeness / QC，非 truth-discriminative 主訊號 |
| `LOH-like` | 只表示資料呈現 haplotype imbalance、`H` flag、高 `AF`、`Potential_LOH` 或相近 proxy；**不等於正式 LOH** |
| `phase/QC annotation` | 可幫助解釋 read-level 完整度、可分派性、相位品質，但不應直接當 keep / veto 主規則 |
| `support annotation` | 有一定正向訊號，但仍不足以跨樣本、跨模式升級成 hard rule |

## 5. 建議寫法

### 5.1 推薦

1. `HP=1-1 / 2-1 / 3 均為 ALT-supporting reads`
2. `HP=3 代表 ALT read 的 germline HP 背景未能唯一解析`
3. `hp_assign_rate 應降階為 phase/QC annotation`
4. `LOH-like 僅為 haplotype-imbalance proxy，需另結合 LOH.bed / phased genotype / CNV`
5. `HP skew 只能作 diagnostics / annotation，不能單獨當 LOH 或 artifact 決策`

### 5.2 避免

1. `HP=3 = LOH`
2. `HP=1-1 / 2-1 = chimeric read`
3. `hp_assign_rate 高 = 這個位點 biologically 更真`
4. `LOH-like = 已確認 LOH`
5. `單側 HP skew = 可直接判 TP / FP`
