# 個人化研究寫作偏好設定規格

## 1. 固定高影響偏好

以下偏好預設固定保留：

1. 開頭先講結論。
2. 使用台灣繁體中文。
3. 專有名詞第一次出現補中文詞解釋。
4. 所有數據都要解釋意義。
5. 表格要能直接比較。
6. 圖片要解釋 X/Y 軸。
7. `.md` 連結優先使用絕對路徑 Markdown 連結。
8. 報告最後一定列待補齊事項與下一步。
9. 預設輸出採混合版，不只寫管理摘要。

## 2. 不固定的偏好

以下項目保持彈性：

1. 每份報告的篇幅
2. 每份報告的章節數
3. 是否一定要放圖片
4. 是否一定要把所有檔案逐一列出

## 3. 偏好調整原則

1. 若偏好只影響單一任務，先放在當次 prompt，不升級成固定規則。
2. 若偏好反覆出現且跨任務有用，納入 agent/skill。
3. 若偏好彼此衝突，以「可讀性、證據鏈完整性、可追溯性」優先。

## 4. 目前仍待確認的偏好

1. 週報是否需要額外輸出對外簡報版摘要。
2. 是否要把每次 prompt 的問答式 refinement 自動寫入固定 changelog。
3. 是否要把圖表說明固定拉高到投稿級詳細度。
