# 週報生成 Skill 規格

## 1. 目的

用一致、可追溯、可比較的方式，把多份研究記錄整理成單一 Markdown 報告。

## 2. 技能實體

- [intersubmod-weekly-report-writer/SKILL.md](/home/liaoyoyo2001/.codex/skills/intersubmod-weekly-report-writer/SKILL.md)

## 3. 預設輸出風格

混合版：

1. 前半段快速交代管理摘要與本週重點
2. 後半段保留研究證據鏈、表格與來源

## 4. 固定章節

1. Metadata
2. 開頭重點結論
3. 背景知識整理
4. 主要目標與子目標
5. 依時間順序的進展
6. 主題式整合分析
7. 數據表格與圖表解讀
8. 完成度總結
9. 尚待補齊事項
10. 下一步
11. 參考文件索引

## 5. 數據規則

### Benchmark 類

至少列：

| 欄位 | 意義 |
|---|---|
| `truth_total` | 真值集合母數 |
| `TP` | 真陽性數 |
| `FP` | 假陽性數 |
| `FN` | 假陰性數 |
| `precision` | 預測為陽性中有多少正確 |
| `recall` | 真值中有多少被找回 |
| `F1` | precision 與 recall 的綜合指標 |

### 規則比較類

若有 rescue 或 triage，盡量再列：

1. `TP_rescued`
2. `FP_reintroduced`
3. `delta_f1_vs_baseline`
4. `delta_f1_vs_gate`

## 6. 圖表規則

1. 只有真正能增加理解的圖才放進報告。
2. 若放圖，必須解釋：
   - 圖要表達的重點
   - X 軸數值單位與意義
   - Y 軸數值單位與意義
3. 圖片路徑使用：
   - 使用可直接檢視的絕對路徑 Markdown 格式
   - 範例格式請依實際圖片路徑填寫，不要保留占位字串

## 7. 連結規則

`.md` 內的檔案連結優先使用絕對路徑 Markdown 連結，例如：

- 例如：`/big8_disk/liaoyoyo2001/InterSubMod/docs/experiments/in_progress/2026/03/20260307_純樣本round執行與進度報告_01.md`

## 8. 結論分級

每個主結論都要標上屬性：

1. 已證明成立
2. 單一樣本成立
3. 尚未跨樣本驗證
4. 不建議升級為正式規則

## 9. 驗收標準

1. 讀者在開頭 1 段內就能知道本週重點。
2. 讀者能從表格直接看出規則差異。
3. 每個重要結論都能追溯到對應文件或 TSV。
