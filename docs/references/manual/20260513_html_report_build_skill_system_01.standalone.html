2.3 個 prompt mode 對照

report In-progress 草稿 / 短報告 — Tailwind prose 風格 companion

觸發路徑：docs/experiments/in_progress/ / 一般 .md / <200 行 + <5 figures

輸出：{basename}.html（單檔）或 {basename}/ folder（≥200 行或 ≥5 figures 時）

特色：max-width 70ch prose 容器、light restructure（不改 .md 邏輯）、callout for 警告、stat-grid 可選

slide PPT 簡報 — 16:9 canvas + section colors + speaker note

觸發路徑：docs/presentations/*/02_slide_outline.md 或含 ## Slide NN heading

輸出：preview/index.html（topbar + tab nav + iframe）+ slide_XX_*.html × N（self-contained）

9 section colors：S0 紫 / S1 紅 / S2 橘 / S3 黃 / S4 深藍 / S5 綠 / S6 青（reserved）/ S7 棕 / Q&A 灰

互動：PanZoom CDN + CSS hover fallback / 鍵盤 ←→ 切換

standalone ★ PI 終版單檔 — sticky TOC + section cards + inline SVG + 列印友善

觸發路徑：docs/reports/validated/ / pi_reports/ / concepts/ / data_specs/ / references/manual/ / experiments/concluded/

輸出：{basename}.standalone.html — single-file self-contained，給 PI 一個附件就完事

特色（HTML-only，MD 做不到）：

  • Sticky 左側 TOC（220px column）
  • Section cards <details> 折疊（core open / minor collapsed）
  • Inline SVG 圖（≤5，因果鏈/比例條/icon）
  • Stat-grid 焦點數字
  • Print mode 強制展開 + 印 URL
  • Mobile fallback ≤900px 單欄
  • Colorblind-safe row coloring + 文字 verdict 雙重編碼

本文件本身就是 standalone mode 的範例 — 用 dogfooding 方式自我介紹。

5.Auto-trigger 機制

1. 用戶 Edit/Write docs/reports/validated/.../foo.md
2. PostToolUse hook → standalone_trigger.sh 觸發
3. Hook 檢查路徑：
   - SKIP: README.md / CLAUDE.md / state.json / in_progress 草稿
   - SKIP: 若 .standalone.html 已比 .md 新
   - TRIGGER: validated reports / concepts / data_specs / manual
4. Hook 印 3 行 [html-report-build] reminder
5. Claude 看到 reminder，呼叫 Skill html-report-build
6. Skill 讀取：source .md + design_principles.md + standalone_prompt.md
              + standalone_skeleton.html + components/svg_*.html
7. 生成 {basename}.standalone.html (sticky TOC + cards + SVG)
8. 6-Taboo audit + 12 rules self-check → ship
