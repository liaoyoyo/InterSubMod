## 1. 專案總覽

**InterSubMod**(Inter-Subclonal Methylation Analysis)是一套針對**長讀取(Nanopore / ONT)測序**設計的腫瘤表觀遺傳變異分析工具。它整合三種單分子訊號 —— **甲基化(methylation)、體細胞變異(somatic SNV, sSNV)、單倍體型(haplotype, HP tag)** —— 以解析腫瘤內的**亞克隆結構(subclonal structure)**與表觀遺傳異質性。

| 面向 | 內容 |
|---|---|
| **科學目標** | 用 ONT 長讀單分子同讀的 somatic + haplotype + 5mC 訊號,重建腫瘤區域級(≤read-span)亞克隆演化結構 |
| **技術核心** | C++17 + OpenMP 平行運算核心;Python(matplotlib/seaborn/scipy)視覺化;Bash 管線膠合 |
| **主力樣本** | HCC1395(乳腺癌細胞株,SEQC2 truth set 標定)為 ⭐3 exploratory 主樣本;另有 6 cell line × 3 癌種資產 |
| **論文題目** | *Subclonal reconstruction using somatic haplotagging and methylation profiles with Nanopore sequencing* |
| **當前成熟度** | ⭐3(單樣本、single-pipeline 封頂);升 ⭐4 需 ≥5/7 樣本 + COLO829 normal 甲基 |

**專案結構(頂層)**:

| 目錄 | 用途 |
|---|---|
| `src/` `include/` | C++17 核心原始碼(約 30 個核心模組) |
| `tools/` | Python 視覺化(距離熱圖、分群熱圖) |
| `scripts/` | 單樣本一鍵腳本 + 多樣本 benchmark 管線 |
| `docs/` | 研究文件(methodology、paper_focus、thesis、reports…) |

## 2. 當前研究方向

### 2.1 科學定位與三資訊源分工

論文採 **A-framing**,三種訊號角色嚴格分離,這是不可違反的紅線:

| 資訊源 | 角色 | 說明 |
|---|---|---|
| **somatic sSNV 單分子共現** | 🟢 **重建引擎** | 唯一非循環的克隆共現證據;所有 reconstruction 歸此 |
| **haplotag(HP tag)** | 🟢 **鑑別器(非確認器)** | 區分 allelic vs clonal,移除等位性假 subclone |
| **甲基化** | 🟡 **有界 characterize** | 對已確認結構的表觀註解,**不能單獨偵測 subclone** |

一句話貫穿全篇:**「甲基能佐證、不能篩選(methylation corroborates, does not filter)」** —— 須在 Introduction 與 Conclusion 首尾呼應。

### 2.2 創新點口徑(投稿必守,逐字)

> **「無監督 read×read 距離矩陣結構 PERMANOVA + normal-baseline cis-test + somatic-subclone 目標」**

此為 ISM(Individual-read Structure/Methylation)方法與業界主流「per-haplotype 塌平比平均(HP1 vs HP2 germline 軸)」方法的**本質差異點**。

### 2.3 三段研究流程(帶關鍵數字)

**第一段:somatic 共現骨幹重建局部克隆結構**
- 35,332 sSNV(TP 30,490 + FP 4,842,SEQC2 標)→ 7,143 區域。
- 4,678 區有確認結構(含 **677 full_tree** + linear_nested + sibling + 858 co_linked 單 lineage);3,820 區(53%)具分支/階層結構。
- 三桶宇宙帳本:**linked 可建樹 21,554(61.0%)/ underpowered 5,458(15.4%)/ isolated 8,320(23.5%)**。
- ✅ 已排除 tumor BAM 1.18× QNAME 重複污染(co-read 計數 QNAME-keyed 自動去重,三桶比例 canonical)。

**第二段:haplotag 鑑別 allelic vs clonal**
- 不分 HP 時誤判 9,187 個「subclone」;HP gate 後 same-HP 保留 3,949(候選,非確認)、移除 5,238(57%)等位性(diff-HP)。
- HP tag 語意（genome-wide V1 交叉表 2026-07-04 佐證）:`1/2`=germline（V1: 0% 碰 somatic ALT）;`1-1/2-1`=germline HP 上帶 somatic 的 haplotype（V1: ~97% confident ALT）;`3`=HP3 = 經過任一 somatic ALT、但 germline 定相未確認/HP 衝突（V1: ~97.5% confident ALT）;`0`=unphase = REF-only 定相失敗（沒碰 germline 或 germline 衝突;V1: 99.2% 不碰 ALT;ReadParser 輸出 `"0"` 非 `"unphase"`）。判別軸=是否經過 confident somatic ALT;HP3≠unphase，勿混談。🔴 把 `1-1/2-1/3` 當獨立 subclone 證據 = 循環,須嚴格避免。

**第三段:甲基輔助 characterize(有界,非偵測)**
- genome-wide 740 區重抽(驗證 corr=1.000 vs ISM):僅 49 區(6.6%)corroborate;**0 個新 partition 由甲基獨立發現**。
- cis-control(修正後):14/49 可評估,11 解析為 germline 等位特異甲基化(非 subclone)、3 候選。

### 2.4 兩層鐵律(754 區三軸大規模驗證)

| 層 | 訊號強度 | 數據 | 是否有用 |
|---|---|---|---|
| **Haplotype(germline ASM)** | 強、普遍、非循環 | neutral 62%、Δβ 0.97 | ✅ 對 phasing / read 招募有用 |
| **Subclone(somatic-specific)** | 稀少 | 全基因組僅 7–9 區 | 🟡 需 matched-normal |

- 甲基錨點把 read 招募到 HP 準確度 **96.3%**,可救 **334 個** unphased / HP3 read（V2 拆分:318 unphase + 16 HP3;招募指派 HP3 = 15:1 偏一條 lineage、unphase ≈ 50/50 背景）;
- 但 within-HP subclone 招募僅 **10.5%** → 甲基串接是 **phasing 層擴充,非 subclone 層**。

## 4. 方法細節:程式碼架構與分析流程

### 4.1 建置系統與依賴

- **CMake ≥ 3.14**(`CMakeLists.txt`,178 行),`project(InterSubMod CXX)`,C++17。
- **編譯旗標**:Release 預設 `-O3 -march=native -DNDEBUG`;Debug `-g -O0 -DDEBUG`;全域 `-Wall -Wextra -pedantic`。
- **依賴取得**:HTSlib(系統 pkg-config)、Eigen3 3.4.0(FetchContent)、OpenMP(find_package)、jemalloc 5.3.0(ExternalProject 靜態編譯,`-DUSE_JEMALLOC`)、GoogleTest 1.14.0(FetchContent)。
- **CMake targets**:`inter_sub_mod_core`(靜態庫)、`inter_sub_mod`(主執行檔)、`test_phase1_2/3/4_5`(ad-hoc)、`run_tests`(GoogleTest,17 個測試檔)。
- **Python 依賴**(`requirements.txt`):numpy/pandas/matplotlib/seaborn/scipy。

### 4.2 核心模組職責表

`src/main.cpp`(82 行)是輕量 driver:`ResourceMonitor` → `ArgParser` 填 `Config` → `config.validate()` → 建 `RegionProcessor` → `[1] load_snvs_from_vcf` → `[2] process_all_regions(0)` → `[3] print_summary`。所有運算封裝在 `RegionProcessor`(776 行標頭,總調度)。

**A. I/O 與讀取層**

| 模組 | 職責 |
|---|---|
| **BamReader** | HTSlib thread-safe BAM 讀取;RAII `BamRecordPtr`;每執行緒各持一實例避免檔案指標競爭 |
| **ReadParser** | 過濾(MAPQ≥20 / len≥1000 / baseQ≥20);解析 HP/PS phasing tag、strand;用 CIGAR 判 SNV 位點 ALT/REF |
| **SomaticSnv** | VCF SNV 結構 + `ChromIndex`(染色體名↔整數 ID) |
| **FastaReader** | 讀參考序列(驗證 CpG context) |

**B. 甲基化與矩陣層**

| 模組 | 職責 |
|---|---|
| **MethylationParser** | **關鍵模組**:解析 MM(delta 編碼)/ML(機率)標籤 → hg38 座標;**僅取 5mC(`C+m?`)**,5hmC 刻意丟棄 |
| **MatrixBuilder** / **MethylationMatrix** | 建 Read×CpG 稀疏矩陣:raw(0–1,NaN)+ binary(1/0/-1,閾值 0.8/0.2) |
| **ReadAggregator** | 封裝「過濾→甲基解析→建矩陣」子流程 |
| **NormalBaseline** | 由 Normal reads 算 per-CpG 基線,residual 去 germline ASM,分離純體細胞 HP ASM |

**C. 距離、分群與建樹層**

| 模組 | 職責 |
|---|---|
| **DistanceMatrix** | read-read 距離(**BERNOULLI 預設** / NHD / L1 / Jaccard / 相關);C_min、NaN 策略(SKIP 預設)、二值化 |
| **HierarchicalClustering** | 由距離矩陣建二元分群樹;linkage UPGMA(預設)/ Ward / Single / Complete |
| **TreeStructure** | 樹節點結構(leaf/internal、height、branch_length、bootstrap_support),供 Newick 輸出 |
| **PhyloLabeler** | phylo-v4.1 分群標記(coarse null95 + fine null90);固定 seed=20260622 對齊 Python `phylo_v4.py` 跨語言可重現 |
| **SubcloneAnalyzer** | 跨 region 聚合 `RegionAsmProfile`(HP/sample ASM delta、hp_ratio、coverage_multiple…),分 subclone 群組 |

**D. 顯著性統計層(`SignificanceAnalyzer` 為總入口)**

| 模組 | 職責 |
|---|---|
| **SignificanceAnalyzer** | 統合下列檢定的主入口(Global→Local→Structure→Bootstrap) |
| **GlobalTest** | 群組標記 vs 生物標記全域關聯:Fisher-Freeman-Halton(RxC)/ 卡方 / Cramér's V;`gating_p`>0.1 跳過下游省算力 |
| **LocalTest** | 每個 cluster 做 one-vs-rest Fisher,找驅動關聯的具體 cluster |
| **StructureTest** | PERMANOVA(預設 999 置換)+ dispersion 檢查 |
| **LabelTest** | Label-First 路徑:Δ=between−within 距離 + 置換檢定,測 HP/Allele 標記是否解釋距離結構 |
| **Bootstrap** | 重抽 CpG 位點,以 ARI 量化分群穩定度(預設 200 次,含 early-stop) |
| **FisherExact** | 2×2 Fisher(雙尾,R 相容)+ RxC FFH(Monte Carlo) |
| **PerCpgAsm** | Per-CpG ASM 檢測 + epiallele 異質度:Fisher+BH-FDR、NME(正規化甲基熵)、Epipolymorphism |
| **LohBedAnnotator** | 讀 LongPhase LOH BED,標註 region 的 LOH 來源 |

### 4.3 完整資料流(End-to-End)

```
main.cpp
 └ RegionProcessor::load_snvs_from_vcf(VCF)      # [1] 載入 sSNV
 └ RegionProcessor::process_all_regions(0)       # [2] OpenMP 平行,每 SNV 一 region
      每 region:
      1. 讀取過濾   BamReader.fetch_reads(chr, pos±window)
                    → ReadParser 過濾 + HP/PS + CIGAR 判 ALT/REF
      2. 甲基解析   ReadAggregator → MethylationParser(MM/ML,僅 5mC,delta 解碼,映射 ref)
      3. 建矩陣     MatrixBuilder → MethylationMatrix(raw 0-1 + binary 1/0/-1;缺=NaN)
      4. 距離       DistanceMatrix(BERNOULLI;C_min=3;NaN=SKIP)+ forward/reverse strand
      5. 分群建樹   HierarchicalClustering(UPGMA)→ TreeStructure → PhyloLabeler
      6. 顯著性     SignificanceAnalyzer:GlobalTest(FFH)→[gating]→ LocalTest
                    → StructureTest(PERMANOVA)→ Bootstrap(ARI)+ LabelTest
                    + PerCpgAsm + NormalBaseline residual
      7. subclone   SubcloneAnalyzer 跨 region 聚合 ASM profile
      8. 輸出       RegionWriter(matrices/reads)+ TreeWriter(Newick)→ RegionResult
 └ write_significance_summary(results)            # 全域主表 significance_summary.csv
```

**關鍵預設值**(來自 `Config.hpp` / `ArgParser.hpp`):
- 距離度量預設 **BERNOULLI**(非 README 所述 NHD/L1);NaN 策略預設 **SKIP**(2026-06-14 改;去除 1.0 污染,HP-AUC 0.64→0.835)。
- `window_size_bp=1000`、`min_mapq=20`、`min_read_length=1000`、`min_base_quality=20`。
- 二值化閾值 high=0.8 / low=0.2;`min_site_coverage=5`、`min_common_coverage=3`(C_min)。

### 4.4 執行方式

**(a) 手動執行 C++ 核心(僅產數據)**
```bash
./build/bin/inter_sub_mod \
    --tumor-bam data/tumor.bam --reference data/ref.fa --vcf data/somatic.vcf \
    --output-dir results --threads 32 --window-size 1000 \
    --distance-metric BERNOULLI --output-filtered-reads --log-level info
```

## 6. 方法學裁決摘要

### 6.1 sSNV 單分子共現重建骨幹(演算法)

**非循環骨幹**:樹由 sSNV 單分子共現(genotype 軸)建,**不靠 HP tag、不靠甲基**;HP tag 只當鑑別器,normal=REF 確認 somatic。理論根據 = 二元字元 perfect-phylogeny → pairwise 相容即足以定樹。

五階段流程(`_assets/20260627_subclone_4axis_teaching/scripts/`):
S0 宇宙(union TP∪FP)→ S1 分組(gap>50kb 切 linkage group)→ S2 共現(co-read≥6 的 2×2 → 6 類)→ ML(genotype 向量,MINREAD≥3)→ 整合(co_linked union-find / nested 有向邊 / transitive_reduction 去環)→ 拓樸(perfect-phylogeny laminar solve + determinacy)。

### 6.2 三層機率架構(核心裁決)

clone read 標記**可以做且該做成 Cardelino 式 beta-binomial 機率指派**(遺傳驅動);但**甲基與 region 級 CN 絕不能進分群目標函數**。三層角色分離:

```
LAYER 1  分群目標(likelihood,非循環 genetic only)    = { somatic SNV 單分子共現(主), SV breakpoint(共錨) }
LAYER 2  conditioning 錨(固定 prior/offset,不當距離軸)= { HP-germline(1/2), CN / local coverage }
LAYER 3  bounded-auxiliary 事後(群凍結後才動)         = { methylation }
```

**證據階層(3-tier,排序固定)**:
```
P(拓樸 T) ∝ P(sSNV共現|T) × 1[HP-root 相容] × P(甲基|T,normal-baseline)^w
            Tier1 決定性,非循環    Tier2 硬約束        Tier3 prior,弱權,cis-control-gated
```

**為何甲基不得進 likelihood(cis-ASM 循環,DAG 論證)**:令 subclone label `L ≡ f(G_som)`,read 甲基 `M` 是 label 之父 `G_som` 的後裔 → 把 `M` 放進 likelihood 推 `L` = 循環/雙重計數 + collider。經驗證據:跨 CN 態 near-Δβ 幾乎相同(loh/neutral/gain = 0.040/0.040/0.041),去 cis 後僅 6–13% CpG 顯著;甲基連 impute genotype 都做不到(LOOCV balanced_acc 中位 0.566 ≈ 隨機)。

## 附:一句話總結

> InterSubMod 用 **ONT 長讀單分子共現的 somatic sSNV(非循環骨幹)+ HP 定根(鑑別器)+ 甲基有界輔助(characterize)** 重建 HCC1395 腫瘤區域級亞克隆樹。正向核心是遺傳骨幹(61% linked 可建樹、45.4% 有向量區 determined 為軟上界、真正穩固 L4 僅 44 區),三個關鍵演算法正向成果 = pairwise 傳遞救回、gained-pair 定序消除假等機率、incompatible 重分類救回隱藏祖先深分支樹。**甲基被系統性證明只能 bounded-auxiliary**(進 likelihood / 排序拓撲 / 確認 subclone / cis-control 解鎖全部 NEGATIVE);最大未控 confound = CN-gain multiplicity(指向 allelic CN 為最高槓桿)。HD-1 循環性已從卡關收斂為非承重。全程 ⭐3 單樣本封頂;升 ⭐4 的 P0 gate = 跨 6 樣本重現(待 COLO829)+ within-HP 正確 null。**論文主軸 = case-demonstration 版 subclonal reconstruction,以 chr2:18M 旗艦個案為 Figure 1,「甲基能佐證、不能篩選」為貫穿主張。**
