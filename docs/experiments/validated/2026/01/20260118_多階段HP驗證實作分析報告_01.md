# 多階段 HP/Allele 標籤驗證系統 - 實作分析報告

## 1. 實作概述

### 1.1 改動目標

重構 LabelTest 模組，實現多階段驗證架構，以更完整地分析 HP Tag 與 Allele 標籤對甲基化模式的解釋能力。

### 1.2 新增的驗證階段

| 階段 | 名稱 | 分組方式 | 統計方法 |
|------|------|---------|---------|
| Stage 1 | HP Family Merged Test | (HP1+HP1-1) vs (HP2+HP2-1) | Binary Delta Test |
| Stage 2 | HP Fine-Grained Test | HP1, HP1-1, HP2, HP2-1 (4組) | Multi-group PERMANOVA |
| Stage 3 | Allele Test | ALT vs REF | Binary Delta Test |
| Stage 4 | Unassigned Affinity Test | HP3/HP0 歸屬判定 | 距離比較 + Permutation |

### 1.3 修改的檔案

| 檔案 | 修改內容 |
|------|---------|
| `include/core/Stats.hpp` | 新增 `HPFinePairwise`, `UnassignedAffinityResult`, `MultiStageHPResult` 結構 |
| `include/core/LabelTest.hpp` | 更新 `LabelTestResult` 結構，新增多階段測試函數宣告 |
| `src/core/LabelTest.cpp` | 實作 `hp_to_merged_labels()`, `hp_to_fine_labels()`, `test_hp_merged()`, `test_hp_fine_grained()`, `test_unassigned_affinity()` |
| `src/core/SignificanceAnalyzer.cpp` | 整合 `hp_multistage` 結果 |
| `include/core/RegionProcessor.hpp` | 新增多階段結果欄位到 `RegionResult` |
| `src/core/RegionProcessor.cpp` | 更新 CSV 輸出 |

## 7. 結論與評估

### 7.1 改動的影響

1. **核心分類性能不變**
   - Significant 欄位的 Precision/Recall/F1 完全相同
   - 主要的分類邏輯未受影響

2. **VerificationClass 分布調整**
   - Weak 類別的 TP/FP 比從 8.75 提升到 9.79 (+11.9%)
   - Strong 類別的 TP/FP 比維持 4.18 不變
   - 部分 Weak 重新分類為 Noise

3. **DominantLabel 重新分配**
   - 約 41% 原本 HP 主導的區域轉為 Allele 主導
   - 反映新的 Stage 1 (Merged Family) 判定邏輯更嚴格

### 7.2 新功能價值

1. **更精細的 HP 結構分析**
   - Stage 2 提供 4 組細分 PERMANOVA 分析
   - 可識別 germline vs somatic 的甲基化差異

2. **Unassigned Reads 歸屬判定**
   - Stage 4 分析 HP3/HP0 reads 的傾向
   - 提供 affinity_score 量化指標

3. **更豐富的 CSV 輸出**
   - 17 個新增欄位提供更詳細的分析資訊
   - 支援後續 F1 優化研究

### 7.3 是否「更好」?

| 面向 | 評估 |
|------|------|
| 分類準確度 | 無變化 (Significant 欄位) |
| Weak 類別區分 | ↑ 提升 11.9% (TP/FP 比) |
| 資訊豐富度 | ↑ 顯著提升 (多階段結果) |
| 向後相容性 | ✓ 完全相容 |
| 計算效能 | 略有增加 (多階段測試) |

**總體評估:** 此次改動主要增加了分析的**深度與細節**，而非改變核心分類邏輯。新增的多階段結果為後續的 F1 優化和分類策略研究提供了更多可用的特徵。
