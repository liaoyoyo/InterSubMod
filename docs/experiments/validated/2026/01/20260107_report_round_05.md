## 1. 此次程式碼修改

### 修改內容
V ≥ 0.1 + 深度 ≥ 30 組合過濾：

```cpp
bool is_significant = r.passed_gating && 
                      (r.global_p_value <= 0.05) && 
                      (r.cramers_v >= 0.1) &&
                      (r.num_reads >= 30);  // 新增
```

## 3. 結果觀察總結

### 發現
**深度過濾 (≥30) 對結果影響極小**

原因：
1. 已經通過 V ≥ 0.1 篩選的位點，大多深度本來就足夠
2. 低深度位點通常 V 值也低，已被 V 閾值排除
3. 深度過濾是**冗餘的**

---

## 4. 最終結論

### ✅ 最佳方案：Round 2 (V ≥ 0.1 閾值)

```cpp
bool is_significant = r.passed_gating && 
                      (r.global_p_value <= 0.05) && 
                      (r.cramers_v >= 0.1);
```
