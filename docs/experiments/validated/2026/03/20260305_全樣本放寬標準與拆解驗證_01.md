# 全樣本放寬標準與拆解驗證

## 1. 實驗問題

1. 是否存在可套用於全部樣本的單一放寬標準，整體提升 F1？
2. `VAF` 與甲基相關條件（此處以 `AlleleDelta` 為主）是否能再提升 F1？

## 2. 實驗設定

- 樣本：`HCC1395, HCC1395_DORADO, COLO829, H1437, H2009, HCC1937, HCC1954`
- 資料：`per_variant_decision.tsv.gz`（已含 TP/FP 與規則欄位）
- 搜尋條件：
  - `AD` 門檻：`0.15, 0.17, 0.20, 0.25, 0.30`
  - `CV` 門檻：`0.03, 0.025, 0.02, 0.015, 0.01`
  - `VAF` 門檻：`0.15, 0.12, 0.10, 0.08, 0.05`

## 3. 主要結果

### 3.1 全樣本最佳單一標準

- `AD > 0.15 AND CV < 0.03 AND VAF < 0.08`
- 相對 baseline：
  - 改善樣本：`6/7`
  - 平均 F1 delta：`+0.000061`
  - 最差 F1 delta：`-0.000130`（HCC1954）

### 3.2 標準拆解（全樣本平均）

- 單一條件：
  - `VAF`：mean F1 delta `-0.001826`
  - `AD`：mean F1 delta `-0.007942`
  - `CV`：mean F1 delta `-0.692060`
- 雙條件：
  - `AD+VAF`：mean F1 delta `+0.000046`
- 完整條件：
  - `AD+CV+VAF`：mean F1 delta `+0.000053`

### 3.3 邊際影響（Shapley / Ablation）

- Shapley（GLOBAL_MEAN）：
  - `VAF`: `+0.117047`
  - `AD`: `+0.112964`
  - `CV`: `-0.229958`
- Ablation（由 full rule 移除）：
  - 移除 `VAF`：mean drop `+0.003782`
  - 移除 `AD`：mean drop `+0.001732`
  - 移除 `CV`：mean drop `+0.000007`

## 4. 結論（針對提問）

### Q: 是否可表示 `VAF` 與甲基資訊可再提升 F1？

**可以，但要以「組合條件」解讀，不是單一條件。**

1. 單獨使用 `VAF` 或 `AD` 都不足以穩定提升全樣本 F1（平均為負）。
2. `VAF + AD` 組合開始呈現正向效益（mean F1 delta `+0.000046`）。
3. 加上 `CV` 後僅小幅增益到 `+0.000053`，代表現行門檻下 `CV` 不是主要驅動因子。
