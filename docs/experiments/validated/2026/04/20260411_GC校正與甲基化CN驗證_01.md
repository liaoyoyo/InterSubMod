## Investigation 1: GC-Content 校正

### 動機

Coverage_Multiple 最大假設系統誤差是 GC-content bias。ONT 有已知 GC 偏差，ISM 目前零 GC 校正。

### 方法

1. 對每個 ISM region（chr:pos ±1000bp），從 hg38 計算 GC%
2. 建立 GC-coverage curve（3rd-degree polynomial fit: NumReads vs GC%）
3. 計算 GC-corrected NumReads = NumReads / expected_GC_effect
4. 重算 Coverage_Multiple_GCcorr，與 SEQC2 CN 比較 Pearson r
5. Go/No-Go 門檻：delta-r ≥ 0.03

### 結果

| 方法 | Pearson r | CN 分類準確度 | Delta r |
|------|-----------|---------------|---------|
| 75x hardcoded | 0.8271 | 6.2% | — |
| KDE auto (55x) | 0.8271 | 43.8% | +0.0000 |
| GC-corrected (53x) | 0.8269 | 47.8% | **-0.0002** |

**TP/FP 區分 AUC**：

| 特徵 | AUC |
|------|-----|
| Quality_Score | 0.5119 |
| CovMult_75x | 0.5095 |
| CovMult_KDE | 0.5095 |
| CovMult_GCcorr | 0.5097 |
| NumReads | 0.5095 |

### GC Bias 分析

- GC range: 0.138 - 0.760（mean 0.411）
- Mean relative change from GC correction: **1.828%**
- Max relative change: 34.150%
- Regions changed > 10%: **54 (0.1%)**
- 98.7% regions 變化 < 5%

### 判定

**NO-GO**：delta-r = -0.0002，遠低於門檻。ONT 5kHz GC bias 極小，不需校正。

## Investigation 2A: 甲基化特徵-CN 相關性

### 動機

問「甲基化 heterogeneity 是否隨 CN 變化」— characterization 問題，非 filtering。

### 方法

使用 Paired 模式 `annotated_hcc1395_cnv.tsv`（31,640 rows），計算每個 ISM 特徵與 SEQC2_CN 的：
1. Raw Spearman correlation
2. Residualized correlation（對 NumReads 回歸後）

### 結果

| 特徵 | Raw r | Residualized r | 判定 |
|------|-------|----------------|------|
| NumReads | 0.788 | — | — |
| HPFineNGroups | 0.495 | 0.160 | 68% confound |
| PairwiseMeanDist | 0.071 | 0.023 | CN-blind |
| PairwiseMedianDist | 0.056 | 0.018 | CN-blind |
| CramersV | -0.241 | -0.726 | zero-dom artifact |
| ClusterPermanovaF | 0.0 | 0.0 | all zeros (pileup) |

### 判定

**NO-GO**：所有 HP-free 特徵 residualized |r| < 0.07。甲基化對 CN 完全無感。

CramersV residualized r=-0.726 是 artifact：93% 零值 residualize against NumReads 產生虛假相關（見 feedback_L2_collider_bias.md）。

## Investigation 2B: Cluster Count vs CN Agreement

### 結果

- HPFineNGroups raw Spearman r=0.495 與 SEQC2_CN
- Residualize against NumReads 後 r=0.160
- **68% 的相關是 read count confound**

### 判定

**NO-GO**：HPFineNGroups 不能作為 CN 驗證器。其 CN 相關主要來自「更多 reads → 更多 clusters」的統計效應，非生物學 CN-methylation 關聯。

## 已實作 C++ 改進

### 1. KDE Auto-Estimation

- 檔案：`src/core/RegionProcessor.cpp`（`estimate_diploid_coverage()`）
- 方法：histogram-based mode + Gaussian smoothing（bin_size=2, sigma=3）
- 效果：75x hardcoded → 自動估計（HCC1395 = 55x）
- CN 分類準確度：6.2% → 43.8%（7× 提升）
- 跨 7 樣本驗證：mean deviation from 1.0 降低 45%（0.223 → 0.122）

### 2. `--expected-coverage` CLI 參數

- 檔案：`include/utils/ArgParser.hpp`, `include/core/Config.hpp`
- 用途：允許用戶覆寫 KDE 估計
- 預設值：0（= auto-estimate）
- 範圍：0.0 - 1000.0
