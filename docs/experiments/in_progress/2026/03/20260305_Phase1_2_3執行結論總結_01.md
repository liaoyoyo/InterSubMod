### 2.3 Bug 修正：no-filter 模式 Segmentation Fault

**根本原因**：`--no-filter` 模式下，`RegionProcessor` 跳過 FLAG 過濾，使 secondary 讀段（FLAG=256，SEQ="*"）進入 `MethylationParser`，因無效序列觸發未定義行為（非確定性 Segfault）。

**證據**：
- H2009 chr19:206540-216540 含 530 個 secondary 讀段（長度 = 1，SEQ="*"）
- 單獨執行該位點觸發 Segfault；移除 secondary 讀段後穩定
- COLO829 BAM 在同一位點無 secondary 讀段 → 無崩潰

**修正**（`src/core/RegionProcessor.cpp`）：
```cpp
// 即使在 no-filter 模式下，仍需跳過 secondary/supplementary/unmapped/duplicate 讀段
if (no_filter_output_) {
    uint16_t flag = b->core.flag;
    if (flag & (BAM_FSECONDARY | BAM_FSUPPLEMENTARY | BAM_FUNMAP | BAM_FDUP)) {
        continue;
    }
}
```

**驗證**：
- H2009 j=8 修正後：Exit=0, Files=2843 ✅
- ctest：105/105 通過 ✅
