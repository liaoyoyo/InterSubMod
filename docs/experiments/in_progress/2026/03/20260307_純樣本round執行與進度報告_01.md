### Benchmark

### 主要觀察

1. `LongPhase-S` 相對 `ClairS`：

   - F1 `0.8522 -> 0.8513`，下降 `-0.0009`

輸出：

3. [HCC1395 5kHz current core subset summary](/big8_disk/liaoyoyo2001/InterSubMod/output/bip8_disk_output/s-pure/HCC1395/20260307/rule_analysis/current_core_ad015_vaf015_subset_summary.tsv)
4. [HCC1395_DORADO rule comparison](/big8_disk/liaoyoyo2001/InterSubMod/output/bip8_disk_output/s-pure/HCC1395_DORADO/20260307/rule_analysis/rule_comparison.tsv)

關鍵發現：

1. 在真實 VCF 上，`QUAL < 0.75` 分支沒有實際作用
2. 舊規則的實際效果等同於：
   - `AlleleDelta > 0.25`
   - `CramersV < 0.05`
   - `VAF < 0.24`
3. 在 `HCC1395 5kHz`：
   - 舊 combo：`TP removed=3`，`FP removed=56`，`F1 +0.000643`
   - 新 core `AlleleDelta > 0.15 & VAF < 0.15`：`TP removed=2`，`FP removed=83`，`F1 +0.00099`
4. 在 `HCC1395_DORADO`：
   - 舊 combo：`TP removed=7`，`FP removed=0`，`F1 -0.000139`
   - 新 core：`TP removed=12`，`FP removed=2`，`F1 -0.000197`
5. `CramersV < 0.05` 在這批觸發子集幾乎沒有額外篩選力：
   - `ad015_vaf015`
   - `ad015_cv005_vaf015`
   兩者在 `5kHz` 上觸發集合完全相同

目前最合理的解釋：

1. `5kHz` 有一批低 VAF、偏高 `AlleleDelta`、但缺乏穩定全域結構的 artifact-prone calls
2. 這批 calls 在 `5kHz` 上更常是 FP，所以規則有輕微正增益
3. 同樣概念在 `DORADO` 上移除的是 TP 為主，表示它不是跨平台通用規則
4. 這應該被記為「重要候選特徵概念」，而不是直接升級成全域預設規則
