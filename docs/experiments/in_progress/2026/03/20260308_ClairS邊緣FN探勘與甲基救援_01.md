# ClairS 邊緣 FN 探勘與甲基化救援實驗

## 研究動機

InterSubMod 甲基化訊號對 FP triage 有效，但對 TP rescue 的貢獻受限（實驗 19）。
本實驗針對更根本的問題：**ClairS 自身未進入 PASS callset 的 truth set 位點（FN=11,051）**，
其中部分可能有可觀測訊號，甲基化是否能成為補充條件救回其中一部分？

## 實驗結果

### 實驗 1：Pool B FN 數量枚舉 ✅

- Pool B 候選（non-PASS, 非 NonSomatic）：6,647 個
- Pool B 範圍內（truth BED scoping）：3,482 個
- **Pool B FN（在 truth set 中）：840 個**
- Pool B non-FN（不在 truth set）：2,642 個
- **Go/No-Go：GO（840 >> 30 門檻）**

### 實驗 2：Pool B FN 特徵分布 ✅

| 指標 | Pool B FN (840) | Pool B non-FN (2642) |
|------|----------------|---------------------|
| Median GQ | **16.0** | 6.0 |
| Median AF | 0.375 | 0.243 |
| Median DP | 79.5 | 80.0 |
| LowQual only 比例 | 24.3% | 6.9% |
| VariantCluster 比例 | **49.1%** | **85.2%** |
| StrandBias 比例 | 3.7% | 4.7% |

**Pool B FN 的 FILTER 分布（840 個）：**

| FILTER | 數量 | 比例 |
|--------|------|------|
| LowQual;VariantCluster | 411 | 48.9% |
| LowQual | 204 | 24.3% |
| LowQual;NoAncestry | 123 | 14.6% |
| LowQual;LowAltBQ | 52 | 6.2% |
| LowQual;StrandBias | 31 | 3.7% |
| LowQual;MultiHap | 14 | 1.7% |
| 其他 | 5 | 0.6% |

**關鍵觀察**：Pool B FN 的 GQ 中位數 (16) 明顯高於 non-FN (6)，AF 中位數也更高 (0.375 vs 0.243)。
這兩組的 VariantCluster 比例差異最顯著（49% vs 85%），提示 VariantCluster 是區分 FN/非 FN 的重要特徵。

### 實驗 3：甲基化覆蓋率 ✅（策略 B 完成）

- 初始覆蓋率：0.0%（non-PASS 位點未在原本 InterSubMod 輸入中）
- **執行策略 B**：補跑 InterSubMod 在 pool_b_fn.vcf.gz 與 pool_b_non_fn.vcf.gz
  - Pool B FN 補跑後覆蓋率：**99.9%（839/840）**
  - Pool B non-FN 補跑後覆蓋率：**98.8%（2609/2642）**
- **判斷：覆蓋率遠超 40% 門檻 → Combined 規則評估可進行**

### 實驗 4：最佳救援規則 ✅

**Caller-only 規則（依 F1 delta 排序）：**

| 規則 | TP+ | FP+ | Rescue Precision | F1 delta |
|------|-----|-----|-----------------|---------|
| `no_varcluster` | 428 | 390 | 52.3% | **+0.003391** |
| `gq15_and_af015` | 448 | 547 | 45.0% | +0.002316 |
| `gq_ge_15` | 449 | 558 | 44.6% | +0.002235 |
| `lowqual_only` | 204 | 183 | 52.7% | +0.001651 |
| `no_varcluster_and_gq15` | 115 | 45 | **71.9%** | +0.001452 |
| `gq_ge_20` | 187 | 212 | 46.9% | +0.001119 |
| AF 類規則 | - | - | < 30% | 全為負 delta |

**Combined 規則（Caller + Methyl，含 non-FN 甲基數據）：**

| 規則 | TP+ | FP+ | Rescue Precision | F1 delta |
|------|-----|-----|-----------------|---------|
| `gq15_and_allele_delta_low` | 431 | 473 | 47.7% | **+0.002702** |
| `gq15_and_pairwise_ge_015` | 340 | 448 | 43.2% | +0.001471 |
| `gq_ge_20`（caller only 基準） | 187 | 212 | 46.9% | +0.001119 |
| `gq15_and_not_noise` | 259 | 357 | 42.1% | +0.000984 |
| `gq15_and_strong_or_subclone` | 132 | 224 | 37.1% | +0.000128 |
| `class_strong_or_subclone`（甲基唯一） | 259 | 1181 | 18.0% | -0.006265 |
| `pairwise_ge_020`（甲基唯一） | 450 | 1612 | 21.8% | **-0.006968** |

**關鍵發現：**
1. **甲基唯一規則全部有負效益**：`pairwise_ge_020` 和 `class_strong_or_subclone` 大量引入 FP（因 Pool B non-FN 也含 germline 變異，有強烈 HP 甲基訊號）
2. **甲基補充 Caller 的增益極小**：最佳 Combined 規則（+0.002702）僅略優於最佳 Caller-only 規則（+0.002316），差距僅 +0.000386
3. **Caller-only `no_varcluster` 仍是最佳 F1 delta 規則**（+0.003391）
4. **`no_varcluster_and_gq15` 是最乾淨的救援**（TP+115, FP+45, precision=71.9%）
5. **`lowqual_only_gq15` 救回 0 個**：純 LowQual Filter 的 FN 全部 GQ < 15，無法用 GQ>=15 過濾

## 結論與後續行動

### 已確認結論

1. **Pool B FN 數量充足（840 個）**：ClairS 確實過濾了大量 truth TP，值得深入研究
2. **GQ 是主要區分特徵**：Pool B FN 的 GQ 中位數（16）顯著高於 non-FN（6），有 caller-side rescue 空間
3. **VariantCluster 是關鍵區分訊號**：FN 中 VariantCluster 比例（49%）遠低於 non-FN（85%），排除 VariantCluster 能大幅提升 rescue precision
4. **甲基覆蓋率 0%**：需補跑 InterSubMod 策略 B 才能評估 Caller+Methyl 聯合規則
5. **AF 規則全為負效益**：不應用 AF 條件做 Pool B rescue（Pool B 中 AF 高的 FP 也很多）
6. **最佳 Caller-only 規則**：`no_varcluster_and_gq15`（TP+115, FP+45, precision=71.9%, F1 delta=+0.001452）是最乾淨的純 caller 端救援規則

## 最終結論

### 核心發現

1. **Pool B FN 數量充足（840 個）**，是有意義的研究對象
2. **甲基化補充 Caller 的增益極小**：最佳 Combined 規則僅比最佳 Caller-only 規則好 +0.000386
3. **Pool B FN rescue 的主力仍是 Caller 端訊號**，特別是 `VariantCluster` 標籤
4. **甲基唯一規則完全無效**（germline/artifact 的 non-FN 也有強烈甲基訊號）
5. **`no_varcluster_and_gq15` 是最乾淨的實用救援規則**（precision=71.9%, F1 delta=+0.001452）
6. **結論與實驗 19 一致**：甲基訊號對 TP rescue 的貢獻受限，主要價值在 FP triage

### 與計劃預期的對比

| 項目 | 樂觀估計 | 保守估計 | 實際結果 |
|------|---------|---------|---------|
| Pool B FN 數量 | 200-500 個 | 30-100 個 | **840 個**（超預期） |
| 甲基訊號覆蓋率 | 60% | 20% | **99.9%**（遠超預期） |
| 甲基是否超越 GQ-alone | 可能 | 不太可能 | **不超越**（差距 +0.000386） |
| 最佳 F1 delta（combined）| +0.002~+0.005 | +0.0005~+0.001 | **+0.002702**（在合理範圍） |

### 後續行動建議

1. **不推薦將 Pool B Combined 規則升為正式方法**：增益太小、precision 未達 50%+ 實用標準
2. **`no_varcluster_and_gq15` 值得在 DORADO TO 上交叉驗證**（實驗 6）
3. **Pool A-light 無需再探索**：Pool B 已足夠大且結論清晰
4. **研究重點建議轉回 FP triage**：甲基訊號在 FP 識別（low VAF + high AlleleDelta）已有明確正效益
