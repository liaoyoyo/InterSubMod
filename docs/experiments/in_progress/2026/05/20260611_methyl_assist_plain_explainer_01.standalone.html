用 DNA 甲基化幫 read 認「哪條染色體」——三個問題的白話答案

把整件研究用一個比喻講到最清楚。單樣本 HCC1395 · 2026-06-11 · 詳細數字見 VERIFIED_RESULTS §V11b

0先看比喻

每條定序 read = 一張紙，是「從某一本書印出來的」。
你的基因組有兩本書：爸爸給的（HP1）、媽媽給的（HP2）。
腫瘤又在某一本書上手寫塗改了幾個字（= somatic 突變）→ 產生「塗改版分身」（HP1-1 / HP2-1）。
工具 longphase-S 的工作 = 看每張紙上的「字」（SNP）判斷它來自哪本書、哪個版本。

問題在哪：很多紙上的「字」不夠看 → 工具判不出來：

  • unphase（46%）= 看不出來自哪本書
  • HP3 = 看到塗改字、但認不出是哪本書的塗改版
  • HP1 / HP2 = 認出是哪本書，但那張紙剛好沒印到被塗改的字 → 不知道它是不是塗改版

我們的點子：每張紙上還有「浮水印」（= DNA 甲基化）。能不能用浮水印當額外線索，把上面三種判不出來的補判？

1最關鍵的一個事實（決定一切）

浮水印能分 「爸爸的書 vs 媽媽的書」（HP1 vs HP2）——這是真的，不是假象（先前 V10 用正常細胞對照證明過）。

但浮水印分不出 「同一本書的塗改版 vs 原版」（HP1-1 vs HP1）——因為塗改版和原版是同一本書，浮水印一樣。

這一句話直接決定了三個問題的成敗：問題的本質是「分不同的書」就成功，是「分同一本書內部」就失敗。

2三個問題的答案

問題本質浮水印幫得上？
T1 unphase → 哪本書？分爸/媽的書✅ 可以
T2 HP3 → 哪本書的塗改版？分爸/媽的書⚠ 只證一半
T3 plain HP1 → 是不是塗改版？分同一本書內部❌ 不行

T1 ✅ 救 unphase read（認哪本書）

在浮水印分得開的位置，把「假裝看不出來」的紙救回正確的書：誠實的全基因組正確率 88.5%。

但要老實標範圍：真正最需要救的 LOH 區（基因組失去一本書的地方），恰恰是浮水印和判斷工具都最弱的地方——那裡基本沒測到。所以「能救」目前只在「字夠多、浮水印分得開」的區域證實。

T2 ⚠ 把 HP3 歸到哪本書的塗改版（只證明了一半）

證明的一半：浮水印確實能分「爸的塗改版 vs 媽的塗改版」（還是在分爸/媽的書）→ 準確度 0.90。

沒證明的一半：真正的 HP3 read 能不能被正確歸位，沒驗到——因為 HP3 沒有「正確答案」可以對照；而且 90% 的 HP3 根本沒有任何 germline 線索（你點名的「沒經過任何 germline」），其中只有約 15-18% 連量都量不到。所以不能宣稱「HP3 可以救」，只能説「浮水印有分書的能力」。

T3 ❌ 認出偷偷的塗改版（你的核心構想）

你的想法（很合理）：塗改版的紙不管有沒有印到被改的字，浮水印應該一致，所以能間接把它認出來。

但前提是：塗改版的浮水印要跟原版不一樣，否則無從認起。

數據説：不一樣不了。用最嚴格的「同位置配對」檢定，塗改版 vs 原版的浮水印差異 = 純隨機雜訊的程度（p=0.924）；而同一個檢定下「爸的書 vs 媽的書」明顯有差（p 極小）→ 證明檢定有效、只是塗改版真的沒差。

原因就是第 1 節那句話：塗改版和原版是同一本書，浮水印相同。

3一句話總結

浮水印（甲基）是「哪一本書」的線索，不是「哪一個腫瘤塗改版」的線索。
所以它幫得上「分不同的書」（T1 救 unphase、T2 證明能分塗改版的來源書），
幫不上「分同一本書內部」（T3 認塗改版、以及 T2 真正歸位 HP3 那一步）。
