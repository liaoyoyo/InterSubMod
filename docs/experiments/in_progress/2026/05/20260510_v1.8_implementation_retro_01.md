### 4.1 第一次 regression 暴露 N1 false positive

- N1 paired_LOH cycle hypothesis 含 `"NOT confounded by stale binary or merged AF trap"` 與 `"HPFineNGroups subclone marker"`
- evaluator 純 keyword match 看不出否定句
- → P-08 (含 keyword "stale binary") + P-10 (含 keyword "HPFineNGroups") 雙誤觸
- → N1 base composite approve_tier，但因 1 個 component < 0.4 + override 規則升 downgrade_tier
- → **specificity 從 2/2 → 1/2 (False positive!)**

### 4.2 Retune 策略

把廣域 keyword 改更精準（要求出現具體 stale/literal-interpretation 描述 token，而非單字）：

| pitfall | 原 keyword（廣域） | retune 後（精準） |
|---|---|---|
| P-08 KDE stale | "stale binary", "master_phase1", "master dataset" | "binary stale_distance", "post-KDE master regenerate", "downstream stale binary detected", "binary version lag", "KDE fix not propagated" |

### 4.3 第二次 regression 全通過

retune 後：

## §8 給未來自己的 Heads-up（v1.8 補）

16. **Pitfalls keyword 必須過 negative control regression**：純 keyword OR match 對否定句敏感（如 "NOT confounded by X" 仍會 match X）。新加 pitfall 必須過 N1+N2 跑一次再 commit
17. **`disk_guard.sh` flag 預設在 $HOME**：避免 /big7_disk owner 不對權限拒絕；hook 讀同 path
18. **`tmpdir_guard.sh` 不能 set -e**（會 abort 來源呼叫者）；用 return / exit 條件分支
19. **plot_setup.py 不該 raise**：font 找不到只 warn；否則破壞所有下游 plot script
20. **OSF 4 段是 schema additive**：既有 cycle plan.json 不會 retroactive validate fail；但新 cycle 必填
21. **DECLARE 是 cognitive forcing 不是 evidence**：PMID 24423999 警示 CFS 對新手 randomized trial 不顯效；不可取代 L4 多軌證據鏈
22. **OSF schema fields 是 optional 不是 required**：避免破壞既有 cycle；但 research-loop Quality Checklist 第 9 項要求齊全；交付前 self-check
23. **Edit tool 顯示 success ≠ 內容進檔**：批次 Edit 多檔後（特別是同 anchor pattern 跨檔）必須 `grep -c` verify；single-file 場景較少出問題，多檔批次必驗（v1.8 T1-2 第一次 Edit 兩個 launcher 顯示 success 但實際未寫）
