ISM 輔助 tag — 質疑與改進分析

6 個獨立對抗式批判者各攻一個方法支柱 · 主 agent 親自重算驗證關鍵發現 · 2026-05-31 · 這是觀察漏斗文件的 critique companion

紅隊讓核心 NEGATIVE 更穩、更誠實——多條獨立證據都指向「somatic 不特殊」：FN（caller 漏掉的真 somatic）比 TP 更聚類、germline-het null 的 strong 率（0.55%）高於 TP（0.34%）、somatic median ARI 遠低於 imprinted 尺。但它拆穿了 5 個被高估的「正面特徵化」子 claim（172 rare、anti-discriminative 5×、HP-axis 乾淨、ahl 排除 VAF、5 個候選），並留下 3 條真 open（chr16 單點、深覆蓋 AUC climb、5mC/5hmC 未分離）。

這份文件把刀遞給你：每個方法被獨立批判者攻過，我再親自重算最關鍵的數字。每條質疑標一個裁決——它是「已封閉」、「成立但只削弱子 claim」、「成立且反而強化核心」、還是「真 open」。

已封閉 現有證據已紮實答覆，結論安全 削弱子claim 質疑成立，要改某個口徑（不動核心） 強化核心 質疑成立，反而讓 NEGATIVE 更穩 真OPEN 尚未處理，需新分析/數據

1. 怎麼質疑這份結論 — 5 個鏡頭

要打一個 NEGATIVE，這 5 個角度最有殺傷力。後面每條質疑都歸到其中一個：

校正方法依賴：換個多重檢定校正（Bonferroni→FDR）結論會不會翻？「rare」是真稀少還是被過嚴門檻製造的？
區域 hotspot 主導：headline 的 OR/富集是不是被少數染色體（chr8 LOH）撐起來的？leave-one-chromosome-out 後還在嗎？
設計違反自身假設：方法的 docstring 說「只在 X 條件成立」，實際跑的資料有多少違反了 X？
confound 未排除：VAF / coverage / group-imbalance 這些已知 confound，宣稱排除了但真的排了嗎（重算 Spearman）？
單樣本 + 小 n + placeholder：n=1 樣本、FP n=26、AF 是 placeholder——這些讓哪些 claim 撐不住？

核心 NEGATIVE（somatic ASM/clustering 非 somatic-特異）不變——以上全是「正面特徵化」層的精度修正，且 negctrl2 + FN-clustering 兩條反而強化核心。

5. 真正還沒解決（3 條 open）

  1. chr16:34707014 單點（VAF 0.66, balanced 25/48, MAPQ60, blind_allele 0.945 / blind_hp 0.165）：ALT/REF 甲基分裂正交於 phasing。從 JSON 無法分辨「真 somatic-ASM」vs「germline phasing 失敗」。→ 須 BAM/phase-block 人眼核。L3
  2. H5 AUC 在深覆蓋（>200×）爬到 0.605：若不是 n_fp=8 的小樣本噪音，可能代表「高覆蓋下 ASM 對 TP 有微弱判別力」——與整體 NEGATIVE 不完全一致。→ 須 full-sample logistic 測 coverage×|Δβ| 趨勢。L2
  3. 5mC vs 5hmC 未分離：max-collapse 可能遮蓋 5hmC-specific 等位訊號（5hmC 在癌症有獨立角色）。→ 對 26 strong 位點分跑兩修飾。L2

7. 我自己最擔心的 3 個弱點

  1. null 不穩：兩個 germline-het null 互相矛盾（negctrl=0% vs negctrl2=0.55%），n 都小（243 / 1,091）。整個「somatic ≤ baseline」的比較站在一個搖晃的 baseline 上。在做 genome-wide matched null 之前，「強化核心」的那兩條（negctrl2>TP）我只給 L2 不給 L1。
  2. AF placeholder 污染所有機制敘事：pipeline VCF 的 AF/DP/AD 全是常數（AF=0.2）。所以凡是引用「低 VAF / allelic imbalance / copy-ratio」的機制（FP-strong、chr8 hotspot、TO FP）都是 asserted 非 measured。要把這些從 mechanism 降為 hypothesis，直到從 BAM 算真 VAF。
  3. 我可能仍在「為 NEGATIVE 辯護」：H5 深覆蓋 AUC 爬到 0.605 這條，我傾向歸因小樣本噪音（n_fp=8）。但這正是 confirmation bias 會做的事。誠實做法是跑 full-sample logistic 讓數據說話，而不是我先判它是噪音。
