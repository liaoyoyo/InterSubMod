2.外推驗證怎麼做的（方法，供你檢核合理性）

難題：unphase read 沒有標準答案。解法 = 用 germline VCF 的 PS phase-block 當獨立 ground truth（HCC1395 是 cell line 無 trio）：

  1. 在一個大 PS block（如 chr21 最大 block 有 2435 個 het SNP）內，用 germline het 給每條 read 定真 HP（ground truth）。
  2. read 隨機分 train / test 兩半。
  3. test read 完全遮住其 germline 證據（當作 unphase），只給甲基。
  4. 用 train read 甲基建 HP1/HP2 質心 → test read 用甲基距離預測 HP → 對照真 HP。
  5. 對照：打亂 train 標籤 → null accuracy（應掉回 ~0.5）。
為何這是真外推：predictor 從別的 read 學、被預測 read 自己沒有 germline 證據——正是真 unphase read 的處境。比前一輪 anchor leave-one-out（read 自帶證據）嚴格。

3.各染色體救援率（一致性）

救援能力跨染色體一致（多數 acc_median 0.76-0.97，null 全在 0.5 附近）。少數低（chr3 僅 1 窗、chr4 0.62）反映區段特異或小樣本，不影響整體結論。

4.LOH 異常深究：分得開的 LOH 多半是純 LOH（推翻猜測）

前一輪發現 chr8/15/22 的 LOH「反而分得開」，我猜是 cnLOH+copy gain（兩拷貝可有不同甲基）。本輪 intersect SEQC2 cnLOH 細分類驗證：

推翻我的猜測（真數據糾正）：分得開的 LOH 中 76% 是純 LOH（不是 GAINLOH）。所以「chr8/15/22 LOH 分得開」不能用「cnLOH+gain 有兩拷貝」解釋。純 LOH 理論上一條 haplotype 丟失、該分不開，卻分得開 — 這是更深的異常，可能來源：(1) LOH 不完整（殘留少量另一 haplotype）、(2) subclone 異質性、(3) SEQC2 LOH 邊界不精準、(4) 甲基本身的細胞間異質性（非 haplotype）。需 IGV 個案 + 邊界檢視才能定（下一步）。

5.全基因組速度

外推驗證全 22 染色體跑完（速度已解）：外推腳本每條 30-63 秒，12 平行全部完成（chr3 僅 1 窗因該染色體大 PS block 少）。
但 v2 SEQC2 分析的大染色體仍未解：SEQC2 per-region 分析每區 ~8 秒（read fetch + MM/ML 解析），chr1-6 等大染色體 het 多、候選多，全平行互搶 CPU 仍 timeout。根治需「預載整條染色體甲基索引一次、各 region 查表」（未實作）。目前 SEQC2 結論為 7 小染色體 pilot。

7.限制與下一步

  • 外推 caveat：仍是「假裝 unphase」（held-out 有 germline 證據被遮，真 unphase read 甲基覆蓋可能更差）；單樣本 HCC1395；11% 窗失效（哪類待查）。
  • LOH 異常未定性：純 LOH 為何分得開需 IGV + SEQC2 LOH 邊界檢視。
  • SEQC2 大染色體速度：需預載甲基索引才能全基因組。
