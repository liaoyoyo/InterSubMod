0 · 一句話結論

HP/allele 群內外的甲基差異 「不是 copy」獲得決定性證明： copy-clean 二倍體 normal 的分離度 ≥ tumor（整體 0.979 vs 0.866，6/6 染色體 normal 更高）， 且 tumor 的 copy 事件（gain/LOH）反而降低分離度 —— 與「copy artifact」假說完全相反。

但一個誠實修正：絕對 AUC（tumor ~0.87 / normal ~0.98）含方法樂觀成分 （normal 全基因組 ~0.98 不可能全是真 ASM）。誠實 effect size 應引相對 null 的超出量 （real vs shuffle：tumor 0.87 vs 0.67、normal 0.98 vs 0.79）+ V6 救援 88.5%（null 52.4%）， 而非膨脹的絕對 AUC。訊號是真的、且非 copy；只是「強度數字」要用相對量。

1 · 問題與驗證設計

問題（用戶）：read 以 tag 分群、群內外明顯的甲基差異，是 copy（CNV/LOH）造成的假象， 還是 phase tagging 正確判斷的真 haplotype 甲基差異？如何驗證？

最乾淨的驗證 = matched normal 對照。 用單 SNP REF-vs-ALT allele 標籤 （在每個 germline het SNP，把 read 依該位鹼基分兩群算甲基 AUC；不靠 longphase HP tag、不需跨 SNP 相位 → tumor / normal 完全對等且互相獨立）。

判準邏輯：normal HCC1395BL 是二倍體、無 somatic CNV/LOH（copy-clean）。 若甲基分離由 copy 造成 → normal（無 copy 變異）應分不開； 若 normal 也分得開 → 與 copy 無關。normal 同時提供「無 copy、多數非 ASM」的生物學 null。

3 · 三圖證據

4 · 每條證據的意義

  1. ① copy 被決定性排除：normal 二倍體、無 CNV/LOH，分離度卻 ≥ tumor（6/6 染色體）。更關鍵——tumor 的 copy 事件反而把分離度拉低（LOH 0.782 最低、sig 只剩 0.49）。copy 不是製造訊號，是破壞訊號（與 V5「LOH 反而分不開」一致）。
  2. ② 非深度/read 數假象：depth-matched（兩群降等量 read）≈ 未配對（tumor 0.859 vs 0.866；normal 0.982 vs 0.979）→ 排除 known-pitfall P-06。
  3. ③ 是真 haplotype-linked 甲基訊號、copy-independent：在 copy-clean normal 同樣強烈存在 → 此分離是「germline haplotype 的甲基相關性」（同分子 allele 與局部甲基在 cis 連動），在乾淨二倍體最強、被 tumor copy 混亂削弱。正是 V6 救援 88.5% 的根基。
  4. ④ imprinting 正控過關：已知 imprinted DMR GNAS 強雙峰（一 allele 甲基 0.87 / 另一 0.39，Δβ=0.49，~50:50，n=464）→ 方法確實能撈到真正的 allele-specific methylation。

5 · 誠實修正：絕對 AUC 含方法樂觀

normal 二倍體不可能在全基因組 ~90% 的 het 位點都有真 ASM（文獻 ASM 只佔少數位點）。 leave-one-out 質心 AUC + 對稱化 max(auc,1−auc) 會膨脹（真 shuffle null 已是 0.67–0.79，非 0.5）。

因此誠實的 effect size 不是絕對 0.87–0.98，而是「相對 null 的超出量」：

  • real 顯著超 shuffle：tumor 0.87 vs 0.67、normal 0.98 vs 0.79（label-dependent，shuffle 後掉回）；
  • V6 PS-block held-out 救援 88.5%（null 52.4%） — 操作層的真實救援正確率。

→ 訊號是真的、且非 copy；只是「強度數字」要用相對量，對外引用不用膨脹的絕對 AUC。

淨結論：這條 confound 排除對主線是好消息且更穩 —— 救援用的甲基-haplotype 訊號被證明是真實、copy-independent 的 germline 現象， 而非腫瘤 copy 造成的假象。
