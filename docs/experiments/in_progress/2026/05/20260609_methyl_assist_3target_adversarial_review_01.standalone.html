每個挑戰用「不只看 AUC、加正確 null / 正控 / matched 檢定」嚴格重測（腳本 rigor_t1.py/rigor_t2.py/rigor_t3.py），再交 4-agent workflow 對抗審查（3 審查員各專攻一 target 找破綻 + 1 綜整長）。

多 agent 審查品質：3 個審查員獨立從 per-chr 原始 JSON 重現了所有 load-bearing 反駁（T3 matched p=0.924 / T2 H3 無 AUC / T1 train-test 無循環）。我再第三次獨立重現確認（§13.7 不信 subagent 回報而不驗證）：T3 matched median −0.0043 p=0.9237、正控 +0.0425 p=1.77e-49、T2 可指派率 15-18%。審查抓到我 V11 初版 T2 OVERSTATED + T3 framing 錯，已修正。

我先前的錯（已撤）：中途報的「亞群 Δβ 0.110 − 噪音 0.088 = +0.022 部分支持你」是 unmatched-window artifact——把「亞群在亞群窗的 Δβ」拿去比「噪音池化全窗」。同窗配對（亞群窗的噪音其實 0.0997）後，超出量歸 ~0（p=0.924）。多 agent 審查抓到並獨立重現。
為何亞群沒有獨特甲基（機制）：亞群與母本是同一 germline haplotype，共享該 haplotype 的甲基；亞群的定義特徵是 somatic 突變，不是甲基。V10 證明的 tumor-acquired ASM 發生在 H1 vs H2 層級（clonal，所有 H1 細胞含亞群共享），不是亞群特異。
誠實 caveat（站你這邊）：random-split null 可能吸收被分割的微弱亞群訊號 → 本結論排除的是「可用來校正的 within-haplotype 甲基訊號」，不是「亞群層 ASM 完全不存在」。要救 T3 需更強/正交訊號（讓 read 直接覆蓋 somatic 位點、或 long-range linkage），甲基此弱數據做不到。

6 · 共通風險 + 機制天花板（5 條，多 agent 綜整）

  1. 單樣本 + 單一 pipeline self-reference：全線 HCC1395 longphase-S；被矯正的 HP tag 本身是 longphase-S 產物（T2/T3 自我參照）→ tier 硬上限 ⭐2-3。
  2. 真值 vs 生產目標錯配：強數字都在有真值的 read 上量（T1 masked-phaseable / T2 1-1vs2-1），外推到無真值母體（真 unphase / H3）。T2 做了未支持的 leap（blocking）；T1 誠實 hedge（可接受）。
  3. 母體偏 easy case：T1 98.75% CN-gain；高價值 LOH/imprinting 區恰是雜合度/anchor 流失、機制衰退處。
  4. 循環 metric 家族：centroid-LOO pat_auc 把 random-split 噪音膨脹到 0.86 → headline 須用 held-out / matched / null-referenced，不可用 raw centroid-LOO AUC。
  5. 機制天花板（一致）：甲基是 germline-haplotype 層級（V10 copy-independent，normal 0.979 > tumor 0.866）→ 分不同 haplotype 強(T1/T2)、within-haplotype 弱/無(T3)。同一 cis-甲基強度在 LOH/subclone 目標預測失敗 → T1/T2 正面結果不外推到激發此研究的救援情境。
對研究主線的淨意義：可寫進論文的是 方法學 characterization — 「甲基攜帶 germline-haplotype 資訊（T1 救 unphase 在 germline-rich 區可行 0.885；T2 證明分支可分 0.90），但 read-level 弱數據無法解析 within-haplotype 的 subclone（T3）或無真值的 H3 實際歸屬」。非 variant filter（已 DEAD）；正負雙結果都誠實可報。
