2.研究問題

paired phasing 工具 longphase-S 把近半 read 標成 unphase（無相位）。核心問題：能否用每條 read 的甲基化模式，把這些 unphase read 分到正確的 haplotype（HP1/HP2）？

  • 成功 metric = phasing rescue accuracy（被救 read 與真 HP 一致率）+ 對 LOH-phasing 活軸增益。
  • 🔴 紅線：不回頭包裝成 variant TP/FP F1（那是已 concluded 死路）。

3.研究方法（驗證邏輯，供你檢核合理性）

核心難題：unphase read 沒有真 HP（ground truth）可比對。解法 = 用「有 germline SNP、已知真 HP」的 anchor read 做 leave-one-out 驗證：

  1. 取一個 het 區，抽所有 read 的 per-CpG 5mC（pysam 解 MM/ML）+ HP tag。
  2. 只用已知 HP1/HP2 的 anchor read，遮住其 HP 標籤，僅憑甲基模式預測它屬 HP1 還 HP2。
  3. 用 ROC AUC 量化「甲基預測 HP 的準確度」（leave-one-out 質心距離）。
  4. 控制 1（shuffle）✓ 已做：打亂 HP 標籤重算 → 若 AUC 掉，證明訊號是真 label-dependent。
  5. 控制 2（CpG-SNP）待跑：剔除 het C/T SNP 改變的 CpG → 排除假 ASM。
這套方法只能驗證 anchor read（有真 HP）；unphase read 的可救性靠「anchor 驗證 + 外推」推論，外推性本身是限制（見 §8、§10）。

✅ 訊號是真的（label-dependent），不是純方法 leak：95% 的區 real AUC 顯著超過自己打亂標籤的 p95（純 leak 只會 ~5% 假陽率）。甲基確實在絕大多數 het 區帶 haplotype 資訊。
⚠ 但兩個修正：(1) 絕對值 0.974/0.866 是膨脹的，因對稱化 max(auc,1-auc) 把真 null 從 0.5 拉到 0.577；誠實 effect size = 「real 超 shuffle p95 中位數 +0.260」。(2) shuffle 抓不到 CpG-SNP pseudo-ASM（het C/T SNP 改變 CpG 的確定性假關聯，與真標籤相關，shuffle 後也掉）— 文獻列為頭號嫌疑，尚未排除。

8.研究結論（誠實的中途狀態）

問題結論證據強度
全基因組有多少 unphase？45.84%（1382 萬 read），機會空間大P 原始可信（守恆 PASS）
甲基能否帶 haplotype 訊號？能，真的，95% het 區顯著P-caveat（shuffle 證真，但絕對值膨脹）
甲基能否救 unphase read？仍未證實未定（3 個未解問題，見下）

「能否救 unphase」仍未證的三個原因：

  1. CpG-SNP pseudo-ASM 未排除（最大嫌疑）：het C/T SNP 直接改 CpG → 假 ASM 可能撐起那 95%。
  2. 外推性未證：驗證用的 40 區是「≥10 HP1+≥10 HP2 anchor + CpG 充足」篩出的（111 取 40）；unphase read 恰住在不滿足這條件的稀疏區，anchor 結論能否外推到 unphase 未知。
  3. 仍有 2/40 區無訊號：非全有。
絕不誇大：目前能說的只有「甲基在有 anchor 的 het 區帶真 haplotype 訊號」。不能說「甲基能救 unphase」——那需要 CpG-SNP 排除 + 外推驗證。這是負責任的中途定位。
