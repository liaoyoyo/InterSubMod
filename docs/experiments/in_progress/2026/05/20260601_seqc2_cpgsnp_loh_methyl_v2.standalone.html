1.(a) CpG-SNP 排除控制：確認 95% 不是 pseudo-ASM artifact ✅

前一輪最大嫌疑：het C/T SNP 直接改變 CpG → 製造「確定性 allele→甲基」假關聯，可能撐起 95% 高 AUC。本輪剔除「被 het SNP 改變的 CpG 欄」重算 AUC，比對排除前後。

指標值（317 區去重）意義
AUC drop median0.0排除前後無變化
AUC drop mean0.0007平均幾乎 0
drop > 0.05 的區0.6%僅極少數受影響
tainted CpG 中位數0多數區無 het 落 CpG
Wilcoxon 排除前 vs 後p=0.36統計無顯著差異
(a) 結論：CpG-SNP pseudo-ASM 不是 95% 高 AUC 的成因。 het SNP 落在 CpG 上太稀少（中位 0 個），剔除它們對甲基分離無影響（drop=0, p=0.36）。→ 前一輪 95% 甲基帶 haplotype 訊號的結論通過此關鍵控制，最大嫌疑排除。

2.過程揭露：我發現並修正一個取樣 bug

誠實揭露：原始 v2 有重疊 window 重複計數問題。 每個 region 取 ±2kb window，但相鄰 het SNP 間距常 <4kb → window 重疊、共享同一批 read，等於同一證據被算多次。最嚴重：chr22 有 8 個 LOH window 擠在 16,508,969–16,511,702（僅 2.7kb），全部 (n_hp1,n_hp2)≈(19,15) = 同批 read 算 8 次。

修正：去重疊（同 chr 內貪婪保留間距≥4kb），421 區 → 317 區。本頁所有數字均為去重後真值。loss 受影響最大（17→3 區，故 loss 結論信心低）。核心結論（a 不變、c LOH 染色體特異不變）在去重後依然成立。

(c) 結論：LOH 區甲基可分性不是 LOH 普遍性質，而是染色體/區段特異。 理論上 LOH（一條 haplotype 丟失）甲基該分不開 — chr5/6 符合（0.6）。但 chr8/15/22 卻分得開（0.8-0.97），且 chr8 兩次獨立跑重現（0.80/0.81，非偶然）。本輪 7 條染色體去重後 LOH vs neutral 無差異（p=0.96），與前輪 chr5/6/7（p=0.0019）相反 — 證實此現象高度依賴看哪些染色體。chr8/15/22 的「分得開 LOH」是真正值得深究的異常。

5.(b) 全基因組進度（部分完成）

速度仍是瓶頸，全基因組未完成。 已優化（pysam in-process depth + 向量化 AUC + 22 平行吃 80% 資源），但大染色體 het SNP 太多（chr1 幾萬個），每區 per-read 甲基解析 ~8 秒，22 條同時平行互搶 CPU → chr1-6/9-14/17-19 在 90 分鐘 timeout 仍未完成。目前 7 條小染色體（chr7/8/15/16/20/21/22）完成。 全基因組需進一步優化（如預載 MM/ML、減 K、或分批而非全平行）。本頁結論為 7 染色體 pilot 級。

7.限制與下一步

  • partial scope：僅 7 小染色體；大染色體速度瓶頸未解（全基因組待優化）。
  • loss n=3（去重後）：信心低，HCC1395 本就少 loss。
  • LOH 異常未深究：chr8/15/22 分得開的 LOH 為何分得開（cnLOH? subclone? allelic imbalance?）需對照 SEQC2 cnLOH 細分 + IGV。
  • 下一步建議：(a) 深究 LOH 異常個案（IGV + SEQC2 cnLOH 細分）/ (b) 解全基因組速度瓶頸 / (c) 回主線寫 unphase 救援原型 / (d) 先停讓你檢視。
