ISM 輔助 tag — 甲基 × haplotype × somatic 觀察推論漏斗

InterSubMod · HCC1395 paired_full（單樣本）+ TO 對比 · 2026-05-29 → 05-31 · 供方法步驟與圖片真實性驗證

ISM 機器能正確量測每個 somatic 位點的甲基化結構，但「somatic 事件驅動 ASM／子克隆甲基化聚集」這個科學主張不成立。從 39,447 個 SEQC2 高信度 somatic TP 出發，經 5 道篩選只剩 172（0.34%）達 strong-ASM，且它們無方向性、在 FP 反而富集 5×、median ARI 系統性低於已驗證的真-ASM 尺（imprinted 0.758）。BRCA2 等個別位點確有真實強 cluster，但反映突變落在本就有該甲基狀態的等位（germline allelic Layer A），非 somatic 驅動。

0. 怎麼讀這份文件

整份調查問一個問題：把 tumor 的 read 按 haplotype 分群後，能不能找到「受 somatic 事件影響、且明顯內聚」的甲基化子分群？要回答，必須把訊號拆成 3 層、用兩個獨立方法（B1 平均、B2 聚類）× 兩個軸（HP、ALLELE）測，並先做一把能偵測真 cluster、拒絕假 cluster 的尺，才能分辨「NEGATIVE 是真生物」還是「方法看不到」。

第 2 節是核心：從全部樣本的數字開始，逐級展示用哪個方法篩掉多少、保留多少、保留下來的有什麼現象。其餘各節是每一級的細節與不同情況（TP / FP / FN / het / imprinting / LOH / TO）的並排觀察。

1. 目標 + 3 層訊號框架

分群定義（非循環） L1：longphase-to-mod 用 HP tag 分 reads。HP1-1（HP:i:11）= phase 到 germline HP1 且攜帶 somatic ALT allele 的 read；HP1 = 同 haplotype 但不帶 somatic 變異。親讀源碼 HaplotagProcess.cpp:512-722 確認分群只用 SNV/INDEL allele，不用甲基化，故「用甲基化找甲基化差異」不構成循環論證。

兩個軸：HP-axis（HP1 vs HP1-1，同 germline haplotype、只差 somatic 變異 → somatic-controlled，乾淨）；ALLELE-axis（ALT vs REF reads → 會被 baseline 等位甲基化 confound）。下方漏斗兩軸都列，但只有 HP-axis 能支撐 somatic-特異主張。

文獻前提 L2：甲基化是癌症 established driver，但「甲基-突變相關」機制多為 trans（IDH/EZH2/DNMT3A 等修飾酶突變 + 拷貝數 → 全域甲基化），非 cis（somatic SNV 自身 read 的甲基化）。本調查正是測 cis 軸 — 結果與文獻「cis 罕見」一致。

  • 無方向性：hypo 76 / hyper 96（44.2% hypo）— 沒有「somatic 一致去甲基化或加甲基化」的方向 dominance。

3. B1 平均檢定的最終讀法 — NEGATIVE

漏斗看似在 p<0.05 有「TP > null」的訊號，但這是門檻 artifact：

L1 effect 隨 coverage 下降（Spearman ρ=−0.245，p≈0）= noise-driven artifact 的簽名。B1 結論：somatic 的平均 ASM 位移不高於任意 germline-het 位點的 baseline。 germline-het null 用同一條 pipeline 跑（n≈1,334 records；243 + 1,091 兩批）作為「真實生物 baseline」對照，不是理論值。

5. 分群品質「尺」— 先驗尺，再用尺

B2（read-level 聚類）若只用肉眼看「有沒有分群」會自欺。所以先設計一把 red-team 硬化的尺，主判準 = M1 blind-ARI（盲分群 k=2 能否重新發現 somatic/germline split，最難造假），輔以 M0 observed-only（禁 imputation）/ M8 placebo-collider / M2 het-null / M5-M6 artifact 簽名。用尺前先證明尺有效（meta-validation）：

尺 VALIDATED：能偵測真 cluster、拒絕假 cluster、在真 imprinting 上 ARI≈1.0。所以後續 somatic NEGATIVE 是真生物（somatic 真的沒有 broad ASM 聚集），不是尺鈍掉。 這是整份調查最關鍵的方法學保證。
