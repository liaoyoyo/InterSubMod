0 · 一句話結論

甲基能輔助跨不同 haplotype 的 tag：T1 unphase→H1/H2 held-out 92.6%、 T2 H3→H1-1/H2-1 分支 AUC 0.90； 但無法解析同一 haplotype 內的亞群：T3「沒踩 somatic 位點的 H1 是否其實是 H1-1」AUC 0.65（低於 null 0.71）。

機制（一致）：甲基訊號是 germline-haplotype 層級（V10 已證 H1 vs H2 真實且非 copy）。 所以分「不同 haplotype」強（T1、T2），分「同 haplotype 內亞群 vs 母本」弱（T3）—— 亞群與母本共享同一 germline haplotype 甲基，tumor-acquired ASM 不足以製造強 subclone-特異 epiallele。

5 · 機制：為何 T1/T2 行、T3 不行

  1. 甲基訊號是 germline-haplotype 層級（V10 決定性對照已證：HP1 vs HP2 甲基差異真實、copy-independent、在 copy-clean normal 同樣存在）。
  2. T1（unphase→H1/H2）：分的是不同 germline haplotype（H1 vs H2）→ 訊號強 → 92.6%。
  3. T2（H3→H1-1/H2-1）：H1-1 與 H2-1 分屬不同 germline haplotype 分支（H1-branch vs H2-branch）→ 等同分 H1 vs H2 → AUC 0.90。
  4. T3（1-1 vs 1）：亞群與母本是同一 germline haplotype，共享同樣的 haplotype 甲基。唯一可能的差別是 subclone-特異的 tumor-acquired ASM —— 但數據顯示這個 subclone 層級訊號太弱（AUC 0.65 連自己的 shuffle null 都沒過）→ 甲基此弱數據不足以拆 plain H1 是否亞群。
T3 是你最 novel 的構想，誠實結論是 NEGATIVE。 不是「亞群完全無 ASM」，而是「亞群層級的甲基差異 ≪ haplotype 層級」，弱到甲基無法可靠區分。要拆 plain H1 是否亞群，需更強訊號（如直接讓 read 覆蓋 somatic 位點，或其他正交證據），甲基幫不上。

6 · 對 tooling / 研究主線的意義

面向結論
可落地的甲基 tooling✅ T1 unphase 救援（92.6%、79% 高信心 yield）+ T2 H3 分支歸屬（0.90）= 兩個 haplotype 層級的真實 assist
不可行的方向❌ T3 subclone 解析—— 甲基無法拆 plain H1 是否亞群；勿據此宣稱可矯正未踩 somatic 位點的 read
與 V10 一致三 target 的成敗完全由「是否分不同 haplotype」決定 → 印證 V10「甲基=germline-haplotype 層級訊號」
誠信邊界不是 variant TP/FP filter（已 concluded DEAD）；這是 haplotagging assist（不同目標，允許）
淨結論：甲基當「弱數據」確實能輔助 longphase-S 的兩類 haplotype 層級 tag 矯正（unphase 救援、H3 分支歸屬），但不能做 subclone 層級解析。這是清楚、可寫進論文 tooling 章節的正負雙結果。
