methylation × haplotype × somatic 完整調查

InterSubMod · HCC1395 paired_full（單樣本）· 2026-05-29 → 05-30 · 供方法步驟驗證

ISM 機器能正確「量測」somatic 位點的甲基化結構，但「somatic 事件驅動 ASM / 子克隆甲基化聚集」這個科學主張不成立 —— 用兩個獨立新方法（平均檢定 B1 + read-level 聚類 B2，後者配一把已驗證的分群品質尺）測，somatic 位點的 ASM/clustering 都不高於任意 germline-het 位點的 baseline allelic 甲基化。BRCA2 等個別位點有真實強 cluster，但反映 pre-existing 等位甲基化（突變落在本就有該甲基狀態的 allele），非 somatic 驅動。

這份報告組織整個調查的方法、步驟、細節、結果供驗證。每個 claim 標證據等級 L1 親測 L2 推導 L3 推測。

1. 目標 + 3 層框架

目標：在 tumor 裡，read 按 haplotype 分群後，找出受 somatic 事件影響的甲基化子分群與狀態（observe→discover→verify→analyze→output）。關鍵在把訊號拆成 3 層：

文獻前提 L2：甲基化是癌症 established driver（ASM/aDMR 於 RET/CDKN2A；TSG 啟動子沉默）。但「甲基-突變相關」機制多為 trans（IDH/EZH2/DNMT3A 等表觀修飾酶突變 + 拷貝數 → 全域甲基化），非 cis（somatic SNV 自身 read 的甲基化）。read-level 聚類偵測子族群有業界工具（cvlr、NanoMethPhase）。

2. 方法與步驟（pipeline）

分群定義 L1：longphase-to-mod 用 HP:Z tag 分 reads。HP1-1（HP:i:11）= phase 到 germline HP1 且攜帶 somatic ALT allele 的 read；HP1 = 不帶 somatic 變異。親讀源碼 HaplotagProcess.cpp:512-722 確認分群只用 SNV/INDEL allele，不用甲基化 → 非循環。
甲基化抽取 L1：MSA C++（REF-anchored CpG）→ Level1 per-read per-CpG。BAM 是 5mCG_5hmCG，每 CpG 發 5mC + 5hmC 兩列 → max-collapse 成 any-modification beta。
雙軸 ASM L1：HP-axis（HP1 vs HP1-1，somatic-controlled）+ ALLELE-axis（ALT vs REF reads）。per-CpG Wilcoxon paired（B1）。
B2 read-level clustering L1：read×CpG 矩陣 → read-read Hamming 距離（observed-only，禁 imputation）→ PERMANOVA + 盲分群 ARI + dispersion。
對照 L1：germline-het null（baseline Layer A）+ n_reads-match + placebo-anchor（collider）+ TP/FP/FN 分類。

規模：全 39,447 SEQC2 high-conf TP 重跑 → 51,171 dual-axis records（含 LOH 20,564）；germline-het null n≈1,670；B2 廣掃 TP/FP/FN/het 各 ~45 隨機位點。
