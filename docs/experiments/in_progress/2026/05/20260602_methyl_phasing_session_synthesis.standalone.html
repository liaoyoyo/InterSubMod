用一句話講整個研究：longphase-S 把近半 read 標成 unphase（沒相位），我們想用「甲基模式」把它們救回正確 haplotype；先證明「甲基確實能分 HP」（過了所有 confound 控制），但「能否真的救 unphase」還沒驗證完，因為 unphase read 本身沒有標準答案可比對。

1.研究了什麼問題

背景：paired phasing 工具 longphase-S（HCC1395 tumor-normal）把很大一部分 read 標成 unphase（無 HP tag） 或 HP3（卡住的 somatic read）。這些 read 「不知道屬於哪條染色體單倍型」。

核心假設：每條 read 自帶 CpG 甲基化模式；同一單倍型的 read 甲基模式應較相似 → 能否用甲基把 unphase read 分到正確 HP1/HP2？

成功定義（鎖死）：phasing rescue accuracy（救回的 read 與真 HP 一致率）。🔴 紅線：不回頭包裝成 variant TP/FP F1（那是已 concluded 死路）。

類別count%

守恆 PASS（各類和=total 30,149,552）。意涵：unphase 是巨大機會空間（1382 萬 read）；HP3 在 paired 模式極稀，救援主力是 unphase。

4.觀察 2：甲基確實能把 read 分到正確 haplotype 方法存疑→已驗

方法：用「有 germline SNP、已知真 HP」的 anchor read，遮住標籤、只憑甲基預測 → ROC AUC。

方法學發現：imprinting DMR（H19/SNRPN）germline SNP 稀疏 → 無雙 HP anchor 可驗（chicken-egg：最想驗的區偏偏沒 ground truth）。

5.觀察 3：連過 3 道對抗控制，排除 3 大假象 ★

「甲基能分 HP」這個發現，連續通過三個試圖推翻它的控制：

控制擔心的假象真實結果結論
shuffle-label方法 leak（AUC 與真標籤無關仍高）95% 區 real 超 shuffle p95；真 null median 0.577✅ 訊號 label-dependent
CN-confound（SEQC2）倍體 gain 放大假分離CN vs AUC rho=0.035 p=0.71；gain≈neutral p=0.70✅ 非倍體 artifact
CpG-SNP 排除het C/T SNP 改 CpG 製造假 ASM排除後 AUC drop median=0.0, Wilcoxon p=0.36✅ 非序列 artifact
觀察 3 結論：甲基帶 haplotype 訊號是穩固的真發現，不是任何已知 confound 造成的假象。但 ⚠ 絕對 AUC（0.866/0.974）被對稱化膨脹（真 null=0.577 非 0.5），誠實 effect size 用「超 shuffle p95 median +0.260」。

6.觀察 4：倍體用 coverage 就能讀，甲基非必要

倍體與 coverage 幾乎完美對應 → 要讀倍體用 coverage 即可，甲基不攜帶額外倍體資訊（呼應觀察 3 的 CN 無相關）。但 gain 區甲基較常雙峰（53.6% vs neutral 21.4%）→ 多拷貝區甲基較複雜，重指派時須 paralog/mappability 過濾。

7.觀察 5：LOH 可分性是染色體特異的（副產品發現）★

理論：LOH（一條 haplotype 丟失、兩條同源）甲基該分不開 — chr5/6 符合（0.6）。但 chr8/15/22 卻分得開（0.8-0.97），chr8 兩次獨立跑重現（非偶然）。→ LOH 可分性不是 LOH 普遍性質，而是區段特異。chr8/15/22「分得開的 LOH」是值得深究的異常（疑 cnLOH 疊加 subclone / allelic imbalance），如 chr8:87663325 的 HP1/HP2=96/17 極不平衡。
