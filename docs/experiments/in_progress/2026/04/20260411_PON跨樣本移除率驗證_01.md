# PON 跨樣本 FP 移除率驗證

## 結論

**PON 移除率跨 7 樣本穩定，定性結論「PON 是最強 filter」穩固。**

- Raw VCF-level PON rate: **95.16% - 98.81%**（mean 97.77%, SD 1.12%）
- Refined FP-level PON rate: **98.44% - 100%+**（所有樣本 > 98%）
- 穩定度：3 → **4**（跨樣本驗證通過）

## 方法

對 7 個樣本的 ClairS-TO raw SNV VCF（`snv.vcf.gz`）統計 FILTER 欄位分布：
- `NonSomatic`：PON databases 命中（gnomAD + dbSNP + 1000G + CoLoRSdb）
- `PASS`：somatic candidates 通過所有 caller filters
- `LowQual;*`（不含 NonSomatic）：caller quality filters 移除

## 關鍵觀察

### H2009 異常

- PON rate 95.16%（最低），PASS/Total 4.46%（最高，其他 0.94-1.99%）
- 原因：H2009 truth_total = 168,529（7 樣本中最高），是肺癌細胞株，突變負荷高
- 更多 somatic variants 逃逸 PON（因 AF 接近 germline frequency 或 PON 覆蓋不足）
- **但 refined PON_FP_Rate 仍 ~100%**，說明 H2009 的低 PON rate 是因為有更多 true somatic variants，不是 PON 失效

### HCC1954 特殊性

- TO ISM FP rate 74.6%（最高）但 PON rate 97.75%（正常範圍）
- 說明 HCC1954 的高 FP rate 不是 PON 問題，而是 caller 層面的 FP

### 論文影響

- 原始單樣本數據「99.48%」可修改為：「7 樣本 refined PON_FP_Rate 98.44-100%，mean > 99%」
- 定性結論不變：PON databases 是 TO pipeline 最強的 FP 移除機制
