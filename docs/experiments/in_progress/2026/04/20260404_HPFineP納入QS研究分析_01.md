# HPFineP 納入 Quality Score — 研究分析與觀察報告

## 1. 現有 TO 模式 QS 解剖

### 1.1 TO QS 組件與個別 AUC

目前 TO mode 的 `get_tumor_only_weights()` 設定 `loh_penalty=0` 和 `verify_bonus=0`，有效組件僅剩：

| 組件 | 觸發率 | TP 觸發 | FP 觸發 | 個別 AUC |
|------|--------|---------|---------|----------|
| read_penalty (nr<50) | 28.2% | 25.6% | 44.7% | **0.602** |
| cov_penalty (anomaly) | 45.2% | 42.6% | 61.8% | **0.612** |
| cpg_penalty (cpg<30) | 0.6% | 0.6% | 0.4% | 0.499 |
| effect_bonus (V≥0.2) | 5.7% | 6.2% | 2.3% | 0.519 |
| loh_penalty | 0% | — | — | (disabled) |
| verify_bonus | 0% | — | — | (disabled) |

**結論**：TO QS 幾乎完全由 read count 和 coverage anomaly 驅動（AUC 0.60-0.61），缺乏 haplotype 信號。

### 1.2 TO QS AUC = 0.624

QS 值分布高度離散（大部分區域集中在 75 和 100），區分能力有限。

## 2. HPFineP 整合形式探索

### 2.1 五種候選形式

| 形式 | 描述 | 觀察 |
|------|------|------|
| **A: Binary** | HPFineSig (p<0.05) | All ratio=1.75; LOH ratio=**3.00**; non-LOH ratio=1.08 |
| **B: NGroups** | HPFineNGroups 分級 | NGroups≤1 ratio=**0.39** (FP 嚴重富集) |
| **C: Continuous** | -log10(HPFineP) | AUC=0.667, 但不如分段式 |
| **D: LOH-conditional** | LOH + HPFineSig | ratio=**3.20** (最高) |
| **E: Interaction** | HPFineSig × NGroups | sig + NGroups≥2: ratio=1.75 |

### 2.2 關鍵觀察

**觀察 O1: LOH 條件下 HPFineSig 的區分力是全域的 3 倍**
- All HPFineSig: ratio = 1.75
- LOH HPFineSig: ratio = **3.00**
- non-LOH HPFineSig: ratio = 1.08（幾乎無區分力）

**觀察 O2: NGroups≤1 是強 FP 指標**
- NGroups≤1: TP=17.9% vs FP=**45.5%** → ratio=0.39
- 含義：HP Fine 僅有 0-1 個 group 時，幾乎一半是 FP
- 原因：FP 區域的 somatic variant 不存在 → reads 無法形成多 HP group

**觀察 O3: NGroups=2 是 TP 富集的最佳標記**
- NGroups=2: TP=56.8% vs FP=32.2%（1.76× enrichment）
- NGroups=2 內，sig rate: TP=67.1% vs FP=47.7%

**觀察 O4: NGroups=3 的 sig 幾乎沒有區分力**
- NGroups=3 sig rate: TP=76.0% vs FP=78.6%（FP 略高！）
- 原因：3-group 通常出現在 normal reads 混入的複雜場景

## 3. QS 整合方案模擬

### 3.1 方案比較

| 方案 | 參數 | AUC | Δ AUC | 備註 |
|------|------|-----|-------|------|
| Baseline | — | 0.6238 | — | 現有 TO QS |
| Scheme 1 | LOH+HPFineSig bonus=15 | 0.6457 | +0.022 | 只加 bonus |
| Scheme 2 | NGroups≤1 penalty=15 | 0.6549 | +0.031 | 只加 penalty |
| **Scheme 3** | **bonus=15, penalty=15** | **0.6715** | **+0.048** | **推薦方案** |
| Scheme 3 | bonus=25, penalty=25 | 0.6779 | +0.054 | 過擬合風險 |
| Scheme 5 | LOH cont. scale=7 + pen=15 | 0.6739 | +0.050 | 連續版，略好但複雜 |

### 3.2 參數掃描熱圖

```
bonus↓ pen→   pen= 0  pen= 5  pen=10  pen=15  pen=20  pen=25
  bon= 0      0.6238  0.6452  0.6484  0.6549  0.6590  0.6619
  bon= 5      0.6325  0.6501  0.6555  0.6603  0.6640  0.6667
  bon=10      0.6368  0.6566  0.6603  0.6648  0.6682  0.6689
  bon=15      0.6457  0.6640  0.6673  0.6715  0.6729  0.6741
  bon=20      0.6484  0.6676  0.6707  0.6729  0.6748  0.6758
  bon=25      0.6525  0.6718  0.6729  0.6755  0.6773  0.6779
```

**觀察 O5**：penalty 的 AUC 貢獻 > bonus。penalty=15 alone 給 +0.031，bonus=15 alone 給 +0.022。

### 3.3 推薦方案：Scheme 3 (bonus=15, penalty=15)

**選擇理由**：
- AUC 0.6715（Δ+0.048），相比 baseline 0.6238 提升 **7.7%**
- 15/15→25/25 marginal gain 僅 +0.006（不值得冒過擬合風險）
- Chromosome-level stability: mean=0.689 ± 0.083（baseline: 0.643 ± 0.080）
- 15 分的 bonus/penalty 在 QS 的 0-100 scale 上是合理幅度

## 4. 推薦方案細部分析

### 4.1 Score 變化分布

| 變化方向 | 數量 | TP | FP |
|---------|------|-----|-----|
| 改善（score 提升） | 4,570 | 4,312 (94.4%) | 258 (5.6%) |
| 惡化（score 下降） | 7,658 | 5,463 (71.3%) | 2,195 (28.7%) |
| 不變 | 23,070 | — | — |

### 4.2 Bonus 受益者

- 觸發條件：LOH **且** HPFineSig
- 總數：12,062（TP=11,493, FP=569）
- **TP 率 95.3%** — bonus 幾乎只惠及 TP

### 4.3 Penalty 受害者

- 觸發條件：HPFineNGroups ≤ 1
- 總數：7,658（TP=5,463, FP=2,195）
- FP 率 28.7% — penalty 懲罰的群體中 FP 比例比全域（13.7%）高 2.1 倍
- **TP 也會被連帶懲罰**（71.3%），但這些 TP 本身缺乏 HP 信號，QS 分數降低是合理的

### 4.4 Tier 分布變化

**關鍵改善**：FP High% 從 79.4% → 64.3%（-15.1pp），TP High% 從 91.2% → 86.9%（-4.3pp）。

### 4.5 LOH 子類型 AUC

## 5. 關鍵副作用與風險

### 5.1 ⚠️ Paired 模式方向完全相反

| 指標 | TO ratio | Paired ratio | 方向 |
|------|----------|-------------|------|
| LOH + HPFineSig | 3.20 (TP>FP) | **0.80** (FP>TP) | **相反** |
| NGroups≤1 | 0.39 (FP>TP) | **1.25** (TP>FP) | **相反** |

**Paired 模式套用同樣 bonus/penalty → AUC 下降 -0.014**

**原因**：
- Paired: FP germline variants 被正確 phased → HPFine 偵測到真實 germline ASM → FP 更容易 sig
- Paired: TP somatic variants 在正常 phasing 下可能破壞 HP 結構 → NGroups 較低
- TO: 方向相反因為 FP 沒有真正的 somatic 影響

### 5.2 安全措施

**必須將 HPFine bonus/penalty 僅寫入 `get_tumor_only_weights()`，不觸碰 `get_paired_weights()`。**

### 5.3 過擬合風險

- 僅在 HCC1395 5kHz 單一樣本上驗證
- Chromosome-level stability check: std=0.083（與 baseline std=0.080 接近）
- 保守選擇 15/15 而非 25/25 是正確的

### 5.4 TP 被 penalty 連帶懲罰

- NGroups≤1 penalty 會懲罰 5,463 個 TP（17.9%）
- 這些 TP 本身就缺乏 haplotype 信號（只有 0-1 個 HP group）
- QS 降低反映了「證據不足」，不是「判定為 FP」
- 這些 TP 在後續分析中本來就缺乏解釋力

## 6. 實作建議

### 6.1 修改 `get_tumor_only_weights()`

新增兩個欄位到 `QualityScoreWeights`：
- `hp_fine_loh_bonus = 15.0f` — LOH + HPFineSig → +15
- `hp_fine_no_group_penalty = 15.0f` — NGroups≤1 → -15

Paired 保持 0.0f（不啟用）。

### 6.2 修改 `compute_quality_score()`

新增兩個參數：`bool hp_fine_sig`, `int hp_fine_n_groups`

```cpp
// HPFine LOH bonus (TO-only)
if (potential_loh && hp_fine_sig) {
    score += weights.hp_fine_loh_bonus;
}

// HPFine no-group penalty (TO-only)
if (hp_fine_n_groups <= 1) {
    score -= weights.hp_fine_no_group_penalty;
}
```

### 6.3 不觸碰的部分

- `get_paired_weights()` — 不改動
- 現有的 read/cpg/cov/effect 組件 — 不改動
- Quality Tier 門檻 — 不改動
