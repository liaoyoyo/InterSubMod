# VCF 來源錯誤矯正報告

## 1. 問題描述

### 1.1 錯誤

ISM 的「TO 模式」分析使用了**錯誤的 VCF 來源**：

| 項目 | 錯誤（實際使用） | 正確（應該使用） |
|------|----------------|----------------|
| **Caller** | ClairS v0.4.1 (Paired pileup) | ClairS-TO v0.3.0 |
| **VCF source** | `##source=ClairS` | `##source=ClairS-TO` |
| **Normal BAM** | ✅ 使用（過濾 germline） | ❌ 無（TO 模式） |
| **TP** | 30,490 | 28,396 |
| **FP** | 4,842 | **11,843** |
| **FP 率** | 13.7% | **29.4%** |

### 1.2 原因

ISM VCF 路徑設定為 symlink：
```
data/vcf/HCC1395/pileup/ → ClairS_ssrs/.../pileup/
```
目錄名稱 `pileup` 是 ClairS **paired** mode 的 pileup sub-module，不是 ClairS-TO。

### 1.3 ISM Log 確認

```
Somatic VCF: /big8_disk/liaoyoyo2001/InterSubMod/data/vcf/HCC1395/pileup/filtered_snv_tp.vcf.gz
```

VCF header: `##source=ClairS` + `NAF`/`NDP`/`NAD` 欄位（Normal BAM 資訊）= 確認為 paired mode。

## 2. 位點重疊盤點

### 2.1 交叉比對矩陣

|  | ClairS-TO TP | ClairS-TO FP | 不在 ClairS-TO 中 |
|--|-------------|-------------|------------------|
| **ISM TP (30,476)** | 28,274 (92.8%) | **0** | 2,202 |
| **ISM FP (4,822)** | **0** | 196 (4.1%) | 4,626 |
| **不在 ISM 中** | 122 | **11,647** | — |

### 2.2 關鍵數字

| 指標 | 數值 | 意義 |
|------|------|------|
| **標籤污染** | **0** | ISM TP 與 TO FP 零重疊 → 過去 AUC 不受 mislabel 影響 |
| **TP 覆蓋率** | 99.6% (28,274/28,396) | TP 側幾乎完整 |
| **FP 覆蓋率** | **1.7%** (196/11,843) | ⚠️ **98.3% TO FP 無 ISM 資料** |
| **Paired-only 位點** | 6,828 | 在 TO 場景下不相關 |
| **TO-specific 缺失** | 11,769 | 需要新跑 ISM |

### 2.3 根因

Paired caller 和 TO caller 的 FP 幾乎完全不同：
- **Paired FP** (4,842): mapping/calling artifacts（germline 已被 Normal BAM 過濾）
- **TO FP** (11,843): 主要是 **germline variants 被誤判為 somatic**（無 Normal 對照）

兩者重疊僅 196 個位點 = 真正的 non-germline artifacts。

## 4. 結論風險評估

### 4.1 可能方向反轉（🔴 最高風險）

| 結論 | 原風險 | 原因 |
|------|--------|------|
| **NGroups≤1 是 FP 指標** | ratio=0.39 | 新增 germline FP 有真正 HP groups → NGroups 分布右移 → 指標可能失效 |
| **LOH+HPFineSig ratio=3.00** | bonus 依據 | 新增 germline FP 有真正 ASM → HPFineSig 觸發率上升 → ratio 下降 |
| **Scheme 3 AUC +0.048** | 實作依據 | 上述兩個支柱受衝擊 → 改善可能大幅縮水或消失 |

### 4.2 數字改變但方向保留（🟡）

| 結論 | 說明 |
|------|------|
| LOH_Strong/Weak AUC > 0.88 | AUC 可能下降但仍 > 0.5；覆蓋率可能更低 |
| AlleleDelta FP > TP | 新增 germline FP 有更明確的 ASM → 方向更強化 |
| F1 改善很小 | Baseline F1 降低（0.927→0.804），改善空間更大但覆蓋率可能更低 |
| NOT ACTIONABLE 判定 | 結構性限制（覆蓋率、過擬合）不因 FP 數量改變 |

### 4.3 完全不受影響（🟢）

| 結論 | 說明 |
|------|------|
| AlleleDelta 定義（ALT vs REF，非 HP） | 程式碼邏輯 |
| ISM 自算 LOH（不讀 LOH.bed） | 程式碼邏輯 |
| Selection bias（HP_Ratio 選子群 + HP 特徵） | 方法學分析 |
| AF confound 是主要驅動力 | 因果推理，新增 FP 更強化 |
| TO/Paired 必須分離 | 架構決策 |
| Paired mode 的所有分析結果 | 使用正確 VCF |
| 多層 HP 測試邏輯正確性 | 程式碼不變 |

## 6. 防止再犯

### 6.1 VCF 來源驗證檢查清單

每次 ISM 運行前必須確認：
1. `grep "##source=" VCF` → 確認是 ClairS-TO 而非 ClairS
2. VCF 中是否有 `NAF`/`NDP` 欄位 → 有 = paired（錯誤）
3. ISM log 中的 `Somatic VCF:` 路徑是否指向正確目錄
4. TP+FP 數量是否與 `variant_counts.txt` 一致

### 6.2 建議改善

- ISM 啟動時自動檢查 VCF header 的 `##source` 欄位
- 如果是 TO 模式但 VCF 來自 ClairS（非 ClairS-TO），發出警告
- 在 ISM log 中記錄 VCF source 和版本
