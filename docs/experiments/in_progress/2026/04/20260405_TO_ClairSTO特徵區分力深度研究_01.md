# TO ClairS-TO 特徵區分力深度研究報告

## 1. Executive Summary

**測試內容**：針對 ISM 在 Tumor-Only (TO) 模式下的 32 個連續 + 6 個布林特徵，在 5 個分層（All / LOH / Non-LOH / LOH_Strong / LOH_Weak）中的 TP/FP 區分力，並比較兩種 haplotagging 版本（longphase-to baseline vs PON-only v2b）。

**最高信賴結論**：

1. **HP2FamilyN LOH_Weak AUC 0.72 大部分是循環依賴 artifact**。去混淆後 All LOH AUC 僅 0.54，全量 AUC 0.53。
2. **RF 多特徵組合 CV AUC 上限 0.69-0.77**（依分層），比最佳單特徵高 +0.03~0.10。LOH 子分層信號最強（LOH_Weak RF AUC=0.75-0.77），但 Non-LOH 上限僅 0.64。
3. **Baseline haplotagging 在 LOH 內區分力等於或優於 PON-only v2b**，但 v2b 擴展了 LOH 覆蓋率（72.6% vs 58.7%）。
4. **所有甲基化距離特徵（PairwiseMeanDist, CramersV 等）在所有分層中 AUC ≈ 0.50**，完全無區分力。
5. **AlleleSig 在 Non-LOH 方向反轉**（FP>TP），因為 germline heterozygous variants 擁有天然 ASM。

**決策變更**：TO 模式 ISM 的 FP filtering 即使用 ML 組合也僅能達到中等效力（AUC 0.69-0.77），且主要依賴結構特徵（read counts、HP ratio）而非甲基化信號。研究方向應轉向「ISM 特徵在 ML caller 中作輔助特徵」而非「ISM 獨立 FP filter」。

## 3. Setup and Evaluation Protocol

### 3.1 數據集

| 版本 | Haplotagging | BAM | ISM 輸出 | TP | FP | LOH% |
|------|-------------|-----|---------|----|----|------|
| **PON-only v2b** | longphase-to PON-only v2b | `output/pononly_v2b/tumor_tagged.bam` | `ism_pononly_v2b_clairsto_{tp,fp}/` | 28,383 | 11,830 | **72.6%** |
| **Baseline** | longphase-to baseline | `output/baseline/tumor_tagged.bam` | `ism_baseline_clairsto_{tp,fp}/` | 28,383 | 11,830 | **58.7%** |

- 兩版都使用正確的 ClairS-TO VCF（`##source=ClairS-TO`）
- 樣本：HCC1395 100% purity
- VCF 來源：`filtered_snv_{tp,fp}.vcf.gz`
- ISM 參數：window=5000, BERNOULLI, min-mapq=20, methyl-low=0.2, methyl-high=0.8

### 3.2 分析方法

| 問題 | 方法 | 指標 |
|------|------|------|
| Q1: NGroups 完整性 | Chi-squared + per-bin Fisher + per-chr 穩定性 | NGroups≤1 FP/TP ratio, AUC + 95% CI |
| Q2: LOH_Weak 去混淆 | 3 層 AUC (LOH_Weak → All LOH → All) + threshold scan | Deconfounded AUC, TP loss/FP removal |
| Q3: 反轉特徵 | 全特徵×5 分層 AUC 矩陣 + bootstrap CI | AUC<0.48 計數, per-chr 穩定性 |
| Q4: Boolean 特徵 | Rate analysis + joint 2×2 + filter simulation | TP loss %, FP removal % |
| Q5: AlleleDelta | Zero-inflation + minor HP stratification | Per-bin AUC, zero% |
| Q6: 特徵組合 | GroupShuffleSplit (chromosome), 5 folds, 80/20 | CV AUC ± std |

### 3.3 Q6 特徵分層

| Tier | 特徵 | 用途限制 |
|------|------|---------|
| **Tier 1**（安全） | PairwiseMeanDist, CramersV, NumReads, NumCpGs, HeuristicScore, Coverage_Multiple, NHP0, NHP3 | 無 |
| **Tier 2**（層內安全） | HPFineP, HPFineNGroups, AlleleDelta, AlleleP, HPMergedDelta | 不可跨 LOH/Non-LOH |
| **Tier 3**（定義層特徵） | HP_Ratio, HP1FamilyN, HP2FamilyN | 循環依賴，CV 內可用 |

## 4. Main Findings

### 4.1 關鍵數據總覽

| 指標 | PON-only v2b | Baseline | 差異 |
|------|-------------|----------|------|
| LOH 佔比 | 72.6% | 58.7% | v2b +13.9pp |
| QS AUC | 0.507 | 0.507 | 相同（隨機） |
| Best single AUC (All) | HPFineP 0.588 | HPFineP 0.580 | v2b +0.008 |
| Best single AUC (LOH) | HPFineP 0.615 | HPFineP 0.661 | **baseline +0.046** |
| Best combo CV AUC (All) | RF 0.689 | RF 0.691 | 相同 |
| Best combo CV AUC (LOH) | RF 0.712 | **RF 0.736** | **baseline +0.024** |
| Best combo CV AUC (LOH_Weak) | RF 0.746 | **RF 0.773** | **baseline +0.027** |

### 4.2 最重要的發現

**發現 1: HP2FamilyN 0.72 是循環依賴 artifact（Q2）**

| 去混淆層級 | PON-only v2b | Baseline |
|-----------|-------------|----------|
| Test A: LOH_Weak only | 0.721 | 0.686 |
| Test B: All LOH | **0.540** | **0.517** |
| Test C: All data | **0.530** | **0.532** |

AUC 從 0.72 驟降至 0.54。HP2FamilyN 的高 AUC 來自 LOH_Weak 定義本身（HP_Ratio 極端 → Potential_LOH → LOH_Subtype），不是獨立的區分信號。

**發現 2: RF 組合 CV AUC 0.69-0.77 是真實的 AUC ceiling（Q6）**

| 分層 | Best Single | RF Tier123 (CV) | Δ |
|------|------------|-----------------|---|
| All | 0.588 | **0.689** | +0.101 |
| LOH | 0.615 | **0.712** | +0.097 |
| Non-LOH | 0.584 | **0.640** | +0.056 |
| LOH_Strong | 0.646 | **0.720** | +0.074 |
| LOH_Weak | 0.721* | **0.746** | +0.025 |

*LOH_Weak best single 有循環依賴。Combo 的 +0.025 是在已膨脹基線上的增量。

**發現 3: Baseline haplotagging 在 LOH 內更好（Q6）**

| 分層 | v2b RF | Baseline RF | Δ |
|------|--------|-------------|---|
| LOH | 0.712 | **0.736** | +0.024 |
| LOH_Strong | 0.720 | **0.724** | +0.004 |
| LOH_Weak | 0.746 | **0.773** | +0.027 |
| Non-LOH | **0.640** | 0.635 | -0.005 |

原因：v2b 將 LOH 從 58.7% 擴展到 72.6%，增加的邊界 LOH 區域混入更多難以區分的 FP，稀釋了信號。

**發現 4: 甲基化距離特徵完全無效**

PairwiseMeanDist, CramersV, HPMergedDelta, PairwiseMedianDist 在所有 5 個分層中 AUC = 0.49-0.52。Germline FP 的甲基化距離模式與 somatic TP 完全相同。

**發現 5: AlleleSig Non-LOH 方向反轉（Q3/Q4）**

| 分層 | TP AlleleSig rate | FP AlleleSig rate | 方向 |
|------|-------------------|-------------------|------|
| LOH | 0.515 | 0.369 | TP>FP ✓ |
| Non-LOH | 0.614 | **0.678** | **FP>TP** ✗ |

Non-LOH FP (germline heterozygous) 有天然 allele-specific methylation (ASM)，導致 AlleleSig 反向觸發。

## 5. Statistical Validation

### 5.1 Q1 穩健性

- Chi-squared p < 1e-200（兩版皆是）：NGroups 分布 TP/FP 差異統計顯著
- Per-chromosome ratio range [0.98, 2.95]：無單一染色體主導（最大染色體 <10%）
- 但 HPFineNGroups AUC 僅 0.56-0.58（翻轉後），實際區分力弱

### 5.2 Q2 去混淆嚴格性

三層設計清楚顯示 HP2FamilyN 從 LOH_Weak (0.72) → All LOH (0.54) → All (0.53) 的 AUC 崩塌。這不是 power loss（LOH 有 29,191 rows），而是真正的循環依賴 artifact。

### 5.3 Q5 Zero-inflation

| 分層 | TP AlleleDelta=0% | FP AlleleDelta=0% |
|------|-------------------|-------------------|
| LOH (v2b) | 22.0% | **46.8%** |
| LOH (baseline) | 26.5% | **61.4%** |
| Non-LOH | ~1% | ~1.5% |

LOH 內 FP 有顯著更高的 zero-inflation（Baseline 更明顯），支持 FP germline variant 在 LOH 區域缺乏 allele-specific methylation 差異。

### 5.4 Q6 交叉驗證穩定性

- GroupShuffleSplit by chromosome 確保無 data leakage
- 5 folds，std 通常 0.01-0.03：結果穩定
- RF Tier123 consistently > LR Tier12 > LR individual trios

### 5.5 證據弱點

- 單一樣本（HCC1395 100% purity）
- LOH_Strong sample size 較小（v2b: 6,109, baseline: 4,273）
- LOH_Weak threshold scan 方向相反（低 HP2FamilyN → TP removal），使實際 filter 不可用
- RF 的 train/test AUC gap 未報告（但 CV 架構已控制過擬合）

## 6. Figure-by-Figure Interpretation

### Q1-Fig1: NGroups Distribution (LOH vs Non-LOH)
- **目的**：驗證 NGroups TP/FP 分布差異是否真實。
- **觀察**：LOH 中 NGroups=1 的 FP 顯著多於 TP（v2b: 40.8% vs 23.2%），NGroups=2 的 TP 顯著多於 FP（67.6% vs 50.7%）。Non-LOH 差異小但方向一致。
- **支持結論**：NGroups 差異真實（p<1e-200），但效果量小（Cramér's V=0.18-0.24）。
- **決策意涵**：NGroups 可作 ML 輸入特徵但不可做硬閾值 filter。

### Q1-Fig2: Per-Chromosome NGroups≤1 Ratio
- **目的**：排除單一染色體驅動 bias。
- **觀察**：22 個染色體 ratio range [0.98, 2.95]，大多在 1.2-2.5 之間，無極端 outlier。
- **支持結論**：NGroups 差異是全基因組性的，非特定染色體 artifact。

### Q2-Fig2: HP2FamilyN Distribution + 3-Level ROC
- **目的**：量化循環依賴對 HP2FamilyN AUC 的膨脹。
- **觀察**：ROC 從 LOH_Weak (AUC 0.72) 急劇降至 All LOH (AUC 0.54)。Test B 和 Test C 幾乎重疊在隨機線附近。
- **支持結論**：**HP2FamilyN 的區分力 73% 來自循環依賴**（0.72→0.54 的 drop = 0.18 out of 0.22 above random）。
- **決策意涵**：HP2FamilyN 不可作為獨立 FP filter。在 ML 模型中作為連續特徵仍可使用（CV 架構控制 leakage）。

### Q2-Fig3: Threshold Scan
- **目的**：測試 HP2FamilyN 硬閾值 filter 的實用性。
- **觀察**：**所有閾值的 TP loss 遠大於 FP removal**（e.g., thr<1: TP_loss=42.6% vs FP_removal=7.4%）。Filter 方向錯誤。
- **支持結論**：HP2FamilyN 硬閾值 filter 在 LOH_Weak 中不可用 — 低值 correlate with TP（somatic LOH 的 minor haplotype genuinely 少）。
- **決策意涵**：完全排除 HP2FamilyN 閾值 filter 路線。

### Q3-Fig1: Directional AUC Heatmap
- **目的**：全景觀察所有特徵×分層的方向性。
- **觀察**：LOH 分層中大量紅色（FP>TP 反轉），尤其 LabelAllelePermanovaP (0.38)、HPFineP (0.39)、AlleleP (0.40)。Non-LOH 幾乎全部在 0.47-0.53（灰色，無信號）。
- **支持結論**：LOH 內有雙向信號（某些特徵 TP>FP，某些 FP>TP），但 Non-LOH 完全是隨機的。
- **決策意涵**：任何 TO FP filter 策略都必須限定在 LOH 區域內。

### Q4-Fig1: Boolean Significance Features
- **目的**：比較 HPFineSig / AlleleSig 在不同分層的 TP/FP rate 差距。
- **觀察**：HPFineSig TP>FP 在 LOH 中一致（Δ=+5-18pp），但 AlleleSig 在 Non-LOH 反轉（FP>TP by 6.3pp）。Baseline 的 Δ 比 v2b 更大。
- **支持結論**：HPFineSig 是 LOH 內唯一有效的 boolean filter，但 TP loss 過高（14.7-51.1%）無法實用。
- **決策意涵**：Boolean filter 策略在 2% TP loss 限制下不可用。

### Q5-Fig1: AlleleDelta Distribution
- **目的**：揭示 LOH 與 Non-LOH 中 AlleleDelta 的不同行為。
- **觀察**：LOH 有大量 zero-spike（FP >> TP），Non-LOH 幾乎無 zero-spike 且 FP > TP（反轉）。
- **支持結論**：LOH FP germline 的 AlleleDelta=0 是因為 germline variant 在缺失的 haplotype 上 → 無 allele-specific methylation。Non-LOH FP germline het 有天然 ASM → AlleleDelta 更大。
- **決策意涵**：AlleleDelta 的方向在 LOH/Non-LOH 之間完全相反，不可用於全局 filter。

### Q5-Fig2: Minor HP Stratified AUC
- **目的**：測試 AlleleDelta 是否在特定 read count 條件下有用。
- **觀察**：僅在 minor HP count = 0-2 時 AUC > 0.55（v2b 0.584, baseline 0.617），其他 bin 全部 <0.50（反轉）。
- **支持結論**：AlleleDelta 的有效信號僅來自 LOH 區域中 minor haplotype 極少 reads 的情況（本質上是 HP2FamilyN 的 proxy）。

### Q6-Fig2: Model Comparison
- **目的**：評估組合特徵的 CV AUC ceiling。
- **觀察**：RF Tier123 在所有分層中最佳（0.64-0.77）。LR Tier12 接近但稍低。Statistical trio 和 Structural trio 各有優勢分層。
- **支持結論**：16 特徵 RF 是 AUC ceiling（0.69-0.77），進一步增加特徵的邊際收益有限。
- **決策意涵**：0.69-0.77 是 ISM 特徵在 TO 下的能力上限。要超過這個上限需要 ISM 以外的信號。

### Q6-Fig4: LOH_Strong Decision Tree
- **目的**：產生可解釋的 LOH_Strong 分類規則。
- **觀察**：
  - v2b: HP_Ratio 是根分裂（≤0.97），所有葉節點預測 TP（AUC 0.72 但無 FP 葉）。
  - Baseline: AlleleDelta > 0.16 AND HPFineP > 0.10 AND HeuristicScore ≤ 21.88 → FP（唯一 FP 葉）。
- **支持結論**：即使是最佳可解釋模型也無法在 LOH_Strong 中可靠地分離 FP，大多數路徑預測 TP（因 TP>>FP in data, 3.3:1 ratio）。
- **決策意涵**：Class imbalance 是根本挑戰，需 cost-sensitive 方法或 undersampling。

### Q6-Fig6: AUC Ceiling Summary
- **目的**：一張圖總結全部 AUC ceiling。
- **觀察**：Combo 比 Single 在每個分層都有改善，但改善幅度在 LOH_Weak 最小（因 single 已有循環依賴膨脹）。
- **決策意涵**：最終 AUC ceiling: All 0.69, LOH 0.71-0.74, Non-LOH 0.64, LOH_Weak 0.75-0.77。

## 7. Failure Cases / Negative Results / Limitations

### 7.1 完全失敗

| 項目 | 結果 | 原因 |
|------|------|------|
| **甲基化距離特徵** | AUC 0.49-0.52 全分層 | Germline FP 的甲基化模式與 somatic TP 完全相同 |
| **QS 框架** | AUC 0.507（隨機） | 設計假設（FP 缺乏生物信號）在 TO 下不成立 |
| **HP2FamilyN 硬閾值** | TP loss >> FP removal | Filter 方向錯誤（低值=TP in LOH） |
| **Non-LOH 全部特徵** | 最佳 AUC 0.584 | Germline het FP 與 somatic TP 在所有維度上相同 |

### 7.2 循環依賴

HP2FamilyN, HP_Ratio, HP1FamilyN 在 LOH_Weak/LOH_Strong 中的高 AUC 大部分來自循環依賴：
- HP_Ratio 定義 Potential_LOH
- Potential_LOH + VerificationClass → LOH_Subtype
- 在 LOH_Weak 內觀察 HP2FamilyN 等同於在 HP_Ratio 極端子集內觀察 HP counts → tautological

### 7.3 限制

1. **單一樣本（HCC1395 100% purity）**：高純度最大化 somatic signal，低純度樣本的 AUC 可能更低。
2. **Class imbalance**：LOH_Strong TP:FP = 3.3:1 ~ 4.5:1，影響 DT/RF 的 FP detection。
3. **RF train AUC vs CV AUC gap**：Fig3 ROC 是 train set（AUC 0.81-0.86），CV AUC 是 0.71-0.77，存在過擬合。
4. **特徵之間的高相關性**：HP1FamilyN-HP2FamilyN (r=0.70), HP_Ratio-Coverage_Multiple (r=0.45) 可能導致 LR 係數不穩定。

### 10.5 Haplotagging Impact Summary

| 指標 | PON-only v2b | Baseline | Winner |
|------|-------------|----------|--------|
| LOH Coverage | **72.6%** | 58.7% | v2b |
| LOH NGroups≤1 ratio | 1.75 | **1.91** | baseline (stronger signal) |
| HPFineP AUC (LOH) | 0.615 | **0.661** | baseline |
| AlleleDelta AUC (LOH) | 0.570 | **0.605** | baseline |
| RF CV AUC (LOH) | 0.712 | **0.736** | baseline |
| RF CV AUC (LOH_Weak) | 0.746 | **0.773** | baseline |
| RF CV AUC (All) | 0.689 | **0.691** | tie |
| RF CV AUC (Non-LOH) | **0.640** | 0.635 | tie |
| HPFineSig Δ (LOH_Strong) | +0.077 | **+0.177** | baseline (2.3× stronger) |

**結論**：PON-only v2b 的改進 haplotagging 擴展了 LOH 覆蓋率 +13.9pp，但新增的邊界 LOH 區域稀釋了特徵區分力。在所有 LOH 內指標上，baseline haplotagging 都等於或優於 v2b。v2b 的價值在於 coverage，不在於 discrimination。
