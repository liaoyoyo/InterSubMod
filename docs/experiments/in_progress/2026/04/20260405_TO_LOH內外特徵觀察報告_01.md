# ClairS-TO Correction / Round 1 / TO LOH 內外特徵觀察 / 2026-04-05

## 1. Executive Summary

用正確 ClairS-TO VCF 重跑 ISM 後，逐一特徵 × LOH/Non-LOH 分層檢查 TP vs FP 的區分能力。**核心結論**：

- **LOH 內有 3 個統計檢定特徵 AUC 達 0.60-0.62**（HPFineP、AlleleP、LabelAllelePermanovaP），其餘均 <0.58
- **Non-LOH 幾乎無任何有效特徵**（所有 AUC <0.585）
- **甲基化距離特徵（PairwiseMeanDist、HPMergedDelta、CramersV）在所有分層下均 ≈ 0.50**（無區分力）
- **LOH_Weak 子類中 HP read count 特徵 AUC 最高可達 0.72**（HP2FamilyN），但這是結構性特徵非甲基化信號
- **AlleleDelta 在 LOH 內 TP median=0.014 而 FP median=0.000** — germline FP 在 LOH 區域反而缺少 allele-specific methylation

**決策變化**：ISM 甲基化特徵在 TO 模式下無法區分 TP/FP。僅有的信號來自統計檢定 p-value（中等效力）和結構性 read count 特徵（LOH_Weak 限定）。

## 4. Main Findings

### 4.1 數值上特別的觀察

#### O1: LOH 內 HPFineP 中位數差異 18 倍（最大單一特徵差異）

```
LOH TP median = 0.025 (顯著)
LOH FP median = 0.454 (不顯著)
AUC = 0.615
```

**解讀**：TP somatic variants 在 LOH 區域產生真正的 HP fine 群組差異（因為 somatic allele 改變了甲基化模式），而 germline FP 的 HP fine 群組無系統性差異。HPFineP 是 LOH 內**最一致且可解釋的信號**。

#### O2: LOH 內 LabelAllelePermanovaP — 最高 AUC 但生物學限制

```
LOH TP median = 0.010 (顯著)
LOH FP median = 0.600 (不顯著)
AUC = 0.623（LOH 內所有特徵最高）
```

**解讀**：Allele-label PERMANOVA 測試 ALT vs REF reads 在距離矩陣中是否分離。TP 在 LOH 內 ALT reads 少但甲基化不同（somatic effect），FP 的 ALT/REF reads 甲基化相同（germline variant 無 epigenetic impact）。但 AUC 0.623 仍然不足以做有效 filter。

#### O3: AlleleDelta LOH 內 — TP > FP（方向與直覺一致但效力微弱）

```
LOH TP median = 0.014
LOH FP median = 0.000 (!)
AUC = 0.570
```

**注意**：FP median = 0.000 非常特殊。這意味著大量 LOH germline FP 的 ALT 和 REF reads 甲基化完全相同（因為 germline variant 不影響甲基化）。TP 有微小但非零的 AlleleDelta（somatic mutation 略微改變局部甲基化）。但 AUC 僅 0.570 — 重疊太多，無法實用。

#### O4: LOH_Weak 中 HP2FamilyN AUC = 0.721（唯一 >0.70 的單一特徵）

```
LOH_Weak TP: HP2FamilyN median ≈ 35
LOH_Weak FP: HP2FamilyN median ≈ 65
LOH_Weak HP_Ratio AUC = 0.711
```

**解讀**：LOH_Weak 的 FP 有極端偏向 HP2 的 read count（因為 germline variants 位於 LOH 缺失的 haplotype 上 → 大部分 reads 來自保留的 haplotype）。但這是**結構性特徵**（read count bias），不是甲基化信號。而且 LOH_Weak 僅佔全量的 20%。

#### O5: Non-LOH 全面無差異

```
Non-LOH 最佳特徵: HPFineNGroups AUC = 0.584
所有甲基化特徵: AUC 0.50-0.53
QS AUC = 0.503 (完全隨機)
```

**解讀**：在 Non-LOH 區域，TP 和 FP 的所有 ISM 特徵分布幾乎完全重疊。Germline FP 和 somatic TP 的甲基化景觀在非 LOH 區域不可區分。

### 4.2 常見特徵的觀察

#### O6: 甲基化距離特徵全面失效

| 特徵 | LOH AUC | Non-LOH AUC |
|------|---------|-------------|
| PairwiseMeanDist | 0.524 | 0.531 |
| PairwiseMedianDist | 0.524 | 0.530 |
| HPMergedDelta | 0.500 | 0.507 |
| CramersV | 0.507 | 0.506 |

所有甲基化距離特徵的 AUC 均在 0.50-0.53 之間。**結論**：read-pair 甲基化距離無法區分 TO TP 和 FP。

#### O7: Quality Score 在所有分層下失效

| 分層 | QS AUC |
|------|--------|
| All | 0.507 |
| LOH | 0.513 |
| Non-LOH | 0.503 |
| LOH_Strong | 0.538 |
| LOH_Weak | 0.604 |

僅 LOH_Weak 略有效（0.604），但這主要由 HP read count 間接驅動（因為 QS 計算包含 VerificationClass，而 VerificationClass 受 HP ratio 影響）。

#### O8: Boolean features — HPFineSig 是唯一有方向性差異的

| Feature | LOH Δ(TP−FP) | Non-LOH Δ(TP−FP) |
|---------|-------------|-------------------|
| **HPFineSig** | **+0.174** | +0.049 |
| AlleleSig | +0.147 | −0.063 (反轉!) |
| PassedGating | +0.013 | +0.013 |

HPFineSig 在 LOH 內 TP 顯著率 53.3% vs FP 35.8%（差 17.4pp）。這與 O1（HPFineP）一致。但 Non-LOH 差異僅 4.9pp。

AlleleSig 在 Non-LOH 反轉（FP > TP），這是因為 Non-LOH germline FP 是 het variants，天然有 allele-specific signal。

#### O9: VerificationClass — LOH 內 Noise 比例是唯一差異

```
LOH:     TP Noise=40.2%, FP Noise=50.3% (Δ=10.1pp)
Non-LOH: TP Noise=26.1%, FP Noise=26.3% (Δ=0.2pp)
```

LOH 內 FP 更多被歸為 Noise（+10pp），LOH 內 TP Strong 比率略高（22.8% vs 18.9%）。Non-LOH 幾乎完全相同。

## 7. Failure Cases / Negative Results / Limitations

### 7.1 甲基化距離特徵的全面失敗

| 特徵 | 最佳 AUC（任何分層） | 結論 |
|------|---------------------|------|
| PairwiseMeanDist | 0.531 (Non-LOH) | **無效** |
| PairwiseMedianDist | 0.530 (Non-LOH) | **無效** |
| HPMergedDelta | 0.507 (Non-LOH) | **無效** |
| CramersV | 0.507 (All) | **無效** |
| CramersV_HPFine | 0.507 (LOH) | **無效** |
| CramersV_HPFamily | 0.504 (Non-LOH) | **無效** |

**根本原因**：Germline FP 和 somatic TP 的甲基化距離分布相同。Germline variants 不改變 CpG 甲基化模式，somatic variants 在統計上也幾乎不改變（因為是 point mutation，不是 epigenetic driver）。

### 7.2 Non-LOH 的全面空白

Non-LOH 區域（TP=7,599, FP=3,423）沒有任何特徵 AUC > 0.585。Non-LOH germline FP 是正常的 heterozygous variants，在所有維度上都與 somatic TP 無法區分。

### 7.3 LOH_Weak 信號的局限

- LOH_Weak 僅佔全量的 20%（TP=6,305, FP=1,749）
- AUC 0.72 主要來自結構性特徵（HP read count），不是可泛化的甲基化信號
- 應用 HP read count filter 會同時移除大量 TP（因為 TP 也有極端 HP ratio 的情況）

### 7.4 本報告限制

- 單一樣本（HCC1395, 100% purity）
- PON-only v2b haplotagging（已知有 somatic HP tag 缺陷）
- ISM window=5000，單一距離度量 BERNOULLI

| Test A | LOH_Weak only | **0.721** | **0.686** |
| Test B | All LOH | 0.540 | 0.517 |
| Test C | All data | 0.530 | 0.532 |

**結論**：AUC 從 0.72 驟降至 0.54（-0.18）。原因是 HP2FamilyN → HP_Ratio → Potential_LOH → LOH_Subtype 的循環依賴。在 LOH_Weak 內觀察 HP2FamilyN 等同於在 HP_Ratio 極端子集內觀察 HP counts — **tautological**。

**追加：Threshold scan 確認不可用**：

```
HP2FamilyN < 1 (v2b LOH_Weak): TP_loss=42.6%, FP_removal=7.4%
HP2FamilyN < 5 (v2b LOH_Weak): TP_loss=51.1%, FP_removal=11.9%
```

Filter 方向錯誤 — 低 HP2FamilyN 對應 TP（somatic LOH 的 minor haplotype genuinely 少），不是 FP。

**狀態**：~~**評估** LOH_Weak HP read count filter~~ → **STOP**

### O8 更新：AlleleSig LOH Δ=+0.147 → 確認為 Simpson's Paradox

**原觀察**：AlleleSig LOH 內 TP=0.533, FP=0.358, Δ=+0.174。

**深度驗證（AlleleSig 專題分析）**：

| LOH Subtype | TP AlleleSig | FP AlleleSig | Δ | AUC |
|-------------|-------------|-------------|---|-----|
| LOH_Strong | 0.976 | 0.978 | **-0.002** | 0.499 |
| LOH_Weak | 0.972 | 0.979 | **-0.007** | 0.497 |
| LOH_Subclone | 0.000 | 0.000 | 0.000 | 0.500 |
| LOH_Noise | 0.000 | 0.000 | 0.000 | 0.500 |
| **全 LOH** | **0.515** | **0.369** | **+0.147** | **0.573** |

**每個子類型內 Δ ≈ 0，全 LOH 的 Δ=0.147 完全來自組成比例差異**：

- TP 53% 在 Strong+Weak（AlleleSig ≈ 1.0），40% 在 Noise（AlleleSig = 0.0）
- FP 38% 在 Strong+Weak（AlleleSig ≈ 1.0），52% 在 Noise（AlleleSig = 0.0）
- → TP 的加權平均 AlleleSig rate 較高，純粹是組成效應

**ML 驗證（AlleleSig marginal contribution）**：

| 對比 | LR Δ | RF Δ |
|------|------|------|
| Base 13 features → +AlleleSig | +0.0004 | **-0.0026** |
| Full 20 features → −AlleleSig | +0.0001 | **+0.0008** |

**AlleleSig 不含任何獨立信息**。移除它反而讓 RF 微幅改善。

**狀態**：~~**保留** HPFineSig/AlleleSig 作為 LOH-only soft filter~~ → **STOP**（AlleleSig 確認無效），HPFineSig 同理（見下）

HPFineSig 在 LOH 內 TP>FP（Δ=+17pp）同樣是組成效應：

### O3 更新：AlleleDelta LOH — 生物機制確認

**原觀察**：LOH FP median AlleleDelta = 0.000。

**深度驗證（Q5 + AlleleSig 專題）**：

按 AlleleSig 狀態拆分 LOH AlleleDelta：

| AlleleSig | Label | Mean | Zero% | 解釋 |
|-----------|-------|------|-------|------|
| false | TP | 0.0015 | 45.3% | LOH TP + 無 allele test power → 趨零 |
| false | **FP** | 0.0014 | **74.1%** | LOH FP + minor HP=0 → **物理上無法計算 ASM** |
| true | TP | 0.062 | 0.0% | LOH TP + somatic ASM → 正常範圍 |
| true | **FP** | **0.077** | 0.0% | LOH FP + **germline 天然 ASM → 比 TP 更高** |

**結論**：
1. FP AlleleDelta=0 的原因不是「germline FP 缺乏 ASM」，而是 **minor haplotype reads=0 導致無法計算**
2. 有足夠 reads 的 FP (AlleleSig=true) 反而有**更強的 ASM**（天然 germline ASM > somatic effect）
3. 按 minor HP count 分層：AUC 僅在 minor_hp=0-2 時 >0.55（本質上是 zero-inflation 的 proxy），其餘 bin 全部 <0.50

**Trade-off**：v2b = 更多 LOH coverage + 更弱 discrimination；baseline = 更少 coverage + 更強 discrimination
