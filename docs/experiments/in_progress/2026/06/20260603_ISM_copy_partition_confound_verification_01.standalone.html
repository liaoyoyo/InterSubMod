cis-ASM candidate 的 copy-partition confound

三項量化驗證 · HCC1395 單樣本 · 2026-06-03 · ⭐3 · L1 decisive decomposition · A pilot · subset 7/60

一句話結論

在 HCC1395 單樣本中，within-tag allele 效應於 4/4 測試位點顯著非零（3 強顯著 p≤0.006 + BRCA2 marginal p≈0.02）——somatic-cis-ASM 為真現象，但量級遠小於 HP-axis 表面值。多數 candidate 表面訊號主要來自 subclone/copy partition（HP1-1=somatic subclone tag 非 copy、非 CN-dosage；見修正 banner），而非 somatic allele 本身：BRCA2 焦點 cis d_within=−0.023 邊際（vs d_HP −0.122；% split 不 robust）。唯一乾淨的強 cis 是 chr17:79991120（mech NEUTRAL）；chr18:11741161 帶 CpG-creation 機械假象待釐清。尚需跨樣本複現。

⚠ 修正 banner（2026-06-07，longphase-S 源碼審計後）：「copy-partition」應讀作「subclone/copy partition」。源碼（HaplotagStrategy.cpp:505-516）確認 HP1-1 = germline 單倍型1 + somatic ALT = somatic SUBCLONE tag，不是「一個 copy」；故 d_copy 是 somatic-subclone vs germline 甲基差（已證非 CN-dosage）。數字成立（d_within 經三重證據驗為有效 subclone-control：HP1-1/ref 19/19 帶其他 somatic ALT + focal confident REF + 甲基歸 subclone 群）→ BRCA2 表面 ASM = subclone/copy 主導（焦點 cis d_within=−0.023 邊際；% split 不 robust）。「7/60 測不了」是 subclone CONTROL 限制；raw 焦點對比 d_focal_CLEAN 10/11 可算。完整：InterSubMod/docs/experiments/in_progress/2026/06/20260607_HP11_tag_definition_correction_record_01.md。

對抗 workflow 的 Angle 4 挑戰：在 CN-gain（擴增）區，HP1 與 HP1-1 兩個 tag 可能對應不同的 copy，各帶 copy-specific 甲基化。HP-axis 把「copy 之間的差異」誤當成「somatic allele 的 cis 效應」。

② confound 機制：為什麼 HP-axis 會混淆 copy 與 allele

關鍵：HP1-1 tag 是「phased 到 HP1 且 帶 somatic ALT」的 reads。在正常二倍體區，HP1 與 HP1-1 是同一條 haplotype、只差一個 somatic 鹼基 → 兩者甲基差 = 純 somatic 效應。但在擴增區，同一 haplotype 有多個 copy，HP1-1 可能來自某個特定擴增 copy，而該 copy 本身就帶不同甲基 → 差異混入了 copy 身分。

③ 方法：4 種量測把 copy 與 allele 拆開

對每個位點，用 longphase HP-tag × MSA per-read allele（ALT/REF 由 SNV 定義，非甲基），算 4 個 paired per-CpG Δβ：

量測定義held constant捕捉什麼
d_HPHP1 vs HP1-1（all）—copy + allele 混合（原始訊號）
d_withinHP1-1 內 alt vs reftag（→ copy）純 somatic-allele cis ★ 正確指標
d_copyHP1/ref vs HP1-1/refallele（皆 REF）純 copy/tag 差異
d_allele全 tag ALT vs REF（pooled）—ALLELE-axis（檢查是否也 confound）
成分對照（非嚴格可加）：  d_HP  ~  d_copy  ⊕  d_within
⚠ 這不是乾淨的加法分解：三量測在不同 read 子集與 CpG 集合上估計（d_HP=between-tag pooled、d_within=within-somatic-tag、d_copy=cross-tag-on-ref），故 d_copy+d_within 對 d_HP 的殘差達 6–40%。極端如 chr17：d_within(0.142) > d_HP(0.122)（成分大於整體）——因 pooling 在 HP-axis 稀釋了真 within-tag 效應。下方 bar 是「成分大小對照」，非把 d_HP 切兩塊；用途是看哪一半主導，不是精確分帳。

殘餘 copy 控制（permutation）：在 somatic tag 內把 read 的 allele label 隨機重排 2000 次 → null 分布。觀測 d_within 落在 null 之外 = 真 allele-specific；落在 之內 = 僅 within-tag 異質性。

ALLELE-axis 的 copy-confound 是 locus-dependent，不是通則：5/7 位點 d_allele 追 d_within（乾淨），只有 BRCA2 + chr5（copy-dominated）追 d_copy。BRCA2 是例外：d_allele(−0.099) ≈ d_copy(−0.110)，遠離真 cis(−0.023)。
→ 修正口徑：copy-dominated 位點（BRCA2）ALLELE-axis 同樣被 copy 污染；allele-dominated 位點（chr17）ALLELE-axis 反而追真 cis。故 6/01「BRCA2 ALLELE-axis cis」那半確需撤回（BRCA2 屬 confounded 類），但不可泛化成「所有 ALLELE-axis 都不乾淨」——那會犯與 HP-axis 同樣的 n=1 過度推論。唯一普遍乾淨的指標仍是 d_within。

為何 chr18 要降級：它的 somatic SNV（T>C）在 ALT allele 上創造一個新 CpG。當 ALT 有新 CpG、REF 沒有時，within-tag ALT-vs-REF 的甲基差會帶一個純機械性差異（非生物 allele-specific 調控），而本報告的 permutation（打亂 allele label）排不掉這個 confound——因帶新 CpG 的 read 永遠在 ALT 側。故 chr18 從「乾淨 cis」降為「需先排除 CpG-creation 才能確認」。
chr17:79991120（mech=NEUTRAL、n_cpg=126、ALLELE-axis 同向）是7 個可做 copy-test 的位點中唯一三重乾淨者。基因/調控 context 與 COLO829 複現尚未做。
⚠ 重大覆蓋偏差（勿讀成「chr17 是全域最強乾淨 cis」）：copy-test 只能在 somatic tag 同時有 ALT+REF reads（leaky tagging）的位點算 → 僅 7/60 T3 可算。而**訊號最強的 6 個位點**（chr4:133868344 d_cis=0.706、chr20:59439285 ratio=10.9、chr7:79941963…）somatic tag 是純 ALT（ref=0）→ 結構上無法 copy-test，其 cis-vs-copy 狀態未知。chr17 排訊號強度僅第 6（ratio 2.1），它「乾淨」是因剛好可算。此法能 demote leaky/弱候選，但無法裁決最強的乾淨-tag 位點（需 per-read copy-phasing 或 COLO829）。多重檢定：60 T3 用未校正 p<0.05；Bonferroni(0.05/816) 只剩 10（chr17 p_cis=0.0 自身 survive）。

⑨ 意涵與後續

pipeline 修正

  • P3 cis_test 加 d_within（within-tag-allele）當主 cis 指標，d_HP 降為 screen-only。
  • cis-ladder tier 改以 copy-control 後的 d_within + per-locus permutation 判定，而非 HP-axis 量級。

引用聲明（誠實口徑）

  • 引用 BRCA2 cis 必標：「HP-axis −0.122 中真 allele-cis 對 HP-axis 僅 19%（d_within ≈ −0.023，marginal，p≈0.02、兩次 perm 0.022/0.024、obs 僅略超 null CI、n=19/19，需 COLO829 確認非零）」。
  • 撤回 6/01「BRCA2 ALLELE-axis cis」（BRCA2 屬 copy-confounded 類）；但限定 BRCA2，勿泛化成所有 ALLELE-axis（5/7 位點 ALLELE-axis 其實追真 cis）。

值得做的後續

  • chr17:79991120（唯一三重乾淨）優先 deep-dive：基因/調控 region、生物機制、COLO829 複現（升 ⭐4 必要條件）。
  • chr18:11741161 先做 CpG-creation 控制（比較含/不含新 CpG 位點的 d_within），排除機械假象後才納入。
  • 低覆蓋 53/60 T3：需更深測序或 pooling 才能拆解，目前判定未定。

⑩ 限制

  • 單樣本 HCC1395，結論需 COLO829 複現；BRCA2 殘餘 cis 為 marginal，尤須複現。
  • 僅 7/60 可做 copy/allele 拆解，且結構性偏向 leaky-tag（som tag 有 ALT+REF）位點；最強 6 個位點純 ALT tag 測不了（見 ⑧），不能宣稱「全部如何」。
  • 證的是 association 非 causation：permutation 顯示「chr17 該 tag 內 ALT-read 甲基 ≠ REF-read」，不等於「somatic 突變 cis-驅動甲基化」（無機制、無 pre/post、無跨樣本）。本法明示 characterization-only、非 filter 非因果證明。
  • 存活者生物意義（基因、調控）未查；chr18 帶 CpG-creation 機械 confound 未排除。
  • 「d_HP ≈ d_copy + d_within」僅近似（三量測在不同 read 子集/CpG 集合估計，殘差 6–40%），非乾淨加法分解；勿據此做精確分帳。
  • d_within permutation 控制 within-tag 異質性，但若 somatic tag 內仍混多 copy，殘餘 copy 無法完全排除。機制：殘餘 copy 異質性會作為額外變異併入 within-tag allele 對比、使 d_within 偏向高估 → 故真 cis ≤ d_within（上界）；逼近真值需 per-read copy-phasing 把 tag 再依 copy 細分（本樣本無直接 copy marker）。
