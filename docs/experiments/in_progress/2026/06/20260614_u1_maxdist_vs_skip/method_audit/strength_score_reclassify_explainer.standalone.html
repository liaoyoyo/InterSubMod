把「最終判別」從飽和的啟發分數，升級成
連續強度分數 + 救回假陰性的分類

這個 C++ 改動做兩件事：① 用連續 StrengthScore（0–1）取代飽和、無梯度的 HeuristicScore；② 用 reclassify-v2 把原本「粗+標籤錨定」的 4 類判別，升級成能救回假陰性、且不誤判（0 FP）的細分類。全基因組 30,490 region pilot 驗證，C++ Stage ①④ 已實作。

L0 一眼看懂這個改動

問題：原本的「強度」是 HeuristicScore，它飽和（median 20 / max 22）= 沒有梯度，無法排序強弱；而判別只認「離散 cluster × 標籤」，會把有連續結構訊號（Δβ / HP-AUC 高）但不對標籤的真訊號誤判成 Weak/Noise。改法：連續 StrengthScore + 「任一結構證據就保留」的 reclassify-v2。

▸ 給 PI 一句話：全基因組 pilot 證實 reclassify-v2 救回 3,810 / 8,179 = 46.58% 的 Weak+Noise（這些是有 Δβ / HP-AUC 結構但被舊邏輯漏判的真訊號），且 0 個原 Strong 被改掉（FP=0，純加識別無副作用）。StrengthScore 從飽和變成漂亮梯度（median 0.344，A–E 五級分佈）。C++ 已實作 Stage ①（強度分數）+ Stage ④（新判別簡版），ctest 221/221、C++=Python 0/2624 不一致、regression 雙守護 PASS。

① 為何改：原方法三個不足

改動不是憑感覺 —— 三個問題都有證據。

原方法問題證據
HeuristicScore（強度）飽和（median 20 / max 22）無梯度 → 無法排序強弱
VerificationClass 4 類粗 + 標籤錨定46.6% 假陰性可救（且 0 FP）
判別只認離散 cluster×標籤漏 Δβ / HP-AUC假陰性實例 6202793：HP-AUC=0.969（距離結構極強）卻被判 Weak
核心洞察：「結構訊號」有兩種 —— 離散的（cluster 對應某標籤）與連續的（Δβ level-shift、HP-AUC 距離結構）。舊判別只看離散那種，所以把「甲基整體位移、距離結構強、但不分成對應標籤的明顯兩群」的真訊號（= label-first 抓得到、structure-first clustering 漏掉的）誤判成噪音。reclassify-v2 把連續證據也納入「保留」條件。

② StrengthScore：連續強度分數（取代 HeuristicScore）

四個面向各取一個 0–1 的子分數，加權成一個 0–1 的總強度。

struct = clamp((HP_AUC_All − 0.5) / 0.5, 0, 1) # 距離結構（HP-AUC 0.5→0, 1.0→1） eff = clamp(|GermlineAsmDbeta| / 0.3, 0, 1) # Δβ effect size（甲基率差大小） assoc = CramersV # 標籤關聯（reliable-gated） sig = clamp(−log10(max(GlobalP, 1e-6)) / 4, 0, 1) # 顯著性（GlobalP=0 → 1） StrengthScore = 0.30·struct + 0.25·eff + 0.25·assoc + 0.20·sig ∈ [0, 1]
worked example · 假陰性 6202793 這個 region HP-AUC=0.969（距離結構極強）但被舊邏輯判 Weak。算 StrengthScore：
struct = (0.969 − 0.5)/0.5 = 0.938 ← 距離結構這一項就很高 → 即使 assoc(CramersV) 低（不對標籤），struct·0.30 ≈ 0.28 已把它推離「Noise/Weak」區 → StrengthScore 給出梯度，reclassify-v2 用「HP-AUC≥0.7」把它救回 StructureNoLabel

③ 量化：StrengthScore 從「飽和」變成「梯度」

全基因組 30,490 region 的實際分佈 —— 這是改動有效的直接證據。

④ reclassify-v2：救回假陰性 + 細分類（量化）

核心哲學（用戶定）：任一結構證據就保留（valid）。下面是 valid 條件 + 新細類 + 全基因組救回量化。

valid = Δβ_sig # 任一 Δβ module 顯著（level-shift，主救回來源） OR HP_AUC_All ≥ 0.7 # 連續距離結構 OR cluster_matches_label # 原 GlobalTest（離散） OR within_HP_clean_multigroup # §5 新指標（Stage② 待補） OR (SEQC2_LOH AND structure) # SEQC2 真值（Stage③ 待補）
