ISM 在做什麼？哪些有效？有哪些 gap？

把 ISM 「甲基 × 標籤」的所有顯著性方法，用 A/B 兩個方向 重新整理 → 看清每個方法對應什麼目標、是否有效、缺什麼。整體判定：核心計算合理、無致命錯誤，但有 6 個 gap 待補（最關鍵 = Δβ 缺檢定 + somatic 殘差缺檢定）。

L0 一眼看懂

ISM 驗證「甲基和某個標籤（HP / 等位 / 腫瘤-正常）有沒有關係」其實有兩種根本不同的方向，現在混在一起講：

▸ 方向 A（label-first 標籤驅動）：先按已知標籤分組 → 算組間甲基差（Δβ）→ 檢定。問「這個標籤有沒有甲基效應？」= 確認 germline/somatic ASM。
▸ 方向 B（structure-first 結構驅動）：先按甲基結構（read 距離）分群 → 再看群對不對得上標籤。問「甲基自己分成幾群？是不是新結構？」= 唯一能找 subclone 的方向。

▸ 整體判定：6 類方法、4 個目標層；Fisher-FH / PERMANOVA / BH-FDR / NME-Epipoly 都對標業界標準 ✅；但 6 個 gap，最高槓桿 = #1 Δβ 有值無檢定 + #3 somatic 殘差借 tumor 的 p（沒真檢定）。

證據分級：方法歸類/計算邏輯 = L1（框架引源碼行號）；數據（HP-AUC normal 0.788 等）= 本 session 已驗；有效性/替代 = L2（領域評估，待逐一驗）。

⑥ 整體判定 + 最高槓桿下一步

整體判定 ISM 核心顯著性計算合理、無致命錯誤 —— Fisher-FH / PERMANOVA(Anderson) / BH-FDR / NME-Epipoly 都對標業界標準。問題在「描述有了、檢定缺了」：Δβ 有值無檢定（#1）、somatic 殘差借 tumor 的 p（#3）。
最高槓桿（最上游 + 直接決定「ASM/somatic 能否可信判定」）： #1（Δβ 檢定） + #3（somatic 殘差檢定） 其實可一次統一 —— 做一個方向 A 的 Δβ 模組：germline Δβ（family/fine same-hap）+ somatic 殘差 Δβ（tumor−normal）+ permutation 檢定，輸出 dbeta/p/sig，並取代有缺陷的 hp_residual。檢定成本低（mean-permutation ≪ distance permutation）。#2/#4 改善嚴謹度，#5/#6 釐清。
下一步內容理論依據
(a) Δβ 檢定模組somatic 殘差 Δβ + germline Δβ + permutation；先 perm(i)，beta-binomial(ii) 後對照DSS/methylKit interaction = somatic ASM 標準
(b) 實際數據驗Δβ sig 比例 vs 舊 hp_residual_sig；與 DSS-like 對齊方法一致性
(c) 精簡冗餘移除 LabelTest distance delta / hp_residual(distance)#6/#3，雙守護 regression 保結果不變
