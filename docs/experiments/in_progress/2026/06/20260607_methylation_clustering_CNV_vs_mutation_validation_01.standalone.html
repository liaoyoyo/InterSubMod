甲基分群驅動來源完整驗證

CNV / copy-partition vs somatic-mutation-cis · HCC1395 單樣本 · 2026-06-07 · ⭐3 multi-channel confound-controlled · task B · partial（單樣本 + 7/60 leaky）

一句話結論

甲基分群不是 CN 數量(dosage)、不是 alignment、不是純 artifact 造成；其量級主因是 copy-PARTITION（擴增區「哪個 copy」帶的結構性甲基差）。跟 HP-tag 一致是因 HP1-1 在 amplicon 挑出特定 copy，跟突變一致是因突變定義那個 copy。全 816 位點過完所有 filter，只剩 1 個（chr17/TBC1D16）是 copy-control 後存活的乾淨真 cis。

⚠ 修正 banner（2026-06-07，longphase-S 源碼審計後）：本報告「copy-PARTITION」通道應讀作「subclone/copy partition」。源碼（HaplotagStrategy.cpp:505-516）確認 HP1-1 = germline 單倍型1 + somatic ALT = somatic SUBCLONE tag，非 copy。d_within 經三重證據驗為有效 subclone-control（HP1-1/ref 19/19 帶其他 somatic ALT）→ 量化成立、僅 relabel：BRCA2 表面 ASM = subclone/copy 主導（焦點 cis d_within=−0.023 邊際；% split 不 robust）。raw 焦點對比 d_focal_CLEAN 10/11 可算。完整：InterSubMod/docs/experiments/in_progress/2026/06/20260607_HP11_tag_definition_correction_record_01.md。

① 問題

HCC1395 的「甲基分群 / Δβ」是 CNV / copy-partition / ploidy 驅動，還是 somatic-mutation-cis 驅動？跟 HP-tag + 突變一致，會不會只是 CNV 或 alignment 的副作用？這質疑 ASM 訊號的根本 validity，須逐通道排除。

⑧ 你的假設 — 三層判定

子主張判定
甲基分群 = copy-DOSAGE（CNV 數量）副作用❌ REFUTED（量級跨 CN-state 平、signed ρ 反向）
甲基分群 = alignment 副作用❌ REFUTED（5/6 對齊正常；chr11 旗標）
分群量級 = copy-PARTITION（哪個 copy）✅ SUPPORTED 主導（~64%）
完全 artifact、無真訊號❌ REFUTED（within-tag permutation 4/4 顯著；chr17 乾淨）

綜合：甲基分群存在性與量級的主因是 copy-partition（結構性 copy 甲基差），不是 CN 數量、不是 alignment、不是純 artifact。跟 HP-tag + 突變一致是 copy 中介的副作用——你的直覺在「結構/copy 是主因」這層對了，但更精確是 copy-PARTITION（哪個 copy）而非 dosage（幾個 copy）。全 816 只 1 個乾淨真 cis（chr17/TBC1D16）。

⑨ 硬天花板（誠實）

單樣本 HCC1395 內，對最強訊號集 copy 與 mutation 近乎不可識別：純 ALT tag 測不了（7/60 才可算）；CN=2 乾淨地層只 76 位點且 75/76 是 TP（無 TP/FP 對比）。要裁決那 6 個最強訊號（d_cis 到 0.706）必須換 design（COLO829 跨樣本 / 實驗擾動）——但 COLO829 無 SEQC2-style CN truth，CN-disentanglement 那支綁死 HCC1395。這不是「多跑就好」，是單樣本的識別極限。

⑩ 限制 + 後續

  • 單樣本；read-level copy-partition 只 7/60 可算；alignment 測 24 位點；6 untestable 的 copy-vs-cis 未定（CGI-沙漠結構 prior 非證實）。
  • 「64%」與「chr17 唯一乾淨」是 7-leaky / 可測子集數字，引用須 scope-lock（非全域代表值）。
  • 業界對照：CN→甲基通道真實（dosage compensation；CAMDAC）但 CGI/promoter-localized + directional，與我們 CGI-沙漠最強訊號不符 → desert 訊號非 dosage 簽名；field standard 去 confound = CAMDAC（ASCN+purity），HP-axis 是其 read-level 類比。
  • 後續：chr17(TBC1D16) deep-dive + COLO829 複現（升 ⭐4 必要）；6 untestable 需 per-read copy-phasing 或 COLO829；chr11 排除 divergent-region 假象。
