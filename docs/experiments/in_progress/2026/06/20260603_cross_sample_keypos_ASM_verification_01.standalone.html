方法 / caveat（必讀）

方法：複用已驗證 pysam 抽取（modkit crossval Pearson=1.0）；per-read 5mC β（mean over CpGs in ±600bp），依 HP:Z tag 分群；somatic-controlled HP-axis Δβ=β(subhap)−β(main)。
口徑：window-mean 5mC（各樣本一致）重現 HCC1395 credible-loci delta 的方向，非精確 magnitude（原表 paired-CpG MAX-collapse Wilcoxon）。
限制：① SEQC2 truth 只有 HCC1395（其他 5 樣本 TP VCF 是 caller 輸出、無正交 truth）；② targeted「不復發」部分受 LOH/低 N 使 germline 軸不可測所限（非純生物缺席）；③ IGF2 是 cnLOH，4/5 樣本 germline 軸塌縮 → 已知 imprinting 被 LOH 遮蔽（footnote，非 code bug）；④ genome-wide 固定門檻 raw rate 受小 N 噪音灌水（median|Δβ| 全 <0.10），必看 excess-over-null。⑤ 6 樣本共用同一 ClairS-TO/longphase caller + 同一 HP-axis 估計法 → 此為「現象複製」非獨立管線/獨立 cohort 驗證；共用系統性偏差（caller 或估計法）未排除，故 tier 封頂 ⭐3（bordering ⭐4），升 ⭐4 需獨立管線或正交 truth。⑥ genome-wide rate 用 window-mean 5mC（與 targeted credible-loci 的 paired-CpG MAX-collapse Wilcoxon 口徑不同），方向可比、magnitude 不可直接並列。
