🔴 關鍵發現 + 機制解釋（驗證假設 → 找到例外）

加 Δβ-meanshift branch 後 TP/FP 分離比從 I0 的 3.7 崩到 ~1.0（FP 率上升≥TP）→ Δβ branch 新增的位點 FP-balanced/FP-enriched，非 TP-discriminative。機制解釋: 高|Δβ| 集中在 LOH/低覆蓋/極端baseline 區=FP(caller誤判)集中處 → Δβ 反映基因組困難度非 somatic 真實性 (對齊舊 strong-ASM FP-enriched OR=0.194 regression-to-extreme)。dispersion-warn 漏入=0(例外檢查每迭代皆過)。

白話：你假設「兩訊號都能找到有意義資訊」—— 機械上對（聯集多抓 ~85% 位點），但加 Δβ branch 後 TP/FP 判別比從 3.7 崩到 ~1.0（FP 升得比 TP 還多）→ Δβ 平均差多抓的是「基因組困難區」（LOH/低覆蓋，FP 集中處）非 somatic 真實訊號。**這是假設的例外，且與舊機制 (strong-ASM FP-enriched) 一致。**
