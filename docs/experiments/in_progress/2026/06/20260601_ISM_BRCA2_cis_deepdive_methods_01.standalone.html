BRCA2 cis 深掘 + 方法驗證

InterSubMod · HCC1395 paired_full · BRCA2 chr13:32,315,128 + 9 對照位點 · 2026-06-01 · 對 10 位點重跑小範圍 MSA（tumor+normal）

回答「突變 cis 驅動甲基化是否存在、怎麼清楚驗證」：per-tag cohesion 不夠（germline-het 也能高內聚），關鍵是 normal-anchored cis-test——比 normal HP1（突變前基線）/ tumor HP1（同 haplotype 無 ALT）/ tumor HP1-1（帶 somatic ALT）。BRCA2 在兩個獨立軸（HP-axis + phasing-independent ALLELE-axis）都通過 cis-test（somatic reads 偏離 baseline −0.14 顯著、germline 幾乎不漂移），而 germline-het 對照即使 cohesion 高也只是 drift。→ BRCA2 是真正的 cis-driven 候選，與「pre-existing germline 等位甲基」的多數位點不同。全域 NEGATIVE 仍成立（多數位點非 cis），但 cis-test 能撈出 BRCA2 這種真案例。

每個 claim 標 L1 親測 L2 推導 L3 推測。圖可點放大。

1. MSA 是什麼？與 ISM 有關嗎？方法合理嗎？ L1

MSA = MethylSomaticAnalysis（外部 C++ 工具 /big8_disk/.../MethylSomaticAnalysis v1.0.0），不是專案自己的 ISM/inter_sub_mod binary。

MSA（外部）ISM / inter_sub_mod（本專案）
角色甲基抽取引擎：haplotagged BAM → 每 read 每 CpG 甲基 + HP tag + ALT/REF專案 clustering/structure 引擎（SubcloneAnalyzer / DistanceMatrix …）
本調查產 Level 1 餵 PythonASM 部分沒用 ISM binary

合理性（4-agent audit）：抽取層合理高效，但內建統計不可靠：

  • ✅ 正確認 HP:Z:1-1/2-1/3 tag、ref/alt 分類、per-read CpG（MethylHaploExtractor.cpp:337-392）。
  • ❌ Level 3 的「ASM 差異/p」比的是 VCF 來源不是 HP group，p 值非標準粗近似 → 不可用。所以我們正確改用 Level 1 + Python pivot（script 18）。
  • ⚠ RAM 全量累積（--max-ram-gb 死參數）、Level 1 全基因組 50-200GB → 全量需分染色體 batch。

一句話：MSA 當「抽取工」合理；它的「分析工」有缺陷，我們沒用、改用 Python——分工正確。

2. 方法鏈 S1-S6（每步動作 → 產出）L1

相位分組（longphase）：用 germline het SNP 把 tumor read 相位成 HP1/HP2；帶 somatic ALT 的加 "-1"（HP1-1）。只用 SNV、不用甲基化 → 非循環。
等位分型（MSA）：比對 read 在 somatic 位點 base vs VCF ALT → ALT/REF。
甲基抽取（MSA Level1）：每 read 每 CpG，5mCG_5hmCG BAM 發 5mC+5hmC 兩列未標記 → max-collapse any-mod（§5 證實 BRCA2 5hmC 可忽略）。
兩軸（script18）：HP-axis = ALT-vs-REF 限同 haplotype（控 germline 等位甲基）；ALLELE-axis = ALT-vs-REF pooled（baseline-confounded）。
配對檢定：兩臂都覆蓋且各 ≥3 reads 的 CpG 配對 → Wilcoxon signed-rank。合理（非常態+配對），但小 n 有離散下限（n≤20 censored）。
漏斗 + 對照：Bonferroni→|Δβ|≥0.1；germline-het null；LOH/CN；coverage-match；normal-anchored cis-test（本文件新增）。

3. per-tag 群內群外聚集度 L1 新

用存活的 MSA Level 1，算每個 tag 的 silhouette（群內緊←高 / 混雜←0）。BRCA2：HP1-1 somatic / ALT 最內聚。

但「內聚」不等於「cis 驅動」：germline-het 對照位點 chr1:181698147 的 HP1-1 cohesion 高達 0.598，卻是 germline 等位甲基（見 §4 它 cis-test 不過）。所以單看 cohesion 會誤判 → 必須做 cis-test。

★ 4. normal-anchored cis-test（核心驗證）L1 新

要證明「突變 cis 驅動甲基」，比三組（同 germline haplotype HP1 上）：

組意義
A = normal HP1突變前基線（matched normal，無 somatic）
B = tumor HP1tumor 同 haplotype、不帶 somatic ALT
C = tumor HP1-1tumor 同 haplotype、帶 somatic ALT（somatic 子克隆）

判準：d_cis = C−A（somatic vs 基線）顯著 且 d_drift = B−A（germline 漂移）小 → 甲基變化特異於帶 ALT 的 reads = cis-driven 候選。

前提已驗證 ✓ L1

cis-test 依賴「tumor 與 normal 的 HP1 是同一條 parental haplotype」。實測每個位點 HP1 的 REF-fraction 在 normal/tumor 一致（BRCA2 都 1.0；het 都 0.0…）→ phasing 一致，cis-test 有效。

5. 5mC vs 5hmC 分離（從 BAM）L1 新

Level 1 把兩修飾存成「未標記兩列」無法分開 → 回 BAM 的 MM/ML（C+m=5mC、C+h=5hmC 明確標記）抽。

意義：BRCA2 的 ASM 純粹是 5mC 效應，5hmC 可忽略 → max-collapse any-mod 沒有掩蓋 5hmC-specific 訊號（解掉先前標的 open 項）。5mC/5hmC 與 HP/somatic 一致性：5mC 隨 somatic 下降、5hmC 與 tag 無關。L2 跨位點是否普遍 5hmC 可忽略，需擴對照。

6. LOH / 拷貝 / 分群 L1

  • LOH：BRCA2 = nonLOH（不在 LOH bed）→ 兩 haplotype 都在，HP-axis 在 BRCA2 乾淨（沒有「43% LOH 污染」問題）。
  • 拷貝：在 CN-gain 區（SEQC2 CNV bed chr13:18.4-49.0Mb = gain）→ 拷貝增益，但 beta 是 fraction 不直接受影響。
  • 分群：read-level cluster 真實（下圖 MDS R²=0.478, p=0.002）但反映等位甲基；per-tag 證實 somatic 群最內聚（§3）。

誠實 caveat

  • 單一 cis-candidate（BRCA2）+ 1 個 allele-axis 弱候選（TP_LOH chr4）。可測位點少（低 VAF / 無 shared CpG → cis 不可測）。
