Subclonal reconstruction using somatic single-molecule co-occurrence（ONT long-read）
樣本 HCC1395（ONT 5kHz + 5mCG/5hmCG tagged） 更新 2026-07-10（P0 誠實重分類：六層 funnel + mutation-bearing） scope chr1–22（chrX out-of-scope）· 固定錨 2e69811 證據分級 L1源碼/實測 L2文獻+推演 L3單樣本觀察 L4前瞻/推論
一句話結論：以 somatic sSNV 單分子共現 在布爾超立方體上重建腫瘤演化樹，是一個 正確、可精確枚舉、非循環的方法；它誠實地在能定的地方定樹、不能定的地方回報「定不出來」。 這是一個可驗證的「區域突變狀態樹」重建——生物 subclone 可如其他工具（PhyloWGS/Canopy/CITUP）一樣推論， 但單一 bulk 下是推論不是確認。甲基化只事後輔助、不決定樹；read 數可在拷貝數乾淨區收斂等機率樹。方法上限 = ⭐3（characterize）。

1方法：從 sSNV 共現到演化樹 L2

每個 somatic 點突變（sSNV）是超立方體的一個座標軸；一條 ONT 長 read 直接讀出「哪些突變在同一條 DNA 分子上」——這是本方法的命脈（跨 read 拼接無法保證同分子，單分子共現可以）。

數學物件生物意義
超立方體頂點 {0,1}ⁿ一個基因型（已獲得哪些突變）
根 = 0ⁿ（全 R）germline（未突變祖先）
有向邊（翻一個 0→1）一次 infinite-sites 獲得突變
隱藏（Steiner）節點推斷的、未被直接觀測到的祖先 clone
partial read（只覆蓋部分位點）超立方體的一個「子面」約束（= IDPP，Pe'er 等 2004）
最小樹（枚舉全部）maximum parsimony 演化樹（所有等成本候選）

形式化：directed rooted (group) Steiner arborescence on Boolean hypercube = Incomplete Directed Perfect Phylogeny。逐區位點數 ≤8（涵蓋 97.5% 的區）→ 頂點 ≤256 → 暴力精確枚舉可行，不需近似。

3誠實的核心：能定 vs 定不出來 L2

✅ 枚舉精確解集（做得到）

逐單位精確窮舉所有等成本候選樹（mutation-bearing determined 5,384 唯一定樹 + ambiguous 5,959 精確枚舉候選集）。實例大小為常數（位點 ≤8），暴力精確；partial read 以隱藏 Steiner 節點納入同一超立方體。

❌ 指派唯一全域樹（理論不可）

單一 bulk 樣本下，43.2%（5,959 單位）有多候選樹、無法定唯一；跨區整棵樹也非可辨識。這是資訊論極限，非計算能力問題——「多候選／定不出來」就是它們的精確答案。

此立場與領域一致（Tarabichi 2021 / MACH2 2024 / Pairtree）：資料不足時輸出候選集 + 不確定性，而非強行給單一樹。

4本輪兩個新結論

4.1 partial-read 區的正確建樹 L1

沒有任何 read 穿越全部位點時，正確做法 = 把整區當一個超立方體問題，未觀測的全突變基因型當隱藏 Steiner 節點，用各 partial read 的子面約束枚舉所有相容樹——而非把兩兩 pairwise 分開拼。分層 solver（tree_enumeration_solver.py）正是如此：實測純 partial 區全部建/枚舉出樹、約 63% 帶隱藏節點；獨立驗證器 V1–V7 全過。

4.2 用 read 數（頻率）收斂等機率樹 L1

當 solver 誠實輸出「多棵一樣好的樹」（§2 的 5,959 ambiguous）時，可用每個突變的 read 數加權：早發生的突變在更多後代細胞中 → 更多 read（pigeonhole：祖先頻率 ≥ 後代頻率）。這把「多棵等機率」變成「加權 posterior + 較可能者」，且純用 read count（遺傳訊號、非甲基、非循環）。

⚠ 兩個必須誠實標的 caveat（peer-review 揪出）：① 99.4% winner-clean 是自洽率、不是驗證——winner 本來就是依 pigeonhole 分數選出、再用同一 pigeonhole 檢查，必然幾乎全過；它證明「加權內部一致」，非「贏家生物正確」。② 「CN-clean 1,960」名不符實：實為 neutral 220 + LOH 1,639 + loss 101（loss 是缺失、read 反而變少，是相反方向 confound）；嚴格 read≈CCF 只有 strictly-neutral（~220）。且 CCF = 未經 purity/CN 校正的 ALT read fraction。真正可信 reach 應以 strictly-neutral 為準、遠小於 66.8%。

5誠實邊界（必須向審閱者標明）

🔴 CN-gain（拷貝數放大）confound L2：在被放大的區，一個突變的 read 數被拷貝數放大 → read 數 ≠ 真細胞頻率。此類佔多樹並列區的約 67%，其「贏家」不可信。現階段先假設不考慮 CNV、取整體 66.8% 為觀察值，並明確記錄此 caveat 待後續處理；真正可信 = 拷貝數乾淨區。⚠ 無 CN 資料的樣本，recurrence/CN 裁決應標 unavailable 而非預設 neutral。
🔴 甲基化 = 有界輔助，不能決定樹 L2：甲基與突變共分離主要是突變的局部順式足跡（cis-ASM，屬循環）。四配子實證：唯二「顯著」的甲基訊號全落在 cross-HP CN-gain confound，乾淨案例從不顯著。故甲基只做負向篩選 + 弱旗標，絕不進 likelihood、絕不排序樹。
⭐ 單樣本上限 ⭐3 L3：單一 bulk 只能刻畫（characterize）+ 推論（infer），不能確認（confirm）subclone；隱藏節點標 inferred。root-only 純 REF 家族不算重建出樹。突破需 single-cell / multi-region 正交真值。

6與現有工具的定位 L2

主流腫瘤演化重建多以族群層 VAF（PyClone/PhyloWGS/Pairtree）或單細胞矩陣（SCITE/Cardelino）為單位；本方法的差異在資料單位 = 單一 bulk 內的單條 ONT 分子（直接共現、非統計反推）。

6.1 深入：頻率反推 vs 直接共現（vs PhyloWGS / Canopy / CITUP）L2

這三者是同一家族——都從突變頻率（VAF/CCF）反推樹：找一個拓撲，使頻率滿足 pigeonhole/crossing rule（祖先 CCF ≥ 後代 CCF 之和）。它們不直接觀測共現，而是從頻率推論哪些突變在同一 lineage。

頻率反推（PhyloWGS / Canopy / CITUP）

觀測 = 全腫瘤平均頻率；共現與樹是統計反推。單一 bulk 的頻率欠定樹 → Canopy/CITUP 需多樣本/多區；且需拷貝數校正把 VAF 換成 CCF。

直接共現（本方法 ISM）

觀測 = 單條 ONT 分子上哪些突變在一起（直接證據，非反推）；樹由觀測到的共現枚舉。單樣本即有共現骨幹；骨幹對 CNV 較穩（共現與拷貝數無關）。

💡 關鍵洞見：pigeonhole/crossing rule 是他們唯一的樹決定機制；在我們這裡只是枚舉出候選樹之後、可選的第二層加權（見 §4.2）。所以「我們能不能做他們做的事」——能，CCF 加權層本質就是 CITUP/Pairtree 那套——但我們是加在直接共現骨幹之上，不是唯一依賴。生物 subclone 因此可推論（inferable），與他們同級，只是誠實標為推論非確認。
工具特點與本方法的關鍵差異
PhyloWGS最強在 subclonal CNV 建模（把 VAF 依拷貝數校正成 CCF）它顯式建 CNV（相對優勢）；我們的骨幹不需要 CNV 校正（共現本身 CN-robust）
Canopy需多樣本／多區 + allele-specific CN 才能鎖樹我們單樣本即有共現骨幹（不必多切片）——ONT 單分子的核心差異
CITUP從 CCF 分群枚舉相容樹拓撲（純頻率驅動）概念上最接近我們的頻率加權層；差別在我們的輸入是「共現 + 可選頻率」而非純 CCF
🔴 誠實的「相同限制」：要把跨區組成整棵樹時，單一 bulk 一樣欠定——這點我們和 Canopy/CITUP 同受限（他們用多樣本解決；我們誠實標「定不出來」+ ⭐3 封頂）。而且一旦我們啟用頻率加權，就繼承他們同樣的 CN-multiplicity confound（read ≠ CCF；即 §5 的 CN-gain caveat）。
