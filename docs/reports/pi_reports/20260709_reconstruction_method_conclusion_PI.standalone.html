Subclonal reconstruction using somatic single-molecule co-occurrence（ONT long-read）
樣本 HCC1395（ONT 5kHz + 5mCG/5hmCG tagged） 更新 2026-07-10（兩軸拓撲 + capped 相容性 + CCF 可信 reach） scope chr1–22 · ⭐3 證據分級 L1源碼/實測 L2文獻+推演 L3單樣本觀察
一句話結論：以 somatic sSNV 單分子共現 在布爾超立方體上重建腫瘤演化樹，是一個 正確、可精確枚舉、非循環的方法；它在能定的地方定樹、不能定的地方誠實回報。 這是可驗證的「區域突變狀態樹」重建——生物 subclone 可如其他工具（PhyloWGS/Canopy/CITUP）一樣推論，但單一 bulk 下是推論不是確認。 拓撲形狀確定的達 51.1%（7,046 單位）；其餘多樣性主要在「未觀測中間 clone 的排列順序」＝資訊論極限，非演算法不足。 甲基化只事後輔助、不決定樹；read 數只在拷貝數乾淨區收斂順序（可信 reach 僅 0.4–11%）。方法上限 = ⭐3（characterize + infer）。

1方法：從 sSNV 共現到演化樹 L2

每個 somatic 點突變（sSNV）是超立方體的一個座標軸；一條 ONT 長 read 直接讀出「哪些突變在同一條 DNA 分子上」——這是本方法的命脈（跨 read 拼接無法保證同分子，單分子共現可以）。

數學物件生物意義
超立方體頂點 {0,1}ⁿ一個基因型（已獲得哪些突變）
根 = 0ⁿ（全 R）germline（未突變祖先）
有向邊（翻一個 0→1）一次 infinite-sites 獲得突變
隱藏（Steiner）節點推斷的、未被直接觀測到的祖先 clone
partial read（只覆蓋部分位點）超立方體的一個「子面」約束（= IDPP，Pe'er 等 2004）
最小樹（枚舉全部）maximum parsimony 演化樹（所有等成本候選）

形式化：directed rooted (group) Steiner arborescence on Boolean hypercube = Incomplete Directed Perfect Phylogeny。逐區位點數 ≤8（涵蓋 97.5% 的區）→ 頂點 ≤256 → 暴力精確枚舉可行，不需近似。

3誠實的核心：兩軸 — 拓撲形狀 vs 順序 L2

「多候選樹」≠「多拓撲」。一個單位可能有多棵樹、但分支結構（形狀）相同，只是「哪個突變先發生（順序）」未定。分兩軸看才誠實：

軸是什麼誰來定本樣本狀況
① 拓撲形狀分支結構（鏈狀？分叉？）單分子共現（CN-independent）確定 51.1%（5,384 唯一 + 1,662 單形狀）
② 順序/方向同形狀內哪突變先read/VAF 頻率（只 CN-clean 可信）可信收斂 reach 僅 0.4–11%

✅ 拓撲形狀可精確定（51.1%）+ 密集區可驗證相容

唯一帶突變樹 5,384 + 單一形狀 1,662 = 拓撲確定 7,046（51.1%）。連 capped 密集聚集區（676）也 98.5% 通過 four-gamete 相容性檢查（無衝突 ⟺ perfect phylogeny 存在，Gusfield 定理）—— 這些區結構乾淨巢狀、樹存在，只是完整枚舉所有順序組合在計算上龐大（無必要）。

❌ 指派唯一全域樹（理論不可）

真多拓撲 31.2%（4,297 單位）＋順序未定 → 單一 bulk 無法定唯一；跨區整棵樹亦非可辨識。這是資訊論極限，非計算能力問題——「多候選／定不出來」就是精確答案。

此立場與領域一致（Tarabichi 2021 / MACH2 2024 / Pairtree）：資料不足時輸出候選集 + 不確定性，而非強行給單一樹。capped 相容性 = capped_cluster_conflict.py（four-gamete，可完整驗證）。

4本輪兩個新結論

4.1 partial-read 區的正確建樹 L1

沒有任何 read 穿越全部位點時，正確做法 = 把整區當一個超立方體問題，未觀測的全突變基因型當隱藏 Steiner 節點，用各 partial read 的子面約束枚舉所有相容樹——而非把兩兩 pairwise 分開拼。分層 solver 正是如此：純 partial 區全部建/枚舉出樹、70.5% 的樹需至少一個隱藏（推斷）祖先；獨立驗證器 V1–V7 全過（全量 V4/V5 覆蓋 95.6% 非-capped 單位、0 fail + 4,000 seeded stress 0 mismatch）。

4.2 用 read 數（頻率）收斂順序 — 但可信 reach 有限 L1

對「順序未定」用每突變 read 數（→CCF）加權：早發生的突變在更多後代細胞 → 更多 read（pigeonhole：祖先頻率 ≥ 後代）。這是軸②的收斂層，純 read count（非甲基、非循環）。但它只動順序、不動拓撲形狀。

5誠實邊界（必須向審閱者標明）

✅ 先講清楚：CN 不否定樹 L2：拓撲形狀純由共現建構、solver 不碰 CN → CN-gain 不影響、不否定樹的拓撲。「CN 不可信」只是說用 read 數決定的「順序排名」在該區不可信——樹本身有效、V1–V7 可驗證、可用。7 樣本 CN 覆蓋 5/7（HCC1395/DORADO=SEQC2、H1437/H2009/HCC1954=SAVANA；COLO829/HCC1937 purity mis-fit=unavailable）。
🔴 CN 的 3 個角色（為何需要 CN） L2：① recurrence 拆分——27 個「違反 infinite-sites」的區，CN 一查 = artifact(CN-gain) 20 + LOH 7 + 真收斂 0（無 CN 會全誤標 candidate）。② CCF 可信度——無 CN 無法圈 strictly-neutral 可信子集。③ VAF→CCF 校正——gain/loss/LOH 區 VAF 被拷貝數扭曲（和 PhyloWGS/Canopy 共有的限制）。
🔴 甲基化 = 有界輔助，不能決定樹 L2：甲基與突變共分離主要是突變的局部順式足跡（cis-ASM，屬循環）。四配子實證：唯二「顯著」的甲基訊號全落在 cross-HP CN-gain confound，乾淨案例從不顯著。故甲基只做負向篩選 + 弱旗標，絕不進 likelihood、絕不排序樹。
⭐ 單樣本上限 ⭐3 L3：單一 bulk 只能刻畫（characterize）+ 推論（infer），不能確認（confirm）subclone；隱藏節點標 inferred。root-only 純 REF 家族不算重建出樹。突破需 single-cell / multi-region 正交真值。

6.1 深入：頻率反推 vs 直接共現（vs PhyloWGS / Canopy / CITUP）L2

這三者是同一家族——都從突變頻率（VAF/CCF）反推樹：找一個拓撲使頻率滿足 pigeonhole/crossing rule。它們不直接觀測共現，而是從頻率推論哪些突變在同一 lineage。

頻率反推（PhyloWGS / Canopy / CITUP）

觀測 = 全腫瘤平均頻率；共現與樹是統計反推。單一 bulk 的頻率欠定樹 → Canopy/CITUP 需多樣本/多區；且需拷貝數校正把 VAF 換成 CCF。

直接共現（本方法 ISM）

觀測 = 單條 ONT 分子上哪些突變在一起（直接證據，非反推）；拓撲形狀由觀測共現枚舉、不需 CN 校正（共現與拷貝數無關）。單樣本即有骨幹。

💡 關鍵洞見：pigeonhole/crossing rule 是他們唯一的樹決定機制；在我們這裡只是枚舉出拓撲之後、可選的第二層「順序」加權（§4.2）。生物 subclone 因此可推論（inferable），與他們同級——但我們的拓撲骨幹是 CN-robust 的直接共現，頻率只加在其上。
🔴 誠實的「相同限制」：組跨區整棵樹時單一 bulk 一樣欠定——這點我們和 Canopy/CITUP 同受限（他們用多樣本解；我們誠實標「定不出來」+ ⭐3）。且一旦啟用頻率加權，就繼承同樣的 CN-multiplicity confound（read ≠ CCF；即 §5 的 CN-gain caveat）。
