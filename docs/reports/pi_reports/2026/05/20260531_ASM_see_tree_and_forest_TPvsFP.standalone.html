甲基化 × HP × somatic — 個案排序 + 大規模統計 + FP 特殊現象

全基因組 per-site ASM（genome_survey_v2, 51,171 TP + 5,150 FP records）。HP-axis（HP1 vs HP1-1，somatic-controlled 乾淨軸）為主結論；ALLELE-axis 因 baseline allelic 甲基化 confound 僅列不下結論。每數字本 session 親自重算。

核心：甲基差異 per-site 可清楚定位 + 排序，但「差異越清楚」常常是 FP 的 artifact。 HP-axis strong-ASM 僅 57/23,771（0.34%）。FP 的 strong-ASM 是低 coverage（½ n_cpg）+ 極端 baseline（2× extremity）+ 92% 在 LOH 的雜訊膨脹 — 非真生物。這就是為何 ASM 真實卻 anti-discriminative（不能判別 TP/FP）。

FP 特殊現象 = 雜訊膨脹三連（低 coverage + 極端 baseline + LOH） FP 的「清楚 ASM」不是真生物訊號，而是 regression-to-mean artifact：在 LOH 區（92%）+ germline 甲基化飽和（~0.82, 27% 極端）+ CpG 覆蓋只剩一半（n_cpg 50 vs 102）的情況下，somatic-haplotype reads 的甲基估計噪大且從極端值回歸 → 產生看似大的 \|Δβ\|（多為 hypo），但本質是測量噪 + 統計回歸，非 allele-specific 生物現象。
對照 — TP 的 ASM 較可信 TP-strong 有 2× coverage（n_cpg 102）+ 中段 baseline（0.586，非飽和）+ 多為 nonLOH（64%）。BRCA2（n_cpg 197, germ 0.234 中低, nonLOH）正是 TP-side 可信 ASM 的典範。

§4機制結論 — 對你研究目標的回答

  • 能清楚定位 + 排序甲基差異（見樹）：✅ per-site Δβ 從 −0.61 到 +0.67 全可定位排序，BRCA2/extreme/canonical/FP 各類清楚。
  • 能大規模統計確認整體（見林）：✅ 漏斗 23,771→57 strong；方向無偏好；effect-size 核心抗 13-test confound。
  • FP 有清楚可辨的特殊現象：✅ 低 coverage + 極端 baseline + 92% LOH + 表面大 \|Δβ\| → 是雜訊膨脹，非真生物。
  • 但「差異清楚」≠「位點有利」：最大的 ASM（−0.613）是 FP；strong-ASM 在 FP 富集 5×。所以 ASM 真實可定位，但不能當 somatic/TP 判據（anti-discriminative 已被機制解釋）。
可操作的「可信 ASM」篩選準則（從 TP vs FP 差異導出） 若未來要挑「可信的 per-site ASM」位點，應加門檻：n_cpg ≥ ~100（高 coverage）+ germline baseline 非極端（0.5±0.3 內）+ 優先 nonLOH，並對 LOH 位點標 caveat。BRCA2 符合全部 → 可信 anchor；chr8 FP 群全部不符 → 應排除。
