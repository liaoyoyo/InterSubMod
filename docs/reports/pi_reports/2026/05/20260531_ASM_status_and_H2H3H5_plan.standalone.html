§3三個待驗假設 — 要驗什麼 + 方法依據

H2 scout 中 濾掉 artifact 後，乾淨 regime（78 位點）的真 ASM 跨 7 樣本是否一致？
→ 確認「真 ASM」是不是真現象（雖稀有）。方法依據：cross-sample 一致性是黃金標準。關鍵風險：其他 6 樣本可能沒有 MSA 甲基 ASM 數據（只有 phasing），若需 6 個 MSA rerun (~100GB BAM each) 則今晚 BLOCKED — scout 正在確認；若 blocked 改 within-sample bootstrap/chr-split proxy + 標 partial。
H3 scout 中 LOH regime 的「ASM」是不是其實是 CNV？
→ LOH 區物理上單 haplotype，HP1-vs-HP1-1 比較可能混入 copy-number/loss 而非甲基化。方法依據：充分 — 若 ASM 是 CNV artifact 則 Δβ 應隨 CN 系統性變化（Spearman + 分層 Kruskal-Wallis）；若真甲基則與 CN 無關。資料：HCC1395 有 SEQC2 CNV truth（gain/loss/cnLOH）。可行性高（既有單樣本數據）。
H5 scout 中 「可信 ASM 篩選準則」能否把 ASM 從 anti-discriminative 救成 neutral？
→ 用 \|Δβ\| 預測 is_TP 的 AUC：全部 vs 只 credible regime，看 AUC 是否從 <0.5 升到 ~0.5+。方法依據：對齊 auc-confound-guard（permutation null + within-coverage-bin 控制）。可行性高（既有數據）。風險：credible regime n=78 算 AUC 樣本偏小 → 須報 CI/permutation。
方法學自審（用戶要求的「是否有觀察依據 + 合理分析支持」） H3/H5 = 既有單樣本 HCC1395 數據可做，方法有充分依據（CN 分層 / AUC+confound-guard）。H2 跨樣本是黃金標準但可能卡資料（6 樣本 MSA ASM 是否存在）— 這是 workflow scout 階段優先確認的，避免盲目啟動 6×100GB BAM 重算。所有結論將標單樣本 partial flag（除非 H2 跨樣本資料齊）。
