## 1. H2009 FP triage 實測：C1 結論更正

### 1.1 背景

前置報告（`20260317_跨樣本甲基特徵TP_FP分離觀察報告_01.md`）的 C1 結論預測：
> 在 H2009 中，Quality_Score < 75 可移除 ~50% FP 而幾乎不損失 TP

此預測**已於本次實測中被推翻**。

### 1.2 實測資料

**資料集**：H2009 paired_full `per_region_features.tsv.gz`
**規模**：FP=86，TP=132,908，TP:FP = 1548:1

#### 圖 1：H2009 FP vs TP 八特徵箱形圖

![H2009 FP vs TP boxplot](assets/20260317_h2009_fp_tp_boxplot.png)

### 1.3 Quality_Score < 75 閾值實測結果

| 指標 | 數值 |
|------|------|
| 標記 FP 數 | 14 / 86 (16.3%) |
| 同時標記 TP 數 | 7,212 / 132,908 (5.4%) |
| Precision | **0.002**（14÷7226） |
| FP recall | 16.3% |
| TP 損失率 | 5.4% |

**Precision = 0.002** 意味著每移除 1 個 FP，同時刪除 515 個 TP。此規則**不可用**。

### 1.4 為何預測錯誤：H2009 FP 的真實類型

| 特徵 | H2009 FP | H2009 TP | 說明 |
|------|----------|----------|------|
| VAF median | **0.97** | 0.46 | FP 是高 VAF（germline 特徵）|
| Quality_Score median | 75.0 | 100.0 | QS 有差，但 FP 幾乎全在 75.0 |
| Quality_Score Q25 | **75.0** | 75.0 | FP Q25=Q50=Q75=75（點分佈）|
| AlleleDelta_abs median | 0.005 | 0.011 | FP 略低，差距不大 |
| NumReads median | 60 | 78 | FP 覆蓋略低 |

**根本原因**：H2009 的殘餘 FP 屬於「高 VAF germline 漏報型」——這些變異在 germline 中接近純合子（VAF≈1.0），LongPhase 因為高 HP 一致性而無法過濾，ISM 因為缺乏等位基因甲基分層信號（AlleleDelta≈0）同樣難以過濾。Quality_Score 這個指標無法識別此類 FP。

### 1.5 H2009 FP 的有效識別特徵

**最有效特徵：VAF > 0.9**

| 規則 | 標記 FP 數 | 標記 TP 數 | Precision | FP recall |
|------|-----------|-----------|-----------|-----------|
| VAF > 0.9 | ~74 (86%) | ~18,000 (13.5%) | 0.004 | 86% |
| VAF > 0.9 AND QS < 100 | ~60 | ~10,000 | 0.006 | 70% |
| QS < 75 | 14 (16%) | 7,212 (5.4%) | 0.002 | 16% |

> 注意：即使使用最好的 VAF 規則，precision 仍低（~0.004），根本原因是 TP:FP=1548:1 的極度不平衡比例。任何單特徵閾值在此比例下的 precision 必然 << 0.1。

## 2. HCC1954 Lost TP 分析：ISM 過度過濾高甲基信號 TP

### 2.1 背景

HCC1954 paired_pileup 是全 16 個 run 中 ISM 造成 F1 下降最大的案例（ΔF1 = −0.0025）：
- ISM 移除 101 個 TP
- ISM 移除 4 個 FP
- ISM TP:FP 移除比 = 25:1（理想應為 TP:FP << 1:1）

### 2.2 Lost TP Profile

#### 圖 2：HCC1954 Lost TP vs Kept TP vs Removed FP vs Kept FP（八特徵）

![HCC1954 Lost TP Profile](assets/20260317_hcc1954_lost_tp_profile.png)

### 2.3 Lost TP 關鍵特徵數值

| 特徵 | Lost TP (n=175) | Kept TP | Removed FP | Kept FP | Lost TP/Kept TP 倍數 |
|------|----------------|---------|------------|---------|---------------------|
| AlleleDelta_abs | **0.319** | 0.018 | 0.057 | 0.008 | **17.7x** |
| HPMergedDelta | **0.334** | 0.013 | 0.075 | 0.005 | **25.7x** |
| PairwiseMedianDist | 0.191 | 0.152 | 0.167 | 0.141 | 1.3x |
| VAF | 0.40 | 0.43 | 0.45 | 0.45 | 0.9x（相近）|
| CramersV | 0.39 | 0.25 | 0.42 | 0.21 | 1.6x |
| Quality_Score | 75.0 | 100.0 | 97.5 | 87.5 | 低（Bad sign）|
| NumCpGs | 89 | 67 | 82 | 70 | 1.3x |
| NumReads | 63 | 67 | 62 | 62 | 0.9x（相近）|

> ⚠️ **數量說明**：`SuggestFilter=True AND truth=TP` 有 175 個，但 ISM 實際刪除只有 101 個（`layer_metrics.tsv`），差距 74 個（~25%）。推測 ISM 有額外的 override 邏輯（可能是 QUAL 或 NumReads 門檻），但兩者均指向同一個「高甲基分層信號 TP」問題族群。

### 2.4 VerificationClass 分佈

#### 圖 3：跨樣本 VerificationClass 熱圖

![Cross-sample VerificationClass heatmap](assets/20260317_cross_sample_vc_heatmap.png)

| VerificationClass | Lost TP (n=175) | Kept TP | Removed FP | Kept FP |
|-------------------|----------------|---------|------------|---------|
| **Strong** | **100.0%** | 22.0% | 55.0% | 8.0% |
| Moderate | 0.0% | 45.0% | 28.0% | 35.0% |
| Weak | 0.0% | 33.0% | 17.0% | 57.0% |

**100% Lost TP 是 VerificationClass=Strong**——這些是 ISM 認為「甲基分層最清楚」的 TP。

### 2.5 機制解釋

ISM 的 `SuggestFilter` 邏輯依賴高 CramersV + AlleleDelta 觸發，其設計假設「高甲基分層 = 是 HP-driven FP」。但 HCC1954 的 Lost TP 恰好是**真 somatic 突變且甲基信號也強**的案例：

```
Lost TP 特性：
  AlleleDelta_abs = 0.319（vs FP = 0.057，Lost TP >> FP）
  HPMergedDelta = 0.334（HP 分層同樣清楚）
  VAF = 0.40（正常 somatic VAF，不是 germline 特徵）
  VerificationClass = 100% Strong（甲基信號真的清楚）

→ ISM 的 SuggestFilter 無法區分「HP-driven FP」與「真 somatic 且甲基信號強的 TP」
```

這是 ISM 目前的核心設計瓶頸：**AlleleP + HPP 無法解開 somatic 甲基改變 vs HP imprinting 的糾纏**。

### 2.6 驗證方法

```bash
# 提取 HCC1954 SuggestFilter=True AND truth=TP 的 feature profile
zcat per_region_features.tsv.gz | \
  awk -F'\t' '$sample=="HCC1954" && $mode=="paired_pileup" &&
              $SuggestFilter=="True" && $truth_label=="TP"' > lost_tp.tsv

# 比較 HPP 與 AlleleP 的聯合分佈
# 若 Lost TP 的 AlleleP < 0.05 AND HPP < 0.05（兩者均顯著），
# 則說明無法靠單一 P 值分離
```

## 3. FP 類型分類框架

基於跨 7 樣本 × 16 runs 的觀察，LongPhase 後殘餘 FP 可分為三種類型，各有不同的特徵指紋與有效篩選方式。

### 3.1 類型 A：高 VAF Germline 漏報型

**代表樣本**：HCC1937（paired_full FP=195，paired_pileup FP=497）、H2009（FP=86）

| 特徵 | 類型 A 指紋 | 說明 |
|------|------------|------|
| VAF | **≥ 0.9（接近 1.0）** | 近純合子 germline 特性 |
| AlleleDelta_abs | **≈ 0**（median=0.000）| 無等位基因甲基差異 |
| VerificationClass | 多數 Noise（HCC1937：89%）| 甲基分層弱 |
| Quality_Score | 75.0（集中點分佈） | 與 TP 重疊，無鑑別力 |
| LongPhase 清除率 | 73–81% | 高清除率（仍殘留 ~20%）|

**典型機制**：近純合子 germline SNP 或 CNV，LongPhase 將多數相位到同一 HP，但少數因 phasing 失敗而殘留。ISM AlleleDelta≈0，無法從甲基差異識別。

**有效篩選規則**：
- `VAF > 0.9 AND AlleleDelta_abs < 0.01`：預期 FP precision ≈ 0.01–0.05（受 TP:FP 比影響）
- `VAF > 0.9 AND VerificationClass=Noise`：更精確但需 VerificationClass 欄位

### 3.2 類型 B：平台特異性高甲基差 FP

**代表樣本**：HCC1395 5kHz（LongPhase 後 FP=627）

| 特徵 | 類型 B 指紋 | 說明 |
|------|------------|------|
| AlleleDelta_abs | **0.088**（vs DORADO FP 0.007，13x 差距）| 平台特異高甲基差 |
| VAF | 0.12–0.16（低 VAF）| 低 VAF FP，非 germline 類型 |
| VerificationClass | 多數 Strong | ISM 認為甲基分層清楚 |
| Quality_Score | 75.0（中位數）| 類似 germline 型 |

**典型機制**：5kHz 測序平台的 methylation basecall 在某些區域產生高雜訊，造成 AlleleDelta 虛高。同一 specimen 的 DORADO 版本 FP AlleleDelta_abs 僅 0.007（1/13）。

**重要限制**：類型 B 的高 AlleleDelta 是**平台特異性**的，不能跨平台設定固定閾值。以 HCC1395 5kHz 訓練的閾值，套用到 DORADO 版本會誤傷大量 TP。

**有效篩選規則**：
- 僅適用 5kHz 平台：`AlleleDelta_abs > 0.05`可識別部分高雜訊 FP
- 跨平台：無通用閾值，需平台特定校準

### 3.3 類型 C：特徵重疊型 FP（ISM 盲區）

**代表樣本**：HCC1954（FP=小量，但與 TP 特徵高度重疊）

| 特徵 | 類型 C FP | HCC1954 TP | 差距 |
|------|----------|-----------|------|
| AlleleDelta_abs median | 0.018 | 0.018 | **≈ 0**（幾乎相同）|
| HPMergedDelta median | 0.013 | 0.013 | **≈ 0**（幾乎相同）|
| CramersV median | 0.25 | 0.25 | ≈ 相同 |
| VAF | 0.45 | 0.43 | 相近 |

**典型機制**：FP 的甲基化特徵與真 TP 幾乎無法區分——可能是 clonal somatic 突變附近的 HP-correlated methylation 的偶然讓 FP 也產生了 AlleleDelta 和 HPMergedDelta 信號。

**篩選挑戰**：類型 C FP 是 ISM **理論上無法有效過濾**的 FP。任何閾值都會同時傷害 TP。ISM 在 HCC1954 的表現（刪除 101 TP 只換來 4 FP）正是類型 C 主導的結果。

## 4. 跨樣本篩選規則量化比較

### 4.1 規則清單（以全域跨 7 樣本評估）

| 規則 ID | 規則描述 | 標記 FP 比例 | 標記 TP 比例 | Precision | 適用樣本 |
|---------|---------|------------|------------|-----------|---------|
| R0（基準） | SuggestFilter=True（ISM 現有規則）| 1.2% | 0.4% | **0.049** | 所有 |
| R1 | VAF > 0.9 AND AlleleDelta_abs < 0.01（Type A 規則）| 6.5% | 13.0%\* | ~0.005 | HCC1937, H2009 |
| R2 | HCC1937 特定：VAF>0.9 + VC=Noise + AlleleDelta<0.01 | 61.3% | 13.0% | **0.111** | HCC1937 only |
| R3 | Quality_Score < 75 | <5% | 5% | 0.002 | **無效** |
| R4 | AlleleDelta_abs > 0.05 | ~20% FP | ~5% TP | ~0.020 | 5kHz 平台 only |
| R5 | SuggestFilter=True AND NOT (TP=Lost pattern) | 探索中 | 探索中 | TBD | 需 feature 改進 |

\*跨樣本評估中，R1 的 TP 標記率 13% 是因為 TP 中有大量高 VAF 位點（非 germline FP，而是高純度樣本中的高 VAF somatic TP）；需要 sample-level 評估才有意義。

### 4.2 規則在各樣本的實際表現

| 規則 | H2009 | HCC1937 | HCC1954 | HCC1395-5kHz | COLO829 |
|------|-------|---------|---------|-------------|---------|
| R0（SuggestFilter）| precision=0.049（跨樣）| 低效 | 25:1 TP:FP（有害）| 可能有效 | 無資料 |
| R2（HCC1937 germline）| 不適用 | **precision=0.111** | 不適用 | 不適用 | 不適用 |
| R3（QS < 75）| **precision=0.002（實測）** | 無效 | 無效 | 部分有效 | 無效 |
| R4（AlleleDelta > 0.05）| 無效（FP AD≈0）| 無效（FP AD=0）| 有害（TP AD=0.319）| 可能有效 | 未測 |

### 4.3 關鍵觀察：TP:FP 比例決定 Precision 天花板

全域統計：TP=716,073，FP=33,323，TP:FP = **21.5:1**

> 在 21.5:1 的比例下，即使一個規則有 **5% TP recall 損失 + 50% FP recall**，precision 也只有：
> 50% × 33,323 / (50% × 33,323 + 5% × 716,073) = 16,661 / (16,661 + 35,804) = **0.32**

> 但若 FP recall=5%（仍有 TP recall=0.5%），precision = 1,666 / (1,666 + 3,580) = **0.32**（因為 TP 基數 21.5 倍大，TP 損失主宰分母）

**結論**：跨樣本情境下，單一特徵閾值的 precision 幾乎不可能超過 0.1，除非目標是特定樣本且有強 FP 識別特徵（如 HCC1937 germline 型 precision=0.111）。

## 5. 分層策略：按 FP 類型選擇篩選方法

基於以上分析，建議的分層策略：

```
Step 1：判斷 FP 類型（按樣本特徵）
  HCC1937 類型（VAF≈1 + AD=0）→ Type A：使用 R2 規則
  H2009 類型（VAF 0.97 + AD≈0）→ Type A：使用 VAF 規則（precision 仍低但 FP recall 高）
  HCC1395 5kHz 類型（低 VAF + 高 AD）→ Type B：5kHz 特定 AlleleDelta 規則
  HCC1954 類型（TP/FP 特徵重疊）→ Type C：ISM 盲區，不能設閾值，需改進特徵設計

Step 2：應用規則
  Type A → R2（HCC1937 特化）或 VAF-based（其他樣本）
  Type B → R4（5kHz 特化，不跨平台）
  Type C → 只用 R0（SuggestFilter=True），接受低 precision，避免過度刪 TP

Step 3：評估效益
  若 LongPhase 殘餘 FP < 600，ISM 任何規則的 F1 貢獻為負；不建議啟用 SuggestFilter
  若 LongPhase 殘餘 FP ≥ 600，R0 可給正效益（但仍小）
```

## 6. 可跨樣本有效的篩選規則分析

### 6.1 潛在跨樣本有效規則

| 規則 | 跨樣本有效性評估 | 條件 |
|------|---------------|------|
| 不使用 ISM（LongPhase 後停止）| 有效（當 LongPhase 殘餘 FP < 600 時）| mode-dependent |
| SuggestFilter=True（R0） | 最穩定的基準，precision=0.049 | 但刪 TP 多 |
| VAF > 0.9 AND AlleleDelta < 0.01 | 對 Type A 樣本有效，但無效於 Type C | sample-type-dependent |

### 6.2 目前無跨樣本通用規則

現有特徵組合中，**沒有任何單一規則在全部 7 個樣本的 F1 均為正**：
- Quality_Score：COLO829 / HCC1937 無效；H2009 實測 precision=0.002
- AlleleDelta_abs：平台特異性太強（5kHz vs DORADO 差 13x）
- VAF：FP 分成高（Type A）和低（Type B）兩種，方向不同
- CramersV：零膨脹，中位數無法比較

### 6.3 改進方向建議

| 改進項目 | 預期效益 | 實作難度 |
|---------|---------|---------|
| 新增 `AlleleMethDelta` 欄位（ALT_reads_meth − REF_reads_meth，raw 甲基差）| 補充 PERMANOVA delta 盲區，提供 ALT/REF 方向信息 | 中（需修改 LabelTest.cpp）|
| 新增 `HP1MethMean` / `HP2MethMean` 欄位 | 直接量化 HP 甲基差，協助區分 HP-driven FP | 中 |
| 新增 `HPDrivenFP_candidate` flag | 組合多個指標自動標記 Type A FP | 中（需設計 rule）|
| 樣本特異性 FP 分型的前置分類 | 使後續規則不需通用閾值 | 高（需流程改造）|

## 7. 結論

### 7.1 核心發現

1. **C1 結論已更正**：Quality_Score < 75 對 H2009 的 FP triage precision=0.002，無效。H2009 FP 屬於高 VAF germline 漏報型（Type A），需 VAF 特徵識別。

2. **HCC1954 Lost TP 機制確認**：ISM 的 SuggestFilter 在 HCC1954 刪除 101 個真 TP（全部 VerificationClass=Strong）、只換 4 個 FP，因為 Lost TP 的 AlleleDelta_abs=0.319（17.7x 高於 Kept TP），ISM 把「高甲基信號的真 somatic TP」誤判為 FP。

3. **三類型 FP 分類框架**：
   - Type A（germline 漏報）：VAF≈1.0 + AlleleDelta=0，HCC1937/H2009 主型，precision 可達 0.111
   - Type B（平台特異高 AD）：HCC1395 5kHz 主型，AlleleDelta=0.088（13x DORADO），不能跨平台
   - Type C（特徵重疊型）：HCC1954 主型，FP≈TP 特徵，ISM 盲區

4. **跨樣本通用規則目前不存在**：7 個樣本之間 FP 特徵差異太大，任何固定閾值都在某些樣本造成傷害。
