## 2. Quality_Score 箱形圖有效性詳析

### 2.1 全域結論

**全域 Quality_Score 是最可靠的 TP/FP 分離指標**（std_delta=+0.800，TP median=95，FP median=75），但存在重要的 sample/mode dependency：

```
有效（std_delta > 0.5）：H2009, H1437（pileup）, HCC1954
有效但弱（std_delta 0.1–0.5）：HCC1395（pileup）, HCC1395_DORADO
無效（std_delta ≈ 0）：COLO829, HCC1937, to_pileup 所有 runs
```

### 2.3 Quality_Score 箱形圖的三種模式

**模式 A（有效）**：H2009、H1437(pileup)、HCC1954

```
TP: ─────[====|====]─  （median 高、IQR 上偏）
FP: ─[====|===]──────  （median 低、IQR 也偏低）
```

箱型不重疊或重疊少。建議在這些 sample/mode 可考慮 soft threshold（如 Quality_Score < 75 → FP 風險提示）。

**模式 B（弱/無效）**：HCC1395（paired），COLO829，HCC1937

```
TP: ─[====|====]──
FP: ─[===|====]───  （中位數相同，箱型高度重疊）
```

不可作為分離依據。

**模式 C（to_pileup 完全無效）**：HCC1395(TO)、HCC1395_DORADO(TO)

- 兩組中位數均為 75.0，IQR 高度重疊
- TO 模式 FP 主要是高置信度 germline，QUAL 分數本身就高，Quality_Score 無法區分

### 2.4 COLO829 Quality_Score 異常低（特殊現象）

⚠️ **COLO829 的 TP median Quality_Score=60.0**，而其他所有 sample 的 TP median 均 ≥ 75.0（多數為 85–100）。

| Sample | Platform | TP QS median | FP QS median |
|--------|---------|-------------|-------------|
| H2009 | ONT_Google_5mCG | 100.0 | 75.0 |
| H1437 | ONT_Google_5mCG | 100.0 | 82.5–97.5 |
| HCC1954 | ONT_Google_5mCG | 100.0 | 87.5–95.0 |
| HCC1937 | ONT_Google_5mCG | 75.0 | 75.0 |
| HCC1395 | ONT_5kHz | 85.0 | 75.0–85.0 |
| HCC1395_DORADO | ONT_Dorado | 85.0 | 75.0 |
| **COLO829** | **ONT_PAO_5mCG** | **60.0** | **50.0–60.0** |

COLO829 使用的是 ONT_PAO_5mCG 平台（不同於其他樣本的 ONT_5kHz 或 ONT_Google_5mCG）。Quality_Score 整體偏低可能反映：
1. PAO 平台的 basecall 品質分數校準方式不同
2. 或 COLO829 melanoma 特有的基因組複雜性造成讀段品質下降
- **結論**：Quality_Score 在 COLO829 完全無 TP/FP 分離能力，且整體分數偏低，是平台或樣本特異性現象，需排除在跨樣本統計解讀之外

### 特殊現象 S1：HCC1937 FP 呈現純 germline-origin 模式

#### 3.1.1 觀察

HCC1937 的殘餘 FP（LongPhase 後）在 VAF 上呈現接近純合子的分佈（median≈1.0），同時 AlleleDelta_abs 中位數完全為 0。這兩個指標的組合在全部 16 個 run 中是唯一的。

#### 3.1.2 資料來源與數值計算

**來源**：`data/feature_summary.tsv`，`grouping=run_truth`，`sample=HCC1937`

| Feature | HCC1937:paired_full FP | HCC1937:paired_pileup FP | 來源欄位 |
|---------|----------------------|------------------------|---------|
| VAF median | **1.0000** | **0.9597** | `median` |
| VAF Q25 | 0.9754 | 0.1429 | `q25` |
| VAF Q75 | 1.0000 | 1.0000 | `q75` |
| AlleleDelta_abs median | **0.0000** | **0.0000** | `median` |
| AlleleDelta_abs mean | 0.00352 | 0.00779 | `mean` |
| n_FP | 195 | 497 | `n` |

**對比 HCC1937 TP 的同欄位**：

| Feature | HCC1937:paired_full TP | HCC1937:paired_pileup TP |
|---------|----------------------|------------------------|
| VAF median | 0.3684 | 0.3258 |
| AlleleDelta_abs median | 0.0099 | 0.0100 |

**差距量化**：VAF delta = 1.0000 − 0.3684 = **+0.632**（paired_full），是全 16 個 runs 中 VAF TP/FP delta 最大的樣本。

#### 3.1.3 替代解釋排除

| 替代解釋 | 排除理由 |
|---------|---------|
| FP 是低品質呼叫（隨機雜訊） | 排除：隨機雜訊的 VAF 應呈低值或分散分佈；HCC1937 FP VAF Q25=0.975（幾乎全部>0.97），不符合雜訊特性 |
| FP 是高純度腫瘤的真實 somatic | 排除：若是真 somatic，AlleleDelta_abs 應 > 0（有 ALT vs REF 甲基差異）；但 FP median=0.000，mean=0.0035，顯示無甲基等位基因差異 |
| 資料集特有的 benchmark 問題 | 可能性存在，但 paired_full 與 paired_pileup 兩個 mode 方向一致（VAF median 分別 1.000 和 0.960），排除單一模式的 caller artifact |

#### 3.1.4 驗證方法

```bash
# 從 per_region_features.tsv.gz 提取 HCC1937 FP，
# 查看 VAF > 0.9 的 FP 所在 region 是否對應 known imprinting region 或 CN-altered region
zcat per_region_features.tsv.gz | awk -F'\t' '$sample=="HCC1937" && $truth=="FP" && $VAF > 0.9' \
  | bedtools intersect -a stdin -b known_imprinting_regions.bed -u
```

或人工：取 HCC1937 paired_full FP 中 VAF>0.95 的 top 20 位點，查閱 UCSC/ENCODE germline 資料庫或 GIAB high-confidence germline region。

#### 3.1.5 信心等級

**信心：高（三個獨立特徵一致支持）**
1. VAF≈1.0（兩個 mode 一致）
2. AlleleDelta=0（兩個 mode 一致）
3. VerificationClass Noise 佔 89%（來自 `verification_class_summary.tsv`）
4. LongPhase 清除率 73–81%（germline 具有相位一致性）

### 特殊現象 S2：HCC1954 paired_pileup InterSubMod 損失 101 TP 僅移除 4 FP

#### 3.2.1 觀察

HCC1954 的 LongPhase→InterSubMod 步驟造成 F1 下降 0.0025，是全 16 個 run 中下降最大的案例。核心問題是：ISM 移除了 101 個 TP，但只移除了 4 個 FP。

#### 3.2.2 資料來源與數值計算

**來源**：`data/layer_metrics.tsv`（transition 數字）+ `data/feature_summary.tsv`（feature 分佈）

**F1 計算追蹤**（以 `layer_metrics.tsv` 為基礎）：

```
HCC1954:paired_pileup
  LongPhase F1 = 0.9083  → TP_LP, FP_LP 對應原始數字
  ISM F1 = 0.9058  → dFP = +4, dTP = -101
  F1 下降 = 0.9058 - 0.9083 = -0.0025
```

**feature_summary.tsv 驗證 FP-TP 重疊**：

| Feature | HCC1954:pileup FP | HCC1954:pileup TP | 差距 | 信心 |
|---------|------------------|------------------|------|------|
| AlleleDelta_abs median | **0.0182** | **0.0184** | 0.0002 | ⚠️ 幾乎相同 |
| AlleleDelta_abs mean | 0.0433 | 0.0311 | −0.0122 | FP 均值略高 |
| CramersV median | 0.000 | 0.000 | 0 | 無差異 |
| HPMergedDelta median | 0.00785 | 0.0132 | +0.005 | 略有差距 |
| NumCpGs median | **103.0** | **68.0** | **−35（FP 高 51%）** | ⚠️ FP 在高 CpG 區 |
| NumReads median | 66.0 | 66.0 | 0 | 完全重疊 |

**關鍵推論**：AlleleDelta_abs 在中位數層面幾乎完全重疊（0.0182 vs 0.0184），ISM 無法基於此特徵分離 FP 與 TP。

#### 3.2.3 替代解釋排除

| 替代解釋 | 排除理由 |
|---------|---------|
| ISM 參數設置問題（可調整閾值修正） | 部分成立：但即使調整，AlleleDelta 完全重疊意味著任何 delta-based threshold 都會同時刪除 FP 和 TP |
| 這些 TP 是「弱訊號 TP」，被刪除可接受 | 排除：HCC1954 的 TP AlleleDelta_abs median=0.0184 與全域 TP median=0.0105 相近，不是特別弱；損失量（101 TP）相對於 FP 移除（4 FP）比例懸殊 |
| benchmark 問題（這些「TP」實際上是假TP） | 無法從特徵層面排除；但 LongPhase 後這些 TP 已通過相位驗證，低可能性是偽 TP |

#### 3.2.4 驗證方法

1. 列出 HCC1954 paired_pileup 被 ISM 刪除的 101 個 TP（LongPhase 有但 ISM 刪除）的 feature profile
2. 與同 sample 中 ISM 保留的 TP 比較：被刪除的 TP 有哪些 feature 偏向 FP 端？
3. 檢查 ISM 刪除的 TP 是否集中在高 NumCpGs region（>100），確認是否是 CpG 密度閾值設計的副作用

#### 3.2.5 信心等級

**信心：高（F1 數字來自 layer_metrics.tsv 直接計算，feature 重疊由 feature_summary.tsv 數值確認）**

### 特殊現象 S3：HCC1395 5kHz 與 DORADO 同一 specimen 的 FP AlleleDelta 相差 13 倍

#### 3.3.1 觀察

HCC1395 5kHz 的 FP（LongPhase 後殘餘）AlleleDelta_abs 中位數 = 0.0883，而 DORADO 版本的 FP AlleleDelta_abs 中位數 = 0.0068。相差 13 倍。兩者使用的是同一個 biological specimen 和同一個 SEQC2 truth set。

#### 3.3.2 資料來源與數值計算

**來源**：`data/feature_summary.tsv`，`grouping=run_truth`

**LongPhase 後殘餘 FP 的特徵（paired_full 模式）**：

| Feature | HCC1395 5kHz FP（n=627） | HCC1395_DORADO FP（n=240） | 比值/方向 |
|---------|------------------------|--------------------------|---------|
| AlleleDelta_abs median | **0.0883** | **0.0068** | **13x 差距** |
| AlleleDelta_abs Q25 | 0.0294 | 0.0000 | 5kHz FP Q25 > DORADO median |
| HPMergedDelta median | **0.0238** | **0.0000** | 方向完全不同 |
| VAF median | 0.1562（**低 VAF**） | 0.5933（**中高 VAF**） | 方向相反 |
| PairwiseMedianDist median | 0.2307 | 0.1342 | +72% |

**比較基準（同 specimen 的 TP）**：

| Feature | HCC1395 5kHz TP（n=29,740） | HCC1395_DORADO TP（n=29,883） |
|---------|--------------------------|--------------------------|
| AlleleDelta_abs median | 0.0181 | 0.0171 |
| VAF median | 0.4324 | 0.4394 |

**關鍵計算**：
- 5kHz FP AlleleDelta = 0.0883，是 5kHz TP 的 4.9 倍（0.0883/0.0181）
- DORADO FP AlleleDelta = 0.0068，是 DORADO TP 的 0.4 倍（比 TP 還低）
- 這表示 5kHz FP 在甲基等位基因差異上「超過」了 TP，而 DORADO FP 沒有

#### 3.3.3 替代解釋排除

| 替代解釋 | 排除理由 |
|---------|---------|
| 5kHz FP 樣本數少（627），可能有抽樣偏差 | 排除：627 是足夠的樣本量；且 paired_pileup 也呈現類似模式（FP AlleleDelta median=0.056，n=1253） |
| SEQC2 truth set 差異造成 | 排除：兩個版本使用完全相同的 SEQC2 truth set（同一 biological specimen） |
| 這些 5kHz FP 其實是「真的 somatic TP 被 truth set 錯標」 | 此假說需進一步驗證（5kHz FP 在 DORADO 上是否呼叫？）；但就現有分析，它們仍按 SEQC2 label 為 FP |

#### 3.3.4 驗證方法

1. 取 HCC1395 5kHz FP AlleleDelta > 0.05 的位點（前 20%），查看這些位點在 DORADO 的呼叫狀態
2. 若這些位點在 DORADO 也呼叫為 FP（相同 SEQC2 判定）→ 確認是 platform artifact
3. 若這些位點在 DORADO 呼叫為 TP 或未呼叫 → 更複雜的 truth set 問題

#### 3.3.5 信心等級

**信心：高（同一 specimen 的直接對比，樣本量充足，paired_full 與 paired_pileup 兩個模式一致）**
⚠️ 機制推論（platform artifact）的信心為中等（尚未確認 5kHz FP 在 DORADO 的狀態）

### 特殊現象 S4：to_pileup 模式下 QUAL 方向逆轉（FP > TP）

#### 3.4.1 觀察

在 paired 模式下，所有 runs 的 TP QUAL 均高於 FP QUAL（差距 8–10 分）。但在 to_pileup 模式下，FP QUAL **高於** TP QUAL。這個逆轉在 5kHz 和 DORADO 兩個 to_pileup runs 中一致出現。

#### 3.4.2 資料來源與數值計算

**來源**：`data/feature_summary.tsv`，`grouping=run_truth`，`feature=QUAL`

**配對模式 QUAL 分佈（paired full model）**：

| Run | TP QUAL mean | FP QUAL mean | TP QUAL median | FP QUAL median | TP−FP 差 |
|-----|-------------|-------------|---------------|---------------|---------|
| HCC1395:paired_full | 20.52 | 12.73 | 21.19 | 11.85 | **+9.34** |
| H1437:paired_full | 21.45 | 12.13 | 21.98 | 11.51 | **+10.47** |
| H2009:paired_full | 21.40 | 12.60 | 22.02 | 12.05 | **+9.97** |

**to_pileup QUAL 分佈（逆轉）**：

| Run | TP QUAL mean | FP QUAL mean | TP QUAL median | FP QUAL median | TP−FP 差 |
|-----|-------------|-------------|---------------|---------------|---------|
| HCC1395:to_pileup | 19.45 | **19.99** | 19.58 | **19.88** | **−0.30（逆轉）** |
| HCC1395_DORADO:to_pileup | 19.59 | **20.11** | 19.63 | **19.98** | **−0.35（逆轉）** |

**推算 FP 來源**：
- HCC1395 to_pileup FP VAF median = 0.6494（中高），n=11,601
- HCC1395_DORADO to_pileup FP VAF median = 0.6573（中高），n=11,572
- 高 VAF FP → germline 變異；germline 有高 QUAL 是合理的（高覆蓋、高置信度）

#### 3.4.3 替代解釋排除

| 替代解釋 | 排除理由 |
|---------|---------|
| to_pileup 的 QUAL 計算方式與 paired 不同（scale 不同） | 有可能：paired_full QUAL median ≈ 21，paired_pileup ≈ 0.98（不同 scale），to_pileup ≈ 19.6；但不影響方向比較（同 mode 下 TP vs FP 的相對比較） |
| 這些 FP 是高品質 somatic 但 truth set 未收錄 | 部分可能性（tumor-only 的 FP 中混有 truth set gap）；但 11,601 個 FP 全部 QUAL > TP 不符合「少量遺漏」的解釋 |

⚠️ **注意**：paired_pileup 的 QUAL 是 0-1 scale（ClairS pileup probability）；paired_full 的 QUAL 是 Phred-scale。to_pileup 的 QUAL 是 Phred-scale。方向比較需在同 mode 下進行，不可跨 scale 直接比較數值大小。

#### 3.4.4 驗證方法

1. 在 to_pileup FP 中，按 QUAL 分桶（19-20, 20-21, >21），計算各桶的 VAF 分佈
2. 確認高 QUAL FP 的 VAF 是否集中在 0.9-1.0（pure germline 特徵）
3. 此驗證可確認「高 QUAL to_pileup FP = germline 洩漏」的機制

#### 3.4.5 信心等級

**信心：高（兩個 to_pileup runs 一致，方向在 paired 模式下也完全一致）**

### 特殊現象 S5：InterSubMod 效益存在 LongPhase 殘餘 FP 門檻

#### 3.5.1 觀察

InterSubMod 的 F1 增益與 LongPhase 殘餘 FP 數量呈現明顯的門檻關係：LongPhase FP < 100 時，ISM 移除零個 FP 但損失多個 TP；LongPhase FP > 600 時，ISM 移除 FP 的效率達 30–42 倍。

#### 3.5.2 資料來源與數值計算

**來源**：`data/layer_metrics.tsv`，每個 run 的 LongPhase FP 數、ISM 新增/移除 TP/FP 數

計算欄位定義：
- `ISM_dFP` = LP_FP − ISM_FP（正值=ISM 移除了 FP）
- `ISM_dTP` = LP_TP − ISM_TP（負值=ISM 損失了 TP）
- `FP_TP_ratio` = ISM_dFP / |ISM_dTP|（若 dTP=0，設 ∞；若 dFP=0，設 0）

**全部 16 個 run 的計算結果**：

| Run | LP_FP | ISM_dFP | ISM_dTP | FP/TP 比 | ISM F1 delta | 效果分類 |
|-----|-------|---------|---------|---------|------------|---------|
| H1437:paired_full | **8** | 0 | −8 | 0.00 | +0.0000 | ❌ 無效（0 FP 移除） |
| HCC1954:paired_full | **29** | 0 | −45 | 0.00 | −0.0012 | ❌ 最差（0 FP 移除，損失 TP） |
| H2009:paired_full | **86** | +1 | −30 | 0.03 | −0.0001 | ❌ 近乎無效 |
| HCC1954:paired_pileup | **148** | +4 | −101 | 0.04 | −0.0025 | ❌ 最差（損失 101 TP） |

### 特殊現象 S6（補充）：Quality_Score 在 COLO829 整體偏低，喪失 TP/FP 分離能力

#### 3.6.1 觀察

**來源**：`data/feature_summary.tsv`，`feature=Quality_Score`

| Sample (paired_full) | Platform | TP QS median | TP QS Q25 | TP QS Q75 | FP QS median |
|---------------------|---------|-------------|---------|---------|------------|

⚠️ COLO829 的 TP Q75=70.0，即 75% 的 TP 都在 Quality_Score ≤ 70；而其他 sample 的 TP Q25 至少 = 60，Q75 多數 = 100。

#### 3.6.3 替代解釋與未確認點

⚠️ 目前只有一個 platform（ONT_PAO_5mCG）、一個 sample（COLO829 melanoma），**無法從現有資料區分以下兩個假說**：

#### 3.6.4 驗證方法

1. 若有 COLO829 的其他 basecall 版本（如 DORADO），重跑 InterSubMod 比較 Quality_Score 分佈
2. 查閱 Quality_Score 的計算公式：若依賴 QUAL/depth，則不同 basecaller 的 QUAL scale 差異會直接影響

#### 3.6.5 信心等級

**信心：高（數值明確，COLO829 確實偏低）；機制推論信心：低（無法從單一 sample 區分平台 vs 樣本效應）**

## 5. 可驗證的量化結論

### C1：Quality_Score < 75 對 H2009 的 FP triage **無效**（已實測更正）

> ⚠️ **2026-03-17 更正**：此結論依據實測資料重新評估，原始預測有誤。

**實測結果**（H2009 paired_full per_region_features.tsv.gz，n=FP:86, TP:132,908）：

| 指標 | 數值 | 說明 |
|------|------|------|
| QS < 75 標記 FP 數 | 14 / 86（16.3%） | FP recall 極低 |
| QS < 75 同時標記 TP 數 | 7,212 / 132,908（5.4%） | TP recall 損失 |
| Precision | **0.002**（14/(14+7212)） | 每移除 1 個 FP 需同時刪掉 515 個 TP |

**原始預測錯誤原因**：
- 原假設：H2009 FP 的 Q75=75，故以 75 切割可移除 ~50% FP
- 實際：H2009 FP Q25=Q50=Q75=75.0（集中在 75.0 的點分佈），QS < 75 只能捉到最低端 14/86 個 FP
- 更重要：H2009 FP 的主要類型是**高 VAF germline 漏報（VAF median=0.97）**，Quality_Score 在此類型 FP 上和 TP 幾乎相同（FP QS median=75，TP median=100，但因 FP 集中於 75.0，切點略低於 75 的收益接近 0）
- Quality_Score < 75 precision 為 0.002，在 TP:FP = 1548:1 的比例下，任何單一閾值 precision 必然極低

**修正結論**：Quality_Score 作為 FP triage 工具，在 H2009 的實際效益**不如預期**。H2009 FP 的有效區分特徵是 VAF（FP median=0.97 vs TP median=0.46），而非 Quality_Score。

⚠️ 限制：此規則不適用於 COLO829、HCC1937、to_pileup。Quality_Score 對 H1437(pileup)、HCC1954 的實際有效性需另行實測確認。

### C2：VAF 單一全域閾值策略無效

驗證方式：以全域 FP VAF median=0.565 設為閾值，計算各樣本 FP 移除率。

已知結果：HCC1395（低 VAF FP 主體 0.13–0.16）幾乎無效，HCC1937（高 VAF FP 0.97–1.0）反而誤殺大量低 VAF TP。

### C3：InterSubMod 效益需以 LongPhase FP 殘餘量分層評估

驗證方式：以 LongPhase FP 為 x 軸，InterSubMod F1 delta 為 y 軸，確認閾值位置（約在 FP=500 處轉正）。
