# PMC12424993 論文重點與 InterSubMod 完整比較報告

## 1. 任務範圍與回答方式

本報告回應以下需求：
1. 理解並整理論文 `PMC12424993` 的研究重點。
2. 與本專案 InterSubMod 做「完整相似與差異」比較。
3. 補充背景知識脈絡與可執行的後續研究方向。
4. 另外檢索並整理相似研究。
5. 明確區分「直接證據」與「推論」。

標註規則：
- `[直接證據]`：可在文獻/知識庫/程式碼中直接對應。
- `[推論]`：基於直接證據的合理延伸，非原文直接陳述。

## 2. 指定論文重點（PMC12424993）

### 2.1 研究目標與核心設計

- `[直接證據]` 論文主題是將腫瘤「克隆演化」與「甲基化演化」整合到同一框架，分析抗癌治療前後的演化軌跡。  
  來源：PMC12424993
- `[直接證據]` 研究對象為同一位病人的兩個卵巢癌時點腫瘤（時間間隔 12 個月，期間有 7 次 carboplatin）。  
  來源：PMC12424993
- `[直接證據]` 實驗組合包含：ONT 長讀長 WGS + methylation（兩個 bulk tumor）與 21 個 single-cell derived subclones 的短讀 WGS。  
  來源：PMC12424993
- `[直接證據]` 作者提出 `TreeHarmonizer`，用來把 single-cell clone 的 SNV 樹與 bulk long-read 變異訊號對齊，處理 caller 的 FN/FP 不一致。  
  來源：PMC12424993

### 2.2 主要發現

- `[直接證據]` 研究觀察到 SNV 與 methylation 並非單一路徑同步變化，而是可有平行（parallel）且分歧的演化。  
  來源：PMC12424993
- `[直接證據]` 文中以 branch/trajectory 方式辨識 methylation 動態（包含 DMR 軌跡），並連結到特定功能基因集合。  
  來源：PMC12424993
- `[直接證據]` 論文有做 pseudo-bulk benchmark：使用已知克隆組成的混樣，評估 caller 與 TreeHarmonizer 後續整合流程。  
  來源：PMC12424993
- `[直接證據]` 文中明確比較了深度學習 somatic caller（如 DeepSomatic、ClairS）在其框架下的效能差異。  
  來源：PMC12424993

### 2.3 方法學價值

- `[直接證據]` 論文的關鍵貢獻不是單一 caller 準確率，而是「跨資料型態的一致化演化解釋」：single-cell clone lineage + bulk long-read methylome。  
  來源：PMC12424993
- `[推論]` 這種設計對 InterSubMod 的意義是：我們不只可做「位點附近 read-level 差異」，也可升級到「克隆樹分支層級的甲基化事件歸因」。

## 3. 與 InterSubMod 的完整相似與差異

## 3.1 比較基準（我們目前 InterSubMod）

- `[直接證據]` 根據 `Knowledge/05_tools/InterSubMod.md`，InterSubMod 目前定位是以 read-level methylation pattern 解析 subclonal 結構，核心輸出為 distance matrix、heatmap、subclonal 訊號。
- `[直接證據]` 根據 `src/core/DistanceMatrix.cpp`，本工具支援 NHD/L1/L2/CORR/JACCARD/BERNOULLI 距離，並處理低共覆蓋（`min_common_coverage`）與 NaN 策略。
- `[直接證據]` 根據 `src/core/SignificanceAnalyzer.cpp` + `src/core/RegionProcessor.cpp`，目前有 Global/Local/Label-First 多階段檢定與 `Strong/Subclone/Weak/Noise` 分類，但實務 pipeline 中 PERMANOVA 目前在 RegionProcessor 內預設關閉。
- `[直接證據]` 根據 `Knowledge/06_workflows/methylation_analysis.md` 與 `Knowledge/06_workflows/somatic_variant_calling.md`，InterSubMod 依賴 haplotagged BAM（HP）與 MM/ML 標籤，流程上位於 somatic calling + phasing 之後。

## 3.2 相似處（完整列舉）

1. `[直接證據]` 都是「長讀長 + 甲基化 + 體細胞變異」的整合分析路線。  
2. `[直接證據]` 都重視 subclonal/heterogeneity，而非只做平均甲基化。  
3. `[直接證據]` 都使用 caller 結果作為下游甲基化-演化分析入口（論文有 caller benchmark；InterSubMod 接 ClairS/ClairS-TO/DeepSomatic）。  
4. `[推論]` 兩者都可作為「變異可信度與生物解釋」之間的橋接層：不是只看 VCF 分數，而是加入 read-level 表觀訊號。  

## 3.3 差異處（完整列舉）

1. 資料層級差異  
- `[直接證據]` 論文整合 single-cell clone WGS + bulk long-read methylome；InterSubMod 目前主要是 bulk long-read 為主，未原生整合 single-cell clone 樹。  

2. 模型層級差異  
- `[直接證據]` 論文核心是「演化樹對齊（TreeHarmonizer）+ branch assignment」；InterSubMod 核心是「區域 read-distance + 統計驗證」。  
- `[推論]` 論文更偏「宏觀克隆歷史重建」，InterSubMod更偏「局部位點微結構檢驗」。  

3. 統計設計差異  
- `[直接證據]` InterSubMod 現有雙向驗證與多階段 HP 檢定（Global + Label-First + Quality tier）；論文重點是樹一致化與軌跡推斷，統計問題定義不同。  
- `[推論]` 兩者可互補：InterSubMod 的位點級顯著性可作為 TreeHarmonizer 分支打分特徵。  

4. 輸出層級差異  
- `[直接證據]` 論文輸出的是 clone phylogeny 對應的 SNV/methylation trajectory；InterSubMod 輸出是每位點區域 summary（`significance_summary.csv`）與熱圖。  

5. 基準驗證差異  
- `[直接證據]` 論文做 pseudo-bulk 組成已知 benchmark；InterSubMod 現行主流程以 truth-set TP/FP 與顯著性統計為主。  

## 3.4 一句總結

- `[推論]` `PMC12424993` 比較像「跨層級演化整合框架」，InterSubMod 比較像「高通量位點級 epigenetic 驗證引擎」；兩者不是替代關係，而是可串接關係。

  來源：`Knowledge/05_tools/variant_callers.md`, `Knowledge/06_workflows/somatic_variant_calling.md`

## 5. 可執行的後續研究方向（InterSubMod 對齊該論文）

## 5.1 短期（可在現有程式上落地）

1. 建立「TreeHarmonizer-like 前置層」原型  
- `[推論]` 輸入 short-read clone SNV + bulk long-read calls，做位點一致化表（candidate branch assignment + confidence）。  
- 產物：`branch_harmonized_variants.tsv`（每變異對應分支與置信度）。

2. 在 InterSubMod summary 增加 branch-aware 欄位  
- `[推論]` 於 `significance_summary.csv` 增加 `BranchID`、`BranchSupport`、`TrajectoryClass`，讓位點級結果可回投到克隆樹。  

3. pseudo-bulk benchmark 移植  
- `[推論]` 利用既有 HCC1395 purity/subsample 資料，建立已知混樣比例，評估 caller + InterSubMod +（未來）harmonizer 的整體可辨識度。  

## 5.2 中期（方法學升級）

1. 分支層級 DMR/trajectory 模型  
- `[推論]` 從「每位點顯著性」升級到「每分支軌跡顯著性」（例如 branch-specific DMR burden、方向一致性）。  

2. 與 LOH/CNV 的共同解釋  
- `[推論]` 目前 InterSubMod 已有 potential LOH / subtype 欄位，可把甲基化分歧與 copy-number 事件聯動評分，降低偽陽性訊號。  

3. 不確定性建模  
- `[推論]` 把 caller 不確定性、phase 不確定性、distance 稀疏性都顯式化，輸出每個結論的 confidence interval，而非只有單點 p-value。

## 5.3 長期（研究定位）

1. InterSubMod 作為「演化樹上的甲基化證據層」  
- `[推論]` 讓 InterSubMod 從下游驗證工具，升級成可直接參與 clonal evolution reconstruction 的模組。  

2. 形成可發表的方法學問題  
- `[推論]` 主題可定義為：`Robust branch-aware methylation evidence integration under caller uncertainty in long-read cancer data`。

## 6. 相似研究檢索整理（2026-03-03）

以下以「與本論文 + InterSubMod 的方法相近程度」分層。

## 6.1 高相似（癌症長讀長 + 甲基化 + 演化/異質性）

1. Long-read sequencing of advanced cancers in a clinical setting（Cell Genomics, 2024）  
- `[直接證據]` 大型 cohort（189 tumors + 41 matched normals）呈現癌症長讀長基因體/甲基體地景，包含 aDMR/ASM 與腫瘤相關事件。  
- 相似點：都做癌症 long-read + methylation 的全域刻畫。  
- 差異點：該研究偏 cohort landscape，非單病人時序克隆樹對齊。  
- 連結：https://pubmed.ncbi.nlm.nih.gov/39406235/

2. Long-read whole-genome profiling of medulloblastoma（Cell Genomics, 2023）  
- `[直接證據]` 展示 medulloblastoma 的 haplotype-resolved 基因體與甲基化異質性。  
- 相似點：重視 long-read 上的結構/甲基化整合。  
- 差異點：疾病模型與設計不同，未必有像 TreeHarmonizer 的 clone 樹對齊。  
- 連結：https://pmc.ncbi.nlm.nih.gov/articles/PMC10392416/

3. Epigenetic and genomic architecture of repeat-rich DNA in HGSOC（Sci Rep, 2025）  
- `[直接證據]` 聚焦卵巢癌（HGSOC）long-read 基因組與表觀訊號（特別是重複區）。  
- 相似點：同癌別脈絡、同樣關心 genomic + epigenomic 共同變化。  
- 差異點：重點在重複區域結構與表觀特徵，不是克隆樹 harmonization。  
- 連結：https://pubmed.ncbi.nlm.nih.gov/39898768/

## 6.2 中相似（關鍵方法可補強 InterSubMod）

1. NanoMethPhase（Genome Biology, 2021）  
- `[直接證據]` 以 phased SNP 為基礎建立 haplotype-specific methylation。  
- 互補點：可強化 InterSubMod 的 allele/HP 解釋穩定性。  
- 連結：https://pubmed.ncbi.nlm.nih.gov/33618748/

2. MethPhaser（Nature Communications, 2024）  
- `[直接證據]` 用 methylation 訊號延伸 phasing，改善 haplotype block。  
- 互補點：可提升 InterSubMod 上游 phase 品質，降低 HP0/HP3 對下游統計的干擾。  
- 連結：https://pubmed.ncbi.nlm.nih.gov/38909018/

3. sgootr（Genome Research, 2023）  
- `[直接證據]` 以 single-cell DNA methylation 重建 migration histories（演化軌跡型方法）。  
- 互補點：提供「軌跡重建」觀點，可借鏡到 branch-level methylation trajectory。  
- 連結：https://pubmed.ncbi.nlm.nih.gov/38240490/

## 6.3 工具層相似（非同題，但關鍵基礎）

1. Severus（Nat Biotechnol, 2025）  
- `[直接證據]` 長讀長腫瘤複雜 SV 偵測工具。  
- 互補點：若納入 SV branch event，可提升演化解釋完整度。  
- 連結：https://pubmed.ncbi.nlm.nih.gov/39868252/

---

## 7. 重要推論與風險註記

1. `[推論]` 把 `PMC12424993` 的 TreeHarmonizer 思路直接搬到 InterSubMod 可行，但需先解決輸入資料一致性（single-cell clone WGS 是否可取得、caller/座標系統一致化）。  
2. `[推論]` InterSubMod 若只維持位點級 summary，難完整回答「演化路徑層級」問題；需新增 branch-aware middle layer。  
3. `[推論]` 若直接用現有 p-value/heuristic_score 推演分支歷史，會有模型錯置風險；建議先做 pseudo-bulk 模擬驗證再外推。  

---

## 8. 結論（給決策用）

1. `PMC12424993` 的核心價值是「克隆樹與甲基化軌跡的跨層級整合」，不只是 caller 比賽。  
2. InterSubMod 現況在「位點級 read-level 檢驗」非常完整，但在「branch-level 演化整合」仍是缺口。  
3. 最值得做的下一步是：`Harmonization layer + branch-aware summary + pseudo-bulk benchmark` 三件事一起規劃，才能把 InterSubMod 從分析工具提升為演化推論框架。
