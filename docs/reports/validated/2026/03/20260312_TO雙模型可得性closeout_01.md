# TO 雙模型可得性 closeout

## 破題結論

本輪已可正式定案：

> **在目前 `/big8_disk/data/HCC1395/` 的 tumor-only source tree 中，尚未確認存在可直接做 `pileup vs full model` benchmark 對照的 TO full-model 產物。**

這代表目前所有 `HCC1395 5kHz TO` 與 `HCC1395_DORADO TO` 的 caller 模型差異討論，都只能以 **pileup 路線** 為主。  
因此：

1. 先前文件中的「TO pileup vs full model 尚未補齊」現在應更精確改寫為：  
   **`TO dual-model comparison unavailable in current source tree`**
2. `v0_3_0` 與 `ss_v0_3_0` 目前應視為 **不同 pileup model family**，不是 `pileup/full model` 對照組。
3. 若未來要真的做 TO 雙模型 benchmark，前提不是補表格，而是：
   - 找到或重跑真正的 TO full-model 產物
   - 再補 benchmark split / compare step

---

## 1. 研究問題

這輪只回答一個問題：

### 現有 `HCC1395 5kHz TO` 與 `HCC1395_DORADO TO` 的 source tree 中，是否已經有可直接比較的 `pileup / full model` 輸出？

成功條件：

- 能用 source tree 與 log 證據，明確回答 `有 / 沒有`

失敗條件：

- 仍停留在「看起來可能有」或「應該只差 benchmark」的模糊口徑

## 3. 關鍵證據

### 3.1 TO 四個 source tree 都只有 pileup 路線

從 `run_clairs_to.log` 可見，四個 TO 來源樹都只出現：

- `SNV PILEUP AFFIRMATIVE MODEL PATH`
- `INDEL PILEUP AFFIRMATIVE MODEL PATH`

而沒有 paired raw caller 中會看到的：

- `FULL-ALIGNMENT MODEL PATH`
- `fa_tensor_can`
- `full_alignment.vcf`
- `full_alignment_filter.vcf`

### 3.2 目錄結構也支持同一結論

在 TO source tree 中可找到：

- `tmp/pileup_tensor_can_affirmative`
- `tmp/pileup_tensor_can_negational`

但找不到：

- `tmp/fa_tensor_can`
- `full_alignment.vcf`
- `full_alignment_filter.vcf`

反過來，在 paired raw caller `/big8_disk/data/HCC1395/ONT/ClairS_v0_4_0` 中可找到：

- `tmp/pileup_tensor_can`
- `tmp/fa_tensor_can`

而且 log 也明確寫出：

- `FULL-ALIGNMENT MODEL PATH`
- `full_alignment.vcf`
- `full_alignment_filter.vcf`

### 3.3 benchmark scope 也尚未齊全

四個 TO source tree 中，只有：

- `HCC1395 ONT TO v0_3_0`

擁有原生 `benchmark-test/`。其餘三條 TO 路線目前都沒有現成 `benchmark-test`。

這代表即使未來找到 TO full-model 產物，也還需要再補 compare step。

## 5. 正式 closeout 結論

### 已成立結論

1. `TO dual-model comparison` 在現有 source tree 中 **不可直接進行**
2. 目前 TO 路線應以 **pileup-only** 視之
3. `v0_3_0` 與 `ss_v0_3_0` 不應再被描述成 `pileup vs full`
4. paired raw caller 的雙模型對照已成立，但 **不能直接拿來推論 TO 也具備同樣產物**

### 不應再使用的舊口徑

- `TO pileup vs full model 尚未補齊雙模型直接對照`

這句話太容易被理解成「資料已存在，只差分析」。  
現在應改寫成：

- `TO dual-model comparison unavailable in current source tree; current TO evidence is pileup-route only`

---

## 6. 對主線研究的影響

這個 closeout 對主線有三個直接影響：

1. 之後所有 TO caller 模型差異討論，都必須先標示：
   - `pileup-route only`
2. phase 2 中的 paired raw `pileup/full` 結論，不能直接平移到 TO。
3. `未完項 closing plan` 中，關於 TO 雙模型的 workstream 現在已從：
   - `需要比較`
   收斂成：
   - `需要先補 full-model source 或正式維持 unavailable 狀態`
