# Phase 4 甲基化亞克隆視覺觀察：驗證、推論與結論整理

**日期**：2026-03-16
**資料**：HCC1395 5kHz Paired (s-pure/20260307)，ClairS + LongPhase-S haplotagging
**方法**：InterSubMod cluster heatmap + distance heatmap + methylartist SVG + BAM 直接分析
**案例**：5 TP（VerificationClass=Subclone，CramersV>0.3，NumReads≥30）+ 4 FP（對照組）

---

## 一、HP Tag 定義確認（LongPhase-S Paired 模式）

本輪最重要的前置修正：釐清 HP tag 的實際語意。

| HP 值 | 正確定義 | 錯誤解讀（已修正） |
|-------|---------|----------------|
| HP=1 / HP=2 | Normal 的 germline haplotype 1 或 2，apply 到 tumor reads | ✓ 無誤 |
| HP=0 | 此 read 在該區域無法相位（缺乏附近 germline SNP） | ✓ 無誤 |
| **HP=1-1** | **HP1 背景的 read，且帶有 Somatic ALT allele** | ✗ 原誤解：「跨越兩個 phased block 的 chimeric read」 |
| **HP=2-1** | **HP2 背景的 read，且帶有 Somatic ALT allele** | ✗ 原誤解：「跨越兩個 phased block 的 chimeric read」 |
| **HP=3** | **LongPhase-S 無法區分 HP1/HP2，但 read 帶有 Somatic ALT** | ✗ 原誤解：「第三個 phase group，暗示 LOH/CNV」 |

**關鍵推論**：HP=1-1、HP=2-1、HP=3 **均是 ALT reads 的 HP tag**，代表 somatic ALT allele 在不同 germline haplotype 背景上的表現。HP=3 不等於 LOH；LOH 需由 HP1-only 或 HP2-only 在 tumor 中的 skew 推論，而非由 HP=3 標籤直接判斷。

## 二、TP Subclone 案例觀察與結論

### 2.1 各案例數值概覽

| 位點 | CramersV | ALT reads | ALT-REF delta | 主要 HP 組成 | 甲基特徵 |
|------|---------|-----------|--------------|------------|---------|
| chr6:145444893 | **0.722** | 19/58 (33%) | +0.039 | 全 HP=2-1（ALT） | 中等甲基，3 群 |
| chr4:70548355 | 0.502 | 11/48 (23%) | +0.037 | 67% HP=0（REF+ALT 均） | 高甲基，2 群弱邊界 |
| chr5:153209947 | 0.443 | 17/57 (30%) | +0.035 | 全 HP=2-1（ALT），0% HP=0 | 低甲基（全域），2 群極微弱 |
| chr16:35118902 | 0.442 | 25/91 (27%) | **−0.198** | HP=3(12)+HP=1-1(13)（ALT），HP=0(42)（REF主） | **雙峰**，ALT=低甲基 |
| chr7:109185781 | 0.429 | 28/127 (22%) | −0.025 | HP=2-1（ALT），HP=1(70)（REF主） | 中等甲基，HP+Allele 共線 |

### 2.2 TP-1：chr6:145444893（最乾淨的 Allele-driven 訊號）

**觀察**：Heatmap 呈 3 層；ALT（HP=2-1，橙）自成獨立群；REF（HP=2，黃）分成兩個亞群。距離矩陣 ALT block 與 REF 之間距離明亮（差異大）。

**已驗證**：
- AlleleP=0.001，HPP=1.0 → allele 是唯一有效標籤，HP 完全不分離
- k=3 確認（1 ALT 群 + 2 REF 亞群）
- 視覺 3 層與 k=3 計算完全吻合

**推論與結論**：
HP=2-1 表示 ALT reads 的 germline 背景是 HP2，但帶有 somatic ALT。HP 標籤無法分離這個 case（HPP=1.0），allele 是分群的唯一驅動力。**這是最乾淨的「somatic allele 與特定甲基化狀態共分離」的案例**，符合 subclonal epigenetic change 的理想定義。

---

### 2.3 TP-2：chr4:70548355（高 HP=0 背景下的 Allele 分離）

**觀察**：67% reads HP=0（灰），Heatmap 仍顯示 2 群；ALT reads（HP=1-1，深藍）傾向集中在高甲基群；HP=0 reads 分散在兩群中。

**已驗證**：
- AlleleP=0.011（邊緣顯著）；高比例 HP=0 不損害 PERMANOVA，因為 HP label 未被用來計算 allele PERMANOVA
- HP_Ratio=0.937（極端偏 HP）但實際上是 HP=0 佔多數，HP1/HP2 imbalance 暗示此位點難以相位

**推論與結論**：
高 HP=0 區域通常表示附近 germline SNP 稀少或是 repeat/segdup 區域，LongPhase-S 無法建立相位框架。但這**不影響 allele PERMANOVA 的有效性**，因為 allele label（ALT/REF）來自 variant calling，而非 phasing。HP=0 reads 散布於兩群（而非自成一群）進一步支持「甲基差異由 somatic allele 驅動，與 HP 背景無關」。

---

### 2.4 TP-3：chr5:153209947（低甲基背景的微弱差異）

**觀察**：整個 Heatmap 均勻藍色（全域低甲基，0.04–0.25）；ALT vs REF 兩群視覺差異極微弱，幾乎需要放大才能辨認；methylartist 2kb 視窗確認全程低甲基（smoothed 值 7–12%）。

**已驗證**：
- AlleleP=0.003（顯著）：57 reads × 48 CpG 的多變量矩陣在 delta=0.035 下仍達顯著
- 整體低甲基（< 0.3）提示此位點在 CpG island 或 promoter 調控區（低甲基 = gene activation 的特徵）

**推論與結論**：
「低甲基背景中的微弱差異」是視覺最難驗證的 subclone 類型，但 PERMANOVA 的多 CpG 聯合檢驗比肉眼或單位點比較更敏感。**視覺工具（heatmap/methylartist）在此案例的鑑別力有限，統計方法（InterSubMod PERMANOVA + CramersV）是主要可靠指標。** 若為真實 somatic subclone，可能代表 promoter 的表觀遺傳活化（somatic 突變伴隨輕微 promoter 甲基化升高），而非典型 silencing。

---

### 2.5 TP-4：chr16:35118902（最清晰雙峰，表觀遺傳重程式化範本）

**觀察**：Heatmap 呈現最清晰的雙色分層：**上方深紅帶（REF，高甲基 0.5–0.8）vs 下方深藍帶（ALT，低甲基 0.1–0.35）**。HP=3（紫，12 reads）全落在 ALT 低甲基帶；HP=0（42 reads）主要在 REF 帶但少數散入 ALT 帶。距離矩陣顯示最完整的雙 block 結構。

**已驗證**：
- ALT-REF delta = −0.198（5 個案例中最大），AlleleP=0.001
- Bimodal fraction = 55%（26.4% high + 28.6% low），最接近理想 50/50 雙峰
- HP=3 reads（LongPhase-S 無法區分 HP1/HP2 但帶有 ALT）全部在低甲基帶，與 ALT reads 一致

**推論與結論**：
**ALT allele = 低甲基亞克隆**，這是 5 個案例中最符合「somatic subclone 伴隨表觀遺傳重程式化（epigenetic reprogramming）」定義的案例。腫瘤亞克隆的 somatic 突變伴隨大幅甲基化失去（hypomethylation，delta −0.198），而正常細胞（REF reads）維持高甲基。HP=3 的出現（ALT read 的 germline HP 背景未能唯一解析）提示此區域存在 phase complexity，使 germline phasing 困難，但 somatic ALT 訊號仍清晰可辨；若要進一步判定 LOH，仍需另查 phased genotype、`LOH.bed` 或 CNV track。**這個位點可作為「bimodal_ALT_hypomethylated」subclone methylation 類型的 prototype 案例。**

---

### 2.6 TP-5：chr7:109185781（HP+Allele 共線，高統計功效）

**觀察**：Heatmap 兩帶邊界較 chr16 模糊；HP=2-1（橙，28 ALT）在上方，HP=1（藍，70 REF）在中下方；ALT reads 橙色帶內部甲基化有明顯異質性（std=0.124），視覺上可看到橙色帶中有些 reads 偏紅、有些偏藍。

**已驗證**：
- 唯一 HPP=0.001 AND AlleleP=0.001 的案例（HP 和 Allele 雙重顯著）
- ALT-REF delta = −0.025（最小），但 127 reads 的統計功效使此微小差異仍達顯著
- HP=2-1（ALT）帶有 HP2 germline 背景；此位點 HP1 vs HP2 可能有 germline methylation difference

**推論與結論**：
HP 和 Allele 雙重顯著的核心原因是 **HP-ALT 共線性**：ALT reads 因恰好在 HP2 背景（HP=2-1），繼承了 HP2 的 germline methylation pattern，使 allele PERMANOVA 也間接顯著。**ALT-REF delta=−0.025 是 5 案例中最小，HP 才是主要分離驅動力，allele 效應量極弱**。ALT reads 的高內部 std（0.124）提示 28 個 ALT reads 可能進一步分成兩個次群（不同表觀遺傳狀態的腫瘤亞亞克隆），值得深入分析。

### 2.7 TP 案例跨案例結論

**1. Allele-driven TP 的鑑別指標**（chr6、chr4、chr5 模式）：

| 指標 | 數值範圍 | 解讀 |
|------|---------|------|
| HPP | > 0.3（理想 > 0.5） | HP 不是分離驅動力 |
| AlleleP | < 0.05 | Allele 是分離驅動力 |
| ALT reads 在 heatmap | 集中在同一層 | 視覺確認 allele 分離 |

**2. Allele-HP 共線 TP 的識別**（chr7 模式）：

- HPP < 0.05 AND AlleleP < 0.05 **同時顯著**
- AlleleDelta < 0.05（效應量小）
- ALT reads 的 HP 全在某一 HP 側（HP2-1 代表 HP2 背景）
- 需確認 allele 有獨立於 HP 的效應量，否則是 HP-driven

**3. TP Subclone 甲基類型分類（初步）**：

| 類型 | 代表位點 | 核心特徵 |
|------|---------|---------|
| T1：Allele-only（中甲基） | chr6 | HPP=1.0，allele 唯一驅動，3 群，中等甲基 |
| T2：高甲基弱分離 | chr4 | 67% HP=0，整體高甲基，邊界模糊 |
| T3：低甲基背景微差異 | chr5 | 全域低甲基（< 0.3），delta < 0.04，視覺難辨 |
| T4：雙峰 ALT低甲基 | chr16 | delta=−0.198，最清晰雙峰，bimodal 55% |
| T5：HP+Allele 共線 | chr7 | 雙重顯著，delta=−0.025，高讀數高功效 |

## 三、FP 案例觀察與結論

### 3.1 FP 概覽

| 位點 | FP 類型 | CramersV | AlleleDelta | ALT reads | 核心問題 |
|------|---------|---------|-------------|-----------|---------|
| chr8:93565727 | **A1（低 VAF Subclone）** | 0.000 | +0.187* | **2**/68 | VAF=3%，功效不足 |
| chr9:137953060 | **A2（高 CpG 假顯著）** | 0.000 | −0.003 | **5**/58 | 158 CpG 假顯著 |
| chr7:52087777 | **B1（HP-driven + INDEL 鄰近）** | **1.000** | +0.058 | 11/78 | local HP-labeled 結構；鄰近 SEQC2 INDEL |
| chr9:75383880 | **B2（local alignment anomaly）** | 0.736 | **+0.005** | 15/106 | HP-driven；`-1 deletion-like gap` |

> \* AlleleDelta=0.187 由僅 2 個 ALT reads 計算，統計上無意義（AlleleP=1.0）。

### 3.2 FP-A1：chr8:93565727（低 VAF 假 Subclone）

**觀察**：Heatmap 左側 Allele strip 幾乎全 REF（68 reads 中 2 個 ALT）；4 個聚類群清晰可見，但 2 個 ALT reads 散落在不同群中，**無法自成一群**；HP strip 全灰（97% HP=0）。

**已驗證**：
- CramersV=0.0 正確反映：2 個 ALT reads 無統計功效
- 4 群的聚類結構由 HP=0 reads 中的甲基化 pattern 差異（非 allele）驅動
- **PairwiseMedianDist=0.359（最高）**：高異質性來自 repeat region 多重對齊，與 somatic subclone 無關

**結論**：**VAF=3%（2/68）是核心問題**。即使這 2 個 ALT reads 真的是 somatic，PERMANOVA 也無法計算有意義的 allele 效應。97% HP=0 提示此位點在 repeat/segdup 區域，甲基異質性來自 multi-mapping，而非 somatic subclone 結構。
- **辨識規則**：ALT reads < 5 且 HP=0 > 90% → VerificationClass=Subclone 幾乎可確認為 FP

---

### 3.3 FP-A2：chr9:137953060（高維假顯著）

**觀察**：5 個 ALT reads 在 Allele strip 中**隨機散布**於不同群，視覺上完全無法辨識；3 群由 HP=0（42）vs HP=1（15）驅動；ALT_meth=0.581 = REF_meth=0.581（完全相同）。

**已驗證**：
- CramersV=0.0 正確：即使 LabelAllelePermanovaP=0.010 顯著，效應量仍為零
- 158 CpG 是假顯著的直接原因：高維矩陣導致 PERMANOVA type I error inflation（即使 delta=0 也能在 158 維中找到小差異）
- **CramersV 是防止高維假顯著的關鍵安全閥**

**結論**：這是「統計顯著但效應量為零」的典型案例。LabelAllelePermanovaP 的 p-value 在高 CpG 數下失去可靠性；**只有 CramersV 和 AlleleDelta 這兩個效應量指標仍可信**。即使不看 heatmap，CramersV=0.0 AND AlleleDelta < 0.01 可直接排除，不需視覺確認。

---

### 3.4 FP-B1：chr7:52087777（HP-driven + SEQC2 INDEL 鄰近）

#### 觀察

Heatmap 最清晰（CramersV=1.0），但**主要是 local HP-labeled structure 在驅動分層**，不是乾淨的 allele-only 分離。後續以主 tumor BAM 驗證後，target ALT reads 為 `11/78`，且都標成 `HP=2-1`；因此這裡應描述為「ALT-supporting reads 與同一 local HP label 共線」，而不是再寫成 `HP1` 背景或直接推成親緣來源。

#### 已驗證

- `LabelHPP=0.001` AND `LabelAlleleP=0.001`，表示 HP 與 allele 兩者都顯著，但 `DominantLabel=hp`
- 主 tumor BAM 驗證：`tumor ALT=11/78`，`normal ALT=0/48`，`tumor_alt_hp_counts=2-1:11`
- nearby truth event：`chr7:52087776:TA>T`（SEQC2 HighConf sINDEL）

#### 重要發現：SEQC2 INDEL TP 鄰近

| 項目 | 詳情 |
|------|------|
| 我們的 variant | chr7:52087777 A>T（SNV FP，ClairS 呼叫） |
| SEQC2 的 variant | **chr7:52087776 TA>T（INDEL TP，PASS+HighConf）** |
| 關係 | 兩者**相鄰 1bp**（INDEL 在 52087776，SNV 在 52087777） |
| Benchmark 問題 | SNV-only benchmark 不含 sINDEL truth set → 必然標記為 FP |

**機制推論**：
```
Ref: ...chr7:52087774  T A [A] A G...
                           ^
                     52087776: TA>T deletion（SEQC2 INDEL TP）

deletion → alignment shift →  ClairS 在 52087777 看到 A>T mismatch
        → 呼叫為 SNV → SNV-only benchmark 標記為 FP
```

這個「SNV FP」較像 **INDEL-adjacent alignment artifact**，而非獨立的 somatic SNV。SNV-only benchmark 在 INDEL ±2bp 範圍內的評估存在結構性缺陷。

#### 結論

**兩個獨立問題同時存在**：
1. **甲基信號是真實的，但主要由 local HP-labeled structure 解釋**；若要升級成更強的等位基因來源敘述，仍需再驗證 phase block / `PS`
2. **Variant 標籤可能是 benchmark 誤判**（INDEL-adjacent SNV 被 SNV-only benchmark 標記為 FP）

這個案例提示：benchmark annotation gap 可能導致部分「FP」實際上是真實的 somatic event（或 INDEL 相關的 SNV artifact），應在大規模 evaluation 中對 SEQC2 sINDEL ±2bp 位置的 SNV 特別處理。

### 3.5 FP-B2：chr9:75383880（local alignment anomaly / -1 deletion-like gap）

#### 使用者觀察

在 IGV 中觀察到：**chr9:75383880 的 ALT-supporting reads，在前一個位置（75383879）都帶有明顯的局部異常訊號**。這個畫面一開始容易被誤判成 MNP，但後續用主 tumor BAM 的嚴格驗證後，需要改寫成 `target SNV + -1 deletion-like gap / local alignment anomaly`。

#### BAM 直接分析驗證

| 分析項目 | 結果 |
|---------|------|
| 主 tumor BAM target ALT | `15/106` |
| ALT reads 的 HP | `1-1:15` |
| `adj_minus1_alt_del_frac` | **1.000** |
| 嚴格 MNP screen | **0 candidates** |
| 修正後判讀 | `target SNV + -1 deletion-like gap / local alignment anomaly` |
| ALT reads 在 SNV 附近的 query sequence | `TAGAAATT`（全部 ALT reads 一致） |

#### 修正後解釋

使用者看到的「前一格也異常」現象是真實的，但**目前較支持 `-1 deletion-like gap / local alignment anomaly`，而不是乾淨 MNP**：

1. `adj_minus1_alt_del_frac=1.000`
2. 嚴格 MNP 篩查結果是 `0 candidates`
3. 因此不能再把此案例當成「相鄰雙 SNV 被拆分」的代表

#### 為何呈現 FP 標籤

1. `AlleleDelta=+0.005` 幾乎為 0，甲基效應量本身很弱
2. `DominantLabel=hp`，表示甲基分群主要由 HP / local read structure 解釋
3. target 前一格的 deletion-like gap 會進一步增加局部對齊複雜度

#### 結論

這個案例更適合歸類為：**HP-driven + local alignment anomaly**。  
它提醒我們：IGV 視覺上的「像 MNP」不等於已驗證 MNP，仍必須回到 BAM / adjacent-gap 指標 / 嚴格篩查工具做正式確認。

### 3.6 TP vs FP 視覺鑑別規則

視覺觀察的決策樹：

```
1. 看 ALT reads 數量
   ├── < 5 reads → FP 風險極高（FP-A1, FP-A2）
   └── ≥ 10 reads → 繼續評估

2. 看 ALT reads 在 heatmap 中是否集中成群
   ├── ALT reads 隨機散布於各群 → FP（FP-A1, FP-A2）
   └── ALT reads 集中在同一層 → 繼續評估

3. 看 HP strip vs Allele strip 誰分層更整齊
   ├── HP strip 更整齊（HP 顏色完美分群，ALT reads 跟隨 HP） → FP（FP-B1, FP-B2）
   └── Allele strip 分層明顯（ALT reads 不隨 HP 偏移） → TP 可信

4. 確認 AlleleDelta
   ├── < 0.02（接近 0） → HP confounding，即使 LabelAlleleP 顯著也是 FP（FP-B2）
   └── > 0.05 → 有實質 allele-meth 差異，支持 TP

5. 確認 HPP vs AlleleP
   ├── HPP << AlleleP（HP 強，Allele 弱） → HP-driven FP
   └── AlleleP << HPP 或 HPP 不顯著 → Allele-driven TP
```

## 四、兩大關鍵發現

### 4.1 發現一：SEQC2 INDEL-adjacent SNV 的 Benchmark Annotation Gap

**現象**：FP-B1（chr7:52087777 A>T）被我們的 pipeline 標記為 FP，但 SEQC2 在 chr7:52087776 有 PASS+HighConf INDEL TP（TA>T deletion）。

**機制**：INDEL 引起的 alignment shift 導致 ClairS SNV caller 在 +1bp 位置（52087777）看到 A>T mismatch 並呼叫，但這個 SNV 在 SEQC2 SNV truth set 中不存在。

**影響評估**：
- HCC1395 SEQC2 有約 4,000 個 sINDEL TP
- 若每個 INDEL 平均影響 ±2bp = 4 個位置，**約有 16,000 個 SNV 位置在 INDEL 鄰近區域可能受影響**
- 目前 precision/recall 計算中，這些位置的 SNV 被計入 FP（可能過度懲罰 precision）

**建議行動**：
1. 建立「INDEL-adjacent exclusion zone」（±2bp），在計算 precision 時排除或特別標記這些位置
2. 引入 sINDEL truth set 做聯合評估
3. 或在 filter step 中添加 `INDEL_ADJACENT` flag，而非直接計入 FP

---

### 4.2 發現二：局部對齊異常可偽裝成相鄰 SNV 現象

**現象**：chr9:75383880（T>A）在 IGV 中看起來像 target 前一格也有一致異常，但主 tumor BAM 的嚴格驗證顯示此案例更像 `target SNV + -1 deletion-like gap / local alignment anomaly`。

## 五、InterSubMod 系統性推論

### 5.1 CramersV 的正確解讀

| CramersV 值 | 通常含義 | 潛在風險 |
|-------------|---------|---------|
| = 0 | 無甲基-allele 關聯；AlleleDelta 可確認 | 高 CpG 數時仍需確認 AlleleDelta |
| 0.3–0.7 | 中等效應量，有意義的甲基分離 | 需確認 HP vs Allele 驅動（看 AlleleDelta） |
| > 0.7 | 高效應量，強甲基分離 | 可能是 HP-driven germline imprinting（FP-B1=1.0 仍是 FP） |
| = 1.0 | 完美分離 | **高風險是 HP imprinting**，非 somatic |

**結論**：CramersV 高是**必要條件**（FP-A1/A2 的 CramersV=0 直接排除），但非**充分條件**（FP-B1/B2 的 CramersV=0.7–1.0 仍是 FP）。**AlleleDelta > 0.05 是必要的補充條件。**

### 5.2 TP/FP 的複合過濾邏輯（從本輪案例歸納）

```
TP 高可信（all conditions required）:
  ① ALT reads ≥ 10
  ② AlleleDelta > 0.05
  ③ AlleleP < 0.05
  ④ CramersV > 0.3
  ⑤ HPP > AlleleP（allele 比 HP 更能解釋分離）
  或
  ⑤' HP strip 無法解釋 ALT reads 的位置（HPP 不顯著，或 ALT reads 跨越多個 HP）

FP 高可信（any one condition sufficient）:
  ① ALT reads < 5（FP-A1/A2 類型）
  ② CramersV = 0 AND AlleleDelta < 0.01（高 CpG 假顯著）
  ③ ALT reads 全在某一 HP 側 AND AlleleDelta < 0.02（HP-driven，FP-B1/B2 類型）
```

### 5.3 PairwiseMedianDist 的限制

**本輪確認**：PairwiseMedianDist 高不等於 somatic subclone 訊號。
- FP-A1（chr8）的 PairwiseMedianDist=0.359（最高），但是 repeat region 的 multi-mapping 造成的假異質性
- chr16（TP）的 PairwiseMedianDist 也高，但同時有 AlleleDelta=−0.198 支撐

**結論**：PairwiseMedianDist 應作為「甲基異質性程度」的描述指標，而非 TP 鑑別規則。在 paired mode 中 FP > TP 的方向特性（已在 Phase 1 確認），進一步限制了它在過濾規則中的應用。
