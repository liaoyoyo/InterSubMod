Model reference

Model-A solver：最佳化目標、上限與分類

每個genotype是ALT bit set；full observation必須在node set，partial X-pattern是一個subcube。Solver找最少hidden nodes的unit-flip closed node sets，再枚舉所有parent choices。

minimize e = |N \ ({root} ∪ full)|
subject to: full ⊆ N; every partial subcube intersects N; every x≠root has a predecessor x−{j} in N

Search limits

  • k≤8（state space≤256）
  • extra hidden cap=4
  • per-level budget=150,000
  • 超出→greedy fallback + capped=true

Candidate count

n_trees(N)=Π n_valid_predecessors(x)，再跨minimal feasible N求和。Read count通過MINREAD後不進objective。

Class精確條件安全說法
determinednon-capped、存在refree minimal N、n_trees=1模型內唯一最小candidate
ambiguousnon-capped、存在refree minimal N、n_trees>1多個最小candidate
recurrence_required所有minimal solutions都需某bit重複取得Model A內需要recurrence
cappedhidden/budget search未完成not-applicable exact claim
Capped accounting bugfull={RR,AA}強制cap時，top-level n_hidden=0、stored tree n_hidden=1；root被扣兩次。
Order reproducibilitytree list未canonical sort；digest只sort每棵edges，不sorttree list。display prefix可跨process改變。
