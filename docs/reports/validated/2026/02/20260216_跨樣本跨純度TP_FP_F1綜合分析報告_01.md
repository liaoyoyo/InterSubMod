# 跨樣本跨純度 TP/FP/FN/F1 綜合分析報告

**報告日期**: 2026-02-16
**分析範圍**: 7 純樣本（100%）× 2 組純度系列 × 甲基化過濾器效果
**Pipeline**: ClairS pileup v0.4.1 → LongPhase-S somatic_haplotag → InterSubMod → Methylation Filter
**核心問題**: 甲基化輔助 sSNV 過濾在不同樣本與純度下的有效性與安全性

---

## 執行摘要

本報告整合 2026 年 1-2 月所有 InterSubMod 實驗結果，涵蓋 7 個癌症樣本（100% 純度）及 HCC1395 的 2 組純度稀釋系列，系統性評估甲基化輔助體細胞突變過濾的效果。

### 五條核心結論

1. **Pileup 模式全面優於 Output 模式**：6/7 樣本 Pileup F1 高於 Output（平均 +0.0062），應作為標準輸入來源。
2. **QUAL 過濾在 Pileup 模式下有害**：QUAL < 0.75 平均誤刪 ~1,150 TP，6/7 樣本 F1 下降，已正式移除。
3. **Methylation-only 過濾安全有效**：TP 誤刪率 < 0.1%（除 HCC1954），可安全部署於 100% 純度樣本。
4. **低純度（< 40%）時甲基化過濾傷害 Recall**：固定門檻不適用於所有純度，需 purity-aware 策略。
5. **甲基化特徵提供 VCF 品質正交的資訊**：120 個 QUAL > 0.75 的高品質 FP 僅甲基化分析能識別。

### 推薦使用條件

| 條件 | 建議 |
|------|------|
| 純度 ≥ 60%、BAM 含 MM/ML | 啟用甲基化過濾（AD > 0.15, CV < 0.03, VAF < 0.15） |
| 純度 40-60% | 保守過濾或僅觀察、不過濾 |
| 純度 < 40% | 不啟用甲基化過濾 |
| BAM 不含 MM/ML | 無法進行甲基化分析，僅使用 LongPhase 基線 |


## 第四章：甲基化特徵判別力

### 4.1 特徵分布差異（HCC1395, SEQC2 Truth Set）

基於 HCC1395 的 30,476 TP 與 4,822 FP（Pileup 無過濾基線），各特徵的 TP/FP 分布統計：

| 特徵 | TP 平均 | FP 平均 | 差異倍數 | TP/FP 分離度 | 門檻能力 |
|------|--------|--------|---------|-------------|---------|
| **QUAL** | 0.977 | 0.698 | 1.4× | 極高 | 門檻 0.75 可過濾 62.6% FP（但在 Pileup 下誤刪 TP） |
| **VAF** | 0.494 | 0.153 | 3.2× | 高 | 門檻 0.24 有效區分真實突變 vs mapping 錯誤 |
| **AlleleDelta** | 0.120 | 0.309 | 2.6× (反向) | 中高 | 門檻 0.25 識別甲基化異常位點 |
| **CramersV** | 0.022 | 0.000 | — | 二元 | FP 100% 為零；V > 0 作為安全閥保護真實 ASM |

**QUAL 的判別力最強**（TP 高度集中在 > 0.90，FP 分散在 < 0.75），但在 Pileup 模式下 TP 的 QUAL 分布下移，導致門檻失效。**VAF 是第二有效特徵**，TP/FP 差異 3.2 倍。AlleleDelta 與 CramersV 組合提供獨立於 VCF Caller 的甲基化維度資訊。

### 4.2 AlleleDelta 的 Fat Tail 分布現象

分析 HCC1395 的 AlleleDelta 分布發現 FP 特有的高尾部特徵：

| AD 區間 | TP 比例 | FP 比例 | FP/TP 富集比 |
|---------|--------|--------|-------------|
| < 0.10 | ~90% | ~55% | 0.6× |
| 0.10 - 0.20 | **8.6%** | **22.5%** | **2.6×** |
| > 0.20 | ~1.4% | ~22.5% | ~16× |

**機制**：
- 將 AD 門檻從 0.25 下修至 0.15，正是在精準打擊 0.15-0.25 這個 **FP 富集但 TP 稀疏** 的區間。
- 這解釋了為何 HCC1395 的新優化標準（AD > 0.15）能額外移除更多 FP 且幾乎不傷 TP。

### 4.3 甲基化的「獨立價值」：120 個高品質 FP

這是本研究最重要的發現之一。在 HCC1395 上使用原始三階段過濾（QUAL + Methylation），被移除的 FP 按來源分布：

| FP 移除來源 | 數量 | 佔總移除 FP 比例 |
|------------|------|-----------------|
| 僅 QUAL < 0.75 | 3,021 | 88.9% |
| 僅甲基化條件 | **120** | **3.5%** |
| 兩者皆符合 | 255 | 7.5% |
| **總計** | **3,396** | 100% |

**關鍵意義**：那 120 個 FP 的 QUAL 均 > 0.75（VCF Caller 認為是高品質變異），只有甲基化分析能識別它們。這些位點的共同特徵：

- **QUAL 高**（0.858 - 0.998）：VCF Caller 無法識別
- **AlleleDelta 極高**（0.35 - 0.70）：Ref/Alt 甲基化差異巨大
- **CramersV = 0**：差異不具統計顯著性
- **VAF 低**（0.05 - 0.22）：Alt reads 數量少

這證明甲基化資訊提供了 **與 VCF 品質正交的獨立過濾維度**。

### 4.4 同時被移除的 TP 分析

| TP 移除來源 | 數量 | 佔總 TP 比例 |
|------------|------|-------------|
| 僅 QUAL < 0.75 | 634 | 2.08% |
| 僅甲基化條件 | **3** | **0.01%** |
| 兩者皆符合 | 3 | 0.01% |
| **總計** | **640** | **2.10%** |

甲基化條件獨立僅誤刪 3 個 TP（0.01%），佐證其極高的安全性。

## 第五章：FN 回收可行性

### 5.1 問題定義

FN（False Negative）是 Truth Set 中存在但未被 Variant Caller 檢測到的真實突變。以 HCC1395（100% Pileup）為例：

| 指標 | 數值 |
|------|------|
| Truth 總數 | 39,447 |
| ClairS TP | 30,476 |
| ClairS FN | 8,971 |
| 未檢測率 | 22.7% |

### 5.2 技術限制分析

**InterSubMod 無法回收 FN 的根本原因**：

1. **InterSubMod 是下游分析工具**：它分析的是 Variant Caller 已輸出的 VCF 位點，不會主動掃描 BAM 尋找新變異。
2. **Pipeline 架構限制**：
   ```
   ClairS → VCF → LongPhase-S → InterSubMod
                ↑
           FN 在此已遺失
   ```
3. FN 的根本來源是 ClairS variant calling 的 sensitivity 限制，與甲基化分析無關。

### 5.3 FN 在各階段的累積

| 階段 | FN 數量 | 累積未檢測率 | 新增 FN 來源 |
|------|---------|-------------|-------------|
| ClairS pileup | 8,971 | 22.7% | Variant Caller sensitivity |
| LongPhase-S | 9,386 | 23.8% | Benchmark 重算（+415） |
| Methylation Filter | 9,386 | 23.8% | 無新增（過濾不增加 FN） |

**注意**：LongPhase-S 階段 FN 增加 415，並非 LongPhase-S 造成 TP 丟失，而是 benchmark 重新計算的結果（部分邊界位點在新 VCF 中被重新分類）。Methylation Filter 不會增加 FN，因為它只移除被標記為 FP-like 的位點（這些位點被移除後計入 FN 的數量極少——僅 5 個 TP 誤刪）。

### 5.4 結論與展望

| 問題 | 回答 |
|------|------|
| 甲基化過濾能回收 FN 嗎？ | **否**——InterSubMod 只分析已有 VCF 位點 |
| 甲基化資訊理論上能幫助找 FN 嗎？ | **可能**——若整合到 Variant Caller 內部 |
| 下一步如何利用甲基化降低 FN？ | 需修改 ClairS/DeepSomatic 納入甲基化特徵，或開發獨立的甲基化敏感 Caller |

### 表 6.1: 甲基化分析有效性評估矩陣

### 6.2 推薦使用策略

**保守型**（推薦於生產環境）：
- 僅在純度 ≥ 60% 且 BAM 含 MM/ML 時啟用
- 使用優化參數：`AD > 0.15, CV < 0.03, VAF < 0.15`
- 預期效果：HCC1395-like 樣本 F1 提升 +0.002，其他樣本中性

**積極型**（推薦於研究環境）：
- 在純度 ≥ 40% 時啟用，接受微幅 F1 波動
- 適合需要最大化 Precision 的場景（如臨床報告中最小化假陽性）

### 6.3 Pipeline 最佳實踐總結

| 步驟 | 最佳選擇 | 理由 |
|------|---------|------|
| VCF 輸入 | Pileup VCF（非 Output） | 6/7 樣本 F1 更高 |
| QUAL 過濾 | 停用 | Pileup 模式下有害 |
| 甲基化過濾 | AD > 0.15, CV < 0.03, VAF < 0.15 | 安全、核心樣本正向 |
| 純度限制 | ≥ 60%（保守）/ ≥ 40%（積極） | 低純度傷害 Recall |

### 6.4 未來改進方向

| 方向 | 預期收益 | 優先級 |
|------|---------|--------|
| **Purity-aware Filter** | 根據估計純度自動調整或關閉過濾 | 高 |
| **ML 整合** | 使用 QUAL + AD + CV + VAF 訓練分類器 | 中 |
| **LongPhase-TO 驗證** | 擴展到 Tumor-only 場景 | 中 |
| **FN 回收（Caller 整合）** | 將甲基化特徵納入 Variant Caller 提升 Sensitivity | 低（需修改上游工具） |
| **更多樣本 Purity 系列** | COLO829、H1437 等的純度系列驗證 | 低（需大量計算資源） |

### 附錄 C: 方法論細節

#### C.1 Benchmark 方法

- 使用 LongPhase-S 內建 benchmark 功能，基於 Truth VCF 和 High-Confidence BED 區域
- TP/FP/FN 分類基於位點精確匹配（chromosome + position）
- F1 計算：`F1 = 2 × TP / (2 × TP + FP + FN)`

#### C.2 甲基化過濾機制

InterSubMod 對每個 VCF 位點執行以下分析：
1. 從 Tagged BAM 中提取 ±1000bp window 內覆蓋的 reads
2. 解析 MM/ML tags 定位 CpG 位點甲基化狀態
3. 建立 Read × CpG 二元甲基化矩陣
4. 按 Allele (Ref/Alt) 分組計算組間/組內距離
5. 計算 AlleleDelta（結構差異）和 CramersV（統計關聯）
6. 應用過濾條件標記可疑位點

#### C.3 純度影響機制

低純度下甲基化過濾失效的原因：
- 腫瘤 reads 比例低 → Alt allele reads 數量少
- 少量 reads 的甲基化模式統計量不穩定
- AlleleDelta 因隨機波動而虛高
- CramersV 因樣本量不足而為 0（非因 mapping error）
- 結果：正常 TP 位點被錯誤標記為 FP-like 並被移除
