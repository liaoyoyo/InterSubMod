## 1. 研究背景與核心問題

### 1.1 核心流程

```
ONT Raw BAM (含 MM/ML 甲基化 tags)
  ↓ ClairS pileup v0.4.1 (somatic variant calling)
Somatic VCF
  ↓ LongPhase-S somatic_haplotag (haplotype 標記)
Tagged Tumor BAM (含 HP tags)
  ↓ InterSubMod (甲基化模式分析)
significance_summary.csv (含 AlleleDelta, CramersV 等特徵)
  ↓ 過濾條件應用
最終過濾後結果 → F1-score 評估
```

### 1.2 問題陳述

**Mapping 錯誤導致的假 ASM (Allele-Specific Methylation)**：

在長讀段定序中，部分 reads 因基因組重複區域、低複雜度區域等原因被錯誤比對（mapping error），導致來自不同基因組位置（不同甲基化狀態）的 reads 被錯誤歸入同一位點。這會產生「看起來像 ASM」但實際上是技術假象的現象。

**具體表現**：
- **高 AlleleDelta**：Ref reads 與 Alt reads 之間存在很大的甲基化模式差異（因為它們實際上來自不同基因組區域）
- **低/零 CramersV**：這種差異不具統計顯著性（因為是隨機的、不系統性的）
- **低 VAF**：錯誤 mapping 的 reads 通常是少數，導致變異等位基因頻率低

### 1.3 核心假設

> **如果一個 sSNV 位點的 Ref/Alt reads 在甲基化模式上差異巨大（高 AlleleDelta），但這種差異不具統計意義（低 CramersV），且該位點的變異頻率很低（低 VAF），那麼這個位點很可能是 mapping 錯誤產生的假陽性而非真實的體細胞突變。**

## 2. 過濾條件與各參數意義

### 2.1 最終過濾條件

```python
Remove if: (QUAL < 0.75) OR 
          (AlleleDelta > 0.25 AND CramersV < 0.05 AND VAF < 0.24)
```

此條件由兩部分組成：
1. **QUAL < 0.75**：VCF caller 品質低 → 直接移除（傳統方法）
2. **AlleleDelta > 0.25 AND CramersV < 0.05 AND VAF < 0.24**：甲基化+VAF 聯合過濾 → 識別 **QUAL 過濾無法捕捉的高品質假陽性**（本研究創新點）

### 2.2 QUAL — VCF 品質評分

| 項目 | 說明 |
|:-----|:-----|
| **來源** | VCF 檔案 QUAL 欄位，由 ClairS variant caller 計算 |
| **計算** | `QUAL_normalized = 1 - 10^(-QUAL/10)`，其中 QUAL 為 Phred-scale 品質分數 |
| **意義** | 衡量 variant caller 對該變異真實性的信心程度 |
| **TP 分布** | 平均 0.98，高度集中在 > 0.9 |
| **FP 分布** | 平均 0.70，分布分散 |
| **門檻 0.75** | 可過濾 62.6% 的 FP，僅誤刪 2.1% 的 TP |

### 2.3 AlleleDelta — Allele 甲基化差異

| 項目 | 說明 |
|:-----|:-----|
| **來源** | InterSubMod `significance_summary.csv` 的 `AlleleDelta` 欄位 |
| **計算** | `between_mean - within_mean`（Ref/Alt 組間甲基化距離的平均 − 組內距離的平均） |
| **意義** | 衡量兩組 reads（Ref vs Alt）甲基化模式的結構差異大小 |
| **TP 分布** | 平均 0.12，集中在 0.05-0.25 |
| **FP 分布** | 平均 0.31，有明顯的高尾部 |
| **門檻 0.25** | 識別甲基化模式異常的位點 |

**生物學解釋**：
- **低 AD (< 0.2)**：正常情況，Ref 與 Alt reads 的甲基化一致
- **高 AD (> 0.25)**：Ref 與 Alt 的甲基化差異顯著，可能原因：
  1. **Mapping 錯誤**（主要）：reads 來自不同基因組區域
  2. **真實 ASM**（少數）：需結合 CramersV 確認

### 2.4 CramersV — 甲基化關聯強度

| 項目 | 說明 |
|:-----|:-----|
| **來源** | InterSubMod `significance_summary.csv` 的 `CramersV` 欄位 |
| **計算** | `sqrt(χ² / n)`，基於 Allele (Ref/Alt) × Methylation (甲基化/未甲基化) 的 2×2 列聯表 |
| **意義** | 衡量 Allele 與甲基化狀態之間的**統計關聯強度** |
| **TP 分布** | 平均 0.022，中位數 0.00 |
| **FP 分布** | 平均 0.00，中位數 0.00，**100% 為零** |
| **門檻 0.05** | 實質上是二元判斷：V = 0（無關聯）vs V > 0（有關聯） |

**關鍵洞察**：

> CramersV 在此扮演**安全閥**角色。如果高 AlleleDelta 伴隨 V > 0，說明甲基化差異是系統性的、可重複的——可能是真實的 ASM，應保留。如果 V = 0，說明差異是隨機的、不可統計的——很可能是 mapping 錯誤。

### 2.5 VAF — 變異等位基因頻率

| 項目 | 說明 |
|:-----|:-----|
| **來源** | VCF FORMAT 欄位 AF 值，由 ClairS 計算 |
| **計算** | `Alt_reads / (Ref_reads + Alt_reads)` |
| **意義** | 該變異在定序樣本中的等位基因頻率 |
| **TP 分布** | 平均 0.49，集中在 0.3-0.7 |
| **FP 分布** | 平均 0.15，集中在 0.05-0.20（**3.2 倍差異**） |
| **門檻 0.24** | 區分真實突變（通常 VAF 較高）與 mapping 錯誤（通常 VAF 低） |

**VAF 與 AlleleDelta 的聯合效果**：
- 高 AD + 低 VAF → 很可能是少數錯誤 mapping reads 造成的假象
- 高 AD + 高 VAF → 可能是真實的 ASM，VAF 條件保護這些 TP 不被誤刪

## 4. 處理細節與執行步驟

### 4.1 完整流程

```
步驟 1: Somatic Variant Calling
   ClairS pileup v0.4.1 (tumor-normal mode)
   → somatic VCF (含 QUAL, VAF 等特徵)

步驟 2: Germline Phasing
   Clair3 → germline VCF
   LongPhase phase → phased germline VCF

步驟 3: Somatic Haplotagging
   LongPhase-S somatic_haplotag
   輸入: phased_germline.vcf, normal.bam, somatic.vcf, tumor.bam, reference.fasta
   輸出: tumor_tag.bam (含 HP:z:1, HP:z:2, HP:z:1-1, HP:z:2-1, HP:z:3)
   附帶: purity estimation, benchmark 結果 (TP/FP/FN VCF)

步驟 4: InterSubMod 甲基化分析
   輸入: tumor_tag.bam, filtered_snv_tp.vcf.gz / filtered_snv_fp.vcf.gz
   輸出: significance_summary.csv (含 AlleleDelta, CramersV, VerificationClass 等)

步驟 5: 過濾條件應用
   讀取 significance_summary.csv + VCF (取 QUAL, VAF)
   應用: (QUAL < 0.75) OR (AD > 0.25 AND V < 0.05 AND VAF < 0.24)
   計算: 過濾後 TP/FP/FN → Precision/Recall/F1
```

### 4.2 關鍵資料路徑

| 項目 | 路徑 |
|:-----|:-----|
| Reference | `/big8_disk/ref/GRCh38_no_alt_analysis_set.fasta` |
| Tumor BAM | `/big8_disk/data/HCC1395/ONT/...` |
| Normal BAM | `/big8_disk/data/HCC1395/ONT/...BL...` |
| Tagged Tumor BAM | `longphase_somatic_output_ssrs/HCC1395_Tmode_tagged_ClairS_pileup_v040_woFilter.bam` |
| SEQC2 Truth VCF | `/big8_disk/data/HCC1395/SEQC2/high-confidence_sSNV_in_HC_regions_v1.2.1.vcf` |
| SEQC2 HC BED | `/big8_disk/data/HCC1395/SEQC2/High-Confidence_Regions_v1.2.bed` |
| InterSubMod Binary | `/big8_disk/liaoyoyo2001/InterSubMod/build/bin/inter_sub_mod` |

### 4.3 InterSubMod 的甲基化資訊擷取

InterSubMod 從 BAM 檔案中以下方式處理甲基化：

1. **MM/ML Tag 解析**：從 BAM reads 中讀取 `MM:Z:C+m,...` 和 `ML:B:C,...` tags
2. **CpG 位點定位**：在 reference genome 上定位 SNV 周圍 ±1000bp window 內的 CpG sites
3. **甲基化矩陣建構**：建立 Read × CpG 的二元甲基化矩陣
4. **距離計算**：使用 Bernoulli distance 或 NHD 計算 read 兩兩之間的甲基化模式距離
5. **統計檢驗**：
   - **AlleleDelta**: 比較 Ref/Alt 組間 vs 組內距離差異
   - **CramersV**: 建立 Allele × Methylation 列聯表，計算 χ² 關聯強度
   - **LabelTest**: 多階段 HP/Allele 驗證

> [!NOTE]
> **甲基化資訊是「未被分析的」嗎？** 
> 
> 嚴格來說，MM/ML tags 在 ClairS pileup 和 LongPhase-S 中**不被使用**。ClairS 僅使用 base quality 和 mapping quality 進行 variant calling；LongPhase-S 使用 germline phasing 和 allele 資訊進行 haplotagging。
> 
> **甲基化資訊是在 InterSubMod 階段才首次被提取和分析的**。因此，AlleleDelta、CramersV 等特徵確實提供了 ClairS 和 LongPhase-S 流程中**未使用過的額外資訊維度**。

## 5. 核心機制：甲基化資訊如何識別假 ASM

### 5.1 假 ASM 的形成機制

```
真實情境:
  基因組位置 A (高甲基化區域) ← reads 被錯誤 mapping 到此
  基因組位置 B (低甲基化區域) ← 真正來自此區域的 reads

觀察到的結果:
  位點 X 的 reads:
  ├── Ref reads → 大多來自位置 A → 高甲基化 → 組內一致
  ├── Alt reads → 來自位置 B (mapping error) → 低甲基化 → 組內一致
  └── AlleleDelta = 高 (兩組間差異大)

  但 CramersV = 0 (差異不具統計顯著性):
  因為 mapping error 的 reads 數量少、位置隨機
  不足以形成系統性的 Allele-Methylation 關聯
```

### 5.2 真實 ASM vs 假 ASM

| 特徵 | 真實 ASM | 假 ASM (Mapping Error) |
|:-----|:---------|:----------------------|
| AlleleDelta | 高 | 高 |
| CramersV | **> 0**（系統性關聯） | **= 0**（隨機差異） |
| VAF | 正常 (0.3-0.7) | 低 (< 0.24) |
| QUAL | 通常高 | 可能高或低 |
| 生物學意義 | 印記基因、X 染色體失活等 | 無 |

### 5.3 為何此策略有效

1. **互補性**：QUAL 反映的是讀段品質和 mapping 品質，甲基化反映的是區域表觀遺傳狀態——這是兩個**完全獨立的資訊維度**
2. **安全性**：三個條件的 AND 邏輯確保了高度特異性：
   - 僅 AD > 0.25 → 會誤刪真實 ASM
   - 加上 V < 0.05 → 排除了統計顯著的真實 ASM
   - 加上 VAF < 0.24 → 進一步排除高頻率的真實突變
3. **實證支持**：獨立使用此條件僅誤刪 6 個 TP（0.02%），但移除 375 個 FP

## 6. 結論

### 6.1 核心結論

1. **甲基化資訊可以有效識別 mapping 錯誤導致的假 ASM**
   - 在 ClairS pileup 和 LongPhase-S 處理後，BAM 中的 MM/ML 甲基化 tags 提供了**未被利用的額外資訊**
   - 透過 InterSubMod 分析，可計算 AlleleDelta 和 CramersV 等甲基化特徵

2. **過濾條件有效減少 FP 而不誤刪 TP**
   - F1-score 從 0.8155 提升至 **0.8439**（+3.48%）
   - 總 FP 移除率 70.4%
   - TP 誤刪率僅 2.1%（其中甲基化條件獨立誤刪僅 0.02%）

3. **甲基化特徵與 VCF 品質是互補的**
   - 120 個高品質 FP（QUAL > 0.75）被甲基化過濾識別
   - 這些 FP 是 VCF caller 無法識別、只有甲基化分析能發現的

### 6.2 方法學價值

此研究首次系統性地證明：**利用 ONT 長讀段固有的甲基化資訊（MM/ML tags），可在不增加實驗成本的前提下，提升體細胞突變檢測的準確度**。這是一個「免費」的額外資訊來源——因為 ONT 定序天然就產生甲基化資訊。

### 6.3 限制

1. 目前僅在 **HCC1395 單一樣本**上驗證
2. 門檻（0.25, 0.05, 0.24）為此數據集優化，可能不適用於其他樣本
3. 僅測試了 **LongPhase-S + ClairS pileup** 組合
4. 未驗證 **LongPhase-TO**（tumor-only mode）的效果
5. 未測試不同 **purity** 水平的影響

## 8. 未來大規模驗證規劃

### 8.1 驗證矩陣

需要覆蓋**四種實驗配置** × **多個樣本**：

| 驗證類型 | Longphase 工具 | 樣本純度 | 輸入 | 目標 |
|:---------|:---------------|:---------|:-----|:-----|
| 類型 1 | LongPhase-S | 純的 (100%) | tumor_tag.bam | 基準線 |
| 類型 2 | LongPhase-S | 不同 purity | tumor_tag.bam | 純度影響 |
| 類型 3 | LongPhase-TO | 純的 (100%) | tumor_tag.bam | 工具差異 |
