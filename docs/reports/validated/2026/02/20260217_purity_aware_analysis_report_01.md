# Purity-Aware 分析報告：TP/FP 差異、FN 回收、門檻優化

**報告日期**: 2026-02-17
**分析樣本**: HCC1395_DORADO（含 MM/ML）5 級 purity 系列
**Pipeline**: ClairS pileup v0.4.1 → LongPhase-S → InterSubMod
**Truth Set**: SEQC2 v1.2.1（39,447 高信心 sSNV）

---

## 執行摘要

本報告透過實際計算驗證三個核心問題：

1. **不同純度下 TP/FP 特徵分布如何變化？**
2. **放寬 QUAL 門檻能否救回 FN 以提升 F1？**
3. **依據純度調整過濾門檻能否改善 F1？**

### 核心發現

- **19.4% purity**: Baseline F1=0.4673 已是最佳，無法透過過濾提升
- **39.6% purity**: Baseline F1=0.7636 已是最佳，無法透過過濾提升
- **60.0% purity**: Baseline F1=0.8365 已是最佳，無法透過過濾提升
- **80.0% purity**: 最佳 F1=0.8563（ΔF1=+0.0001），參數 AD>0.1, CV<0.005, VAF<0.1
- **100.0% purity**: 最佳 F1=0.8601（ΔF1=+0.0001），參數 AD>0.15, CV<0.005, VAF<0.1

- **FN 回收最大潛力**: 19.4% purity，納入全部 LowQual 變異後 ΔF1=+0.0007

### 2.3 QUAL 分布分析——ClairS 的二元分類機制

**關鍵發現**：ClairS pileup 對變異採用 **二元分類**，而非漸進式品質評分：

- **PASS 變異**：QUAL > 0（如 0.52 ~ 0.99）
- **LowQual 變異**：QUAL = 0.000（所有 LowQual 的 QUAL 均為精確的 0）

| 純度 | LowQual 總數 (BED 內) | LowQual QUAL | 說明 |
|------|---------------------|-------------|------|
| 19.4% | 39 | 全為 0.000 | 二元分類，無邊界區間 |
| 39.6% | 77 | 全為 0.000 | 同上 |
| 60.0% | 114 | 全為 0.000 | 同上 |
| 80.0% | 192 | 全為 0.000 | 同上 |
| 100.0% | 276 | 全為 0.000 | 同上 |

**這意味著不存在「QUAL 邊界」可供調整**。變異要嘛通過 ClairS 內部檢查（PASS），要嘛完全不通過（QUAL=0）。因此「降低 QUAL 門檻來救回邊界 FN」這個策略在根本上不適用。

### 2.4 FN 回收結論

1. **ClairS 的 QUAL 是二元分類（PASS vs QUAL=0），不存在「邊界」可調**：LowQual 變異的 QUAL 均為 0，無法透過微調門檻選擇性地救回部分 FN。
2. **LowQual 中可回收的 TP 極少**（佔 FN 總量 < 1%）：即使全部納入，F1 提升僅 10⁻⁴ 量級。
3. **FN 的根本來源**：
   - **~99% 的 FN 根本不存在於 pileup VCF 中**（ClairS 完全未 call 到）
   - **< 1% 的 FN 被 ClairS 標記為 LowQual**（QUAL=0）
4. **結論：透過調整 QUAL 門檻來回收 FN 不可行**。FN 的改善需從 Variant Caller 的 Sensitivity 本身著手（如使用更敏感的 Caller 或整合甲基化資訊到 calling 階段）。

## 綜合結論

### 1. TP/FP 特徵分布隨純度系統性變化

- **AlleleDelta**: TP 的 AD 隨純度下降而增大（甲基化統計量不穩定），與 FP 重疊增加
- **VAF**: TP 的 VAF 隨純度下降而降低（腫瘤 reads 比例低），進一步削弱區分力
- **CramersV**: 跨純度穩定，TP 中 CV>0 比例高於 FP
- **QUAL**: 低純度時 TP 和 FP 的 QUAL 分布均集中在高值區，區分力下降

### 2. QUAL 邊界 FN 回收不可行

- LowQual 變異中可回收的 TP 佔 FN 總量 < 1%
- 放寬 QUAL 門檻的 F1 提升量級 < 10⁻³，不具實質意義
- **FN 的根本來源是 Variant Caller 未檢測到這些位點**，非 QUAL 篩選所致

### 3. Purity-Aware 門檻的實際效益

- **高純度 (≥80%)**: 可安全使用甲基化過濾，但最佳提升仍極小 (< 0.001)
- **中純度 (40-60%)**: 過濾效果中性至微負，建議關閉或使用極保守門檻
- **低純度 (<40%)**: 任何過濾均傷害 F1，應完全關閉

### 4. 推薦的 Purity-Aware 策略

```python
def get_filter_params(estimated_purity):
    if estimated_purity >= 0.80:
        return {'ad': 0.15, 'cv': 0.03, 'vaf': 0.15, 'enabled': True}
    elif estimated_purity >= 0.60:
        # Conservative: higher AD threshold to avoid TP harm
        return {'ad': 0.30, 'cv': 0.03, 'vaf': 0.10, 'enabled': True}
    else:
        return {'enabled': False}  # No filtering
```
