## 1. 流程概覽

### 1.1 單次分析流程

```
Input BAM (原始 tumor.bam)
  ↓ LongPhase-S 或 LongPhase-TO (haplotagging)
tumor_tag.bam (含 HP tags + MM/ML methylation tags)
  ↓ InterSubMod (甲基化分析)
significance_summary.csv + 各 region 輸出
  ↓ 過濾分析腳本
metrics.json (F1/Precision/Recall + 過濾前後對比)
  ↓ 空間清理
刪除 tumor_tag.bam (僅保留分析結果)
```

### 1.2 批量流程

```
主控腳本 (run_full_benchmark.sh)
  ├── 遍歷所有樣本 × 所有模式 × 所有 purity
  ├── 每個組合執行上述單次流程
  ├── 完成後刪除 tumor_tag.bam
  └── 最終匯總所有 metrics.json → cross_sample_report.csv
```

## 2. 四種驗證模式定義

| 模式代號 | Longphase 工具 | 樣本純度 | 目標 |
|:---------|:---------------|:---------|:-----|
| **`s-pure`** | LongPhase-S | 100% (t50_n00 或原始) | 基準線驗證 |
| **`s-purity`** | LongPhase-S | 不同 purity 梯度 | 純度影響評估 |
| **`to-pure`** | LongPhase-TO | 100% | 工具差異驗證 |
| **`to-purity`** | LongPhase-TO | 不同 purity 梯度 | 工具×純度交互 |

### 2.1 模式 `s-pure`：LongPhase-S 純腫瘤

```bash
# 步驟 1: Germline phasing (正常樣本)
longphase phase \
  -s germline_snp.vcf \
  -b normal.bam \
  -r reference.fasta \
  --ont -t 64 \
  -o phased_normal

# 步驟 2: Somatic haplotagging (含 benchmark)
longphase-s somatic_haplotag \
  -s phased_normal.vcf \
  -b normal.bam \
  --tumor-snv-file somatic_snv.vcf \
  --tumor-bam-file tumor.bam \
  -r reference.fasta \
  -t 64 \
  --tagSupplementary -q 20 \
  --truth-vcf truth.vcf \
  --truth-bed hc_regions.bed \
  -o output_prefix
```

### 2.2 模式 `to-pure`：LongPhase-TO 純腫瘤

```bash
# 步驟 1: Phase (含 PON)
longphase-to phase \
  -s snv.vcf \
  -b tumor.bam \
  -r reference.fasta \
  --ont --loh \
  --caller clairs_to_ssrs \
  --pon-file pon1.vcf.gz,pon2.vcf.gz \
  --strict-pon-file pon3.vcf.gz,pon4.vcf.gz \
  -t 64 \
  -o phased_output

# 步驟 2: Haplotag
longphase-to haplotag \
  -s phased_output.vcf \
  -b tumor.bam \
  -r reference.fasta \
  -t 64 \
  -o tumor_tag
```

## 5. 主控腳本規格

### 5.1 `run_full_benchmark.sh` 設計

```bash
#!/bin/bash
# 大規模甲基化過濾策略驗證 — 主控腳本
#
# 使用方式:
#   ./run_full_benchmark.sh --mode <mode> [--sample <sample>] [--purity <purity>]
#   ./run_full_benchmark.sh --mode all
#
# 模式:
#   s-pure      LongPhase-S, 純腫瘤樣本
#   s-purity    LongPhase-S, 不同純度
#   to-pure     LongPhase-TO, 純腫瘤樣本
#   to-purity   LongPhase-TO, 不同純度
#   all         依序執行所有模式

set -euo pipefail

# === 配置 ===
SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
CONFIG_DIR="${SCRIPT_DIR}/config"
STEPS_DIR="${SCRIPT_DIR}/steps"
OUTPUT_DIR="${SCRIPT_DIR}/output"
REFERENCE="/big8_disk/ref/GRCh38_no_alt_analysis_set.fasta"
THREADS=64
INTERSUBMOD_BIN="/big8_disk/liaoyoyo2001/InterSubMod/build/bin/inter_sub_mod"
LONGPHASE_S_BIN="/big8_disk/liaoyoyo2001/longphase-s/longphase-s"
LONGPHASE_TO_BIN="/big8_disk/liaoyoyo2001/longphase-to/longphase-to"

# === 參數解析 ===
MODE=""
SAMPLE=""
PURITY=""

while [[ $# -gt 0 ]]; do
    case "$1" in
        --mode) MODE="$2"; shift 2 ;;
        --sample) SAMPLE="$2"; shift 2 ;;
        --purity) PURITY="$2"; shift 2 ;;
        --threads) THREADS="$2"; shift 2 ;;
        *) echo "Unknown: $1"; exit 1 ;;
    esac
done

# === 核心函數 ===

run_single_analysis() {
    local sample=$1
    local mode=$2
    local input_bam=$3
    local output_dir=$4

    echo "[$(date)] === 開始分析: ${sample} / ${mode} ==="
    mkdir -p "${output_dir}"

    # Step 1: LongPhase haplotagging
    local tagged_bam="${output_dir}/tumor_tag.bam"
    if [[ "${mode}" == s-* ]]; then
        bash "${STEPS_DIR}/step01_longphase_s.sh" \
            --input "${input_bam}" \
            --output "${tagged_bam}" \
            --sample "${sample}" \
            --threads "${THREADS}"
    else
        bash "${STEPS_DIR}/step02_longphase_to.sh" \
            --input "${input_bam}" \
            --output "${tagged_bam}" \
            --sample "${sample}" \
            --threads "${THREADS}"
    fi

    # Step 2: InterSubMod 分析
    bash "${STEPS_DIR}/step03_intersubmod.sh" \
        --bam "${tagged_bam}" \
        --sample "${sample}" \
        --output "${output_dir}/intersubmod_output" \
        --threads "${THREADS}"

    # Step 3: 過濾分析與 F1 計算
    python3 "${STEPS_DIR}/step04_filter_analysis.py" \
        --summary "${output_dir}/intersubmod_output/significance_summary.csv" \
        --sample "${sample}" \
        --output "${output_dir}/metrics.json"

    # Step 4: 清理 tagged BAM (節省空間)
    bash "${STEPS_DIR}/step05_cleanup.sh" "${tagged_bam}"

    echo "[$(date)] === 完成分析: ${sample} / ${mode} ==="
}

# === 主邏輯 (依模式分派) ===

case "${MODE}" in
    s-pure)
        # 所有 7 個樣本的純腫瘤 + LongPhase-S
        for sample in HCC1395 COLO829 H1437 H2009 HCC1937 HCC1954 COLO829_NYGC; do
            run_single_analysis "${sample}" "s-pure" \
                "$(get_tumor_bam ${sample})" \
                "${OUTPUT_DIR}/s-pure/${sample}"
        done
        ;;
    s-purity)
        # 所有 7 個樣本的不同 purity + LongPhase-S
        for sample in HCC1395 COLO829 H1437 H2009 HCC1937 HCC1954; do
            for purity_bam in $(get_purity_bams ${sample}); do
                purity_label=$(basename $(dirname ${purity_bam}))
                run_single_analysis "${sample}" "s-purity" \
                    "${purity_bam}" \
                    "${OUTPUT_DIR}/s-purity/${sample}_${purity_label}"
            done
        done
        ;;
    to-pure)
        # 類似 s-pure 但使用 LongPhase-TO
        for sample in HCC1395 COLO829 H1437 H2009 HCC1937 HCC1954 COLO829_NYGC; do
            run_single_analysis "${sample}" "to-pure" \
                "$(get_tumor_bam ${sample})" \
                "${OUTPUT_DIR}/to-pure/${sample}"
        done
        ;;
    to-purity)
        # 類似 s-purity 但使用 LongPhase-TO
        for sample in HCC1395 COLO829 H1437 H2009 HCC1937 HCC1954; do
            for purity_bam in $(get_purity_bams ${sample}); do
                purity_label=$(basename $(dirname ${purity_bam}))
                run_single_analysis "${sample}" "to-purity" \
                    "${purity_bam}" \
                    "${OUTPUT_DIR}/to-purity/${sample}_${purity_label}"
            done
        done
        ;;
    all)
        $0 --mode s-pure --threads "${THREADS}"
        $0 --mode s-purity --threads "${THREADS}"
        $0 --mode to-pure --threads "${THREADS}"
        $0 --mode to-purity --threads "${THREADS}"

        # 最終匯總
        python3 "${SCRIPT_DIR}/utils/aggregate_results.py" \
            --input "${OUTPUT_DIR}" \
            --output "${OUTPUT_DIR}/cross_sample_report.csv"
        ;;
    *)
        echo "Invalid mode: ${MODE}"
        echo "Valid modes: s-pure, s-purity, to-pure, to-purity, all"
        exit 1
        ;;
esac
```

## 6. 各步驟腳本規格

### 6.1 `step01_longphase_s.sh` — LongPhase-S Haplotagging

**輸入**: 原始 tumor BAM  
**輸出**: tumor_tag.bam (含 HP tags)  
**核心指令**: `longphase-s somatic_haplotag`

**必要前置**:
- Phased germline VCF（需先完成 Clair3 + LongPhase phase）
- Normal BAM
- Somatic VCF（ClairS 輸出）

**產出 HP tag 格式**:
| HP | 意義 |
|:---|:-----|
| `HP:z:1` | Germline haplotype 1 |
| `HP:z:2` | Germline haplotype 2 |
| `HP:z:1-1` | Somatic on haplotype 1 |
| `HP:z:2-1` | Somatic on haplotype 2 |
| `HP:z:3` | Unassigned |

### 6.2 `step02_longphase_to.sh` — LongPhase-TO Phase + Haplotag

**輸入**: 原始 tumor BAM  
**輸出**: tumor_tag.bam (含 HP tags)  
**核心指令**: `longphase-to phase` + `longphase-to haplotag`

**必要前置**:
- PON 資料庫（pon-file + strict-pon-file）
- Somatic VCF（ClairS-TO 輸出）

**注意**: LongPhase-TO 不需要 normal BAM，但需要 PON 資料庫

### 6.3 `step03_intersubmod.sh` — InterSubMod 分析

**輸入**: tumor_tag.bam + somatic VCF  
**輸出**: significance_summary.csv + per-region 輸出

```bash
#!/bin/bash
# InterSubMod 甲基化分析步驟

BAM=$1
VCF=$2
OUTPUT_DIR=$3
THREADS=$4
REFERENCE="/big8_disk/ref/GRCh38_no_alt_analysis_set.fasta"
INTERSUBMOD_BIN="/big8_disk/liaoyoyo2001/InterSubMod/build/bin/inter_sub_mod"

${INTERSUBMOD_BIN} \
  --bam "${BAM}" \
  --vcf "${VCF}" \
  --ref "${REFERENCE}" \
  --output "${OUTPUT_DIR}" \
  --threads "${THREADS}" \
  --window 1000 \
  --min-mapq 20 \
  --log-level INFO
```

### 6.4 `step04_filter_analysis.py` — 過濾分析

**輸入**: significance_summary.csv + VCF (取 QUAL, VAF)  
**輸出**: metrics.json

```python
#!/usr/bin/env python3
"""
過濾分析腳本: 應用甲基化過濾條件並計算 F1-score

輸入:
  - significance_summary.csv (InterSubMod 輸出)
  - TP/FP VCF (含 QUAL, VAF)
  - Truth set 資訊 (SEQC2 total count)

輸出:
  - metrics.json: {
      "sample": str,
      "mode": str,
      "purity": str,
      "baseline": {"tp": int, "fp": int, "fn": int, "precision": float, "recall": float, "f1": float},
      "filtered": {"tp": int, "fp": int, "fn": int, "precision": float, "recall": float, "f1": float},
      "improvement": {"f1_delta": float, "f1_pct": float, "fp_removed": int, "tp_removed": int}
    }

過濾條件:
  Remove if: (QUAL < 0.75) OR (AlleleDelta > 0.25 AND CramersV < 0.05 AND VAF < 0.24)
"""

import json
import pandas as pd
import sys

def apply_filter(row):
    """判定是否為假陽性"""
    if row['QUAL'] < 0.75:
        return True
    if (row['AlleleDelta'] > 0.25 and
        row['CramersV'] < 0.05 and
        row['VAF'] < 0.24):
        return True
    return False

def calculate_metrics(tp_kept, fp_kept, truth_total):
    """計算 Precision, Recall, F1"""
    fn = truth_total - tp_kept
    precision = tp_kept / (tp_kept + fp_kept) if (tp_kept + fp_kept) > 0 else 0
    recall = tp_kept / truth_total if truth_total > 0 else 0
    f1 = 2 * precision * recall / (precision + recall) if (precision + recall) > 0 else 0
    return {
        'tp': tp_kept, 'fp': fp_kept, 'fn': fn,
        'precision': round(precision, 4),
        'recall': round(recall, 4),
        'f1': round(f1, 4)
    }
```

## 7. 空間管理策略

### 7.1 估算空間需求

| 項目 | 每次分析 | 說明 |
|:-----|--------:|:-----|
| tumor_tag.bam | ~150 GB | LongPhase 輸出，**分析後刪除** |
| InterSubMod 輸出 | ~500 MB-2 GB | significance_summary.csv + per-region |
| metrics.json | < 1 KB | 過濾結果摘要 |
| **淨空間需求** | ~2 GB | 刪除 BAM 後 |

### 7.2 空間管理原則

1. **序列執行**：一次只產生一個 tumor_tag.bam
2. **即時清理**：每完成一次分析即刪除 tumor_tag.bam
3. **峰值空間**：~150 GB（一個 tumor_tag.bam 的大小）
4. **最終空間**：~50 個分析 × 2 GB ≈ 100 GB

### 7.3 可選壓縮策略

```bash
# 可選: 壓縮 per-region 輸出 (通常佔空間最大)
tar -czf "${OUTPUT_DIR}/regions.tar.gz" "${OUTPUT_DIR}/intersubmod_output/"
rm -rf "${OUTPUT_DIR}/intersubmod_output/"
# 僅保留 significance_summary.csv 和 metrics.json
```

| sample | 樣本名稱 |

| purity | 純度標籤 (t50_n00 等) |
| baseline_f1 | 未過濾 F1 |
| filtered_f1 | 過濾後 F1 |
| f1_improvement | F1 提升幅度 |
| fp_removed_pct | FP 移除率 |
| tp_removed_pct | TP 誤刪率 |
| total_tp | 總 TP 數 |
| total_fp | 總 FP 數 |

### 8.3 最終報告

`utils/generate_report.py` 讀取 `cross_sample_report.csv` 生成：

1. **跨樣本 F1 比較表**：確認門檻的泛化性
2. **模式比較**：LongPhase-S vs TO 的效果差異
3. **Purity 影響曲線**：F1 隨 purity 的變化
4. **門檻穩健性**：不同樣本是否需要不同門檻
