2.觀察起點：17.3:1 偏移與 chr19 SP1/2/3

§2.1 全基因組 HP1:HP2 = 17.3:1（94.6% 偏 HP1）— 3 條獨立論證 obs
指標baseline隨機預期偏離
HP1 reads（somatic ALT）614,000~325,0001.89×
HP2 reads（somatic ALT）35,500~325,0000.11×
HP1:HP217.3:11:117.3×
HP1 占比94.6%~50%+44.6 pp

為什麼真實存在（3 條獨立論證）：

  1. 生物學：tumor 的 somatic ALT 屬某 sub-clone 的真實 haplotype，跨 23 染色體不該系統性偏 HP1。
  2. 跨染色體一致：cnLOH artifact 只影響單一 chr；94.6% 跨 23 chr 同向必為工程 bias。
  3. paired GT 對照：paired tumor-normal 同樣 reads HP1:HP2 ≈ 1:1；只 TO 模式出現 17.3:1。
§2.2 chr19 SP1/2/3 三極端案例（113:0 / 109:1 / 108:0）— V5 翻回 paired 3/3 obs
位點染色體位置baseline HP1:HP2V5 HP1:HP2vs paired

SP2chr19:12,452,332109 : 1翻 HP2對齊 ✓
SP3chr19:12,467,180108 : 0翻 HP2對齊 ✓

SP1/SP3 完全失衡（0 reads 對側），SP2 僅 1 → 不是噪音、caller、alignment 問題；是 read assignment 強制集中。baseline 與 paired 方向相反（baseline HP1 → paired HP2）→ 翻轉而非弱化。V5 修正後 3/3 翻回 paired → 「修對了」初步證據。

8.顛覆性發現 — 三項 chr19 結論被推翻 + V5 Layer 1.5 設計缺陷

§8.1-8.4 三項 chr19 結論顛覆：占比 2.16% / chr8 冷區 / Layer 1.5 在 germline-absent 區觸發 +560,881 TWIST
  1. chr19 不是 hotspot — 占全基因組 priority bug 僅 2.16%（rank 19）；主要分佈 chr7 / chr2 / chr1 / chr16 / chr20
  2. chr8 是 priority bug 冷區（0.34× avg, rank 21）— 與 chr8 LOH+HPSig 7.4× FP enrichment 是不同 layer
  3. Layer 1.5 在 germline 缺席區觸發 +560,881 reads — V5 改 GT2 reclassify 104K germline het → reads shift Layer 1 → Layer 1.5（zero-sum 重分配）
機制因果不變：priority bug 仍是真，V3F/V5 仍 100% 修對。但 hotspot 詮釋與 Layer 1.5 觸發角色都需修訂。
