§4 L2 條件式自動載入 Rules

位於 .claude/rules/，由 CLAUDE.md 引用，符合特定編輯條件時自動載入到上下文。設計目的：降低 always-loaded 部分大小（CLAUDE.md ≈ 3K tokens）。

output-structure.md操作 output/Region 目錄結構、檔案說明
觀察：rules 機制不是 Claude Code 原生功能，而是透過 CLAUDE.md「自動載入於 .claude/rules/xxx.md（觸發：...）」的提示式約定。實際上 Claude 並無 hook 強制讀取對應 rules — 是模型在 CLAUDE.md 中讀到引用後自主拉取。
風險（Q3）：模型可能忽略條件，導致規則文字在 CLAUDE.md 中存在但未被遵循。

§10 合理性質疑與待決策清單

  • Q1 [高] defaultMode 不一致：全域 auto vs 專案 acceptEdits。用戶可能不確定何時自動接受編輯、何時需確認。
    建議：明文規範三模式邊界（auto 用於 headless / acceptEdits 用於互動研究 / ask 用於探索）。
