17.3:1 = L1 assignment 1.77:1 × L2 priority bug 9.8×（兩 mechanism 疊乘，不是 single 17× bug）：
  • L0 設計層（self-phasing circular dep, 球員兼裁判）→ ✅ 修對 (8b8c1fd PON-only)
  • L1 Phasing (a)（phased VCF 結構）→ ✅ 修對 (d0bcd8c)

V3F alone (沒 PON-only) 即修對 17:1 核心 — v3f_no_pononly BAM chr19 實測 1.21:1（17.3 → 1.21 = 移 L2 9.8× 放大後接近 L1 1.77 assignment）。PON-only 是 L0 修補，非 17:1 必要 commit。詳見 13 段技術報告 §5.3 + erratum E5 §3a.5b.12。

§ 1 一張圖看 bug（L2 priority bug 機制） ≈ 30 sec

同一 countMap 輸入（HP2 有 5 票 germline、HP1_1 有 1 票 somatic），baseline 與 V6 輸出方向完全相反。這張圖是 L2 priority bug 與修補的最短敘述（不含 L0 / L1 機制，後者見 13 段技術報告）。

  • Bug 位置：longphase-to/HaplotagProcess.cpp:506-530 的 getVote()。
  • 單一函式內：reorder pair + remove break 即解；API signature 不變、外部 caller 零影響。

§ 2 為何放大到 17.3 倍而非 5 倍 ≈ 30 sec

單一機制不足以解釋 17.3:1。是兩個放大器疊乘的湧現結果：tumor 生物學提供「方向一致性」，algorithm 設計提供「規模放大」。

  • 關鍵洞察：bug 不創造方向，只放大上游已有的微小偏向。Paired mode 同樣 biology 但用不同 binary（longphase-s），結果 1:1.275 ≈ 1:1，證實放大器 B 是唯一可修部位。
  • 單機制反例：若僅有 biology 偏向，比應約 1.1:1（germline 主導）；若僅有 algorithm bug 而 somatic 隨機，比應約 1.5:1（部分讀數受影響）。觀察值 17.3:1 必須兩者疊加。

§ 3 修補：移除 algorithm 放大器 ≈ 30 sec

V6 把 getVote() 從 3-pair ordered + break 結構整個拆掉，改成 explicit two-layer：Layer 1 germline 永遠先決定方向，Layer 2 somatic 只決定 11/21/33 後綴。

V6 強制三個 invariants：
  1. never short-circuit germline：無 break；germline 永遠被讀
  2. somatic does not pick direction：除非 germline 全為 0，否則 somatic 不參與方向決策
  3. germline-absent 保守：germline=0 且 somatic>0 → HP:i:33（不從 somatic 推方向）

§ 4 驗證：5 gates + 4 樣本一致 ≈ 45 sec

V6 通過 5 個外部可觀察 verification gates。每 gate 含具體數值 / 檔案輸出 / 命令成功標準（非主觀判斷）。跨樣本一致性 4/4 通過，HCC1395 V5 baseline 1.86 也壓回近中性。

  • 無副作用：Gate 5 caller F1 完全相同（0.7166 / 0.6273），V6 只動 tagging layer，caller 不受影響。
  • 單一阻塞：COLO829 VCF permission 阻塞 5-sample expansion（4/5 已具足夠信心通過）。

§ 5 結論與下一步 ≈ 15 sec

結論 V6 = production-candidate（修對 L0+L2，覆蓋 4 層中 3 層）。Bug 在單一函式內，修補不改 API signature，外部 caller 零影響。
核心 fix 歸功 V3F (41ff147) alone 即修對 17:1 主軸（L2 priority bug 9.8× 放大）— v3f_no_pononly 實證 17.3 → 1.21:1。PON-only (8b8c1fd) 修 L0 self-phasing 設計（LOH 31.2% artifact / N50 +99.7%），非 17:1 必要 commit；但完整 production candidate 仍需 5 commits 累積。
