§4 為何 F1 不變 — 從 source code 機制圖示

F1 評估流程 + longphase 改動範圍

[Step 1] ClairS-TO caller
   ↓ snv.vcf.gz: 49,987 variants, FILTER 欄已決定
   ↓ (753 PASS = F1 唯一輸入集合)
   ↓
[Step 2] longphase phasing  ← 改動 8b8c1fd / d0bcd8c / 938f0df
   ↓ convertNonGermlineToSomatic() — 簡化 phasing graph
   ↓ somaticCalling()           — 重新分類 SOMATIC/PON/GERMLINE
   ↓ syncPhasingResultOrigins() — sync GT 格式 (0/1 → 0|1)
   ↓
   ↓ ★ 不動 FILTER 欄 (source grep "FILTER write" = 0) ★
   ↓ tumor_phased.vcf: 加 PS (phase set ID) + GT (phased)
   ↓
[Step 3] longphase haplotag  ← 改動 41ff147 / 380e8d2
   ↓ getVote() + judgeHaplotype()  — 兩層投票
   ↓
   ↓ ★ 不動 VCF (BAM tag 不寫回 VCF) ★
   ↓ tumor_tagged.bam: 加 HP:i: read-level tag
   ↓
[Step 4] F1 evaluation
   ↓ bcftools isec --filter "PASS"
   ↓ 抽 FILTER=PASS variants 與 ground truth 比對
   ↓ → caller_passed 集合與 input 100% 相同
   ↓ → TP/FP/FN 不變
   ↓ → F1 = 0.7166 mathematically invariant

→ longphase 改的 (PS / GT / HP:i:) 與 F1 看的 (FILTER) 在 VCF 不同欄位, 數學上 orthogonal。phasing 不論多大改, F1 都不會動。

§6 Bottom Line

✅ V6 = production candidate

  1. 對 baseline 全面改善 — 17.3:1 → 1.84:1 / Phase N50 +99.7% / Phased% +23.6pp / paired GT +13.3pp / 4 樣本 ratio 中性 / marker coverage +9%
  2. 對 V3F 是 trade-off — V6 在 cross-sample + marker eng 勝, V3F 在 ratio + germline preservation 勝
  3. 對 V5 在 HCC1395 5kHz 不可區別 (V5 BAM = V6 BAM 0 diff), V6 優勢在 cross-sample 4 樣本顯現
  4. 真實價值在 read-level paired GT (+13.3 pp) + cross-sample 穩定化, 不在 caller F1 (FILTER 不動 → 數學保證 invariant)

給 PI 報告可以強說的 5 鐵證

  1. 發現並修好 longphase-to 一個被忽略的 priority bug (V3F two-layer getVote `41ff147`) — read-level 17.3:1 → 1.84:1
  2. PON-only Pass 2 解決 self-phasing circular dependency (8b8c1fd) — Phase block N50 +99.7%, Phased rate +23.6 pp
  3. caller F1 = 0.7166 invariant 經驗證實 (不是巧合) — longphase 完全不動 FILTER, row-by-row identical
  4. V6 = production candidate — cross-sample 4 樣本 ratio 中性化 (0.61-1.24) + marker coverage +9.0%
  5. 真實價值在 read-level (+13.3 pp paired GT concordance) — 不在 caller F1

需要小心說的 3 個 caveat

  1. V6 vs V3F 不是全面更好 — V3F 有 ratio 1.14:1 最佳 + 保留 21% germline-only outcomes
  2. V6 vs V5 在 HCC1395 5kHz 不可區別 — V6 優勢只見 cross-sample (4 樣本 ratio 中性化)
  3. 「34,855 reads V6 100% 修對」原 framing 過強 — V3F (41ff147) 是 100% 修對主力; V6 對廣義 17,404 subset partial (44.6% 翻方向)
