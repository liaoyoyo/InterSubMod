## 2. 驗證階段（3 個平行 agents）

修正前先進行獨立驗證，確保修正方向正確。三個 agent 分別負責不同面向的事實查核。

### Agent A: HP Tag 格式驗證

- **目的**：確認 HP:i:11 / HP:i:21 / HP:i:33 的真正語義
- **查閱來源**：
  - `src/core/ReadParser.cpp` 第 129-141 行（ISM 原始碼中的 switch-case mapping）
  - Knowledge Base `05_tools/longphase_s.md`（LongPhase-S HP tag 格式定義）
  - Knowledge Base `05_tools/longphase_to.md`（LongPhase-TO 輸出與判讀邊界）

- **關鍵發現**：

  1. **HP:i:11 = somatic-supported haplotype 1**（用戶直覺正確）
     - LongPhase-S 字串格式 `HP:Z:1-1` 對應 LongPhase-TO 整數格式 `HP:i:11`
     - Knowledge Base 明確定義：「支持 somatic ALT，且可追溯到 germline haplotype 1 的 read」
     - ISM ReadParser.cpp 的 mapping：`case 11: info.hp_tag = "1-1"; break;`
  2. **第二個數字 = somatic support indicator，不是 phase block ID**
     - `1-1` 格式中的 `-1` 代表「somatic ALT support」，不是 phase block 編號
     - 整數格式中 `11` = 十位數 `1`（haplotype 1）+ 個位數 `1`（somatic support）
  3. **HP:i:33 = ambiguous somatic，不是第三個 haplotype**
     - 對應 LongPhase-S 的 `HP:Z:3`
     - Knowledge Base 判讀邊界明確指出：「HP:z:3 是 ambiguous somatic haplotype，不是 LOH 標記」
     - ISM 的 mapping：`case 33: info.hp_tag = "3"; break;`

- **影響範圍**：需修正 `01_hp_integer_tag_fix.md` 和所有提到 HP tag 格式的文件中，任何將第二個數字解讀為「block ID」的描述

- **驗證結果彙整**：

  | HP 整數值 | ISM 映射 | 正確語義 | 先前可能的誤讀 |
  |-----------|---------|---------|--------------|
  | 1 | "1" | Germline haplotype 1 | （無誤讀） |
  | 2 | "2" | Germline haplotype 2 | （無誤讀） |
  | 11 | "1-1" | Somatic-supported, haplotype 1 | 誤為「block 1 的 haplotype 1」 |
  | 21 | "2-1" | Somatic-supported, haplotype 2 | 誤為「block 1 的 haplotype 2」 |
  | 33 | "3" | Ambiguous somatic | 誤為「第三個 haplotype」 |

### Agent B: LOH-like / Region / Tier 定義驗證

- **目的**：確認定義的精確性，以 source code 為 ground truth
- **查閱來源**：
  - `src/core/RegionProcessor.cpp` 第 38-49 行（`compute_hp_ratio` + `is_potential_loh`）
  - `scripts/analysis/build_loh_round1_cross_sample_audit.py` 第 643 行（`effective_hp_reads` 計算）
  - `scripts/analysis/build_loh_round2_support_hp0_analysis.py` 第 57-73 行（Tier 定義）

- **關鍵發現**：

  1. **LOH-like 閾值 0.1/0.9 -- source code verified**
     - `RegionProcessor.cpp:47-48`：`return (hp_ratio < 0.1) || (hp_ratio > 0.9);`
     - 此為 ISM 自身的 region-level proxy，與 LongPhase 的 `LOH.bed` 是完全不同的判定系統
     - ISM LOH-like 基於 read-level HP 分佈比例，LongPhase LOH.bed 基於 phased genotype ratio
  2. **effective_hp 定義確認**
     - `build_loh_round1_cross_sample_audit.py:643`：`df["effective_hp_reads"] = df["HP1FamilyN"].fillna(0) + df["HP2FamilyN"].fillna(0)`
     - 確認：effective_hp = HP1FamilyN + HP2FamilyN，**排除 HP0 和 HP3**
     - HP0 = unphased reads，HP3 = ambiguous somatic reads，兩者不計入 LOH 判定的分母
  3. **HP Ratio 計算公式確認**
     - `RegionProcessor.cpp:38-42`：Laplace smoothing 以 epsilon = 0.001 實現
     - `hp_ratio = (HP1FamilyN + 0.001) / (HP1FamilyN + HP2FamilyN + 0.002)`
     - 當 effective_hp = 0 時，hp_ratio = 0.001/0.002 = 0.5（HP_Ratio=0.5 陷阱的根源）
  4. **Tier 邊界是經驗性的，非理論推導**
     - `build_loh_round2_support_hp0_analysis.py:58-70` 定義：
       - Tier C0：effective_hp = 0（完全無 HP 資訊）
       - Tier C：effective_hp 1-9（極弱 support）
       - Tier B：effective_hp 10-29（中等 support）
       - Tier A：effective_hp >= 30（強 support）
     - 這些邊界是分析過程中根據 enrichment pattern 確認的經驗閾值
  5. **分佈數據**：
     - Paired：TP 中位 effective_hp = 68，FP 中位 = 32
     - TO：TP 中位 effective_hp = 72，FP 中位 = 63

- **影響範圍**：需補充到 `00_background.md` 的術語表和定義段落，確保 LOH-like、effective_hp、Tier 的定義在全系列文件中一致

### Agent C: Cell Line 與 Confound 研究

- **目的**：評估 cell line 限制的嚴重性，以及 confound 跨樣本的差異程度
- **查閱來源**：
  - 文獻調查報告（`08_literature_survey.md`）
  - O11/O12 workspace 的 confound 分析
  - TO FP provenance 報告（`docs/reports/validated/2026/03/`）

- **關鍵發現**：

  1. **Cell line 是方法開發的標準做法**
     - SEQC2 consortium（多平台 somatic variant calling benchmark）使用 HCC1395 等相同 cell line
     - DeepSomatic、ClairS 的 training/evaluation 也基於 cancer cell line
     - Cell line 提供 truth set（paired normal + high coverage），是目前唯一可提供大規模 TP/FP 標籤的系統
  2. **推廣到臨床的已知限制**
     - Cell line 長期培養可能產生 culture-induced methylation drift
     - Tumor microenvironment（基質細胞、免疫細胞）在 cell line 中不存在
     - Purity 接近 100%，與臨床樣本（purity 30-80%）差異顯著
     - 推廣需要 tissue-origin correction + purity-aware analysis
  3. **TO FP 本質確認**
     - TO FP 中約 99% 為 germline variant（根據 paired_raw_absent 統計：98.55-98.74%）
     - 這是 tumor-only calling 的根本限制，不是 ISM 特有問題
     - ISM 特徵無法有效區分 germline 和 somatic，因為兩者在 epigenetic context 中表現近似
  4. **n_reads confound 跨樣本程度不同**
     - HCC1395：n_reads AUC(TP vs FP) = 0.926（極強 confound）
     - H2009：n_reads AUC = 0.634（中等）
     - 這意味著以 pooled dataset 進行的 confound correction 在不同樣本上效果不均

- **影響範圍**：需在 `00_background.md` 新增 Cell Line 限制段落，並在 `09_conclusions_and_actions.md` 的所有核心結論後加入外部效度 disclaimer
