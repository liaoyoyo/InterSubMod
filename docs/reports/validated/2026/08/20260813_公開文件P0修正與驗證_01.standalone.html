3. 科學證據 ceiling

可保留的核心說法 同一 read record 上的 allele 共現是 recorded/called molecular evidence，不是無誤差 cellular truth；98,955 → 85,941 → 75,224 → 71,955 是可重算 funnel；63,506/71,955=88.2579% 是唯一 rooted-unlabeled topology signature，其中可包含多個並列 labeled trees；3/811=0.3699% 是 formal methylation association。
必須撤回或加限定 confirmed cellular clone、linear ancestry、canonical CCF、methylation 獨立確認、correct rescue tag、gene silencing 與唯一 whole-sample phylogeny。
四個常用術語的操作定義

family-complete：minimum candidate vertex-set family 已完整枚舉且未撞 SEARCH_NODE_GUARD。ranked-complete：再要求 read-AF 可用且通過 recurrence screen。robust：只指 frozen methyl manifest 保留的 association 類別，不代表因果。normal-ASM-screen-negative：只表示未命中既定 normal ASM screen，不證明 normal ASM 不存在，也不證明 tumor-acquired／clone-specific。

7. 必須補的資料

以下依「能否改變 claim ceiling」排序，而不是依取得容易度排序；前三項是本輪 top 3，其餘為後續升級 gate。

  1. Allele-specific CN／LOH + purity／ploidy／multiplicity + CCF uncertainty。每 locus/block 保留 caller、version、segment、normal contamination 與 confidence。
  2. 獨立 cellular truth。優先 single-cell DNA 或 joint DNA-methylation、single-cell-derived colonies；次選 spatial／multi-region／longitudinal。不可仍由同一 bulk reads 派生。
  3. Known-truth simulation／physical mixtures。預先固定 genotype/tree/frequency、CN/LOH、coverage、MM/ML error，報 topology、frequency、abstention 與 calibration。
  4. Next gate — 跨 biological samples replication。HCC1395 與 DORADO 只是 technical pair；至少需第二 biological sample 與預註冊 gate。
  5. Methylation rescue truth。需 per-read truth、coverage strata、confusion matrix、abstention、calibration、false-rescue rate 與 held-out validation。
  6. Functional assay。gene regulation／silencing 需 RNA、chromatin 或 perturbation；local methylation alone 不足。

  • 有授權的 tiny BAM/CRAM + index、FASTA + index、VCF fixture。
  • SHA-256、license、reference build、tool/container lockfile。
  • Fresh-clone CI：build → fixture run → schema/hash acceptance。
