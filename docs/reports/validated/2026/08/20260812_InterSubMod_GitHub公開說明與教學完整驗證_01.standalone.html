6. 重要確認清單：為何可確認

  • 7 technical datasets／6 biological IDs／469,849 records：authority JSON 可重算，7/7 scope pass；technical pair 不當 biological replicate。
  • 170,131/255,752=66.5219%：arithmetic 與 denominator registry 一致；只確認 strict-component k=1。
  • 63,506/71,955=88.2579%：funnel 加總自洽；只確認 ranked mathematical shape。
  • 3/811=0.3699%：formal methyl registry 可重算；只確認 conditioned regional association。
  • paired-pure read-level ΔF1=+0.011159：95% bootstrap CI +0.004437 到 +0.018808；73,230 reads／537 regions 的 frozen comparison；不是 variant caller whole-genome F1。
  • HCC1395 paired/TO variant ΔF1=+0.000981/+0.000274：canonical outputs 可重算；不泛化其他樣本。
  • VAF Spearman≈0.909：technical pair reproduction；不能改名 accuracy 或 truth。
  • InterSubMod build＋tests：fresh configure/build exit 0；direct 270/39 PASS；CTest 270/270 PASS。
  • One-locus runtime：1.90 s、85 reads、11 CpGs、3,443 valid／127 invalid pairs；同時確認 <100 reads 會 fallback，非 KDE-corrected benchmark。
  • LongLineage feature foundation：clean build、47/47、check_all FOUNDATION_PASS；stdout 仍列 release blockers。
  • Pages deployment：17/17 HTTP 200、live bytes 與 deploy source 相同。
  • Sidecar 5.83 GiB：7 檔 exact sum=6,256,168,164 bytes；此確認不延伸到未登錄的 tagged BAM。

新版新增的 6 個 regression

REGRESSED

HP family = physical copy

未校正 CN/LOH、沒有 parental origin 時，只能稱 phase/haplotag read families；不能視為可識別的實體 chromosome copy。

REGRESSED

Likelihood product 必然錯

條件獨立性與 misassignment bias 取決於完整生成模型；需 simulation/calibration，不能先固定偏誤方向。

REGRESSED

ξ 主導 error floor

缺 ξ decomposition/calibration，現有式子也未涵蓋 mapping、chimera、Hamming-1 與 partial coverage。

REGRESSED

δ·r = detection limit

Background probability 不等於 detection limit；還需 n、α、power、multiple testing 與 detector definition。

REGRESSED

Optimizer 幾毫秒收斂

頁面同時承認 non-concavity/multi-start，卻無 hardware、input、repeat、failure-rate benchmark。

REGRESSED

Production likelihood

spec 尚未 calibration/simulation/truth-set/deployment gate，只能稱 proposed likelihood。

10. 我們最需要補的資料

科學 P0

Allele-specific CN/LOH/purity/CCF

每 locus/block 需 caller/version、segment confidence、purity/ploidy、multiplicity、CCF uncertainty。Coverage proxy 不等於 correction。

科學 P0

Independent cellular truth

single-cell DNA/joint methyl、colonies、spatial/multi-region 或 longitudinal；必須能把 molecule state 對回 cell population。

科學 P0

Known-truth benchmark

固定 genotype/tree/frequency/CN/LOH/error 的 simulation/mixture，報 topology、frequency、abstention、calibration。

科學 P0

Biological replication

HCC1395/Dorado 是 technical pair；需不同 biological samples 的 pre-registered held-out replication。

科學 P0

Per-read rescue truth

若主張 correct tag，需 confusion matrix、false-rescue、abstention、calibration 與 held-out validation。

工程 P0

Portable fixture + claim registry

tiny licensed BAM/FASTA/VCF、hash、expected outputs；每 claim 連 validator、分母、版本與 status。

證據 P1

Storage registry

7 tagged BAM exact bytes/hash/compression；另做 BAM field-level byte census。

證據 P1

Performance benchmark

hardware、compiler、commit、inputs、repeats、median/IQR/tails、threads curve。

定位 P2

Dated novelty review

databases、query、date、納排與 head-to-head；沒有就不說 first/unique。
