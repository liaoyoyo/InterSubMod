## 3. 科學敘述的證據上限

```text
read record 上的 allele、HP/PS、MM/ML calls
                ↓ recorded/called evidence [L1；仍有測序、比對與 tag-calling error]
同一物理分子的局部共現與甲基 pattern
                ↓ 模型條件推論 [L2]
local recurrence-allowed mutation-state candidate
                ↓ 分組後 association [L2]
genetic-pattern-conditioned regional methylation
                ╫ 目前缺資料
allele-specific CN/LOH + purity/ploidy/multiplicity + cellular truth
                ╫
confirmed cellular clone / lineage / whole-sample phylogeny / function
```

### 可確認 [L1/L2]

- 一筆 read/alignment record 對應一條被定序的 DNA fragment；其 allele、HP/PS、MM/ML 是 recorded/called evidence，仍受測序、比對、phasing 與 tag-calling error 影響，不是無誤差的物理真值。
- `170,131 / 255,752 = 66.5219%` 是 strict read-linkage components 的 `k=1` 比例。
- 相對 469,849 dataset records，`170,131 / 469,849 = 36.2097%`；兩者 grain 不同。
- 98,955 final groups → 85,941 mutation-bearing → 75,224 family-complete → 71,955 ranked-complete。
- `63,506 / 71,955 = 88.2579%` 是一種 ranked mathematical shape，不是 clone accuracy／prevalence。
- formal methylation 為 1,045 frozen → 811 evaluable → 3 robust；`3/811=0.3699%`，只支持 association。

操作定義：`family-complete` 是 minimum candidate vertex-set family 已完整枚舉且未撞 `SEARCH_NODE_GUARD`；`ranked-complete` 再要求 read-AF 可用且通過 recurrence screen；`63,506` 指唯一 rooted-unlabeled topology signature（可能有多個並列 labeled trees）；`robust` 只指 frozen methyl manifest 保留的 association 類別；`normal-ASM-screen-negative` 只表示未命中既定 normal ASM screen，不證明 normal ASM 不存在，也不證明訊號為 tumor-acquired／clone-specific。

### 尚不可確認 [L4/L5]

- read 的 originating cell、cellular co-membership、clone 數與 biological lineage。
- 未整合 allele-specific CN、LOH、purity、multiplicity 時的 canonical CCF。
- methylation 對 clone 的獨立確認、因果演化 clock、基因沉默或正確 per-read rescue tag。
- whole-sample、唯一且已確認的 tumour phylogeny。

## 8. 目前最需要補的資料

以下依「能否改變 claim ceiling」排序，而不是依取得容易度排序。

### 最優先三類科學真值資料

1. **Allele-specific CN／LOH + purity／ploidy／multiplicity + CCF uncertainty。**每 locus/block 需保留 caller、version、segment、normal contamination 與 confidence；沒有這些，只能把 VAF transform 稱案例近似值。
2. **獨立 cellular truth。**優先 single-cell DNA 或 joint DNA-methylation、single-cell-derived colonies；次選 spatial／multi-region／longitudinal。真值不可仍由同一批 bulk reads 派生。
3. **Known-truth simulation／physical mixtures。**預先固定 clone genotype/tree/frequency、CN/LOH、coverage、MM/ML error，報 topology、frequency、abstention 與 calibration，而不只報可收斂案例。
### 後續升級 gate

4. **跨 biological samples replication。**HCC1395 與 DORADO 是同一 cell line 的 technical pair，不是 biological replicate；至少需第二 biological sample 與預註冊 gate。
5. **Methylation rescue 真值。**若要宣稱 correct tag，需 per-read truth、coverage strata、confusion matrix、abstention、calibration、false-rescue rate 與 held-out validation。
6. **Functional assay。**若要宣稱 gene regulation／silencing，需 RNA、chromatin 或 perturbation evidence；只有 local methylation 不足。

### P0 公開重現性資料

1. 有授權的 tiny BAM/CRAM + index、FASTA + index、VCF fixture。
2. 每個 input/output 的 SHA-256、license、reference build、tool/container lockfile。
3. Portable wrapper 與 CI smoke：fresh clone → build → fixture run → expected schema/hash。
4. 統一 version manifest：default README、繁中 README、Wiki、Pages、CCU deploy 都指向相容 commit。

### P1 文件與可存取性

1. 修 24 個 InterSubMod P1/P2，特別是 storage receipt、novelty search、benchmark runtime、file counts 與 statistical wording。
2. 修 26 個歷史 SVG 的 `<title>/<desc>`；不把 0 static FAIL 當成 WCAG 全通過。
3. 將 claim registry／guard 納入 CI，generator 與 generated output 同時驗證。

## 10. 外部研究對齊

- [L3] PairClone 顯示 short reads 的 proximal mutation pairs 也能提供 linkage；因此應寫「long reads 提供更長距離 joint evidence」，不能寫成 short reads 原理上只有 marginal VAF。[PairClone](https://academic.oup.com/jrsssc/article/68/3/705/7058355)
- [L3] Single-/multi-bulk reconstruction 可在 purity、CN、multiplicity 與模型假設下做 benchmark；這反駁「single bulk 完全不可能」，但不保證唯一或無偏。[Practical guide](https://pmc.ncbi.nlm.nih.gov/articles/PMC7867630/)
- [L3] 2024 DREAM benchmark 使用 truth-known simulated tumours 系統比較 subclonal reconstruction，支持本報告要求 known-truth simulation、校準與 failure analysis。[DREAM benchmark](https://www.nature.com/articles/s41587-024-02250-y)
