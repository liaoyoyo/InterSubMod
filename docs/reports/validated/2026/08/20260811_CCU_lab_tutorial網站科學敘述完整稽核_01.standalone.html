3.六個 P0 頁面會把讀者帶過證據上限

Evidence / Verdict

★★★★★ L1 haplotype/molecular carrier state 不是 cell ID；LongPhase-S 的 estimand 是 tumour DNA fraction，即使輸出欄位名為 purity。需重寫。

★★★★★ L1 tag 表示局部 germline/somatic haplotype carrier 類別，不是 orthogonally confirmed clone。層級錯置。

8.四段替換文字可直接把敘事拉回證據範圍

首頁

我們把 long reads 指派到局部 germline/somatic haplotype state，辨識支持 somatic variants 的 DNA molecules，並在明示模型假設下估計 tumour DNA fraction。這些輸出不等同單一細胞身分、cellular purity 或完整 clone lineage。

M9

固定 exact PS、HP 與 genetic pattern 後，可檢驗區域 methylation 是否仍與分子 pattern 關聯；這是 association-only auxiliary evidence，不能單獨把 reads 指派為不同 cellular clones。

M12

Somatic haplotagging 把 reads 指派到局部 germline/somatic haplotype-carrier classes。相同 tag 表示在該模型與 phase block 下共享分子狀態，不代表已確認來自同一癌細胞群。

M13 / 全站共通

在特定圖模型與 error assumptions 下，真正候選可能呈現較一致的 local haplotype path；這是可檢驗假說，不是必然規則。若候選本身參與 phasing/haplotagging，HP concentration 不是獨立驗證。

10.沒有 orthogonal truth 時，「尚未確認」不能寫成「生物上不存在」

  • confirmed cellular subclone=0 是目前沒有案例跨過正交確認門檻，不是腫瘤真實 subclone prevalence=0。
  • 3 個 robust methyl associations 沒有 same-locus cross-sample replication；不能升格為 clone，也不表示 methylation 完全無資訊。
  • HCC1395 與 HCC1395_DORADO 是 technical pair；高 reproducibility 不等於跨病人泛化。
  • 本 repo 的 TO negative generalization evidence 不直接推翻 LongPhase-TO 的特定 paper benchmark。
  • HCC1395 LOH bp-level F1≈0.9625 可重算，但只限固定 cell line/reference/parameters。
  • 這份判定只適用網站 commit 46b6f5b…e605；網站更新後需重新 audit。
