## 3. 錯誤原因分析

### 3.1 F1 計算公式問題

報告中可能使用的錯誤公式：
```
F1 = 2 * TP_kept / (2 * TP_kept + FP_kept + 0)
   = 2 * 28167 / (2 * 28167 + 4057)
   = 0.9328  # 接近報告的 0.8985
```

正確公式（考慮 Gold Standard）：
```
Precision = TP_kept / (TP_kept + FP_kept) = 28167 / 32224 = 0.8741
Recall = TP_kept / Gold_Standard_TP = 28167 / 39450 = 0.7140
F1 = 2 * P * R / (P + R) = 0.7860
```

### 3.2 問題核心

報告假設 **FN = 0**（沒有漏報的 TP），這是錯誤的。

實際情況：
- Quality Score >= 40 排除了 **2,309 個 TP**（這些是錯誤排除）
- 只排除了 **765 個 FP**（這些是正確排除）
- **TP 排除數 > FP 排除數**，導致整體 F1 下降

- Quality Score AUC: **0.6243** (+10.2%)

### 5.2 LOH 檢測

- FP 的 LOH 率顯著高於 TP，說明 LOH 是 FP 的重要指標

- 為後續改進提供了清晰方向
