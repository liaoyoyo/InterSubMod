## 1. 概述與背景

### 1.1 生物學意義

#### 等位基因特異性甲基化 (Allele-Specific Methylation, ASM)

ASM 指的是在同一個細胞中，不同等位基因（來自父方或母方的染色體拷貝）呈現不同的甲基化模式。這種現象與：
- **基因組印記 (Genomic Imprinting)**：特定基因僅表達父源或母源等位基因
- **X 染色體不活化 (X-Chromosome Inactivation)**：女性細胞中一條 X 染色體被甲基化沉默
- **疾病風險變異**：某些 SNP 可能影響附近 CpG 位點的甲基化狀態

#### 單倍型特異性甲基化 (Haplotype-Specific Methylation, HSM)

HSM 擴展了 ASM 的概念，考慮連鎖的多個 SNP 形成的單倍型。長讀取定序技術使我們能夠：
- 直接 phase 單倍型而非依賴統計推斷
- 在單一 read 上同時觀察多個 CpG 的甲基化狀態
- 建立「SNV → 單倍型 → 甲基化模式」的完整關聯

#### 亞克隆結構 (Subclonal Structure)

在腫瘤樣本中，不同細胞群體可能具有：
- 不同的體細胞突變組成
- 不同的表觀遺傳狀態
- 不同的甲基化模式

InterSubMod 的核心目標是偵測這些亞克隆結構，判斷甲基化差異是否與已知的生物學標籤（HP Tag / Allele）相關聯。

### 1.2 雙向驗證框架設計理念

傳統的分析方法通常採用單向路徑：

```
Cluster-First: Reads → 距離矩陣 → 聚類 → 檢驗標籤分布
```

這種方法的問題是，聚類本身可能因為技術噪音而產生偽結構。

InterSubMod 採用**雙向驗證框架 (Bidirectional Verification)**：

```
┌────────────────────────────────────────────────────────────┐
│                    Bidirectional Verification              │
├────────────────────────────────────────────────────────────┤
│                                                            │
│   Cluster-First Path:                                      │
│   ┌──────┐    ┌──────────┐    ┌─────────┐    ┌─────────┐  │
│   │Reads │ →  │ Distance │ →  │Clustering│ →  │ Fisher/ │  │
│   │      │    │  Matrix  │    │          │    │Chi-Sq   │  │
│   └──────┘    └──────────┘    └─────────┘    └─────────┘  │
│                                                     ↓      │
│                                              ┌───────────┐ │
│                                              │Significant?│ │
│                                              └───────────┘ │
│                                                     ↓      │
│   Label-First Path:                          ┌───────────┐ │
│   ┌──────┐    ┌──────────┐    ┌─────────┐   │           │ │
│   │Labels│ →  │  Group   │ →  │ Delta   │ → │ Classify  │ │
│   │HP/ALT│    │ Distance │    │Test/PERM│   │           │ │
│   └──────┘    └──────────┘    └─────────┘   └───────────┘ │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

**設計原則**：
1. **獨立驗證**：兩條路徑使用不同的檢驗方法
2. **互補判斷**：結合兩者結果進行四維分類
3. **降低偽陽性**：需要雙向一致才確認為「Strong」關聯

### 1.3 四維分類系統定義

基於雙向驗證結果，每個 Region 被分類為四種類型之一：

| 分類 | Cluster-First | Label-First | 生物學解釋 |
|------|--------------|-------------|-----------|
| **Strong** | 顯著 | 顯著 | 標籤確實解釋甲基化結構，高可信度 |
| **Subclone** | 顯著 | 不顯著 | 存在亞克隆但非簡單的標籤分化 |
| **Weak** | 不顯著 | 顯著 | 標籤有信號但聚類結構弱 |
| **Noise** | 不顯著 | 不顯著 | 無顯著信號，技術噪音或無差異 |

**分類邏輯實作** (`SignificanceAnalyzer.cpp:174-189`)：

```cpp

                           (result.global_alt.fisher_ffh.p_value <= 0.05 ||
                            result.global_hp.fisher_ffh.p_value <= 0.05);
```

## 2. 標籤定義與解析

### 2.1 HP Tag 解析

#### 2.1.1 格式與來源

HP Tag（Haplotype Tag）是 BAM 檔案中的輔助標籤，由 phasing 工具（如 WhatsHap、LongPhase）添加。

**支援的格式** (`ReadParser.cpp:119-129`)：

| HP Tag 值 | 格式類型 | 含義 |
|-----------|---------|------|
| `"1"`, `"HP1"` | 字串/整數 | 單倍型 1 |
| `"2"`, `"HP2"` | 字串/整數 | 單倍型 2 |
| `"1-1"` | 複合字串 | 樣本 1 的單倍型 1 |
| `"2-1"` | 複合字串 | 樣本 1 的單倍型 2 |
| `"0"`, `"HP0"`, `""` | 字串 | 未定相 (Unphased) |
| `"3"`, `"HP3"` | 字串 | 衝突 (Conflict) |

### 2.2 Allele 判斷

#### 2.2.1 判斷流程

Allele 判斷用於確定每個 read 在 SNV 位置支持 REF 還是 ALT allele (`ReadParser.cpp:137-232`)。

```
│                    Allele 判斷流程                          │
├─────────────────────────────────────────────────────────────┤
```

| CIGAR Op | 符號 | 消耗 REF | 消耗 SEQ | 處理方式 |
|----------|------|---------|---------|---------|
| M | Match/Mismatch | Yes | Yes | 檢查 SNV 是否在區間內 |
| = | Sequence Match | Yes | Yes | 同 M |
| X | Sequence Mismatch | Yes | Yes | 同 M |
| I | Insertion | No | Yes | 跳過 |
| S | Soft Clip | No | Yes | 跳過 |
| D | Deletion | Yes | No | SNV 在此則 UNKNOWN |
| N | Ref Skip | Yes | No | SNV 在此則 UNKNOWN |
| H | Hard Clip | No | No | 無操作 |

## 3. 統計檢驗方法詳解

### 3.1 Fisher-Freeman-Halton 檢驗 (Monte Carlo)

#### 3.1.1 理論基礎

Fisher-Freeman-Halton (FFH) 檢驗是 Fisher 精確檢驗對 R×C 列聯表的推廣。在固定邊際總和的條件下，計算觀測表格的機率。

**表格機率公式**：

$$P(\text{table} | \text{marginals}) = \frac{\prod_i R_i! \cdot \prod_j C_j!}{N! \cdot \prod_{ij} n_{ij}!}$$

其中：
- $R_i$ = 第 i 行的邊際總和
- $C_j$ = 第 j 列的邊際總和
- $N$ = 總樣本數
- $n_{ij}$ = 第 (i,j) 格的觀測值

#### 3.1.2 Monte Carlo 實作

由於精確列舉所有可能表格在大樣本時計算成本過高，使用 Monte Carlo 方法：

1. 使用 Patefield 演算法 (1981) 在固定邊際條件下抽樣隨機表格
2. 計算每個抽樣表格的 log 機率
3. 統計機率 ≤ 觀測表格機率的比例

**程式碼** (`FisherExact.cpp:256-317`)：

```cpp
FisherResult FisherExact::test_rxc_mc(const ContingencyTableRxC& table) {
    // ...
    double log_p_obs = log_table_prob_rxc(table);
    int n_extreme = 0;

    for (int iter = 0; iter < config_.max_mc_samples; ++iter) {
        ContingencyTableRxC sampled = sample_table_with_marginals(row_totals, col_totals);
        double log_p_sample = log_table_prob_rxc(sampled);

        if (log_p_sample <= log_p_obs + 1e-10) {
            ++n_extreme;
        }

        // Early stopping with confidence interval
        if (config_.use_early_stopping && result.n_samples >= config_.min_mc_samples) {
            auto [ci_lower, ci_upper] = binomial_ci(n_extreme, result.n_samples, config_.ci_confidence);
            if (ci_upper < config_.alpha || ci_lower > config_.alpha) {
                result.early_stopped = true;
                break;
            }
        }
    }

    result.p_value = static_cast<double>(n_extreme) / static_cast<double>(result.n_samples);
    return result;
}
```

#### 3.1.3 Early Stopping 機制

使用 Wilson Score Interval 計算 p-value 的信賴區間，若區間完全在 alpha 之上或之下則提前停止：

```cpp
// FisherExact.cpp:224-254
std::pair<double, double> FisherExact::binomial_ci(int n_success, int n_total, double confidence) {
    double p_hat = static_cast<double>(n_success) / static_cast<double>(n_total);
    double z = (confidence >= 0.99) ? 2.576 : (confidence >= 0.95) ? 1.96 : 1.645;

    double z2 = z * z;
    double denom = 1.0 + z2 / n;
    double center = (p_hat + z2 / (2.0 * n)) / denom;
    double margin = (z / denom) * std::sqrt(p_hat * (1.0 - p_hat) / n + z2 / (4.0 * n * n));

    return {std::max(0.0, center - margin), std::min(1.0, center + margin)};
}
```

### 3.2 Chi-Square 檢驗

#### 3.2.1 計算公式

$$\chi^2 = \sum_{i,j} \frac{(O_{ij} - E_{ij})^2}{E_{ij}}$$

其中期望值 $E_{ij} = \frac{R_i \times C_j}{N}$

#### 3.2.2 可靠性檢查

Chi-Square 檢驗在期望值過小時不可靠。程式碼中檢查期望值 ≥ 5 的儲存格比例：

```cpp
// GlobalTest.cpp:104-118
int valid_cells = 0;
for (int i = 0; i < table.n_rows; ++i) {
    for (int j = 0; j < table.n_cols; ++j) {
        double expected = (static_cast<double>(row_totals[i]) *
                          static_cast<double>(col_totals[j])) / n_d;
        if (expected >= 5.0) {
            ++valid_cells;
        }
    }
}

double valid_ratio = static_cast<double>(valid_cells) / static_cast<double>(total_cells);
result.chi_square_reliable = (valid_ratio >= config_.chi_square_min_valid_ratio);
```

### 3.3 Cramér's V 效應量

#### 3.3.1 定義

Cramér's V 是衡量列聯表關聯強度的標準化指標：

$$V = \sqrt{\frac{\chi^2}{N \times \min(r-1, c-1)}}$$

**解釋標準**：
- V < 0.1: 可忽略 (negligible)
- 0.1 ≤ V < 0.3: 弱 (small)
- 0.3 ≤ V < 0.5: 中等 (medium)
- V ≥ 0.5: 強 (large)

#### 3.3.2 在系統中的應用

Cramér's V 用於 Gating 條件，確保不僅統計顯著，且效應量足夠：

```cpp
// GlobalTest.cpp:137-142
void GlobalTest::apply_gating(GlobalTestResult& result) {
    bool p_pass = (result.fisher_ffh.p_value <= config_.gating_p_threshold);
    bool v_pass = (result.cramers_v >= config_.min_cramers_v);
    result.passed_gate = p_pass && v_pass;
}
```

### 3.4 PERMANOVA

#### 3.4.1 理論基礎

PERMANOVA (Permutational Multivariate Analysis of Variance) 是一種非參數多變量檢驗，用於測試組間距離是否大於組內距離。

**Pseudo-F 統計量**：

$$F = \frac{SS_{between} / (k-1)}{SS_{within} / (n-k)}$$

其中：
- $SS_{total} = \frac{1}{n} \sum_{i<j} d_{ij}^2$
- $SS_{within} = \sum_k \frac{1}{n_k} \sum_{i<j \in k} d_{ij}^2$
- $SS_{between} = SS_{total} - SS_{within}$

#### 3.4.2 實作細節

```cpp
// LabelTest.cpp:410-441
auto compute_ss = [&](const std::vector<int>& labels) {
    std::map<int, std::vector<int>> groups;
    for (int i = 0; i < n_valid; ++i) {
        groups[labels[i]].push_back(i);
    }

    double ss_total = 0.0;
    for (int i = 0; i < n_valid; ++i) {
        for (int j = i + 1; j < n_valid; ++j) {
            double d = sub_dist(i, j);
            ss_total += d * d;
        }
    }
    ss_total /= static_cast<double>(n_valid);

    double ss_within = 0.0;
    for (const auto& [group_id, members] : groups) {
        int n_k = static_cast<int>(members.size());
        if (n_k <= 1) continue;
        double group_ss = 0.0;
        for (size_t i = 0; i < members.size(); ++i) {
            for (size_t j = i + 1; j < members.size(); ++j) {
                double d = sub_dist(members[i], members[j]);
                group_ss += d * d;
            }
        }
        ss_within += group_ss / static_cast<double>(n_k);
    }

    return std::make_pair(ss_total - ss_within, ss_within);
};
```

#### 3.4.3 排列檢驗


### 3.5 Label Delta 檢驗

#### 3.5.1 核心概念

Label Delta 是 Label-First 路徑的核心統計量：

$$\Delta = \bar{d}_{between} - \bar{d}_{within}$$

- $\bar{d}_{within}$：同標籤 read 之間的平均距離
- $\bar{d}_{between}$：不同標籤 read 之間的平均距離

**正向 Delta 意義**：標籤確實解釋了距離結構（組間距離 > 組內距離）

#### 3.5.2 計算實作

```cpp
// LabelTest.cpp:230-269
void LabelTest::compute_group_distances(const Eigen::MatrixXd& dist_matrix,
                                        const std::vector<int>& group_labels,
                                        double& within_mean, double& between_mean,
                                        int& n_pairs_within, int& n_pairs_between) {
    int n = dist_matrix.rows();
    double sum_within = 0.0, sum_between = 0.0;
    n_pairs_within = 0; n_pairs_between = 0;

    for (int i = 0; i < n; ++i) {
        if (group_labels[i] < 0) continue;  // Skip excluded

        for (int j = i + 1; j < n; ++j) {
            if (group_labels[j] < 0) continue;

            double dist = dist_matrix(i, j);
            if (std::isnan(dist)) continue;

            if (group_labels[i] == group_labels[j]) {
                sum_within += dist;
                ++n_pairs_within;
            } else {
                sum_between += dist;
                ++n_pairs_between;
            }
        }
    }

    within_mean = (n_pairs_within > 0) ? (sum_within / n_pairs_within) : 0.0;
    between_mean = (n_pairs_between > 0) ? (sum_between / n_pairs_between) : 0.0;
}
```

#### 3.5.3 排列檢驗

```cpp
// LabelTest.cpp:275-323
double LabelTest::permutation_test(const Eigen::MatrixXd& dist_matrix,
                                   const std::vector<int>& group_labels,
                                   double observed_delta) {
    int n_extreme = 1;  // Include observed value

    std::vector<int> permuted_labels = group_labels;
    std::vector<size_t> valid_indices;
    std::vector<int> valid_label_values;

    // Extract valid labels
    for (size_t i = 0; i < group_labels.size(); ++i) {
        if (group_labels[i] >= 0) {
            valid_indices.push_back(i);
            valid_label_values.push_back(group_labels[i]);
        }
    }

    for (int perm = 0; perm < config_.n_permutations; ++perm) {
        std::shuffle(valid_label_values.begin(), valid_label_values.end(), rng_);

        for (size_t i = 0; i < valid_indices.size(); ++i) {
            permuted_labels[valid_indices[i]] = valid_label_values[i];
        }

        double within_mean, between_mean;
        int n_within, n_between;
        compute_group_distances(dist_matrix, permuted_labels,
                               within_mean, between_mean, n_within, n_between);

        double perm_delta = between_mean - within_mean;

        if (perm_delta >= observed_delta) {
            ++n_extreme;
        }
    }

    return static_cast<double>(n_extreme) / static_cast<double>(config_.n_permutations + 1);
}
```

### 4.3 啟發式評分公式

```cpp
// SignificanceAnalyzer.cpp:227-260
double SignificanceAnalyzer::compute_heuristic_score(const SignificanceResult& result) {
    double score = 0.0;
    double p_val_alt = (result.global_alt.valid) ? result.global_alt.fisher_ffh.p_value : 1.0;
    double p_val_hp = (result.global_hp.valid) ? result.global_hp.fisher_ffh.p_value : 1.0;

    double best_p = std::min(p_val_alt, p_val_hp);

    // Primary: -log10(best_p)
    if (best_p > 0) {
        score = -std::log10(best_p);
    } else {
        score = 20.0;  // Cap for p=0
    }

    // Bonus for Cramér's V
    double best_v = 0.0;
    if (result.global_alt.cramers_v_reliable) best_v = std::max(best_v, result.global_alt.cramers_v);
    if (result.global_hp.cramers_v_reliable) best_v = std::max(best_v, result.global_hp.cramers_v);
    score += best_v * 2.0;

    // Penalties
    if (result.dispersion_warning) score *= 0.5;
    if (result.permanova.valid && result.permanova.p_value > 0.05) score *= 0.7;

    return score;
}
```

**公式總結**：

$$\text{Score} = \left( -\log_{10}(p_{best}) + 2V_{best} \right) \times \text{Penalty}$$

其中：
- $p_{best} = \min(p_{alt}, p_{hp})$
- $V_{best} = \max(V_{alt}, V_{hp})$ (if reliable)
- Penalty = 0.5 if dispersion_warning, 0.7 if PERMANOVA p > 0.05

## 5. 潛在問題分析

### 5.1 標籤判斷偏差

#### 5.1.1 HP Tag 格式不一致

**問題描述**：不同 phasing 工具產生的 HP Tag 格式可能不同。

| 工具 | 典型格式 | 問題 |
|------|---------|------|
| WhatsHap | `1`, `2` | 無問題 |
| LongPhase | `1`, `2` | 無問題 |
| 自定義 | `HP1`, `HP2` | 需字串比對 |
| 多樣本 | `1-1`, `2-1` | 需特殊處理 |

**影響評估**：
- 低風險：目前程式碼已覆蓋主要格式
- 建議：增加格式驗證和警告日誌

#### 5.1.2 Allele UNKNOWN 比例過高

**問題描述**：以下情況會導致 Allele 判斷為 UNKNOWN：

| 原因 | FilterReason | 典型比例 |
|------|-------------|---------|
| SNV 在 Deletion 中 | `SNV_IN_DELETION` | 1-5% |
| Base Quality 過低 | `LOW_BASE_QUALITY` | 5-15% |
| 非 REF/ALT 鹼基 | `NOT_REF_OR_ALT` | 1-3% |
| Read 未覆蓋 SNV | `SNV_NOT_COVERED` | 視 region 大小 |

**影響評估**：
- 中等風險：UNKNOWN 過多會降低統計檢定力
- 建議：監控 UNKNOWN 比例，設定警告閾值

#### 5.1.3 HP 與 Allele 不一致

**問題描述**：在某些情況下，HP Tag 與 Allele 判斷可能不一致：

```
Case 1: 重組事件 (Recombination)
  HP1 + ALT → 預期
  HP1 + REF → 可能存在重組

Case 2: Phasing 錯誤
  HP Tag 錯誤分配

Case 3: 多突變
  Region 內有多個 SNV，不同 SNV 的 HP-Allele 關係不同
```

**影響評估**：
- 高風險：可能導致 Label-First 和 Cluster-First 結果矛盾
- 建議：增加 HP-Allele 一致性檢查

### 5.2 統計檢驗假設違反

#### 5.2.1 Fisher Monte Carlo 樣本數不足

**問題描述**：對於極小的 p-value，Monte Carlo 估計不穩定。

```
P(p < 0.001) with N=1000 samples:
  - 預期 extreme count ≈ 1
  - 估計誤差 σ ≈ sqrt(1000 * 0.001 * 0.999) ≈ 1
  - 95% CI: [0, 3] / 1000 = [0, 0.003]
```

**影響評估**：
- 中等風險：極端 p-value 可能不精確
- 建議：對小 p-value 增加 Monte Carlo 樣本數

#### 5.2.2 PERMANOVA 離散度異質性

**問題描述**：PERMANOVA 假設各組具有相同的離散度 (dispersion)。若違反：

$$H_0: \mu_1 = \mu_2 = ... = \mu_k \text{ (location)}$$

但 PERMANOVA 實際檢驗的是：

$$H_0: \text{centroid}_1 = \text{centroid}_2 = ... = \text{centroid}_k$$

若離散度不同，可能拒絕 $H_0$ 即使 centroid 相同。

**影響評估**：
- 中等風險：dispersion 檢查已實作但僅作為警告
- 建議：考慮使用 PERMDISP 作為前置檢驗

#### 5.2.3 排列檢驗獨立性假設

**問題描述**：排列檢驗假設觀測值（或殘差）在虛無假設下可交換。但：

```
問題 1: 同一 read 的多個 CpG 不獨立
  Read A: [CpG1=M, CpG2=M, CpG3=M]  → 高度相關

問題 2: 鄰近 read 可能來自同一分子
  若有 PCR 重複，增加偽相關
```

**影響評估**：
- 高風險：可能低估 p-value（偽陽性增加）
- 建議：考慮分塊排列或基於 read 的 bootstrap

### 5.3 閾值選擇的影響

#### 5.3.1 Gating p=0.1 的影響

**問題描述**：Gating p-value 閾值 0.1 較寬鬆，可能允許過多假陽性進入後續分析。

```
若真實 H0 比例為 80%:
  - 預期通過 Gate 的假陽性: 0.8 * 0.1 = 8%
  - 通過 Gate 的比例: 8% + 20% * (1-β)
```

**影響評估**：
- 低風險：後續 p=0.05 會進一步篩選
- 建議：可考慮調整為 0.05 或使用 FDR 控制

#### 5.3.2 min_reads_per_group=3 的影響

```cpp
// LabelTestConfig (LabelTest.hpp:30)
int min_reads_per_group = 3;
```

**問題描述**：每組僅 3 個 read 時：

```
極端情況分析:
  Group A: [0.1, 0.2, 0.3]
  Group B: [0.7, 0.8, 0.9]

  within_mean_A = (0.1+0.1+0.1)/3 = 0.1
  within_mean_B = (0.1+0.1+0.1)/3 = 0.1
  between_mean ≈ 0.5 - 0.6
  Delta = 0.4 - 0.5

  但置換後很容易超過觀測 Delta
```

**影響評估**：
- 中等風險：小樣本導致估計不穩定
- 建議：考慮增加至 5 或 10

#### 5.3.3 缺乏多重比較校正

**問題描述**：同時檢驗 ALT、HP、Sample 三個維度，以及 Local 檢驗每個 cluster，未進行多重比較校正。

```
假設檢驗數量:
  - Global: 3 tests (ALT, HP, Sample)
  - Local: k clusters × 3 dimensions
  - Total: 3 + 3k tests

若 k=3, α=0.05:
  Family-wise error rate ≈ 1 - (1-0.05)^12 ≈ 0.46
```

**影響評估**：
- 高風險：多重比較未校正會增加假陽性率
- 建議：實施 Bonferroni 或 FDR 校正

### 5.4 樣本量問題

#### 5.4.1 小樣本 Delta 估計變異

**問題描述**：Delta 估計在小樣本時變異大。

```
Delta 的變異:
  Var(Delta) = Var(d_between) + Var(d_within) - 2*Cov(d_between, d_within)

若 n_within pairs = 6, n_between pairs = 6:
  - 每個均值估計的 SE 都很大
  - Delta 的 SE 更大
```

**影響評估**：
- 中等風險：小樣本可能導致不穩定的判斷
- 建議：報告 Delta 的信賴區間

#### 5.4.2 不平衡分組

**問題描述**：若分組極度不平衡：

```
Case: HP1 = 50 reads, HP2 = 3 reads
  - HP2 組內 pairs = C(3,2) = 3
  - HP1 組內 pairs = C(50,2) = 1225
  - 組間 pairs = 50 * 3 = 150

  HP2 組內距離估計極不穩定
```

**影響評估**：
- 高風險：少數組統計推斷不可靠
- 建議：檢查分組平衡性，設定最小組大小比例

### 5.5 距離矩陣處理問題

#### 5.5.1 NaN 值處理

```cpp
// LabelTest.cpp:252
if (std::isnan(dist)) continue;
```

**問題描述**：NaN 值被跳過，可能導致：
- 有效 pairs 數量減少
- 不同組的有效 pairs 比例不同

**影響評估**：
- 低風險：目前處理方式合理
- 建議：報告 NaN 比例，若過高則警告

## 6. 改進建議

### 6.1 短期改進（低成本、高影響）

| 項目 | 描述 | 預期效果 | 難度 |
|------|------|---------|------|

| **報告信賴區間** | 對 Delta 和 p-value 報告 CI | 提供不確定性量化 | 中 |

### 6.2 中期改進（中等成本）

| 項目 | 描述 | 預期效果 | 難度 |
|------|------|---------|------|
| **FDR 控制** | 實施 Benjamini-Hochberg 程序 | 控制多重比較誤差 | 中 |

| **分塊排列** | 基於 read 或 CpG 區域分塊 | 減少獨立性違反影響 | 中 |

### 6.3 長期改進（高成本、結構性）
