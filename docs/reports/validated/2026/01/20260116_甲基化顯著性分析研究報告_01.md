## 1. 研究目標與假設

### 1.1 核心研究假設

本專案 (InterSubMod) 的核心假設基於以下生物學原理：

> **假設**: 真正的體細胞突變 (True Positive sSNV) 應該會伴隨著特定的甲基化模式差異，而這種差異可以透過統計方法偵測出來，作為驗證 sSNV 真偽的額外證據。

具體而言：
1. **等位基因特異性甲基化 (ASM)**: 攜帶 ALT allele 的 reads 與攜帶 REF allele 的 reads 之間，應存在甲基化模式的差異
2. **單倍型特異性甲基化**: HP1 與 HP2 單倍型之間，應存在可偵測的甲基化差異
3. **亞克隆結構**: 腫瘤中不同亞克隆可能展現不同的甲基化模式

### 1.2 研究目標

1. **驗證 sSNV 真偽**: 利用甲基化訊號作為額外過濾條件，區分 TP 與 FP
2. **偵測亞克隆結構**: 找出腫瘤異質性 (Tumor Heterogeneity) 的表觀遺傳學證據
3. **整合多層資訊**: 結合 genotype (SNV)、epigenotype (methylation)、haplotype (phasing) 進行綜合分析

### 1.3 預期結果

- TP sSNV 位點應該有較高的甲基化顯著性率
- FP sSNV 位點的甲基化模式應該較為隨機
- 強關聯的 sSNV 位點可以透過甲基化特徵加強可信度

### 2.2 統計方法詳解

#### 2.2.1 Fisher-Freeman-Halton 精確檢驗

**目的**: 測試聚類成員與生物標籤的獨立性

**公式**:
```
H0: 聚類分佈與標籤分佈獨立
H1: 聚類與標籤存在關聯
```

**實作細節** (`GlobalTest.cpp`):
- 建立 R×C 列聯表 (R=聚類數, C=2 標籤類別)
- 使用蒙地卡羅模擬計算精確 p-value
- 輸出 Cramér's V 效應量

#### 2.2.2 PERMANOVA (排列多元變異數分析)

**目的**: 測試組群心點 (Centroid) 是否顯著不同

**偽 F 統計量**:
```
F = (SS_Between / (k-1)) / (SS_Within / (n-k))

其中:
- SS_Between: 組群間平方和
- SS_Within: 組群內平方和
- k: 組群數
- n: 樣本總數
```

**排列檢驗**: 隨機打亂標籤 999 次，計算經驗 p-value

#### 2.2.3 Label Delta 度量

**定義**:
```
Delta = d_between - d_within

其中:
- d_between: 不同標籤讀段間的平均距離
- d_within: 相同標籤讀段間的平均距離
```

**生物學解釋**:
- Delta > 0: 標籤可解釋距離結構 (預期的訊號)
- Delta ≈ 0: 標籤與距離無關 (噪音)
- Delta < 0: 異常情況

### 2.3 距離度量

系統支援 6 種距離演算法：

| 度量 | 公式 | 適用場景 |
|:---|:---|:---|
| **NHD** | `Σ(M_ik ≠ M_jk) / |Common|` | 二值化甲基化 |
| **L1** | `Σ|P_ik - P_jk| / |Common|` | 絕對偏差 |
| **L2** | `√(Σ(P_ik - P_jk)² / |Common|)` | 歐幾里得距離 |
| **Bernoulli** | `Σw_k·δ_k / Σw_k` | 信心加權 (創新) |
| **Jaccard** | `1 - |A ∩ B| / |A ∪ B|` | 集合相似度 |
| **Pearson** | `1 - corr / 2` | 相關性 |

### 2.4 分類邏輯

| 分類 | Cluster-First | Label-First | 生物學意義 |
|:---|:---:|:---:|:---|
| **Strong** | ✓ | ✓ | 強亞克隆訊號，標籤完全解釋 |
| **Subclone** | ✓ | ✗ | 存在結構但標籤無關 |
| **Weak** | ✗ | ✓ | 標籤相關但聚類弱 |
| **Noise** | ✗ | ✗ | 背景噪音 |

## 5. 方法有效性評估與問題分析

### 5.1 核心問題：鑑別力不足

#### 5.1.1 問題描述

實驗結果顯示，甲基化顯著性指標**無法有效區分 TP 與 FP**：

```
Cramér's V AUC = 0.5194 ≈ 0.5 (隨機猜測)
```

這意味著：
- 甲基化顯著性對於 TP/FP 分類幾乎沒有預測能力
- 不能直接用於過濾 FP 或驗證 TP

#### 5.1.2 F1 影響評估

若直接使用甲基化顯著性作為過濾條件：

| 策略 | 移除 TP | 移除 FP | TP:FP 比 | F1 變化 |
|:---|:---:|:---:|:---:|:---:|
| 保留 Significant=True | 28,616 | 4,721 | 6.06:1 | **-0.726** |

**結論**: 直接過濾會導致 F1 從 0.815 暴跌至 0.089，完全不可行。

### 5.2 假設與觀察的出入分析

#### 5.2.1 假設 vs 現實

| 原始假設 | 觀察結果 | 可能原因 |
|:---|:---|:---|
| TP 應有較高顯著率 | TP: 6.10%, FP: 2.09%，差異有限 | 效應量普遍太小 |
| TP 應有較高 Cramér's V | 平均差異僅 0.035 | 大部分位點無甲基化關聯 |
| Strong 類別應富集 TP | FP 的 Strong 比例更高 | 分類邏輯可能有問題 |
| Allele 標籤應主導 TP | HP 主導兩組 (~69%) | 可能是 phasing 的技術結果 |

#### 5.2.2 根本原因分析

**原因 1: 生物學層面**
- **並非所有 SNV 都有相關甲基化變化**: 只有位於 CpG 島附近或調控區域的 SNV 才可能有甲基化關聯
- **效應量本質上較小**: 即使存在 ASM，差異可能不足以達到統計顯著

**原因 2: 技術層面**
- **CpG 稀疏性**: 每個區域平均僅 ~97 個 CpG，且覆蓋不均
- **缺失值比例高**: 距離矩陣中的無效配對需要處理策略
- **定序深度限制**: ~70 reads 可能不足以偵測微弱效應

**原因 3: 統計方法層面**
- **多重比較問題**: 30,000+ 次檢驗需要嚴格校正
- **門控閾值設定**: 現有 p ≤ 0.05 + V ≥ 0.1 可能不適合
- **分類邏輯問題**: "Strong" 類別的定義可能不準確

### 5.3 特殊發現

#### 5.3.1 Label Delta 的潛力

F1 優化分析顯示，**Label Delta 是目前唯一有效的過濾指標**：

| 策略 | 移除 FP | 移除 TP | FP/TP 比 | F1 改善 |
|:---|:---:|:---:|:---:|:---:|
| Remove Delta > 0.25 | 314 | 191 | 1.64 | +0.000407 |
| Remove Delta > 0.30 | 190 | 112 | 1.70 | +0.000294 |

**解釋**: 高 Label Delta 表示標籤與聚類不一致，這在 FP 中更常見。

#### 5.3.2 染色體層級異常

某些染色體 (chr9, chr14) 的 FP 顯著率異常高於 TP，可能暗示：
- 這些區域有特殊的甲基化結構
- 該區域的假陽性有特定的技術來源
- 需要染色體特異性的閾值調整

#### 5.3.3 DominantLabel 差異

FP 中 "Allele" 主導的比例 (26.19%) 高於 TP (16.91%)，而 TP 中 "None" 的比例 (14.50%) 高於 FP (4.56%)。這可能意味著：
- FP 位點更容易產生假的等位基因關聯
- TP 位點的甲基化模式更為隨機（無主導維度）

### 6.2 需要再次驗證與觀察的部分

| **染色體特異性** | 分析 chr9/chr14 的 FP 顯著率異常 | 可能有技術或生物學原因 |
| **CpG 密度影響** | 測試 CpG 數量與顯著性的關係 | 稀疏區域可能不可靠 |
| **Phasing 品質** | 檢查 HP tag 的準確性 | Phasing 錯誤會影響所有後續分析 |
| **距離度量比較** | 比較 NHD vs Bernoulli 效果 | 找出最適合的度量 |
| **窗口大小影響** | 測試不同 window size | 當前 5000bp 可能不是最佳 |

#### 6.2.2 單點深入分析

選取以下位點進行深入驗證：
1. **高顯著 TP**: V > 0.3 且 p < 0.01 的 TP 位點
2. **高顯著 FP**: V > 0.3 且 p < 0.01 的 FP 位點
3. **低顯著 TP**: V < 0.1 且 p > 0.5 的 TP 位點
4. **邊界案例**: V ≈ 閾值的位點

### 6.3 重點觀察分析實作方法

#### 6.3.1 多特徵整合分析

```python
# 概念性程式碼
def integrated_filter(row):
    """
    整合多個特徵進行 TP/FP 分類
    """
    score = 0

    # 1. VCF 品質特徵
    if row['QUAL'] > 0.9:
        score += 2
    if row['VAF'] > 0.15 and row['VAF'] < 0.5:
        score += 1
    if row['DP'] > 50:
        score += 1

    # 2. 鏈偏差
    strand_ratio = min(row['forward'], row['reverse']) / max(row['forward'], row['reverse'])
    if strand_ratio > 0.3:
        score += 1

    # 3. 甲基化特徵 (輔助)
    if row['LabelDelta'] < 0.25:
        score += 0.5
    if row['CramersV'] > 0.2 and row['GlobalP'] < 0.05:
        score += 1

    return score
```

#### 6.3.2 機器學習方法

可嘗試使用機器學習整合多個特徵：

1. **特徵工程**:
   - VCF 特徵: QUAL, VAF, DP, AD, Strand Bias
   - 甲基化特徵: V, p-value, Delta, NumReads, NumCpGs
   - 區域特徵: GC content, CpG density

2. **模型選擇**:
   - Random Forest (可解釋性)
   - XGBoost (效能)
   - Logistic Regression (基線)

3. **驗證策略**:
   - 5-fold Cross Validation
   - Leave-one-chromosome-out

#### 6.4.2 純度梯度實驗設計

**目標**: 測試甲基化顯著性是否隨腫瘤純度變化

| 純度 | 預期 TP 顯著率 | 預期 VAF 範圍 |
|:---:|:---:|:---:|
| 1.0 | 基線 | 0.5 (雜合) |
| 0.8 | 略降 | 0.4 |
| 0.6 | 顯著降低 | 0.3 |
| 0.4 | 大幅降低 | 0.2 |
| 0.2 | 接近噪音 | 0.1 |

**假設**: 若甲基化訊號與突變相關，顯著率應與純度正相關

#### 6.4.3 跨樣本驗證

1. **一致性檢驗**: 在不同樣本中，相同基因區域的甲基化模式是否一致
2. **泛化能力**: 在一個樣本訓練的閾值是否適用於其他樣本
3. **腫瘤類型特異性**: 不同癌症類型是否有不同的甲基化特徵

### 6.5 亞克隆分析方向

#### 6.5.1 使用甲基化偵測亞克隆

**方法**:
1. 收集所有 "Subclone" 類別的區域
2. 分析其甲基化模式的聚類結構
3. 跨區域整合，尋找一致的亞克隆特徵

**驗證**:
- 與 VAF 分布比較
- 與已知 CNV 區域比較

#### 6.5.2 甲基化異常位點 (MSA) 分析

**定義**: 單個 CpG 位點的甲基化狀態顯著偏離預期

**方法**:
1. 建立正常樣本的甲基化基線
2. 計算腫瘤中每個 CpG 的偏離程度
3. 標記顯著偏離的位點為 MSA

**應用**:
- MSA 密集區域可能暗示調控異常
- 可作為亞克隆標記

## 7. 結論

### 7.1 主要發現

1. **鑑別力有限**: 現有甲基化顯著性指標 (AUC ≈ 0.5) 無法有效區分 TP/FP
2. **效應量普遍較小**: 絕大多數 (>95%) 位點的甲基化差異不足以達到統計顯著
3. **Label Delta 有潛力**: 是目前唯一能微幅改善 F1 的指標 (最多 +0.0004)
4. **分類邏輯需檢討**: "Strong" 類別在 FP 中的比例高於 TP，暗示定義可能有問題

### 7.2 方法的適用場景

| 場景 | 適用性 | 說明 |
|:---|:---:|:---|
| 直接過濾 TP/FP | ✗ | 會造成大量 TP 損失 |
| 輔助驗證 | △ | 僅對少數高效應量位點有效 |
| 亞克隆偵測 | ○ | "Subclone" 類別可能有生物學意義 |
| 探索性研究 | ✓ | 可發現特殊甲基化模式 |

### 7.3 建議優先順序

| 優先級 | 建議項目 | 預期收益 |
|:---:|:---|:---|
| 1 | 整合 VAF/QUAL 等 VCF 特徵 | 顯著提升 F1 |
| 2 | 調整 Label Delta 閾值 (0.25-0.3) | 微幅提升 F1 |
| 3 | 深入分析 "Strong" 分類邏輯 | 理解方法限制 |
| 4 | 純度梯度實驗 | 驗證生物學假設 |
| 5 | 跨樣本驗證 | 確認泛化能力 |
| 6 | 機器學習整合 | 長期優化目標 |

### 7.4 最終建議

甲基化分析**不應作為獨立的 TP/FP 過濾器**，而應：

1. **作為輔助特徵**: 與 VAF、QUAL 等特徵整合
2. **關注特殊案例**: 只對高效應量位點 (V > 0.3) 給予額外權重
3. **用於探索**: 發現潛在的亞克隆結構和調控異常
4. **持續驗證**: 在更多樣本和條件下測試假設
