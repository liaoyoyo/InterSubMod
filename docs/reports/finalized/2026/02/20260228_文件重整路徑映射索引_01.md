# 文件重整路徑映射索引

- 日期：2026-02-28
- 用途：提供本次重整後新舊路徑對照，避免歷史引用失效

## 1. 分層調整

1. `docs/analysis/*` -> `docs/reports/validated/YYYY/MM/*`
2. `docs/reports/2026/*` -> `docs/reports/finalized/YYYY/MM/*`
3. `docs/experiments/outputs/*` -> `docs/experiments/validated/YYYY/MM/*`
4. `docs/experiments/*_draft*` -> `docs/experiments/in_progress/YYYY/MM/*`
5. `docs/experiments/` 其餘總結 -> `docs/experiments/finalized/YYYY/MM/*`
6. `docs/plans/2026/01/*` -> `docs/plans/2026/01/*`

## 2. 命名調整

統一為：`YYYYMMDD_主題_流水號.md`

範例：
- `2026-02-13_HCC1395_subsample_purity_完整驗證報告.md`
- -> `20260213_HCC1395_subsample_purity_完整驗證報告_01.md`

## 3. 映射資料檔

完整搬移映射 JSON 已歸檔於：

1. `docs/archive/2026/02/20260228_docs_reorg_move_plan_v1_01.json`
2. `docs/archive/2026/02/20260228_docs_reorg_move_plan_v2_01.json`

## 4. 注意事項

1. `archive/deep/` 為歷史快照，維持原貌，不在本輪重命名範圍。
2. 歷史文件中的 `file://` 連結將分批清理，不一次性覆寫以避免誤改語意。
