# ISM 研究目標合理性與主張驗證

用 SCQA + claim-evidence ladder：

**TL;DR：ISM 的核心研究目標合理且具明確差異化，但現階段應定位為「somatic-haplotag-conditioned、read-level 的癌症甲基結構觀測與區域式 subclone 假說框架」；不能直接宣稱甲基造成突變、已確認演化順序、或已完成一般化的完整 subclonal reconstruction。（影響：高，信心：高）**

## 1. 最終裁決

### Situation

使用者提出的目標包含：

1. 在長讀 tumor／normal 樣本上，聯合觀測甲基、phasing/haplotype tag 與 somatic mutation。
2. 在 read 層次找出高關聯突變、tumor 甲基差異，以及 tumor-normal 甲基差異。
3. 解釋甲基差異與 allele、haplotype、somatic tag、LOH/CN 或其他組合的關聯。
4. 用多點突變與甲基關聯建立 subclone 分析，並確認可能的演化順序。
5. 在只有單一 tumor 樣本時，仍提供比傳統位點層級更細緻的區域觀察。

### Complication

上述願景同時混合了四個不同證據層級：

| 層級 | 問題 | 合理動詞 |
|---|---|---|
| 觀測 | read 上看到了什麼？ | observe、quantify、characterize |
| 關聯 | 哪些標籤與甲基結構共同變化？ | associate、prioritize、consistent with |
| 重建／推論 | 哪些 reads／突變可能屬同一區域 subclone？ | infer、hypothesize、regional reconstruction |
| 因果／確認 | 甲基是否造成突變？演化順序是否確定？ | demonstrate、confirm、causal |

ISM 現有證據主要落在前兩層，部分案例可到第三層；尚未普遍到第四層。

### Answer

**研究願景可保留，但論文與軟體主張必須分級。**

- 現在可防守：read-level 聯合觀測、區域結構檢定、候選區域排序、matched-normal 去混淆、區域式 subclone 假說。
- 需要限縮：subclone reconstruction 應標示為 regional／haplotag-anchored／case-demonstration。
- 目前不可直接主張：甲基造成突變、已確認演化順序、甲基可獨立重建 subclone、單樣本可完成外部驗證。

### 1.1 與 G1–G5 的對應

| 目標 | 本研究定位的服務方式 |
|---|---|
| G1 longphase 家族 + ISM 整合突破 | somatic haplotagging 作 genetic backbone，ISM 提供 read-level methylation characterization |
| G2 longphase-s + longphase-to 協同 | 以相同輸入 provenance 分析 paired／tumor-only，但必須補第二 pipeline 打破自我參照 |
| G3 ISM read-level epigenetic 突破 | 本報告最核心：read×read structure、normal-anchored 去混淆與區域 subclone 假說 |
| G4 多樣本一致性 + reproducibility | 需要完成 G-A 與輸出 evidence label／可重跑 schema |
| G5 業界級可外部驗證 | 需要 head-to-head benchmark、正交 ground truth 與誠實 claim 分級 |

### 1.2 研究任務啟動五問

1. **Thread D read-level epigenetic？** 是，且是本任務核心。
2. **Thread B 撤回範圍？** methylation 作 TP/FP filter 已 DEAD；本報告只把它當主張邊界，不重開。
3. **資料 KDE-corrected？** 本次沒有執行新的 coverage／KDE 數值實驗，不適用；後續跨樣本量化仍須遵守 KDE-corrected 口徑。
4. **需要 VCF caller AF？** 本次不做 AF 推論；若驗證演化順序／clone composition，必須使用 caller AF 並標明來源，不可默認 merged AF。
5. **觸及長計算／C++／檔案搬移／NO-GO gate？** 本次只做源碼、輸出與文獻審查，沒有長計算或檔案搬移；HD-1／R-SELFREF 仍是後續 Hard Gate。

## 2. 建議的正式研究目標

### 2.1 中文正式版

> **InterSubMod（ISM）是針對長讀癌症定序的 read-level、haplotype-conditioned 表觀基因體分析框架。它整合 tumor 與可選 matched-normal 樣本中的 somatic SNV、somatic haplotag 與原生 DNA 甲基訊號，找出並排序甲基結構與 allele、haplotype、LOH/CN 或候選 subclone 配置一致的區域，輸出可追溯的區域式 subclone 假說與去混淆證據；演化順序與因果關係則明確分級為觀測、關聯、推論或已確認。**

### 2.2 英文正式版

> **InterSubMod is a read-level, haplotype-conditioned epigenomic characterization framework for long-read cancer sequencing. It integrates somatic variants, somatic haplotags, and native DNA methylation from tumor and optional matched-normal samples to identify and prioritize genomic regions where methylation structure is associated with allelic, haplotypic, LOH/CN, or candidate subclonal configurations. It supports regional subclone hypothesis generation and de-confounding while explicitly distinguishing observed associations from inferred evolutionary relationships and causal claims.**

### 2.3 一句話差異化

> **ISM 的差異化不只是「長讀可讀甲基」，而是把 somatic haplotag、read×read 甲基結構檢定、matched-normal baseline 與 LOH/CN-aware 解讀整合成癌症區域式證據鏈。**

## 3. 使用者提出目標的逐條合理性審查

| 原始想法 | 裁決 | 可用表述 | 必須避免 |
|---|---|---|---|
| 長讀 tumor/normal 上聯合觀測甲基、haplotype tag、somatic mutation | **合理，源碼與 CLI 已確認** | read-level integrated characterization | 暗示 ISM 自己完成 variant calling 或 phasing |
| 輸出高關聯突變位點 | **合理但需改詞** | 排序「與甲基結構高度關聯的候選變異區域」 | 將高關聯等同真突變、driver 或因果位點 |
| 輸出 tumor 內差異甲基位點／區域 | **合理** | tumor read groups 間的 methylation structure／ASM candidate | 不經 reliability、coverage、multiple-testing gate 即稱顯著 |
| 輸出 tumor-normal 差異甲基位點 | **合理，但 normal 必須有可用 MM/ML 與覆蓋** | matched-normal anchored residual／baseline difference | tumor-only 時仍稱 tumor-normal 差異 |
| 說明甲基與哪些差異組合有關 | **合理，是目前最強主張之一** | allele／HP family／fine HP tag／LOH／sample／cluster 的關聯與去混淆 | 將 single-pipeline 一致性稱作 orthogonal validation |
| 用多點突變與甲基建構 subclone | **部分合理** | somatic haplotagging 為骨幹，甲基作 characterization／coherence evidence | 宣稱甲基目前可獨立定義或指派 subclone |
| 確認可能的演化順序 | **目前只能推論候選順序** | infer candidate regional evolutionary relationships | confirmed lineage、完整 phylogeny、確定演化順序 |
| 單樣本可驗證甲基造成突變 | **不合理，需矯正** | 單樣本可找 mutation-associated methylation 與產生機制假說 | methylation-caused mutation、證明因果方向 |
| 單樣本以甲基+sSNV 建立區域 subclone 分析 | **合理但有界** | within-sample regional subclone hypothesis／case-demonstration | 外推 recurrence、病人泛化或完整 clonal history |
| ISM 是創新領先 | **可稱差異化創新；「領先／首創」待 head-to-head** | differentiated、novel integration、open niche candidate | world-first、state-of-the-art superior，除非完成直接 benchmark |

## 4. ISM 軟體實際能做什麼

### 4.1 已由 CLI／源碼確認的輸入

`include/utils/ArgParser.hpp` 顯示：

- 必要：`--tumor-bam`
- 可選：`--normal-bam`
- 必要：`--reference`
- 必要：`--vcf`
- 可選：`--loh-bed`
- 輸出：`--output-dir`

因此，ISM 是**下游分析引擎**：它使用已有的 somatic VCF、BAM 甲基訊號與 haplotag；它不是 somatic variant caller，也不是完整 phaser。

### 4.2 已由輸出源碼確認的能力

`src/core/RegionProcessor.cpp::write_significance_summary()` 輸出的 `significance_summary.csv` 包含：

- 區域、突變、read 數、CpG 數
- global／HP-family／HP-fine 關聯統計
- read×read 距離、clustering PERMANOVA、dispersion warning
- HP／allele 差異與 pairwise fine-tag distance
- tumor／normal、normal baseline、HP residual
- LOH annotation、subclone ID 欄位
- per-CpG ASM、NME、epipolymorphism
- reliability、quality、gating 與 raw somatic HP-tag audit

這支持「**區域層級多軸觀測與候選排序**」。但目前 `Subclone_ID` 欄位與 clustering 結果本身，不等於完整 clone composition、CCF 或 lineage tree。

### 4.3 一個需要修正／補驗證的實作口徑

C++ 的 `Tumor_HP_Signed_Delta` 使用 `hp_merged_labels`，將 HP1 與 HP1-1 合併、HP2 與 HP2-1 合併，因此主要測的是 **germline allele-family 軸**。若要主張同一 haplotype 內的 somatic subclone 差異，應使用或正式整合 **HP1 vs HP1-1／HP2 vs HP2-1 的 somatic-controlled 軸**，並避免把 merged HP residual 寫成純 somatic-specific signal。

## 5. BRCA2 案例：合理用途與必須矯正之處

### 5.1 可成立的用途

BRCA2/ZAR1L `chr13:32315128` 適合作為：

> **matched-normal／subclone-tag-aware 去混淆案例，展示一個明顯 HP-axis 甲基差異如何被拆解成 subclone/tag 結構與小幅 focal cis residual。**

已驗數字：

- HP-axis Δβ：`-0.122`
- `d_copy`／tag-partition：`-0.11`
- within-tag focal cis residual `d_within`：約 `-0.023`
- permutation p：約 `0.022–0.024`
- CN dosage 假說已被否證：MW `p=0.6183`，signed rho `-0.0829`

### 5.2 必須避免的說法

- BRCA2 不是乾淨 cis anchor。
- `HP1-1` 是 longphase-S somatic subclone tag，不是 copy-number tag。
- 「subclone/copy 占幾 %」的精確比例不穩健，不能引用。
- BRCA2 的甲基差異不能證明甲基造成 BRCA2 突變。
- hypo-methylation 方向也不能直接寫成典型 promoter hypermethylation silencing。

### 5.3 更嚴謹的案例角色

BRCA2 應在 Methods／Results 中被描述為：

> **confound-aware decomposition example**

而不是：

> **causal mutation–methylation exemplar** 或 **clean somatic cis exemplar**

目前最強 cis 候選是 `chr17:79991120 / TBC1D16`，但也只能稱「最強候選，copy 軸已控」：

- `d_within=0.142`
- permutation `p=0.001`
- 仍有較大的 allele-axis residual、Cochran reliability 與單樣本多重檢定限制
- 正確範圍為 **HCC1395 的 816 個 cis-testable loci 中 1 個候選**，不是全 332,705 catalog 已驗只有 1 個

## 6. chr2 旗艦案例：可以證明什麼

### 6.1 原始輸出支持的觀測

`chr2:18,086,020 G>A` 案例：

- `57 reads × 203 CpGs`
- optimal `k=2`
- cluster PERMANOVA：`F=10.612`, `p=0.01`
- dispersion `p=1.0`，沒有 dispersion warning
- global HP：`p=0.027`, Cramér's V `0.6689`
- HP-family：`p=0.003`, V `0.6941`
- HP-fine：`p=0.1105`, V `0.2674`
- allele PERMANOVA：`F=22.9935`, `p=0.01`
- global ALT cluster：`p=0.097`, V `0.2699`
- HP1 family `55` reads，HP2 family `2` reads；raw somatic HP11 `36`
- `Potential_LOH=true`，`LOH_Strong`

這支持：

> **區域內存在明確 read-level 甲基結構，且該結構與 haplotype／somatic subclone tag／allele 配置一致。**

### 6.2 必須揭露的內部口徑差異

- `significance_summary.csv` 的 `GlobalP=0.003`，但 `significance_statistics.txt` 顯示 `Total Significant: 0`。
- `significance.json` 的 global ALT p 值為 `0.097`。
- 因此報告時必須分清楚 global label、HP-family、allele PERMANOVA 與最終 `Significant` flag，不能只挑一個 p 值寫成「全面顯著」。

### 6.3 目前可寫與不可寫

可寫：

> chr2 是一個 **regional case-demonstration**，顯示 somatic haplotagging 定義的 read 配置，與局部甲基結構一致。

不可寫：

- 已確認完整演化樹
- 已確認突變先後順序
- 甲基造成該突變
- 甲基獨立驗證 longphase-S
- 已能泛化至其他樣本

### 6.4 空間結構補充證據

旗艦工作區的 window 分析顯示：

- 600 regions、41,072 reads 的 co-methylation correlation 隨距離快速下降：
  - `0–100 bp` median 約 `0.073`
  - `>1 kb` median 約 `0.021–0.022`
- 531 evaluable somatic-SNV anchored regions：
  - between-minus-within allele distance mean 約 `0.0456–0.0457`
  - `75.9–83.0%` regions 為 between > within

這支持局部 allele-associated methylation structure，但不能單獨推導長距離演化順序；且分析本身已註明 allele 軸可能受 germline-allelic confound。

## 7. 「Subclone」與「演化順序」的證據門檻

### 7.1 現階段最誠實的架構

```text
somatic SNV / somatic haplotag
        ↓  genetic reconstruction backbone
read-level methylation structure
        ↓  characterization / consistency / de-confounding evidence
regional subclone hypothesis
        ↓  尚需額外證據
clone identity + lineage tree + evolutionary order
```

### 7.2 為何不能直接稱完整 reconstruction

外部一手文獻對 reconstruction 的標準更高：

- **BitPhylogeny** 聯合估計 clone 數量、組成與連接它們的 tree。
- **Sgootr** 直接從 single-cell methylation 重建 lineage tree。
- **CAMDAC／TRACERx 2025** 在 217 tumor/normal regions、59 patients 中整合 methylation、DNA/RNA 與 tumor evolution，並處理 methylation deconvolution／CN 相關問題。

因此，flat clustering、區域 read grouping 或單一案例的 reasoned tree，尚不足以普遍稱為 confirmed subclonal reconstruction。

### 7.3 若要「確認演化順序」，至少需要

1. 同一 read／phase block 上多個 somatic mutation 的物理連結。
2. 能區分 trunk、branch、private event 的模型與不確定性。
3. CN、purity、LOH 與 coverage 控制。
4. 多區域、時間序列、單細胞、單細胞衍生 clone 或其他正交 truth 至少一種。
5. 第二 caller／phaser 或獨立 workflow，打破 longphase-S／ClairS-TO 自我參照。
6. 輸出可檢驗的 clone assignment、tree／DAG、branch support，而非只有視覺化推論。

在此之前，建議用：

> **candidate regional evolutionary relationship**
>
> **putative ordering**
>
> **reasoned inference**

而不用：

> **confirmed evolutionary order**

## 8. 單樣本能做什麼、不能做什麼

### 8.1 單一 tumor 樣本仍有價值

在沒有 matched normal 的情況下，ISM 仍可：

- 聯合顯示 somatic allele、haplotag 與 read-level methylation pattern。
- 找到區域內的結構性異質性與候選 subclone 配置。
- 產生待驗證的 mutation-associated methylation／regional subclone 假說。
- 提供比 bulk 平均甲基率更細的 read-level 分布。

### 8.2 單一 tumor 樣本不能完成

- germline baseline 與 tumor-specific drift 的完整區分。
- 因果方向驗證。
- recurrence／泛化。
- 完整 evolutionary history。
- 獨立確認 upstream caller／phaser 的正確性。

所以應將「只有單樣本仍可驗證確認」改為：

> **只有單樣本時仍可做區域式機制假說生成與 within-sample 一致性檢驗；matched normal、跨樣本與正交資料則用於提高 somatic specificity、可重現性與因果可信度。**

## 9. 創新性與領先性判斷

### 9.1 可防守的創新組合

外部文獻已證實：

- read-level／epiallele methylation 分析並非空白，PoreMeth2 等方法已存在。
- methylation lineage tree 並非空白，Sgootr、BitPhylogeny 等已存在。
- tumor evolution 中整合 methylation 與 genomic alteration 並非空白，CAMDAC／TRACERx 已存在。

因此，ISM 的可防守差異化是組合，而非單一元件：

1. **somatic haplotag-conditioned read structure**
2. **無監督 read×read 甲基距離與 PERMANOVA 結構檢定**
3. **matched-normal／normal-anchored cis 與 residual 分析**
4. **LOH/CN-aware 去混淆**
5. **區域式 somatic/subclone characterization**

### 9.2 建議的創新用詞

現在可用：

- differentiated framework
- novel integration
- underexplored tumor/LOH methyl-assisted phasing niche
- region-level, read-resolved cancer epigenomic characterization

完成直接 benchmark 前避免：

- world-first
- first ever
- state-of-the-art superior
- uniquely reconstructs tumor evolution

## 11. 建議的輸出與用語分級

未來軟體輸出／報告建議對每個結論明示一個 evidence label：

| 標籤 | 定義 | 例子 |
|---|---|---|
| `OBSERVED` | 直接由 reads／甲基矩陣／標籤讀到 | chr2 有 57 reads、203 CpGs |
| `ASSOCIATED` | 統計上與 label／cluster 一致 | HP-family p=0.003、V=0.694 |
| `INFERRED` | 根據模型與組合推論 | 候選區域 subclone 關係 |
| `SUPPORTED` | 有多樣本或獨立對照支持 | 未來 G-A／G-E 通過後 |
| `CONFIRMED` | 有正交 ground truth 或直接實驗 | 單細胞、clone-derived、perturbation 等 |

這能防止使用者把「高關聯候選」誤讀成「已確認 driver／因果／演化順序」。

## 13. 結論

ISM 的研究方向**合理、重要，而且有可防守的差異化**。真正強項不是宣稱甲基單獨重建癌症演化，而是：

> **在同一條長讀 read 上，把 somatic variation、haplotag 與甲基結構連接起來，並用 matched normal、LOH/CN 與統計閘控，產生可追溯、可去混淆的區域式 subclone 證據。**

最重要的三個矯正是：

1. **「甲基造成突變」改成「突變相關／與候選 subclone 一致的甲基差異」。**
2. **「確認演化順序」改成「提出並分級驗證候選區域演化關係」。**
3. **「甲基建立 subclone」改成「somatic haplotagging 是骨幹，甲基提供 characterization、去混淆與一致性證據」。**

只要後續完成 G-B、HD-1、G-A、G-D 與第二 pipeline／ground truth，ISM 才能逐步把上述限定語升級成更強的 reconstruction、evolution 與 leading claim。
