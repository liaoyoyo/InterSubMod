# 結論穩定性審查：14 個結論各自有多可靠？

---

## 穩定度評分系統

| 評分 | 意義 | 條件 |
|------|------|------|
| ⭐5 | **堅固** | 多方法驗證 + 不依賴可變前提 + 跨樣本一致 |
| ⭐4 | **穩固** | 充分驗證 + 少量未測假設但影響有限 |
| ⭐3 | **需注意** | 驗證充分但存在可能翻轉的前提或單一樣本限制 |
| ⭐2 | **脆弱** | 核心前提未驗證或存在反向證據 |
| ⭐1 | **不可靠** | 多個前提失效或邏輯缺陷 |

### 結論 2：PON 移除 99.48% raw FP ⭐3

| 維度 | 分析 |
|------|------|
| **前提** | HCC1395 5kHz 的 ClairS-TO 輸出 + SEQC2 truth set |
| **驗證狀態** | 部分——僅 1 個樣本（2,717,339/2,731,541） |

| **如果前提改變** | 即使跌到 95%，「PON 是最強 filter」的結論不變 |
| **需要額外驗證** | 在其他 6 個樣本計算 PON 移除率（特別是 HCC1954, COLO829） |

### 結論 9：Self-phasing 是 TO LOH 主因 ⭐4

| 維度 | 分析 |
|------|------|
| **前提** | 62% 消失 + 17.3:1 bias + r≈0 + 86.5% 平衡 |
| **驗證狀態** | 充分（288K pairs × 7 samples；Cohen's d=-1.20） |
| **隱含假設** | ⚠️ (1) Paired phasing 作為 ground truth 有自身限制（switch error）；31.2% 的定量比例可能需修正（20-25%）。**(2) 重要精確化**：「62% TO LOH 消失」中的 LOH 是 ISM HP_Ratio LOH，而非 LOH.bed region-level LOH。PON-only 實驗證實 LOH.bed 完全不受 self-phasing 影響（Jaccard=1.0），因此因果鏈影響位於 haplotag→ISM 路徑，而非 LongPhase LOH detection |
| **如果前提改變** | 定性結論不變（self-phasing 確實汙染 ISM HP_Ratio），定量比例可能略降。但需更精確描述為「self-phasing 是 ISM-level HP imbalance 主因」而非「self-phasing 是 TO LOH 主因」|
| **需要額外驗證** | (1) 精確區分兩層 LOH 概念的影響範圍；(2) CNV 工具獨立驗證 structural LOH 位置 |

### 結論 10：PON-only phasing VCF 正確但 haplotag 缺陷 ⭐4

| 維度 | 分析 |
|------|------|
| **前提** | LOH.bed Jaccard=1.0 + bias 消除 + N50 翻倍 + haplotag GT 解析缺陷 |
| **驗證狀態** | 僅 HCC1395 1 個樣本 |
| **隱含假設** | ⚠️ **LOH.bed Jaccard=1.0 是意外**——如果 LOH.bed 基於 VCF AD 而非 HP tag，self-phasing 不影響是預期行為。**兩套 LOH 判定系統可能用不同來源**，kappa=0.670 的不一致由此解釋 |
| **需要額外驗證** | **(1) 確認 LOH.bed 生成機制**；(2) 多樣本驗證；(3) Purity 0→修復 |

> **關鍵待驗證問題**：LOH.bed 的生成機制是基於 VCF allele depth 還是 BAM HP tag？這影響我們對兩套 LOH 系統關係的理解。

### 補充結論 15：LOH 區域內甲基化全面失效 ⭐3

| 維度 | 分析 |
|------|------|
| **前提** | LOH 內 CramersV AUC~0.53, PairwiseMedianDist~0.54, HPMergedDelta~0.50 |
| **驗證狀態** | Phase 1+2 驗證（7 samples）；caller_gq paired AUC=0.922 保留 |
| **隱含假設** | ⚠️ (1) LOH 區域本質上是 HP 分群退化的區域——依賴 HP 的甲基化特徵在此**定義上**無法成功（非「失效」，而是「不可能」）。(2) 未測試不依賴 HP 的甲基化特徵（region-level entropy, mean methylation）在 LOH 區域的表現 |
| **如果前提改變** | 不依賴 HP 的甲基化特徵可能有殘餘信號，但效應量預計很小 |
| **需要額外驗證** | 測試 HP-independent 甲基化特徵在 LOH 區域的 AUC |

> **措辭修正建議**（來自方法論審查）：「全面失效」應更精確表述為「依賴 HP 分群的甲基化特徵在 LOH 區域天然無效（因缺乏雙側 HP 對比）」。

### 補充結論 16：HPFineNGroups 是 somatic heterogeneity marker POSITIVE ⭐4 ⬆️

**升級理由（20260418 F pilot 三階段驗證）**：新 canonical filter NG=4+AF<0.4+NR≥80 NonLOH TP rate=0.9281（舊 0.8912 +3.7pp），5/7 ≥0.85；HCC1954 +21.0pp 挽救；chr-shuffle null Z=43.5（非 spatial）、Coverage_Multiple 跨 CN tiers 0.90-0.94（非 CN confound）；NGroups 非單調根因 = germline AF confound。

| 維度 | 分析 |
|------|------|
| **前提** | 新 canonical filter: **NG=4 + AF<0.4 + NR≥80 NonLOH → TP rate=0.9281**（14,197 regions）；舊 NG≥4+NR≥80 NonLOH TP rate=0.8912 保留為對照；residualized AUC=0.617；per-sample effect HCC1954 +21pp/HCC1937 +15pp/5 樣本 ≥0.85 |
| **驗證狀態** | 原驗證：20260406 肉眼觀察報告 Section 8-11；**B.1-2（20260417）**：飽和假說否定；**B.1-1（20260417）**：多變數 residualized AUC Δ=+0.025 ROBUST；**B.1-4**：LOH NGroups=4 僅 n=11 → 僅 NonLOH；**F pilot（20260418）**：三階段深度質疑 → NG=2 germline confound 解釋、HCC1954 AF≥0.4 FP 富集根因確認、Paired 99.85% 非 gain（baseline 98.96%）、chr-shuffle Z=43.5 pass、CN tiers 0.90-0.94 穩定 |
| **隱含假設** | ⚠️ (1) NGroups 上限=4 為 HP1/HP1-1/HP2/HP2-1 分群的合理代理；(2) TO mode self-phasing 修正後訊號保留；(3) 跨 NR bin 訊號外推合理；(4) **AF<0.4 排除 germline het 對 NonLOH 區域為合理代理（F pilot 新增）**；(5) Cell line purity=1.0 可外推臨床 |
| **如果前提改變** | P0-2 haplotag 修正後 NGroups 分布可能變化；臨床 cohort purity<1.0 時 AF<0.4 閾值需重校正；若 LOH.bed 漏標 CNV 區（HCC1954 HER2+ 高 ploidy 情境），AF≥0.4 germline-like FP 可能回流 |
| **需要額外驗證** | (a) ~~B.1-1~~ **已完成 20260417**；(b) ~~F pilot 深度質疑~~ **已完成 20260418**；(c) P0-2 後 haplotag 乾淨重測；(d) AF<0.4 stratified per-sample Cohen's d 重算（HCC1954/COLO829 可能 "特殊"→"POS"）；(e) patient-derived non-SEQC2 外推（⭐4→⭐5 條件） |

**新增限制（20260417 B.1-2 + B.1-1 + B.1-3 + 20260418 F pilot 驗證）**：
1. **LOH 不適用** — LOH 區域 NGroups 被單側 HP 壓縮至 1-2（NGroups=4 僅 n=11）
2. **Ceiling effect（H2009）** — overall TP rate=0.911 時 NGroups 訊號被壓扁（新 filter Δ 仍 +2.3pp）；Paired mode TP=0.99 完全 ceiling（baseline 98.96%）
3. **COLO829 out-of-scope（F pilot 20260418 精確化）** — ONT_R10 basecall 無 methylation，HPFineNGroups 訊號本身為 artifact；NG≥4+NR≥80 NonLOH 全 AF<0.4（n=34），新 filter 無 gain；應加 sample-level gating「優先 ONT_5mCG 或 5mCG+5hmCG basecall」
4. **Per-sample ΔAUC 僅 1/7 ROBUST（B.1-1）** — AUC 層級 7/7 Δ>0、1/7 ROBUST
5. **Per-sample Effect Size 5/7 POS + 2/7 特殊（B.1-3）** — 3/7 medium (HCC1395_DORADO/HCC1937/HCC1954 d=+0.57~+0.60)、2/7 small、1/7 negligible (H2009 ceiling)、1/7 NEGATIVE (COLO829 小樣本)
6. **NGroups 非單調（F pilot 20260418 新發現）** — NG=2 TP rate 0.643 < NG=1 0.763；根因為 germline AF confound（NG=2 AF 平均 0.471、AF∈[0.45,0.55] fraction 0.212 最高、NG=2+AF 0.8-1.0 TP rate 0.339）；「NGroups 作為 monotone subclone marker」需精確化為「NG=4+AF<0.4 才是 somatic marker」
7. **HCC1954 失效機制釐清（F pilot 20260418）** — HER2+ 高 ploidy 未標註 LOH 讓 germline het 表現 AF≈0.5 → FP AF≥0.4 富集；AF<0.4 可挽救 +21pp；非「樣本特異性無法解釋失效」
8. **Paired mode 非應用場景（F pilot 20260418）** — baseline 已 98.96%，filter gain 僅 +0.89pp，Step 1 原 99.85% 驚人為 baseline artifact

| 維度 | 分析 |

| **前提** | TO Δ_NG Inter−Ext=+0.705 / Paired=+0.787；7/7 step2 方向一致；step3 segment-level meta-ρ=+0.367 (TO) / +0.357 (Paired) |

**B.2-1 新增兩項限制**：
1. **Per-sample 功效門檻** — step3 每樣本應要求 n_CN1_segments ≥ 50；HCC1954 (34)、H2009 TO (25) 不達標，應標記為「underpowered」而非「方向一致」
2. **「7/7 一致」精確化** — 應修正為「7/7 step2 Δ POS、5/7 step3 CI 明確、2/7 功效不足」

**B.2-5 新增發現（20260417）**：
3. **cnLOH vs deletion-LOH 方向一致** — CN1 deletion median Δ_NG=+0.505 (7/7 POS)、CN3 cnLOH_high median Δ_NG=+0.238 (6/6 POS)、CN2 near +0.343 (6/6)、CN4+ +0.337 (5/5)；**否定「混合兩者可能掩蓋真實機制」擔憂**；deletion-LOH 效應強 2× 可能是 CN=1 noise 較低，非機制性差異

**B.2-2 新增發現（20260417）**：
4. **Coverage_Multiple proxy 僅可排序** — 僅 COLO829 (1/7) 呈 bimodal（因 99.7% CN1）；其他樣本單峰但 CN 分佈差異極大（HCC1937 CN4+=13.5%, H2009 CN2=78.7%）；**不宜用於精確 CN 估計，未來 Phase 2 建議整合 Delly/Manta/sequenza**

**B.2-3 新增發現（20260417）— NR confound 擔憂駁回**：
5. **NR-matched 7/7 POS** — TO LOH NR decile-matched subsample 後 7/7 樣本仍顯著正向 (Δ=+0.29~+0.80, p<10^-26)
6. **per-bin Δ 隨 NR 遞減** — NR [40,60) Δ=+0.638 → NR [150,500) Δ=+0.174；**原 step2 ρ 隨 NR 遞增是排序穩定度增加，region-level effect size 則遞減**；駁回「高 NR 假關聯 artifact」擔憂
7. **Paired LOH 驗證待辦** — master dataset 僅有 to_loh_bed_hit；需重跑 cross_sample_audit 加入 paired_loh_bed_hit 才能完整驗證 Paired mode
