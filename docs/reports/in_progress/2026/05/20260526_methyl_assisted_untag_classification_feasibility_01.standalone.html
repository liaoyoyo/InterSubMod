0. TL;DR / Executive Summary

核心 idea（用戶 2026-05-26 提出）

對 longphase-S paired-mode tagged BAM，用 甲基化 clustering 做三件事：

  1. Q1：把沒被標 tag 的 reads (untag) 重新歸類到 HP1 / HP2 / somatic
  2. Q2：對 HP3 (ambiguous somatic) 細分為兩子類並給不同 confidence
  3. Q3：對既有 tagged reads (HP1/HP2/HP1-1/HP2-1) 做二次驗證並輸出 confidence

1.3 為什麼用甲基化作 orthogonal signal？

  • 獨立於 SNV vote：甲基化是 read 上 epigenetic 標記，longphase-S 完全不用這資訊
  • 長度不依賴 informative SNV 數：即使 read 沒經過任何 germline het，仍可能有 CpG methylation 資訊
  • 同 hap reads 甲基 pattern 應相似：cell-of-origin 同 sub-population，cluster 後抱團
💡 直白比喻：read 比作學生。SNV vote 像看學生的「姓」（爸爸或媽媽姓），有時看不清。甲基化像看學生的「穿著風格」— 同班同學（同 sub-clone）穿著風格相似，即使姓被遮住也能猜出班級。

3.6 教學版直白比喻（核心 4 條）

🛡️ LOH 區是 sanity？

LOH 區好比一個房間只放了 1 條毛巾。若 cluster algorithm 在這分出 2 群 — 一定是雜訊或 mosaic。LOH 是天然 negative control，若這裡 fail，整套方法不可信。

🔬 CN≥3 為何更需要看？

CN=2 是普通 diploid；CN=3 cnLOH 物理仍 2 hap 但 reads 數不均；CN=4 各 hap 都複製。真正「3 群以上」要看 subclonal 結構 — 此時甲基 cluster ≥3 群但 longphase-S 仍標 2 群 → 甲基比 longphase-S 更精細。

⚠️ ASM region 為何是 confound？

ASM = 兩條 hap 甲基狀態天生不同。3 來源：(1) germline imprinting；(2) cis-mQTL；(3) subclonal ASM（我們要的）。區分方法：cross-ref with normal BAM（normal 也有 = germline；only tumor 才 = somatic）。

🎯 甲基為何比 inheritHaplotype 穩？

longphase-S inheritance 用 somatic variants vote — self-phasing 機制下所有 somatic 100% 共現於同 hap，vote 必偏一邊（V5 Layer 1.5 priority bug 4.19:1 根因）。甲基訊號不受影響，是真 orthogonal。

5. Pre-mortem 反例與失敗模式

反向假設「方法已失敗，what could have caused this?」

FM1: ASM 訊號來自 germline imprinting / cis-mQTL

機制：Sa cell 內甲基差異本是 germline 設定 → cluster 誤把 germline ASM 當 somatic subclone

反例比例：32-66% of 甲基 differential CpG 為 germline-origin

Mitigation：cross-ref normal BAM + germline VCF imprinting region 排除 + 限定 cells C1/C4/C5/C6 在 non-ASM

FM2: Untag 物理不可分

機制：Untag 內 40-60% 物理 unphasable — read 沒經過 informative SNV、長度太短、MQ<20 — 甲基化也面臨相同限制

Mitigation：Trust framework 排除 LOW + 報告 "rescue rate among phasable reads"

FM3: HP:Z:3 太稀少（chr19 0.3%）

機制：per 2kb window 多 <10 HP3 reads — 統計 power 不足

Mitigation：aggregate per 1Mb window + 跨 sample pool HP3 + HP3 細分降級 secondary

FM4: HCC1937 BRCA1 outlier

機制：BRCA1 mutant + CNV-driven germline het sample，已知 FP/TP 0.194 vs 其他 0.01

Mitigation：per-sample 報告，不強行 pool + 用 median 不用 mean

FM5: cluster centroid 偏向 majority hap

機制：hap-imbalance 區（LOH-adjacent）centroid dominantly 反映 majority → untag 偏向被歸類為 majority

Mitigation：balanced subsample centroid + Z-score normalize

6.2 探索建議（按 ROI 排序）

Phase A（推薦先做，最低成本驗證 trust framework）

Tooling MVP：移植 read_phylogeny_validator.py + 新增 untag classifier；在 HCC1395 chr19 only 跑 C1+C2+Sa+Sb

工程量 <1 day，無需新 C++。Pass criterion：C2 sanity pass + Sa confound 確認 + C1 silhouette >0.1

Phase B（Phase A 成功後）

擴 C3 + C4 + C5 + C6；HCC1395 全基因組；工程量 ~2-3 day

Phase C（Phase A+B 成功後）

Cross-sample 7 樣本（先檢查 COLO829 methylation calling）；Wilcoxon paired 跨樣本一致性；串接 Phase BCD 4-group framework；工程量 ~3-5 day

Phase D（NOT recommend immediately）

整合進 MSA 或 longphase-S binary (C++ 改動)；待 Phase A-C 全 POSITIVE 後啟動；工程量 ~2-3 週
