§2改進 tag 構想（6 狀態 R/A/X + 缺失值補完 + linear depth 演化樹）

用戶 5/22 提出的核心構想：現行 LongPhase-S HP tag 只看 germline het anchor + 1 階 somatic 累積，遺漏多階 sub-clone 演化結構。改進方向分三層；v4 採 linear depth notation（per user 5/23 選）。

§2.1 兩位點 R/A/X 9 狀態 matrix

對相鄰兩 SNV 位點，每個 read 在每位點的可能狀態為：

  • R (Reference) = 該 read 在該位點顯示 ref allele
  • A (Alt) = 該 read 在該位點顯示 alt allele（含 somatic SNV）
  • X (eXtinct/missing) = 該 read 未覆蓋該位點 / base quality 不足 / 對齊邊界

兩位點組合 = 3 × 3 = 9 種，其中 4 種含 X 缺失需補完：

Locus 2 = RLocus 2 = ALocus 2 = X
Locus 1 = R RR RA RX
Locus 1 = A AR AA AX
Locus 1 = X XR XA XX

藍 = Ref 紅 = Alt 灰 = Missing (X)

§2.2 X 缺失值補完規則（4 種模式 + 3-step ISM flow）

對 4 種 X 缺失模式（RX / AX / XR / XA），ISM 用 read 的甲基化模式聚類 + 鄰近 SNV vote，把 X 的 read 歸到最相似的 R 或 A 群：

缺失模式已知資訊3-step 補完規則
RXlocus 1 = R(1) 同 PS read → (2) ISM methyl cluster → (3) 鄰近 SNV vote → {RR, RA}
AXlocus 1 = A同上 → {AA, AR}
XRlocus 2 = R同上推 locus 1 → {RR, AR}
XAlocus 2 = A同上推 locus 1 → {AA, RA}

§2.3 HP 細分樹 — linear depth naming（4 場景 A/B/C/D）

v4 採 user 5/23 選定的 linear depth notation：

  • HP1 = germline root（RR）
  • HP1-1 = HP1 的第一代 child（+1 somatic event α）
  • HP1-1-1 = HP1-1 的第二代 child（+2 somatic events，linear extension）
  • HP1-2 = HP1 的第一代 child 但 mutation event 不同（兩個 1st-gen events sibling）
  • HP1-1-2 = HP1-1 第二代不同 mutation event sibling
  • HP2/HP2-1/HP2-1-1 同理（germline het 另一條 haplotype）

4 場景結構（per plan v4 §A4 + v4_evolution_figures README）：

  4. 85.9% PS set 含 ≥2 TP（A2_1 證實）→ ISM read-level 甲基聚類有足夠樣本
  5. HP 細分樹（HP1-1-1 / HP1-1-2 etc., linear depth）encode sub-clone 結構進 BAM aux field → future ClairS-TO retraining 直接吸收

Reframe

「LongPhase-S --somaticMode 用 germline het SNV 為 phasing anchor，LOH 不改變 normal-derived germline het 狀態（只改 tumor allelic frequency），因此 HP tag 在 LOH vs non-LOH 區段分配無顯著差異（AUC 0.504）。要間接驗 LOH 需改觀察 tumor HP1 vs HP2 read count imbalance（如 chr8 99.1% LOH 區段，HP1:HP2 比例顯著偏離 1:1），而非 HP-missing rate。」

當前 cycle status（v5 補：誠實面對 cross-sample failure）

Phase 2 methyl_filter 經 cycle 1-3 觀察，caller_af 為主導 feature（rank 1 in global FP LR，coef +3.44），methylation 5th-rank（marginal contribution）。

Cross-sample LOSO 結果 NEGATIVE — 必須誠實 disclose（v6: 雙數字 disambiguated）
  • HCC1395 in-distribution 5-fold OOF ΔF1 = +0.02236（cycle 1 global FP LR, 10 features, τ=0.39）
  • HCC1395 LOSO held-out (4-sample combined train) ΔF1 = −0.00012（drop = +0.02248, 100% effect = sample-level circularity bias）
  • 5-sample LOSO mean ΔF1 = −0.00004（HCC1395 / HCC1937 / HCC1954 / H1437 / H2009 全部 ≈ 0, Wilcoxon p=0.125, DIRECTION_NEGATIVE）
  • HCC1954 transfer 極端 case ΔF1 = −0.377（catastrophic — caller_af direction-inconsistent: HCC1395 d=+1.60 vs HCC1937 d=−1.41）
  • per memory project_phase2_cycle1_global_fp_filter.md（DOWNGRADED 2026-05-20 LOSO）

意涵：HCC1395 ΔF1+0.02236 屬 single-sample in-distribution gain，**不可用作 cross-sample LongPhase-S retraining 直接證據**。我們的 LR filter 在 production 設定下 not deployable — 此為與 LongPhase-S Reviewer 2 #3 同類「cancer cell line 外推困難」的誠實 case study，而非 positive evidence。
