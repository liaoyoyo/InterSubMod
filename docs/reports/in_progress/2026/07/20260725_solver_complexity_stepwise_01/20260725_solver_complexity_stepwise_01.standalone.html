§1　問題物件：超立方體、Steiner 點、group

每個區域內的 k 個 somatic sSNV 構成布爾超立方體 {0,1}^k 的座標軸。 一條 ONT read 的基因型向量 = 一個頂點；根固定在 germline all-REF（0^k）； 邊只允許 unit-flip（一次獲得一個突變，popcount 遞增）。

long-read 的部分覆蓋，如何變成「group」

這是本形式化最關鍵的一步：read 只穿過區域的一部分時，未覆蓋位點記為 X（未知，非 0）。 一個含 u 個 X 的觀測，對應超立方體上一個 2^u 個頂點的子立方體（面）； 樹只要碰到其中任一個就算解釋了這條 read。這正是 group-Steiner 的「group」。

3.3　樹數定理（S6/S7 的數學基礎）

定理

設 ∅ ∈ N ⊆ {0,1}k 且 N 為 unit-flip-closed（每個非根 x∈N 至少有一個 unit-pred 在 N 中）。 則以 ∅ 為根、邊皆 unit-flip 的生成樹（arborescence）數目恰為
A(N) = Πx∈N, x≠∅ dN(x)，　　dN(x) = #{ j∈x : x∖{j} ∈ N }
證明．（⊇）每個非根節點 x 獨立選一個 parent ∈ {x∖{j} : j∈x} ∩ N（closed 保證非空，共 dN(x) 種）。 所得圖中每個非根節點恰一入邊；沿 parent 指標走，popcount 嚴格遞減 1 ⇒ 不可能成環， 且必在有限步抵達唯一無父節點 ∅ ⇒ root-connected。故為合法 arborescence。
（⊆）反之，任一合法 arborescence 中每個非根節點恰有一個 parent，且該 parent 必為其 unit-pred 且屬於 N， 故對應唯一一組選擇。
兩者互逆 ⇒ 雙射 ⇒ 計數為乘積。∎

§5　兩個誠實的工程邊界

① S7 在生產是無上限的

ANALYSIS_TREE_CAP=0 ⇒ store_limit=None ⇒ 全部樹都實體化（非工作站顯示用的 32）。理論上這是 Θ(A_total) 的指數步； 實務上因實測 max=125 而無害，但理論上無界。 若骨幹擴大或 MAX_SNV 調高，這裡會先爆。

② capped 有兩種成因，意義不同

  • budget 超支（473 個）＝ 問題太密，放棄搜尋。
  • extra_cap 耗盡 → greedy fallback（355 個） ＝ 真的需要 >4 個隱藏節點，退化成單一貪婪解。
後者不只是「沒枚舉完」，而是連最小性都不保證。兩者目前共用同一個 capped 標籤， 論文中值得分開陳述。

§6　一句話口徑

求最小 group-Steiner 樹集合的成本集中在「逐層節點集搜尋」：候選數為 Σe≤E C(P,e)，在 P ≤ 2k−1 = 255、extra_cap=4、 budget=150,000 三重限制下有精確上界 164,221 （最壞約 1.641 秒／unit）。樹的計數由 A(N)=Π dN(x) 在 O(|N|·k) 內完成（多項式），列舉才是 Θ(A(N))（指數）。 理論絕對上界 Amax(8)=Πj jC(8,j) ≈ 7.7×10145 在 caps 下不可達； HCC1395 實測最大 125 棵、全基因組共 66,837 棵。
