# HCC1395 逐位點拓撲子結構跨來源驗證

## TL;DR

同一 HCC1395 cell line 的兩個跨來源技術資料，在共享 sSNV mutation-relation constraints 上呈現高於 within-region site-label permutation baseline 的部分再現性；證據支持 **partial technical reproducibility**，但不足以證明方法已重建真實 clone tree、已具 accuracy，或可泛化至其他樣本。

主要 HTML：`InterSubMod/docs/reports/in_progress/2026/07/20260712_HCC1395逐位點拓撲子結構跨來源驗證_01/20260712_HCC1395逐位點拓撲子結構跨來源驗證_01.html`

## 1. 問題與比較合約

- **C**：read pattern 推得的群組／節點數；對應布林超立方體上的有向根節點群組 Steiner tree 節點。
- **T**：與 read full/partial pattern 相容的候選樹結構。
- **Read full candidate space**：保留所有與直接 read pattern 相容的 T，不把多候選假裝成唯一結果。
- **VAF exact-score top set**：使用每個位點 read AF 的祖先－後代次序分數選出最高分 T；所有 exact ties 保留。此結果是推測，不是 posterior probability 或獨立 truth。
- **逐位點對關係**：每一對共享 sSNV 編碼成 F（較小 position 為祖先）、R（反向祖先）或 P（平行）。
- **誘導子結構**：只有一側 HP-specific 位點集真包含於另一側，且共享位點投影關係方向相容，才稱 induced substructure。相同位點下的候選集合包含只稱 resolution nesting。
- **HP mapping**：fixed region outcome 每個 evidence layer 只允許 identity 或整個 region 一次 HP1↔HP2 swap；禁止逐 component 選最好結果。逐位點 ledger 則先固定 Read-selected mapping，再用同一 mapping 顯示 VAF。

## 4. 每一對共享 sSNV 的支持關係

共有 8,096 個 shared-site pairs。

| Site-pair outcome | Read full | VAF official |
|---|---:|---:|
| Determined same | 868 | 5,304 |
| Ambiguous equal | 4,431 | 96 |
| One-sided contained | 2,753 | 707 |
| Ambiguous overlap | 8 | 0 |
| Conflict | 2 | 1,667 |
| Not evaluable | 34 | 322 |

- Read 的 determined-same：868/8,062 evaluable = 10.77%。
- VAF 的 determined-same：5,304/7,774 evaluable = 68.23%。
- VAF conflict：1,667/7,774 evaluable = 21.44%。
- `ambiguous_equal` 只代表兩側支持集合相同；`one_sided_contained` 只代表關係支持集被包含。兩者都不冒充已確定的單一拓撲。

## 5. Within-region site-label permutation null

Null 在同一 region、同一 mapped HP component 中置換 B 端共享位點標籤，保留 k、Q-set size、candidate multiplicity 與 HP mapping。Chromosome block bootstrap 與 leave-one-chromosome-out 用於不確定度；VAF top set 凍結且沒有重新 scoring。

| Endpoint | Observed | Null mean | Excess | Block 95% CI | Empirical p | LOCO |
|---|---:|---:|---:|---:|---:|---:|
| Read candidate-set exact | 50.30% | 42.22% | +8.07 pp | +7.08～+9.12 pp | 1/5001 | 22/22 positive |
| Read robust nested | 99.55% | 84.35% | +15.20 pp | +14.01～+16.51 pp | 1/5001 | 22/22 positive |
| VAF candidate-set exact | 56.66% | 32.79% | +23.86 pp | +22.34～+25.32 pp | 1/5001 | 22/22 positive |
| VAF robust nested | 67.98% | 41.61% | +26.37 pp | +24.90～+27.78 pp | 1/5001 | 22/22 positive |

Null 的 exact／robust-nested endpoint 是 shared-site projected candidate-set relation；其 p 值不能直接套到 fixed `strict exact＋真 induced` 1,599／1,790 上。

預先工程 gate 的結果：Read exact excess +8.07 pp 未達 +10 pp；VAF exact excess通過 +10 pp，但可判定 coverage 67.48% 未達 70%。較寬鬆的 Read robust-nested 同時通過，但該 endpoint 接近飽和，不能取代嚴格結構結果。

## 6. 粗拓撲、癌症基因與藥物資料的定位

- 先前 coarse exact-coordinate agreement：3,969/5,720 = 69.39%，Cohen's κ=0.4973。
- COSMIC CGC gene-body present-vs-absent：+3.15 pp，matched-null p=0.5855。
- DGIdb approved-antineoplastic gene-body：+3.11 pp，matched-null p=0.4295。

粗分類相似支持 face validity，但不是逐位點拓撲 endpoint。CGC／藥物 strata 未顯著，不能當 topology truth、方法 accuracy 或用藥證據。

## 7. 結論與 claim ceiling

### 可支持

> 同一 HCC1395 cell line 的兩個跨來源技術資料，在共享 sSNV mutation-relation constraints 上呈現高於 within-region site-label permutation baseline 的部分再現性。

### 不可支持

- 不能宣稱方法已準確重建真實 clone tree。
- 不能宣稱 VAF 已獨立確認祖先方向。
- 不能把兩個資料稱為獨立 biological replicates。
- 不能把結論泛化至其他 cell lines 或病人。
- 不能宣稱癌症基因或藥物註記驗證了 topology。

整體 verdict：**PARTIAL technical reproducibility；SCIENTIFIC NO-GO for proof of accuracy/effectiveness**。
