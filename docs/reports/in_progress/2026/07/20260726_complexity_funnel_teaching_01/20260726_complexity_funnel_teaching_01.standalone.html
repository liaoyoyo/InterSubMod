L0

全基因組當成一個超立方體

起點 · 為什麼非分區不可

把 HCC1395 chr1–22 的 80,234 個 sSNV 全部當成一個布林向量的維度，狀態空間是 280,234 —— 一個 24,153 位數的整數。宇宙原子數大約 80 位數。這一層存在的唯一目的，是說明「不分區」在數學上就已經出局。

|Xglobal| = 2N,   N = 80,234  →   log10|X| = N·log102 ≈ 24,153

Directed Boolean Hypercube {0,1}ᵏ

單區內部 · 狀態空間長什麼樣

L3

演化樹限制：unit-flip + 有根 + 單親

第二刀 · 生物學限制值多少錢

在超立方體上「選一棵樹」不是隨便連。三條限制：① 根固定是 0ᵏ（germline 全 REF）；② 每條邊剛好翻一個 bit 且只准 0→1；③ 每個非根節點恰好一個 parent。這三條合起來就是 arborescence（有向有根樹）。

A(k) = ∏x≠0 popcount(x) = ∏j=1k jC(k,j)   vs    無限制： nn−1, n = 2k

為什麼是連乘？因為每個非根頂點 x 只能從「少一個 1 的鄰居」來，這種鄰居剛好有 popcount(x) 個，而且每個頂點獨立挑一個。邊一定是 popcount 遞增，所以天然無環、天然 root-connected——不需要額外檢查。

L4

覆蓋公理 + closed：哪些節點集合法

第三刀 · 資料說了算

光是「是一棵樹」還不夠，樹必須解釋觀測。兩條硬約束：覆蓋公理——每筆通過門檻的觀測都要被樹上某個節點相容（完整觀測其基因型節點本人必須在樹上）；closed——每個節點的祖先鏈必須也在樹上，不能憑空冒出來。

N 合法 ⟺ ∀ x ∈ N∖{0}, ∃ j ∈ x : x∖{j} ∈ N   (closed)
且 ∀ p ∈ O*, ∃ x ∈ N : x ~ p   (覆蓋公理)

「相容」的定義決定了 Group 從哪來：完整觀測只相容它自己（一個點）；有缺口的部分觀測相容一整個子立方體（一群點），碰到其中任一個就算覆蓋。這就是 group Steiner 的 group。

H（隱藏節點）選擇：從池子 P 選 e 個

爆炸點 · 91% 的時間都花在這

觀測到的節點通常接不成樹，中間缺的祖先要補進來——這些補進來的就是隱藏節點 H（Steiner 點，程式裡 label 前綴就是 H_）。目標是 H 越少越好，做法是 e = 0, 1, 2, … 逐層往上試，第一個找得到可行解的層就是 emin，並把那一層所有可行解全部收下。

Cand(P) = Σe=0E(P) C(P, e),   E(P) = min( 4,  min{ e : C(P,e) > 150,000 } − 1 )

兩道閘：硬上限 extra_cap=4，以及每層預算 per_level_budget=150,000。哪道先咬到，看候選池 P 多大。

最反直覺的一件事：P 變大，工作量可能暴跌。因為預算一咬，E 就自動降級。所以「越密越慢」是錯的——是鋸齒。

從節點集到樹：獨立選 parent

輸出 · 樹的數量反而很小

節點集 N 定下來之後，樹的數量是純組合：每個非根節點獨立從「在 N 裡面的 unit-pred」挑一個當爸爸。所以是連乘，再對所有並列最小的 N 求和。

ntrees = ΣN ∈ 𝒩min ∏x ∈ N∖{0} | { j ∈ x : x∖{j} ∈ N } |

一個漂亮的等價定理（solver 靠它省下生成所有樹的成本）：某節點的 pred 數 ≥ 2 ⟺ 該 N 違反 rooted three-gamete ⟺ 它的所有生成樹都含 recurrence。反之 pred 數全 = 1 → 連乘 = 1 → 唯一一棵無 recurrence 的樹。所以「數樹」和「判斷相容性」是同一件事。

VAF / CCF 加權：ambiguous 集合內部定序

最後一刀 · 用 read 數破等

枚舉完剩下 5,959 個 unit 有多棵並列最小樹。破等的依據是 pigeonhole：祖先節點的 read 數必然 ≥ 它後裔的 read 數，所以 read count 本身就攜帶方向資訊。

P(T | reads) ∝ ∏ read-count   （pigeonhole：祖先 read 數 ≥ 後裔 read 數）
數值佔比
ambiguous unit 總數5,959100%
成功破等（top posterior ≥ 0.6）3,98066.8%
維持等機率（不強行定序）1,97933.2%
破等者中 winner 符合 pigeonhole3,95699.4%

這一層最容易被攻擊，先講清楚兩件事

① 為什麼這不算循環論證？
read count 來自同一條通道 B（sSNV 基因型），不是甲基、不是 HP。形式化規格的紅線是「不得用通道 A（φ）或通道 M（d，含甲基）對樹集全序化」，寫成 ∂(tree set)/∂φ = ∂(tree set)/∂d = 0。甲基一律事後註記，不進 likelihood。read-count 加權沒有跨通道，所以不觸線。
② CN confound 沒有解決。
3,999 / 5,959 （67%）的 ambiguous unit 位於 CN-gain 區。在 CN-gain 區「read 數 ∝ CCF」的前提不成立，所以那部分的破等結果只能當工程 heuristic，不能當證據。CN-clean 的只有 1,960 個。

L8

Group Steiner Arborescence：名稱、複雜度、與紅線

定位 · 我們到底解了什麼、沒解什麼

把前面所有層合起來，這個問題的正式形狀是：在有向布林超立方體上，找一棵以 0ᵏ 為根的 arborescence，覆蓋所有 terminal group（完整觀測＝單點群，部分觀測＝子立方體群），使 Steiner 點最少。這正是 Group Steiner Arborescence 的形狀。

三個名詞各自對應什麼

名詞數學意義在本問題裡是什麼
Groupterminal 不是單點，是「一群點，碰到任一個就算」一條 read 沒讀完全時，它相容的整個子立方體
Steiner為了連通而必須額外加入、非 terminal 的節點隱藏祖先基因型 H（未被任何 read 直接觀測到）
Arborescence有向有根樹：每個非根節點恰一個 parent、全 root 可達根 = germline 全 REF；邊只准 0→1，方向由突變不可逆決定

複雜度地圖：哪些是多項式島、哪些是 NP-hard 海

階段數學問題複雜度本方法的立場文獻
骨幹（完整觀測）directed perfect phylogenypoly算到底、確定Gusfield 1991
部分觀測補全（缺口）Incomplete Directed Perfect Phylogenypoly→linear算到底，有嚴格基礎Pe'er et al. 2004

三條不可跨越的紅線（規格 §7.5.3）
  1. 枚舉，不是最佳化：輸出所有並列最小的樹，不宣稱解通用 directed / group Steiner 的 min-cost 最佳化。「minimal」= 字典序前緣的全集，不是挑一棵代表。
  2. 不用任何通道對樹集全序化：甲基與 HP 一律事後註記，保證 ∂(tree set)/∂φ = ∂(tree set)/∂d = 0。
  3. 通用 group-Steiner cover-minimize = 白地：partial-read → subcube 群覆蓋是真結構類比與原創 motivation，但 solver 做的是「capped-k 窮舉 + IDP 補全 + 覆蓋公理」，不是 cover-and-minimize 求解。

那 NP-hard 怎麼繞過的？

沒有繞過——是不進去。NP-hardness 是 k → ∞ 的漸近性質；我們有硬上界 k ≤ 8，狀態空間只有 256 點，落在窮舉可解的小島上。代價已經在 L1 付過了：46,137 個 sSNV 因 densest-8 沒進 solver。這是把 NP-hard 換成資訊損失，而不是換成近似誤差——差別在於損失是可數、可報告的。
