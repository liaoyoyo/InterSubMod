**碩論主軸**：*Subclonal reconstruction using somatic haplotagging and methylation profiles with Nanopore sequencing*
（來源：`20260701_thesis_research_handoff_onboarding_01.md §0`）

**三資訊源分工（口徑鎖定）**：
| 資訊源 | 角色 | 邊界 |

**Pipeline 骨架**：
`ClairS v0.4.0 paired（somatic call + germline filter）→ LongPhase-S recalibrated（FILTER=PASS VCF + 逐 alignment HP/PS tag）→ per-region sSNV 單分子共現 → per germline-HP-family lineage-unit 布爾超立方體 group-Steiner 枚舉全最小樹（rooted three-gamete 判 recurrence + V1-V7）→ SAVANA CN post-hoc recurrence annotation（5/7 可用）+ 甲基 bounded-auxiliary 事後 L3`

**單位階層 6 層（絕不混分母鐵則）**：
- U1 sSNV → U2 read → **U3 region（主分母）** → **U4 lineage-unit（region × germline-HP-family = 一次重建的自然單位 = 一組枚舉樹）** → U5 tree → U6 node
- 🔑 **region ≠ group ≠ unit ≠ HP-family**：07-14 口徑下 group = region（51,815 = 51,815）；lineage-unit = region × HP-family；HP-family = HP 軸（read→family 1:1；`1/1-1/1-2`→1、`2/2-1/2-2`→2、`3/4` auxiliary），region 依 family 分開建樹修 allelic/clonal 混淆。
- 🔴 分母不可比：region all-determined 32.6%（分母 region）≠ lineage-unit determined 55.2%（分母 lineage-unit）。

**Tier 天花板 ⭐3 的原因**：單樣本層級 + 單 pipeline 自我參照 + regional 非 genome-wide + 僅約 11% 完全可辨識 + 缺 single-cell / 正交真值。升 ⭐4 需 ≥5/7 樣本 + COLO829。

## §2 新 sSNV 共現研究 — 完整細節 / 結論 / 數據（核心）

### §2.1 方法定義
把 retained sSNV 依位置聚成 **region**（adjacent-gap ≤50 kb 的 somatic sSNV 連通鏈）；每個 region 內 primary HP1/HP2 **lineage-unit** 各自建一組候選樹，候選集由 read-state 約束建立（full-span `obs_populations` + 重疊 partial-read `obs_subreads`）。**「partial-read-constrained」= 候選集來自互相重疊的 read-state 約束**，不代表缺資料/錯誤，也不等於有單一 read 跨完整 region。

### §2.4 關鍵科學 caveat — `backbone_sensitive`（L1）
主結果（LongPhase-S PASS）與 ClairS PASS sensitivity 判定為 **backbone_sensitive**：aggregate 僅差 2.06 pp，但 **min site Jaccard 0.577 / min unit Jaccard 0.474 / topology concordance 0.936** → 拓撲對 caller backbone 敏感。故主結果**固定用 LongPhase-S PASS**，ClairS PASS 僅作 sensitivity。⚠ 此比較只驗 recalibration 效應，**非獨立第三方 caller 的 robustness**。

### §2.5 結論 + claim 邊界
- **可寫**：7/7 dataset terminal PASS；partial-read-constrained model-determined regional mutation-state trees；完全定樹率 27.4%、完全不定 47.2%（誠實報告不定比例）。
- **不可寫**：region tree = biological clone；C>1 = confirmed subclone；clone 數/fraction/祖先關係為 confirmed（皆 inferable，需 single-cell / multi-region 正交真值）。
