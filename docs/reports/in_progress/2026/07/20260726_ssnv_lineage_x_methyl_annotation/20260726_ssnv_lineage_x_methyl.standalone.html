兩個問題的實測答案

Q1 為何 HP 下 ALT 內還會看到多群？主因是分群程序本身——匹配的單峰 null 在同一門檻下也產生 5% 的「兩群」，而管線的 optimal_k 值域根本沒有 1。扣掉 null 後確實還有真實多峰 （ALT 23.9%），但同位點的 REF 群是 23.6%，一樣多（配對 p=0.29）—— 所以那是區域屬性（epiallele／PMD 式的分子間異質性），不是等位或譜系屬性。

Q2 與 sSNV-lineage 分群是否高度相關？否，接近零。 骨幹位點 M2 比例 3.7% vs 孤立位點 3.6%（OR=1.03, p=0.854）。 唯一看似有訊號的 M1 位移（+1.7pp, p=0.007）在固定局部突變密度後完全消失。

L1Q1 為何會看到「ALT 內多群」—— 四個成因，逐一量化

  1. 分群程序保證產生分群（最大宗）。任何 1 維資料做 k=2 最佳切分都會得到「兩群」； 用同 n 同 SD 的單峰高斯重抽，在同一門檻下也有 5% 被判為多群。 管線自己的 optimal_k 在 30,476 個位點中從未輸出 1（值域 2–6）， 結構上就不可能回答「其實只有一群」。
  2. 真實的分子間異質性存在，但屬區域屬性。扣除 null 後 ALT 有 23.9% 超標， 遠高於 5% 的期望值 —— 這是真的。但同位點 REF 群 23.6%，兩者無差異。 癌症基因組的 partially methylated domain 與 epiallele 隨機性會讓整個區域的分子彼此不同， 與該位點帶不帶突變無關。
  3. read 覆蓋範圍差異（已排除）。每條 read 覆蓋不同 CpG 子集，逐 read 平均會混入「覆蓋差異」。 改用共同-CpG 集（中位 21 個，全窗 99 個）後分離度中位由 3.25 變 3.21 —— 影響可忽略，不是主因。
  4. 正反股（strand）（已排除）。ALT 分群與股別顯著關聯者僅 4.6%， 等同 5% 的偽陽性率。

還有兩個本輪未能分離的候選成因：CN 增益（同一 HP 家族內有多份拷貝， 各拷貝甲基狀態可不同 —— HCC1395 52% 單元為 gain）與細胞型別混雜／HP 指派誤差。 兩者都會產生「區域性、非等位專一」的多群，與觀察到的模式一致，但需要 single-cell 或 CN-neutral 足量樣本才能拆開。

L3定義、方法與限制

狀態定義（lineage 軸與 methyl 軸）

lineage 軸（來自 sSNV 共現骨幹）：L1_BACKBONE = ≥1 partner·雙端 somatic·coread≥6；L2_WEAK_LINK = 有 partner 但未過閘；L3_ISOLATED = 無 partner

methyl 軸（本輪定義，全部對 null 校準）：

  • M2_ALT_ONLY_MULTI：ALT 群分離度 ≥ null-95th 且 兩子群 |Δβ|≥0.20，且 REF 群未達門檻。 最保守 —— 要求內建對照乾淨。
  • M3_REGION_MULTI：ALT 與 REF 都達門檻 → 區域屬性。
  • M1_ALTREF_SHIFT：within-HP ALT vs REF 平均位移顯著且 |Δβ|≥0.10 且超過置換 null。
  • M0_NONE：以上皆非。
null 的建構（為何門檻是 3.86 而不是拍腦袋）

每個單元各自產生匹配的 null：同 n、同 SD 的單峰高斯重抽 3 次，各自求最佳 2-切分的分離度。 全基因組 9,414 個 null 的 95 百分位 = 3.86。用它當門檻時，null 自身的通過率 依定義為 5.0%，觀察值超出的部分才是訊號。

另一個獨立 null 是置換 null（保持 read 集合不變、隨機重排 ALT/REF 標籤），用於 M1 的超額計算。

限制
  • 單樣本（HCC1395）、單一 2026-01 w5000 資料線。跨 7 樣本未驗證。
  • 覆蓋門檻：同一 HP 內各需 ≥6 條 read 且共同 CpG ≥8，9,346/30,490 位點才進入標記層 —— 偏向高覆蓋區。
  • CN 未拆開：52% 單元為 gain、47% 為 LOH，CN-neutral 極少， 無法用它作乾淨對照。
  • M2 與 REF 對照不完全對稱：M2 額外要求 |Δβ|≥0.20（REF 未存該欄），故 M2 為保守估計； 公平的對稱比較見第一張圖。
  • lineage 狀態沿用 2026-07-26 的串聯註記，未納入分層樹求解器的拓撲狀態。
