## 技術總結：區間高重疊，粗拓撲僅部分一致

- **區間層：** 6,252 個 exact-coordinate matches，覆蓋 HCC1395 的 **82.37%** 與 DORADO 的 **86.02%** primary regions。
- **五分類層：** 5,720 個 complete-both regions 的 agreement 為 **69.39%**（95% CI 68.18%–70.57%），Cohen κ=**0.497**。染色體保留的 5,000 次 permutation null agreement 97.5% 上界只有 **40.51%**（empirical p=0.000200），因此不是單純類別比例造成的偶合。
- **但不等價：** 五類 aggregate profile 的 total-variation distance 為 **20.03 percentage points**；ordered exact-tree set agreement 僅 **19.74%**，容許 HP1/HP2 phase swap 後為 **35.21%**。
- **VAF 推測層：** 在兩側原本都 `Topo>1`、且各自被 VAF 第一順位集合縮至單一 shape 的 2,089 對中，shape agreement 為 **43.99%**／swap **77.74%**；在兩側都實際使用 VAF 且各自唯一的 2,543 個 mutation-labeled exact forests 中，agreement 為 **20.61%**／swap **37.32%**。前者沒有 mutation direction，後者仍只是 raw read-AF heuristic；兩者都不是 accuracy 或 biological truth。


### 癌症基因與藥物註解不能當成 truth set

CGC gene-body-present regions 的 descriptive agreement 為 **72.39%**，比 absent 高 **3.15 pp**，但 chromosome + region-length-decile conditional p=**0.5855**；DGIdb approved-antineoplastic gene-body-present 為 **72.25%**，比 absent 高 **3.11 pp**，conditional p=**0.4295**。COSMIC CLP all-status n=333 的 p=0.3195；confirmed-somatic 只有 n=12，agreement=75.00%（95% CI 46.77%–91.11%），p=0.7313。**7/7 annotation strata 的 two-sided p 都 >0.05**，因此只能做 context/face validity，不能證明 topology 正確或藥物可用。


### 目前判定

**SHARE WITH CAVEATS / PARTIAL technical reproducibility；SCIENTIFIC NO-GO for proof-of-effectiveness.** HCC1395 與 HCC1395_DORADO 是同一生物 cell line 的兩個技術 sequencing/processing datasets，不是兩個獨立病人。現有結果支持「訊號高於 chance、工程內部自洽、部分技術再現」，但 historical layered-v2 不能證明 biological clone truth，也不能驗證因果藥物關係。

## 五分類定義

| Class | Rule | Boundary |
|---|---|---|
| 無 HP 內關係 | Topo=1 且 primary HP 圖中沒有分岔、也沒有深度≥2 的直系鏈 | 可能是單 HP 單節點，也可能是 HP1/HP2 各自孤立；不等於單一 clone |
| 姐妹 only | Topo=1 且至少一個 primary HP 節點 out-degree≥2，但 max depth<2 | 分岔只在同一 HP 內計算 |
| 直系 only | Topo=1 且至少一個 primary HP max depth≥2，但無分岔 | H_ intermediate/partial state 參與圖深度 |
| 姐妹＋直系 | Topo=1 且同一 region 的 primary HP forest 同時出現分岔與深度≥2 | 雙 HP 保留 ordered forest，不跨 HP 連邊 |
| Topo>1 未定 | Topo>1；候選集仍包含一種以上形狀 | 強制保留未定，不用某一候選形狀代表 region |
