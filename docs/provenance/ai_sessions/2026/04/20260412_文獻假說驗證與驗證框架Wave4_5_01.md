## 2. 關鍵決策

### 2.1 驗證框架設計決策

| 決策 | 理由 |
|------|------|
| `--track paired\|to` 參數貫穿整個 pipeline | 確保 TO 與 Paired 模式從 validate.sh → run_benchmark.sh → compare_metrics.py → baseline_store.json 全鏈正確 |
| Git worktree 隔離實驗 | 各實驗分支獨立建置，共享只讀 BAM/VCF 數據，避免衝突 |
| 目前循序執行（非平行）| 避免 NFS 共享磁碟資源競爭，未來可擴展為 multiprocessing |
| YAML fallback parser | 環境可能無 PyYAML，提供無依賴備案 |

### 2.2 文獻驗證設計決策

| 決策 | 理由 |
|------|------|
| 從 significance_summary.csv 直接構建路徑 | 避免 NFS 上 glob 掃描 30K+ 目錄（極慢），改用 `{chr}/{chr}_{pos}/{chr}_{pos-5000}_{pos+5000}/` 直接構建 |
| 兩層分析策略 | Part A（全域 340K aggregate, 快速）+ Part B（5,360 sampled, 精確方向性分析）|
| AF proxy 用 HP family ratio | 沒有直接 AF 欄位，用 min(HP1,HP2)/(HP1+HP2) 近似 |
| PMD 用 mean methylation 0.3-0.7 proxy | 無外部 PMD 註釋 BED 檔，但文獻定義 PMD 即為中度甲基化區域 |

## 4. 核心定量結果

### 4.1 L1 方向性 ASM（epiTRACERx 假說）

```
                      TP (somatic)          FP (germline)
signed_delta mean:    -0.0003 (p=0.854)     -0.0205 (p=1.16e-14)
ALT>REF 比例:         49.4% (隨機)           44.3% (偏向 REF)
|ASM| per CpG:       0.0416                0.0699
AlleleDelta (PERMANOVA): 0.0200            0.0312
|AlleleDelta| AUC:   0.5353 (反轉 — FP > TP)

結論: NEGATIVE — TP 無方向性 ASM；文獻的 ASM 限於 driver mutations
```

### 4.2 L2 PMD 分層

```
CpG variance:  PMD-like=0.118 vs Non-PMD=0.072 (p=1.13e-140) ← 生物學確認
High-var CpG:  PMD-like=69.6% vs Non-PMD=46.2% (p=3.91e-102) ← 確認

|ASM| AUC by zone:
  Hypomethylated:     0.505 (無效)
  PMD-like:           0.586 (微弱)
  Fully methylated:   0.622 (反而更好)

結論: 生物學 POSITIVE（PMD 異質性確認），應用 NEGATIVE（不改善判別）
```

### 4.3 L3 Normal Baseline 可行性

```
Normal BAM 可用性:  7/7 樣本均有 Normal BAM，全部含 MM/ML 甲基化標籤
HCC1395BL.bam:      140GB, 有 C+h 和 C+m 標籤 (5mCG + 5hmCG)
FP germline ASM:    mean=-0.0205 (p=1.16e-14) ← Normal baseline 可消除此信號

結論: FEASIBLE — Phase 2A 最高優先級實作方向
```

### 4.4 L4 fCpG（EVOFLUx）

```
CpG variance mean:   TP=0.0828 vs FP=0.0825 (p=0.767, 無差異)
High-var CpG frac:   TP=0.510 vs FP=0.530 (幾乎相同)

結論: NEGATIVE — fCpG 選擇無法改善 TP/FP 判別
```

### 4.5 AF 分層驗證

```
AlleleDelta by AF bin: 所有 bin 中 FP ≥ TP（差異一致）
AlleleSig rate: TP 在 AF 0.3-0.5 有更高 sig rate（47-59% vs 34-43%）
HP_Ratio 與 AlleleDelta: Spearman r=-0.075 (TP), -0.128 (FP)（弱相關）

結論: ASM 差異不依賴 AF bin，是獨立的生物學效應
```

## 5. 研究方向影響

### 確認關閉的方向
- L1 方向性 ASM（用於 TP/FP 判別）
- L4 fCpG 選擇（用於 TP/FP 判別）
- PMD/ChromHMM Gating（用於 TP/FP 判別）

### 強化支持的方向
- **Phase 2A Normal Methylation Baseline** — BAM 可用 + 理論依據最強（可消除 FP 的 germline ASM）

### 新發現
- FP 有顯著方向性 ASM (REF>ALT, mean=-0.0205)，可能對應 germline mQTL
- Mid-methylation (PMD-like) FP 的 ASM 最強 (delta=-0.041)
- Fully methylated 區域的 TP/FP 判別力最高 (AUC=0.622)
