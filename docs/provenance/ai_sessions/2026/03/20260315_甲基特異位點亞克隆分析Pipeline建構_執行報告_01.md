## 對話背景

使用者提供一份詳細研究計劃書，要求實作以下四個 Phase：
- Phase 1：從 significance_summary.csv 建立 TP/FP 特徵矩陣
- Phase 2：甲基化辨識位點分析（分層統計 + ROC-style threshold sweep）
- Phase 3：亞克隆地圖建構（Subclone 位點 + 染色體密度圖）
- Phase 4：Case Study 視覺驗證（路徑確認，不執行圖像生成）

計劃書原本預設使用 `20260119_all-with-w5000_1`（舊欄位），但實際發現 `s-pure/HCC1395/20260307` run 已含所有新欄位，故使用該 run 作為 pilot 資料來源。

## 關鍵決策

| 決策 | 原因 | 影響 |
|------|------|------|
| 使用 s-pure/HCC1395/20260307 而非 20260119 | 20260307 已有新欄位（PairwiseMedianDist 等），20260119 無 | 分析範圍縮小（29,740 TP vs 30,476），但欄位更完整 |
| Phase 3 region_root 路徑調整為 `intersubmod_tp/filtered_snv_tp/{chr}/{chr}_{pos}/*/` | 實際目錄結構有 chr 子目錄與 window 子目錄，非扁平 | clustering enrichment 成功（198/200 region 有效） |
| 不執行 all-with-w5000 新 run | 計劃書已有 s-pure run 可直接使用，節省數小時運算 | 需要在 pilot 報告中標記此 limitation |
| Phase 4 只確認路徑而非生成報告 | 視覺驗證需要人工判讀 SVG/HTML，AI 無法代替 | 輸出了 15 個 case study candidates 清單 |

## 核心發現（觀念更新）

| 更新前認知 | 更新後（本輪發現） |
|---|---|
| Subclone class 的特異性未量化 | Subclone FP 率僅 **0.71%**，是所有 class 中最低的 |
| CramersV>0.3 的精確度未知 | CramersV>0.3 整體 precision=**99.72%**；在 Subclone 中為 **100%**（15/15 TP） |
| Subclone 可能與 allele 訊號相關 | Subclone AlleleDelta≈0，**與 allele 分離完全獨立**，是純甲基化特徵 |
| all-with-w5000 run 才有足夠 FP | s-pure run 的 627 FP 已足以做 pilot 分析 |
| PairwiseMedianDist 方向未確認 paired mode | Paired mode FP>TP（0.231>0.200），再次確認 dataset-dependency |

## 對話摘要

本輪依計劃書建立三個 Phase 的分析 pipeline，使用 HCC1395 5kHz 20260307 s-pure run（含新欄位）執行 pilot。Phase 1 建立了 30,367 行特徵矩陣；Phase 2 發現 AlleleDelta 是最強的 FP 辨識特徵，CramersV>0.3 達 99.72% precision；Phase 3 建立全基因組亞克隆地圖，識別出 1,412 個 Subclone 位點（chr8 密度最高），並選出 15 個強候選位點供人工視覺驗證。最重要的新發現是 Subclone class 的 FP 率僅 0.71%，且完全獨立於 allele 訊號，是純甲基化亞克隆特徵。
