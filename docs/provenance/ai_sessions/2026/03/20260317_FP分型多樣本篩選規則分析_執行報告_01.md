## 觀念更新

- 【舊】Quality_Score < 75 在 H2009 可有效移除 ~50% FP → 【新】實測 precision=0.002，H2009 FP 屬 germline 漏報型，需 VAF 特徵識別
- 【舊】HCC1954 Lost TP 問題待分析 → 【新】確認機制：AlleleDelta=0.319（17.7x）使 ISM 把高甲基信號的真 TP 誤判為 HP-driven FP
- 【舊】期望找到跨樣本通用篩選規則 → 【新】確認不存在：7 樣本 FP 類型各異（A/B/C），通用閾值必然在某些樣本造成損害
- 【新增】FP 三類型框架：Type A（germline, VAF≈1）、Type B（平台特異高 AD）、Type C（特徵重疊，ISM 盲區）

本次對話完成了三項主要工作：(1) 對 H2009 per-region 資料實測 Quality_Score < 75 的 FP triage 效率，結果 precision=0.002 推翻前置報告 C1 結論；(2) 生成 HCC1954 Lost TP vs Kept TP 八特徵箱形圖，確認 ISM 過度過濾高甲基信號真 TP 的機制（AlleleDelta 17.7x、100% Strong）；(3) 建立 FP 三類型分類框架（Type A 高 VAF germline / Type B 平台特異高 AD / Type C 特徵重疊型），並量化各篩選規則 precision/recall，確認跨樣本通用規則目前不存在，最好的單樣本規則是 HCC1937 germline 型（precision=0.111）。
