## 對話背景

Phase 4 Case Study（2026-03-15/16）完成了 9 個位點（5 TP + 4 FP）的甲基化視覺觀察，發現需要一套標準化流程整合 IGV 截圖 + 甲基熱圖 + 統計特徵。計劃書（v3 溯源驗證版）要求三條核心原則：溯源可追蹤、比較建立基準、觀察→結論→驗證閉環。

## 關鍵決策

| 決策 | 原因 | 影響 |
|------|------|------|
| 報告結構四層（A視覺+B甲基+C比較+D驗證）| 確保觀察有可驗證的閉環，不只是描述圖片 | 每個 case 都需要驗證假說表（支持/反駁/驗證方法/驗證結果）|
| 第 0 節「研究溯源」整份報告只寫一次 | 確保報告獨立可讀，不依賴上下文記憶 | 包含樣本資訊、pipeline 版本、篩選條件、HP tag 說明 |
| HPP 作為 HP-driven FP 最可靠指標 | FP-B1 案例驗證：HPP=0.001 vs TP chr6 HPP=1.0 差異最顯著 | K1 知識點：HPP < 0.05 是 HP-driven FP 第一警示 |
| 比較框架三層（全局+同類+差異對照）| 觀察的特殊性需要多角度確認，才能避免主觀誤判 | 每個 case 需要同類 FP 對照（FP-B2）和差異 TP 對照（chr6 TP-1）|

- 【舊】CramersV 高 = 甲基信號強 = 較可能是 TP → 【新】CramersV=1.0 的 FP-B1 提醒：CramersV 高是甲基-allele 相關強度，不是 somatic 充分條件；需同時確認 HPP
