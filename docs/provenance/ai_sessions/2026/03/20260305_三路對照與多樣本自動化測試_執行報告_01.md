## 對話背景

本次對話依照預定計劃執行三個 Phase：
- **Phase 1**：以 HCC1395 DORADO BAM 進行 tumor-only / normal-only / mixed 三路對照，量化甲基化距離差異
- **Phase 2**：對所有 6 個 ONT 癌症樣本執行 chr19 快速 InterSubMod 測試，建立基準線
- **Phase 3**：依實驗觀察結果修正問題

在執行過程中發現計劃有一個錯誤（t50_n00 標記為「50/50」但實為 100% tumor）、一個非預期 Bug（H2009 Segfault），並完成了 Bug 的根本原因分析與修正。

---

## 關鍵決策

| 決策 | 原因 | 影響 |
|------|------|------|
| 將 Mixed 樣本從 t50_n00 改為 t30_n20 | 計劃有誤：t50_n00=100% tumor，非混合；t30_n20=60%T+40%N 才是真正混合 | 三路對照結果更具科學意義 |
| 先跑 chr19 快速驗證，全基因組背景執行 | 全基因組（112,387 regions）需要數小時；chr19（592~826 regions）不到 1 分鐘 | 快速取得初步結論，背景持續跑全基因組 |
| H2009 改用 j=7 執行（後修正為可用 j=8）| 調查 Segfault 根本原因前的暫時繞過；修正後 j=8 可正常運作 | H2009 2843 regions 成功完成 |
| 修正 no-filter + secondary reads bug | 發現根本原因：secondary reads 無 SEQ，進入 MethylationParser 觸發崩潰 | 穩定性大幅提升，105 測試全過 |
| 重啟全基因組任務使用新 binary | 舊 binary 有 bug，mixed_t30n20 全基因組在 j=24 和 j=7 都崩潰 | 確保全基因組結果正確 |

## 科學觀察與更新

| 更新前認知 | 更新後認知 |
|-----------|-----------|
| t50_n00 是「50/50 混合」| t50_n00 = 100% tumor；真正混合應用 t30_n20（60%T+40%N） |
| H2009 Segfault 是線程問題 | 根本原因：--no-filter 未過濾 secondary reads → BAM 中 530 個 length-1 secondary reads 進入 MethylationParser |
| 各樣本距離分布應相似 | HCC1395 DORADO 距離（0.316）遠高於其他癌症樣本（0.097~0.215），差異顯著 |
| H3 假設（組織差異）未驗證 | chr19 初步支持：Tumor(0.316) < Normal(0.354) < Mixed(0.442)，效應量中等 |
| H2009 是普通樣本 | H2009 顯著性率最高（3.8%，109/2843），且含大量 secondary reads，需特別處理 |

## 對話摘要

本次對話成功執行了三路對照實驗（chr19 快速版），初步量化了 tumor / normal / mixed BAM 在甲基化距離上的差異，方向符合 H3 假設（梯度：Tumor < Normal < Mixed）。同時完成所有 6 個 ONT 癌症樣本的 chr19 基準線建立，發現各樣本距離分布差異顯著，H2009 具有最高甲基化顯著性率。在過程中發現並修正了 `--no-filter` 模式下 secondary reads 導致非確定性 Segfault 的重要 Bug，並通過了完整的 105 個單元測試。全基因組三路任務持續在背景執行中，完整評估有待後續 haplotagging 與跨 purity 驗證。
