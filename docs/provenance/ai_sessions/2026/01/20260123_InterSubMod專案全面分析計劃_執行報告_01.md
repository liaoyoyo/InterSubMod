### 計劃內容摘要

本次對話處理的計劃包含以下核心內容：

#### 一、研究目標與科學動機
- 核心研究目標：透過整合 DNA 甲基化、體細胞變異、單倍體型資訊解析腫瘤異質性
- 解決的科學問題：腫瘤演化、變異檢測準確性、表觀遺傳機制
- 長讀取測序優勢：直接定相、單分子解析度、多模態檢測

#### 二、方法學設計與技術選擇
- **距離度量算法**：
  - NHD（預設）：直觀反映不一致率
  - Bernoulli（優化）：抑制低信心位點雜訊
  - L1/L2、Jaccard、Pearson（各有適用場景）
- **UPGMA 階層聚類**：適合演化分析，無需預設 K 值
- **統計檢定**：PERMANOVA（計劃中）+ Cramér's V 效應量

#### 三、核心演算法實作細節
- **MM/ML 標籤解析**：Delta-encoding、座標轉換、CpG 驗證、多重修飾處理
- **CIGAR 字串座標校正**：精確映射 Read Index → Reference Coordinate
- **距離矩陣計算優化**：OpenMP 平行化、位元運算、記憶體管理
- **統計檢定實作**：Fisher Exact Test、Chi-square、FDR 校正

#### 四、實驗結果與效能評估
- **F1 分數優化**：QUAL < 0.8 過濾策略提升至 0.8424（提升 2.7%-3.3%）
- **TP/FP 辨識效果**：
  - VCF QUAL AUC: 0.9668（極佳）
  - VCF AF AUC: 0.9235（極佳）
  - Cramér's V AUC: 0.5194（無效）
- **關鍵發現**：VCF 品質特徵遠優於甲基化異質性指標
- **處理速度**：單 Region < 300ms，批次繪圖 50 regions/sec

#### 五、已知問題與技術限制
- **資料解析問題**：MM/ML 標籤遺失、多重修飾索引混淆、CIGAR 座標映射
- **演算法限制**：Pearson Correlation 失效、Jaccard 生物學爭議、統計檢定不穩定
- **TP/FP 辨識瓶頸**：
  - 僅 6.1% TP 顯示顯著甲基化異質性
  - 93.9% TP 無顯著信號，限制獨立驗證能力
- **效能限制**：深度依賴性、稀疏矩陣計算、視覺化效能
- **科學驗證挑戰**：甲基化異質性非 SNV 普遍特徵，FP 生物學特徵複雜

#### 六、程式碼架構與設計決策
- **核心模組**：RegionProcessor、MethylationParser、DistanceCalculator、ClusteringEngine、StatisticalTester
- **資料流程**：S0-S7 Pipeline（VCF → Region → BAM → Matrix → Distance → Cluster → Output）
- **平行化策略**：Per-Region（粗粒度）+ Matrix Calculation（細粒度）
- **關鍵設計模式**：Strand-Aware Processing、Anchor-based Analysis、稀疏轉稠密、狀態位元壓縮

#### 七、未來研究方向與改進策略
- **方法學改進**：全面導入 Bernoulli 距離、自適應距離權重、非監督式分群、多重比較校正
- **提升 TP/FP 辨識**：機器學習整合模型、區域性過濾（黑名單）、救援策略
- **解決甲基化信號稀缺**：擴展分析窗口、甲基化異常位點（MSA）分析、關注亞克隆類別
- **整合新特徵**：CNV/LOH 資訊、鏈偏差、多樣本/純度梯度分析
- **效能優化**：GPU 加速、增量更新、稀疏矩陣優化
- **科學驗證**：跨樣本驗證、臨床應用（亞克隆追蹤）、表觀遺傳生物標記發現

#### 八、實施建議與優先順序
- **短期（3 個月）**：VCF 過濾 + Bernoulli 距離 + 救援策略
- **中期（6 個月）**：機器學習模型 + 聚類方法改進 + 效能優化
- **長期（12 個月）**：表觀遺傳亞克隆研究 + 臨床應用開發

## 觀念更新

本次計劃梳理過程中，以下核心觀念得到進一步確認或更新：

| 觀念更新項目 | 更新前 | 更新後 |
|------------|--------|--------|
| **專案核心價值** | 利用甲基化異質性廣泛驗證 SNV | 非遺傳驅動的表觀遺傳亞克隆研究才是長讀取測序的獨特價值 |
| **TP/FP 辨識策略** | 依賴甲基化顯著性指標 | VCF 品質特徵為主 + 甲基化救援為輔的整合策略 |
| **距離度量方法** | NHD 為預設且足夠 | Bernoulli 距離是處理 Nanopore 雜訊數據的必要方法 |
| **統計顯著性解釋** | p-value < 0.05 即為有效訊號 | 需結合效應量（Cramér's V ≥ 0.1）避免微小差異被放大 |
| **F1 優化方向** | 開發複雜甲基化分析策略 | 簡單的 VCF QUAL 過濾即可達成最佳效果（F1: 0.8424） |
| **甲基化信號普遍性** | 體細胞突變應普遍伴隨甲基化改變 | 僅 6.1% TP 有顯著信號，非普遍特徵 |
| **FP 特徵** | 假陽性為隨機定序錯誤 | FP 常來自具真實生物學異質性的複雜區域（如重複序列） |
