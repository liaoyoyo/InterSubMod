# 兩 repo 分支收斂裁決（2026-08-17）

## 為什麼需要這份文件

「所有分支都合併到 main 了嗎」這個問題，如果答案是「除了那幾條以外都合了」，
就必須說清楚**是哪幾條、為什麼**。否則下一個接手的人（或 AI）看到殘留的分支
只有兩個選擇：盲目合併，或盲目忽略。兩者都是錯的。

這份文件把每條分支的裁決連同實測依據記下來，讓「沒合」是一個**有理由的決定**，
而不是一個看起來像遺漏的狀態。

## 3. 怎麼重新驗證這份裁決

```bash
# 每條分支相對 main 的獨有 / 落後 commit 數
for b in $(git branch -r --format='%(refname:short)' | grep -v HEAD); do
  printf "%-56s %s\n" "$b" "$(git rev-list --left-right --count origin/main...$b)"
done

# 是否有共同祖先（空輸出 = 無關歷史，不可合併）
git merge-base origin/main origin/<branch>

# 堆疊包含關係
git merge-base --is-ancestor origin/<inner> origin/<outer> && echo "inner ⊂ outer"
```

LongLineage 專屬：

```bash
bash scripts/ci/check_history_hygiene.sh 5daf50f HEAD
bash scripts/ci/check_public_preview_gate.sh HEAD
ctest --test-dir build            # 期望 49/49
```
