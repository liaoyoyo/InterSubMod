# Provenance 入口

## 目的

`docs/provenance/` 用來保存 **AI 對話 provenance** 與執行過程紀錄。  
這些文件的價值在於：

1. 回看當時做了哪些操作與決策
2. 追溯某個研究結論是怎麼被整理出來的
3. 保留工作過程，而不是只保留最後結論

## 與 `docs/reports/` 的差別

1. `docs/reports/`：
   - 放可引用、可重跑、可驗證的正式報告
2. `docs/provenance/ai_sessions/`：
   - 放 AI 對話執行報告、工作 provenance、過程性整理

簡單說：

- `reports` 是 canonical 結論入口
- `provenance` 是工作過程入口

## 路徑規則

1. AI 對話 provenance：
   - `docs/provenance/ai_sessions/YYYY/MM/`
