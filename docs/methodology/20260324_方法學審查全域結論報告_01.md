## 三、Paired Track 核心機制確認

### VerificationClass 框架整體評估

```
Strong   ← 最可靠（Precision 81~100%），但包含 germline ASM FP（HCC1395）
Weak     ← 合理（label 顯著但全域弱，Precision 90~99%）
Subclone ← 需分層：
             LOH_Subclone（HCC1395/HCC1937 佔 87~89%）= LOH 驅動，語意明確
             Non-LOH Subclone（COLO829/H1437 佔 80~90%）= unreliable CramersV 噪訊
Noise    ← 含大量 TP（33~67%），這些 TP 信號弱但存在 → 正確捨棄（gate 過嚴限制）
```

### FP 來源機制確認（HCC1395）

```
FP（胚系變異）富集於 germline ASM 區域：
  - FP AlleleDelta 中位數 = 0.155（TP 的 2.5×）
  - FP AlleleSig=True 比率 = 94%（TP = 76.4%）
  - 98.7% FP 靠 unreliable CramersV 通過 gate
→ ISM gate 無法區分「體細胞驅動」vs「胚系 ASM 驅動」的甲基化差異
→ 改善需要 normal sample 甲基化參考，或非甲基化特徵
```

### PERMANOVA 跨樣本 AUROC

| 樣本 | AUROC | 結論 |
|------|-------|------|
| HCC1395 pileup n=99 | 0.531 | 無辨別力 |
| COLO829 pileup n=99 | 0.534 | 無辨別力 |
| HCC1937 pileup n=99 | 0.588 | 略高（高 LOH 樣本） |

**結論：全基因組尺度無一致辨別力，保留為 annotation。**

## 六、當前已確認有效的特徵組合

### Paired Track 下游使用建議

```python
# 1. 有信號標準（取代 Significant=True）
has_signal = vc != 'Noise'

# 2. 高信心有信號（進一步精選）
high_conf = vc in ('Strong', 'Weak')

# 3. 可靠 Subclone
reliable_subclone = (vc == 'Subclone') and (loh_subtype == 'LOH_Subclone')

# 4. 觀察性 annotation（不作 filter）
annotations = {
    'loh_subtype': loh_subtype,          # LOH 分層
    'pairwise_mean_dist': pmd,            # 聚類距離
    'allele_delta': allele_delta,         # 等位基因甲基化差（注意跨樣本不一致）
}
```

### TO Track 下游使用建議

```python
# TO rescue rule（選擇一）
rescue_gq = gq >= 3            # 最高 F1 (+0.0094)
rescue_qs = quality_score >= 50  # 最高 Precision (+0.0086)

# TO rescue QC annotation
low_phase_quality = hp_assign_rate < 0.2   # 46.1% FP rate，標記後需謹慎
cv_high = cramers_v > 0.3                  # 85.4% 精度（非 99.7% paired 精度）
```

## 七、方法學 closeout 後的接手建議

### 7.1 此文件現在的角色

- 本檔是 `paired track + TO track` 的 closeout summary，用來說明哪些假設已驗證、哪些方向已關閉。
- 後續 live 主線請轉讀：`docs/references/20260324_InterSubMod研究方法與相關文獻突破方向全域分析_01.md`，以及更新後的研究藍圖與執行計畫。

### 7.2 可直接沿用的已確認前提

- 高層流程固定為 `caller-first → methylation-support → annotation / QC / artifact triage`
- `VerificationClass` 可保留為 annotation / interpretation frame，但不再當唯一主研究目標
- `VC != Noise` 可作 downstream 的 `has_signal` 標準
- `LOH_Subtype='LOH_Subclone'` 可作 reliable subclone annotation
- `GQ>=3` / `QS>=50` 目前只是在 `HCC1395 5kHz TO pilot` 成立的 support rule，尚未升級成全域 TO 規則

### 7.3 主線切換後的優先順序

1. **Phase 1：方向 E**
   - `ML read classification`
   - 目標：突破 unsupervised clustering 天花板，和現有 `VerificationClass / QualityScore / Pairwise` 做 head-to-head 比較
2. **Phase 2：方向 A+D**
   - `normal methylation reference + CN/Purity-aware modeling`
   - 目標：處理 germline ASM 根因，讓 LOH / purity 不再只是事後解釋變項
3. **Phase 3：方向 B**
   - `gene-level / mechanism-level evidence integration`
   - 目標：把 per-SNV 視窗證據往 biallelic event / second-hit narrative 提升
4. **Phase 4：方向 C**
   - `CpG 功能分層與智慧選點`
   - 目標：把不同 CpG 子集連到 driver / ASM / lineage / structural 不同用途

### 7.4 已關閉或降階的方向

- `H006 window_bp=1000`：已理論 rejected，不再列為近期待測項目
- `AlleleDelta standalone filter`：降為 annotation-only
- `PERMANOVA as filter`：保留 annotation，不再列為主線優化方向
- 以 gate 微調直接解決 germline ASM FP：現階段不可行，需要 `normal methylation reference`
- TO 跨樣本驗證：保留為 validation lane，不再單獨充當主研究主線

### 7.5 殘留 hard cases 的用途

- `paired_persistent_final_fp` 已完成 closeout，不再當獨立規則探索題
- 這批 hard cases 應轉作 `Phase 2 normal baseline / CN-purity-aware` 的 diagnostics input
- `paired_raw_absent` 與 shared hotspot inventory 較適合當 strict blacklist / PON candidate inventory，不適合當 deployable methylation rule
