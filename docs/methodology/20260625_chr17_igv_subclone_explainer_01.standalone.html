②如何偵測 sSNV 並建立關聯

1
取 per-read 等位：pysam 對每個 somatic SNV 位置，逐 read 讀出 base → REF/ALT（MAPQ≥20）。同一條 long read 覆蓋多個 sSNV → 得該 read 的多位點基因型向量。
2
normal 確認 somatic：normal BAM 同位置必須 REF（≤1 ALT 容錯）→ 排除 germline。此處 α/β/γ normal 皆 ~0 ALT。
3
建共現 2×2 表：對每對 sSNV，數覆蓋兩者的 read 的 (REF/ALT)×(REF/ALT) 四格。例 α×β2：

關聯判讀（從 2×2）：互斥(ALT_ALT=0,離對角>0)=兩突變在不同細胞=sibling；嵌套(一方向=0,ALT_ALT>0)=一突變 ⊂ 另一=祖先-後代；共連(兩離對角=0)=同 lineage。🔴 須同 germline HP 才算 subclone（異 HP=等位）；此處 17q LOH → 只剩單一 haplotype → 互斥必為細胞層級。

③如何建立分類（克隆）樹

把 2×2 關係串起來：γ 與 α 互斥 → 兩 sibling 分支；β1/β2 嵌套在 α 內且彼此共連 → α 的後代。得 4 細胞群：ancestral / γ subclone / L1(α) / L2(α+β)。VAF 階層 α 0.82 > β 0.47 > γ 0.18 與拓樸一致（祖先廣、後代次、minor sibling 最小）。

④如何用甲基建立輔助驗證資訊

克隆群一旦由遺傳（sSNV）定義好，甲基就能非循環地 characterize：

甲基輔助驗證的兩個用途：
1. 佐證分群：每個 sSNV 的 REF/ALT 分群若被甲基距離聚類支持（silhouette），加強信心——此處 γ silhouette 0.504 最強、α 0.372，全 4 sSNV corroborated。
2. 刻畫 lineage：祖先 L1 vs 後代 L2 有 16 個 CpG 甲基顯著不同；per-CpG 可歸因（23 CpG→α、6→L1-L2 轉變）。IGV 圖上每條 read 的甲基細條即此資訊。
🔴 誠實邊界：甲基不能單獨定 subclone（genotype-同質群內甲基切群=double-dip 循環）；ISM 無監督甲基 clustering 在此只切得出「有無 somatic」，切不出 L1↔L2。甲基是輔助/characterize，遺傳 sSNV 連鎖才是非循環錨。

CpG 對齊軸：哪些甲基位點佐證哪個 sSNV 的 REF/ALT 分群

IGV 圖頂的 CpG 對齊軸 track（基因track 與 read pileup 之間）：每個 CpG 標其甲基（β）最對齊的 sSNV REF/ALT 軸 = best_axis（FDR-顯著、最大 |Δβ|）。色：α 軸 (23)β1 軸 (2)β2 軸 (2)L1→L2 軸 (6)。
共 33/67 個 CpG 有顯著對齊軸 → 即「能以某個 sSNV 的 REF/ALT 佐證聚類結構」的甲基位點；其餘灰點 = 無顯著對齊（不偏向任何 sSNV 軸）。α 軸吸走最多（23 個）＝祖先 somatic 的 cis-ASM 訊號最強；6 個對齊 L1→L2 lineage＝後代 subclone 特有甲基。

⑤基因資訊 + 癌症影響 + subclone 意義

基因 = SKAP1（Src kinase-associated phosphoprotein 1，ENSG00000141293，17q21.32，負股）。4 個 sSNV 全在內含子（唯一 26bp 外顯子 48363789-814 無命中）→ passenger 突變（lineage tracing 標準標記，非功能）。
癌症影響（SKAP1 基因層）：文獻報 oncogene-like / 預後不良（胃癌、大腸癌、乳癌），機制 JAK1/PI3K/AKT；但非 TNBC/HCC1395-specific、非 census driver。🔴 SKAP1 DNA 甲基化 × 癌症 = 文獻空白（無人研究）。內含子 passenger 突變 ≠ SKAP1 促癌功能，兩條獨立軸不可相乘。
subclone 意義與應用：HCC1395 有 10 subclone 分支演化（Fang2021），S1=MRCA 帶 clonal driver（TP53/PIK3CA/17q NLOH）。此位點在 17q clonal LOH 之上——LOH 是主幹、α/β/γ somatic 定義其上的局部 subclonal 分支。重要性：示範「somatic haplotagging（sSNV 連鎖）重建局部克隆樹 + methylation profiles characterize」——即論文標題。應用：long-read 直接讀出 read 級克隆結構（短讀共識可能漏低-CCF subclone，如 γ）；但⭐3 單樣本只能 characterize，confirmation 需 single-cell/multi-region。
