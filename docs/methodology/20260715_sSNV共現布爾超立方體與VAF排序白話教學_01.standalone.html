01 · MAP

先看全貌：read 是約束，樹是解答集合

這個方法不是先猜一棵樹，再把 reads 塞進去；而是先把每條 read 翻成可觀察的突變狀態約束，接著列舉所有滿足約束、方向合法且額外節點最少的候選樹。

核心判讀

共現回答「同一分子上看到了什麼」；尚未自動回答「同一細胞族群是誰」。

read-level joint state 比單點 VAF 多保留了突變交集資訊；但 molecule、chromosome copy、cell 與 clone 是四個不同層級。HP、CNA／LOH 與取樣偏差決定能否往細胞層解釋。

  1. 1
    建立 region相鄰 sSNV gap ≤ 50 kb；region 總 span 不另設上限。若超過 MAX_SNV=8，保留最密集的連續 8 個位點。
  2. 2
    read × sSNV 編碼每格標成 R、A 或 X；X 是沒有可用判定，不是 R。
  3. 3
    依 HP family 分開HP1 與 HP2 各自求解；H3／H4／none 是輔助層，不跨 HP 硬接成同一細胞。
  4. 4
    形成 terminal constraints完整 pattern 是一個精確節點；partial pattern 是一群可能節點。pattern-level 支持需達 MINREAD=3。
  5. 5
    在布爾超立方體列舉從全 R root 出發，每條有向邊只容許一個 bit 由 0 變 1，搜尋最少額外節點的所有相容 exact trees。
  6. 6
    保留候選集合輸出 n_trees、hidden／extra nodes、recurrence 狀態與 shape；不是預先強迫每個 region 只剩一棵。
  7. 7
    可選的 VAF ranking只在候選集合內做描述性排序；最新 canonical v5 尚未執行這一步，也沒有因此確認真實拓撲。

02 · OBSERVATION LANGUAGE

R／A／X：先分清楚「看到 REF」與「根本不知道」

假設 region 內有 k 個 sSNV。每條可用 read 會形成長度 k 的 pattern；這是進入超立方體前最重要的語言層。

符號布爾表示可說的事不可誤解成
R0該 read 在此位點有可用 REF 判定沒有這個突變的細胞一定存在
A1該 read 在此位點有可用 ALT 判定這個 ALT 必然只出現一次
X?未覆蓋、低品質或其他不可用狀態R／0
FULL

ARA → 精確節點 101

同一 alignment 對三個位點都有可用判定，因此這條 full-span pattern 只對應超立方體中的一個節點。

PARTIAL

ARX → 節點群 {100, 101}

第三位未知，兩個 completion 都合理。solver 只要求候選樹至少碰到其中一個。

PARTIAL

XAA → 節點群 {011, 111}

第一位未知不能偷偷補成 R；否則會把真正的 partial constraint 錯縮為 011。

Γ(p) = {x∈{0,1}k :x 與 p 的所有非 X 位置相容}
Γ(p) = { x ∈ {0,1}ᵏ : x matches every non-X entry of p }

Full pattern 的 Γ 只有一個元素；含有 m 個 X 的 partial pattern 最多形成 2ᵐ 個 completion。

MINREAD=3 到底是在篩什麼？

它是 pattern-level support gate：同一個 R／A／X pattern 至少要有 3 條 reads 支持，才進入約束集合。它不是每個節點的 cell count，也不是「一條 read 等於一個 clone」。

因此罕見但真實的狀態可能因低於門檻而消失；相反地，達門檻只代表分子證據重複出現，仍需排除 mapping、basecalling、PCR／sampling 與 copy-number 機制。

03 · FORMAL MODEL

把問題翻成：帶根、有向、群組 terminal 的最小樹枚舉

名字很長，但白話只有三件事：從 0…0 出發、每步只新增一個突變、讓每一組 read constraint 至少被一個節點滿足。

X={0,1}k , 0k 為 root , x→y⇔y=x+ej
X = {0,1}ᵏ ; root = 0ᵏ ; legal edge x → y iff y = x + eⱼ

eⱼ 只把第 j 個 bit 從 0 改成 1。任何 1→0、一次改兩個 bit、或同層跳接都不是合法候選邊。

必須滿足

Feasibility

  • 樹包含 root 與所有 full terminals。
  • 每個 partial group Γ(p) 至少與樹交會一次。
  • 每個非 root 節點恰有一個合法 immediate predecessor。
  • 所有選中節點都能從 root 到達。
優先順序

Parsimony

先找 額外／非 full-terminal 節點最少 的 feasible node sets；在第一個可行層級保留所有 exact parent assignments。

所以結果可以同時有多個 node set，也可以同一 node set 對應多棵樹。

圖 1｜read patterns 先定義 constraint；parsimony 再決定搜尋層級；最後完整保留該層所有 exact trees。
N(T|N) = ∏x∈N∖{0k} |PN(x)|
For a fixed feasible node set N: number of trees = ∏ over non-root x of |Pₙ(x)|

Pₙ(x) 是 N 中 x 的合法 immediate predecessors。總候選數還要對所有最小-extra node sets 加總。

實際程式真的在跑通用 Group-Steiner optimizer 嗎？

不是。這裡的問題可用 Group-Steiner 語言描述，但目前實作利用 k≤8 的小狀態空間，直接做 capped exhaustive enumeration：最多 2⁸=256 個布爾狀態。

搜尋 extra node 數 e=0…4；每層組合預算 150,000；遇到第一個 feasible e 就停止往更大 e 搜尋。若超過上限則標為 capped／fallback，而不是把不完整搜尋包裝成完整證明。

3-sSNV：正方形升成 8 節點、12 邊的立方體

06 · PARTIAL OVERLAP

Partial reads 怎麼「串接」：交會約束，不是假造長 read

AAX=11? 與 XAA=?11 各自定義一個 terminal group。它們在 111 交會，但兩條不同 reads 的片段不能被宣稱來自同一分子。

Γ(11?) ={110,111} , Γ(?11) ={011,111} , Γ(11?) ∩Γ(?11) ={111}
Γ(11?)={110,111}; Γ(?11)={011,111}; intersection={111}
圖 5｜七棵候選都同時滿足兩個 partial groups。solver 是在共同候選 node set 中求交會，不是把兩條 reads 接成一條不存在的 111 molecule。
合理的串接

Constraint intersection

所有 partial groups 一起限制同一棵候選樹；某節點可以同時滿足多組，也可以由不同節點各自滿足。

不合理的串接

Read concatenation

read 1 的左半段加 read 2 的右半段，不能宣稱為同一分子上的 full state。真正 exact co-occurrence 仍需要一條 read 完整跨過相應位點。

07 · EDGE CASES

最重要反例：唯一樹也可能必須 recurrence

考慮 full states {001,010,110,101}。這組資料只有一棵最小 exact tree，但 A 必須在 B 分枝與 C 分枝各新增一次。

圖 6｜「唯一」只表示目前形式約束下 exact tree 唯一；不表示 infinite-sites 無 recurrence，也不表示已驗證為生物真樹。
四個不同命題

unique ≠ recurrence-free ≠ all nodes observed ≠ biological truth

這四件事必須分開欄位報告。Model A 的價值正是保留 recurrence-required 解，不用 infinite-sites 假設把與 reads 相容的結構預先排除。

特例 1｜hidden／extra node 不等於 hidden clone

它只表示該節點不是達 MINREAD 的 full observed terminal，卻被模型選來連通 root、或用來滿足 partial group。它可能是未取樣中介狀態，也可能只是 partial completion；不能直接命名為仍存在的 subclone。

特例 2｜root 000 是結構基準，不是已觀察祖先

root 讓所有路徑有共同起點，代表在這 k 個局部 sSNV 上全為 reference。它不保證樣本裡真的有一群 000 細胞，也不代表正常細胞或腫瘤 founder 已被 read 直接看到。

特例 3｜兩個 cap 不可混為一談

輸入 cap：MAX_SNV=8 決定 region 超過 8 個 sSNV 時，只分析最密集連續 8 個。搜尋 cap：extra nodes 僅搜 e=0…4、每層預算 150,000。另有 display cap 32 只限制畫面列出幾棵，不應改變分析集合。

特例 4｜CNA／LOH 不只扭曲 VAF，也會改變 read-state 的細胞解釋

allele-specific amplification 可讓同一個 cell 的 HP1-derived copy A=10、copy B=11；同 HP 看到 10 與 11 因而不必然是兩群細胞。deletion／LOH 也可能移除既有突變，違反模型的 0→1 單調方向。

目前 L2 CN 只在 L1 建樹後，以 region midpoint 的 segment annotation 協助標記 recurrence／multiplicity；不回頭重建 L1 topology，也不等於已知 allele-specific 1+1。要稱為 cellular ancestry，仍需 allele-specific copy number、mutation multiplicity、purity 與 subclonal CNA 模型。

08 · HP-ORDERED FOREST

同一 region 的 HP1 與 HP2：兩棵分開的樹，不是一棵跨 HP 細胞樹

Primary analysis 先把可追溯到 parental homolog 1 與 2 的 reads 分家，再對每個 region × mutation-bearing HP family 獨立求解。區域結果是有 family 欄位順序的 forest／Cartesian product；「ordered」不表示 HP1 比 HP2 更早。

圖 7｜HP 是 homologous haplotype background。兩側一起出現在同一 region，仍沒有資訊知道 HP1 state 與哪個 HP2 state 位於同一顆細胞。
Cregion = ∏h∈Hprimary ntrees,h
C_region = ∏ over primary HP families h of n_trees,h

這是候選 forest 組合數，不是 region 內 clone 數。若 HP1 有 2 棵、HP2 有 3 棵，區域有 2×3=6 種 ordered forest combinations。

同一 HP label 跨 phase sets 不自動保證整段 biological phase continuity。最新 canonical 中 PS 先作 QC，不拿來切 tree；因此 mixed-PS region 的局部候選仍可報，但若要把方向升級為跨 block 的生物相位主張，需另做 phase-continuity gate 或正交 phasing 驗證。

為何 chr1–22

核心模型以兩條 homologous copies 與固定 diploid 背景作主要語境。chrX／Y 受 biological sex、ploidy、PAR 與 X-inactivation／mapping 特性影響，需另立規則。

不是丟掉 X／Y

sex chromosomes 保留在 ledger

它們目前是 out-of-scope census，而非「沒有生物意義」。要納入正式樹，應先按 sex、PAR/non-PAR、allele-specific CN 與 phase policy 分層後再跑。

Clone boundary

同 HP 內有多個 read states，只能提高「多個分子狀態／lineage-compatible states」的證據。

它比只看 marginal VAF 更接近物理 linkage；但 allele-specific duplication 可讓一個 cell 的兩個 HP1-derived copies 分別是 10 與 11。沒有 CN/multiplicity model 時，仍不能把每個 node 一對一翻譯為 extant clone。

09 · OPTIONAL HEURISTIC

VAF 能做什麼：在已存在的候選樹內排序

直覺是祖先突變應出現在至少不低於後代的分子比例，因此沿每條 edge 比較 ancestor-site read-AF 與新取得突變的 read-AF。這是方向性 heuristic，不是 posterior。

歷史分析限定

最新 canonical v5 尚未執行 VAF candidate ranking。

下列公式忠實說明 2026-07-11／12 historical layered-v2 派生分析的 same-HP read-AF ranking。不可把該比例移植為 canonical v5 的正式結果，也不可稱為已確認最可能真樹。

fj = nALT,j nREF,j+nALT,j
fⱼ = ALTⱼ / (REFⱼ + ALTⱼ), computed within the same HP family; X/unusable calls are excluded

不同 site 的分母可能不同；它是 callable molecules 的 marginal fraction，不是 exact multi-locus state fraction，更不是 cancer cell fraction。

S(T) = ∑p→c∈E(T) ∑a∈A(p) (fa−fj)
For edge p→c that acquires mutation j: add fₐ−fⱼ for every mutation a already present in parent p

root edge 沒有 ancestor mutations，因此貢獻 0。正式 top set 為 exact Fraction score 的 argmax；完全同分的候選全部保留。

圖 8｜若 fA=fB，兩棵 exact tie；若 CN amplification 使後發 B 的 molecule fraction 反而較高，ranking 甚至可能反向。
S(x→y→z) =(fx−fy) +(fx−fz) +(fy−fz) =2(fx−fz)
For a 3-event chain, the middle mutation cancels: S = 2(f_first − f_last)

這揭露 score 的盲點：它可能無法區分中間順序。例 fA=0.70、fB=0.50、fC=0.20 時 A-B-C 得 1.00；但 fA=0.60、fB=fC=0.20 時 A-B-C、A-C-B 與 A→{B,C} fork 都可得 0.80，並列甚至跨 shape。

為什麼 site VAF 不等於 CCF？

E[VAFj] = ρ∑cπcmcj 2(1−ρ)+ρ∑cπcCcj
E[VAFⱼ] = ρ Σc πc mcj / [ 2(1−ρ) + ρ Σc πc Ccj ]

ρ=tumor purity；πc=clone c 的 cell fraction；Ccj=該 clone/site 的 total copy number；mcj=mutation multiplicity。相同 CCF 可因 CN／multiplicity 產生不同 VAF，反之亦然。

風險如何讓排序誤導應對
allele-specific CNA／LOH放大後發 allele、刪掉祖先 allele，使 fancestor≥fdescendant 失效加入 allele-specific CN 與 multiplicity
callable denominator 不同每個 site 由不同 read 集估 AF報有效分母、joint callability、bootstrap
同批 reads 重用read states 建候選、read-AF 再排序，並非獨立驗證稱輔助排序；以 held-out／正交資料驗證
score cancellation／比較數中間節點消去；不同樹累加項數可能不同另報 normalized sensitivity，不取代 official exact argmax
softmax看似機率，但溫度任意且無生成模型校準不可稱 posterior
較完整的 future model

把 joint read states 與 CN-aware marginal counts 放進同一生成式 likelihood。

讓 candidate tree、clone fractions、allele-specific CN、mutation multiplicity、read error 與 missingness 一起產生資料；再以 held-out reads／independent assay 校準。這比把同批 reads 的 marginal AF 當第二張選票更合理。

Sister-only至少一個 branching point，但沒有多層 mutation-state path已證明有多個並存 clones
Direct-only有多層 ancestor–descendant path，但沒有分枝已證明 ancestral 與 derived subclone 都仍存在
Sister＋Direct同時含 branching 與多層 path已確認多 clone 且其中有 subclone
合理用語

說 geometry、candidate state、model-implied order；不要把 shape 名稱變成細胞人口普查。

Direct edge 表示在 monotone Boolean model 中，child state 的 ALT set 比 parent 多一個；未證明兩個 state 都對應可分離、仍存在的 cell populations。

目前實作需要保留在方法章的三個精確附註

TERM
determined 語意仍需一致化。

形式規格表曾限定「唯一、0 hidden」；目前 solver 對 non-capped、n_trees=1 且存在 recurrence-free 解即標 determined，即使 n_hidden>0。現階段最安全寫法是 model-determined，並永遠同報 n_hidden、candidate completeness 與 full/partial provenance。

COUNT
read counts 是 MINREAD gate，不是 tree objective 的支持度加權。

pattern 通過門檻後進 constraint；目前 structural solver 最小化 extra nodes 並枚舉父節點選擇，不會因 100 reads 對 3 reads 就自動偏好某棵樹。

COMMENT
solver 內一段舊註解的「multiple predecessor ⇔ recurrence」不是一般真命題。

實際判定已用 rooted three-gamete compatibility，邏輯正確；上方唯一 recurrence 反例正好證明每個節點即使各只有一個父候選，整棵樹仍可能讓同一 bit 在兩枝重複。

UNIVERSE
從未在任何 full／partial pattern 出現 A 的 bit 會從 active universe 修剪。

這是觀察驅動的 parsimony pruning；X-only 且從未見 ALT 的位置不會被當作可自由新增的 mutation。
