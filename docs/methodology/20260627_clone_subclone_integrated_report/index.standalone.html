🔴 可信度先後（precedence）— 整合鐵則

subclone 判定鏈（順序不可顛倒）：① sSNV read 連鎖（非循環·ground truth）→ ② HP（genetic·sibling vs allelic）→ ③ 甲基（epigenetic·corroborate 非 detect）。衝突時 genetic 勝（甲基異質=同克隆內可塑性）。基礎見 00b_methods_grounding_HP_ISM.md。

L1 — HP tag 貢獻（單變量 ablation）

HP = sibling 判別不可或缺：ablation 無 HP gate 9,187 對全當 sibling；有 HP 只留 3,949 → 移除 5,238 allelic（57.0%）。⚠ nested/co_linked/independent same-HP 85–94%（~1.7–1.87× baseline 0.5，independent 最高）= 區域背景屬性，非克隆連鎖特異證據（克隆連鎖證據 = sSNV 共現結構本身）。HP 的診斷力在 mutual_excl（DEPLETED 0.86×）= sibling vs allelic 鑑別器，非確認 nested/co_linked。

L2 — CCF tier + 克隆階層梯度（單變量）

祖先≥後代 VAF 梯度（決定性邊）= 0.925（CN-clean 0.96） vs null 0.5 → read-樹方向被 VAF 獨立驗證（含 tie 全邊 69.8% 支持 / 違反僅 5.7%）。離散 CCF 峰 ~0.9 clonal / ~0.45 major / ~0.05 rare = 一致 subclone 層級。

L3 — phase-set（單變量 PS）

PS-reliable 區域 = 6,623 / uncertain 449（rate 0.927）。多 PS region = phase-switch 風險，HP 判別不可信（最乾淨 sibling 結論排除之）。Tier-PS（同 PS >50kb）= germline 單倍型 context，非克隆連鎖（同 PS ≠ 同克隆）。

L4 — 甲基 corroboration（單變量；已從 BAM 重抽補完 genome-wide）

既有 ISM 甲基輸出只覆蓋 0.19%（9/4678）→ 已直接從 tumor BAM MM/ML 重抽（驗證 corr=1.000 vs ISM）。genome-wide CN-clean：740 區測試，49（0.066）甲基 corroborate 遺傳群。
🔑 有效性審查（L8）：訊號**存在但 power-gated** — 高功率區（popB_n≥20）corroboration 達 0.549，但僅 51 區達此功率（0.588 的 powered 落在功率飢餓帶）。🔴 cis-control 0/740 不可評估（hp_control_eval=0）→ 撤回「subclone-specific」。CN 分層（使用者校正）：41/49 是 LOH → germline 等位 ASM 結構上不可能 → subclone/somatic-cis 候選；8/49 neutral 才可能 germline cis-ASM。median sig CpG=0、0 新 partition → 甲基 = 有界弱 corroborator 非 detector（見 08_methylation_sufficiency_audit）。

L8 — 甲基輔助有效性審查（per-region 漏斗 + power dose-response + cis-control）

問題：甲基（分群結構/差異對齊位點）能否提升 clone/subclone 準確度？標記/輔助是否足夠有效？方法：把 6.6% 終點數字拆成 740 區 per-region 有效性漏斗。
裁決 = BOUNDED_AUXILIARY（不足以作獨立/主要 subclone 標記）。三條 data-supported：
① 覆蓋瓶頸：740 測試區中 193 區（26%）連可測 CpG 都 0；powered 僅 459。
② 🔑 訊號 power-gated（非無訊號）：corroboration 隨覆蓋陡升 — popB_n 5–7=0.0064 → 12–19=0.1304 → ≥20=0.549；但僅 51 區達 popB_n≥20。
③ 🔴 cis-control 不可評估 + 0 偵測：hp_control_eval=0/740 → 「subclone-specific」撤回；甲基偵測 0 個新 partition；full_tree（subclone 最多）corroboration 反而最低（0.0256）。
誠實回答：甲基不能當偵測器/主要標記（0 新發現）；只在少數高覆蓋區提供未經 cis 校正的弱佐證；要稱「甲基支持 subclone」須先補 matched-normal cis-control。符合 ⭐3 / auxiliary-not-driver。詳見 08_methylation_sufficiency_audit.md。

整合敘述（sSNV + read → clone/subclone）

骨幹：ONT long read 同分子讀多 sSNV → 共現 2×2 → 局部克隆樹（7,143 區域：4,678 有確認結構〔含 677 full_tree〕，其餘 2,465 sparse/single-pair）。
HP 加值：把 read 級互斥轉成細胞層 sibling（移除 57.0% allelic）。
CCF 加值：祖先≥後代 VAF 0.925 獨立驗證樹方向 + 離散 subclone CCF 層級。
PS：reliability 旗標（排除 phase-uncertain 區）；不延伸克隆連鎖。
甲基：已從 BAM 重抽 genome-wide（740 區）→ 僅 0.066 corroborate；power-gated（高功率 0.549）；cis-control 不可評估 → 有界弱 corroborator（非 subclone-specific）。
→ 結論：sSNV+HP+CCF 三軸一致支撐局部克隆階層（單樣本 ⭐3 分子證據）；甲基為**弱**佐證（6.6% 區域有獨立表觀支持）。

🔴 限制（誠實，無可被質疑的未佐證推論）

⭐3 單樣本；regional（≤read-span）非 genome-wide tree；HP 有 ~85-90% phasing 誤差 + problem PS block（已標記排除）；甲基 corroborate 非 detect（既有輸出覆蓋 0.19% → 已重抽 740 區，僅 6.6% 弱 corroborate）；CCF 僅 CN-clean 可估（gain multiplicity 歧義）；52.8% somatic sSNV 在 CN-gain（CN-confounded 53.2%；乾淨集 LOH/neutral 46.8%）；分子證據非 single-cell confirmation。對外勿稱「甲基偵測 subclone / genome-wide tree / 對手缺檢定」。
