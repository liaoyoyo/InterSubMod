🔴 可信度先後（precedence）— 整合鐵則

subclone 判定鏈（順序不可顛倒）：① sSNV read 連鎖（非循環·ground truth）→ ② HP（genetic·sibling vs allelic）→ ③ 甲基（epigenetic·corroborate 非 detect）。衝突時 genetic 勝（甲基異質=同克隆內可塑性）。基礎見 00b_methods_grounding_HP_ISM.md。

L1 — HP tag 貢獻（單變量 ablation）

HP = sibling 判別不可或缺：ablation 無 HP gate 9,187 對全當 sibling；有 HP 只留 3,949 → 移除 5,238 allelic（57.0%）。nested/co_linked same-HP 85–91%（~2× chance 0.5）= 真同單倍型克隆連鎖。

L2 — CCF tier + 克隆階層梯度（單變量）

祖先≥後代 VAF 梯度 = 0.925（CN-clean 0.96） vs null 0.5 → read-樹方向被 VAF 獨立驗證。離散 CCF 峰 ~0.9 clonal / ~0.45 major / ~0.05 rare = 一致 subclone 層級。

L3 — phase-set（單變量 PS）

PS-reliable 區域 = 6,623 / uncertain 449（rate 0.937）。多 PS region = phase-switch 風險，HP 判別不可信（最乾淨 sibling 結論排除之）。Tier-PS（同 PS >50kb）= germline 單倍型 context，非克隆連鎖（同 PS ≠ 同克隆）。

L4 — ISM 甲基 corroboration（單變量；🔴 既有輸出覆蓋不足）

既有 ISM 甲基只覆蓋 9/323 結構區（anchor 窗稀疏）→ genome-wide 甲基 corroboration 需從 BAM 重抽（後補）。小樣本 4/8 corroborate（subclone-specific），但 n 過小不下定論。🔴 甲基 = corroborate 非 detect（genotype-anchored 才非循環）。

整合敘述（sSNV + read → clone/subclone）

骨幹：ONT long read 同分子讀多 sSNV → 共現 2×2 → 局部克隆樹（7,143 區域，full_tree —）。
HP 加值：把 read 級互斥轉成細胞層 sibling（移除 57.0% allelic）。
CCF 加值：祖先≥後代 VAF 0.925 獨立驗證樹方向 + 離散 subclone CCF 層級。
PS：reliability 旗標（排除 phase-uncertain 區）；不延伸克隆連鎖。
甲基：corroborate（既有輸出不足，待重抽）。
→ 結論：sSNV+HP+CCF 三軸一致支撐局部克隆階層（單樣本 ⭐3 分子證據）；甲基為佐證（待補）。

🔴 限制（誠實，無可被質疑的未佐證推論）

⭐3 單樣本；regional（≤read-span）非 genome-wide tree；HP 有 ~85-90% phasing 誤差 + problem PS block（已標記排除）；甲基 corroborate 非 detect + 既有輸出覆蓋 ~3%（需重抽）；CCF 僅 CN-clean 可估（gain multiplicity 歧義）；64% sSNV 在 CN-gain 混淆（乾淨集=LOH/neutral）；分子證據非 single-cell confirmation。對外勿稱「甲基偵測 subclone / genome-wide tree / 對手缺檢定」。
