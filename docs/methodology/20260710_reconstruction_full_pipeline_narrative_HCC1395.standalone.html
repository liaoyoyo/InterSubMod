從 ClairS PASS sSNV 到演化樹確定性：完整漏斗 · 分群 · 拓撲 · read/VAF/CN 輔助（2026-07-10，全機械重算）
§0 一頁流程圖 · §1 資料漏斗 S→retained · §2 區 W 與 k 分佈 · §3 densest-8 為何截斷 · §4 HP 分類 + 分群數 · §5 樹建構與隱藏祖先 · §6 兩軸：拓撲 vs 順序 · §7 樹確定性完整分類 · §8 read/VAF + CN 輔助 · §9 capped 可解性 · §10 誠實邊界
一句話：把 113,997 個 ClairS PASS sSNV 過六層漏斗後，真正進樹的是 25,639 個（建成 7,928 區）； 依 germline haplotype 家族拆成 13,785 個樹單位。用單分子共現在布爾超立方體上重建， 拓撲形狀確定的達 51.1%（7,046）；其餘的多樣性主要在「未觀測中間 clone 的排列」與「頻率對稱」——是單一 bulk 的資訊論極限，非演算法不足。 CN／甲基／read 頻率只作有界輔助，不決定拓撲。單樣本上限 ⭐3（characterize + infer，非 confirm）。

6兩條正交的軸：拓撲形狀 vs 順序 L2

「多候選樹」≠「多拓撲」。一個單位可能有多棵樹、但分支結構（形狀）相同，只是「哪個突變在哪條邊＝順序」未定。所以要分兩軸看：

軸是什麼誰來定受 CN 影響？
① 拓撲形狀分支結構（鏈狀？分叉？星狀？）單分子共現否（solver 不碰 CN，純共現）
② 順序/方向同一形狀內哪個突變先發生read/VAF 頻率是（只在 CN-clean 可信）
📈 5,959 個 ambiguous 中，1,662 是單一形狀（拓撲唯一、只順序未定）、4,297 才是真多形狀。→ 把單形狀併入唯一，拓撲層確定的達 7,046（51.1%），真正「連分支結構都多種」的只有 31.2%。

8read/VAF 頻率 + CN：有界輔助層 L2

對「真多拓撲 / 順序未定」用每突變 read 數（→CCF）加權：早發生的突變在更多後代細胞 → 更多 read → 當祖先（pigeonhole）。這是軸②的收斂層，純 read count（非甲基、非循環）。
