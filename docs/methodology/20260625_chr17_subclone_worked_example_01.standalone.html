用一個位點把整套 subclonal reconstruction 的方法、陷阱、洞見串成可重述的故事
①候選②連鎖③矛盾④完整樹⑤甲基⑥教訓

為什麼選這個位點：它把每一環都示範了——甲基如何「提出候選」、為何甲基單獨不能定 subclone、sSNV 連鎖如何「非循環確認」、一個矛盾如何揭露漏掉的 somatic、完整克隆樹如何重建、甲基最終的正確角色。讀懂這一個，就讀懂整個 pipeline。

①起點：甲基 cis-test 篩出的「候選」

34,736 位點 → 甲基結構 1,139 候選 → normal-anchored cis-test 洗掉循環假象 → 9 個「tumor-specific、非循環」候選，chr17:48360161 是其一。此時只知「這裡甲基不是 germline cis、像 tumor 特有」——還不知是不是真 subclone（甲基切群有 double-dip 循環風險，單獨永遠不能回答）。

②第一層遺傳錨：sSNV read-level 連鎖

要非循環確認需遺傳證據：同一條 long read 上多個 somatic SNV 的共現。此窗 filtered-TP 有 3 個：β1(48362515)、α(48365089)、β2(48365161)。逐 read 共現 2×2 顯示：α×β2 的 REF-ALT=0 → β2 嵌套在 α 內（α 祖先、β2 衍生）；β1×β2 完美共連。→ α 較早，其上累積 β 形成後代 subclone（nested 線性演化，有方向）。

③一個矛盾：HP1-1 但三個 sSNV 全 REF

按 α/β 基因型分群後，有一群 read 在我們 3 個 sSNV 全 REF（看似「無 somatic 的祖先」），但其中 5 條被 LongPhase-S 標 HP1-1。

🔑 關鍵推理：HP1-1 定義 = 「hap1 上、被 phase-block 內任一 somatic 標記的 read」。所以「HP1-1 但已知 sSNV 全 REF」⟹ 這條 read 必然帶著一個我們沒看到的 somatic。HP tag 比手上 VCF「知道更多」。

④找出漏掉的 γ → 完整克隆樹

順矛盾追：這 5 條 read 的 phase-set PS=46496608（~1.9Mb），span 48326-48381kb。filtered-TP 內沒有第 4 個，但 longphase 輸入集 + FP 集裡有 γ=48357368(C→T)。逐 read 定型：那 5 條 HP1-1 read 在 γ 是 ALT，γ normal=35/0 REF + tumor VAF 0.18 = ONT 偵測候選（SEQC2 未收 HighConf/superSet＝缺金標準確認）；γ×α 互斥(AA=0) → γ、α 是兩 sibling 分支。

⑤甲基的正確角色：characterize 已驗 lineage（非循環）

lineage 一旦由 sSNV（遺傳）定義好，再看甲基就不循環。實測 L1 祖先 vs L2 後代 16 個 CpG 甲基顯著不同；per-CpG 可歸因：23 個關連 α（祖先 ASM）、6 個關連 L1→L2 轉變。

甲基熱圖（reads 按基因型 lineage 分組）：甲基模式隨遺傳定義的克隆群變化 = characterize。

每差異 CpG 歸因到基因驅動者（α 祖先 / L1→L2 後代 / β）。

🔴 對照——甲基單獨做不到：ISM 無監督甲基 clustering 只切出 1-2(L0/γ 為主) 與 1-1(L1+L2 混)；BERNOULLI 距離 UPGMA 樹也一樣——只切得出「有無 somatic」，切不出 L1↔L2 subclone。→ 甲基提出候選 + 刻畫已驗 lineage，subclone 細分必須靠遺傳錨。

⑥三個方法學教訓

1. 甲基 ≠ subclone caller：genotype-同質群內甲基結構永遠 double-dip；甲基=characterize/corroborate，subclone 非循環確認來自同 germline-HP 上 ≥2 somatic SNV 的 read 共現。
2.「HP-tag 但已知 sSNV 全 REF」= 偵測漏掉 somatic 的訊號；完整重建應用 longphase 輸入集(methyl_PASS) + normal 確認，非只 SEQC2-filtered TP（會移除如 γ 的 clonally-informative 候選——ONT 偵測但 SEQC2 未收）。
3. 兩個尺度：HP tag 在 phase-block(~Mb) 標 lineage（靠 phasing）；read 共現只在 ≤read-長(~10-50kb) 直接連。互補，但跨 phase-block 無法 read 連（reconstruction GAP）。
對論文：這體現「Subclonal reconstruction using somatic haplotagging and methylation profiles」—— somatic haplotagging(sSNV 連鎖+HP tag)=重建骨幹（定 γ/α/L1/L2 克隆群）、methylation profiles=characterize（刻畫表觀，非偵測驅動）。🔴 邊界：⭐3 單樣本、局部克隆階層非 genome-wide tree。
