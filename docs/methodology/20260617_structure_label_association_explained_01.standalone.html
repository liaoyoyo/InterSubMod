① 列聯表/對齊 資料自己分的群是否「對齊」標籤 → 74.23% 有顯著關聯（Fisher）
② Δβ/標籤位移 標籤群的甲基平均是否不同 → 97.1%（venn「label關聯」軸，近飽和）

1① 列聯表（對齊）怎麼算 — 計算方法

把每條 read 的兩個身分擺成一張表：橫列 = 它被無監督分到哪個甲基群（cluster，來自 read×read BERNOULLI 距離 + UPGMA），直行 = 它的已知標籤（HP1/HP2 或 ALT/REF）。再問：這兩者獨立嗎？

# GlobalTest.cpp:58-62 — 填列聯表 row = cluster_id(read) # UPGMA 分群（無監督，只看甲基距離） col = label(read) # HP1/HP2 (get_hp_label) 或 ALT/REF (get_allele_label) table[row][col] += 1 # GlobalTest.cpp:73-132 — 三個量 chi_square = 獨立性檢定（對齊 = 不獨立） cramers_v = χ² 標準化到 [0,1] = 關聯強度 / purity # 但走 Cochran 可靠性 gate fisher_ffh = Fisher-Freeman-Halton 精確 p（小樣本穩健）

CSV 欄位語義（RegionProcessor.cpp:2524-2533 逐行核實）：

  • GlobalP = min(Fisher p 跨 cluster×allele、cluster×HP、cluster×HP-family) → 三種標籤中「最容易對齊」的那個 p（答「有沒有關聯」）
  • CramersV = max(可靠的 Cramér's V 跨三者)，每個 v = cramers_v_reliable ? v : 0 → 最強「可靠」關聯強度（答「多強」，但不可靠時壓 0）

🔴 double-dip 鐵證（資料層直接證明）：cluster-PERMANOVA valid 23,007 個，顯著也是 23,007 個 = 100%。每一個能算的位點 p 都打到最小值 0.001 → 必顯著。因為「群」本來就是從這條距離矩陣切出來「最分離」的 → 拿同一距離回測必然顯著（循環推論）。所以 cluster-PERMANOVA 不能單獨當「有結構」的證據，判別力要靠 a-priori 標籤軸。
