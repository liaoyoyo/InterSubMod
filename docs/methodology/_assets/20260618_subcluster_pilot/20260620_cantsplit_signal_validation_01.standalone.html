① null 對照：PERMANOVA 是 999 次置換檢定 → 切不出·multi 的 p<.05 = 86.6%（隨機 5% 的 17.3×）、p≤.001 = 65.6%（隨機 0.1% 的 656×） → 訊號絕非 chance。
② 效應量：切不出 \|Δβ\| 中位 0.045（3755 個 >0.1）= 真實量值，只比切得出（0.052）略小 → 效應略小=低於離散分群解析度。
④ per-CpG：切不出 Fisher_Frac 0.188（~19% CpG 個別顯著）→ CpG 層真有訊號。

③ 距離分佈：切不出單峰(無 gap) vs 切得出(較分散)

切不出·有訊號 (med 0.236) 與真null (med 0.112) 都偏單峰（reads 距離集中、無乾淨雙峰 gap）→ clustering 無 gap 可切；切得出 (med 0.285) 分佈較右移/分散（含群間距離）。這直接是「為何切不出」的機制：沒有離散 gap。

⑤ 直接看熱圖：甲基有 HP mean-shift、距離無離散塊

切不出·有訊號（按 HP 排序）：左甲基看 HP1 vs HP2 的 mean-shift（對齊側欄 HP 藍/紫）、右距離整片均勻無對角塊 = 有訊號但切不出。真null = 甲基均勻；切得出 = 距離有對角塊。

⑥ 軸分解 + 誠實邊界
