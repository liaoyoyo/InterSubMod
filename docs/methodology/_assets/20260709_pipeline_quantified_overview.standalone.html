樹選擇(Q1)：對 mixed_shape 區用 read 數排形狀 → 全 7 樣本僅 5% 可排，95% 純隱藏祖先(0-read 分不出)。→ read 數不當 tree-selector；正確用途=軸2 clone/subclone 頻率。
