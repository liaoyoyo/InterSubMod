🔭 跨樣本觀察（不同維度整合）
• 維度①群數 c：c=1(單群)為主(36–67%)、c=2 次之、c≥3 稀少(≤6%)→ 拓撲空間淺(全樣本僅 11 種 canonical 樹形)
• 維度②拓撲組成：多數樣本 單群+2平行+2直系 三分;COLO829 單群最高(67%)=結構最簡、HCC1937/H2009 最複雜
• 維度③有效性：incompatible% 差 0.4↔19.1%(COLO829 最乾淨、H2009 19.1% 資料品質最差)
• 維度④read 驗證：🔴 branched%(幾何上界)常 > confirmed%(read 驗證)—偏 branched 前二 COLO829(87.1%)、HCC1954(79.0%),但 COLO829 confirmed 僅 39%(缺口最大=低 coread artifact)、HCC1954=undetermined
• 跨樣本效應：c=2 branched-vs-linear CramérV=0.222(small-med);不報 chi2 p 值(pseudoreplication·真 n=7);6/7 樣本 CN 未控 → 裁決 partly-artifact / L3(統計正確≠生物差異)
📖 欄位意義
• 群數 c=含≥1 ALT 向量的細胞群數(germline 不計);上界 c≤k
• 拓撲組成=canonical 樹形(單群 ■/2平行 ■/2直系 ■);形狀種類=此樣本不同 canonical 樹形數(全 7 樣本合計 11 種、0 未分類)
• incompatible%=四配子/perfect-phylogeny 違反率(🔴 誠實有效性訊號)
• branched%=兩 ALT 向量非嵌套(幾何上界,不需 read) ｜ confirmed%=有 read 驗證結構的比例。缺口=幾何斷言但 read 未驗
