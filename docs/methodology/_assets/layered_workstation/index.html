02 / 證據

read-level sSNV 共現

03 / 限制

不可越過資料識別度

單一 bulk 的 regional candidates 不能單獨證明細胞比例、真實 ancestry 或正交生物學確認；多解與 incomplete 都是應保留的結果。

Evidence stack

L0 → L3 的承重順序

後續 auxiliary layer 不得回頭重寫 read-level observation，也不得偷偷選樹。

L0

HP family partition

HP1/HP2 mutation-bearing units 是 primary；H3、unphased 與 reference-only 都排除於 primary denominator。

L1

Candidate enumeration

以 read-state constraints 枚舉 minimal candidates；capped 代表候選集合未完成。

L2

Copy-number context

只對 recurrence-like outcome 提供 post-tree annotation；不重新定義 observed state。

L3 · NOT EVALUATED

Bounded methyl auxiliary

本 canonical run 未評估；未來僅限 negative screen / residual flag，禁止排序或確認候選。

PS / QC ONLY

Phase-set 只保留作 phase-block 品質脈絡；不是 topology edge，也不是 lineage label。全 cohort 有 5,623 個 multi-PS regions。
