Interpretation boundary

每張圖都應回到「觀察、推論、限制」三層；不能唯一決定不是失敗，而是資料可識別性的結果。

01 · 回答什麼

哪些區域樹被資料允許？

對每個 eligible multilocus region，分 HP family 回答相容最小樹是否唯一、存在多個等價解，或因 dense state space 被 capped。

02 · 證據是什麼

read-level sSNV 共現狀態

L0 HP family 與 L1 單分子共現是樹骨幹；solver 枚舉全部最小解。L2 CN 只在有資料時提供事後裁決，V1–V7 記錄內部一致性。

03 · 不能宣稱什麼

不是已確認的生物 subclone

不能由此單獨宣稱全腫瘤 clone phylogeny、細胞比例或正交確認。L3 methylation 目前 pending，且不參與樹的排序或選擇。

Reading protocol

比較前先鎖定分母與證據層

欄位讀法

  • HP multiplicity = 2：目前 census 記錄兩個 germline family units 的 region 比例；可能包含 root-only control，不等同 both-mutation-bearing。
  • All determined：該 region 的所有 census lineages 都只有一棵最小樹；不表示每個 lineage 都有 mutation edge。
  • Has ambiguous：至少一個 lineage 有多棵等價最小樹；完整保留解集合。
  • Has capped：隱藏祖先空間超過列舉上限；不是唯一樹證據。

不可跨用的分母

Region %、lineage-unit % 與舊 pooled % 不可互換。工作站首頁只呈現 region-level 比例；每個樣本頁再展開 U1–U6 單位與 V1–V7 檢核。
