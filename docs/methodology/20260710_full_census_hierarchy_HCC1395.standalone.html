G能確認樣本「完整」癌症突變樹嗎？

🔴 否——但可推論。 本方法做的是可驗證的「區域突變狀態樹」重建：每區/每家族的局部樹 + 誠實可辨識性分類（determined / ambiguous / capped）。生物 subclone 可如其他工具（PhyloWGS / Canopy / CITUP）一樣「推論」，但單一 bulk 下 43.2% 單位多候選、跨區整棵樹非可辨識（資訊論極限）→ 是推論不是確認。封頂 ⭐3；確認需 single-cell / multi-region 正交真值。
