# BERNOULLI 閾值敏感性分析

**狀態：Rejected (N/A) — CLI 參數為死碼，Step 3 測試假設無效**

---

## 分析目標

原計劃 Step 3：比較 `--methyl-high/low` 三種配置（0.75/0.25 vs 0.80/0.20 vs 0.90/0.10）
對 VerificationClass 分佈、PassedGating 率、AUROC 的影響。

---

## 發現：CLI 參數與實際行為不一致

### 1. `binary_methyl_high/low` 在 Config 中定義但從未被讀取

- **定義位置**：`include/core/Config.hpp` lines 32-33
  ```cpp
  double binary_methyl_high = 0.8;  // 預設值
  double binary_methyl_low = 0.2;   // 預設值
  ```
- **CLI 參數**：`include/utils/ArgParser.hpp` lines 57-60（`--methyl-high`, `--methyl-low`）
- **驗證**：`src/core/Config.cpp` lines 104-127（合法性檢查與 print）
- **使用量**：`grep -rn "config.*binary_methyl" src/` → **0 筆結果**（從未被讀取）

### 2. 實際二值化使用硬編碼閾值

`src/core/RegionProcessor.cpp` 函式 `build_methylation_matrix`（lines 991-997）：

```cpp
if (val >= 0.8) {
    meth_mat.binary_matrix(i, j) = 1;
} else if (val <= 0.2) {
    meth_mat.binary_matrix(i, j) = 0;
} else {
    meth_mat.binary_matrix(i, j) = -1;  // Ambiguous
}
```

**結論**：無論 `--methyl-high/low` 傳入什麼值，二值化始終使用硬編碼 0.8/0.2。

### 3. BERNOULLI 不使用 binary_matrix

`src/core/DistanceMatrix.cpp` lines 341-344：

```cpp
case DistanceMetricType::BERNOULLI: {
    Eigen::VectorXd vec_i = mat.raw_matrix.row(row_i);  // raw，非 binary
    Eigen::VectorXd vec_j = mat.raw_matrix.row(row_j);
    return calculate_bernoulli(vec_i, vec_j, ...);
}
```

BERNOULLI 的 weight function（lines 262-264）：
```cpp
auto weight_func = [](double p) {
    return 2.0 * std::abs(p - 0.5);  // 連續函數，不依賴二值閾值
};
```

| Metric | 使用矩陣 | 受 binary_methyl 閾值影響 |
|--------|----------|--------------------------|
| NHD    | binary_matrix | ✓ |
| Jaccard | binary_matrix | ✓ |
| L1, L2 | raw_matrix | ✗ |
| BERNOULLI | raw_matrix | ✗（使用連續 weight） |

### 4. 預設 metric 是 BERNOULLI

`include/core/Config.hpp` line 39：
```cpp
std::vector<DistanceMetricType> distance_metrics = {DistanceMetricType::BERNOULLI};
```

## Step 3 測試計劃的問題

| 原計劃假設 | 實際情況 |
|-----------|---------|
| 三種 `--methyl-high/low` 配置會產生不同結果 | CLI 參數不影響任何行為（死碼） |
| 預設值為 0.75/0.25 | 實際預設為 0.80/0.20（Config.hpp 確認） |
| BERNOULLI 使用二值化閾值 | BERNOULLI 使用連續 weight = 2\|p-0.5\| |

## 替代分析方向（若需繼續）

若確實需要測試甲基化中間值（0.2-0.8）對結果的影響，有兩種可行方向：

### 方向 A：修改 BERNOULLI weight function
將 weight function 從連續改為 step function（≥threshold → weight=1, else → weight=0）。
需要 C++ 修改，須先通過 cpp-change 協議。

### 方向 B：切換為 NHD metric 並比較二值閾值
在 CLI 中加入 `--distance-metric NHD --methyl-high 0.9 --methyl-low 0.1` 等參數。
但 NHD 的 TP/FP 辨別力可能不如 BERNOULLI（需先測試基線）。

## 結論

**Step 3 BERNOULLI 閾值敏感性分析：Rejected (N/A)**

- `--methyl-high/low` CLI 參數為死碼（Config 值從未被讀取）

- 測試「三種閾值配置」將得到完全相同的結果

3. 移除或標記 `binary_methyl_high/low` 為僅供 NHD/Jaccard 使用的旗標
