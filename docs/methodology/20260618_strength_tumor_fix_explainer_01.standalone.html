一張圖看懂這次在修什麼： strength_tumor 是 5 元件「結構強度分數」(StrengthScore) 的其中一格。它原本問「這位點的 tumor reads 無監督分群有多明顯？」——但那個問法對純噪音也幾乎一定說 yes（double-dip）。改成問「這位點的 tumor reads 依事前標籤（germline vs somatic-carrier）分開後甲基有沒有差？」——這才是真正的 subclone 訊號。

1 · 問題：strength_tumor 吃了會 double-dip 的軸

舊版 strength_tumor = tumor_intrinsic ? …。tumor_intrinsic 是無監督 tumor-only 結構偵測：先用距離矩陣把 reads 分成 2 群，再用同一個距離矩陣測這 2 群是否分離 → 循環推論（double-dip），對隨機噪音也幾乎一定顯著。

strength_tumor > 0 的比例，照位點是「有結構」還是「噪音」分組：

2 · 改動：一行，把 gate 換成 a-priori 軸 C′

- result.strength_tumor = result.tumor_intrinsic ? clamp01(result.tumor_only_silhouette / 0.5) : 0.0; + result.strength_tumor = result.within_hp_subclone_sig ? clamp01(result.within_hp_best_sil / 0.5) : 0.0; // src/core/RegionProcessor.cpp:1257 (commit 44f434b)
新 gate
within_hp_subclone_sig = C′：single germline-HP 內，tumor reads 依 hp_tag 分 germline("1") vs somatic-carrier("1-1") 兩組 → 對距離矩陣跑 PERMANOVA(999-perm)+PERMDISP。
關鍵
標籤是事前 haplotag（不是從距離矩陣分出來的群）→ 結構上無法 double-dip（源碼 :1206-1207 親證）。
強度
within_hp_best_sil（within-HP 最佳分裂的 silhouette）當 0–1 magnitude。
保留
tumor_only 那組 emit 欄留作 raw 診斷觀察，只把它剔出評分。
為什麼用 C′ 而不是「無監督再分群配 null」？
原計畫 C（降 silhouette 閾值 + 打亂甲基值 gap-null）已被 memory 證實對 tumor-only 軸 NEGATIVE——ONT read 內甲基本身相關，隨機 reads 也會產生假結構，permute 破壞相關使 null 太易被打敗。唯一合法路徑＝a-priori 子標籤 PERMANOVA（監督式），即 C′。對齊「結構偵測(silhouette) + a-priori 標記確認(PERMANOVA)」雙軌。

4 · 個案親驗：證明 C′ 抓的是「對的訊號」

數字翻轉只證「方向對」。要證「抓對訊號」，得親看甲基矩陣。挑最會被質疑的案：一個被全域判為 Noise_Uniform、卻拿到 strength_tumor=1.0 的位點——這是 bug 還是 feature？

判讀＝feature 非 bug： 這是「全域均值看不到、但依事前 somatic-carrier 標籤條件後才浮現的 per-CpG 子結構」。C′ 是多變量距離檢定，抓得到這種 pattern；全域均值/無監督抓不到。Noise_Uniform 是「全域軸」的判定，strength_tumor 是「a-priori 條件軸」——兩者本來就該不同，這個差異正是「位點光看 tumor 資訊就有的」候選 within-HP germline/carrier 甲基分離標記（⭐3 mark-for-confirmation，非 multi-subclone 重建）。

去污染檢查（移除的是真噪音嗎？）+ magnitude 健康度

  • 去污染 48 例（Noise + OLD 開火 + NEW 歸零）：0/48 帶任何 a-priori Δβ 標記 → 移除的確實是真噪音。⚠ 此乾淨僅 scope 到 VC=Noise（全 VC 範圍見 §6：1,582 個非-Noise 去污染位點中 502 仍帶標記）。
  • magnitude 非退化：best_sil 分布 最小 0.117 → 中位 0.421 → 最大 0.843；無退化堆積在 0（無一為零），29.9% 飽和到 1.0 → 有梯度非一刀切。
  • 交叉佐證：442 個 C′-sig 位點中 199（45%）同時帶獨立 a-priori Δβ 標記 → C′ 非憑空，與其他軸互相佐證。
  • Noise+sig 很罕見：chr1 僅 4/2,624（0.15%），3/4 是 p<0.01 強顯著（非邊際）。

6 · 誠實 caveat（對論文口徑很重要）

🔴 口徑紅線（對抗驗證強制 · 守 memory 非循環性）

成果寫成「double-dip removed / ~2.4× enriched on legacy VC」，絕不寫「more discriminative」或「0% noise」（後者是循環論證，memory 明禁）。

  • 低 recall，不是靈敏偵測器：C′ 只在 ~17% 真結構位點開火，且 ~40–44% 位點因 germline/carrier 各 <3 reads 而 abstain。所謂富集講的是「噪音 vs 結構開火率的比例」(~2.4×)，不是高 sensitivity 的偵測力。
  • 非完美乾淨：仍在 ~7% 真噪音位點開火（不是零）。
  • 去污染 0/48 只在 VC=Noise 成立：跨全 VC 的去污染中，~502/1,582 非-Noise 位點其實帶標記 → 「去污染不丟訊號」這句話必須加 VC=Noise 限定。
  • 「subclone」是 within-HP germline-tag vs somatic-carrier-tag 甲基分離，不是 multi-subclone 重建；維持 ⭐3 mark-for-confirmation，不升 hard verdict。
  • 單樣本：跨生物樣本（COLO829 / H1437）復現 deferred（原始 BAM/VCF 不可及）。
