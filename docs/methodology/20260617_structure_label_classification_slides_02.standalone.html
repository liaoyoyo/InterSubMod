各位老師好。今天講的是我們分類方法本身——怎麼把「甲基化的聚類結構」和「已知標籤」之間的關係，用乾淨的統計檢定分類成幾種『狀況』。

先講清楚定位：這份報告的重點是「清楚的檢驗與分類」，不是急著下 subclone 的結論。subclone 的判讀是下一步，要建立在這份乾淨分類的基礎上。

方法分三段：① 用甲基無監督 UPGMA 建結構；② 用 PERMANOVA 配 PERMDISP 做統計假設檢定，確認結構是不是真的；③ 看結構跟哪種標籤高關聯，分類成狀況，並分成只用 tumor 跟 tumor+normal 兩層。

誠實前提：這是單一樣本，方法整體封頂 ⭐3（SOUND_WITH_CAVEATS）——範式站得住、但有具體 caveat 要守，我會逐一講。

S1

方法骨架 —— 五步，順序是鐵則

stack 鐵則：existence → k → stability
來源：20260618_distance_matrix_cluster_validation_methods §2 / §0 91.7% Weak/Noise：同 §2

這頁是全貌：方法五步，而且順序是鐵則。

① 建結構：把每個位點裡 reads 兩兩的甲基化距離算出來，用無監督 UPGMA 分群。② 統計驗證：用 PERMANOVA 配 PERMDISP 確認這個群是不是真的、不是雜訊——這是核心，下兩頁細講。③ 標籤關聯：看這個結構跟哪一種已知標籤（haplotype、等位基因）最相關。④ 狀況分類：分成對齊、多結構對一標籤、一結構對多標籤等狀況。⑤ 兩層輸出：只用 tumor 的結果、跟加上 normal 的結果分開列。

為什麼順序是鐵則？因為要先 gate「有沒有結構」，再談分幾群。全基因組大約 91.7% 的 region 其實是 Weak/Noise（多數沒有真結構）。如果不先做存在性檢定，就在這些沒結構的區硬去選 k，你一定能切出「看起來像群」的東西——那是製造假群。這就是為什麼 existence 要排第一。

S2

第①步 建結構：無監督 UPGMA

完全無標籤輸入
  • 怎麼建：read 兩兩算甲基不相似度（BERNOULLI + 信心權重），距離矩陣丟 UPGMA average-linkage 長樹。
  • 無監督：標籤不進來，結構是甲基自己長出來的。
⚠ 切 k 仍有疑慮（已知缺口）：ISM 目前只有存在性檢定，缺 k-selection 與 stability；甲基工具的 k（在 model 空間）不可移植到距離矩陣，須用距離原生法（silhouette / clusterboot）。
💡 結構是甲基自己長出來的（無監督）；但「分幾群、穩不穩」是已知缺口，須補距離原生方法（見附錄選單）。
DistanceMatrix.cpp:240–301 (Bernoulli, weight 2|p−0.5|) · HierarchicalClustering (UPGMA) k 缺口：20260618_distance_matrix_cluster_validation §0/§4

第①步，建結構。每個位點窗口內的 reads，兩兩算「甲基化模式有多不像」——我們用 BERNOULLI 距離 δ=p(1−q)+(1−p)q，再乘信心權重 2|p−0.5|（越確定甲基或未甲基的位點權重越高）。距離矩陣丟進 UPGMA average-linkage 長一棵樹，用 silhouette 切 k。

關鍵：標籤完全沒進來，群是甲基自己長出來的——這是「無監督」的意思。

但這裡要對老師誠實標一個已知缺口：切 k 還有疑慮。ISM 目前只有存在性檢定（PERMANOVA），還缺「決定分幾群（k-selection）」跟「群穩不穩（stability）」這兩塊。而且不能直接借甲基領域工具的 k——那些（像 cvlr 固定 k=2、Epiclomal）都在 model／特徵空間操作，不能移植到我們的 precomputed 距離矩陣。要補的話得用距離原生的方法，例如 silhouette、clusterboot。這在附錄的方法選單裡有列。

S3

第②步 統計驗證：PERMANOVA 配 PERMDISP

核心 · SOUND_WITH_CAVEATS
  • 為何 SOUND：「任意距離 → 幾何分解 → permutation 推論」是數十年成熟框架（Legendre / Anderson 2001）。
  • 非循環：HP 標籤來自 somatic_haplotag（零甲基，源碼證實）→ 「甲基結構 vs 獨立基因標籤」對齊，非自證。
  • PERMANOVA 必配 PERMDISP（Anderson&Walsh 2013：兩者一組），否則「只是較離散」會被誤判成「型態不同」。
🔴 誠實標：PERMDISP（check_dispersion）已實作於 C++，但此次 run 未開（enable_dispersion=false, RegionProcessor:1716）→ 啟用是收尾動作。
💡 PERMANOVA 問「有沒有結構」、PERMDISP 問「是不是只是較散」——兩個一起才算數（此 run PERMDISP 未開）。
StructureTest.cpp: run_permanova (pseudo-F, 99 perm) + check_dispersion (PERMDISP) · RegionProcessor.cpp:1714/1716 SOUND_WITH_CAVEATS：20260618_ism_method_soundness §1–§3

第②步是核心——怎麼確認剛剛切出來的群是真的，不是雜訊。

PERMANOVA（左圖）：問「這些群在距離空間裡是不是真的分離」。做法是把標籤打亂 99 次建一個 null 分布，如果真實的 pseudo-F 落在打亂分布的右尾（比亂排的高很多），p 就小，代表結構真實。公式是組間平方和除以組內平方和的比值。

但有個陷阱（右圖）：PERMANOVA 顯著，可能只是因為某一群「比較離散」，而不是型態真的不同。所以 Anderson 跟 Walsh 2013 明講——PERMANOVA 必須配 PERMDISP，這兩個是一組的。PERMDISP 專門檢查「是不是只是散度差異」。

為什麼這套方法站得住（SOUND）？因為「任意距離→幾何分解→permutation 檢定」是生態學數十年的成熟框架（Legendre、Anderson 2001），不是我們臨時拼的。而且它非循環——我們用來對齊的 HP 標籤來自 longphase 的 somatic_haplotag 路徑，那條路徑完全不用甲基（源碼證實），所以是拿「甲基結構」去比「獨立的基因標籤」，不是自己驗自己。

這裡必須誠實標一個程式現況：PERMDISP 的 check_dispersion 已經寫進 C++ 了，但這一次全基因組的 run 把它關掉了（enable_dispersion=false）。所以嚴格講，這次結果還沒有 PERMDISP 的保護——把它打開、讓 dispersion warning 跟 pseudo-F 一起報出來，是收尾要做的事。我把這點放在這裡，是因為它直接影響結論能說多強。

S4

第③步 標籤關聯：用標籤判讀

結構與哪種原始標籤高關聯？
  • 主：對每個標籤軸（HP、等位基因）各跑一次 label-PERMANOVA，看結構主要沿哪軸分離 → DominantLabel。
  • 輔：cluster × 標籤列聯表的 Cramér's V / Fisher（三軸）量「離散關聯強度」。
  • 兩個度量都在 code，互補：PERMANOVA 是距離空間存在性、V 是離散關聯強度。
💡 先用 PERMANOVA 確認結構真實，再看它沿哪個標籤分——這就是「用結構確認 + 用標籤判讀」。
SignificanceAnalyzer.cpp: label_hp_permanova / label_allele_permanova · GlobalTest.cpp:149–304 (Cramér's V/Fisher 三軸)

第③步——確認結構之後，用標籤來判讀它：這個結構是跟哪一種已知標籤高關聯？這就是「用標籤判讀」與「用結構確認」兩件事的接點。

主要度量（左）：對每一個標籤軸——haplotype、等位基因——各跑一次 PERMANOVA。哪一軸的 pseudo-F 高、p 小，代表結構主要沿那一軸分離，我們記成 DominantLabel（主導軸）。

輔助度量（右）：再用 cluster × 標籤的列聯表算 Cramér's V 跟 Fisher 精確檢定，量「離散層面的關聯強度」，分三個軸（等位基因、HP-family、HP-fine）。V 有一個 Cochran 可靠性 gate，期望次數太小就壓成 0，寧可低估。

這兩個度量都已經在程式裡，是互補的：PERMANOVA 回答「距離空間裡結構存不存在、沿哪軸」，Cramér's V 回答「離散關聯有多強」。我們兩個都報。

S5

第④步 狀況分類：用結構確認

每個位點都落入一種狀況
狀況計數來源：20260617_situation_inventory §0（as-of 2026-06-18 snapshot） 單樣本 HCC1395

第④步——把結構跟標籤的關係分類成「狀況」。這就是「用結構確認」的部分。套到全基因組每個位點，每個位點都會落進一種狀況：

對齊：群乾淨對到標籤，一結構一標籤，22,497 個（74%）。多結構→一標籤：同一個標籤之內，甲基又分出 ≥2 群（你問的「多個小結構對應到一個子標籤」），8,077 個（26%）。一結構→多標籤：群成立但不追隨標籤，一群混多種標籤（含沒有子標籤組合可對應的大結構），510 個（1.7%）。

這裡有一個必須一開始就講清楚的紅線：「有結構」這件事其實很普遍。全基因組大約 91.7% 的 region 被判為 Weak/Noise，反過來說真正有乾淨結構的是少數；而即使有結構，「分出狀況」也不等於「找到 subclone」。狀況分類只是把現象乾淨地整理出來——判讀哪些是真 subclone 是下一步的工作，要再加 cis-control、連鎖、CN 等控制。這個數字標的是 as-of 快照，因為來源文件還在更新。

S6

第⑤步 兩層輸出：tumor-only vs tumor + normal

加 normal 後判別是否改變
  • 為何分兩層：同一套分類，放不同 read 進去結論性質不同，要分開列才不混淆。
  • ① tumor-only：列只用腫瘤 read 就能判別的結果（如 WithinHP 子結構，!is_tumor continue）。
  • ② tumor+normal：加 normal 看判別是否變。實測對齊保持 51.6%、median V 0.665→0.319（read-level 校準 89.7%）→ 約半強度來自 normal。
兩組結果分開列 → 供下一步 subclone 分析或其他目的取用。
PERMANOVA群在距離空間是否真分離（pseudo-F + 排列檢定）＝存在性檢定
Cramér's Vcluster×標籤列聯表的關聯強度（0–1；走 Cochran 可靠性 gate）
Fisher (FFH)列聯表的精確顯著性檢定（小樣本/稀疏格仍穩）
read-set 分流：GlobalTest(paired) vs RegionProcessor !is_tumor(tumor-only) · Level-2：situation_inventory §0/§6.4 (as-of snapshot)

第⑤步——把結果分成兩層輸出。因為同一套分類，放進去的 read 不一樣，結論的性質就不一樣，所以要分開列、不能混。

第一層：只用 tumor 資訊。列出單靠腫瘤 read 就能判別的結果，例如同一個 HP 之內的子結構（程式碼用 !is_tumor continue 只留腫瘤 read）。

第二層：再加上 normal 資訊。基礎聚類跟對齊其實是 tumor+normal 一起算的，我們看「加了 normal 之後，判別有沒有改變」。實測很清楚：我們抽 300 個對齊位點，只留 tumor reads 重算，可測的裡面只有 51.6% 還保持對齊，中位 Cramér's V 從 0.665 掉到 0.319（read-level 重建的對拍準確率 89.7%）——代表對齊強度大約有一半是 normal reads 撐起來的。

把這兩組結果分開列清楚，下一步要做 subclone 分析、或別的目的，就有乾淨的基礎可以接。

有效：PERMANOVA 是甲基領域 best-in-class 的存在性檢定，分類窮舉覆蓋每個位點，並分 tumor-only / tumor+normal 兩層。合理：整個範式建在生態學數十年的成熟框架上——Legendre&Legendre、Anderson 2001 的 PERMANOVA、McArdle&Anderson，加上微生物組 β-diversity 的大量同構先例；設計非循環（HP 標籤來自零甲基的 somatic_haplotag）；read-level 也有 qFDRP、cvlr 先例。可行：PERMANOVA 與 PERMDISP 都已寫進 C++，單細胞領域 PDclust/scMelody/SINCEF 用同一套骨架（我們還多一道 existence-gate），外部 61 篇（59 親讀）、無同-regime 衝突。

但我要誠實把邊界講滿：第一，分類不等於 subclone——有結構這件事很普遍，判讀哪些是真 subclone 是獨立的下一步。第二，PERMDISP 這次 run 還沒開、k 跟 stability 還是缺口。第三，還有一串方法陷阱要守：假分群、非歐距離要用 UPGMA、小樣本 p 有下限、per-CpG Fisher 的 over-dispersion 是 KB 列的必修。

還有一個對外口徑請老師幫忙把關：我們不能說「ISM 是唯一有顯著性檢定的方法」——cvlr、ASMS 都有 randomization 檢定。我們真正的增量是檢定的對象不一樣：我們對 read×read 的距離「結構」做檢定、有 normal-baseline 的 cis-test、目標瞄準 somatic subclone。最後，這套方法定位是 characterization，甲基訊號處在 germline-haplotype 層，當 variant filter 的方向是死的。整體單樣本單管線，封頂 ⭐3。下一步就是開 PERMDISP、補 k/stability、然後才進 subclone 判讀，再跨樣本驗證。
