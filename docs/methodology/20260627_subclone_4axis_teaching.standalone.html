§1 核心觀念：非循環性是「有條件的」

一條 ONT read = 一條 DNA 分子 = 一個細胞的一條單倍型。兩 sSNV 同 read 共現 = 物理 cis 連鎖 = 同 lineage,是直接觀測不需統計指派——這是非循環的根。

L1對 phase-switch 免疫(真強項):相位切換是跨 read 統計拼接的假象,單分子內部不可能切換單倍型。

L1🔴 但最強反駁=比對偽影(paralog/segdup/amplicon mis-map):錯比 read 帶「其實不在此處」的 ALT→分子層級偽造 cis 共現;somatic-confirmed 修不了(錯比 read 在 normal 也一致缺席)、MAPQ 擋不住 segdup、本輪缺 mappability track。

∴ 條件化核心主張(對外一律用此版):在 uniquely-mappable ∩ CN-clean(LOH+neutral) ∩ somatic-confirmed ∩ coread≥6 的位點對下,同 read 共現=cis=同 lineage。整體骨幹 68.9% 落 CN-gain(vs genome-wide 52.8%)→ 含 gain 區的「方向」標 UNDETERMINED,structure fraction 為上界。

對比:甲基分群是循環的(double-dip)——用甲基分群再檢定群間甲基差異,同量算兩次,故甲基只能事後佐證。

§2 骨幹軸深掘（6 小節）

2.1 直接性 vs 短讀 — 為何不需 phasing

短讀要「統計 phasing 架橋」才知道兩變異是否 cis;long-read 直接讀出。骨幹**不依賴**甲基/頻率推估/下游分群 → 非循環。前置 gate(2.1 條件)是把「read=cell」這個載重前提守住的代價。

2.2 2×2 共現 census — read-level four-gamete 檢定

對每對 sSNV,只看同跨兩位點的 read 填 RR/RA/AR/AA。這是 read-level four-gamete / perfect-phylogeny 相容性檢定(infinite-sites 下每位點只突變一次,不該見四種 gamete)。實際 classify() 門檻(已驗碼):

mutual_exclaa<2(容忍1個AA)且 ra+ar≥2兩 ALT 幾不共現=sibling/allelic

2.3 L1→L2→L3 組裝 + 為何 component≠subclone

L1 pairwise 2×2 → L2 multi-locus 基因型向量(局部 population) → L3 整合成區域樹。連通圖散成 6,146 個 component(局部連鎖區域),含環 23 個(0.37%,必丟)。

🔴 component ≠ subclone:① 由可觀測性+距離定義非細胞身份;② 混 same-HP(克隆)與 diff-HP(allelic)須再 HP-gate;③ 真 subclone 突變散全基因組會被切進數千 component;④ Fisher 顯著只證連鎖存在不分 subclone/allelic。 誠實橋接:6,146 components ≠ 7,143 regions(不同 pipeline 階段,環 23≠inconsistent 22)。

2.4 統計 null 與 power-gate — 存在性≠鑑別性

null=Fisher exact(2×2 條件檢定)。Fisher vs free-margin MC 一致 258/264=97.7%(穩健)。power-gate:sparse 類僅 2.2% 顯著≈機率底線(不從噪聲造結構)。

🔴 diff-HP 負對照(物理不可能同克隆)仍 50.3% 顯著 → Fisher 顯著只回答「共現存在嗎」,「是 subclone 還是 allelic」全靠 HP-gate。這是骨幹(存在性)交棒 HP(鑑別性)的分工。

2.5 γ 類 FP-source 與偽影 — TP∪FP union 的誠實框架

骨幹 linked-somatic 按來源:TP 17,611 + FP-source 3,204。依建構原則,build 用 TP∪FP union、somatic 由 normal 定;SEQC2 的 TP/FP 是觀察疊層不是 filter。所以 FP-source 3,204 是「SEQC2 標 FP 但流程 normal 判 somatic-like」的觀察,不可當「漏掉的確證 somatic」(F3 自承 convergence tautological)。

🔴 偽影:1,163 個 linked-somatic 落 80 個 dense-uniform cluster(≥5 in ≤5kb);chr9:41777788-41804669 區 78 sSNV 擠 26.9kb(n_links 逼近上限)=偽影最像處(連鎖越多≠越可信)。→ structure fraction 為單向上界。

🔴 單讀脆弱性 → ε=2% 噪聲底線定案

分類靠零格定拓樸,但一條定序錯誤 read 能把真 co_linked 讀成 nested(假階層)。決定格只有 1 條 read 的比例:nested 50.6% / independent 57.8%。觀察發現這些**不是低覆蓋**(coread 中位 42-64),而是**off-diagonal 佔比落在 ONT 噪聲底線(1/42≈2.4%)**。

定案規則:cell 為真 ⟺ count > coread × 2%(ONT 噪聲底線)。保留最低 1 條(低 coread 單讀仍算),高 coread 單讀(1 ≤ coread×2%,coread≥50)判 noise。
逐筆可驗:data/pairs_eps2_annotated.tsv(每對附 floor_2pct + 強/弱/noise)。例:RA=1/coread=60/floor=1.2 → noise;RA=1/coread=20/floor=0.4 → 保留;RA=18/coread=22 → strong。
