Baseline-discipline 概念詞典 — 逐項對照

2026-06-21 · 19 詞 × 測什麼/對照誰/意義/不能說 · 外部 3-agent 文獻核 verdict · 外部 citation L3（投稿前 /citation-verification）
🧭 一句話（整份的地基）：任何「測量出來的量」（甲基分群 / Δβ / ASM / 對齊 / 結構 / k 群 / co-occurrence）都不是結果，是中間產物。它的意義 = f(量, 你拿它對照的 baseline)。一個詞把 baseline 藏起來 → 就把中間產物誤當答案。
寫任何 claim 必明寫三件：(1) 測什麼 (2) 對照誰(baseline/null/label/control) (3) 因此意義 + 不能說什麼。缺 (2) = 概念模糊。
⚠ 「baseline-dependence」是 sound 原理但非單一可引定理 → 投稿拆引（M3C/Şenbabaoğlu null + control-design）。

B. 字詞關係圖

(a) 升級鏈（必要非充分 — 每步過了才有資格談下一步，不可跳級）

有 reads→ 切得出群→ 有結構（PERMANOVA sig + 非 PERMDISP）→ 對齊獨立 a-priori 標籤（CramérV≥0.7）→ 扣 cis 後仍共分離（normal cis-control）→ [仍只是 subclone 候選 / characterization]→ 需 ground truth（single-cell/multi-region）才 confirm
多數位點停在前段（85% 對齊但 = cis-ASM）。✅ 外部 verdict：R1 CONFIRMED（PERMDISP 作 location≠dispersion 子步）。

(b) 包含 ⊃ / 對比 / 前提 / 因果

類型關係verdict
包含 ⊃reconstruction ⊃ {CCF+phylogeny+CN deconv}（ISM 真子集）· clone ⊃ subclone · ASM ⊃ {germline/cis/somatic} · confirm ⊃ validate✅ CONFIRMED
對比（易混）cis-ASM ↔ lineage · 驗證 ↔ 確認 · same-molecule ↔ same-haplotype · location ↔ dispersion · germline-ASM ↔ somatic-ASM · lineage(descent) ↔ cluster✅ CONFIRMED

因果epiallele/read-內相關 → over-clustering · somatic SNV → cis-ASM · LOH → 既存 ASM unmask(82-91%)✅ CONFIRMED

C. 投稿紅線速查（最易被 reviewer 抓）

#紅線為何
1🔴 「SampleASM」改名「tumor–normal differential methylation (DMR)」tumor-vs-normal 是跨樣本 DMR 不是 allelic ASM = misnomer
2🔴 禁「只有 ISM 有顯著性檢定」cvlr+ASMS 都有 permutation；delta = 檢定對象(距離矩陣結構) + normal-anchor + somatic target
3🔴 甲基共分離 ≠ 刻畫 subclone（TERM6，最大暴露）= cis-ASM（同事件）或 lineage，須 cis-control 分（Shoemaker Cat I/II + Onuchic-Do PMID33077733）；扣 cis 前 = G-B 未定
4🔴 「reconstruction」綁 somatic-haplotagging；甲基永遠用 characterize 動詞reconstruction 是 Tarabichi 定義的 5-step；ISM 做 subset，禁「we reconstruct subclones using methylation」
5🔴 lineage ≠ cluster；CCF ≠ VAF；ONT β ≠ array intensityISM 有 cluster 非 lineage tree；不算 CCF 故禁把 VAF 當 CCF；ONT β=read-fraction(threshold/depth)
6⚠ Methods 必寫 2 載重前提(a) HP 標籤非循環性全靠「phasing 用零甲基」(甲基進 phasing→PERMANOVA 循環)；(b) over-cluster null 須 correlation-preserving
