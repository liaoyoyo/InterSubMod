## Step 2：VerificationClass 決策樹量化分析

**目標**：量化各分支 TP/FP 流量、特徵 AUROC、跨樣本一致性

**狀態**：✅ 完成

**決策樹邏輯**：
```
passed_gate = alt_gate.passed_gate OR hp_gate.passed_gate  ← OR 邏輯（GlobalTest.cpp:127-141）
gate 使用 RAW CramersV（unreliable allowed），CSV 輸出 RELIABLE CramersV

cluster_significant = passed_gate AND (global_alt_p ≤ 0.05 OR global_hp_p ≤ 0.05)
label_significant   = HPMergedSig OR AlleleSig

Strong   = cluster_sig AND label_sig
Subclone = cluster_sig AND NOT label_sig
Weak     = NOT cluster_sig AND label_sig
Noise    = NOT cluster_sig AND NOT label_sig
```

**關鍵發現**：

1. **Noise class 含大量 TP**（33~67%）：ISM 有效但 gate 過嚴，或信號弱
2. **FP PassedGating 率 > TP**（HCC1395/H1437/HCC1954）：候選池偏差，FP 較多位於高甲基化不穩定區域
3. **Reliable CramersV ≈ 0 但 passed_gate=True 的比例極高**（66~91%）：gate 主要靠 unreliable CramersV 觸發

**各特徵 AUROC（HCC1395 pileup 全量）**：

| 特徵 | AUROC | 說明 |
|------|-------|------|
| HeuristicScore | ~0.65 | 最強 |
| GlobalP（倒數） | ~0.60 | 穩定 |
| AlleleDelta | 0.763 | 僅 HCC1395-5kHz 有效 |
| ClusterPermanovaF | 0.531~0.534 | 跨樣本無效 |

**分析腳本**：`scripts/analysis/verify_class_decision_tree_audit.py`

## Subclone Class 合理性（補充分析，2026-03-24）

**目標**：確認 Subclone 分類語意、LOH 驅動比例、是否可更明確定義

**狀態**：✅ 完成

**兩類 Subclone 機制**：

### LOH_Subclone（有生物意義）
- 條件：`LOH_Subtype = 'LOH_Subclone'`，HP_Ratio ≈ 0 或 ≈ 1
- 機制：LOH 區域全部 reads 位於單一 haplotype → HP 分佈極端偏移 → unreliable CramersV 高 → gate passes
- 佔比（HCC1395=89.1%, HCC1937=87.1%）：在高 LOH 樣本中為主流

### Non-LOH Subclone（可能雜訊）
- 條件：`LOH_Subtype = 'None'`，HP_Ratio ≈ 0.5，AlleleDelta ≈ 0
- 機制：unreliable CramersV 因期望次數不足而膨脹 → 假觸發
- 佔比（COLO829=89.9%, H1437=80.4%, HCC1954=84.0%）：在低 LOH 樣本中為主流

**分層方案（不需 C++ 修改）**：

```python
# CSV 中 LOH_Subtype 欄位已存在
df['Subclone_LOH']   = (df['VerificationClass'] == 'Subclone') & (df['LOH_Subtype'] == 'LOH_Subclone')
df['Subclone_Noise'] = (df['VerificationClass'] == 'Subclone') & (df['LOH_Subtype'] == 'None')
```

## 尚未解決的問題與後續行動

### ✅ 問題 1：FP PassedGating 率在部分樣本 > TP（已分析，No Action）

- 影響樣本：HCC1395（50.6% vs 31.7%）；H1437 FP=8 不具統計意義
- **根本原因確認（2026-03-24）**：HCC1395 FP 富集於**胚系 ASM（Allele-Specific Methylation）區域**
  - FP AlleleDelta 中位數 = 0.155（TP = 0.062，差距 2.5×）
  - FP AlleleSig=True 比率 94%（TP = 76.4%）
  - 98.7% FP 靠 unreliable CramersV 通過 gate（TP = 80.5%）
  - FP GlobalP 均值更低（0.0089）→ FP 訊號反而更強
- **結論**：ISM gate 無法區分體細胞驅動 vs 胚系 ASM 驅動的甲基化差異；提高 gate 嚴格度會同等損失 TP
- **No Action** — 需要 normal sample 參考或非甲基化特徵才能改善
- **文件**：`docs/methodology/20260324_FP_PassedGating高於TP機制分析_01.md`

### ✅ 問題 2：Non-LOH Subclone 機制（已確認，No Action）

- COLO829 Non-LOH SC：HP_Ratio 中位數 0.525（平衡），AlleleDelta 中位數 0.0081，GlobalP 中位數 0.0195
- **根本原因**：k=2 聚類在小 region（期望次數不足）找到 strand/length 偽結構 → unreliable CramersV 膨脹 → gate 觸發
- **影響小**：Non-LOH Subclone 佔全 TP 的 0.3~2.3%；`LOH_Subtype` 欄位已可分層
- **No Action** — 下游分析用 `LOH_Subtype='LOH_Subclone'` 篩選即可
