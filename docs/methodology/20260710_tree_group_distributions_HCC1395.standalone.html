🔴 裁決：這 46,137 個「不需（也無法）用共現處理」。被截斷的 sSNV 來自 340 個大跨距區（中位 200 kb、最大 4 Mb），遠超單條 read 長度（~30 kb）→ 沒有任何一條 read 能同時讀到它們 → 物理上無法單分子共現，留著也建不了共現樹。densest-8 保留「跨距最小的 8 個」（read 最可能同時覆蓋者）。要放置這些 sSNV 需頻率法（PhyloWGS/Canopy 那套 VAF 反推），非本方法的共現骨幹範疇——這正是 ⭐3 與「和頻率法共有的限制」。（>8 區另有 pairwise 建樹 fallback〔commit 151a86d〕保留部分兩兩關係。）

🔴 關鍵：歧義幾乎全來自隱藏祖先。determined（唯一樹）多是 0–1 個隱藏（4,047+2,842＝91%）；ambiguous（多候選）多是 2–3 個隱藏（2,470+2,132＝77%）。越多「沒被直接看到的中間 clone」要推斷 → 排列方式越多 → 越歧義。這也解釋 §6 為何 read/VAF 破不了——歧義在未觀測的中間節點上，觀測突變的 read 數給不出那裡的資訊。
