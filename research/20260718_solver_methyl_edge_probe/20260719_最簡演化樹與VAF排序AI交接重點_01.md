## 1. 背景摘要

本方法要解決的是：在同一個區域、同一個 haplotype（HP）內，利用 ONT reads 上多個 somatic SNV（sSNV）的共現狀態，重建與 reads 相容的最簡 mutation-state 結構。它比只看 bulk VAF 多了一層 molecule-level linkage，因此可以先排除不可能的突變組合，再用 VAF/read-AF 協助排序仍然相容的候選。

每個完整 mutation state 是一個二元向量 \(v\in\{0,1\}^m\)。有向布林超立方體的每條邊只允許一個 mutation 從 0 變成 1。Partial read 以 `R/A/X` 表示 reference、alternate、unknown；一條 partial read 對應一個 compatible subcube terminal group，樹只需和每個 group 至少相交一次。

目前 structural solver 固定根 \(0^m\)，先找最少 hidden nodes，再列出所有同樣最低 objective 的 candidate vertex sets。固定 vertex set 後，每個非根節點選一個 Hamming-1 predecessor，即可形成 rooted out-arborescence；在 unit edge cost、單一固定根、所有節點可由根到達時：

\[
|E|=|V|-1.
\]

因此最小化額外節點、總節點及樹邊數在全部可行候選上等價；terminal groups 是否為 subcube 不影響這個樹論證明。

VAF/read-AF 不是 structural hard constraint 的替代品。正確分工是：read/HP constraints 先決定哪些結構可行；最低 objective 決定哪些是同層最簡候選；VAF/read-AF 只在候選全集完成或有安全 exact certificate 時排序。目前 primary BQ-aware likelihood 依賴 candidate vertex set，不依賴同一 vertex set 的 parent-edge assignment，因此同一 \(V\) 只應 fit 一次。

生物上，read 是 molecule-level observation，不是 cell。即使已分 HP，同一 HP 的 allele-specific amplification、subclonal CNA 或 LOH 仍可能使同一細胞產生多種 HP-derived copy states。因此輸出首先是 regional mutation-state graph geometry，不能未經 CN/LOH 與跨區域證據就直接稱為真實 clone/subclone。

## 2. 一句話流程

```text
HP 分組與 read-state
  → 建立 R/A/X subcube groups
  → 硬限制排除不相容結構
  → exact solver 證明最低 hidden-node objective
  → 列舉或壓縮表示全部同層 candidate vertex sets
  → 每個 vertex set 只做一次 VAF/read-AF likelihood
  → CN/LOH/confounding 註記
  → unique first／同拓撲並列／跨拓撲未解／fail-closed
```

## 4. 必須知道的數學邊界

### 4.1 最少節點與最少邊何時等價

需要同時滿足：

1. 單一固定根。
2. 每個 selected 非根節點恰有一個 parent。
3. 每個 selected node 都可由根到達。
4. 輸出是單一 arborescence，不是 forest 或含冗餘邊的一般 DAG。
5. 每條 edge cost相同，通常為 1。

滿足時：

\[
\sum_e x_e=\sum_{v\neq r}y_v=|V|-1.
\]

Subcube group 只改變「哪些 vertex sets 可行」，不改變每棵可行樹的 \(|E|=|V|-1\)。

### 4.2 Directed hypercube 不等於 strict perfect phylogeny

Hypercube edge只禁止單一路徑上的 \(1\rightarrow0\)，但不會自動禁止同一 mutation 在兩個分支分別 \(0\rightarrow1\)。所以：

```text
RR → AR → AA
└──→ RA
```

以及鏡像連法都可以是 recurrence-allowed 的最簡候選。只有額外限制每個 mutation 全樹最多使用一次，或通過 \(h^*+d=m\) 的 perfect-event certificate，才能稱 strict infinite-sites/perfect layer。

### 4.3 Objective、family 與 ranking 是三種不同的完成

```text
objective_certified
  ≠ candidate_family_complete
  ≠ ranking_complete
```

這是本輪最重要的交接防誤解規則。

### 4.4 必須分開的兩種 abundance endpoint

1. **歷史 scalar AF monotonic heuristic**  
   以「祖先mutation molecule fraction不低於後代」作方向性懲罰：
   \[
   AF_{\mathrm{ancestor}}\ge AF_{\mathrm{descendant}}.
   \]
   這是容易解釋的祖先方向排序，但不是本輪compressed probe驗證的current
   primary endpoint。
2. **Current primary BQ-aware read-pattern mixture likelihood**  
   使用每個read pattern、base quality與candidate vertex-set profiles做mixture
   fit。評分單位是vertex set；同一\(V\)的不同parent edges通常得到相同分數，
   所以它不能單獨選出同一vertex set內的父邊方向。

後續AI不得把兩者合併成同一個「VAF likelihood」。若要改ranking endpoint，
必須另立spec、oracle與receipt。

## 8. 生物解釋邊界

### 可以說

- Read linkage與HP分組比只用bulk VAF提供更直接的molecule-level共現證據。
- 結構可用來描述哪些mutation states能共同解釋reads，以及哪些ancestor/branch方向較相容。
- VAF/read-AF可在結構可行集合內檢查「祖先molecule fraction通常不低於後代」。

### 不能直接說

- 一條read就是一個cell或clone。
- 同一HP上看到`10`與`11`就一定是兩群細胞。
- Sister/direct geometry已證實多clone/subclone。
- 同時看到HP1/HP2已排除所有CNA/LOH。

關鍵反例：

```text
同一個 cell
HP1-derived copy A = 10
HP1-derived copy B = 11
```

Allele-specific amplification即可產生上述狀況。Subclonal LOH、deletion、mapping bias與phasing error也會使molecule fraction不等於cell fraction。
