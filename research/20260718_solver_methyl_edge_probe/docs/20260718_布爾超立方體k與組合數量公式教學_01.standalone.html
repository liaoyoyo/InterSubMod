Boolean lattice field guide

k 個 sSNV 的組合宇宙

從 2k 個 mutation states，走到 symbolic subcube、hidden-state enumeration 與 parent assignments。 公式、實作限制與 k = 1–12 即時計算放在同一張教學地圖。

Current M2 讀圖規則

R=0、A=1、X=?。 O/D/S/L、明示 X 與未覆蓋位置會轉成 X；exact gate 使用 observed-ALT effective k≤12。

01 · Formula map

先記住這六式

前四式描述超立方體本身；後兩式直接對應目前 solver 的候選數量與主要計算瓶頸。

所有狀態節點 |V|=2k

每個 sSNV 只有 R/A 兩態，k 個位置形成長度 k 的二元字串。

第 r 層節點 |Vr|= (k!r!(k−r)!)

第 r 層代表恰有 r 個 ALT mutations；整列就是 Pascal triangle。

所有合法 unit-flip edges |E|=k·2k−1

每個維度有 2k−1 條由 0 指向 1 的邊，共 k 個維度。

固定 N 的 parent trees T(N) = ∏x∈N∖{0} d−N(x)

每個非根節點從 N 內合法前驅選一個 parent；各節點選擇數相乘。

選 h 個 hidden nodes (P!h!(P−h)!)

若 extra pool 有 P 個候選，測試恰好 h 個 hidden nodes 就有 C(P,h) 種。

一筆 partial pattern 的 completions |C(p)|=2x

一筆 read 有 x 個 X，就形成含 2x 個 compatible states 的 subcube group。

03 · Nodes & levels

節點不是 clone，是 mutation state

每個節點是一個區域內 k 個 sSNV 的 R/A 組合。層級由 A 的個數決定，方向永遠由少 mutation 指向多 mutation。

總和檢查： C(3,0)+C(3,1)+C(3,2)+C(3,3)=1+3+3+1=8=23。
如果只問「所有節點子集合」，數量是多少？

從 2k 個節點任選一部分，理論子集合數為：

2(2k)

若 ROOT 必須存在，剩下 2k−1 個節點可自由選：

2(2k−1)

k=8 時即為 2255，約 5.79×1076。 但多數子集合不滿足 read coverage、root-connectivity 或最小 hidden-node 條件。

04 · Edges & parents

合法父節點都只差一個 A

若 child 含 r 個 ALT，完整 lattice 中理論上有 r 個父節點；在選定集合 N 中，只保留真正存在於 N 的前驅。

合法 parent set PredN(x) = {x∖{j} ∈ N : j∈x}

移除 child 的任一 ALT bit，且所得狀態必須已選入 N。

實際 parent choices d−N(x) = |PredN(x)|

d−=1 表示 edge structurally determined；大於 1 則必須保留多個 parent assignments。

關鍵： 「選突變狀態最接近的 parent」不能消除歧義，因所有合法 parent 本來就與 child 的 Hamming distance = 1。

節點集合相同，邊仍可能不同

對固定 N，每個非根節點獨立選一個合法 parent，因此樹數是每個節點 parent choices 的乘積。

N={00,10,01,11}： d−(10)=1、d−(01)=1、d−(11)=2， 因此 T(N)=1×1×2=2。
完整 Boolean lattice 全部節點都選入時

第 r 層共有 C(k,r) 個節點，每個節點有 r 個父節點，因此：

Tfull(k) = ∏r=1…k rC(k,r)

k=8 時約 7.70×10145 種 parent trees。 這不是實際資料的候選數，而是完整 lattice 的理論規模。

所有 edge subsets 為何不是有效的 tree 計數？

完整 lattice 有 k2k−1 條邊，所以任意 edge subset 有 2k2k−1 種。但絕大多數不是 rooted tree： 可能斷裂、讓 child 有多個 parents，或包含無用途 edges。

目前程式直接用 ∏d−N(x) 計數合法 parent assignments， 避免枚舉所有 edge subsets。

07 · Actual subcube contract

X 不是補值，而是一個待命中的狀態集合

實際程式先把一條 molecule 投影成精確的 R/A/X 字串；R/A 是固定觀察， 其他不能安全判成 R 或 A 的狀況全部保留為未知。solver 不替 X 猜一個答案。

Fixed R／A：固定 allele call

保留該位點的 Phred BQ；在結構限制中固定為 0 或 1，在 likelihood 中使用 match／flip probability。

Marginalized O／D／S／L／X／未覆蓋 → X

other base、deletion、refskip、低 BQ、明示未知與 component 內未覆蓋，都不能偷當 REF；它們在 likelihood 中作 missing marginalization。

對 pattern p，令 fp 是 R/A 固定位置、 ap 是其中 A 的位置、xp 是 X； M 是 structural observed-ALT active mask：

GM(p) = {v ⊆ M : ((v ⊕ ap) ∧ fp ∧ M) = 0} |GM(p)| = 2popcount(xp ∧ M) N ∩ GM(p) ≠ ∅  ⇔  Σv∈GM(p) zv ≥ 1

也就是：候選 vertex set N 至少包含一個與這筆 partial pattern 相容的完整 state。

AXR：conceptual full cube 
AXR
├─ ARR
└─ AAR

第 1 位 A、第 2 位未知、第 3 位 R。若第 2 位屬於 active mask， 一個 X 對應 2 個 compatible states。

AXR：observed-ALT effective cube 
M 包含第 1 位
M 不含第 2、3 位

AXR → ARR only

若 structural patterns 從未在第 2 位明示 A，該維度不進 active universe； effective free bits 由 1 降為 0，completions 由 2 降為 1。

結構門檻與 scoring 門檻不是同一件事

程式先把完全相同的 R/A/X pattern 聚合計數。Current M2 primary structural_exact_pattern_minread=3：同一 exact pattern 至少 3 molecules 才形成 full／subcube 硬限制；敏感度 grid 是 1、2、3、5。

低於 3 的 informative molecules 沒有被丟掉，仍全部進 BQ-aware likelihood； all-X pattern 因對所有候選機率都相同，只保留在 funnel 守恆、不參與排名。

為什麼 symbolic subcube 比逐一補 X 小很多？

若有 g 個 partial groups，第 j 群有 uj 個 effective X， 把每群 completion 做 Cartesian product 會產生：

逐補值 worlds = ∏j=1…g 2uj = 2Σuj

Current solver 保留 g 條聯合 group-hit rows；縮減前 row nonzeros 約為：

rows = g，group-row NNZ = Σj=1…g 2uj,eff

例：10 群、每群 4 個 X，逐補值是 240=1,099,511,627,776 個 joint worlds； current representation 是 10 rows、最多 160 個 group-row coefficients。

但這不代表整個 solver 只有 160 的成本：它仍有 2m 個 active vertex variables， 每條 group row 仍會 materialize 最多 2ueff 個相容 indices。

確認後的精確說法： 我們避免的是「completion-wise tree worlds」與「跨 reads 的 Cartesian product」； 並非完全不展開 subcube。每個 reduced group 的 sparse MILP row 仍列出 active universe 內的 compatible vertex indices。

08 · Current implementation

實際流程：先滿足義務，再找最少 extra states

這是 current M2 source 的真實順序。所謂 hidden node 在 objective 裡其實是「非 ROOT、非完整 read mandatory state 的額外 mutation state」。

隔離 reconstruction unit

HP family × exact known PS × read-linked component × bridge threshold；不同 HP／PS 不混池。

建立 exact R/A/X groups

完全相同 pattern 聚合；count≥3 形成硬限制，全部 informative molecules 留給 likelihood。

壓縮 active bits

只保留 structural patterns 曾明示 A 的 loci，total k 投影成 effective m，variables 由 2k 變 2m。

Exact group reductions

移除 duplicate、已被 mandatory 命中的 group、被更窄 group 支配的 group；singleton 直接 forced。

求 minimum-extra h*

ROOT／full states 固定選入；每個 partial group 被命中，每個非根 selected state 至少有一個 selected predecessor。

列完同分 V，再做 likelihood

固定 h* 加 no-good cuts；只有最後證明無更多解才 complete=true。同一 V 的 parent assignments 不重算 read-AF。

只檢查新增 hidden state 的現有父節點，是否足以維持樹？

對 final selected set 的 current recurrence-allowed monotone model：是，對「root connectivity」足夠。

zv ≤ Σp∈Pred(v) zp  ，  Pred(v)={v 移除任一個 A}

Boolean lattice 的 parent 每次少一個 A，popcount 嚴格下降，不可能成環。 因此只要對每個 selected non-root state 都確認至少一個 selected Hamming-1 predecessor， 沿 parent 反覆回溯必定到 ROOT。最後再替每點選一個 parent，就得到 rooted arborescence。

不需要要求新增點已有 child：leaf 本來就可以沒有 child。 搜尋過程若保證從 ROOT 依 popcount 向外、完整探索所有 frontier choices， 可以要求每個新點立刻有 parent；但 current obligation B&B 會先放入 mandatory full states，因此允許暫時 orphan，再把「必須補一個 predecessor」留成 obligation。

局部條件只保證合法，不保證最少： full states AAR 與 ARA 可共享 parent ARR，所以 h*=1；若貪婪分別選 RAR 與 RRA，得到的 h=2 仍是合法 rooted tree，卻不是 minimum。 因此不能只保留一個「最近 parent」。

可以如何把「只看目前父子義務」變成 exact 加速？

Exploratory exact B&B 不掃所有 C(P,h) 子集合，而維護 (I,E)：已選 vertices I 與已排除 vertices E。 尚未完成的義務是：

Q(I)=未命中的 subcube groups ∪ 尚無 selected parent 的 selected vertices

每次挑 domain 最小的義務，對其中所有可能 vertex 完整分枝； singleton 直接傳播，無 root path 的 branch 剪掉，再以 disjoint packing、coverage 與 connection cost 的最大值 作安全 lower bound。只有「所有分枝都探索或被可證 lower bound 剪除」 才保持 exact。

所以正確版本不是「只找一個局部 parent」；而是 以父子／group obligations 限定下一步可選範圍，仍完整探索必要分枝。

小例實算： k=2 的 AX + XA，兩群各有2個completions。Current exact solver得到 h*=2、V=3：{RR,AR,AA}、{RR,AR,RA}、{RR,RA,AA}。 若只貪婪挑第一個completion，會漏掉另外兩個同分node sets。

09 · Limits & explosion

上限控制資源，不會把未知變成唯一答案

Current M2 的 exact gate 已從歷史 k≤8 擴到 observed-ALT effective m≤12； 但「變數可建」不等於「全部同分候選可列完」。

局部 parent 條件與 strict perfect phylogeny 不可混為一談

Current model 只保證每條 path 單調增加 A；它允許同一 mutation 在不同分枝各取得一次。若要求 classical strict perfect phylogeny， 還需全域 three-gamete 限制：任一 mutation pair 不能同時含 10、01、11。 

current monotone：00 → 10 → 11，且 00 → 01   ✓ local rooted
strict perfect：mutation 2 在 00→01 與 10→11 取得兩次   ✗ global

因此新增 state 時只查現有 parent，對 current rooted-tree contract 足夠， 對 strict perfect-tree contract 不足。Strict pilot 在8個真實 capped units 中沒有證明 h* 下降，兩個全列舉案例15秒後仍 incomplete，不能把 strict constraint 當成已證實的主要加速。

11 · Glossary & boundary

公式正確，不等於生物已證實

component 的總 sSNV 數；current exact gate 另使用 observed-ALT effective m。
m
structural patterns 曾明示 A 的 active loci 數；current M2 exact gate 為 m≤12。
V
候選 mutation-state 節點集合，不是已確認的 cellular clones。

objective 中的 extra state：可為 partial representative 或 root connector；不是 hidden clone count。
