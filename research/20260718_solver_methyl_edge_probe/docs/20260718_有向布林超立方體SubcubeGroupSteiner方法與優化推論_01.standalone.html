GENERAL THEORY

Minimum-Cost Rooted Subcube-Group Steiner Arborescence on a Directed Boolean Hypercube

Minimum-extra-state rooted connected vertex-set selection with subcube-group constraints

中文：具有子立方體群組限制的最少額外狀態根連通節點集合選擇。

03 · Formal definition

先定義完整理論，再標出 current objective

3.1 有向布林超立方體

令 m 為此分析單位內的 sSNV 維度。完整狀態是二元向量：

v = (v1, …, vm) ∈ {0,1}m vj=1 表示此 molecule/haplotype-state 在第 j 個位點帶 ALT；不是直接表示整個 cell clone。

有向邊只允許一個 bit 由 0 變 1：

(u,v) ∈ E ⇔ dH(u,v)=1 ∧ uj≤vj for all j 因此每條路徑的 Hamming weight 嚴格增加；圖是 DAG，根為 r=0m。

3.2 Partial read 誘導 subcube group

一個 pattern pi∈{0,1,?}m 的相容完成集合為：

Gi = { v∈{0,1}m : pij≠? ⇒ vj=pij } 若有 x 個未知位點，完整 cube 中最多有 2x 個 completions。程式用 R/A/X：R=read 在已覆蓋位點觀察到 REF、A=ALT、X=未覆蓋／未知。

R 不等於「整個細胞永遠沒有此 mutation」：它只表示這條 molecule/read 在該已覆蓋位點支持 reference allele。把 read observation 提升成 cell-wide absence 需要額外 copy-state 與細胞模型。

3.3 一般化 arborescence 目標

minimizeT   Σe∈E(T) ce    subject to   r∈V(T),   V(T)∩Gi≠∅ ∀i T 是以 r 為根的 out-arborescence。這是可用於論文「問題類別」的定義。

3.4 現行程式的真正目標

令 M 為固定 mandatory set：root 加上通過結構門檻的 full read states。現行 objective 是：

h(N) = |N \ M|,    h* = minN feasible h(N) 額外狀態可能是 partial-group representative、連通 bridge 或兩者兼具；不應一律叫 hidden clone。

精確修正：不是「所有 full reads 都 mandatory」。只有通過結構 support threshold 的 full patterns 進入 M；較低支持的 reads 仍可進後續 likelihood，而不成為硬式 terminal。

05 · Code reality

目前是「先點、後邊、再排序」的兩階段 exact pipeline

HP × PS read states

full R/A states 與 partial R/A/X groups；相同 patterns 合併並保留 count。

Vertex-set selection

最小化 h(N)=|N\M|；每個 partial group 至少被一點命中。

Exact family

固定 h* 後列出所有最低 vertex sets；不完整即 abstain。

Parent factorization

每個 child 從 selected Hamming-1 predecessors 選一 parent，不展開 Cartesian product。

Read likelihood

每個 distinct vertex set fit 一次；same-N parent edges 保持不可辨識。

原稿敘述判定目前程式的精確說法
solver 直接求最小 arborescence 需修正 先求最低 root-connected vertex sets；parent edges 在後段解析。
Steiner node 是未觀察祖先 clone 過度解讀 是 latent connector mutation state；可作祖先假說，不是已確認細胞群。
列出並逐一評分所有 parent trees 需修正 tree 數以乘積解析計數；likelihood 只對 distinct N fit 一次。
VAF/read-AF 可決定同一 N 的 parent edge 目前不成立 snapshot likelihood 只依 N；same-N edge variants 標為 EDGE_NONIDENTIFIABLE。

現行 vertex-set constraints 的代數形式

令 yv∈{0,1} 表示是否選 v。現行核心約束可寫為：

yr=1;   yv ≤ Σu∈Pred(v) yu   ∀v≠r;   Σv∈Gi yv ≥ 1   ∀i 因每個 predecessor 的 popcount 少 1，連續回溯不可能循環，最後只能到 0m；所以 local predecessor condition 足以推出 root-connectivity。

這與原稿的 edge-variable ILP 是等價問題類別的一種不同 formulation，但不是同一份程式模型。

05B · Exact vertex-set search

高效找點：先證最低成本，再只追尚未滿足的義務

核心不是「把所有節點子集合都試一次」，而是把問題改寫成： 現在還有哪些 read groups 沒被命中？哪些已選節點還缺 parent？ 每次只對最緊的未滿足義務分枝。

最重要的分工：subset-DP 只證明最低額外節點數 h*； obligation B&B 才負責列完所有達到 h* 的 vertex sets。

CURRENT CANONICAL SOURCE

Prepared-base MILP＋no-good cuts

第一次 MILP 求 h*；固定 cardinality 後，每找到一組就追加 no-good cut， 直到下一次求解回傳 infeasible，才證明 family 已列完。

修補後固定矩陣只建一次，但仍約需 F+1 次 MILP calls； F 是最低 vertex sets 數量。

BOUNDED RESEARCH BACKEND

Small-q DP＋bitset obligation B&B

DP 先給 objective certificate；B&B 在一次 traversal 中用 bitsets、 logical propagation、admissible lower bounds 與 memo 列完整 family。

已通過 bounded oracle，但程式仍明示 BOUNDED_RESEARCH_BACKEND_NOT_PRODUCTION，尚未取代 canonical route。

兩條路徑求的是同一 estimand： 在相同 root、mandatory states、partial groups 與 gain-one predecessor 規則下， 最小化 h(N)=|N\M|。優化改變搜尋方式，不改變生物模型。

壓縮維度

0. 建立輸入契約 M={0}∪full states；每個 partial pattern 成為 compatible group Gᵢ。 先固定 estimand；read count 不偷偷改變硬式 feasibility。 root、mandatory、groups、predecessor relation。
1. Active-bit compression 只保留通過結構門檻之 patterns 在 observed-ALT universe 中可為 1 的 m 個 dimensions；低支持 reads 仍可留在後續 likelihood。 在目前模型契約內，其餘 dimensions 固定為 0；投影與回嵌一一對應。 P=2ᵐ states，而非 2ᵏ。
2. Group presolve duplicate、mandatory-hit、singleton forcing、inclusion-minimal antichain。 A⊆B 時命中 A 必然命中 B；singleton 是所有可行解的必選點。 required mask＋較少的 active groups。
3. Downward closure 對每個 seed state 列出全部 submasks，只保留其 union。 monotone root→seed 路徑只能經過 seed 的 submasks；最低解不需要無 terminal descendant 的枝。 n≤P 個 closure vertices、e 條 induced gain-one arcs；非最低但可行的多餘枝可能被移除。
4. Bitset preparation vertex、group、predecessor、children 全轉成 integer masks。 只是相同集合關係的無損編碼；AND／OR／popcount 取代 Python set 掃描。 固定的 PreparedBitsetProblem。
5. Subset-DP dp[A][v] 合併 terminal subsets，並沿 DAG 由 child 向 parent 放鬆。 任何可行樹可拆成「同一分枝點合併＋逐邊連接」；每個 recurrence 也能還原合法結構。 OPTIMAL_VALUE_CERTIFIED，只證 h*。

三位點例子：一個 100 同時解除兩個 parent obligations

假設 full-read mandatory states 是 110 與 101，root 是 000。一開始兩個已選 state 都還沒有 selected predecessor：

I₀={000,110,101};   Q₁=Pred(110)={100,010};   Q₂=Pred(101)={100,001} 100 同時出現在 Q₁ 與 Q₂，因此選一次就能讓 110、101 都接回同一共享 connector。
真正包含 partial-group representative choice 的二位點例子：AX＋XA

以 pattern 顯示順序表示： G₁=AX={AR,AA}、G₂=XA={RA,AA}，root 為 RR。 此時 solver 必須同時決定「每個 group 由哪個完成狀態命中」與「如何接回 root」。

h*=2;   N₁={RR,AR,RA};   N₂={RR,AR,AA};   N₃={RR,RA,AA} 三組都是最低 vertex sets：第一組分別命中兩個 groups；後兩組由 AA 命中兩組，但仍需 AR 或 RA 作為 AA 的 predecessor。

Canonical MILP 與 research DP＋B&B 都回傳相同三組 family。 這才是 terminal-group representative selection；前一個 110／101 例子主要示範共享 parent connector。

CORRECTNESS CHAIN

為何可以確保模型內正確？

  1. 可行性：沒有 obligation 時，每個 group 已命中、每個非根 selected state 已有 selected predecessor。
  2. 根連通：沿 predecessor 每次 popcount 減 1；有限步後只能到唯一 weight-0 state 0ᵐ。
  3. 下界安全：packing、coverage、connection 都不高估仍需新增的成本，而且只取最大值、不相加。
  4. 分枝完備：每個 feasible extension 在 chosen domain 中都有唯一的第一個 selected candidate。
  5. 最優性：DP 證 h*，或由未中止的完整 B&B traversal 證明 best。
  6. 完整 family：只有 traversal 未逾時、未達 cap，且所有 leaves／pruned branches 都有證明時，才設 family_complete=true。
Subset-DP recurrence：如何只證 h*？

令 q 是「required non-root singleton terminals＋剩餘 partial groups」的 terminal-domain 數， dp[A][v] 是從 state v 連到 terminal subset A 的最低額外 node cost，且不重複計算 v 自身。

dp[{i}][v]=0   if v∈Dᵢ
dp[A][v]=min∅≠B⊂A{dp[B][v]+dp[A\B][v]}
dp[A][v]=min{dp[A][v], c(u)+dp[A][u]}   for each v→u 第一式命中 terminal domain；第二式在 v 合併兩個子問題；第三式沿一條 gain-one edge 向 child 延伸並支付 child cost。

超立方體是 DAG；按 Hamming rank 由高到低處理，child 的值會先完成，再回傳 predecessor。 最後 dp[all][0] 就是 h*。DP 不保存所有最佳 vertex sets，因此 objective_certified=true 不等於 family_complete=true。

Obligation B&B：哪些剪枝是安全的？
機制計算安全理由
Infeasible domain 某個未滿足 obligation 在排除點後 domain 為空。 任何 extension 都無法再命中它，整枝必不可行。
Singleton propagation |Q|=1 時強制加入唯一候選。 所有可行 extensions 都必須含它，不是 greedy 猜測。
Dynamic antichain A⊆B 時只保留 A。 命中較強的 A 必然同時命中 B。
Disjoint packing r 個互斥 domains 至少需要 r 個新點。 同一點不可能同時命中兩個互斥集合。
Coverage bound ceil(#obligations / max coverage per vertex)。 即使每次都選覆蓋最多者，也至少需要這麼多點。
Root-connection bound 估計 selected orphan／group candidate 回到 root 的最低新點成本。 取各需求的最大值，不錯誤重複加總共用 connectors。
Potential reachability 只保留在目前 excluded mask 下仍存在 root path 的候選。 找不到任何未排除路徑才刪；「可達」不代表沿路祖先已 selected，後續仍會產生 parent obligations。
Memo 完整 key 是 (selected,excluded)。 相同 key 的剩餘 subproblem 完全相同；只消除重複路徑。
LB(I,X)=cost(I)+max{LBpacking, LBcoverage, LBselected-connect, LBgroup-connect} 只有 LB > best 才剪枝；LB = best 仍必須保留，才能列出其他同分最低 sets。

時間與空間複雜度：快很多，但最壞情況仍是指數

令 k 為 raw positions、m 為 active dimensions、P=2ᵐ、n 為 downward-closure 後 vertices、 e 為 closure 內 gain-one arcs、q 為 terminal domains、 F 為最低 vertex-set family 大小、I=Σ|Dᵢ| 為 terminal-domain incidences。

階段時間複雜度空間複雜度真正的限制
Active universe Θ(P)=Θ(2ᵐ) states；完整 gain-one edges 為 m2ᵐ⁻¹。 Θ(P) 起跳。 m 才是主要 exponent；raw k 很大但 active m 小時仍可能可解。

Parent factorization O(EN) 掃一次 legal parent arcs。 O(EN+|N|)；可串流再降低額外空間。 若逐棵 materialize，數量是 ∏|PredN(v)|，可能極大。

複雜度的重點：DP 把 exponent 放在較小的 q；B&B 希望靠 obligations 讓實際 visited states 遠少於 3ⁿ。但若使用者要求輸出 F 個不同最低 sets，任何 exact 方法至少要付出 Ω(F)，不能靠「更聰明的搜尋」讓答案本身消失。

Exactness 契約：active-bit projection 與 downward closure 是本專案在 monotone gain-only、pure existential group hits、所有 optional nodes 為正成本的條件下推導。 若加入 mutation loss、zero/negative node reward、edge reward 或全域 tree constraints，必須重新證明； small-k oracle 的 0 mismatch 是實作佐證，不取代一般證明。

固定 N 後，為何 parent choices 可以 O(Eₙ) 處理？

對每個非根節點：

PredN(v)={u∈N : dH(u,v)=1, |u|₁=|v|₁−1}
#Trees(N)=∏v∈N\{0}|PredN(v)|

在目前 M0 recurrence-allowed model 中，每個 child 的 parent 可獨立選： 所有 parent arcs 都嚴格降低 rank，所以任何組合都不會成環，且每個 child 恰有一條入邊。 若 edge score 可加總，最佳分數就是每個 child 的最佳 parent score 相加，只需掃每條 legal edge 一次。

例外：strict infinite-sites 會加入「同一 mutation 全樹最多 gain 一次」的跨 child coupling， 此時 parent choices 不再完全獨立，不能直接沿用乘積式作 strict-feasible tree 計數。

06 · Proposition

最少總節點 ⇔ 最少邊：可以證明，但條件要寫完整

PROOF

命題

對任一固定根的有限 out-arborescence T=(V(T),E(T))：

|E(T)| = |V(T)| − 1

根的入度是 0；每個非根節點恰有一個 parent，因此所有入度相加就是 |V(T)|−1，也等於邊數。故兩棵可行 arborescences 的節點數排序與邊數排序完全一致。

套到現行 objective

在同一分析單位中 mandatory set M 固定，且 M⊆N：

|N| = |M| + |N\M| = |M| + h(N)   ⇒   argmin h(N) = argmin |N| = argmin |E(T)| 最後一個等號限 unit edge cost，且 T 是涵蓋 N 的單一 rooted arborescence。
h(N)=|N\M|=|E(T)|+1−|M| 這表示三個目標的 argmin／候選排序相同，不表示三個數值彼此相等；只有 |M|=1 時 h(N)=|E(T)|。

因此答案是「是」：在目前固定根、固定 mandatory set、單一 arborescence、unit edge cost 下，最少額外狀態的解一定也有最少總節點與最少邊。

07 · Evolutionary assumptions

Directed hypercube 只保證不可逆，不自動等於 infinite-sites

M0 · CURRENT BASELINE

Recurrence allowed

每條祖先路徑只做 0→1，不允許 back mutation；不同 branches 可重複取得同一 mutation。

M1 · PROTOTYPE GATE

Strict infinite-sites

post-hoc three-gamete compatibility evaluator 已有，但尚未在 strict constraints 下重新求所有最優解。

M2 · NOT IMPLEMENTED

Loss-supported / Dollo

尚無明確 copy/loss state model；在 CNA/LOH 區域固定回傳 unresolved，不應硬判。

M1 必須 fail closed：只有 allele-specific CN 已知且為 2/1/1、雙 homolog retained， 並排除 clonal/subclonal LOH、deletion、amplification、WGD boundary、mutation loss 與 phasing/mapping QC 問題，才可把 molecule-state topology 標為 strict-perfect-compatible。

partial unknown 是否讓 perfect phylogeny 一定變成 NP-hard？

不一定。Incomplete Directed Perfect Phylogeny 的「可行性＋建一解」已有多項式方法； 但列出或計數全部相容樹仍可能爆炸，計數版可達 #P-complete。 所以 strict gate 可以很快，卻不能推出「全部 ambiguity family 可多項式列完」。

∏ |PredN(v)|

Subset-DP 的 q 與 Mahapatra 文獻的 q 不是同一個量

本專案 DP 的 q 是 reduced terminal domains／obligations 數。 Mahapatra 等人的 penalty q 是經 invariant-character preprocessing 後的 cost(T)−m。兩者不可互換，因此文獻的 Õ(36q) 不能直接替本專案 group 版本背書。

為什麼不能靠設定 max_sets 宣稱「最可能」？

max_sets 是資源上限，不是科學限制。到達上限只能標記 CANDIDATE_SET_INCOMPLETE_MAX_SETS；即使 h* 已由 DP 證明，也不知道未列出的同分 sets 是否會得到更高 likelihood。正確策略是 checkpoint/resume、等價類壓縮，或明確 abstain，不是對 prefix 排名。

10 · Inference boundary

Exact solver 能證明模型內最小；不能把 molecule geometry 變成 cell lineage truth

family_complete=true 時可說
  • 在目前 M0、rooted、gain-one-edge model 下，已找到全部 minimum-extra vertex sets。
  • 每個硬式 partial group 至少被一個相容 selected state 命中。
  • h* 是此數學模型與輸入門檻下的最小額外狀態數。
  • 固定 N 後，可精確計算合法 parent mapping 數。
  • read likelihood 可排序不同 N 對觀察 patterns 的相容程度。
即使 complete 也不能說
  • 每個 selected state 必然是一群真實 cell clone。
  • Sister／Direct geometry 已證明多 clone／subclone。
  • 同一 N 內某條 parent edge 是唯一真祖先。
  • 同 HP 的多個 states 必然來自不同細胞。
  • CNA、LOH、mutation loss、purity 已被 M0 自動處理。

read likelihood 與 molecule fraction 的正確位置

選定 N 後，可對 clone-state mixture weights π 做 pattern likelihood：

ℓ(N) = maxπ∈Δ Σi ci log [ Σv∈N πv P(pi | v) ] ci 是 pattern support count；unknown bits 在 emission/compatibility 中邊際化。相同 group constraint 只留一次，count 不會在結構層重複加權。

由 fitted mixture 可得到第 j 個 mutation 的 molecule fraction：

f̂j = Σv∈N π̂v vj 這是 molecule-state fraction，不等於未校正的 cell fraction；CNA、allelic multiplicity、LOH 與 purity 會破壞直接換算。

目前 edge 不由此 likelihood 決定：若兩棵樹有相同 N，只改 parent mapping， ℓ(N) 完全相同。未來若有獨立且校準的 methylation/longitudinal edge evidence， 可在固定 N 後加入 additive local edge score；但那是第三層 tie-break，不是現行 canonical read-AF 結論。

最重要的生物反例

Allele-specific amplification

一個 cell，多個 HP-derived copies

同一細胞內可同時有 HP1-derived copy 10 與 11；不同 molecule states 不必然是兩群細胞。

LOH / deletion

Mutation 可以「看似消失」

copy-neutral LOH、deletion 或 subclonal loss 會讓 1→0 的觀察出現，違反 M0 的單調假設。

Sampling / error

未觀察 ≠ 不存在

coverage、mapping、basecall、phasing 與 read dependence 都會改變 group evidence；absence 需要統計 negative evidence。

root 的安全解讀：0m 是所選 regional loci 的 model baseline， 不一定是一條真正觀察到的 normal cell，也不必然等於整個腫瘤的真實 MRCA。

11 · Paper-ready wording

可直接使用的安全敘述

中文方法定位

本研究將每個 partial read pattern 表示為有向布林超立方體中的一個相容子立方體群組， 並在固定根 0^m 與通過 support threshold 的 mandatory full states 下， 聯合選擇每個群組的至少一個代表狀態及使所有 selected states 根連通所需的額外狀態。 現行 exact solver 最小化額外 selected mutation states 的數量，而非直接最佳化 parent edges。 對每個最低 vertex set，合法 parent assignments 由 selected Hamming-1 predecessors 解析計數； read-pattern likelihood 僅排序不同 vertex sets，因此相同 vertex set 內的 parent edges 保持不可辨識。

英文問題定義

We define a structured directed Group-Steiner variant, termed the Subcube Group Steiner Arborescence on a Directed Boolean Hypercube (SGSA-DH). Each partial read induces a possibly overlapping terminal subcube, and a feasible solution must select at least one compatible state from every subcube while remaining reachable from the fixed root 0^m. Our current exact implementation optimizes a node-weighted minimum-extra-state formulation; it first enumerates the complete family of optimal rooted-connected vertex sets and then factorizes their legal parent assignments. Read-pattern likelihood ranks distinct vertex sets, not parent-edge variants within the same set.

一行結論

你們不是在固定 terminals 上直接找一棵唯一 Steiner tree；而是在 partial-read subcubes 中選代表狀態，找出所有最低 root-connected state families，再保留 parent-edge ambiguity。

這句同時符合目前 source、exact receipts 與生物 claim ceiling。
