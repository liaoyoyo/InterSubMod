# k 大於 12 與 A–B／B–C 串聯合理性驗證

> **任務類型**：B（comprehensive validation）；HCC1395 為完整 chr1–22 驗證，七 technical datasets 目前僅 4/7 產出 strict summary，跨樣本結論標記 **PARTIAL**。
> **敘述框架**：定義 → 資料證據 → 推論邊界 → 決策。
> **TL;DR**：`k>12` 應保留為一個完整的 source region `W`，並標記為「超出目前 solver 上限」；運算時才切成 `k_B≤12` 的 computational blocks `B`，不可直接稱為高密度區域。A–B 與 B–C 都有直接 read evidence 時，A、B、C 可屬同一 read-linked connected component，但不能因此宣稱同一 read、cell、clone 或 A→B→C 演化順序。現行分區還有 4 個 child blocks 失去內部連通性，正式 tree gate 需補上 connectivity 檢核。

## 1. 直接判定

| 問題 | 判定 | 正確處理 |
|---|---|---|
| `k>12` 要不要切？ | **source region 不切；solver input 要切。** | 保留 `source_component_id` 與完整 W；建立一個或多個 `k_B≤12` 的 B。 |
| `k>12` 是否代表特殊高密度區？ | **不代表。** | 稱為 `large-k` 或 `oversized_for_exact_solver`；若要稱高密度，另算 loci/kb、相鄰位點距離或 graph density。 |
| A–B、B–C 可否串成 A–B–C？ | **可串成同一 analysis component。** | 傳遞的是 connected-component membership，不是 direct molecular co-occurrence。 |
| 可否據此稱三者為同一 clone？ | **不可。** | 需另外納入 bulk mixture、purity、copy number、VAF/CCF、error 與 phylogeny model。 |
| 不同 blocks 的局部樹可否直接拼接？ | **目前不可。** | 必須保留跨 block constraint，並有 shared-separator／bridge likelihood 與 global consistency certificate。 |

若使用者原句中的「A 大於 12」是指 `k>12`，以上判定適用；若 `A` 指 ALT call，`A` 是類別碼而不是可與 12 比較的數值。
口試時建議把 A–B–C 改說「位點 1–2、位點 2–3」，避免位點代號 A 與 ALT call code `A` 混淆。

## 2. 術語與資料粒度

| 符號／術語 | 本研究中的精確定義 | 不代表 |
|---|---|---|
| `R`／`A` | read 在某 sSNV 位點通過品質門檻後的 REF／ALT fixed call | clone 身分 |
| `X` 或 `?` | 該 read 對該位點沒有可用 fixed call | REF |
| direct edge | 同一 exact PS×HP 容器內，至少 3 條 distinct canonical molecules 對兩端都有 fixed `R/A` call | 演化樹 edge |
| source region `W` | threshold-qualified direct-edge graph 的 maximal connected component；`k_W=|W|≥2` | 一條 read、單一細胞或單一 clone |
| block `B` | 為運算上限建立的連續、非重疊 child block；`k_B=|B|≤12` | 新的生物區域 |
| `k_total` | W 或 B 內納入的 sSNV site 數 | read 數、clone 數、空間密度 |
| active `m` | 某些 solver 中至少被一個 pattern 明示為 ALT 的有效 bit 數 | W 的全部 site 數 |

未知狀態應寫成 `X` 或 `?`；目前 extractor 中的 `S` 是 reference skip（CIGAR `N`）原因碼，不宜再拿來表示 unknown。

## 3. `k>12` 為何是雙層政策

```text
完整 source region W（研究與追溯單位，k_W 可大於 12）
├── k_W≤12：形成一個 B
└── k_W>12：依 read constraints 分成多個 k_B≤12 的 B
                 ↓
             只求 local candidate topology
```

### 3.1 為何不是「高密度」

\[
\text{site density}=\frac{k}{(\max(pos)-\min(pos)+1)/1000}\quad\text{loci/kb}
\]

13 個位點散布在 5 kb 與 1 Mb 都是 `k=13`，但密度完全不同。本地 HCC1395 的 90 個 `k_W>12` regions，其 coordinate-envelope density 約介於 **0.0513–3.795 loci/kb**，已直接證明 `k>12` 不是單一密度類型。

### 3.2 HCC1395 實際數據

| 指標 | 結果 |
|---|---:|
| source W | 11,462 |
| `k_W>12` W | 90（0.785%） |
| 最大 `k_W` | 153 |
| bounded B | 11,712 |
| segmentation constraint rows | 57,629 |
| retained／cut／unavoidable rows | 53,918／1,078／2,633 |
| molecule weight retained／cut／unavoidable | 281,685／1,242／2,669 |
| retained molecule weight 比例 | 98.631% |

`12` 是目前工程 cap：binary state vertices 從 `2^12=4,096` 增至 `2^13=8,192`，tree enumeration 的成本還可能更快上升。外部文獻沒有證明 12 是生物 cutoff 或領域最佳值；正式論文應稱「本研究設定的計算上限」，並補 `k=10–14` runtime、RSS、capped rate 與結果敏感度。

## 4. A–B 與 B–C 串聯：成立與不成立的推論

### 4.1 在 source graph 層成立

若：

```text
read set 1：直接支持 A–B，support≥3
read set 2：直接支持 B–C，support≥3
A–C：沒有 direct edge
```

則 A、B、C 仍屬同一 connected component。這符合 graph connectedness，也符合 HapCUT2／LongPhase 以 read overlap 建立 phase block 的基本思想。

若把 pair evidence 寫成 factors，聯合問題為：

\[
L(A,B,C)=f_{AB}(A,B)\,f_{BC}(B,C)
\]

兩個 factors 共享變數 B，因此 A、B、C 應在同一 joint inference problem 中處理；但公式沒有創造不存在的 `f_AC`。

### 4.2 不能跳到 molecule、cell 或 clone

\[
AB\in E \land BC\in E
\Rightarrow A,B,C\text{ 在同一 connected component}
\]

但不推出：

\[
AC\in E,\quad
\text{same molecule},\quad
\text{same cell},\quad
\text{same clone},\quad
A\rightarrow B\rightarrow C
\]

bulk tumor 的反例是 B 為 trunk mutation，A 與 C 分別出現在兩個 sister subclones：

```text
      B
     / \
    A   C
```

此時可同時看到 AB 與 BC read patterns，卻未必存在 ABC clone。因此「最小相容圖／樹」只能稱為目前證據與模型下的 **model-minimal compatible candidate**，不能稱為直接觀察到的 clone truth。

### 4.3 partial patterns 的例子

```text
ARX：A=ALT、B=REF、C=unknown
XRA：A=unknown、B=REF、C=ALT
```

兩者在 B 相容，`ARA` 是一個可能 completion；但兩條 reads 可能來自不同細胞，所以 `ARA` 仍是候選而非觀察事實。

若為：

```text
ARX
XAA
```

兩者在 B 衝突；它們仍可位於同一 read-linked component，但模型至少要以多個 states、error 或其他生物機制解釋，不能強行合成一個 pattern。

## 5. block 層的關鍵限制

### 5.1 同一 block 與跨 block 必須分開

- 若 A、B、C 位於同一個 `k_B≤12` block，且 block 內 threshold-3 induced graph 連通，可以聯合推論 partial states。
- 若 `{A,B}` 與 `{B,C}` 被設計為兩個**重疊** blocks，理論上可用 shared separator B 串接，但必須強制兩邊對 B 的 state 一致，並共同計入 evidence；這是 junction-tree／factor-graph 類型的額外模型。
- 現行 partition 產生的是**非重疊** blocks，每個 site 只屬一個 B。跨 cut 的 constraints 會標成 `cut` 或 `unavoidable`，因此現行 local trees 不具備直接拼接成 global tree 的充分條件。

### 5.2 本地稽核找到的工程 gate

HCC1395 的 11,700 個 `k_B≥2` blocks 中：

| 檢核 | 數量 |
|---|---:|
| induced threshold-3 graph connected | 11,696 |
| induced graph disconnected | **4** |
| `retained_segmentation_constraint_weight=0` | 134 |
| 上述 134 經 authoritative molecule calls 重投影後仍有 MINREAD-supported patterns | 75 |
| 上述 134 重投影後仍 unsupported | 59 |

這表示：

1. `retained segmentation weight=0` **不能單獨當排除條件**，因 adapter 會把 authoritative molecule calls 投影到 block。
2. 4 個 disconnected blocks 全部是 zero-weight，且 0/4 通過 projected-pattern support；它們不應進 tree inference。
3. 現行 adapter 已檢查 `k≥2` 與 `MINREAD-supported pattern`，但尚未檢查 child block 的 induced connectivity。

建議正式 gate：

```text
block_tree_eligible =
    (k_B >= 2)
    AND induced_threshold3_graph_connected
    AND adapter_pattern_supported_at_MINREAD
```

### 5.3 端到端 adapter 尚未達 production PASS

上述 75／59 是以 authoritative `molecule_sparse_calls` 按現行 adapter 規則獨立重投影所得，不能寫成正式 strict-bound adapter artifact 已通過。實際執行又發現三項整合缺口：

1. `hcc1395_partition_v2/` 尚缺 adapter CLI 要求的 root-level `run_receipt.json`。
2. partition receipt 的 membership 大小欄位名稱是 `bytes`，adapter strict-binding check 讀取的是 `size_bytes`；即使 path 與 SHA-256 相同，仍會誤判 mismatch。
3. adapter docstring 寫「only retained constraints are projected」，但實作其實只以 retained constraints 驗證 disposition mass，tree patterns 則由全部 authoritative per-molecule calls 投影後重建。文件與實作語意需統一。

因此目前 verdict 是：

```text
local reprojection semantics：PASS
strict partition → adapter end-to-end production binding：BLOCKED
```

這是 schema／流程整合問題，不是 membership 資料內容不一致；修正後仍須以 formal receipt 重新驗證 75／59 與全部 tree-input groups。

### 5.4 RR-only edge 的定義敏感度

現行 primary edge 的 `support_total=RR+RA+AR+AA`。HCC1395：

| 指標 | 數量 |
|---|---:|
| primary edges | 76,202 |
| RR-only edges | 18,116（23.77%） |
| 移除 RR-only 後會改變 membership／partition 的 W | 2,437／11,462（21.26%） |
| 受影響的 `k>12` W | 28／90（31.11%） |

RR-only 可證明兩位置在同一 molecules 上「共同可判讀」，並提供兩端都為 REF 的負向 state evidence；它不證明 ALT 共現。建議：

- primary graph 可保留 RR-inclusive，名稱必須是 `jointly callable mutation-state graph`；
- 論文同步報 ALT-any 與 ALT-support≥3 sensitivity；
- 只有 AA 是雙 ALT 共現；RA／AR 也不是雙 ALT 共現。

## 6. 與領域方法的對齊

| 方法／文獻 | 可支持本研究的部分 | 不可借用的結論 |
|---|---|---|
| [HapCUT2](https://doi.org/10.1101/gr.213462.116) | read-fragment graph、connected components、missing calls | diploid phase block 不等於 tumor clone |
| [LongPhase](https://doi.org/10.1093/bioinformatics/btac017) | long-read-supported variant graph 與 phase-block 延伸 | 間接連通不等於同一 read／cell／clone |
| [PairClone](https://doi.org/10.1111/rssc.12300) | mutation-pair reads 可在 Bayesian mixture model 中估 subclones | pair connectivity 本身不能產生 clone |
| [TreeClone](https://doi.org/10.1214/18-AOAS1224) | mutation pairs 結合 mixture 與 tree prior 推論 | 不可省略 purity、error、genotype/tree model |
| [Pradhan & El-Kebir](https://doi.org/10.1186/s13015-019-0156-x) | long-read constraints 可縮小 phylogeny 解空間 | pair constraints 不保證唯一 tree |
| [Pe'er 等人：IDPP](https://doi.org/10.1137/S0097539702406510) | unknown binary states 可做相容 completion | unknown 不可直接補 REF，也不是 clone truth |

HapCUT2 與 LongPhase 的主要問題是 diploid germline phasing；本研究處理 bulk tumor mixture，因此只能借用「read-linked analysis component」概念，不能照搬兩條 haplotypes 的推論強度。

## 7. 建議放入論文與口試的說法

### 方法章

> 本研究先在同一 chromosome、exact phase set 與 primary haplotype 容器內，以至少三條不同 canonical molecules 對兩個 sSNV 位點皆具有 fixed REF/ALT call，建立 direct read-link edge。達門檻 edges 的 maximal connected component 定義為 source region W。A–B 與 B–C 可由不同 molecules 支持，因此其傳遞性只界定共同分析範圍，不代表 A–C 直接共讀、同一細胞、同一 clone 或演化順序。

### `k>12` 說法

> 當 source region 的位點數 `k_W>12` 時，本研究保留完整 source identity 與所有 constraint accounting，但因 exact/local solver 的計算上限，將其分成 `k_B≤12` 的 computational blocks。block 不是新的生物區域；在尚未完成跨 block global reconstruction 前，只報告 local candidate topology。

### 口試短答

> A–B 和 B–C 可以讓三個位點進入同一個 connected analysis region，因為 B 把兩組直接 read evidence 連起來；但傳遞的是分析資格，不是 clone 身分。若 `k>12`，原始 region 仍保留，只把 solver input 切小；切開後的局部結果不能自動拼成一棵全域 clone tree。

## 8. 已知、未知與下一步

### 已知

1. strict graph 的 A–B＋B–C connectedness 程式語意與合成測試一致。
2. HCC1395 chr1–22 partition receipts 與 constraint mass 守恆通過。
3. `k>12` 是 engineering cap，不是 genomic density。
4. 現行 child-block partition 不保證 induced connectivity。
5. strict partition 與 adapter 目前有 receipt schema／root receipt 整合阻塞，尚無正式 end-to-end PASS artifact。

### 尚未知／不可過度宣稱

1. `k=12` 是否為 runtime、memory、completeness 與 evidence retention 的最佳折衷。
2. RR-inclusive 與 ALT-informative graph 哪個對生物結論更穩健。
3. local block candidates 如何以可證明一致的方式形成 global topology。
4. 這些 read-linked candidate states 是否對應真實 cellular subclones；仍需 orthogonal／single-cell／truth-set validation。
5. 七 technical datasets strict production 目前僅 4/7 有完整 summary，不能先宣稱 cohort-complete。
6. zero-weight block 的 75／59 重投影結果仍需在 strict-bound adapter 修復後由 formal receipt 重驗。

### Step → Verify

1. 修正 partition／adapter receipt contract，補 root `run_receipt.json` 並統一 `bytes`／`size_bytes`
   → 驗證：`--require-strict-endpoint-receipt` 對 chr1–22 全部通過，membership path、size 與 SHA-256 三者一致。
2. 在 adapter 前加入 child-block induced-connectivity gate
   → 驗證：4 個已知 disconnected blocks 全部 abstain，既有 11,696 connected blocks不因該 gate 被誤刪。
3. 產出 RR-inclusive、ALT-any、ALT-support≥3 三種 graph sensitivity
   → 驗證：報告 W 數、membership changed、split/shrink/singleton 與 `k>12` 受影響率。
4. benchmark `k=10–14`
   → 驗證：每個 k 報 wall time、peak RSS、complete/capped rate 與 retained evidence。
5. 若要做跨 block reconstruction，先定 shared-separator 或 bridge likelihood contract
   → 驗證：合成 `{A,B}`＋`{B,C}` 在 B 一致時可重建，B 衝突時必須 abstain／多解，且不虛構 A–C direct edge。
