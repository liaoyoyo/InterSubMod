Answer first

不能直接判定為 subclone，也不能由單一 sSNV 推定 linear evolution

不支持原命題。「單一 truth-labeled FP sSNV 的 focal-ALT reads 被 InterSubMod 無監督分成多群」只證明同一 readset 內存在候選甲基異質性，不等於不同細胞 clone；一個 mutation state 也沒有足夠結構資訊判斷 linear 或 branching ancestry。

合理的 evolution-tree 輸入

仍應使用同一次最新 LongPhase-S 輸出的 recalibrated FILTER=PASS sSNV作 genetic input，再整合 multi-locus read co-occurrence、CN/LOH、purity-adjusted CCF 與不確定性。單一 sSNV 的 methyl group 只能作 annotation 或 targeted linkage anchor，不能取代 sSNV callset、不能直接當 tree node。

下一個最高資訊量實驗

  1. 以 10 strict sites 為 anchors，抽取同 reads 跨越的其他 latest PASS sSNVs、germline phase markers 與 CN/LOH segment。
  2. 比較 methyl group A/B 的 multi-locus somatic co-occurrence，預註冊至少 2 個獨立 genetic markers。
  3. 加入 matched-normal 同 region methylation matrix，使用相同 row-circular null。
  4. 把 HCC1395 chr8 四 sites 當一個 regional component 檢驗，避免把 epigenetic domain 當四個 clones。
  5. 只有通過 genetic co-membership + CCF consistency 的 candidates 才送入 topology inference。
