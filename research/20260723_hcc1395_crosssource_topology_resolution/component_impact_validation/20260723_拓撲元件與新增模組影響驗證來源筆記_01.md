可以驗證，但目前不能把所有差異直接拆成四個已知百分比。現有證據支持：

1. `phase/unit` 與 `region` 對結果有影響訊號，但尚未在同一母群做因果消融。

3. `edge identifiability` 的限制已被數學與負控制確認：同一 vertex set 的不同 parent trees 在現行 snapshot likelihood 下必須同分。

證據標籤：

- `CONFIRMED_LIMITATION`：負控制或數學結構已確認不可辨識。
- `METHOD_VALIDATED`：合成／oracle／契約測試通過，但不代表真實資料生物效應。
- `ASSOCIATION_ONLY`：觀察到與結果共同變化，尚未固定母群做 intervention。
- `RELEASE_PENDING`：正式全量 downstream／receipt 尚未完成。
- `ENGINEERING_ONLY`：預期科學輸出必須完全不變。

## 3. 已存在的定量證據

### 3.1 phase / unit：有訊號，尚非因果效應

- 同 internal sSNV、兩側 shape 可解時，unlabeled rooted-shape agreement：`3,681/5,039 = 73.05%`。
- 再限制兩側 primary unit 數相同：`3,681/4,508 = 81.65%`。
- 診斷差值：`81.65% - 73.05% = +8.60 percentage points`。

這個 `+8.60 pp` 只能稱 selection-conditioned diagnostic proxy，不能稱 phase 修正的因果增益，因為限制條件改變了分母與 case mix。正式效應必須在同一 frozen region／site／molecule 母群做 parity on/off paired contrast。

### 3.2 region：site backbone 高於 region 重現性

- retained exact allele-site Jaccard：`84.87%`。
- exact-coordinate region Jaccard：`72.8%`。
- 共同 exact regions 中，internal sSNV set 相同：`6,682/6,998 = 95.48%`。

這支持「region construction／boundary 會放大上游差異」的解釋，但 site Jaccard 與 region Jaccard 是不同 grain，不能直接相減成因果效應。需在固定 exact-allele union 上凍結 region strategy，並讓所有 arms 保留相同 master denominator。

### 3.3 partial-read：母群影響大，實際增益未量化

- 72,994 primary units 中，28,322（38.80%）同時有 full+partial evidence；44,672（61.20%）為 partial-only overlapping-read constraints。
- symbolic vs explicit compatible states：9,840 patterns、2,015,538 checks、0 mismatch。
- frozen exhaustive solver vs MILP：66 個可比較 vertex-set checks、0 mismatch。

因此 partial-read 不是少數角落案例；但「佔比大」不等於「改善正確率」。正式驗證須把 partial 對 structural candidate space 與對 likelihood scoring 的貢獻拆成 2×2。

### 3.4 edge：不可辨識限制已確認

- 同 internal sSNV、兩側 candidate unique 時，exact labeled-edge agreement：`1,582/4,482 = 35.30%`。
- same vertex set／different edge 的 likelihood difference：`1.42e-14`，在數值容差內為 0。

現行 likelihood 的觀測單位是 molecule 的 R/A/X＋BQ pattern，score 依賴 vertex set `V`，不依賴 parent-edge assignment `T`。所以 same-V/different-T 若被選出唯一 edge，反而是 false specificity；正確輸出是 equivalence class 或 `EDGE_NONIDENTIFIABLE`。

### 3.5 新 exact-PS adapter：HCC-only 技術鏈已驗證，跨來源效應未驗證

HCC1395 chr1-22 pilot 把單位改為 `exact PS × HP × read-linked component × bounded block (k=2..12)`：

- 11,542 tree-input route-blocks；其中 9,600 mutation-bearing、9,180 candidate-complete。
- cross-PS violations=0、cross-HP violations=0、Python/C++ mismatch=0。
- VAF ranking未執行；DORADO與其餘6資料集尚未跑。
- 舊版 8,222 coordinate regions與新版 route-blocks同時改了PS boundary、region、BQ、read policy、k上限與block selection，故不能直接相減。

這已確認新 adapter 的 fail-closed 分區與工程一致性，尚未確認 phase或region個別造成多少 topology 改善。

## 5. 正式共同母群

Primary scope 是 HCC1395 × HCC1395_DORADO 的 chr1-22；不退回 subset 作 validation evidence。

1. 建立兩來源 `PASS-any + raw-all sensitivity` exact-allele union。
2. 在兩個 BAM 對所有 union sites 重數 R/A/O/D/S/L/X、BQ/MQ、strand、HP/PS 與 matched-normal support。
3. 用 pooled discovery-half read bridges 與共享 germline anchors 凍結 source-neutral atomic region ID；held-out molecules評估。
4. master row 不因 arm 不可評估而刪除；保留 `not_evaluable_reason`。
5. 同一 canonical molecule 只能投一票；duplicate／supplementary policy全 arms一致。

Master endpoint row：

`frozen_region_id × exact_site_set_hash × analysis_arm × source_pair_or_split_half_seed`

## 6. 因子設計

### 6.1 Phase P

- `P_native`：各來源現行 exact known `HP family × PS`。
- `P_harmonized`：共享 germline heterozygous anchors估 block parity；無 anchor abstain。
- `P_unlabeled`：只作診斷，抹除 HP label 後比較 rooted morphology。

負控制：整個 PS block 做 HP1/HP2 swap；unlabeled morphology 必須不變。禁止以 topology agreement 最大化來選 flip。

### 6.2 Region R

- `R_positional`：歷史 50 kb／cap 策略，作 sensitivity baseline。
- `R_union_frozen`：fixed union coordinates 的固定窗口。
- `R_readlinked_frozen`：discovery-half pooled read bridges，threshold 1/2/3/5，primary=3；held-out評估。

另把 block/cap、BQ與read policy分成顯式因子：`densest k=8`、`retained-weight k=8`、`k≤12`；BQ 0/10/20；primary-only與明列 supplementary sensitivity。否則舊 coordinate regions與新 exact-PS route-blocks的差異無法歸因。

負控制：bridge／coordinate permutation 應降低 read-linked resolution；任何以 cross-source agreement挑出的 region 定義視為 leakage。

### 6.3 Partial Q：必要的 2×2

在同一 frozen component、sites、molecules 與完整 candidate enumeration上：

| Arm | partial 建 structure | partial 進 score | 回答 |
|---|---:|---:|---|
| Q00 | no | no | full-only baseline |
| Q10 | yes | no | partial 對可行 candidate space 的影響 |
| Q01 | no | yes | partial 對固定 candidate ranking 的影響 |
| Q11 | yes | yes | full method 與 interaction |

full-only 無法求解者標 coverage loss，不可從分母移除。另用 full reads 人工 mask 為 partial，建立 known-V 的 synthetic dropout truth。

### 6.4 Edge E

- `E_equiv`：same V 的全部 T 合併成 edge-equivalence class，沒有獨立證據則 abstain。
- `E_forced`：舊 AF／列舉順序強迫 edge，只作 false-specificity 對照，不能作 primary。
- `E_orthogonal`：未來 single-cell／colony／longitudinal／multi-region truth。

負控制：same-V/different-T、vertex order permutation、parent permutation全部必須同分；若不同即 NO-GO。

## 7. 統計 estimands

每個 arm 同時報兩類結果：

1. `fixed-denominator success = correct_or_agree / all_master_units`。
2. `conditional agreement = agree / jointly_evaluable`，並附 jointly-evaluable coverage。

主要跨來源 residual：

`E_arm = D_cross_arm - 0.5 × (D_within_HCC_arm + D_within_DORADO_arm)`

其中 `D_within` 來自每來源 molecule-level split-half 完整重跑，不共享 full-data phase 才可稱 total reliability ceiling。元件影響以 paired contrast `Δ_j = E_on - E_off`；非加成效應用預先指定的 `P×R`、`Q_structure×Q_score` 交互作用，最後才以 Shapley decomposition 描述順序不變的 attribution，不能把它當 biological variance component。

信賴區間以 synchronized chromosome×PS-block bootstrap；molecule bootstrap僅量 ranking stability，不當 biological replicate。所有 arms 同報：

- master N、evaluable N/%、jointly evaluable N/%；
- 每個 abstention reason；
- raw agreement、Cohen's κ、candidate-set Jaccard；
- vertex-equivalence accuracy（synthetic truth）；
- exact edge precision/recall（只限 orthogonal truth）；
- held-out log loss 與 selective agreement–coverage frontier。

## 8. Gate

1. **語意 gate**：cache on/off science SHA、V-set digest與數值欄位 bit-identical；否則立即 NO-GO。
2. **phase gate**：HP label swap不改 unlabeled morphology；parity不能由 topology outcome選擇。
3. **region gate**：region 在 discovery half 凍結；held-out評估，所有 arms用同 master universe。
4. **partial gate**：任何 incomplete enumeration不得產生 winner；synthetic masked truth 的 true V 必須在完整 candidate set內。
5. **edge gate**：same-V/different-T 必須 tie；真實 HCC 無 orthogonal truth 時只報 reproducibility／abstention。
6. **新增模組 gate**：M1/M2/G1/G2/R1/B1/C1 各自保留 claim ladder；上游 audit PASS 不代替 final downstream receipt。

不預設一個 universal agreement cutoff。模組「有幫助」至少需要 paired effect CI 排除 0，且固定分母成功率改善不是由 coverage下降造成；若 conditional agreement上升但 master success不升，判為 selective abstention，不判為解析力提升。

## 9. Step → Verify

1. Freeze exact-allele union、molecule identity、phase anchors與region discovery split。
   → 驗證：protocol、input、region、source hashes在結果前寫入 receipt；兩臂 master N相同。
2. 先跑合成 truth 與 partial 2×2／edge負控制。
   → 驗證：same-V/different-T score差在容差內為0；incomplete candidate一律 abstain；true V coverage可直接計算。
3. 各來源做 ≥50 molecule split-half seeds，再跑 HCC cross-source arms。
   → 驗證：read ID零重疊；每 seed輸出不是獨立 biological replicate；CI按 chromosome×PS block。
4. 跑 P、R、Q、E targeted factorial，再加新模組 on/off。
   → 驗證：每 contrast同時有 fixed denominator、coverage、conditional metric、interaction與abstention。
5. 加 matched-normal、CN/CCF 與 orthogonal truth gate。
   → 驗證：CN只移除 infeasible solutions；沒有獨立 edge truth不輸出 edge accuracy。
