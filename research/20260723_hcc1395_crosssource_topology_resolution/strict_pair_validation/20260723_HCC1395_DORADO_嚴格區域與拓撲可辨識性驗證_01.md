# HCC1395 與 HCC1395_DORADO 嚴格區域及拓撲可辨識性驗證

> 用 Claim–Evidence–Limit：**候選 sSNV 高度一致；DORADO 可辨識的局部無向 read-linkage 骨架大多重現在 HCC1395 中，但解析量明顯不對稱；新版 strict-bound clone/subclone topology 與 parent→child edge 尚未完成，因此不能宣稱兩棵演化樹高度一致。**（影響：高；信心：圖骨架高、演化樹低）

## 1. 直接回答

### 1.1 分類位點是否非常一致？

是。以完全相同的 `(chrom, pos, REF, ALT)` 比較：

- HCC1395：79,687 個 candidate alleles。
- HCC1395_DORADO：79,739 個。
- 交集：76,721 個。
- Jaccard：**92.76%**。
- 雙向包含率：HCC1395→DORADO **96.28%**；DORADO→HCC1395 **96.22%**。

在全部 7 個 technical datasets 的 21 組配對中，HCC1395–DORADO 的 candidate Jaccard 排名 **第 1**；次佳的不同 biological ID 配對只有 **0.041%**。因此，這批資料確實保留很強的同一 biological ID 訊號。

### 1.2 建樹前的可觀測結構是否一致？

不能只看對稱 Jaccard；需要同時看雙向 containment：

| 證據層 | HCC1395 數量 | DORADO 數量 | Jaccard | HCC→DOR | DOR→HCC | 解讀 |
|---|---:|---:|---:|---:|---:|---|
| Active allele loci | 36,384 | 32,307 | 78.59% | 83.08% | **93.56%** | active 位點高度重現 |
| W allele loci | 22,689 | 11,215 | 42.75% | 44.75% | **90.54%** | DORADO 的可建構區域大多被 HCC 包含 |
| 無向 direct edges | 53,883 | 13,324 | 19.80% | 20.62% | **83.38%** | DORADO 邊大多重現，但 HCC 多解析約 4 倍 |
| Exact component site-set | 8,728 | 4,881 | 21.73% | 27.83% | 49.76% | 完全相同 component 邊界對 fragmentation 敏感 |
| Component co-membership pair | 86,554 | 22,360 | 19.70% | 20.71% | **80.18%** | DORADO 的局部連通關係多被 HCC 重現 |

限制在 76,721 個共同 candidate alleles 後，DORADO→HCC1395 containment 進一步為：

- Active loci：**99.48%**
- W loci：**97.45%**
- 無向 direct edges：**98.28%**
- ALT-informative direct edges：**98.16%**
- Component co-membership：**90.05%**

因此，低 edge Jaccard 主要是**解析量不對稱**，不是 DORADO 選出大量與 HCC 相衝突的邊。較準確的描述是：DORADO 得到一個較短、較碎、較稀疏的局部骨架，而這個骨架大多嵌在 HCC1395 的較大骨架內。

### 1.3 建立演化樹後的 topology、structure、edge selection 如何？

目前必須分成兩種「edge」：

1. **Strict direct edge**：兩個 sSNV endpoint 被足夠 canonical molecules 直接連結；它是無向 read-linkage edge。這一層的 DORADO 邊具有高單向重現，沒有顯示大規模錯選邊。
2. **Evolutionary parent→child edge**：需要候選 mutation-state tree、partial-read likelihood、VAF/CN/CCF ranking 與方向可辨識性。DORADO 尚未產出新版 strict-bound partition／units／constraints／ranking／topology／likelihood，因此這一層**尚無結果可比較**。

所以不能把 98.28% 的共同母群 strict edge containment 寫成「parent→child edge 98.28% 一致」；前者只證明局部共現骨架，後者才是 clone evolution。

## 2. 為什麼 component 與對稱 edge Jaccard 較低？

正式 dataset summary 顯示：

| 指標 | HCC1395 | HCC1395_DORADO | 影響 |
|---|---:|---:|---|
| Exact chromosome×PS | 3,971 | 11,515 | DORADO 約 **2.90×** 更碎 |
| Exact PS×HP containers | 7,118 | 18,396 | 更多 hard boundaries |
| Median W span | 17,837 bp | 5,753.5 bp | DORADO linkage reach 較短 |
| Median direct-edge distance | 11,963 bp | 4,801 bp | DORADO 長距離連結較少 |
| Canonical molecule rows | 3,201,802 | 3,507,573 | DORADO 並非單純因總 molecule rows 較少 |

Exact-PS hard boundary 能防止沒有 signed cross-PS 證據時的錯誤拼接，方法契約較嚴謹；代價是不同 pipeline 的 PS fragmentation 會直接變成 region、component 與 edge recall 差異。一條邊的增加或缺失也可能使整個 connected component 合併或分裂，因此 exact component site-set 比 loci 或 edge containment 更敏感。

同一 cell line 不等於同一 aliquot、passage、library 或相同 molecules，殘差也不能全部歸咎於演算法。不過 candidate alleles 五層排名均第 1，以及共同 candidate 母群中 DORADO 骨架的高 containment，支持主要差異更像 phase/block 與技術解析度，而非兩批資料完全不同。

## 3. 方法是否有問題？

### 已通過

- 7 datasets × chr1–22 的 extraction 與 strict region receipts 已完成。
- 本次獨立讀回每組 88 個檔案，candidate、active、W、tree-eligible component 與 retained edge 六類守恆檢查全數 PASS。
- HCC1395–DORADO 在 candidate、active、W、direct edge、exact component 五層的 21-pair 排名都為第 1，顯示方法具有很強的 biological-ID specificity。
- Exact-PS×HP region contract 合理：沒有直接跨 PS 定向證據就不跨 block 接樹。

### 尚未通過

- Strict partition→topology adapter 的 production binding 仍是 **BLOCKED**：缺 root-level receipt，`bytes`／`size_bytes` schema 不一致。
- Adapter 的 strict-binding gate 已存在，但既有 HCC-only topology run 沒有啟用 `--require-strict-endpoint-receipt`，且綁的是舊 exploratory partition；因此不能用該 run 代表新版 strict end-to-end PASS。
- HCC1395 的 11,700 個 `k≥2` computational blocks 中有 4 個 induced threshold-3 graph 不連通；正式 tree gate 必須排除。
- DORADO 尚無 strict-bound topology solver 產物，無法做新版 tree-to-tree comparison。
- Threshold=3 目前是工程門檻，不是已完成跨技術最佳化的統計門檻。
- Read-linkage connectedness 不等於同一 read、cell、clone，也不提供 A→B→C 的演化方向。
- HCC1395 與 DORADO 的 strict receipts 使用同一組 pre-hotfix builder SHA；現有稽核認定 missing-PS hotfix 對這兩者不觸發、數值等價，但若要求最嚴格的 same-current-builder provenance，仍需在新 root 重跑。

因此，**region/read-linkage graph 方法可稱合理且可重現；完整 clone/subclone tree inference 仍未完成方法學驗證。**

## 4. 建議正式結論

不建議：

> 底層高度相似、可辨識拓撲中高度重現、精確邊仍不穩定。

建議改為：

> **HCC1395 與 HCC1395_DORADO 的候選 sSNV 骨架高度一致。DORADO 可解析的局部無向 read-linkage 骨架大多重現在 HCC1395 中，但因 exact-PS fragmentation 與 linkage reach 不同，兩者解析度明顯不對稱，完整 component partition 只部分重現。新版 strict-bound clone/subclone topology 與精確 parent→child ancestry 尚未完成，因此目前不能宣稱兩棵演化樹高度一致或唯一。**

如需更短版本：

> **底層位點高度一致；DORADO 的局部無向骨架高度包含於 HCC1395；解析度不對稱；精確親子方向尚不可辨。**

## 5. 口徑警告

本次 candidate Jaccard 92.76% 使用完整 strict `site_catalog S`。先前 84.87% 使用舊 current-v5 retained allele-sites；分母與處理階段不同，不能以兩數相減宣稱 exact-PS 矯正帶來 7.89 個百分點改善。要驗證「矯正後更好」，必須在同一 frozen candidate/read 母群上執行 old-region vs exact-PS paired ablation。

## 7. Claim ceiling

本報告證明的是 allele-site identity、strict read-linkage observability、無向 edge／component skeleton 的跨來源重現性。它不證明唯一 mutation-state topology、clone 數量、subclone fraction、parent→child ancestry 或全基因組 global clone tree。

## 8. 後續固定比較重點

以下結論作為後續報告與最終整合樹分析的固定口徑：

1. **只有 HCC1395–HCC1395_DORADO 明顯相似**：在 7 datasets 的 21 組配對中，HCC pair 於 candidate、active、W、direct edge、exact component 五層均排名第 1；不同 biological ID 的次佳 Jaccard 分別僅 0.041%、0.048%、0.067%、0.146%、0%。這證明方法沒有把所有樣本都做成相似結構，具有 biological-ID specificity。
2. **此處主要是結構骨架相似，不是已證實的演化樹拓撲相似**：可確認的是共同節點、無向 read-linkage edge 與 component co-membership。真正的 tree topology 還需要有向 parent→child、rooted branching、VAF/CN/CCF 與 candidate-tree identifiability。
3. **對最終樹只能作條件式預期**：共同 candidate 母群中，DORADO→HCC1395 的 direct-edge containment 為 98.28%、co-membership containment 為 90.05%，因此在可辨識且共同覆蓋的區域，兩者的主要 trunk／高支持 partial order 合理預期會比任何不同 cell line 更接近。DORADO 較可能是 HCC1395 高解析樹的 contraction／pruned view，而不是完全不同的生物樹。
4. **不能預先保證 exact tree isomorphism**：DORADO 的 PS 更碎、edge 較少；同一骨架缺少少數邊時，solver 可能留下多個等價候選樹，或把分枝壓成 unresolved polytomy。故精細 subclone 數、branch ordering 與 parent→child edge 仍可能不同。
5. **正式驗證單位應是 candidate-tree set 與 partial order，不是任選一棵 best tree**：完成 DORADO strict-bound solver 後，固定共同 node universe，比較 rooted-triplet／ancestor-descendant concordance、方向邊 containment、collapsed-tree compatibility 與 CN/CCF-adjusted clone fraction；並將 HCC pair 的結果與其餘 20 組 negative-control pairs 排名。

固定一句話：

> **HCC1395 pair 已證明同一 biological ID 的局部 read-linkage 結構具有高度特異且非對稱的重現；這提高兩者最終主要樹幹相近的可信度，但尚不能保證完整有向 clone tree 完全相同。**
