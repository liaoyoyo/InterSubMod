### 2.2 尚未確認

- 兩來源的確切 passage number、culture lot、DNA extraction lot、aliquot ID 與 library-prep ID 是否相同。
- 目前 residual topology conflict 中，有多少比例是 biological culture drift。
- DORADO source-specific allele-specific CN、purity 與 mutation multiplicity；現行分析沿用 `SEQC2_same_cell_line` CN，只能作 sensitivity，不能作獨立確認。
- 任一區域的唯一 biological clone tree 或全基因組 clone K。

因此目前最合理歸因仍是：

> **Identifiability-dominant, upstream/source-contributed, sampling-plausible, biological-divergence-plausible-but-unresolved。**

來源差異是必須控制的 confound，但不能成為所有不一致的免責理由。

## 3. 目前信號落差說明

| Grain | current evidence | 判讀 |
|---|---:|---|
| retained exact allele overlap | Jaccard 84.87% | 位點 backbone 高度重現 |
| exact shared-site caller AF | CCC 約 0.953 | 頻率主體高度相似 |
| matched morphology | 75.18%，κ=0.557 | 中度重現，尚未達 substantial |
| same internal sSNV + resolvable shape | 73.05% | unlabeled shape 仍只有中度一致 |
| 再要求 primary unit count 相同 | 81.65% | unit/HP/PS 建構可解釋一部分差異 |
| exact labeled edge | 35.30% | exact ancestry 解析不足，不能稱同一棵樹 |

這表示問題不主要是「兩邊位點完全不同」，而是共同位點之後的 phase/unit、partial-read observation、candidate multiplicity 與 edge identifiability 放大差異。

## 4. 核心原則：特異性與解析力不能用強迫唯一來交換

- **特異性**：降低錯誤 edge／錯誤 clone claim；依靠 quality-aware likelihood、negative controls、獨立驗證與 abstention。
- **解析力**：增加真正可區分的 state／edge；依靠更多 informative molecules、較穩定 phase anchors、multi-marker linkage 與獨立 CN/CCF constraints。
- 降低 abstention、只留一致區域、事後挑 HP flip、以 HCC similarity 調權重或固定最少 clone catalog，只會增加「表面解析力」，不會增加 truth identifiability。

目前 Read-linked Hypercube M2 的正確方向是：完整枚舉 minimum-extra vertex sets，再以 BQ/error-aware molecule likelihood 比較不同 `V`。但同一 `V` 內的不同 parent edges `T` 沒有新增觀測時仍不可辨，必須輸出 `EDGE_UNIDENTIFIABLE`，不能靠 AF 再選一次。

## 5. 正式驗證流程（Step → Verify）

### G0. Freeze 與盲化

1. 凍結 VAF-free primary metric、HP permutation 規則、depth target、排除條件與 margin。  
   → 驗證：protocol hash 在任何新結果產生前固定；HCC 標為 development pair。
2. 將 read-AF ranking 降為 secondary。  
   → 驗證：primary 報告不含任何以 AF 直接建構的 similarity component。

### G1. Sample identity 與 provenance

1. 以 normal/tumor germline SNP 做 `bcftools gtcheck` 或 VerifyBamID2/NGSCheckMate fingerprint。  
   → 驗證：兩來源與對應 normal 的 identity/contamination 報告完整；fingerprint 只能確認身份，不能確認 passage。
2. 對完整 read UUID/QNAME 與 raw POD5/FAST5 checksum 做交集；整理 SRA/BioSample、run、flowcell、library、extraction、culture metadata。  
   → 驗證：明確標示 `same_molecule`、`same_library`、`same_aliquot`、`same_culture` 為 yes/no/unknown，不以 unknown 當 no。

### G2. Within-source reliability ceiling

1. 每來源做至少 50 個 molecule-level split-half seeds，read ID 零重疊，完整重跑 phasing/haplotag/topology。  
   → 驗證：若只共用 full-data HP，只能標 `conditional-on-phasing ceiling`。
2. 以 synchronized chromosome/PS-block bootstrap 估計 topology distance、κ、candidate coverage。  
   → 驗證：seed 不當 biological replicates；CI 以 chromosome/PS block 為單位。

**建議先驗 operational Gate（不是 universal cutoff）**：`D_morph` 95% upper ≤0.05；morphology κ point ≥0.70 且 lower CI ≥0.60；evaluable coverage ≥80% 且跨 ≥15 chromosomes。若失敗，先判 measurement reliability 不足，不進 biological drift claim。

### G3. 共同觀測與 pipeline factorial

1. 建立兩來源 `PASS-any + raw-all sensitivity` exact-allele union，在兩個 BAM 全部重數 REF/ALT/OTHER/DEL/REFSKIP/uncovered、BQ/MQ/strand、HP/PS 與 normal support。  
   → 驗證：missing 分為 `no_coverage`、`no_alt_support`、`HP_missing`，不得默認 REF。
2. 兩側使用相同 reference、minimap2 command、caller model、germline anchors、phaser、LongPhase-S options；確認 one-molecule-one-vote。  
   → 驗證：upstream command/inputs 有 hash；duplicate molecule 不重複貢獻 likelihood。
3. 高 depth 來源盲化 downsample；匹配 per-chrom depth、read length、BQ/MQ、HP/PS availability。  
   → 驗證：depth ratio 0.90–1.10、continuous covariate SMD<0.10；所有 target 事先凍結。
4. 若 raw POD5 可得，在每一來源內讓同一 molecules 跑兩套 basecaller/pipeline，形成 `source × pipeline` factorial。  
   → 驗證：同 molecules 不同 pipeline 估 pipeline effect；不同 sources 同 pipeline 估 source/library residual。

### G4. Phase、region 與 likelihood

1. 以共享 germline heterozygous anchors 建 PS block-overlap graph，block 級估計 same/swapped parity；無 anchor 則 abstain。  
   → 驗證：不得以最大 topology agreement 選 HP flip；leave-one-anchor-out 穩定。
2. 共同 atomic PS blocks 上，以 discovery-half 的 pooled read bridges freeze regions；held-out molecules 推論。  
   → 驗證：region ID、sites、bridge threshold 與 hash 固定；不得 densest-8 或只留 concordant regions。
3. 在完整 candidate vertex sets 上用 BQ/MQ/error-aware molecule likelihood，並保留 same-vertex/different-edge equivalence class。  
   → 驗證：輸出 likelihood、bootstrap、error-grid、held-out score 與具名 abstention reason；agreement 必須連同 coverage 畫 selective agreement–coverage curve。

### G5. CN-aware biological feasibility

1. 兩來源各自估 allele-specific CN、LOH、purity interval 與 mutant multiplicity；共享 SEQC2 CN 只作 sensitivity。  
   → 驗證：每個 edge/clone solution 都帶 CN/purity/multiplicity feasible interval。
2. 對候選 global solution 檢查：非負 clone fractions、總和 ≤1、acyclic、`CCF_child ≤ CCF_parent`、siblings sum rule，以及 mutation gain/loss/recurrence 與 CN history 相容。  
   → 驗證：違反任一必要條件即 reject；通過只代表「可行」，不代表唯一真實。
3. 每個 subclone 至少需兩個獨立 genetic markers 的 group-specific co-membership；同 reads 衍生的 VAF/likelihood 不算獨立軸。  
   → 驗證：沒有 single-cell/colony/spatial/long-range cellular anchor 時，只輸出 regional genotype classes 或 descendant-compatible，不升級 cellular subclone。

### G6. Cross-source inference 與外部確認

主要量：

`D_excess = D_cross − mean(D_split,HCC, D_split,DORADO)`

`Δ_sep = min(D_matched-unrelated) − D_HCC-pair`

1. 非劣性：`D_excess` one-sided 95% upper CI < 預註冊 margin（建議初始 `0.02`）。  
   → 驗證：不能用「差異不顯著」冒充 equivalence。
2. literal「最相近」只作 secondary：`Δ_sep≥0.02`、lower CI>0、rank=1 且 ≥95% synchronized bootstraps 維持 rank 1。  
   → 驗證：比較對必須是技術條件匹配的 unrelated A_i–B_j，不是任意 21 dyads。
3. Conditional added value：held-out/leave-one-chromosome-out 中比較 `M0=loci+VAF+depth+PS+CN+completeness` 與 `M1=M0+VAF-free topology`。  
   → 驗證：預註冊示例 Gate 為 log-loss 改善 ≥5% 且 ≥0.02 bits/region，block-CI lower>0，conditional permutation p≤0.05。
4. HCC 只能開發 protocol；乾淨 confirmatory 至少需 5 個不同 biological sources 的 external technical pairs，實務建議 8–10。  
   → 驗證：leave-one-biological-source-out；threshold/metric 在 external 解盲前凍結。

## 6. 如何判斷是資料、pipeline、演算法或生物差異

| 觀察 | 最合理歸因 |
|---|---|
| 同一 BAM split-half 已不穩 | sampling／phase／candidate identifiability 或 algorithm reliability；先不談 biological drift |
| 同 molecules、不同 pipeline 明顯分歧 | basecaller/alignment/phasing/caller effect |
| 共同 pipeline + matched depth 後 HCC pair 明顯靠近 | upstream pipeline/coverage 是主要來源 |
| 共同 pipeline 後只在同-vertex parent edge 不穩 | edge 本質不可識別；輸出 equivalence/abstain |
| split-half 穩、共同 pipeline 後仍超出 ceiling，且 source-specific CN/private mutation clusters 在同來源多 libraries 重現 | culture/library biological divergence 變得可信，但 passage 原因仍需 metadata |
| germline fingerprint 不符或 contamination 異常 | sample swap/mixture；停止 topology comparison |

## 7. Clone/subclone 理論合理性的 claim ladder

1. **Regional mutation state supported**：共同 exact allele、known PS/HP、獨立 molecules、error control、complete candidate set、held-out 重現。
2. **Regional heterogeneity compatible**：同 HP 至少兩 exact states，且 ASCN／purity／subclonal CNA alternatives 已建模。
3. **Descendant/branch compatible**：CCF 與 mutation/CN history 可行；edge 若同 vertex set 多解，仍不得稱 lineage confirmed。
4. **Cellular subclone supported**：再加 single-cell、colony、spatial 或 long-range cell linkage與獨立 replicate。
5. **Global clone tree supported**：跨 region 且跨獨立 mixture axes 的 genotype/fraction 一致，design matrix full rank、非負解唯一、held-out 可預測。

HCC1395 與 DORADO 觀察的是近似同一 bulk mixture，而不是兩個獨立 spatial/timepoint mixture equation；它們能驗證 reproducibility，通常不能把 local regions 唯一連成 global clone tree。可報告的是 consensus backbone、must edges、may edges、source-private candidates 與 unresolved equivalence classes。
