單位點 sSNV 甲基多群：代表位點定義、圖解與停止判定

研究主計算可以停止。 位點、read tag、M1/M2 與代表矩陣都已存在且可追溯；現有結果支持 shared ancestral ALT reads 內的 latent molecular substructure candidates， 不支持 confirmed cellular subclone 或 linear ancestry。

固定研究問題已回答，停止不等於否定甲基價值

要停止的是重複計算與無限背景追查；應保留的是已驗證位點、正確分母、代表圖與 claim ceiling。

✓ 科學完成
全量 M1、singleton M1/M2、latest tag join、共現與控制軸已有 frozen 結果。
✓ 位點存在
30 個 singleton M2 PASS 有逐位點表；HCC1395 兩個正例有完整 read-level 圖資。
■ 發布停止
signed release 因 nested finalizer schema blocker 停止，不能宣稱正式簽章發布完成。
✕ 不可升級
現有證據不能直接升級為 confirmed clone、clone 數、parent→child 或唯一演化樹。

四個分母必須分開，30/48 不能當成盛行率

同一批結果可產生不同問題的比例；只有先說清楚分母，才不會把高度選擇後的 M2 子集外推到全體。

M1 找穩定結構，M2 排除已量測對齊軸，兩者都不是 clone 身分證

方法的價值在於把「看到分群」拆成可重現性與常見 confound 兩層，而不是直接把任何 clustering 命名成 subclone。

本報告中的關鍵術語
名詞 精確定義 能回答 不能回答
focal ALT reads 在指定 sSNV 支持 ALT allele 的 reads 同一 ALT carrier 群內是否異質 reads 必然屬於同一細胞 clone
positional singleton 50 kb transitive component size=1 沒有本地 partner 可做正式共現 全基因組 read-sharing degree=0
M1 stable multigroup 跨 seeds 穩定且通過 shuffle null 與最小群門檻 read-level 甲基多群可重現 技術／生物 confound 已全排除
M2 PASS 八個已測軸可判定且無軸與群組對齊 常見已測技術軸未解釋分群 未量測 confound、CN/purity、細胞身分已排除
Bernoulli distance reads 在共同 CpG 上的甲基狀態差異 哪些 read pattern 較相似 突變時間或方向
UPGMA 甲基距離的 average-linkage hierarchy 距離分群階層 cellular phylogeny / mutation tree
M2 NOT_EVALUABLE 不等於 M2 FAIL。 它表示至少一個必要控制軸資訊不足或不可判定，不能把「沒完成排除」寫成「已證明沒有結構」。

資料鏈的五個固定契約
  1. 母體是 469,849 個 latest LongPhase-S PASS sSNV，不是 raw ClairS 全候選。
  2. latest HP/PS join 發生在 focal-ALT selection 之前。
  3. embedded BAM/reads.tsv HP 不作正式分析來源。
  4. HCC1395 與 HCC1395_DORADO 是同一 biological sample，不算獨立重現。
  5. 沒有輸出或覆寫 LongPhase-S tagged BAM。

chr14 強正例把「群內近、群間遠」直接畫成區塊

`chr14:86,272,476 A>T` 的距離矩陣、CpG pattern 與 UPGMA 三張圖指向同一件事： focal-ALT reads 可依甲基狀態穩定分成兩個分子群。

  • 支持：共享 focal ALT reads 內有穩定甲基 pattern 分層。
  • 支持：已量測八個技術軸沒有與群組對齊。
  • 不支持：Group A/B 必然是兩個細胞 clone。
  • 不支持：UPGMA merge height 是突變時間。

chr22 正例顯示 pattern 分群不等於單一平均甲基值二分

`chr22:47,466,517 A>G` 的跨群距離仍高於群內，但 CpG 圖更像局部 pattern 組合； 這說明方法需要 read×CpG 結構，而不是只用一個平均甲基值。

甲基能提出 ancestral ALT 下的分層，但證據鏈在 cellular clone 前停止

最精確的敘述不是「找到 subclone」，而是「找到可重現、未被已測技術軸解釋的 read-level latent molecular substructure candidate」。

[F] L1 · 計算事實
結構可重現

M1/M2、assignment、matrix 與 tag join 可 exact 回查。

[O] L2 · 分子觀察
latent substructure

shared focal ALT reads 內有穩定甲基分層候選。

[I] L3 · 生物推論
可能對應 subclone

合理但待第二 marker、CN/CCF 與正交驗證。

[U] 未成立
cellular lineage

confirmed clone、clone count、linear ancestry 都是 0。

共現沒有把這個缺口補完。 正式 G1 只有 7 個 focal candidates，G2=0；現行 production strict directed topology=0/7。 因此 methyl group 與 sSNV cooccurrence 可互相支持候選，但沒有足夠資訊建立唯一 linear tree。
要升級為 cellular subclone 還需要什麼？
  • 第二個獨立 sSNV marker 的 read-level cooccurrence。
  • tumor-REF 與 matched-normal control。
  • exact-locus CN、purity、multiplicity 與 CCF。
  • 跨技術重現，或 single-cell / colony / spatial 正交驗證。
  • 預先註冊的 lineage identifiability 與 falsifier。

現在應保存與解釋；若要升級 clone claim，必須開新驗證週期
