# 單位點 sSNV 甲基多群：代表位點定義、圖解與停止判定

> **PARTIAL VISUAL SUBSET｜[F] Illustration**：全量數字使用 7 datasets、chr1-22、469,849 個最新同次 LongPhase-S recalibrated `FILTER=PASS` biallelic sSNV；圖解只選已有完整 read-level artifact 的 HCC1395 代表位點。代表圖不是盛行率抽樣，也不是 validation evidence 的替代品。

## 結論先讀：科學分析可以停止，留下的是明確的證據邊界

**可以停止主計算與背景追查。** 469,849 個位點已完成 focal-ALT 甲基多群、latest HP/PS sidecar join、singleton、sSNV 共現與控制軸分析；本輪不需要再重跑 ClairS、LongPhase-S、BAM、tag、分群或拓撲。

**可以確認有這類位點。** 全體 M1 穩定甲基多群為 `102,842/469,849=21.8883%`；positional-singleton 中，M1 為 `5,961/50,432=11.8199%`，M2 PASS 為 `30/50,432=0.05949%`。這些是 operational screen yield，不是腫瘤內 clone prevalence。

**目前最強且正確的生物敘述**是：共同攜帶同一 ancestral focal ALT 的 reads 內，存在可重現的 latent molecular substructure 候選；甲基資訊可提出或輔助單位點分層，但不能單獨證明 cellular subclone、clone 數、線性親子關係或唯一演化樹。

**signed release 與科學完成是兩件事。** 科學數據已驗證；正式 authority/receipt/signature 發布鏈因 nested finalizer schema blocker 依 bounded-attempt policy 停止，不能宣稱 signed Task-B release 完成。

## 四個數字先建立正確分母

| 問題 | 分子 / 分母 | 比例 | 正確解讀 |
|---|---:|---:|---|
| 全 sSNV 有多少 M1 穩定多群？ | 102,842 / 469,849 | 21.8883% | 全位點 operational M1 screen yield |
| singleton 有多少 M1 穩定多群？ | 5,961 / 50,432 | 11.8199% | 無 50 kb positional partner 的區域仍可見甲基多群 |
| singleton 有多少 M2 PASS？ | 30 / 50,432 | 0.05949% | 對全部 singleton 的保守 operational yield |

補充：HCC1395 有 8,279 個 singleton，其中 8,074 個 M1 可評估、734 個 M1 穩定多群；734 個的群數分布為 K=2/3/4/5：`651/73/9/1`，目前 M2 PASS 為 2。

## 名詞定義：每一層回答不同問題

| 名詞 | 本研究中的精確定義 | 能回答 | 不能回答 |
|---|---|---|---|
| latest LongPhase-S sSNV | 同一次 LongPhase-S recalibrated `FILTER=PASS` chr1-22 biallelic sSNV | 分析母體是哪批位點 | 原始 ClairS 全部候選都等價可用 |
| focal ALT reads | 在指定 sSNV 位點支持 ALT allele 的 reads | 同一 ALT carrier 群內是否異質 | 這些 reads 必然來自同一 clone |
| positional singleton | 同 dataset/chrom、以相鄰 gap≤50 kb 的 transitive component 中 size=1 | 沒有本地 50 kb sSNV partner 可做正式局部共現 | 全基因組 read-sharing degree=0 |
| M1 stable multigroup | 甲基距離分群跨 seeds 穩定、通過 column-shuffle null 與最小群門檻 | 是否有可重現 read-level 甲基多群 | 技術或生物 confound 已全部排除 |
| M2 PASS | strand/start/end/length/MAPQ/CpG-called/latest HP 等已測軸皆可判定，且無軸與群組對齊 | 常見已測技術軸未解釋該分群 | 未量測 confound、CN/purity、細胞身分已排除 |
| latent molecular substructure | 同一 focal ALT read 集內，存在穩定但尚未綁定細胞身分的甲基分層 | 提出 subclone 候選或輔助分層 | 等同已確認 subclone |
| Bernoulli read distance | 兩條 read 在共同可比較 CpG 上的甲基狀態差異 | 哪些 reads 的甲基 pattern 較相似 | 突變時間或演化方向 |
| UPGMA | 對 read×read 甲基距離做 average-linkage hierarchy | 顯示分群的距離階層 | cellular phylogeny / mutation tree |
| HP/PS | 最新 same-run LongPhase-S sidecar 的 haplotype/phase-set tag | 控制與 sSNV phase/read linkage | HP1/HP2 等於 clone 1/clone 2 |

## 資料鏈已鎖定：位點與 read tag 不是舊 BAM 內嵌值

1. 分析母體是 469,849 個最新 LongPhase-S PASS sSNV，不是 raw ClairS 全部位點。
2. 38,345,639 個 site-read observations 全部 exact join 到 same-run LongPhase-S external HP/PS sidecar。
3. 33,693,248 個 source HP 被 latest tag replacement；projection multimatch=`0`。
4. embedded BAM/`reads.tsv` 舊 HP 不作正式分析來源。
5. 七組資料的 `persisted_bam=false`；沒有輸出新 tagged BAM，也沒有覆蓋原 LongPhase-S BAM。

## 代表位點不是只挑漂亮圖片，而是涵蓋正例、極端與邊界

| 角色 | Dataset / locus | 已知結果 | 選它的理由 |
|---|---|---|---|
| 強區塊正例 | HCC1395 `chr14:86,272,476 A>T` | M2 PASS；108 core reads；86/22；42 CpGs | 群內距離低、群間距離高，最容易理解 |
| pattern 正例 | HCC1395 `chr22:47,466,517 A>G` | M2 PASS；109 core reads；88/21；93 CpGs | 全域均值未必極端，但局部 CpG pattern 可分 |
| 三群極端例 | H2009 `chr6:52,060,111 C>A` | M2 PASS；3 groups；108 core reads；min group=5 | 30 個 singleton M2 PASS 中唯一 K=3 |
| M1 邊界例 | HCC1395 `chr14:95,851,393 C>G` | M1 K=3；43/12/37；M2 NOT_EVALUABLE | 顯示多群不等於 M2 FAIL，也不等於 clone |
| 高 K 邊界例 | HCC1395 `chr9:26,274,295 G>T` | M1 K=4；19/5/3/26 + 3 other | 顯示 hierarchy 與 quarantine reads |
| 唯一 K=5 例 | HCC1395 `chr12:240,507 A>T` | M1 K=5；20/6/3/20/30 + 2 outlier | HCC1395 singleton M1 中唯一 K=5 |

後三個位點目前是「結構教學與後續候選」，不是 M2 PASS。H2009 三群位點有完整凍結 artifact，但本報告不新繪圖，以維持「停止新計算」的範圍。

## chr14 正例：距離矩陣直接顯示群內近、群間遠

![HCC1395 chr14 代表 read 的 Bernoulli 甲基距離矩陣](../20260718_singleton_alt_methyl_substructure_validation/results/heatmap_qa/01_locus_1_distance_heatmap.png)

讀圖方式：

- 每一列與每一欄都是 focal-ALT read；A/B 是 methyl-group alias，不是 HP。
- 對角線必為 0，因為 read 與自身距離為 0。
- 左上與右下同群區塊較淺，代表群內甲基 pattern 接近。
- 右上與左下跨群區塊較深，代表群間差異較大。
- 圖中是 deterministic representative reads；判定使用完整 108 core reads。

## chr14 的 read×CpG 圖顯示差異來自哪些甲基位置

![HCC1395 chr14 focal-ALT read × CpG methylation probability](../20260718_singleton_alt_methyl_substructure_validation/results/derivative_validation_v4/figures/chr14_86272476_A_T.read_by_cpg_methylation.png)

讀圖方式：

- 列是代表 reads，欄是 genomic CpG positions。
- 黃色接近 methylated、深藍接近 unmethylated、灰色是該 read 沒有可用 call，灰色不能當成 0。
- 黑線區隔 M1 Group A/B；兩群在多個 CpG 區段形成一致 block difference。
- 這張圖支持甲基 pattern 分層，不證明兩群是兩個細胞 clone。

## chr14 的 UPGMA 只畫距離階層，不畫演化方向

![HCC1395 chr14 focal-ALT read average-linkage UPGMA](../20260723_hcc1395_singleton_alt_methyl_multigroup_visual_report/figures/01_chr14_86272476_A_T_representative_UPGMA.png)

橫軸是 average-linkage merge height；越晚合併代表甲基距離越大。枝條沒有時間軸、沒有 parent→child 方向，不能稱為 clone tree。藍/橘 leaf labels 只標記 methyl Group A/B。

## chr22 正例：局部 pattern 仍能形成穩定兩群

![HCC1395 chr22 代表 read 的 Bernoulli 甲基距離矩陣](../20260718_singleton_alt_methyl_substructure_validation/results/heatmap_qa/04_locus_2_distance_heatmap.png)

chr22 同樣有清楚的群內低距離；跨群距離比群內高，但形狀不像 chr14 那麼接近全域 high/low 二分。它示範甲基分群應使用多 CpG pattern，而不能只看每條 read 的單一平均甲基值。

![HCC1395 chr22 focal-ALT read × CpG methylation probability](../20260718_singleton_alt_methyl_substructure_validation/results/derivative_validation_v4/figures/chr22_47466517_A_G.read_by_cpg_methylation.png)

灰色仍是缺 call；Group A/B 仍是 methyl assignment。完整判定使用 109 core reads，圖中只抽 deterministic representative reads 方便閱讀。

![HCC1395 chr22 focal-ALT read average-linkage UPGMA](../20260723_hcc1395_singleton_alt_methyl_multigroup_visual_report/figures/02_chr22_47466517_A_G_representative_UPGMA.png)

這棵 hierarchy 支持「reads 可依甲基距離形成穩定分組」，不支持「突變 A 先於突變 B」；本位點是 positional singleton，本來就沒有局部 partner 可建立正式 sSNV 共現方向。

## 從位點分群到 subclone，仍缺一段不可跳過的證據鏈

| 證據層 | 目前狀態 | 可用詞 |
|---|---|---|
| [F] 計算事實，L1 | M1/M2 位點、read assignment、矩陣與 tag join 可重現 | 「偵測到穩定甲基多群」 |
| [O] 分子觀察，L2 | shared focal ALT reads 內存在 latent molecular substructure candidate | 「支持分子子結構候選」 |
| [I] 生物推論，L3 | 甲基群可能對應 ancestral ALT 下的不同 subclone | 「可能、候選、待正交驗證」 |
| [U] 細胞結論，未成立 | confirmed cellular subclone、clone count、linear ancestry | 不可宣稱 |

要升級為 cellular subclone，至少需要其中數項共同成立：第二個獨立 sSNV marker 的 read cooccurrence、tumor-REF/matched-normal 對照、exact-locus CN/purity/multiplicity/CCF，以及跨技術或 single-cell/colony/spatial 正交驗證。

目前正式 sSNV 共現結果只有 7 個 G1 focal candidates；G2=`0`，confirmed cellular subclone=`0`，linear ancestry=`0`。因此甲基是「提出與輔助分離」的額外訊息，不是單獨完成演化樹的替代物。
