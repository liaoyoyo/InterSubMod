- Task type：B — Comprehensive validation
- Scope：7 個 technical datasets、6 個 biological IDs、GRCh38 chr1-22
- 服務目標：G4 多樣本一致性與 reproducibility；G5 可被外部驗證
- Cancer mapping：
  - breast：HCC1395、HCC1395_DORADO、HCC1937、HCC1954
  - lung adenocarcinoma：H1437、H2009
  - melanoma：COLO829

Exact-coordinate fail-closed 診斷：

- 完整 topology-signature set 相等：2,691 / 2,825 = 95.26%
- topology-signature set 相容：2,714 / 2,825 = 96.07%

整體 primary-edge Jaccard 只有 0.198，不能表述為「精確邊高度一致」；但在 shared exact candidate universe 上，HCC1395_DORADO primary edges 被 HCC1395 包含的比例為 0.982751。這表示主要落差來自候選位點宇宙、region/partial-read 與可識別性，而非所有共享訊號的邊關係都完全不一致。

## Biological-ID dedup 與 exact label permutation

先將所有涉及 HCC1395 biological ID 的 HCC1395、HCC1395_DORADO technical-pair 指標做等權 macro-average，再對 6 biological IDs 枚舉全部 `6!/(3!2!1!) = 60` 個 3/2/1 分組。統計量為四個 within-group pairs 平均相似度減十一個 between-group pairs 平均相似度；one-sided exact p 為不小於觀察統計量的 assignment 比例。

| 指標 | within − between | one-sided exact p |
|---|---:|---:|
| candidate-site Jaccard | +0.000081 | 0.1000 |
| active-site Jaccard | +0.000095 | 0.0167 |
| W-site Jaccard | +0.000133 | 0.0167 |
| primary-edge Jaccard | +0.000199 | 0.1000 |
| exact-component Jaccard | 0 | 1.0000 |
| coarse topology TVD similarity | +0.077657 | 0.0167 |
| coarse topology JS similarity | +0.167955 | 0.0167 |
| latest VAF JS similarity | +0.037935 | 0.3000 |
| baseline VAF JS similarity | +0.039273 | 0.3333 |

Cancer-group profile 的清楚訊號在 coarse topology composition；VAF 與 exact edge-set Jaccard 並未得到相同程度的 group-level exact-permutation 支持。active/W 雖達最小可能 p 值 1/60，但絕對效應量只有約 10^-4，解讀時需同時呈現 effect size。

## 結論上限

本輪足以支持：

1. 方法能非常清楚辨識同一 biological ID；HCC1395 兩技術來源遠比其他樣本對接近。
2. 在可 1:1 對齊的局部區域，數學拓撲形狀高度重現；祖先關係為中高重現。
3. coarse topology composition 具有 cancer-group 層級訊號。

本輪不能單獨支持：

1. 每條精確邊都穩定；global primary-edge Jaccard 仍低。
2. 已確認唯一的 cellular clone 數量或生物演化祖先關係。
3. 已完成跨區域融合的唯一全域 clone tree。

因此最精確的表述是：「biological-ID specificity 很強、局部可辨識拓撲高度重現、整體結構 profile 接近；精確邊與跨區域融合樹仍需另行做 partial-order consensus、bootstrap 與衝突檢定。」
