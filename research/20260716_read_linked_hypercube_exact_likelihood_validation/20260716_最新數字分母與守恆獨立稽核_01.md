## 1. Scope、資料單位與分母規則

- Task Type：**B Comprehensive validation**。
- 研究目標：**G3 read-level epigenetic / mutation-state evidence、G4 多樣本一致性與 reproducibility、G5 外部可驗證**。
- 染色體：`chr1–chr22`；`638,259 raw` 與 `582,820 LongPhase-S PASS` 是上游 producer contract，從 `469,849` 才開始 chr1–22 biallelic scope。
- 樣本：7 technical datasets、6 biological samples。`HCC1395` 與 `HCC1395_DORADO` 是同一生物樣本的兩份 technical datasets，不能作為兩個獨立腫瘤個體。
- 跨 dataset 加總是 **dataset-record / dataset-region** 加總；不是跨樣本去重後的 genomic loci。

下列命令只使用 Python standard library，直接讀 current funnel receipt、canonical JSON 與 M0 independent verification；不 import producer、report builder 或 M0 aggregation code。

```bash
/usr/bin/time -v python3 - <<'PY'
import json
from pathlib import Path

root = Path('/big7_disk/liaoyoyo2001/InterSubMod')
funnel_path = root / 'research/20260716_read_linked_hypercube_exact_likelihood_validation/results/current_funnel_v1/current_funnel_receipt.json'

def total(rows, field):
    return sum(row[field] for row in rows)

fd = funnel['datasets']
cs = canonical['samples']
ma = m0['independently_recomputed_aggregate']
cr = m0['canonical_reconciliation']
cc = m0['categorical_conservation']
checks = {

    'funnel_each_pass': all(d['longphase_s_recalibrated_pass'] == d['branch_counts']['out_of_scope_non_autosomal'] + d['autosomal_biallelic_sSNV'] for d in fd),
    'funnel_each_auto': all(d['autosomal_biallelic_sSNV'] == d['branch_counts']['positional_singleton'] + d['branch_counts']['max_snv_excluded'] + d['branch_counts']['retained'] for d in fd),
    'funnel_sum_raw': total(fd, 'raw_clairs_records') == funnel['aggregate']['raw_clairs_records'],
    'funnel_sum_pass': total(fd, 'longphase_s_recalibrated_pass') == funnel['aggregate']['longphase_s_recalibrated_pass'],

    'funnel_sum_retained': total(fd, 'retained_sSNV') == funnel['aggregate']['retained_sSNV'],
    'region_each_tree': all(s['W_tree'] == s['W_primary'] + s['no_primary_lineage'] for s in cs),
    'region_each_primary': all(s['W_primary'] == s['complete_regions'] + s['incomplete_regions'] for s in cs),
    'region_each_topology_complete': all(s['complete_regions'] == s['topology_classes']['exact_and_topology_unique'] + s['topology_classes']['topology_unique_exact_multiple'] + s['topology_classes']['topology_multiple_exact_multiple'] for s in cs),
    'region_each_hidden_complete': all(s['complete_regions'] == s['hidden_classes']['hidden_zero'] + s['hidden_classes']['hidden_positive'] for s in cs),
    'region_each_hp': all(s['W_tree'] == sum(s['hp_h3'].values()) for s in cs),
    'region_each_C': all(s['W_primary'] == sum(s['C_bins'].values()) for s in cs),
    'region_sum_Wtree': total(cs, 'W_tree') == canonical['aggregate']['W_tree'],
    'region_sum_Wprimary': total(cs, 'W_primary') == canonical['aggregate']['W_primary'],
    'region_sum_complete': total(cs, 'complete_regions') == canonical['aggregate']['complete_regions'],
    'unit_sum_primary': total(cs, 'primary_units') == canonical['aggregate']['primary_units'],
    'm0_unit_dataset_status': all(x['n_hp_lineage_units'] == sum(x['selection_status_counts'].values()) for x in ma['by_dataset'].values()),
    'm0_unit_sum': sum(x['n_hp_lineage_units'] for x in ma['by_dataset'].values()) == ma['n_hp_lineage_units'],
    'm0_primary_eligible_capped': cr['n_primary_mutation_hp_lineage_units'] == cr['n_eligible_hp_lineage_units'] + cr['excluded_hp_lineage_unit_counts']['CAPPED'],
```

## 9. 問題分級

### 9.1 P1：目前數字錯誤

**0 個。** Funnel/canonical/M0 主要 counts、逐 dataset subtotals、互斥 partitions 與 eligibility conservation 均通過。

### 9.2 P1：最終結論 readiness blocker

1. **Full M2 尚未完成。** 現在沒有 chr1–22 × 7 datasets 的 lossless molecule extraction、partial-read exact enumeration、robust likelihood ranking terminal receipts，因此不能宣稱已得到 M2 後最終拓撲或 clone count。
2. **舊 backbone 數字若混入 current 主表會形成 P1。** `.canonical` 主分析是 `582,820 → 469,849`；同一 JSON 的 `.sensitivity` 是 `568,080 → 455,210`。兩者是不同 backbone，必須分表。`98,941、48,963、39,885、29,053` 等舊版本數字不可放入 current-v5 主結論。

### 9.3 P2：語意／provenance caveats

1. **Legacy capped label 差 4 regions。** 權威 `incomplete_regions=7,975`；legacy `has_capped` label=7,971，差異 4 全在 H2009。報告必須使用 7,975。
2. **M0 receipt 的 legacy invariant 名稱過強。** `eligible_plus_excluded_hp_units_positive` 並未真正驗證等式；deep verifier 已另行驗證 `64,973+8,021=72,994`，結果 PASS。
3. **`all_pass=true` 不等於 optimizer 全收斂。** M0 有 2,626 HP units `RANK_ABSTAIN_OPTIMIZER_NONCONVERGENCE`；`all_fits_converged=false`。它們不可併入 unique/tied。
4. **M0 原始 receipt 1.0.0 的歷史 runtime/source provenance 不完整。** Deep verifier 綁定 verification-time CPython/NumPy/SciPy 與 source hashes，但不能反向證明 census 歷史執行載入完全相同 bytes/runtime。
5. **Legacy C 定義衝突。** `C_region` 是 primary HP 候選樹數乘積，不是 read-group 數；若 M2 使用新的 structural-pattern/group C，必須改名並分欄。
