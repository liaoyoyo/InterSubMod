## 3. Step → Verify 正式順序

1. **Resource preflight**  
   → 驗證：`active_conflict_root_count=0`、`active_conflict_process_count=0`、`resource_gate_pass=true`、exit 0；可用空間至少保留300 GiB。禁止 `--ignore-resource-gate`。每個pilot stage、extraction batch、ranking batch開始前都重驗空間並保存不可覆寫的JSON＋SHA sidecar。

2. **PRE input identity**  
   → 驗證：42 distinct direct roles、7 BAM storage identities、35 non-BAM full SHA-256、21 BAM fixed chunks，`all_pass=true`。

3. **Freeze release**  
   → 驗證：10 scripts + 1 schema，共11檔；files `0444`、directories `0555`；154-task scope、B20/seed、scheduler全部寫入 manifest。

4. **Frozen verify-only — pre-pilot**  
   → 驗證：11檔 path/SHA/mode/inode、immutable manifest/PRE exact equal、runtime identity全通過。

5. **雙 direct pilot**  
   → 驗證：`HCC1395_DORADO chr6` 與 `H2009 chr2`，每個均 extraction、B0、B20；每個stage一份resource gate，合計6份；共四份 pilot verifier receipt 皆 `GO`。  
   → 額外驗證：每份B0/B20 verifier同時綁定該pilot的extraction gate與對應ranking gate；兩gate的manifest必須等於extraction child provenance，完整release identity必須相同。child receipt 的 extractor/ranker path 與 SHA 必須精確等於 release entrypoint；凍結的 `lossless_read_contract.py` 與 `hypercube_exact.py` 也必須重新雜湊等於 release manifest。

6. **Frozen verify-only — post-pilot**  
   → 驗證：pilot 期間11檔 snapshot 沒有漂移。Pilot 只是資源/執行 gate，不代替全量科學證據。

7. **Full extraction**  
   → 驗證：1份session gate＋11份batch gates，共12份；累積 `8,24,40,56,72,88,104,120,136,152,154`。前10次 checkpoint exit 3；最後 terminal exit 0。

8. **Full ranking**  
   → 驗證：同樣1份session gate＋11份batch gates，共12份；每個 child 綁定 exact extraction outputs；terminal receipt 綁定 full extraction receipt SHA；B20/seed不漂移。

9. **POST_COMPARE**  
   → 驗證：使用 release contract 中的 immutable PRE copy；42-role snapshot `exact_snapshot_equal=true`。

10. **Independent final verifier**  
    → 驗證：release、POST、兩段session chain、兩stage共24份resource gates、308 child receipts、candidate table、profile likelihood、conservation、winner/tie/topology全部獨立重算，exit 0，final receipt `0444`。

11. **Final numeric summary**  
    → 驗證：只從已驗證 terminal receipts、child receipts、candidate table及final verifier衍生；所有數字附unit、總分母、相對分母、絕對數與比例。

12. **Presentation freeze + HTML + browser QA**  
    → 驗證：builder/QA/summary code另行凍結；HTML不使用 `--allow-partial`或 `--overwrite`；QA run與verify-only使用同一份frozen QA producer；desktop/mobile/print、SVG、表格、摺疊定義、anchors、console、remote requests皆通過。

## 5. Partial-read 在此協定中的精確語意

一個 pattern `p ∈ {R,A,X}^k` 若有 `u` 個 `X`，完整 k 維立方體中概念上有 `2^u` 個 compatible completions。正式程式不會：

- 建立 `2^u` 個獨立樹世界；
- 建立所有 reads completion 的笛卡兒積；
- 遇到第一個可行 completion 就停止；
- 把 `X` 當成 R/A 各50%。

實作是將每個達structural minread的distinct partial pattern建成一個group：

```text
G(p) = {v : ((v XOR alt_mask) AND fixed_mask) == 0}
```

同一 `component × HP family × exact PS` 的所有groups必須在同一個最佳化問題中同時滿足：

```text
N ∩ G(p) != ∅
```

先求全域最小 `minimum-extra-state count h*`，再列舉所有同 `h*` 的optimal vertex sets。`h*`同時可能包含partial-compatible representative與connector，**不是真實hidden clone數**。非最小但可行的 `h*+1`、`h*+2` 結構不進入當前ranking。

後續 likelihood 使用所有informative molecule patterns（包含低於structural minread者）、BQ與error model對latent states進行marginalization。同一批reads導出的VAF不另外再加一次，以避免double counting。

## 6. 最終必須列出的數據

### Extraction/data funnel

- raw alignment → canonical molecule → exact sidecar joined → HP/PS primary eligible。
- call reasons R/A/O/D/S/L/X 數量與比例；全部守恆式。
- read-linked components；threshold 1/2/3/5；全體與每dataset、HP1/HP2。
- component-site k、effective observed-ALT k、`k<=12` exact coverage、`k>12` abstain。

### Partial/solver funnel

- full/partial distinct patterns、molecule projections、BQ-quality groups三種grain分開。
- `u=#X` 分布、conceptual `2^u`與active-universe effective completion分布。
- structural-retained、below-minread-but-scored、all-X-excluded molecules。
- solver complete/incomplete、`h*`分布、raw parent-edge trees `T`、distinct vertex sets `V`。

### Selection/topology

- `T=1/V=1`、`T>1/V=1`、`T>1/V>1`。
- unique first、tied first + topology consistent、tied first + topology inconsistent、abstain。
- coarse topology：single-only、sister-only、direct-only、sister+direct、ambiguous。
- exact vertex-set uniqueness與parent-edge uniqueness分開；同vertex set的edges若不可辨識，必須保留並列為`EDGE_NONIDENTIFIABLE`。
- 全體、每dataset、HP1/HP2分層均列絕對數、total denominator%、relative denominator%。

## 7. NO-GO / 停止條件

任一項發生就停止，不生成 FINAL HTML：

- resource gate非零衝突、使用ignore/bypass，或pilot root是空目錄／含非canonical preseed；僅允許已通過canonical extraction/B0/B20 stage的精確resume state；
- formal code不是從immutable snapshot執行；
- pilot main producer path/SHA不等於release entrypoint，或dependency snapshot漂移；
- checkpoint batch順序、canonical filename、chain head、child grant/completion任一不一致；
- 154 task pairs不完整、duplicate、orphan、preseed或child receipt schema/hash不一致；
- ranking未綁定exact extraction terminal receipt；
- PRE/POST輸入快照不相同；
- final verifier任一check失敗；
- 數字無法對應精確unit/分母，或有conservation mismatch；
- HTML使用live/unfrozen presentation code卻標成immutable FINAL。

## 8. 主張上限

完成後可以稱：

> solver-certified regional mutation-state candidate sets，以及在已宣告molecule/error/PS契約下，read patterns能區分的minimum-extra candidate vertex sets。

不可直接稱：

> 真實clone數、HP1與HP2的cell-level clone配對、唯一parent edge、或全腫瘤的完整演化史。

## 9. 威脅模型邊界

Release/session attestations證明持久化protocol、檔案內容與鏈結構一致，前提是沒有hostile same-UID actor。PRE/POST可偵測持續性drift，但不能密碼學證明執行期間沒有被短暫修改後復原，也不是trusted timestamp。
