# 方法學原始文獻與主張邊界

> **用途**：這些來源支持問題形式、計算困難度與癌症 bulk 資料的限制；本專案的數量結果仍只可由 frozen input、程式與 receipt 引用，不能由文獻代替。

## Directed hypercube Steiner 的理論位置

- Mahapatra、Narayanan、Narayanaswamy，*Parameterized and Approximation Algorithms for the Steiner Arborescence Problem on a Hypercube*（2021）。論文把 vertex 定義為 `{0,1}^m`、edge 定義為一次只增加一個 bit、root 為 `0^m`，並指出 hypercube 有 `2^m` vertices、問題為 NP-hard；同時提出依 terminal 數、Steiner node 數與 above-guarantee penalty 參數化的 exact／approximation 方法。來源：<https://arxiv.org/abs/2110.02830>。
- 本專案的差異：partial read 不是單一 terminal，而是 compatible subcube 的 **group terminal**；因此目前 symbolic MILP 是本專案契約下的擴充，不能直接宣稱原論文已證明 group 版本的完整效能界。

## Infinite-sites／perfect-phylogeny 假設

- Palacios 等人，*Enumeration of binary trees compatible with a perfect phylogeny*（2021）。論文說明 infinite-sites 下每個 mutation site 只發生一次，observed mutation pattern 會限制但通常不唯一決定相容 genealogy。來源：<https://arxiv.org/abs/2108.04849>。
- 本專案對應：`R→A` 的 monotone unit edge 是 infinite-sites／irreversible mutation 的工程模型；若 recurrence、loss、LOH 或錯誤造成違反，必須分層或 abstain，不能硬解讀為真實 lineage。

## Bulk cancer phylogeny 的資料限制

- PhyClone（2025）以 SNV allele counts、CNV 與 tumour content 推論 bulk cancer phylogeny 的 posterior distribution，而不是只用 raw VAF 決定單一樹。來源：<https://pmc.ncbi.nlm.nih.gov/articles/PMC12964358/>。
- Pairtree（2022）先以 copy-number 修正 VAF，得到 mutation subclonal frequency，再進行 tree inference。來源：<https://aacrjournals.org/bloodcancerdiscov/article/3/3/208/694689/Reconstructing-Complex-Cancer-Evolutionary>。
- Canopy2（2024/2025）展示 bulk VAF 可提供 mutation order，但 branch structure 仍可能錯；加入 cell-level evidence才補上另一種可辨識資訊。來源：<https://pmc.ncbi.nlm.nih.gov/articles/PMC12904911/>。
- PhISCS（2019）把 false positive、false negative、missing values 與 infinite-sites violation 放入整合目標，支持「缺值與錯誤應進生成／觀測模型，而非把 partial read 任意平均分配到邊」。來源：<https://pmc.ncbi.nlm.nih.gov/articles/PMC6836735/>。
- Sapling（2026）以多個同樣合理的 bulk phylogenies為出發點，將不確定解空間摘要成 backbone trees；這支持本研究保留所有同分候選與 topology ambiguity，而非強迫唯一化。來源：<https://pubmed.ncbi.nlm.nih.gov/41709239/>。

## 本研究可引用的結論

1. directed Boolean hypercube 是表達不可逆、一次一 mutation-step 的合理數學空間。
2. partial read 應視為 compatible-state group；每筆 read 在 likelihood 中只計一次並對未知位點邊際化。
3. exact solver 的 `gap=0` 只證明「固定 objective 下的數學最優」，不證明真實 clone ancestry。
4. 同一 bulk snapshot 的 read count、VAF 與 derived AF 不應被當成三份獨立 evidence 重複加權。
5. 在未納入 CN／LOH／purity 或獨立 cell-level／longitudinal evidence 前，輸出應稱 regional mutation-state candidate set，不應稱真實 clone 數或唯一 parent edge。
