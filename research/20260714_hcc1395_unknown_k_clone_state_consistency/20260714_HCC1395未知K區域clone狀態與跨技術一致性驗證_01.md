# HCC1395 未知 K 區域 clone-state 與跨技術一致性驗證

用 Assertion–Evidence + Identifiability ladder：**可以統整所有區域，計算「目前 read 證據至少需要幾種局部 mutation states」並找出候選異常區；但目前不能把這個數字直接稱為真實 clone 數，也不能唯一配對 HP1 與 HP2 成完整 clone。**（影響：高；信心：方法與計數高，生物 clone 解讀低）

## 1. 一句話結論

目前資料適合輸出每區域的 `K_state 下界／相容範圍／樹候選／品質門檻／跨技術重現`；不適合輸出單一「真實 clone K」或唯一 clone tree。HCC1395 與 DORADO 的 retained site 與 VAF 高度一致，但多狀態候選只有中低度區域重現，表示技術、覆蓋與截尾效應仍明顯。

## 2. 任務、假設與 claim 等級

- Task Type：B，comprehensive validation。
- 服務目標：G3（read-level 訊息）、G4（跨技術一致性）、G5（可外部驗證）。
- L1：直接計數或守恆結果，可作正式數據敘述。
- L2：在明列假設下的條件式推論，只能稱 candidate／lower bound。
- L3：需新實驗驗證的生物假說，不作目前結論。

關鍵假設與限制：

1. `R/A/X` pattern 的 R/A 呼叫與 HP tag 暫視為正確；尚未將 base、mapping、HP-switch error 放入 likelihood。
2. 現有 `obs_subreads` 只保存 count ≥ `MINREAD=3` 的 pattern；count 1–2 被截尾。
3. `X` 代表該 read 未覆蓋該位點；不是 REF，也不是缺失 clone。
4. HP1 與 HP2 是 bulk read 的兩個邊際分布，沒有 cell barcode 可指出哪兩條 homolog 來自同一細胞。
5. 區域 selected sSNV 相同的局部 genotype 仍可能對應多個不同的全基因組 clone。

## 3. 三個不同的 K 不可混用

| 名稱 | 單位 | 可否由目前資料確認 | 正確意義 |
|---|---|---:|---|
| `K_h,state` | region × HP | 條件式可算 | 該 HP 的 retained R/A/X pattern 至少需要幾種完整 R/A state 解釋 |
| `K_joint,state` | region × HP1/HP2 coupling | 只能給範圍 | HP1 與 HP2 局部狀態可形成幾種 diploid genotype pairing |
| `K_clone,bio` | sample/cell population | 不可辨識 | 真實細胞 clone 數；可大於局部 genotype 數 |

因此：`T=1` 不是 `K=1`；hidden Steiner node 不是已觀測 clone；`K_h,state≥2` 也只代表 retained patterns 互相衝突、至少需兩種相容狀態，不等於已確認 subclone。

## 4. 實際計算方法

### 4.1 每個 HP 的最小狀態數

把每個 retained `R/A/X` pattern 當作部分指定的二元狀態。若兩個 pattern 在共同覆蓋位點上出現 `R` 對 `A`，兩者不能由同一完整 state 解釋。

建立 pattern conflict graph 後：

\[
K_{h,\min}^{ret}=\chi(G_{conflict})
\]

也就是 conflict graph 的 exact chromatic number。因為每個 color class 都能共同補成一個完整 R/A state，所以這是 retained table 下的精確最小 state cover。

另以 capacitated bipartite max-flow 計算 retained aggregate counts 最多可支持多少不同完整 states，得到 `K_h,max^ret`。此最大值只是 partial read 的組合上限，不是生物 clone 上限。

### 4.2 雙 HP 的條件式範圍

若 HP1、HP2 的局部支持集合大小為 `r1`、`r2`：

\[
\max(r_1,r_2)\le K_{joint,min}\le r_1+r_2-1,
\qquad K_{joint,max}\le r_1r_2
\]

第一個區間表示：即使兩側 state catalog 已知，未知的 mixture weights 仍可能使最稀疏 pairing 需要不同數量的 joint states。`r1 × r2` 只是所有組合皆存在時的局部組合上限。若不同 biological clones 可共享相同局部 genotype，真實 `K_clone,bio` 沒有可由單一區域給出的有限上限。

### 4.3 證據階梯

1. E0：retained patterns 不要求兩種 mutation states。
2. E1：partial retained patterns 要求至少兩種 mutation states。
3. E2：所有 retained patterns 都是 full-span，retained state catalog 可直接列出。
4. E3（未完成）：uncensored per-molecule table + error model + PS + allele-specific CN。
5. E4（未完成）：另一技術資料與 held-out methyl／SNV evidence 重現。
6. E5（未完成）：single-cell／cell barcode 或其他 cell-resolved 確認。

## 7. 為何 high site/VAF concordance 仍不能確認 clone 結構

1. VAF 是相同 read mixture 的 marginal；它和 read-state 不是完全獨立證據。若先用 read states 建模，再把同一批 reads 的 VAF 當獨立權重，會 double count。
2. 高 site overlap 不保證相鄰位點被相同長 read 共同覆蓋，也不保證 PS、HP switch、partial mask 相同。
3. HCC1395 5 kHz 分支的 tree/read evidence 來自 5 kHz BAM，但 caller VCF/FORMAT AF 來自另一套標準 ONT BAM；這是 hybrid candidate-transfer 設計，不是同一 BAM 的 end-to-end 重跑。
4. 兩份資料使用同一 SEQC2 CN 檔，CN label 一致不能作 cross-tech 獨立驗證。
5. Canonical `L3_methyl.status=not_evaluated`；且 HCC 為 `C+m/C+h`、DORADO 為 `C+m`，不能直接把目前 methyl availability 當 clone confirmation。

## 8. 可以如何真正估 unknown K

1. Lossless read table：重新由 BAM/sidecar 輸出每個 `region × HP × PS × read_id` 的 R/A/X、MAPQ、base quality、strand、MM/ML，保留 count 1、2。
   → 驗證：所有 pattern counts 加總等於 callable read identities；每位點 marginal 重建 site ledger。
2. Error-aware per-HP mixture：對 `K=1..Kmax` 配適

   \[
   P(y\mid m,h)=\sum_g\theta_{h,g}P(y\mid g,m,\epsilon)
   \]

   用 BIC／held-out likelihood／bootstrap stability 選「最小足夠 K」，並保留所有近似同分解。
   → 驗證：simulation recovery、parameter bootstrap、count 1–2 sensitivity。
3. Tree constraint：只允許與 read-supported state／unit-Hamming mutation 相容的候選樹；輸出候選集合與 posterior，不強迫唯一樹。
   → 驗證：所有 observed state 可被候選樹解釋；capped 與 incomplete 分開報。
4. Cross-HP coupling：以 `Q_ab` 配對兩側 marginal mixture，分別報 `K_min unique?`、`support unique?`、`weights unique?`。
   → 驗證：row/column sums 精確重建兩側 θ；列出自由度與所有近似同分 coupling。
5. CN/purity：加入 HP-oriented allele-specific CN、purity、mutation multiplicity 與 subclonal CNA；coarse gain/LOH label 只作 exclusion screen。
6. Methyl held-out：只用同一 read identity 的 genotype × methyl vector，在共同 `C+m` 定義與 calibration 後檢查同 genotype 是否可穩定分群；不先用 methyl 建樹再稱其為獨立驗證。
7. Cross-technical／cell-resolved validation：HCC1395 與 DORADO 先測技術重現，最終仍需 single-cell、barcode 或其他 cell-level evidence 確認 biological clone pairing。

## 9. 特殊現象的分類方式

逐區表已保留以下旗標，可用來建立候選清單：

- 高 `K_mut,min` 且跨技術重現：優先 subclone-state candidate。
- 高 `K_mut,min` 但只出現在單一技術資料：優先檢查 basecaller、mapping、HP switch 與 MINREAD sensitivity。
- 多 PS：不得直接合併成一棵連續 haplotype tree。
- CN gain／LOH／loss：需 allele-specific CN 與 multiplicity，避免把 CNA 當 clone mixture。
- 無 full-span read：只能報 partial-state lower bound。
- capped／candidate-set incomplete：不能用目前 `T` 或 Topo 數聲稱候選全集。
- 同 genotype methyl 分群：只列 orthogonal hypothesis，須先排除 coverage、read age、strand、basecaller batch。
