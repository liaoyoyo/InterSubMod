# HCC1395 734 個 singleton ALT 甲基多群位點重算摘要

## TL;DR

Authority v7 重算確認：HCC1395 共 8,279 個 positional-singleton sites，8,074 個可評估，其中 734 個通過 M1 stable multigroup；734/8,279 = **8.8658%**（Wilson 95% CI 8.2724–9.4973%），可評估分母為 734/8,074 = **9.0909%**。這支持「ALT reads 內有穩定甲基多群」，不支持「734 個已確認 cellular subclones」。

## 重算結果

| 層級 | 數量 | 比例/意義 |
|---|---:|---|
| Positional-singleton sites | 8,279 | 完整 HCC1395 母體 |
| M1 可評估 | 8,074 | 97.5239% |
| M1 stable multigroup | 734 | 8.8658% of all；9.0909% of evaluable |
| K=2 | 651 | 88.6921% of 734 |
| K=3 | 73 | 9.9455% |
| K=4 | 9 | 1.2262% |
| K=5 | 1 | 0.1362% |
| M2 PASS | 2 | 0.02416% of 8,279；不可把高度篩選後的 2/2 當母體比例 |

8,279 的完整分割是 `734 M1 flagged + 7,340 evaluable-not-flagged + 205 not-evaluable`。205 個中 203 個 ALT reads 不足，2 個 distance 不完整。

## 為何可以說 734 個有「穩定性與 null support」

- 734/734 的 `stable_null_multigroup=True`、`unstable=False`。
- 10 個 seeds 中，modal K 至少出現 7 次；中位數為 10/10。
- 734/734 的 modal-assignment minimum ARI = 1.0。
- K=2–5 共產生 **828 個通過的 recursive splits**；828/828 的 observed between/within ratio 都高於 40 次 column-shuffle null 的第 95 百分位。
- 828 個 split 的 ratio 中位數 1.5654，observed/null95 中位數 1.1166；最小 observed ratio 1.3006。

重要精度限制：40 次 shuffle 下，另行計算的 empirical rank p 最高可為 3/41 = 0.0732，即使 observed 已高於插值式 null95。因此 HTML 應寫「通過 operational null95 gate」，不應改寫為「每個 split 的古典 p<0.05」。

## 舊檔與 authority v7 對帳

- 兩份檔案的 58 個欄位相同，都有 8,279 rows，8,279 個 site keys 完全相同。
- M1/M2/K 計數與分類無差異。
- 只有一個非關鍵 ARI 浮點表示差：`0.2961179840331525` vs `0.29611798403315254`，絕對差約 4e-17，不影響分類。
- Authority summary 的 39/39 checks PASS，`_SUCCESS.json` 為 `pass=true`。

## Claim ceiling

可說：「734 個 HCC1395 singleton sites 有可重現的 focal-ALT read-level 甲基多群；其中 2 個通過已量測八軸 M2 guardrails。」

不可說：「734 個是 734 個細胞 subclones」、「每群都是不同突變 clone」、「距離 dendrogram 就是突變祖先樹」或「已確定父子關係」。

python3 - <<'PY'
import csv, gzip, json, collections
audit = '/big7_disk/liaoyoyo2001/big7_disk_output/synthesis/observation_workspaces/20260715_all_ssnv_focal_alt_multigroup_cooccurrence_validation/positional_singleton_methyl_multigroup_audit_v2_source_authority_v7/positional_singleton_site_audit.tsv.gz'

flagged = [r for r in rows if r['m1_status'] == 'FLAGGED']
keys = {(r['chrom'], int(r['pos'])) for r in flagged}
print(len(rows), sum(r['m1_evaluable'] == 'true' for r in rows), len(flagged))
print(collections.Counter(int(r['coarse_ng']) for r in flagged))

with gzip.open(assign, 'rt') as f:

        if 'HCC1395' not in line:

        if obj['dataset'] == 'HCC1395' and (obj['chrom'], int(obj['pos'])) in keys:
            objects.append(obj)
splits = [s for obj in objects for s in obj['coarse_split_trace'] if s['passed']]
