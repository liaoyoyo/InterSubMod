## 2. 結論先讀

1. **M2 兩個例子已可直接展示。** `chr14:86,272,476 A>T` 與 `chr22:47,466,517 A>G` 均有完整原始矩陣、v10 M1 assignment、exact-join audit、靜態 read×CpG PNG，以及已通過 browser QA 的 HTML heatmaps。

## 6. UPGMA 是否可重建：精確判定

### 可以重建的部分

1. 以 assignment 的 `all_after_peel_read_ids` 從 Bernoulli matrix 取 focal-ALT after-peel 子矩陣。
2. 對角歸零，`D = max(D, Dᵀ)`。
3. `linkage(squareform(D), method="average")` 建立 deterministic hierarchy。
4. 用 `coarse_labels_all_after_peel` 著色；用 `coarse_split_trace` 標記哪些節點通過 observed ratio、null threshold 與 minimum group gate。
5. 用 `core_reads`/`labels` 繪製不含 `other/outlier` 的主要群；同時保留完整 after-peel 圖以顯示被 quarantine 的 reads。

### 不能直接冒充 M1 的既有檔

每個 region 都有：

- `clustering/linkage_matrix.csv`
- `clustering/tree.nwk`
- `clustering/leaf_order.txt`
- `clustering/significance.json`

這些檔可用來展示上游 whole-region/legacy context，但沒有以 v10 focal-ALT M1 assignment 作為 leaf population 與 gate contract。尤其 chr14 M2 locus 的 legacy tree 是 139 leaves，而 M1 core 是 108 reads，證明兩者不是同一分析母體。

### 可重現性 caveat

資料與演算法足以重建同一 hierarchy 與 M1 labels；若需要 byte-for-byte 相同的 linkage row order，應使用 source-locked Python/SciPy 環境，因完全相等距離的 tie-breaking 可能隨 library version 改變。新 HTML 完成後至少驗證：leaf read-id 集合、每群數量、split child sizes、observed ratios 與 v10 trace 一致。
