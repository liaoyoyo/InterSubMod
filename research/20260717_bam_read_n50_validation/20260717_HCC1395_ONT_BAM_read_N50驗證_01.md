# HCC1395 5 kHz ONT BAM primary-read N50 驗證

> **結論**：HCC1395 5 kHz tumor BAM 的 primary-record read N50 為 **21,047 bp（21.0 kb）**，相當於單一 150 bp read 長度的 **140.31 倍**；投影片可寫「約 140 倍」。  
> 任務類型：B — Comprehensive validation；服務 G3（read-level evidence）與 G5（外部可重算）。

## 1. Claim contract

本次只驗證下列 sample-specific claim：

> HCC1395 5 kHz tumor **aligned BAM** 中，排除 secondary（`0x100`）與 supplementary（`0x800`）後，primary records 的 base-weighted read N50。

這不是：

- raw POD5／FASTQ library N50；
- 所有 ONT 資料的一般 N50；
- read-count median；
- 同一細胞或同一 clone 的跨距。

## 3. N50 定義與實作

對每個通過 filter 且 `l_qseq > 0` 的 BAM record，以 read length `L` 貢獻 `L` 個 sequenced bases。將 read length 由長到短累積，第一次達到所有 retained bases 50% 的 length 即為 read N50。

Filter contract：

```text
exclude_flags = 0x900 = secondary 0x100 OR supplementary 0x800
duplicate、QC-fail、unmapped primary record 不另行排除
```

計算程式：

- Source：`InterSubMod/tools/bam_primary_read_n50.cpp`
- Source SHA-256：`65bbd7349b8c8f508e4cc66f2b15b536384356fb33d5d456c7911c4de3d4b923`
- HTSlib：1.18
- `samtools`：1.17-25-geb3be52（使用 HTSlib 1.18）
- g++：11.4.0

編譯：

```bash
g++ -O3 -std=c++17 \
  InterSubMod/tools/bam_primary_read_n50.cpp \
  -o /tmp/bam_primary_read_n50 \
  $(pkg-config --cflags --libs htslib)
```

## 6. 150 bp 倍數的正確口徑

投影片主句比較單一連續 read：

```text
single-end ratio = N50_bp / 150 bp
                 = 21,047 / 150
                 = 140.3133
```

若只比較一個 `2×150` read pair 的總 called bases，可另算：

```text
paired called-base ratio = N50_bp / 300 bp
                         = 21,047 / 300
                         = 70.1567
```

但 `2×150` 不等於一條連續 300 bp read；兩端之間仍有 insert span 與未定序 gap。因此主句用 `/150`，註腳才補 `/300` 的純算術值。

## 8. 投影片可用句

> **本研究 HCC1395 5 kHz tumor BAM 的 primary-record read N50 為 21.0 kb，約為一條 150 bp short read 的 140 倍。**

建議註腳：

> `Exact N50 = 21,047 bp；排除 secondary/supplementary（0x900）；BAM-based，不是 raw POD5/FASTQ library N50。若只以 2×150 的 300 called bases 算術比較則約 70 倍，但 paired-end 不是一條連續 300-bp read。`

## 9. 限制

1. Aligned BAM 可能不包含 raw library 的所有 reads，因此不得改稱 raw FASTQ／POD5 N50。
2. N50 會隨 sample、DNA extraction、library preparation、chemistry、basecaller 與 alignment pipeline 改變。
3. Read length 表示 same-molecule physical span，不表示 cell identity。
4. 本輪 headline 只對 HCC1395 5 kHz tumor BAM 成立；paired normal 與其他 BAM 不混入主句。

> **Scope note**：這是單一 canonical BAM 的完整全檔統計，加上 pilot 的獨立演算法驗證；不是所有 ONT 資料或所有癌症樣本的泛化結論。
