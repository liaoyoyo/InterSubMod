0.TL;DR

三個 cycle 連續驗證 methyl-augmented FP filter，依序回答三個問題：

  1. Cycle 1 (HCC1395 internal)：把 v1.0 cell-gated pilot (ΔF1 +0.00242 marginal) 改為 global LR 後，能否在 HCC1395 達到 Cohen 小 effect？ — YES, +0.02236 (9.24× v1.0)
  2. Cycle 2 (cross-sample n=5)：cycle 1 filter 是否 generalize 到 4 個新樣本？ — NO, transfer 4/5 NEGATIVE, re-fit 3/5 ≈0
  3. Cycle 3 Step 1 (gate rule)：能否寫出 production rule 避免在不適用樣本造成 F1 regression？ — YES, qualifying mean +0.01499 PASS / high-F1 skip drift=0 PASS

核心機制發現：filter 不是 universal — 它 caller-F1-headroom-bounded。只在 caller F1 < 0.80 AND FP density > 10% 樣本 work。3/4 新樣本 caller F1 > 0.83 + FP density < 4%，filter 無 headroom；唯一 generalize-positive 是 HCC1937 (caller F1 = 0.37)。

4.核心機制 — Caller-F1-headroom-bounded

Cycle 2 的 4/5 NEGATIVE 不是 methylation 失敗，而是 filter 在 caller F1 接近 ceiling 的樣本無 work room。下圖把 5 樣本投影到 (caller F1, FP density) 平面：

機制解讀：5 樣本 caller F1 與 FP density 完全同向（高 F1 必伴隨低 FP density）。原因是 caller F1 = 2·TP / (2·TP + FP + FN)；F1 高 ⇒ FP / TP 比小。所以 AND gate（兩條件同時滿足）冗餘但保守正確 — 即使單一條件變動也不會把 high-F1 樣本誤套 filter。

為什麼 Methylation 不是 fail 的原因

  • Cycle 1 LR 中 HPFineF coef +0.75 排第 5 位，主導為 caller_af (+3.44) / loh_inner_flag (+1.46) / Coverage_Multiple_imp (+1.27) / NG (+1.07)。
  • H_C1_6 證實 V3F/V5/V6 三 BAM 提取的 methylation 特徵跨版本一致 (max_var 0.00055)。
  • 4 新樣本 NEGATIVE 主因 = caller_af coef +3.44 對 HCC1395 AF 分布 overfit（HCC1954 transfer 災難根因）+ 高 F1 樣本 LR 找不到 useful τ。
  • Methylation 訊號弱但 BAM-invariant + 跨樣本 effect 也對 — 不是 cycle 2 fail 的 driver。

5.Cycle 3 Step 1 — Gate Rule (Caller-F1-headroom-aware)

Cycle 2 機制揭示後，cycle 3 的設計目標是：寫一條 production rule 避免在不適用樣本造成 F1 regression，同時保留 qualifying subset 的 uplift。Rule 設計：

IF caller_F1 < 0.80 AND FP_density > 0.10:
    apply per-sample re-fit (cycle 1 LR L2 C=1.0, 5-fold OOF, swept τ)
ELSE:
    skip filter (caller F1 preserved)
