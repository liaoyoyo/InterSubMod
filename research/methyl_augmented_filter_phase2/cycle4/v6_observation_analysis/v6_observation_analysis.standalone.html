8.Cycle 5+ Hypothesis Inputs (觀察 → 新方向)

觀察驅動的 4 個新 hypothesis candidates (給 user inject-hypothesis 評估)

H_NEW_1: loh_inner_flag-aware filter (G3 Two-hit relevance)

觀察證據: loh_inner_flag 5/5 cross-sample positive AUC 0.54-0.72 + Cohen's d 0.37-1.11；圖 7 顯示 caller_af 與 HPFineF 在 LOH Inner zone 表現增強 → LOH stratified filter 可能比 global filter 更 robust。

Pre-reg 候選: LOSO-trained LR with LOH-stratified intercepts → ΔF1 提升 vs cycle 1 sample-level baseline。

H_NEW_2: HPFineF cross-sample marker (G1 Per-CpG×HP×ALT + G2)

觀察證據: HPFineF 4/5 samples AUC > 0.50 same direction，是唯一 cross-sample robust methylation feature。其他 4 個 methylation features 為 caller_af L2 ridge-split 副產品。

Pre-reg 候選: HPFineF + loh_inner_flag 2-feature LOSO-trained LR → 比 caller_af-dominated cycle 1 更 sample-level robust。

H_NEW_3: chr8 hotspot zone-specific filter (G3)

觀察證據: 圖 6 chr8 FP marker rate 突出，V6 未排除；HCC1395 chr8 hotspot LOH+HPSig 7.4× FP enrichment (記憶: project_hcc1395_chr8_hotspot.md)。

Pre-reg 候選: chr8 specific gate (`if chr8 AND high FP marker rate → strict τ`) — zone-specific filter design。

H_NEW_4: caller_af 取消使用 + 新 axis 探索 (G5 redesign)

觀察證據: caller_af AUC 跨樣本 0.20-0.92 (3/5 反向) — 是 LOSO 災難主因。Cycle 5+ 應 deprioritize caller_af 作為 LR feature。

Pre-reg 候選: 完全移除 caller_af 後，2-3 feature LR (loh_inner_flag + HPFineF + V6_NG) LOSO 是否 ΔF1 > 0？

給用戶決策的最簡建議

建議優先測 H_NEW_2 + H_NEW_4 (~1 hr 兩個 LOSO 跑):
- H_NEW_2: 2-feature (HPFineF + loh_inner_flag) LOSO → 看是否 cross-sample 仍有 signal
- H_NEW_4: drop caller_af LR LOSO → 確認 caller_af 是 LOSO 災難主因 (sanity check)

這兩個是 fastest test，可在 ~1 hr 內回答「LR filter 在沒 caller_af 過擬合的情況下，cross-sample 是否仍有 robust signal」這個核心問題。
