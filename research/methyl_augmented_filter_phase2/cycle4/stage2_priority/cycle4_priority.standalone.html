9.Stage 2b — Trial Scope 建議 + 4 H Pre-reg

A Trial A — Interaction LR + 5 Python 新 features (~1.5 day) — 建議優先
內容對應
Baseline LR (cycle 1 10-feature)reference
Interaction terms: caller_af × 5 methyl (HPMergedDelta / HPFineF / NME_imbalance / Epipoly_Delta / ClusterPermanovaF)O3 → H_C4_INT
5 Python 新 features (F1-F5) 加入 LRF1/F2/F3/F4/F5 → H_C4_NEW_FEAT
LRT vs baseline LRintegral significance test
Per-feature AUC + Cohen's dindividual contribution

Decision after Trial A:

  • H_C4_INT PASS AND H_C4_NEW_FEAT PASS → 進 Trial B
  • 1 of 2 PASS only → Trial B optional
  • 全 FAIL → cycle 4 結論 final NEGATIVE
B Trial B — Random Forest + XGBoost + SHAP (~2 day) — Conditional on A
  • sklearn RandomForestClassifier (n_estimators=500)
  • xgboost.XGBClassifier (learning_rate=0.1, n_est=500)
  • 5-fold StratifiedKFold OOF (seed=42)
  • SHAP per-feature contribution
  • 對應 H_C4_NL: ΔF1 over L2 LR > +0.005 = PASS
C Trial C — Per-zone heterogeneous LR (~2 day) — Conditional on B
  • 5 zones: Z-OCH / Z-GL / Z-AUTO / Z-CHR8 / Z-other
  • Per-zone L2 LR + swept τ (含 5 Python 新 features)
  • Aggregate ΔF1 + zone-stratified Wilcoxon
  • 對應 H_C4_ZONE: ≥3 zones ΔF1 ≥ +0.005 = PASS
