  • NG distributional shift
  • Sample-specific FP density shift (HCC1954 3.4% vs HCC1395 14%)

5.為什麼 HPFineF coef +0.75 卻是 vestigial？

L2 ridge-split 機制（淺顯解釋）

L2 regularization 在多個相關特徵之間「分攤」coefficient。如果 HPFineF 與 caller_af 有部分共變異（HPFineF ≈ f(caller_af) + ε），L2 會把 caller_af 的權重「拆」一部分給 HPFineF，讓兩者 coef 都不會太大。

這時 HPFineF 看起來「有 coef +0.75」但其實是 caller_af 的 echo — 把 5 個 methylation features 全 drop 後，caller_af + 其他 features 立刻重新分配權重 capture 同訊息（drop +0.00065 incremental 證明）。

這正是 cycle 1 step 5c 主報告早就觀察到的「methylation 訊號實為 caller_af proxy」現象。

類比: 像是水池中接 5 條水管，其中 3 條共用同一個水源。看每條水管「流量」會以為都在貢獻，但拆掉那 3 條後，剩下 2 條水管自動加大流量，總水量幾乎不變。

6.Mechanism Quadrant — 為什麼只 HCC1395 + HCC1937 work？

5 樣本完全按「caller F1 與 FP density 同向」分布：高 F1 必伴隨低 FP density（這是因為 F1 = 2·TP / (2·TP+FP+FN)；F1 高 → FP/TP 比小）。所以 caller-F1 + FP-density 兩條件其實是 highly correlated，AND gate 冗餘但保守正確。
