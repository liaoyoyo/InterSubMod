# 文獻驗證綜合報告：單分子甲基化分析 × ISM 實證數據

## 摘要

本報告對 60+ 篇癌症甲基化文獻提出的 4 大假說進行系統性驗證，使用 InterSubMod 的 **340,173 區域 × 7 樣本**實證數據（含 333,452 TP + 6,721 FP），以及 5,360 區域的 raw read-level 甲基化數據。

### 關鍵結論速覽

| 假說 | 文獻預測 | ISM 驗證結果 | 判定 |
|------|---------|-------------|------|
| **L1** 方向性 ASM | TP 有系統性 ALT>REF 甲基化 | TP 完全隨機（49.4% ALT>REF）| **NEGATIVE** |
| **L2** PMD 分層 | PMD 區域甲基化異質性更高 | **確認**（CpG var 0.118 vs 0.072, p<1e-100）| 生物學 POSITIVE，判別 NEGATIVE |
| **L3** Normal baseline | 扣除正常甲基化降低 germline confound | BAM 可用，**Phase 2A 可行** | **FEASIBLE** |
| **L4** fCpG 選擇 | 高變異 CpGs 更有判別力 | TP/FP 無差異（p=0.77） | **NEGATIVE** |

---

## 1. L1 方向性 ASM（epiTRACERx / Gaiti et al.）

### 文獻假說
epiTRACERx (Basilicata, Nature 2024) 和 Gaiti et al. (Nature Biotechnology 2019) 報告在體細胞突變位點觀察到 allele-specific methylation (ASM)，ALT allele 的甲基化模式與 REF 不同。

### 驗證結果

#### 方向性分析（Part B, n=5,360 sampled regions）

```
TP signed_delta (ALT-REF):  mean = -0.0003  (p=0.854, not significant)
FP signed_delta (ALT-REF):  mean = -0.0205  (p=1.16e-14, highly significant)

TP 方向比例: ALT>REF = 49.4%, ALT<REF = 50.6%  ← 完全隨機
FP 方向比例: ALT>REF = 44.3%, ALT<REF = 55.7%  ← 偏向 REF>ALT
```

#### PERMANOVA Delta（Part A, n=340,173 全域）

```
TP AlleleDelta:  mean = 0.0200  (allele-based distance difference)
FP AlleleDelta:  mean = 0.0312  ← FP 更高
Mann-Whitney p = 4.71e-04, Cohen's d = -0.19 (FP 方向)
```

#### |ASM| 判別力

```
|ASM| AUC(FP>TP) = 0.5353  ← 微弱，且方向反轉（FP > TP）
TP |ASM| per CpG = 0.0416
FP |ASM| per CpG = 0.0699  ← FP 的 ASM 強度是 TP 的 1.7 倍
```

### 解讀

文獻與 ISM 結果並不矛盾，而是**適用場景不同**：
- epiTRACERx 觀察的是 **driver mutations**（TSG promoter / CpG island）的 ASM
- ISM 數據中的 TP 主要是 **passenger mutations**，不預期有功能性 ASM
- FP（germline variants）有顯著 ASM → germline mQTL / imprinting 的已知現象

**判定：L1 NEGATIVE（用於 TP/FP 判別）**

---

## 2. L2 PMD 分層（Berman / Landau / Gaiti）

### 文獻假說
Partially Methylated Domains (PMDs) 是腫瘤特有的大規模低甲基化區域，文獻預測 PMD 內的 CpG 應顯示更高的表觀遺傳異質性，有利於亞克隆追蹤。

### 驗證結果（使用 mean methylation 0.3-0.7 作為 PMD proxy）

#### 文獻預測確認：PMD 區域確實有更高 CpG 變異度
```
CpG variance: PMD-like = 0.118 vs Non-PMD = 0.072 (p = 1.13e-140)
High-var CpG fraction: PMD-like = 69.6% vs Non-PMD = 46.2% (p = 3.91e-102)
```

#### 但 PMD 區域不改善 TP/FP 判別
```
|ASM| AUC by zone:
  Hypomethylated (<0.3):    AUC = 0.505  ← 完全無效
  PMD-like (0.3-0.7):       AUC = 0.586  ← 微弱
  Fully methylated (≥0.7):  AUC = 0.622  ← 反而更好
```

#### PMD 區域 FP 的 ASM 最強
```
PMD-like zone:
  TP signed_delta = +0.005
  FP signed_delta = -0.041 (p = 6.46e-07)
  → FP 在 PMD 區域有最強的方向性 ASM
```

### 解讀

PMD 的高異質性是**生物學事實**，但這個異質性在 TP 和 FP 中都存在，因此：
- **不能用 PMD 分層來改善 TP/FP 判別**
- PMD 區域的 FP ASM 更強，可能對應 germline variant 的 mQTL 效應
- 反而是 Fully methylated 區域（非 PMD）的判別力略高

**判定：生物學 POSITIVE（PMD 異質性確認），應用 NEGATIVE（不改善判別）**

## 3. L3 Normal Methylation Baseline（Phase 2A）

### 文獻假說
扣除 matched normal 的甲基化 baseline，可以消除 germline ASM confound，凸顯 tumor-specific 甲基化變化。

### 可行性評估

#### Normal BAM 可用性
```
所有 7 個樣本的 Normal BAM 均存在且包含 MM/ML 甲基化標籤：

HCC1395:       /big8_disk/data/HCC1395/ONT_5khz_simplex_5mCG_5hmCG/HCC1395BL.bam (140G)
COLO829:       /big8_disk/data/COLO829/ONT_PAO/PAO33946.bam (117G)
H1437:         /big8_disk/data/H1437/ONT/H1437BL.bam (symlink)
H2009:         /big8_disk/data/H2009/ONT/H2009BL.bam
HCC1937:       /big8_disk/data/HCC1937/ONT/HCC1937BL.bam
HCC1954:       /big8_disk/data/HCC1954/ONT/HCC1954BL.bam
HCC1395_DORADO: /big8_disk/data/HCC1395/ONT_Dorado/HCC1395BL.bam
```

#### L1 結果提供的支持證據
```
FP signed_delta = -0.0205 (p=1.16e-14)  ← FP 有系統性 germline ASM
FP |ASM| = 0.0699 vs TP |ASM| = 0.0416  ← germline ASM >> somatic ASM (1.7×)
```

**如果扣除 normal baseline，預期效果**：
1. germline ASM 被抵消 → FP 的 |ASM| 下降
2. somatic-specific ASM 被保留（如果存在）
3. TP/FP 在甲基化維度的可區分性可能改善

### 實作路徑
ISM 的 C++ `ReadParser.cpp` 需要修改以支援：
1. 同時讀取 tumor + normal BAM 在相同區域
2. 計算 normal baseline per CpG
3. Tumor methylation - Normal baseline → residual methylation
4. 使用 residual 計算距離和統計

### 風險
- Normal BAM 的覆蓋率可能不均勻 → 某些 CpG 位點 normal baseline 不可靠
- Normal 本身可能有 germline heterogeneity（但應遠低於 tumor）
- 計算量翻倍（需讀兩個 BAM）

**判定：FEASIBLE — 建議作為 Phase 2A 優先實作**

## 4. L4 fCpG 選擇（EVOFLUx / Moran-Gaiti）

### 文獻假說
EVOFLUx (Moran, Nature Biotechnology 2023) 提出 fluctuating CpGs (fCpGs) 是追蹤腫瘤亞克隆的最佳標記。只使用高變異 CpGs 來計算距離，應比使用全部 CpGs 更有判別力。

### 驗證結果

```
CpG variance distribution:
  TP mean CpG variance = 0.0828
  FP mean CpG variance = 0.0825
  Mann-Whitney p = 0.767  ← 完全無差異

High-var CpG fraction (fCpG proxy):
  TP = 51.0%
  FP = 53.0%  ← 幾乎相同
```

### 解讀

fCpG 概念在 EVOFLUx 中用於追蹤**已知亞克隆結構的動態變化**（longitudinal study），而非用於區分 TP/FP somatic variants。

在 ISM 的場景中：
- TP 和 FP 區域有幾乎相同的 CpG variability profile
- 篩選高變異 CpGs 不會改善判別，因為 TP 和 FP 的 fCpG 比例相同
- fCpG 選擇可能對 **subclone detection**（HPFineNGroups）有幫助，但不對 **TP/FP filtering**

**判定：NEGATIVE（用於 TP/FP 判別）**

---

## 5. 綜合分析：為什麼文獻正面但 ISM 負面？

### 核心差異：任務定義

| 維度 | 文獻研究 | ISM 應用 |
|------|---------|---------|
| 目標 | 腫瘤 vs 正常細胞區分 | TP somatic vs FP germline 區分 |
| 甲基化來源 | 腫瘤特異性表觀改變 | 兩者都有甲基化（germline ASM 更強）|
| 突變類型 | Driver mutations（功能位點）| 全部 somatic SNVs（90%+ passenger）|
| 分析單位 | Single cell / clone | Read-level at SNV positions |

### 根本性發現

**germline ASM >> somatic ASM** 不是方法缺陷，而是**生物學事實**：
- Germline variants 經過 evolution 選擇，常位於調控區域，有 mQTL 效應
- Passenger somatic mutations 多位於中性區域，不影響甲基化
- 只有 driver mutations 可能有功能性 ASM，但佔全部 SNVs 的 <1%

### 仍有價值的方向

| 方向 | 潛力 | 依據 |
|------|------|------|
| **Phase 2A: Normal baseline** | **高** | 直接消除 germline confound；BAM 全部可用 |
| HPFineNGroups 亞克隆標記 | 已驗證 | N≥4+NR≥80 → 89.1% TP rate |
| FP 的方向性 ASM 作為反向 filter | 低 | AUC=0.535，與 AF 重疊 |
| PMD 分層 × 其他特徵 | 極低 | PMD 異質性在 TP/FP 均存在 |

## 7. 建議後續行動

### 優先實作
1. **Phase 2A Normal Methylation Baseline** — 資料完備，理論依據最強，可直接消除 germline ASM confound
   - 預期效果：降低 FP 的 |ASM|，可能改善 F1 +0.02~0.05
   - 風險：low（Normal BAM 覆蓋率充足）

### 不建議投入
2. ~~L1 方向性 ASM~~ → passenger mutations 無方向性
3. ~~L4 fCpG 選擇~~ → TP/FP 的 CpG variability 完全相同
4. ~~L2 PMD 分層~~ → 異質性在 TP/FP 均存在，不改善判別

### 可深入研究（低優先）
5. FP 方向性 ASM 特徵化 — 理解 germline mQTL 在 ISM 中的呈現
6. Driver vs Passenger 分層 — 如有 driver annotation，可重測 L1 在 driver 子集上的表現
