7 不等於 7 個病人

7 datasets / 6 biological samples。HCC1395 與 HCC1395_DORADO 是同一細胞系兩套資料，不可在 biological denominator 重複計數。

為何玩具例是 k=2，而不是 k=3？

G1 是 germline SNP，用來決定 HP family；樹的 state vector 只放 somatic sSNVs。因此 G1-S1-S2 的正式 query 是 k=2。

Region、state tree、clone 的差別

Region 是 sSNV connected component；HP lineage 是依 germline HP family 分層的 evidence；state 是 R/A/X；tree 是符合 constraints 的 mutation-state topology；clone 是 cell population。前四者可算，第五者不能直接觀察。

03 / EVIDENCE

兩條證據鏈，
最後才取交集。

Topology 描述候選演化幾何；same-site collision 描述同一 genomic sSNV 在兩個 HP 都有 ALT evidence。只有交集才接近固定跨 HP clone catalog。

04 / DEFINITIONS

同一句 direct+sister，
其實有兩個 estimator。

A · Solver topology

目前枚舉結果中，一側全為 direct-only、另一側全為 sister-only，稱 shape-invariant。只有兩側 candidate set complete 時才可作 exhaustive 解讀。

54 enumerated / 45 complete · 17 stored-single / 13 complete-unique

B · Observed full-state geometry

只看 thresholded full reads。mutation sets 有 proper subset 稱 direct；互不包含稱 sister。

14 broad · 7 strict
兩個 estimator 不能混稱 clone 數。Solver 納入 partial subcube constraints；observed geometry 只看完整且 count≥3 的 states。
Cross-HP same-site collision

同一 sSNV position 在 HP1 與 HP2 的 ALT count 都 ≥3。它是候選旗標，仍可能來自 LOH/gain、HP switch、mapping artifact 或 caller error。

single-PS 的精確意思

只表示非缺值 PS 的 distinct count=1，不表示每條 alignment 都帶 PS，也不證明跨區域 phase continuity。H2009 HP1 為 64/75、HP2 為 77/77；HP1 缺 PS 的 11 條全是 XXA，移除後 major-PS sensitivity 不翻轉。

為何 populations 與 subreads 不能相加？

每條 read 先進 subread_groups，完整覆蓋時又進 populations；full key 會重複呈現。反推時 full counts 只能取 obs_populations。

09 / LIMITS

缺的不是更多圖，
是四個資料契約。

  1. 未截斷 read-state table

    保留 count<3、alignment identity、QNAME、HP、PS、state、callable mask與品質。

  2. Molecule denominator sensitivity

    同時報 alignment-identity 與 primary-QNAME，full/partial 分開。

  3. CN 與 HP error

    整合 1+1 magnitude、purity、LOH、switch/confusion；否則只報 molecule fractions。

  4. Model comparison + orthogonal evidence

    固定與替代 catalogs 做 likelihood/bootstrapping；methyl只作 anchored auxiliary；最終需 single-cell或多區域 evidence。

VAF 放在哪裡？

VAF 是 joint read-state model 的 marginal。候選模型應同時預測 per-site VAF並校準；不要把同一批 reads導出的 VAF再當獨立分數重複加權。VAF/read fraction 是 molecule fraction，不是 cancer cell fraction；轉成 CCF 需 purity、allele-specific CN、mutant multiplicity 與 normal contamination 校正。Canonical目前沒有 per-tree VAF ranking。

Methyl 目前能做到哪裡？

54/54 topology candidates 均可 bounded exact join；49/54 兩個 HP 的 MM/ML rate ≥95%，29/54 兩側都有 full-span methyl reads。H2009 指定區域 251/251 exact join，HP1 94/94、HP2 96/96 有 MM+ML；full-span 15/15 有區域內 modification entries，以 alignment.modified_bases_forward 解碼 3,155 entries（HP1 2,086 + HP2 1,069）。這只證明資料可對齊；layered L3 仍是 not_evaluated。穩定 methyl K=2 也只能叫 candidate epigenetic subpopulation，不能單獨確認 clone。

10 / CLAIM

可直接用於教授報告的句子。

在最新 LongPhase-S PASS canonical 的 7 個 datasets（6 個 biological samples）中，我們可以利用 ONT read-level sSNV 共現與 HP 分層，篩出跨 homolog 的 regional mutation-state candidates。51,815 個 regions 中有 22,779 個同時具有 HP1/HP2 mutation-bearing lineages；目前枚舉結果有 54 個呈現一側 direct、另一側 sister，其中 45 個 candidate-set complete；17 個目前各側只儲存一棵樹，其中 13 個才是 analysis-complete tree-unique。然而，沒有任何區域同時符合固定兩-sSNV五成分模型的完整反推條件，因此目前結果支持 regional mutation-state architecture candidates 的定點驗證，不支持已確認四個 cellular clones 或唯一 joint clone tree。
