# 全樣本結構一致性、bulk sampling 與區域 clone/subclone 候選整合驗證

> **用 SCQA + Verdict–Evidence：七個 datasets 都有 Direct-chain 主導的共同輸出模式，但完整 composition 並不一致；HCC1395 同細胞株的兩個 cross-source datasets 在 matched-region 粗拓撲顯著高於指定 null，aggregate composition 卻只屬中等接近。這支持「部分區域結構訊號可跨來源再現」，不證明每區唯一真樹或真實 clone。**

## 1. 任務與 claim ceiling

- Task type：**B Comprehensive validation**；完整覆蓋 frozen historical layered-v2 的 7 dataset rows 與 chr1-22；另依預先定義分開報告 complete、matched-region、CN-ready 與 full-join 子母體。
- 服務目標：**G4 多樣本一致性與 reproducibility、G5 外部可驗證性**。
- Current gate：fresh layered-v3 尚無 root `_SUCCESS`；本報告使用 internally checked historical layered-v2 engineering snapshot。
- 可以驗證：分類守恆、composition 距離、抽樣敏感度、matched-region same-cell-line cross-source 再現、PyClone 條件式區域候選。
- 不可驗證：每區唯一真實演化樹、clone 真實數目、祖先方向、生物等價或臨床有效性。

## 2. 最重要的三層結果

| 層級 | 主要數字 | 判讀 |
|---|---:|---|
| 全樣本 aggregate composition | 7/7 datasets 都以 Direct-chain 為最大類；complete 五類 Direct 56.34%–78.17% | 是共同輸出模式；無 solver/class-space null，尚不能區分生物訊號與演算法／eligibility base-rate bias |
| HCC aggregate composition | complete 五類 Jensen–Shannon distance（square root；log base 2）=0.1984，與 20 個 cross-biological dataset-row comparisons 比為 rank 9/21 | 8/20 comparisons 更接近，涵蓋 7 個 unique biological-ID pair combinations；不能稱高度一致 |
| HCC matched-region pre-VAF coarse topology | 3,969/5,720=69.39%，95% CI 68.18%–70.57%；chromosome-preserving null 39.51%，p=1/5001 | 高於指定 null，支持部分 same-cell-line cross-source 再現；不是 final-shape 或 exact-tree accuracy |
| HCC informative external partition | both-multicluster 只有 34 區，label-invariant exact 21/34=61.76% | clone-like 子結構只有中度、稀疏的再現 |

三層方向上相容，但不是同一 estimand：aggregate 使用全 complete 母體的 VAF-selected final shape；69.39% 使用 exact-coordinate complete-both 母體的 pre-VAF coarse category；PyClone 層再限制到 external state／multicluster 可評估區。其數值差異同時反映 region identity、母體選擇與分類 endpoint，不能只歸因於 aggregate composition 消除 locus identity。作為同口徑描述性敏感度，5,720 matched regions 的 final-shape agreement 為 4,243/5,720=74.18%，matched final-shape composition distance 為 0.1967；目前尚無對應 final-shape permutation null。

## 3. C、T、Topo 與 VAF 選樹的正確口徑

| 符號／欄位 | 本報告定義 | 不可代稱 |
|---|---|---|
| `C_read_groups` | primary HP 內 ALT-containing、MINREAD-supported、完整 R/A read 群；排除 ROOT、hidden、partial、all-reference | PyClone cluster 數、clone 數 |
| `T_exact_candidate_forest_count` | 各 primary HP exact candidate tree 數的乘積 | topology 數、真實樹數 |
| `Topo_shape_count` | 各 primary HP rooted-unlabeled shape 數的乘積 | 完整 tree structure 數 |
| `external_cluster_count` | 該區突變在一個 PyClone fit 中映射到的 fit-local clusters 數 | `C`、真實細胞群數 |
| `tree_selection_source=vaf_resolved_topogt1` | Topo>1 時，以每位點 VAF 對候選樹排序後選出的最可能 shape | 經 orthogonal truth 確認的唯一真樹 |

全 47,377 primary regions 中：

- incomplete 7,492；complete 39,885。
- `C=0` 26,593、`C=1` 10,322、`C>1` 10,462。
- complete regions 中 `T=1` 10,832、`T>1` 29,053。
- complete regions 中 `T=1且Topo=1` 10,832；`T>1但Topo=1` 11,144；合計 `Topo=1` 21,976，另有 `Topo>1` 17,909。
- 21,976 區只有 rooted-unlabeled shape 唯一，其中 11,144 區的 exact tree structures 仍不唯一；15,063 個 Topo>1 區由 VAF 推測 most-likely shape，2,846 區仍 unresolved。

因此 VAF 的角色是**在多顆候選樹間提供可重現的 ranking heuristic**。輸出保留 `vaf_most_likely_topology_status`（例如 `unique_first`、`tied_first_same_topology`）與 `vaf_direction_consistency`；同分或資訊不足時不宣稱唯一。

## 4. Bulk sampling adjustment 是否能讓 HCC pair 變一致

Primary 使用 complete 五類：Single、Sister、Direct、Sister+direct、Unresolved。HCC cross-source pair raw TV=14.55%、Jensen–Shannon distance（square root；log base 2）=0.1984。

| 調整 | HCC JSD median | 95% interval | 相對 rank | P(rank=1) |
|---|---:|---:|---:|---:|
| Raw | 0.1984 | — | 9 | 0 |
| Dirichlet posterior | 0.1987 | 0.1851–0.2116 | 9 | 0 |
| Equal-n rarefaction，n=2,557 | 0.1991 | 0.1814–0.2162 | 9 | 0 |
| Common 5 Mb block bootstrap | 0.1976 | 0.1858–0.2095 | 9 | 0 |
| Common 10 Mb block bootstrap | 0.1967 | 0.1848–0.2092 | 9 | 0 |
| Leave-HCC-out EB sensitivity | 0.1971 | deterministic | 9 | 0 |

結論：統計調整降低了「區域數量不同」與 genomic clustering 對不確定度的影響，但**沒有消除兩來源 composition 差異**。EB 對全表最大比例位移僅 0.204 percentage points；region n 已大，單純 shrinkage 不足以修正 read→region 類別誤判、coverage／basecalling 差異或 region universe 差異。

Resolved-only 四類 TV=8.60% 看似較小，但先移除 HCC 2.05% 與 DORADO 9.90% unresolved 後再 closure，會讓兩者顯得更接近，故只列 secondary。按選樹來源標準化後 resolved TV 反而為 16.75%，說明 raw 值受 mixture cancellation 影響；因 source 是 outcome-dependent selector，此數字只作 sensitivity，不是「校正後真差異」。

## 5. 區域 possible clone/subclone 標記

Primary region state 只在所有 exact region mutations 都能以 `CHROM:POS:REF>ALT` join 到 selected PyClone main fit 時輸出，並要求 `CHROM+POS` 在各 fit 內唯一；`CP>=0.90` 稱 clonal-like point estimate，`CP<0.90` 稱 subclonal-like point estimate。`assignment>=0.80` 是 fit-conditional sensitivity，不是真實 clone 的高信心門檻。

此外部工具口徑與 [PyClone-VI primary paper](https://pmc.ncbi.nlm.nih.gov/articles/PMC7730797/) 及 [original PyClone paper](https://www.nature.com/articles/nmeth.2883) 對齊：它們由 bulk allele counts、copy number 與 purity/normal contamination 推測 mutation clusters 和 cellular prevalence；本報告因此使用 `modeled`／`possible`，不把 cluster 直接命名為真實 clone 或 phylogenetic node。

| Dataset | Regions | Full exact evaluable | Possible-subclone signal | 占 evaluable | 全位點 assignment≥0.8 可評估 |
|---|---:|---:|---:|---:|---:|
| HCC1395 | 7,590 | 5,492 | 156 | 2.84% | 4,608 |
| HCC1395_DORADO | 7,268 | 5,167 | 129 | 2.50% | 2,956 |
| COLO829 | 7,659 | 0 | unavailable | — | 0 |
| H1437 | 8,630 | 8,196 | 884 | 10.79% | 6,654 |
| H2009 | 9,581 | 9,014 | 689 | 7.64% | 6 |
| HCC1937 | 2,674 | 0 | unavailable | — | 0 |
| HCC1954 | 3,975 | 3,766 | 1,047 | 27.80% | 3 |

COLO829、HCC1937 因沒有 reviewed allele-specific CN 而 fail-closed；未用 CN=2 補值。DORADO 使用 HCC1395 CN/purity，欄位標 `external_cn_source_independent=false`。H2009、HCC1954 在 assignment≥0.8 後幾乎全部 unavailable，表示其 minor-cluster assignment 不足，不能直接用 primary 百分比跨樣本比較真實 subclone burden。

HCC 的兩個 separate global fits 分別輸出 4 與 3 個 fit-local clusters；這不是「4 vs 3 個真實 clones」。所有 shared mutations 的 clonal-state agreement 為 98.51%，但 κ=0.544；subclonal mutation Jaccard 為 277/727=38.10%。限制到本報告 regions 後，agreement 98.63%、κ=0.379、subclonal mutation Jaccard 62/259=23.94%。換句話說，占優勢的 clonal-like 主群相似，但 minor subclonal-like mutation assignment 只部分再現。

完整區域表每列包含：region、k sites、HP、C、T、Topo、hidden nodes、VAF 選樹來源／狀態、exact mutation IDs、PyClone join coverage、CP/assignment、possible state、high-assignment sensitivity 與 claim ceiling。HCC pair comparison 另完整 join 5,720/5,720 GENCODE gene-body/promoter、COSMIC CGC、DGIdb approved-antineoplastic 與 CLP flags；這些欄位用於基因區域分層，不是 topology accuracy evidence。

## 6. HCC1395 兩來源的 clone-like 區域是否一致

固定 5,720 exact complete regions 中，4,438 區兩側 external state 可評估；其中 4,296 區 state 相同，表面為 96.80%。但 4,267 區是兩側都只有一個 modeled clonal-like cluster，因此大多數一致是主成分造成，不能寫成「96.8% clone 結構一致」。

- 任一側有 possible-subclone signal：172 區。
- 兩側都有：40 區；presence Jaccard=`40/172=23.26%`。
- 在較寬鬆的 common-joined-mutation endpoint，兩側皆 multicluster 且可比較 partition：34 區。
- 該 endpoint 的 label-invariant partition exact：21/34=61.76%；另 13/34 不同；此分母不可與前述 4,438 個 full-exact-state regions 混用。
- assignment≥0.8 後兩側同 state 2,370/2,370，但全部為 single modeled clonal-like；這是 selection-induced degeneracy，不是完美 subclone 再現。

Pair 明細對空集合採 fail-closed：若兩側 subclonal union=0，`external_subclonal_jaccard=NA`、`defined=false`、reason=`both_absent`；partition exact 只在 34 個 both-multicluster informative rows 定義。這避免 4,996 個空 union 與 5,007 個 both-single-cluster rows 被誤寫成「完美一致」。

所以最精確的說法是：兩來源都穩定再現占優勢的 clonal-like 主成分；稀少 subclonal-like 區域與 multicluster grouping 只呈部分、中度再現。

### 基因／藥物註記區域

在 5,720 個 HCC exact regions 中，4,459 區重疊 gene body、275 區重疊 CGC gene body/promoter、464 區有 DGIdb approved-antineoplastic gene claim、333 區有 CLP variant flag；但 `CLP confirmed somatic=0`。CGC 275 區的 coarse agreement 為 199/275=72.36%，只比全體 69.39% 高約 2.97 percentage points；本輪沒有新的 matched enrichment null，因此不能說癌症基因區證明方法較準。

可供人工檢視的候選例子：

| Region | Annotation | HCC1395 | DORADO | External partition |
|---|---|---|---|---|
| chr11:128802981-128853809 | CGC `FLI1` | clonal+single-subclonal candidate | clonal+single-subclonal candidate | both-multicluster exact |
| chr2:141063678-141096354 | CGC／DGIdb `LRP1B` | clonal+single-subclonal candidate | single modeled clonal-like | resolution-asymmetric |
| chr19:44784709-44850535 | CGC `CBLC` | clonal+single-subclonal candidate | single modeled clonal-like | resolution-asymmetric |

DGIdb 欄位是 gene–drug claim annotation，不能推論該區 mutation 可用藥、具有臨床 actionability 或支持某棵樹為真。

以上三例也只屬 external PyClone×gene prioritization：兩來源的 `C_read_groups` 都是 0，且包含 assignment<0.8 的突變（例如 FLI1 兩側最低約0.38/0.40）。它們沒有 InterSubMod read-level clone corroboration，不能稱為 read-tree 支持的 subclone、致病機制或可用藥證據。

## 7. 能否證明 topology 方法展現樣本狀況

**可以支持到「樣本／位點條件式結構訊號」；不能支持到「每區真實演化樹 accuracy」。**

支持點：

1. 七個 datasets 都有 Direct-chain 主導，確認共同的非均勻輸出模式；未建立 solver/class-space null 前，這一點不能單獨作為方法有效性的證據。
2. HCC same-locus pre-VAF coarse agreement 69.39%，明顯高於 chromosome-preserving null 39.51%，支持 region-level same-cell-line cross-source reproducibility。
3. 結果通過 exact matching、block／permutation與 deterministic rerun。Byte-identical rerun排除未固定 RNG／非決定性實作；它不排除 BAM/read sampling、coverage、basecalling、aliquot或passage差異。

限制點：

1. HCC aggregate JSD rank 9/21，不是 uniquely nearest sample pair，因此 composition 不能當 sample fingerprint。
2. 粗分類會把不同 exact trees 壓成同一類；69.39% 不是 exact-tree accuracy。
3. VAF winner 與 PyClone 都依賴 bulk allele fractions；不是 single-cell／multi-region orthogonal truth。
4. Region windows 有重疊，不能把 5,720 區當成 5,720 個獨立 biological replicates。
5. 目前只有一組 same-cell-line cross-source pair；尚未證明為同 aliquot、同 passage或嚴格 technical replicates，也無法估計一般化的 within-cell-line 與 between-cell-line variance。

## 8. 必要的下一步驗證

1. 同一 BAM 做 molecule-level split-half 與 matched-depth full pipeline rerun，估計方法自身 technical ceiling。
2. 以 union exact loci 對兩 BAM 重新 recount，拆開 callset selection 與 read sampling。
3. 補 DORADO source-specific allele CN/purity；對 COLO829、HCC1937 完成 reviewed CN gate。
4. fresh layered-v3 7/7 root `_SUCCESS` 後，凍結 classifier 重算全部結果。
5. 收集多個 cell lines 的至少兩個獨立技術來源，做 Aitchison/PERMANOVA variance decomposition 與 held-out sample identification。
6. 最後用 single-cell、multi-region 或 synthetic truth 評估 mutation→cluster→directed-edge→tree accuracy。

預先註冊可用的 sampling-adjusted estimand：

```text
theta = D_cross_source - (D_split_half_source_A + D_split_half_source_B) / 2
```

只有 `theta` 的 upper confidence bound 小於預先設定 equivalence margin，才能主張跨來源結構等價。

## 最終 verdict

**Internal engineering verdict：PASS_WITH_CAVEATS。Scientific／external release verdict：NO-GO。** 本輪可作 frozen historical layered-v2 的內部方法診斷：在相同 genomic regions 抓到高於指定 null 的 same-cell-line cross-source 粗結構訊號；但 aggregate composition、VAF most-likely shape 與 PyClone 區域候選仍不足以證明兩來源高度等價、每區唯一真樹或 biological accuracy。須等 fresh layered-v3 7/7 root `_SUCCESS` 與 run-level verification 後，凍結同一分類器重算，才能重新評估科學發布。
