>
> **TL;DR**：37,039 個 final single-shape regions 中，Single/no-within-HP 6,027（16.27%）、Sister 1,459（3.94%）、Direct 27,543（74.36%）、Sister＋direct 2,010（5.43%）。這是 rooted-unlabeled mutation-state graph pattern，不是 clone／subclone 真值。

## 2. 研究問題、假設與判定條件

### 研究問題

在 39,885 個 complete regions 中，先接受原本已 `Topo=1` 的 21,976 個，再加入 VAF exact-first set 縮至單一 ordered HP shape tuple 的 15,063 個，最終 37,039 個 single-shape regions 分成哪四類？

### 假設

既有 shape catalog 的 `max_outdegree` 與 `max_depth` 可決定性映射到四類；VAF-ranked unit 的 `exact_top_shape_ids` 與 fixed-T1 companion HP 的 structural shape 合併後，可 materialize 每個 region 的 ordered HP shape tuple。

### 成功條件

1. `21,976 + 15,063 = 37,039`。
2. 四類合計等於 37,039；另 `37,039 + 2,846 = 39,885 complete`。
3. 原 Topo=1 的四類與既有 coarse classifier 逐 region 完全一致。
4. 每個 selected region 的每個 primary HP 恰有一個 selected shape。
5. 全 7 dataset rows 各自守恆，正式輸出重跑 byte-identical。

### 失敗條件

- 任一 region/HP key 重複、selected shape 不唯一、shape ID 不在 catalog、structural class 不一致或任一分母不守恆。

## 3. 四類可執行定義與名稱修正

| 建議名稱 | 可執行規則 | 不可直接聲稱 |
|---|---|---|
| Single/no-within-HP-relation | 所有 HP component：`max_outdegree<2` 且 `max_depth<2` | 單 clone |
| Sister-pattern | 至少一個 HP：`max_outdegree≥2`；所有 HP：`max_depth<2` | 已確認多 clone |
| Direct-chain-pattern | 至少一個 HP：`max_depth≥2`；所有 HP：`max_outdegree<2` | 已確認 subclone |
| Sister＋direct-pattern | Region-level OR 同時具有 sister 與 direct | 已確認多 clone＋subclone |

重要邊界：

- depth 從 ROOT=0 起算；`ROOT→A` depth=1，`ROOT→A→B` depth=2。
- HP1/HP2 是 ordered forest components，跨 HP 不建立姐妹或祖先關係；region 類別只把兩側 feature 用 OR 合併。
- `H_*` hidden／Steiner／partial-supported nodes 也參與 depth/outdegree。
- Shape canonicalization 移除 mutation/node labels，只保留 rooted-unordered skeleton。

所以使用者給的四句在「圖形結構」層級成立，但括號中的 clone/subclone 解讀超過證據。尤其 Single-only 6,027 中有 5,190（86.11%）是雙 primary HP components，只有 837 是單 HP。

## 4. 計算流程

```text
39,885 complete regions
├─ 21,976 原本 structural Topo=1
│  └─ 直接 materialize 每個 HP 的唯一 shape
└─ 17,909 原本 Topo>1
   ├─ 15,063 VAF exact-first set → one ordered HP shape tuple
   ├─  2,205 VAF first set 仍跨 shape
   └─    641 VAF 不可評估

Final single shape = 21,976 + 15,063 = 37,039
```

對每個 final single-shape region：逐 HP 取得 shape ID → 查 `max_outdegree/max_depth` → 各 HP 分類 → region 層級 OR collapse。

## 7. VAF selection 與方向證據

- 15,063 個 VAF-resolved regions 中，12,105（80.36%）為 `unique_first` exact tree，2,958（19.64%）為多棵 exact-first trees、但同一 unlabeled shape。
- Direction-state：14,956（99.29%）`all_consistent`；12 all-inconsistent、2 mixed、85 無 ancestry comparison、8 partial-all-consistent。
- `all_consistent` 使用既有 margin 規則，仍不是 orthogonal truth；同一 read-derived AF 同時用於 ranking 與方向檢查。
- 2,010 個 Sister＋direct 中，95（4.73%）是 sister 與 direct 分別出現在不同 HP components。
