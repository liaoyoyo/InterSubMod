## 2. HTML 內使用的計算量

| 層 | 數量 | 定義／計算量 | 確認方式 |
|---|---:|---|---|
| Active state space | \(2^q\) | q 是至少一次明示 ALT 的 active 位點數 | 逐 group 從 R/A/X pattern 重算 q |
| Unit-flip edges | \(q2^{q-1}\) | 完整 q-cube 的概念有向邊；程式按需導出 | q=12 應為 24,576 |
| Partial inputs | \(\sum_i2^{u_i}\) | 各 input partial group 分別 materialize compatible states | 逐 group 重算 active-X 數 \(u_i\) |
| Pattern parsing | \(O((F+G)k+\sum_i u_i2^{u_i})\) | 含 full/partial 全長掃描與 partial member 建立 | 對齊 MLHP patterns |
| Exact search | data-dependent exponential | 以 B&B `search_nodes`、certificate 與 guard 判定 | 逐 topology JSONL 重算 |
| Candidate family | \(C_V\) | minimum-extra objective 下的全部 vertex sets | family complete 才能發布 exact \(C_V\) |
| Fixed-set trees | \(C_T(V)=\prod_v d_V^-(v)\) | 每個 child 的合法 parent choice 相乘 | big integer factorization |
| Family trees | \(C_T=\sum_VC_T(V)\) | 跨全部 minimum vertex sets 加總 | 不逐棵 materialize |
| AF ranking | 約 \(O(C_Vn_Vq^2)\) exact-rational ops | child-local max 與 tie product | family complete 且 AF denominator 完整 |

重要邊界：

- `721,557` 是全 cohort 的 input distinct partial groups \(G_{input}\)，不是同時存在的
  dynamic obligations；搜尋節點 B 當下為 \(G_{active}(B)\le G_{input}\)。
- \(3^q\) 是忽略 predecessor-skip 時 connection lower-bound submask 工作的鬆上界，
  不是 full cube 的實際拜訪數。
- \(\prod_{r=1}^{q}r^{\binom qr}\) 是完整 cube 作為單一 vertex set 時的 exact
  parent-assignment 數，不是跨多個 vertex sets 的 \(C_T\) 總上界。
- 本輪 `max_search_nodes=1,000`、`max_family_size=100,000`，且 \(C_V\le B\)；
  因此 family cap 不可能先觸發。10,717 個 abstain 全為 search-node limit。
