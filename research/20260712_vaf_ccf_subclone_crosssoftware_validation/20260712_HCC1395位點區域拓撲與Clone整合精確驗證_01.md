## 2. 多位點區域是否一致？

固定 5,720 regions 全部是 `k≥2`：`k=2` 3,121、`k=3` 1,506、`k≥4` 1,093。位點集合本身非常穩定，但 exact structure 隨複雜度增加而下降：

- Coarse agreement 由 `k=2` 的 63.83% 升至 `k≥4` 的 83.81%，主要因 `k≥4` 有 888/1,093（81.24%）是 `Topo>1 未定↔未定`；這不是 Direct 或 exact tree 變準。
- Read exact＋induced 由 58.03% 降至 19.59%；VAF exact＋induced由 69.75% 降至 15.57%。
- VAF conflict 由 20.91% 升至 54.62%。因此解析度越高，真正 mutation-labeled 一致性越低。
- Read candidate-set compatibility 4,036/4,038=99.95% 只表示廣候選集合幾乎都有交集；不能稱為 exact topology 99.95% 一致。

所以答案是：**多層位點身分高度一致，但位點間精確關係、方向與完整 forest 只有部分一致。** 若某來源是另一來源的真 induced substructure，已另外計入 exact＋induced endpoint；不是用任意「看起來像子圖」放寬。

## 3. 外部 clone 分析能驗證多少？

Primary 使用 HCC1395 與 DORADO 各自獨立的 PyClone-VI fit；joint fit 的共享 labels 由模型建構產生，沒有當成獨立再現證據。

- 全域 30,262 mutations：ARI=0.539、NMI=0.339、subclonal Jaccard=0.381、clonal/subclonal κ=0.544、CP Spearman=0.547。
- 固定區域可雙側連接 14,369/15,713 alleles（91.45%）；regional subclonal Jaccard=0.239、κ=0.379、CP Spearman=0.380，反而比全域弱。
- Assignment ≥0.8 後表面上所有指標等於 1，但 10,965 mutations 中 subclonal union 只剩 **1**，屬 selection-induced vacuous concordance，不能聲稱高信心 clone 完美重現。
- 5,189 個至少連到兩個 PyClone mutations 的區域中，partition exact 5,028（96.90%），但 5,007 個只是兩側都落在單一 cluster。真正兩側都有多群者只有 34，exact 21、different 13，即 61.76%。
- Read directed relation 兩側都可判定者只有 598/8,096；其中 596 同向、2 反向。然而 endpoints 多數同 cluster；高信心 subset 完全沒有 different-cluster edge，所以 0 conflict 無法驗證 ancestry ordering。

結論：**外部分群支持 dominant frequency／clone state 的部分再現，但沒有提供每區樹方向的外部真值。PyClone-VI 本身也不推演化樹。**

## 4. 差異原因與問題排序

1. **Identifiability／候選空間是最強限制。** Read candidates `>20` 相對 `1` 的 exact＋induced 低 73.57 pp；VAF candidates `≥2` 相對 `1` 低 46.71 pp。每 2× candidate 的 adjusted OR 分別為 0.735 與 0.119。
2. **HP／pipeline 有明確影響。** 703/5,720（12.29%）HP unit count mismatch；coarse agreement 50.78%，相對 HP-matched 72.00%，fine read/VAF endpoints 703/703 fail closed。另有 186 個 site-set mismatch regions。
3. **VAF heuristic 有來源敏感性。** VAF conflict 1,234/3,860；VAF 來自同批 reads，未校正 source-specific CN、purity 與 multiplicity，故「最可能」只能稱推測。
4. **Read sampling 有貢獻但不是充分解釋。** 全域 binomial-compatible 93.07%；不相容 site 的區域 exact yield 較低。但 depth／|ΔVAF| 在控制 k、candidate 與 context 後不穩定，尚缺 within-source split-half 與 randomized downsampling。
5. **真實 biological drift 尚未解析。** passage、aliquot、library DNA provenance 不完整；不能把 residual conflict 直接解讀為不同 clone 演化，也不能完全排除 culture drift。

整體原因 verdict：**identifiability-dominant, pipeline-contributed, sampling-plausible, biological-divergence-unresolved。**

## 5. 方法有效性可支持到哪裡？

### 可以支持

- 同一 cell line 的跨技術來源能重現大部分 allele inventory、VAF 主體分布與 broad regional structure。
- 方法能作 structure-signal detection、candidate generation、VAF-supported ranking、abstention 與跨來源 reproducibility 診斷。
- 粗結構、selected shape、exact mutation-labeled forest 必須分層報告；本輪數字顯示這種分層能揭露真正的解析度代價。

### 不能支持

- 每個區域已輸出一棵準確且唯一的真實演化樹。
- 69.39% coarse agreement 等於 69.39% exact-tree accuracy。
- VAF 選出最高分樹就已「確認」該樹；它是 same-read heuristic，不是 calibrated posterior 或獨立 truth。
- 癌症基因／藥物 annotation 或 PyClone cluster agreement可以證明祖先方向。

因此最精確的論文式結論是：**方法已顯示「結構訊號偵測與跨技術來源部分再現」的實用性；accuracy／唯一真樹有效性仍需 single-cell、multi-region、colony、synthetic truth 或其他正交資料。**
