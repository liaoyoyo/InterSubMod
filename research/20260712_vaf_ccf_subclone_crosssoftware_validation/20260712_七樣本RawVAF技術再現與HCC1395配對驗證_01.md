# 七樣本 raw VAF 技術再現與 HCC1395 配對驗證

> **結論先行：HCC1395 與 HCC1395_DORADO 的 raw VAF 在 exact shared alleles 上高度一致，且在 7 個 dataset 的 truth-confirmed 邊際分佈中，DORADO 於 latest 與 baseline、JSD/Wasserstein/KS 三個指標皆為 HCC1395 的第 1 最近鄰。這支持 raw-VAF 結構訊號的跨技術來源再現；不等於 clone/subclone truth，也不能證明唯一演化樹。**

## 2. DP/AF 計數契約與 QA

每列由 `bcftools query` 讀取 chr1–22、`FILTER=PASS`、biallelic SNV 的 `FORMAT/DP`、`FORMAT/AF`、`FORMAT/AD`。計數固定定義為：

- `alt_count = floor(DP × AF + 0.5)`，即 half-up `round(DP × AF)`。
- `ref_count = DP − alt_count`。
- `AD[-1]` 僅作 ALT-depth QA；**從未讀取或使用 `AD[0]`**。

QA 結果：

- 14 個 dataset×source VCF 共 `925,059/925,059` 列通過 count reconstruction invariant。
- derived ALT count 與 reported ALT AD 為 `925,059/925,059` 完全相等。
- AF 四捨五入量化最大絕對誤差為 `0.00005`。
- 14/14 caller VCF 的實際 SHA-256 與 manifest 宣告 SHA-256 相符。

## 6. Claim ceiling

本分析可以支持：

1. 同一 cell line 的兩個技術資料源有高度 exact-locus raw-VAF 技術再現。
2. HCC1395_DORADO 在全 7 dataset 的 raw-VAF marginal profile 中穩定為 HCC1395 最近鄰。
3. latest 結論可由 caller-PASS baseline sensitivity 重現。

本分析不能單獨支持：

1. 兩個資料源具有相同的 clone/subclone truth 或唯一真實演化樹。
2. 不同 cell line 的 marginal VAF 接近代表 clone 演化接近。
3. 將 raw VAF peak 直接等同 clone prevalence；仍需 purity、allele-specific CN/LOH、mutant multiplicity 修正成 CCF，並以 PyClone-VI 等外部模型及 mutation-cluster membership 做下一層驗證。
