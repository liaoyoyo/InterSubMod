用 SCQA＋四類原因分解：**目前不能驗證「每個區域都輸出一棵準確、唯一的真實演化樹」；證據支持同一 HCC1395 cell line 的跨來源結構訊號部分再現，但 exact tree 的主要瓶頸較像可識別性與候選空間膨脹，HP／caller 選擇與 same-read VAF heuristic 次之，單純 depth／二項抽樣不足以解釋全部差異。**（影響：高；信心：高；服務 G4／G5）

# HCC1395 位點／區域拓撲原因分解紅隊稽核

> **Task type B — Comprehensive validation。** 本稽核使用固定 5,720 區域母群，不以 subset 代替 headline；所有 p/q 值僅作診斷，primary 判讀依效果量、block-bootstrap CI、結構定義與 claim ceiling。

## 1. 先直接回答三個問題

### 1.1 能否驗證每區一棵準確且唯一的真實演化樹？

**不能。** `[L1/L2]`

1. 沒有 single-cell、colony、multi-region、synthetic tree 或其他 orthogonal exact-tree truth；SEQC2 只能確認 mutation presence，不提供區域內祖先方向或唯一 tree。
2. Read 層輸出的是 **read-compatible candidate set**，不是 truth。4,038 個可評估區中，兩側 shared-site projected topology 都只剩 singleton 的區域僅 361/5,720（6.31%）；這個窄 subset 中 359/361 的 shared-site projection 相同，不可外推成全域 99.45%。其中 34 區仍只達 `shared_core_only`，所以 headline 的 strict exact/true-induced 是 325/361，而非 359/361；兩個口徑不可混用。
3. VAF 層雖把 3,216/3,860 個可評估區壓到兩側 projected topology size=1，但其中 exact/induced 只有 1,742/3,216（54.17%），另有大量跨來源 conflict。VAF 的「唯一」是 heuristic selection 的唯一，不是 biological identifiability。
4. 同一組 reads 同時形成 read constraints、AF/VAF 與 VAF winner，存在 same-read circularity；不能用自身排序結果確認自身樹為真。

### 1.2 兩份 HCC1395 是否「高度一致」？

要看解析度。`[L1]`

| 解析層 | 一致／相容 | 分母 | 比例 | 可下結論 |
|---|---:|---:|---:|---|
| Coarse final-shape category | 3,969 | 5,720 | 69.39% | 粗結構部分再現 |
| Read full exact＋真 induced | 1,599 | 5,720 | 27.95% | 固定母群 exact/substructure yield 不高 |
| Read full exact＋真 induced（可評估） | 1,599 | 4,038 | 39.60% | 條件式部分一致 |
| VAF top-set exact＋真 induced | 1,790 | 5,720 | 31.29% | VAF 提高部分決斷，但不是 truth |
| VAF top-set exact＋真 induced（可評估） | 1,790 | 3,860 | 46.37% | 條件式中度一致 |
| VAF top-set conflict（可評估） | 1,234 | 3,860 | 31.97% | VAF ranking 亦產生大量來源間衝突 |
| Separate PyClone minor set | intersection 277 / union 727 | 727 | Jaccard 38.10% | minor clone assignment 只中度再現 |

因此最準確的文字是：**broad/coarse structure 與 dominant frequency component 有部分至中度跨來源再現；mutation-labeled exact/substructure 與 minor assignment 未達高度一致。**

### 1.3 差異是資料區域不同，還是方法學問題？

**現有資料不能做單一歸因；最合理排序為：**`[L2]`

1. **Identifiability／region complexity：主要因素。** `k` 與 candidate multiplicity 增加時 exact/substructure 一致率急降，但 coarse agreement 反而上升，表示解析度壓縮會掩蓋 exact 差異。
2. **Source pipeline／HP assignment：明確 blocker。** 703/5,720（12.29%）HP unit count mismatch 被規則性 fail closed；另有 186（3.25%）caller site-set mismatch。這可來自 basecalling、alignment、phasing、HP split/merge 或 caller selection，現有設計無法再拆。
3. **Method selection conflict：明確存在。** VAF top-set 把 read 層廣候選壓縮後產生 1,234 conflicts；這是 heuristic sensitivity，不等於兩份樣本真的有不同演化。
4. **Read sampling／depth：有貢獻跡象，但不是已證實主因。** Raw 位點差異多數符合簡單二項抽樣；然而未做 depth-matched downsample 與 within-source split-half，故不能把 topology 差異因果歸於 sampling。
5. **真實 biological drift：目前不可排除，也沒有被證明。** 兩者是同 cell line 的跨來源資料，不是同一批 molecule；ONT_Dorado 來源涉及另一公開資料來源／可能不同 passage 或 library。缺 passage、aliquot、library DNA provenance，不能把 residual conflict 命名為新的演化事件。

## 2. 固定母群、資料連接與選擇邊界

### 2.1 固定母群

- 5,720 個 `exact_coordinate + complete_a + complete_b` region pairs。
- 15,713 個 shared exact alleles，`CHROM:POS:REF:ALT` identity 15,713/15,713 PASS。
- Caller site set equal 5,534（96.75%）；A⊂B 100、B⊂A 85、partial overlap 1，共 mismatch 186（3.25%）。
- Shared-site complexity：`k=2` 3,121、`k=3` 1,506、`k=4` 731、`k≥5` 362。

### 2.2 Raw VAF/depth 連接

- Historical topology 的 15,713 alleles 對 `baseline_caller_pass` 為 15,713/15,713 exact join；5,720/5,720 regions 完整。
- 對 `latest_lps_pass` 為 15,636/15,713；少 77 alleles，影響 73/5,720 regions，5,647 regions 完整。
- 因此本稽核用 **baseline exact-allele complete join** 作主要原因診斷；這只證明 allele inventory 完整連接，不證明 historical layered-v2 與 raw caller table 來自完全相同的 upstream producer/BAM release。Latest 更只能作 cross-release sensitivity，不能混稱同一 release。
- Baseline region median：mean pair-min DP=60.75、region minimum pair DP=54、mean |ΔDP|=10、mean |log2 DP ratio|=0.223、mean |ΔVAF|=0.0543。

### 2.3 CN/LOH 連接

- PyClone primary metadata 可連 14,369/15,713 alleles；完整覆蓋 4,542 regions、partial 1,119、完全無資料 59。
- Full CN regions：full non-LOH 2,337、full all-LOH 2,197、full mixed-LOH 8。
- 這是 **兩來源共用的 HCC1395 SAVANA CN context**，不是各來源獨立測得的 CN。CN 關聯只能描述 VAF/topology 在不同 genomic context 的行為，不能作 cross-source CN confirmation。

### 2.4 Selection ceiling

固定母群本身要求兩側都有 complete exact-coordinate region，PyClone primary 又要求雙側完整 counts／PASS 與 SEQC2 HC。Topology 來源仍是 historical layered-v2 engineering snapshot，clean-v3 scientific release 尚不能取代它。這些條件可能排除低 VAF、低 depth、HP 不穩或 caller-discordant loci；所以本報告的 estimand 是：

> **在已被兩側選入的 5,720 complete regions 中，兩來源的結構訊號如何不同。**

不是：

> **全基因組所有可能區域的真樹 accuracy。**

### 3.1 最重要的 coarse-vs-exact 反例

`k=2 → k≥5` 時：

- Coarse agreement：63.83% → 87.29%。
- Read exact/induced（可評估）：58.03% → 19.41%。
- VAF exact/induced（可評估）：69.75% → 12.02%。
- VAF conflict（可評估）：20.91% → 60.52%。

這直接證明 **coarse category 越一致，不代表 exact mutation-labeled tree 越一致**。高 k 區域可同時落入相同 `Direct`／`Unresolved` 大類，卻在位點方向、branch、HP forest 或候選集合上不同。

## 4. 為何 depth 結果反直覺？

未調整結果顯示高 depth Q4 的 exact/induced 比低 depth Q1 低，這**不能**解讀為「低深度更準」。`[L1/L2]`

### 4.1 已觀察到的混雜

| 組成 | Depth Q1 | Depth Q4 |
|---|---:|---:|
| `k=2` | 65.1% | 48.3% |
| `k≥5` | 0.8% | 9.4% |
| Full all-LOH | 76.2% | 17.8% |
| Full non-LOH | 7.4% | 61.3% |

低 depth quartile 大量位於 LOH、small-k context；這些區域本來就較容易被 VAF/HP 規則壓成少數候選。高 depth quartile 則包含更多 k≥4、non-LOH 與較複雜區域。Depth 是 genomic context 與 region selection 的 proxy，並非隨機介入。

### 4.2 Cluster-robust 多變量診斷

以 chromosome＋1 Mb block cluster-robust logistic model，同時納入 depth、Δdepth、|ΔVAF|、k、site mismatch、CN/LOH、latest coverage 後：

| Endpoint | 每 2× mean pair-min DP OR（95% CI） | 解讀 |
|---|---:|---|
| Coarse agree，n=5,720 | 1.03 [0.90, 1.17] | 無穩定 depth 效果 |
| Read evaluable，HP-matched n=5,017 | 0.96 [0.79, 1.16] | 無穩定 depth 效果 |
| VAF evaluable，HP-matched n=5,017 | 1.00 [0.84, 1.18] | 無穩定 depth 效果 |
| Read exact/induced，可評估 n=4,038 | 0.75 [0.64, 0.88] | 仍反向；較像 residual selection/model mechanics，不是 accuracy |
| VAF exact/induced，可評估 n=3,860 | 1.11 [0.93, 1.32] | 未加入 candidate 時無穩定效果 |
| VAF exact/induced＋candidate | 0.82 [0.68, 0.99] | BH q≈0.071；不足作因果結論 |

結論：**depth mismatch 不是現有資料中最強、最一致的解釋。** 真正因果估計需要同一 BAM 的 randomized/downsampled depth intervention，而不是觀察性 quartile。

## 5. 四類原因分解

### 5.1 Data sampling：有跡象，但尚未完成因果驗證

`[L1]` Latest all-caller exact-locus raw VAF：76,721 shared alleles、CCC=0.9339、MAE=0.0624；93.07% 位點落在 simple independent-binomial 95% band，noise RMSE ratio=1.0886。Baseline 對應值亦近似（93.14%、1.0859）。

在固定區域中：

- 4,754 regions 的所有可測試 sites 都在 binomial band 內。
- 930 regions 至少一個可測試 site 超出 band。
- 36 regions 因 pooled variance=0 無法作該檢定，未誤列為 incompatible。
- 有 incompatible site 的區域，read/VAF conditional exact/induced 分別低 9.35/10.53 pp；VAF conflict 高 9.20 pp。

這表示小的 per-site AF 波動可能透過離散排序放大成 tree winner 差異。但仍不能說「sampling 已解釋 topology」：

1. Raw binomial test 與 topology/VAF 使用重疊 reads，非正交。
2. Simple binomial 未含 overdispersion、mapping/basecalling、allele bias、HP assignment 與 CN。
3. Global 93.07% 是位點分母；tree 是多位點組合事件，兩者不能直接相等。
4. 尚無 within-source split-half/downsample ceiling；不知道跨來源 31.97% VAF conflict 是否超過同一來源重抽的預期。

**Verdict：sampling contribution = plausible／partially supported；sampling root cause = unproven。**

### 5.2 Source pipeline／region inventory：可觀察，但不可再拆

`[L1]`

- HP unit count mismatch 703/5,720（12.29%）。依 primary rule，read/VAF 703/703 全部 not evaluable；coarse agreement 只有 50.78%，相對 HP-matched 72.00%。這是結構 gate，不是統計巧合。
- HP-matched 後仍有 read not-evaluable 979，其中 957 為 `no_shared_site_pair_relation`，22 為 shared-site recurrence fail-closed。
- VAF not-evaluable 1,860：HP mismatch 703、no shared relation 934、missing VAF 198、recurrence not evaluable 25。
- Caller site mismatch 186/5,720 只占 3.25%；read conditional exact/induced 未下降，但 VAF conditional exact/induced 由 46.85% 降至 30.00%。
- Latest release 少 77/15,713 alleles、影響 73 regions；這 73 區 read conditional exact/induced 僅 13.21%，但樣本很小且是跨 release selection，不能作全域主因。

這些差異可由 basecaller、alignment、variant PASS、read composition、phasing、HP split/merge、region construction 任一環節造成。沒有相同 molecules 的 paired pipeline matrix，就不能定位到單一模組。

### 5.3 Identifiability／candidate multiplicity：目前最強的主要限制

`[L1/L2]`

- Read projected candidate topology max=1：361 regions，其中 exact/induced 325（90.03%）。
- Read max>20：395 regions，其中 exact/induced 65（16.46%）；相差 −73.57 pp。
- VAF projected topology max=1：3,216 regions，其中 exact/induced 1,742（54.17%）。
- VAF max≥2：644 regions，其中 exact/induced 48（7.45%）；相差 −46.71 pp。
- 每 2× read candidate max 的 cluster-robust adjusted OR=0.735 [0.685, 0.788]；每 2× VAF candidate max OR=0.119 [0.084, 0.168]。
- 調整 candidate 後，`k≥5 vs k=2` 仍分別為 read OR=0.535 [0.369, 0.775]、VAF OR=0.105 [0.066, 0.169]；所以 k 除了增加候選數，也提高關係矩陣與 HP forest 的 combinatorial difficulty。

Candidate multiplicity 並非獨立「生物原因」；它與 exact-set endpoint 具有數學耦合。它能可靠指出 **資料不足以唯一識別**，不能證明 solver 錯或樣本真的不同演化。

### 5.4 Method conflict／VAF、CN 與 external clustering

`[L1/L2]`

Read candidate set 只出現 2 個 disjoint conflicts，不能解讀為幾乎完全一致，因為廣候選集合本來就容易 overlap。VAF top-set 縮小集合後：

- Read `resolution_A_more_specific` 中有 642 區轉成 VAF conflict。
- Read `strict_full_exact` 中有 321 區轉成 VAF conflict。
- Read `shared_core_only` 中有 215 區轉成 VAF conflict。
- 合計 VAF conflict 1,234/3,860（31.97%）。

這代表 VAF 提高 decisiveness 的同時，也暴露來源間 scoring instability；不能只報它增加的 exact regions。

CN/LOH 也顯著改變行為：full any-LOH 對 full no-LOH 的未調整 VAF conditional exact/induced 高 29.92 pp；調整 k/depth 等後 OR=2.48 [2.03, 3.01]，加入 candidate 後仍為 1.98 [1.61, 2.43]。這較像 LOH／高 allele fraction context 讓 VAF ranking 更容易集中，而不是 tree truth 被外部確認；因為 CN 是兩來源共用輸入。

PyClone-VI 亦支持同樣的 claim ceiling：

- Joint fit 30,262 mutations 的 95.29% 主群與共享 labels 是 model construction 結果，不是獨立再現。
- 兩來源 separate fits：subclonal mutation Jaccard=0.381、clonal/subclonal κ=0.544、both-subclonal ARI=0.325；兩側都 subclonal 277、either-subclonal 727。
- 這支持 dominant component／binary state 的部分再現；不支持 exact minor clone 或演化樹高度一致。
- PyClone-VI 不產生這些區域的 ancestry tree；不能用 cluster agreement 反推 InterSubMod tree accuracy。

## 6. 能支持與不能支持的主張

### 6.1 可支持

1. `[L1]` 兩資料的 exact alleles 與 raw VAF frequency structure 高度相近，且多數 locus-level 差異在簡單 sampling band 內。
2. `[L1]` Coarse regional category 有 69.39% agreement，read/VAF exact-or-induced 在可評估區分別 39.60%／46.37%；可稱 **partial technical reproducibility**。
3. `[L1]` Region complexity、candidate multiplicity、HP mismatch 與 CN/LOH context 對可評估性／exact yield 有強烈關聯。
4. `[L2]` 現有結果較符合「共同 dominant structure＋不穩定的 exact/minor detail」，而不是兩個資料完全無關。
5. `[L2]` 方法可作 structure-signal detection、candidate generation、abstention 與跨來源部分再現分析。

### 6.2 不可支持

1. 「每區已恢復唯一真實演化樹」。
2. 「69.39% coarse agreement 等於 69.39% exact tree accuracy」。
3. 「VAF 選出一棵最可能樹，因此該樹被確認」。VAF 是 same-read heuristic，未校正 source-specific CN/purity/multiplicity，也不是 posterior truth probability。
4. 「兩資料 conflict 代表各自發生不同生物演化」。技術來源、passage、library、HP/caller 與 model sensitivity 尚未排除。
5. 「93.07% binomial-compatible 證明 topology 差異只是抽樣」。位點與樹的事件層級不同，且缺 within-source ceiling。
6. 「癌症基因／藥物 annotation 驗證樹」。annotation 只提供 biological context，沒有祖先方向或 exact-tree truth。
7. 「PyClone joint 近乎一致證明外部工具確認」。joint labels 是共享建模；separate minor 指標才是較嚴格 endpoint。

## 7. 目前 blockers：如何分清資料抽樣、來源流程、方法學與真實差異

| Blocker | 目前缺口 | 解鎖後可回答 |
|---|---|---|
| Within-source split-half | 同一 BAM 依 molecule/read 隨機二分，重跑 region/HP/tree 50–100 seeds | cross-source 差異是否超過同來源 noise ceiling |
| Depth-matched intervention | 高 depth 來源隨機 downsample 到低 depth；固定 loci／HP／region universe | depth 的因果效果，而不是 genomic confounding |
| Union-site BAM recount | 在兩側 callset union 固定座標重數 DP/ALT/HP，不要求雙側 PASS | caller intersection selection bias 大小 |
| Pipeline factorial matrix | 同一 molecule set 經相同／不同 basecaller、aligner、phaser、caller | 差異定位至哪個 pipeline stage |
| Source-specific CN/purity | DORADO 獨立 CN/LOH/purity/multiplicity | CCF/VAF ordering 是否仍一致 |
| Passage/library provenance | culture passage、DNA aliquot、library、flowcell、basecaller版本 | technical drift 與 biological culture drift 的可辨識性 |
| Orthogonal tree truth | single-cell DNA、colony、synthetic mixtures、validated multi-region/time-course | exact direction/tree accuracy、precision、recall |

在上述資料未補前，最合理 verdict 是：

> **Identifiability-dominant, pipeline-contributed, sampling-plausible, biological-divergence-unresolved。**

## 8. 統計紅隊 QA

### 8.1 已做

- 固定 5,720 分母與 conditional evaluable 分母分開。
- Read、VAF、coarse resolution 分開，不把 coarse 當 exact。
- 11 類 factor strata、123 個預先列出的 binary contrasts。
- Rate difference 以 chromosome＋1 Mb block bootstrap 500 次給 95% CI。
- Fisher exact p 只標為 naive/exploratory；全 contrasts 做 BH q，但不作 primary claim。
- 9 個 logistic diagnostic models 使用 1 Mb block cluster-robust SE；103 coefficient rows，非 intercept 全部做 BH。
- Missing／HP mismatch／recurrence fail closed，不從分母靜默刪除。
- Baseline vs latest release 分開；CN full/partial/unavailable 分開。

### 8.2 仍需注意

1. 多個 regions 可能共享 reads、HP block 或 genomic context；1 Mb cluster 只能部分吸收依賴。
2. Candidate multiplicity 與 exact-set endpoint 在定義上耦合，OR 只能當 identifiability descriptor。
3. VAF delta、binomial compatibility、VAF winner 來自重疊 reads，任何 association 都是同證據診斷，不是獨立驗證。
4. CN/LOH 只在 PyClone primary selection 中完整／部分可得，且兩來源共用；LOH association 可能含 selection bias。
5. Q4 vs Q1 是觀察性 strata；不可當 randomized depth test。
6. 5,720 母群已 conditioned on complete-both；應另以 all-region／union-site estimand 做 missingness sensitivity。

## 9. 建議的正式驗證設計與判定門檻

1. **Within-source ceiling**：各來源各做 ≥50 個 molecule-level split-half／matched-depth replicates；對 coarse、read exact/induced、VAF exact/induced、conflict 分別建立分布。
2. **Cross-source excess test**：primary effect 定義為 `cross-source disagreement − pooled within-source disagreement`；以 chromosome/HP-block bootstrap 給 CI。CI upper≤預先設定 non-inferiority margin 才可稱跨來源再現。
3. **固定 union universe**：caller union sites 全部 BAM recount；missing 不視為 reference，另列 `no_coverage`、`no_alt_support`、`HP_missing`。
4. **Complexity-standardized headline**：依 k、HP count、candidate-size bin、CN/LOH、depth bin 做 direct standardization；不可只報 raw 69.39%。
5. **Negative controls**：在 chromosome×k×HP×candidate-size×depth strata 內 permutation；另做 coordinate permutation，檢查 marginal VAF 相似但 exact edge 應被破壞。
6. **Orthogonal accuracy**：synthetic truth 或 single-cell truth 上才報 exact tree accuracy；真值缺失時只報 reproducibility／compatibility／abstention。
7. **多重檢定**：預先指定 3 個 primary endpoints；其他 strata 為 exploratory，BH-FDR；對 overlapping contrasts 優先報 CI 與 effect size。

## 11. 最終紅隊判定

**工程／實用性：GO with abstention。科學證明「每區唯一真樹」：NO-GO。**

目前數字足以證明方法在同 cell line 的跨來源資料中能找到部分重複的粗結構、read relation constraints 與 frequency signal，也能誠實指出不可判定／候選多重區域；這是實用價值。它還不足以把每區候選樹升格為唯一真實演化，也不足以把 residual conflict 判定為真實 biological divergence。最優先的下一個實驗不是再提高 VAF winner 的決斷，而是 **within-source split-half＋depth-matched downsample＋union-site recount**；只有先建立技術噪音天花板，才能區分資料抽樣、來源流程與方法本身。
