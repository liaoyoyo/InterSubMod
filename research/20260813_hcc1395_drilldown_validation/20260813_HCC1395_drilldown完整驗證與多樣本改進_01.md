# HCC1395 drilldown 完整稽核與多樣本改進

> [!CAUTION]
> **Final gate：BLOCKED for scientific/external claims。** 本報告完成的是全量工程與資料產品稽核，不是 truth-set validation；沒有 TP/FP/FN、precision、recall、F1 或 causal effect 的證據鏈。

> [!WARNING]
> **Multi-sample status：PARTIAL。** 已盤點 7 份同 schema/model/AF-basis 的 topology datasets（6 個 biological samples + 1 個 HCC1395 technical replicate），但沒有 7 份等價的 ISM/lineage drilldown bundles，因此不可宣稱跨樣本甲基化或 lineage 已驗證。

## 技術摘要：工程可用，但科學引用仍被擋住

**Situation。** HCC1395 v1 有 11,590 個 regions、19,849 個 distinct sSNV，asset inventory 計得 32,604 張 panel PNG；topology/MLHP 目前 hash 仍與 receipt 相符。其作為單樣本 observation UI 有實際價值。[L1]

**Complication。** v1 自檢是 10 PASS / 1 FAIL / 1 SKIP，receipt 沒有 generator commit、claim ceiling 與可重建的 ISM hash；v3 雖是 11 PASS / 1 FAIL / 0 SKIP，仍被同一科學 gate 擋住。兩者都缺 truth benchmark，cluster 軸又存在 construction-driven double-dipping；LCA pre/post 也不是同輸入對照。[L1]

**Question。** 應否直接以 v3 取代 v1，或把任一版本提升為多樣本／對外證據？

**Answer。** 不應。v3 的 topology 完全未變，ISM topology linkage 只從 16,195 增至 16,304（+109 loci；81.591% → 82.140%），但 PNG 與 IGV assets 顯著增加，而且 provenance 仍未閉合。2026-07-26 standalone 的 progressive disclosure 值得參考，但其 A/B taxonomy、raw linkage 與 472→14 selection contract 不可搬入 current axes。正確路徑是：保留 v1/v3 不覆寫，採用已完成的 fail-closed、dynamic authority、receipt、observation-scope 與 regression contracts，再以 clean source/new output 重建候選 v4；多樣本則先過 manifest compatibility gate。[L1 + L2]

本輪服務 **G3**（釐清 read-level epigenetic 指標的可解讀性）、**G4**（sample isolation 與 cohort contract）、**G5**（可重現、可外部稽核的 receipt/test/UI authority）。

## 甲基化缺失不是隨機：高 k 位點 coverage 急降

`ISM linkage` 定義為「topology distinct sSNV 中，在 methylation summary 找到對應列的比例」。v1 在 k=1、2 時分別為 85.42%、85.16%，但 k=7 降至 67.36%，k=8+ 只有 41.05%；v3 的 k=8+ 也只有 41.25%。因此任何 methylation-conditioned 統計都要明示 coverage by k，不能把 missing 當 0 或當隨機缺失。[L1]

![ISM availability 隨 active k 降低；v1/v3 window 不同，不是受控 A/B](figures/03_methylation_coverage_by_k.png)

**Implication。** 後續報告至少要同時呈現 numerator、denominator、k-bin、window 與 missing reason；聚合前應檢查 coverage 差異是否改變樣本排序。此圖是 selection-bias diagnostic，不是生物效應圖。

## LCA 數字可描述，但不能當純 LCA 增益

22 條 shared chromosomes 的 `lv_written` 從 86,037 增至 427,519（約 4.969×），post receipts 記錄 `lca_resolved=341,819`，而 net new `lv_written=341,482`，兩者差 337。這些數字本身可重算；因果 gate 仍是 **FAIL**：[L1]

- pre 有 22 files、post 有 24 files，交集 22；chrX/chrY 只在 post。
- 只有 15/22 shared chromosomes 的 `in_bam` 相同。
- 0/22 的 `threads` 相同；threads 本身不是生物 confounder，但此差異破壞「唯一變項只有 LCA」的 controlled-comparison 前提。
- 22/22 的 sample identity 通過，且逐染色體 non-LCA stats 在 missing-as-zero 口徑下相等；這只能說 sample 與部分統計自洽，不能消除 input/parameter confounding。

因此，`4.969×` 必須標為 descriptive pre/post difference。若要稱為 LCA effect，需同 BAM、同 threads、同 code/input hashes，唯一變項只有 LCA treatment。

## 2026-07-26 standalone：版型可參考，方法與類別不可直接套用

舊頁最值得保留的是閱讀順序：claim ceiling → population funnel → 簡潔 filter → 折疊案例卡 → locus/structure/paired heatmap 共置。但 read-only 全量重算揭露四個 P0 方法缺口：[L1]

|---|---:|---|
| legacy class rule | 30,077/30,077 可重建；但採 B-first priority | 不搬分類，只搬資訊架構 |
| B 組純度 | 4,025 B 中 3,544（88.0%）亦達 `V_allele≥0.7` | B 不可作純 HP negative control |
| headline linkage | raw `coread≥2` 20,535；powered 17,749；powered+both-somatic 17,141 | raw hit 不可稱 confirmed linkage |
| branch candidates | 472 中 68 含 FP；27 無 powered+both-somatic branch | 不稱 TP somatic backbone confirmed |
| display selection | A≥3 eligible 18，但頁面只展示 14；4 個省略案例的熱圖亦存在 | 14 是 selection-incomplete curated subset |

舊頁 `7,415 → 518 → 472 → 14` 是 selection funnel；14/472=2.97%，14/7,415=0.189%，不是 prevalence。7,415 components 又由 TP∪FP raw-pair graph 構成，不能與 current 的 11,590 topology regions 對接。完整方法證據見 `InterSubMod/research/20260813_hcc1395_drilldown_validation/legacy_browser_method_audit.md`。[L1]

### Legacy/current coordinate crosswalk 明確拒絕一對一 mapping

| 指標 | n |
|---|---:|
| legacy unique `chrom:pos` | 30,077 |
| current v1 topology unique `chrom:pos` | 19,849 |
| overlap | 16,566 |
| legacy-only / current-only | 13,511 / 3,283 |
| coordinate Jaccard | 49.658% |

兩側都沒有 REF/ALT，因此以上只是 coordinate overlap。更重要的是 schema 不同：legacy 是 ±5 kb、Cramér's V、exclusive B-first taxonomy；current v1 是 ±1 kb、raw-p multi-label axes、exact-PS topology。在 `legacy A ∩ shared coordinates ∩ current L4 available` 的 555 loci 中，current ALT raw-significant 412（74.2%）、HP 218（39.3%）；同一分母定義下的 legacy B 為 2,149 loci，其中 current ALT 1,540（71.7%）甚至略高於 HP 1,489（69.3%）。這直接否證 `legacy A=current ALT / legacy B=current HP`。[L1]

Crosswalk 讀的是 immutable、尚未 harden 的 HCC1395_v1 `index.html`，因此其 axis code 僅為 0–8；新版 source 後加的 `AXIS_UNTESTED=16` 不會回填舊 bundle。`results/legacy_browser_crosswalk.json` 已把這個 encoding provenance 寫成機器可讀欄位，避免把「舊檔沒有 16」誤解成所有 summary 都已檢定。[L1]
