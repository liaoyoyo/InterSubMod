# HCC1395 跨 PS 區域與 HP 方向敏感度驗證

用 Claim–Evidence–Boundary：**確認 current HCC1395 流程會把不同 PS 的同數字 HP 合併，而且相對 HP flip 能實際改變 T／Topo；因此 865 個 mixed-PS regions 尚不能稱為已完成方向矯正（影響：高，信心：高）。**

## 一句話給教授

HCC1395 的 8,222 個建樹區域中，有 865 個（10.52%）包含多個 phase blocks；現行程式有保存 PS，卻只按 HP1／HP2 的數字合併 reads。實際把其中一個 PS block 的 HP1／HP2 對調後，CN-neutral 區域可由 `T=1、Topo=1` 變成 `T=3、Topo=2`，表示 current mixed-PS topology 依賴尚未校正的 block 方向。

## 1. 最白話的概念

- **PS**：一個局部 phase block 的編號。
- **HP1／HP2**：該 block 內兩邊 haplotype 的局部名稱。
- 不同 PS 的 `HP1` 不保證代表同一條實體染色體；整個 block 對調 HP1／HP2 仍可能是同一個合法 phasing 解。

可把它想成兩間教室各自把座位叫「左邊、右邊」：第二間教室的左邊不一定對應第一間教室的同一個人。未先對齊就把所有「左邊」學生合併，分群結果可能改變。

現行流程：

```text
PS-A 的 HP1 reads ─┐
                    ├─ 只看 HP 第一碼 → family 1 → 建樹
PS-B 的 HP1 reads ─┘

PS-A 的 HP2 reads ─┐
                    ├─ 只看 HP 第一碼 → family 2 → 建樹
PS-B 的 HP2 reads ─┘
```

問題不是「PS 應該變成一條拓撲 edge」，而是：**PS 應先防止未定向的 blocks 被錯誤合併。**

## 2. 程式是否真的會跨 PS？答案是會

1. Region 只依相鄰 sSNV gap 切；gap `>50 kb` 才開新區域，完全沒有 PS boundary。
2. HP 與 PS 都正確從 sidecar 讀入。
3. 建樹前 `1/1-1/1-2→family 1`、`2/2-1/2-2→family 2`；分組 key 沒有 PS。
4. PS 只輸出 `phase_set_counts`／`phase_set_HP_counts`，契約明寫 `preserved_for_QC_not_used_as_topology_edge`。
5. Solver 只讀 `populations_by_hp` 與 `subread_groups_by_hp`，因此收到的已是跨 PS pooled patterns。

Frozen source 證據：

- `make_groups` 只看距離：`.../source_bundle/files/imported/001_sm_linkage_genomewide.py:235-246`
- HP family collapse：`.../source_bundle/files/imported/002_sm_multilocus_combinations.py:85-101`
- pattern 只按 family 累積：同檔 `:171-190`
- PS 僅作 QC：同檔 `:227-229,276`
- solver 不讀 PS：`.../source_bundle/files/imported/004_layered_tree_reconstruction.py:115-132`

這也符合 phase-set 定義：相同 PS 才是同一 haplotype block；不同 PS 的關係無法直接確定。未經外部 orientation，整個 block 的 HP1／HP2 對調不等於錯誤。

單位：current raw-all LongPhase-S PASS v5 的 retained MLHP region，chr1–chr22。

因此 mixed-PS 並非全部只是單條雜訊 read。

- alignment/group exposures＝1,934,226
- exact sidecar matches＝1,934,226
- missing＝0

所以根因不是 HP／PS 接錯 read，而是**接對之後，PS 沒有進入 inference unit 或 orientation gate**。

## 4. HCC1395 CN-neutral 實例

Region：`chr20:29077065-29104598`

- CN＝neutral
- k＝2，位置 29,077,065 與 29,104,598
- PS `28828000`＝17 tagged reads
- PS `29125312`＝18 tagged reads
- 353 alignment exposures 全部 exact join；350 reads 有至少一個可用 state，其中 35 有 PS、315 沒有 PS

測試方式：固定第一 PS 作 anchor；只把第二 PS 的已知 reads 做 `HP1↔HP2`，其餘資料與 solver 完全不改。

| 結果 | Native labels | Flip 第二 PS |
|---|---:|---:|
| primary HP families | 2 | 2 |
| **T** | **1** | **3** |
| **Topo** | **1** | **2** |
| Structural class | exact + topology unique | exact multiple + topology multiple |
| Morphology | Single | Sister 或 Direct |

Native 的 HP2 只有一個形狀：

```text
ROOT → H_AR
```

Flip 第二 PS 後，HP2 出現三棵候選、兩種形狀，包括：

```text
# Sister
ROOT ─→ H_RA
     └→ H_AR

# Direct
ROOT → H_AR → H_AA
```

這個結果的正確解讀是：

- **可以確定** current 結果對 PS 方向敏感。
- **不能確定** native 或 flip 哪一個才是真實方向；資料沒有提供答案。
- 315 個無 PS reads 更不能被當成已定向證據；本 probe 保守地只翻 35 個已知 PS reads，結果就已改變。

## 5. 12-region 高對比壓力測試

預先定義條件：`nPS=2、k≤4、每個 PS≥8 tagged reads、兩 block 的 numeric-HP majority 相反`，再依 balance × purity 選前 12 區。

結果：

| 驗證項目 | 結果 |
|---|---:|
| Native patterns／T／Topo 重現 canonical | 12/12 |
| Flip 後 HP-family unit signature 改變 | 12/12 |
| Region T 改變 | 9/12 |
| Region Topo 改變 | 8/12 |
| Region morphology options 改變 | 7/12 |
| Primary-family 數改變 | 6/12 |
| Structural class 改變 | 6/12 |

這是刻意富集的 stress panel，**不可說 HCC1395 的 865 區有 100% 受影響**；它只證明 failure mode 在實際 HCC1395 reads 中存在，且不是單一例外。

## 6. 最終判斷

| 問題 | 判定 |
|---|---|
| Region 會不會跨 PS？ | **會；865/8,222** |
| HP／PS sidecar 有沒有接錯？ | **沒有；1,934,226/1,934,226 exact** |
| 不同 PS 的同數字 HP 會不會被合併？ | **會；程式只用 HP family key** |
| 這會不會真的改變樹？ | **會；neutral 案例與 enriched panel 已實證** |
| 865 區是否全部錯？ | **未知，不能這樣說** |
| Current mixed-PS topology 是否已矯正？ | **沒有；應標 orientation-unresolved/sensitive** |

單一 PS regions 不受「跨 PS 任意 flip」這個特定問題影響，但仍不代表已排除 CN、partial-read、hidden-state、VAF 或 clone-identifiability 等其他限制。

## 7. 正確修正方向

1. Primary inference unit 改為：

   ```text
   dataset × chromosome × known PS × HP family × read-linked component
   ```

2. Missing-PS reads 另列 unanchored／auxiliary，不得直接拿來跨 block 對齊。
3. 若有可靠 bridging reads 或 germline anchor，建立 PS-block signed graph，判定兩 blocks 為 same／flip。
4. 若無法定向，對 b 個 PS 枚舉 `2^(b-1)` 個相對方向；固定一個 block 可移除無生物意義的全域交換。
5. 每個方向重跑相同 solver，只把所有方向都一致的結論標為 `orientation-invariant`；不同則 `orientation-sensitive` 並保留範圍。
6. VAF 排序放在 PS correction 後。VAF 只能排序已建立的候選樹，不能修復一開始把 reads 分到錯誤 HP family 的問題。

HCC1395 865 個 mixed-PS regions 的完整方向空間只有 1,802 configurations（含 native；扣除 native 為 937 個替代 flips），在組合數上可全量驗證。

## 8. 可對教授使用的精確敘述

> HCC1395 的 8,222 個 retained 建樹區域中，865 個跨越多個 PS。HP/PS tag transport 本身完全正確，但 current pipeline 建樹時只按 HP family 聚合，未先校正不同 PS block 的相對 HP1/HP2 方向。CN-neutral 實例顯示，只翻轉第二個 PS，就可使 T 由 1 變 3、Topo 由 1 變 2。因此 current mixed-PS 結果應視為待 orientation-invariance 驗證的局部 mutation-state candidates，而非已確認的 clone/subclone topology。
