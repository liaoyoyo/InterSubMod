## 後續 final-diff correction

Claude Code 審查後的 Codex 唯讀 final-diff audit 另外發現一項 P1：
原綠線使用 `global_best_edge_incidence`，在 tied rows 代表多棵
global-best trees 的 edge union，不能稱為 selected tree。最終版本已拆為：

- 灰線：all-minimum edge union；
- 藍線：all-global-best edge union；
- 綠線：canonical deterministic selected exemplar。

H2009 第一個 `best_tree_ties=6` region 已加入 Playwright regression，
要求藍色 edges 多於綠色 selected edges，且綠色恰為一棵 3-edge tree。
