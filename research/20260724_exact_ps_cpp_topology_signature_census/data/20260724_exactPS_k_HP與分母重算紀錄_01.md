# exact-PS×HP k、HP 與分母守恆重算紀錄

> **Task Type B — Comprehensive validation。**本紀錄服務 G4（多樣本一致性與 reproducibility）及
> G5（可被外部驗證的工程證據）；全七技術資料、chr1-22，沒有 subset。

## 結論

用 Assertion–Evidence：

- **Assertion：七組資料均已套用 exact nonmissing PS × primary HP × strict read-linkage。**
  Evidence：七組各有 22 個 threshold-3 component/container artifacts，所有逐樣本一致性檢查通過。
- **Assertion：source component 共 255,752 個，其中 170,131 個 k=1 singleton 不進樹，
  85,621 個 k≥2 source W 進入 bounded partition。**
  Evidence：`255,752 = 170,131 + 85,621`。
- **Assertion：final topology input 共 98,955 groups，原始位點數全部落在 k=2–12。**
  Evidence：`original_bit_count/n_sSNV k=1=0`、`k>12=0`，k=2–12 合計 98,955。
- **Assertion：每個 k-band 已同時保存區域數與 sSNV membership 數。**
  Evidence：source memberships 逐 component 實數合計 613,480；final memberships 合計
  439,685，兩者均通過逐樣本與 cohort 守恆。
- **Assertion：HP1、HP2 在圖結構單位上約各半。**
  Evidence：final groups 為 HP1 49,550（50.0733%）、HP2 49,405（49.9267%）。
- **Claim ceiling：**此 census 驗證分母、k 與 HP 分流，不驗證 AF topology signatures，
  也不把 HP1/HP2 數量解讀為 cell/clone prevalence。

## 定義與分母

- HP1：合併 raw family `1/1-1/1-2`。
- HP2：合併 raw family `2/2-1/2-2`。
- source component：同一 exact PS、同一 primary HP family 中，threshold-3 retained endpoint
  graph 的 connected component。
- source W：source component 中 `k≥2` 者。
- source k 百分比：分母為該資料集全部 source components。
- source k membership 百分比：分母為該資料集全部 source component sSNV memberships；
  `k>12` 直接逐 component 計算 `Σ(k×component_count_k)`。
- final k：MLHP `n_sSNV`，等同 topology `original_bit_count`，是在 active-column reduction 前計數。
- final k 百分比：分母為該資料集全部 final topology groups。
- final k membership 百分比：分母為該資料集全部 final group sSNV memberships。
- active memberships、HP memberships 都可能重複計入同一 genomic locus；不可與 unique sSNV 混用。

3. 本 census 不計算 AF 最佳樹的 exact topology-signature tie classes；該結果由同目錄 companion
   C++ topology-signature census 另行產生。
