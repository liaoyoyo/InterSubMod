# COLO829 Sample

- 一句結論：黑色素瘤樣本；無 HC BED（用 num_callers≥2）；TO 模式無甲基化（ONT_R10 限制）
- 適用對象：無 HC BED 情境測試、Melanoma 特定分析
- 可直接執行命令（驗證日期：2026-04-22）：
  ```bash
  ls /big8_disk/data/COLO829/NYGC/
  ```

## 特殊處理：無 HC BED

**替代方案**：用 `num_callers ≥ 2` 作 confidence proxy
```bash
bcftools view -i 'INFO/num_callers >= 2' \
  /big8_disk/data/COLO829/NYGC/...vcf.gz > confident_colo829.vcf.gz
```

**影響**：
- F1 可能較 HCC1395 低（無 HC BED 排除低信心區）
- Truth set 異質性較高

---

## 特殊限制：TO 無 methylation

**現象**：COLO829 的 ONT_R10 data 部分缺 MM/ML tag
**後果**：TO pipeline 的甲基化分析無法執行（或大量 NaN）
**解法**：
- 使用 paired_full 為主要 benchmark
- TO 結果需特別註明「partial methylation coverage」

## 已知 HC BED 問題

- NYGC 提供 Illumina-based truth，目的為交叉驗證，無定義 long-read HC BED
- 長讀測序可能有額外 callable region 但無法作 TP/FP 判定
