# Changelog

This file records externally relevant InterSubMod changes. The current entry is an
**unreleased, non-production, non-clinical research handoff candidate**, not a release-ready
product. The reserved name `research-handoff-2026.08.1` has not been tagged or published as a
GitHub Release.

## [Unreleased — research handoff candidate]

### Research boundary

- Kept the frozen 2026-08-01 authority as the sole authority for the handoff's scientific
  numbers: 7 technical datasets, 6 biological IDs, and chr1–22.
- Fixed the claim ceiling at **zero confirmed cellular subclones** and **zero confirmed linear
  ancestry relationships**. Methylation remains association-only. Allele-specific copy
  number, copy-neutral LOH, purity, and multiplicity remain outside the frozen candidate
  reconstruction; optional `--loh-bed` is stratification/annotation only and does not make
  CN/LOH-corrected cellular inference.
- Clarified that 63,506/71,955 (88.2579%) is a frozen-model, ranked-unit graph-shape statistic,
  not biological accuracy, tumour prevalence, or a validated cellular phylogeny.
- Kept LongLineage as a separate `NOT_READY` research preview; `P3/P4/P5/P7/P8` remain
  **BLOCKED**, and its production `run` remains intentionally fail-closed.

### Added

- A governed 2026-08-13 handoff package with research timeline, software/data-flow guide,
  bip7/bip8 instructions, AI context, acceptance questions, and standalone HTML overview.
- Machine-readable dataset, run, artifact, claim, machine-path, storage-root, workflow, and
  authority/supersession registries with schemas and validation.
- Frozen authority hash replay, repository-hygiene receipts, portable site-profile tooling,
  and a tracked tiny synthetic fixture for clone→build→run→schema smoke testing.
- Public-document claim inventory and fail-closed validation covering Markdown, Wiki sources,
  standalone HTML, source paths, and publication-state distinctions.
- Root citation, contribution, security, and changelog metadata for external handoff.
- A schema-validated, clean-commit release-manifest/checksum builder that writes out of tree
  and preserves blocked-versus-approved gate semantics. Closed aggregate and LongLineage
  receipt schemas require the exact 20-gate acceptance set, frozen 19/19 authority replay,
  pinned authority/denominator hashes, and pinned LongLineage candidate; no final checksum
  bundle is generated by this source change.
- Gate-specific acceptance schemas, raw execution-log hash/URI binding, commit-pinned
  15-file reader validation, recursive symlink resolution, and cross-repository LongLineage
  commit/tree/remote-branch byte verification for fail-closed approval.

### Changed

- Corrected public explanations of molecule-level linkage versus cellular lineage,
  denominators, NHD behavior, the 199-column summary schema, and `tree.nwk` as a read
  dendrogram.
- Separated LongPhase-S/TO phasing outputs, exact-PS/LongLineage candidate reconstruction,
  InterSubMod per-region methylation/statistics, and Python/HTML presentation into distinct
  provenance chains.
- Replaced unsupported claims about tagged-BAM storage with an explicitly historical,
  sampled-identity, `PARTIAL/NON_FINAL` inventory. The cross-generation 294.2669× value is
  documented only as a storage-footprint quotient.
- Synchronized source README, Wiki upstream files, Pages upstream, and explanation-center
  content around the bounded claim registry; live publication remains a separate gate.

### Validation recorded so far

- Frozen authority replay: 19/19 registered artifact, binary, and source-snapshot hashes match.
  This proves frozen byte identity only and does not rerun TiB-scale science.
- Local clean build, dynamically enumerated CTest/Python suites, and tiny synthetic E2E have
  bounded PASS receipts. The fixture is DEMO/SMOKE evidence, not biological validation.
- Repository hygiene removed tracked absolute/broken symlink and local-settings hazards from
  the handoff source line without rewriting Git history or deleting archived evidence.
- The public-claim correction source is materially improved, but source validation does not by
  itself prove default-branch, Wiki, Pages, About, or Release publication state.

### Still blocked

- bip7 still lacks four required local data checksum locators and an exact final-commit
  fresh-clone acceptance receipt.
- bip8 has no host-local fresh-clone/build/test/synthetic/real-data preflight receipt.
- Remaining public claims and live GitHub surfaces have not all been verified against one
  immutable release commit.
- The project-level SPDX choice is unresolved: GPL-3.0 text is present, but source headers and
  registry metadata do not yet provide one consistent `GPL-3.0-only` or
  `GPL-3.0-or-later` declaration. Maintainer confirmation is required.
- LongLineage source-origin, license/dependency, public-safety, and `P3/P4/P5/P7/P8` gates are
  not all closed.
- Therefore the aggregate verdict remains **RELEASE_BLOCKED**: no production tag, GitHub
  Release, or release-ready claim is authorized.
