## Pattern lookup quick table

| Source `.md` pattern | Use component | Notes |

| `🚨` / `⚠️` / "撤回" / "blocker" | `callout_critical.html` | Red-frame, high visual weight |

## Anti-pattern check (what NOT to copy)

Even from legacy self_phasing PPT, **do not replicate**:
- Hardcoded `<style>` repeating across 22 files (we now use design_tokens.css `:root` block)
- `:root` block duplicated in each file with inconsistent values (be consistent)
- Inline `style="..."` on slides (use class names instead)
- Color values that aren't in design_tokens.css palette
