# DACI Skeleton

> Intuit; Atlassian Team Playbook — Driver / Approver / Contributor / Informed

```markdown
---
framework: DACI
when: <角色釐清 / 責任分配 / cross-team project>
---

# Decision: <Title>

| Role | Person | Responsibilities |
|------|--------|------------------|
| **D - Driver** | <name> | 推動決策 + 收集 input + 確保 deadline |
| **A - Approver** | <name> | 最終決策權（通常 1 個） |
| **C - Contributor** | <names> | 提供 input + expertise |
| **I - Informed** | <names> | 決策後通知 + 不參與 |

## Decision summary

<決策內容>

## Deadline

<日期>

## Input collected from Contributors

- <Contributor 1>: <input>
- <Contributor 2>: <input>

## Approval status

- [ ] Approver signed off
- Date: ___

---

範例:

# Decision: Cycle 5 走 chr8 zone gate (vs LR direction)

| Role | Person |
|------|--------|
| Driver | 廖子游 |
| Approver | PI |
| Contributor | lab 同儕 + Claude (narrative-frame analysis) |
| Informed | clinical partner |

---

Framework: DACI (Intuit; Atlassian Team Playbook)
```
