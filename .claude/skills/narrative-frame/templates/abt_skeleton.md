# ABT Skeleton

> Randy Olson《Houston, We Have a Narrative》(2015), 《Narrative Is Everything》(2019) — And-But-Therefore

```markdown
---
framework: ABT
when: <1 句講完研究 / 科普 hook / verdict line / abstract>
---

AND <設定共識 / 上下文，1 句>，
BUT <衝突 / 對比 / 意外發現，1 句>，
THEREFORE <結論 / 後果 / 行動，1 句>。

---

範例:
- 「AND V6 修 priority bug 後 chr19 victims 100% rescued，
   BUT cross-sample 仍有 4 樣本 caller-F1-ceiling 卡住，
   THEREFORE 下個 cycle 應 PROBE chr8-specific zone gate。」

- 「AND 既有 7 報告類 skill 都有固定範本，
   BUT 50+ 業界 framework 無單一 SoT，
   THEREFORE 建立 /narrative-frame 動態挑選層取代固定範本。」

---

Framework: ABT (Randy Olson《Houston, We Have a Narrative》2015)
業界引用: 「Every scene has an and, but, therefore in it」
```
