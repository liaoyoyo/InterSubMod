# <Title>

## 1. Attention（吸引）

<最強 hook — 數字 / 故事 / 反常識>

<為什麼 audience 應該關心？放大痛點 + 量化影響>

## 3. Satisfaction（滿足 — 解決方案）

<你提出的方案如何滿足這個需求>

<明確的下一步 — 1 個 action，不模糊>

範例（説服 lab 投入 ISM 研究）:

1. **Attention**: 「ONT cancer caller 漏掉 90% 的 chr8 hotspot — 你的 lab 也在跑」
2. **Need**: 沒有 ISM context，cancer variant 100% 信任 caller，但 caller F1 卡 0.7
3. **Satisfaction**: ISM framework 用 methylation context 強化 caller，把 F1 推 0.75+
4. **Visualization**:
   - Positive: ISM 落地後 paper 主軸 + clinical adoption
   - Negative: 不做 ISM，5 年後仍 0.7 F1，competitor 先一步
5. **Action**: 下週 lab meeting 我 pitch ISM 五目標 — 你能空 30min 嗎？
