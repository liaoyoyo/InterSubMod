# GROW Skeleton

> John Whitmore《Coaching for Performance》— Goal / Reality / Options / Will

```markdown
---
framework: GROW
when: <教練對話 / mentoring / self-coaching>
---

【G】Goal: <你想達到什麼？— 具體 + 量化 + 時限>

【R】Reality: <現在離 Goal 多遠？— 客觀現況 + 阻礙 + 已有資源>

【O】Options: <有哪些路徑？— 至少 3 個（含 vanishing option）>

- Option 1: <pros / cons>
- Option 2: <pros / cons>
- Option 3: <pros / cons>

【W】Will: <你會做什麼？什麼時候？— 具體 1-3 actions + deadline>

---

範例（self-coaching: 下個 cycle 走 chr8 zone gate）:

【G】Cycle 5 在 4 週內驗證 chr8 zone gate ΔF1 ≥ +0.005 在 ≥2 樣本
【R】目前只有 HCC1395 single-sample +0.00699；caller_af direction 已 exhausted
【O】
- Option 1: 全力跑 chr8 zone (high-risk high-reward)
- Option 2: 同時 chr8 + low-F1 panel 雙軌（split focus，慢）
- Option 3: 先 1 週 pilot HCC1937 + HCC1954 確認 chr8 hotspot 存在再全跑
【W】
- 本週: 跑 HCC1937 + HCC1954 chr8 region pilot
- 下週: 若 pilot ≥1 樣本 positive → 推全 cycle；否則 NO-GO
- 4 週 deadline: ≥2 樣本 ΔF1 ≥ +0.005 → ⭐3 升級

---

教練問句（self-ask）:
- G: 真的想要這個 Goal 嗎？還是別人期待？
- R: 我是否避開難題沒寫進 Reality？
- O: 我有沒有列「vanishing option」（不做這事的選項）？
- W: Will 是否具體可驗證？

---

Framework: GROW (John Whitmore《Coaching for Performance》1992)
```
