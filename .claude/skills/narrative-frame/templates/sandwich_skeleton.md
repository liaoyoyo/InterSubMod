# Sandwich Feedback Skeleton

> 1960s management training — 正面 / 改進 / 正面

```markdown
---
framework: Sandwich Feedback
when: <入門級 1-on-1（不熟對方時）>
---

# Sandwich 結構

【+】Positive: <真誠的正面 — 具體，不空洞>

【-】Improvement: <改進建議 — 具體可行>

【+】Positive: <re-affirm positive + 鼓勵>

---

範例:

【+】「你 V6 binary 重構讓 code 比 V5 清楚很多 — 特別是 hp tag 兩層處理分離」
【-】「commit message 可以再寫細一點 — 把 17.3× 分解成 assignment 1.77 × priority 9.8 的因果寫進去」
【+】「不過整體 V6 真的是這個 cycle 最大進展」

---

⚠ Sandwich 的批評（Kim Scott《Radical Candor》）:

「Sandwich Feedback trains people to ignore the middle. 當對方意識到 pattern 後，正面評語會被 discount，改進建議也被忽略。」

→ **推薦改用 Radical Candor 2×2** 或 **SBI** 為主，Sandwich 只在低信任場合用。

---

Framework: Sandwich Feedback (1960s management training)
```
