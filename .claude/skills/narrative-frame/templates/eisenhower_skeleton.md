# 2×2

```
                    Urgent          Not Urgent
                ┌──────────────┬──────────────┐
                │              │              │
   Important   │  Q1: DO       │  Q2: SCHEDULE│
                │  (firefighting)│ (strategy)  │
                ├──────────────┼──────────────┤
   Not          │ Q3: DELEGATE │  Q4: DROP    │
   Important    │ (interrupts) │ (waste)      │
                └──────────────┴──────────────┘
```

## 4 象限分類

### Q1: Urgent + Important — **DO NOW**
- Bug 上線 + crisis
- Deadline 今天

### Q2: Important + Not Urgent — **SCHEDULE** ⭐ 最重要
- 戰略 / 學習 / 預防
- Q2 投入越多，Q1 自然減少

### Q3: Urgent + Not Important — **DELEGATE**
- 別人 interrupt
- 不必你做的 admin

### Q4: Not Urgent + Not Important — **DROP**
- 純浪費 / scroll feed
- 立刻刪

## 工作日重新分配規則

- 每天 ≥1hr 在 Q2（戰略）
- Q1 是 fire — 努力預防（Q2 投入）讓 Q1 縮小
- Q4 自動拒絕

---

範例（廖子游 2026-05-22 todo）:

- Q1: V6 commit pre-commit hook 失敗 → DO NOW
- Q2: narrative-frame v0.2 多語言 catalog → SCHEDULE（next month）
- Q3: 同學 ping 問 longphase 用法 → DELEGATE（指到 doc）
- Q4: scroll Twitter → DROP

---

業界引用: 「What is important is seldom urgent, and what is urgent is seldom important」(Eisenhower)
