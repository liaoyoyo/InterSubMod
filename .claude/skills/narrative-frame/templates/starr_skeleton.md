# STARR Skeleton

> STAR + Reflection — 反思型 portfolio

```markdown
---
framework: STARR
when: <教育 portfolio / reflective practice / PhD viva / medical training>
---

【S】Situation: <情境>
【T】Task: <任務 / 目標>
【A】Action: <行動>
【R】Result: <結果>
【R】Reflection: <反思 — 學到什麼 / 下次會怎麼做 / 對自己的影響>

---

範例:

【S】2026-Q1 V3F 修正後 12 月才發現 1.77× assignment 偏置
【T】audit 為什麼沒早發現 root cause
【A】per-region HP ratio 分析 + 5 Whys
【R】Root cause = chr-level metric 盲點；修正設計 metric
【Reflection】下次新方法上線前必加 per-region / per-chr 細粒度 monitoring；不能只看 chr-level 平均。已加進 monitoring dashboard。

---

Framework: STARR (Education portfolio / reflective practice)
```
