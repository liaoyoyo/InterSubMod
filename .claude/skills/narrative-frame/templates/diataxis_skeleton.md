# Diátaxis Skeleton

> Daniele Procida — Tutorial / How-to / Reference / Explanation (2×2)

```markdown
---
framework: Diátaxis
when: <技術文件 / API doc / SDK / developer portal>
---

# <Library / Tool Name> Documentation

## 2×2 Framework Map

|                | Hands-on (Acquisition) | Cognition (Application) |
|----------------|------------------------|-------------------------|
| **Learning**   | 📘 Tutorial            | 💡 Explanation          |
| **Working**    | 🛠 How-to Guide         | 📚 Reference            |

---

## 📘 Tutorial — Learning by doing

**For**: 新手第一次使用
**Style**: hands-on; lesson; step-by-step; explicit
**Promise**: 「If you follow these steps, you will succeed」

### Structure
1. Setup（5 min）
2. Hello-world example
3. First non-trivial example
4. Wrap-up + next steps

---

## 🛠 How-to Guide — Goal-oriented recipe

**For**: 已知工具，想完成具體任務
**Style**: 直接回答「如何做 X」
**Promise**: 「Here's how to achieve X」

### Structure
1. Goal statement
2. Prerequisites
3. Steps（最短路徑）
4. Verification

---

## 📚 Reference — Information lookup

**For**: 用 API 時查 spec
**Style**: 精確、完整、不解釋
**Promise**: 「Here's what X does, exactly」

### Structure
- API signature
- Parameters table
- Return types
- Examples (minimal)

---

## 💡 Explanation — Understanding why

**For**: 想理解 design rationale / context
**Style**: discursive; 可以 opinion
**Promise**: 「Here's why X is designed this way」

### Structure
- Problem this solves
- Design choices + trade-offs
- Alternatives considered
- When NOT to use

---

範例（InterSubMod doc layout）:
- Tutorial: `InterSubMod/docs/references/manual/20260424_AI啟動壓縮上下文與研究索引_01.md`
- How-to: `InterSubMod/.claude/rules/workflow-commands.md`
- Reference: `InterSubMod/include/core/*.hpp`
- Explanation: `InterSubMod/docs/concepts/`

---

Framework: Diátaxis (Daniele Procida [diataxis.fr](https://diataxis.fr/))
```
