# PEEL Skeleton — Point / Evidence / Explain / Link

> Secondary education essay-writing pedagogy

```markdown
---
framework: PEEL
when: <學術 paragraph / essay / 文章段落>
---

【P】Point: <段落主張 — topic sentence 1 句>

【E】Evidence: <證據 — quotation / data / case>

【E】Explain: <解釋 — Evidence 如何支持 Point；機制 + reasoning>

【L】Link: <連結 — 回到 thesis / 過渡到下段>

---

範例（paper paragraph 寫作）:

【P】V6 binary 修正完整解決了 chr19 HP tag priority bug。
【E】LOSO 驗證 752/752 chr19 reads 在 5 sample 100% rescued（HCC1395 ΔF1 = +0.022, p < 0.001, Cohen d = 1.3）。
【E】此結果證明 V3F 的 hp=33 保守處理是 unnecessary defensive — V6 同時處理 assignment + priority 兩層 bug 後，原本 V5 設計缺陷的 Layer 1.5 germline-absent 區也回歸正常 1.2:1 ratio（vs 過去 4.19:1）。
【L】然而，cross-sample 仍有 caller-F1-ceiling 限制其他 4 樣本進一步突破 — 此將在下段 chr8 zone gate 討論中展開。

---

每段必有 PEEL 結構（especially academic writing）；缺 L → 段落孤立，文章結構鬆散

---

Framework: PEEL (UK / Australia secondary education essay pedagogy)
```
