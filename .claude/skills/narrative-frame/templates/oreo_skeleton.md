# OREO Skeleton

> Opinion / Reason / Example / Opinion — 立場性發言

```markdown
---
framework: OREO
when: <辯論 / 社論 / 立場性發言>
---

【O】Opinion: <你的立場 / 觀點 — 主觀，1 句>

【R】Reason: <為什麼這樣覺得 — 1 個強理由>

【E】Example: <1 個具體例子 / 案例支持>

【O】Opinion: <重申立場，可加情緒強度>

---

範例:

【O】我認為 Cycle 5 應該 pivot 至 chr8 zone gate，不要繼續 LR direction
【R】因為 caller_af direction-inconsistency 跨樣本是 LOSO 災難主因，純 LR 已 exhausted
【E】Cycle 4 H_NEW_4 drop caller_af 後 HCC1395 +0.00699 single-sample，但其他 4 樣本仍卡住 — 證明 LR 不是 cross-sample 解
【O】所以 Cycle 5 必須換 framework — boolean rule / zone gate 才有突破可能

---

差別 vs PREP:
- PREP 強調**事實結論**（客觀）
- OREO 強調**立場觀點**（主觀）

---

Framework: OREO (PREP 變體 — 立場性發言)
```
