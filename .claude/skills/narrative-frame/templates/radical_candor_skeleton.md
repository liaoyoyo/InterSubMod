# 2 軸 4 象限

```
                Challenge Directly
                  ↑
                  │
  Ruinous Empathy │ Radical Candor    ← 理想

─────────────────┼──────────────────→ Care Personally
                  │
  Manipulative   │ Obnoxious
  Insincerity    │ Aggression
                  │
```

## 4 象限定義

### ✅ Radical Candor (Care + Challenge)
- Care Personally: 真正關心對方成長
- Challenge Directly: 直説 + 具體
- 範例:「你今天 lab meeting 報告有點散；我想幫你下次更聚焦 — 開頭直接講 V6 verdict 而不是 timeline」

### ❌ Obnoxious Aggression (No Care + Challenge)
- 只直説不關心 → 對方感覺被攻擊
- 範例:「你 lab meeting 講得超爛」

### ❌ Ruinous Empathy (Care + No Challenge)
- 關心但不敢説 → 對方無法成長
- 範例:「沒事，講得還不錯！」（其實心想很散）

### ❌ Manipulative Insincerity (No Care + No Challenge)
- 既不關心也不直説 → 最糟
- 範例:「呃 還行」+ 心想懶得管

## 應用 step

1. **建立 Care Personally** — 平時花時間了解對方目標 / 個人狀況
2. **再開始 Challenge Directly** — Care 建立後挑戰才會被接受
3. **觀察反應** — 如果對方退縮 → 重新 establish Care
4. **持續 push 自己進 Radical Candor 象限** — 大部分 manager 卡在 Ruinous Empathy
