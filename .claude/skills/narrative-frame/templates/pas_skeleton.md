# PAS Skeleton — Problem / Agitate / Solution

> Direct-mail copywriting 1980s; Dan Kennedy

```markdown
---
framework: PAS
when: <copywriting / 痛點行銷 / insurance / financial>
---

【P】Problem: <識別痛點 — audience 已知或潛在>

【A】Agitate: <放大痛感 — emotional + 量化後果 + 不採取的損失>

【S】Solution: <你的方案 — 解除痛點 + 量化 benefit>

---

範例（ISM tool pitch）:

【P】你的 cancer variant report 還在用 caller default — 漏 30% 真 somatic

【A】每 1 個漏掉的 driver mutation = 1 個 patient 沒拿到對的治療；過去 12 個月你的 lab 跑 200 樣本 → 估計 60 個 missed driver；如果是你親人的 sample 呢？

【S】ISM filter 接 caller 後可 rescue 80% missed driver；單機 3 day 跑完 200 樣本；本週可上線

---

⚠ 倫理注意: PAS 容易過度操弄 (especially in healthcare)。確保 Agitate 階段不誇大 — 用真實數據 + 客觀後果。

---

Framework: PAS (Direct-mail copywriting; Dan Kennedy《Ultimate Sales Letter》)
```
