# AIDA Skeleton

> E. St. Elmo Lewis《Financial Advertising》(1908) — Attention / Interest / Desire / Action

```markdown
---
framework: AIDA
when: <廣告 copy / landing page / email / pitch>
---

# <Title — Attention hook>

## A — Attention（吸引注意）

<最強 hook：問題 / 數字 / 反常識 / 衝擊圖>

範例: 「90% 的 ONT cancer caller 漏掉 chr8 hotspot — 包括 ClairS-TO」

## I — Interest（建立興趣）

<為什麼受眾應該繼續讀 — 連結到他們關心的痛點>

## D — Desire（激發渴望）

<描繪解決後的世界 — 用具體 metric 量化 benefit>

## A — Action（呼籲行動）

<明確要求受眾做什麼 — 1 個 action，不模糊>

---

Framework: AIDA (Lewis 1908; copywriting standard)
```
