# comparison_report — 比對模板

## 觸發 keyword
「A vs B / 對照 / 差異 / before-after / benchmark / 比較」

## narrative skeleton
Setup → Method A → Method B → Side-by-side → Verdict

## 常見頁面（6-8）
1. Setup definition (1)
2. Method A overview (1-2)
3. Method B overview (1-2)
4. Side-by-side metrics table (1)
5. 4-quadrant matrix (optional)
6. Verdict + caveats (1)

## 範例
Phase 1A F1 paired vs TO 對照；longphase TO vs V5 Somatic Fallback 技術報告

## 對應 layouts
side_by_side_compare / 4quadrant_matrix / before_after_split

## counter-example
三方比較（應改用 3-column layout 或拆兩份 comparison）
