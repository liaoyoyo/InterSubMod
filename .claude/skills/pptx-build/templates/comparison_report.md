# comparison_report — 比對模板

## 觸發 keyword
「A vs B / 對照 / 差異 / before-after / benchmark / 比較」

## narrative skeleton
Setup → Method A → Method B → Side-by-side → Verdict

## 常見頁面（6-8）
1. Setup definition (1)
2. Method A overview (1-2)
3. Method B overview (1-2)
4. Side-by-side metrics table (1)
5. 4-quadrant matrix (optional)
6. Verdict + caveats (1)

## 範例
Phase 1A F1 paired vs TO 對照；longphase TO vs V5 Somatic Fallback 技術報告

## 對應 layouts
side_by_side_compare / 4quadrant_matrix / before_after_split

## counter-example
三方比較（應改用 3-column layout 或拆兩份 comparison）

---

## 業界框架對應（2026-05-08 Stage 1 補強）

### SCQA 對應（McKinsey/Minto）

| skeleton 段落 | SCQA |
|---|---|
| Setup（共同前提）| **Situation** — 雙方共享的 baseline |
| Method A vs B | **Complication** — 哪個更好？|
| Side-by-side metrics | **Question** — 量化比較依據 |
| Verdict + caveats | **Answer** — 結論 + scope 限制 |

### McKinsey vs-table 結構（think-cell 標準）

think-cell vs-table 是顧問常用 component：左欄（A）/ 右欄（B）/ 底部 metric row 並列。我們的 side_by_side_compare layout 等同此結構。

### Pyramid Principle 子應用

Verdict slide 標題即「答案」，下方 2-4 個 supporting metrics 構成證據層；caveat 為例外條件。
