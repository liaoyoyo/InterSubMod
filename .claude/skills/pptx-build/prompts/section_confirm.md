# section_confirm.md — P3 → C3 (×N section)

## 使用時機
每 section 5-7 slide 草綱完成後，分批確認（不一次給全部）。

## AskUserQuestion

```yaml
question: "Section <N>: <名稱>，<5-7> slide 標題 + focal point ≤ 20 字。批准？"
options:
  - 批准 section（進下一 section）
  - 修改某 slide focal point
  - 補 slide
  - 刪 slide
```

## 強制檢查
- 每 slide focal point ≤ 20 字
- focal point derive from section thesis（§20.B）
- focal point 出現在標題（assertion-evidence）

## 一次只給一個 section（不一次給全部）
