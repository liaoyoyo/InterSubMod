# 圖例分級顯示 — cognitive-load tiering（隱藏非必要 · 依目的分級）

> **原則**：每張圖有一個**目的**。只顯示服務該目的的資訊；非必要資訊增加認知負擔、甚至誤導 → 隱藏。
> 對齊 design_principles Rule 14（progressive disclosure）+ Tufte data-ink + Franconeri「比較是慢任務」（preattentive 編碼省一個就少一次掃描）。

## 4 級 tier

| 級 | 定義 | 預設處理 | 例 |
|----|------|---------|----|
| **L0 必要** | 圖的論點本身，缺了圖不成立 | **顯示**（最高對比）| 變異位置+類別、HP 分群、Δβ 方向、甲基差異、新舊對照 |
| **L1 輔助** | 幫助定位但非論點，低負擔 | **淡化**（灰/小/邊緣）| 座標軸、群組標籤、anchor 位點虛線、單位 |
| **L2 on-demand** | 只在特定目的需要才顯 | **預設隱藏**，目的需要才開 | base 字母（哪種突變）、精確 per-read 數值、read id |
| **L3 噪音** | 不服務目的、增負擔/誤導 | **隱藏** | 背景 base、冗餘格線、重複 legend、裝飾線條 |

## 判斷流程（每個元素問 3 題）
1. 缺了它，圖的論點還成立嗎？→ 不成立 = **L0**。
2. 它幫助理解但非論點？→ **L1**（淡化）。
3. 它只在某種目的下才有意義？→ 該目的才開 = **L2**；否則 = **L3**（隱藏）。

## 領域具體規則（本專案）
- **背景 base（ATGC 非變異位）= L3** → 預設隱藏。除非目的＝完整序列比對。
- **突變 base 字母 = L2** → 預設隱藏（只顯**位置 + 類別色**）；**僅當目的＝「強調哪種突變」或「區分 base 突變 vs 甲基差異」才顯**。
- **變異位置 + 類別色 = L0** → 一律顯（category-by-FILL，不換形狀）。
- **甲基化 cell（red>0.5 / blue<0.5 ramp）= L0**（甲基圖）；genotype 字母在甲基圖中 = L3（除非 base-vs-methyl 對照）。
- **HP 分群 = L0**（haplotype 圖）→ 用**色 + 分軌 + 標籤**承載，不靠 base。
- **數值精度**：聚合 metric = L0（但 ≤3 有效位）；per-read 原始數值 = L2。

## detail 參數對應（hap_split_track 等 primitive）
| detail | 含 tier | 負擔 | 何時 |
|--------|---------|------|------|
| `tick`（**預設**）| L0 only（變異位置+色）| 最低 | 「方法如何分群/分軌」「存在性」 |
| `base` | +L2（變異格顯字母）| 中 | 「強調哪種突變」 |
| `sequence` | +L3（全背景 base 淡顯）| 高 | 完整序列比對（特例）|

## 字型 / 對齊 / 目的
- **字級 6 階**（conventions §3）：title 24-44 / 區塊 18 / 內文 14 / 圖內標 12 / 軸 9-10 / micro **≥8**（**禁 <8 於可讀文字**）。
- **對齊**：同類元素共用基準 — 左標籤右切齊（`text-anchor=end`）、數值左切齊、欄置中（`middle`）；全圖左 margin 一致。
- **每個文字問「目的」**：標題=論點一句、軸標=定位、caption=可獨立讀懂。**無目的的字 → 刪**。
